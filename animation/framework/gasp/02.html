2.1 GASP的属性

2.1.1 gsap.effects

原文：GSAP v3 官方文档 gsap.registerEffect() / gsap.effects 作用：封装可复用动画片段，注册后通过 gsap.effects.xxx() 调用，支持直接挂载到 Timeline

gsap.effects 是存放所有已注册自定义动画效果的对象。 通过 gsap.registerEffect() 注册自定义动画效果后，即可在 gsap.effects 上访问该效果。 Effect 的本质：把一段动画封装成命名函数，接收目标元素与配置项，支持全局默认参数，还可以直接嵌入 Timeline 时间线，方便跨项目复用动画。

1. 使用方式

  • 方式1：直接调用 gsap.effects.effectName

    假设已经注册名为 explode 的 effect：

    gsap.effects.explode(".box", {
    direction: "up", // effect自定义参数，由注册者定义
    duration: 3,
});

  • 方式2：在 Timeline 上直接调用（需开启 extendTimeline: true）

    注册 effect 时配置 extendTimeline: true，会将 effect 挂载到 Timeline 原型上，直接在时间线实例调用，自动插入动画序列。

  • 示例：fade 淡出效果

    // 注册 effect
gsap.registerEffect({
    name: "fade",
    effect: (targets, config) => {
        // 返回 Tween / Timeline 实例
        return gsap.to(targets, { 
        duration: config.duration, 
        opacity: 0 
        });
    },
    defaults: { duration: 2 }, // 配置默认参数，调用时可覆盖
    extendTimeline: true, // 允许直接在 timeline 实例调用
});

// 用法1：直接调用 gsap.effects
gsap.effects.fade(".box");

// 用法2：在 timeline 上链式调用
let tl = gsap.timeline();
tl.fade(".box", { duration: 3 })
    .fade(".box2", { duration: 1 }, "+=2")
    .to(".box3", { x: 100 });

2. 核心能力

  • 4项核心能力

    1. 自动解析 targets 传入选择器字符串（.box），GSAP自动转为DOM元素数组，传递给 effect 回调函数，无需手动处理 querySelectorAll。
    2. 自动合并默认参数 defaults 每次调用 effect，自动把 defaults 和传入的 config 合并，不用手写大量 if 判断填充默认值。
    3. 统一注册与访问入口 所有自定义效果统一托管在 gsap.effects 对象，全局一处管理。
    4. extendTimeline 扩展时间线方法

  • extendTimeline: true：Effect 名称会成为 Timeline 的实例方法，直接链式调用。

    // extendTimeline: true 写法
const tl = gsap.timeline();
tl.yourEffect(".class", { configProp: "value" }, "+=position");

  • extendTimeline: false：需要手动使用 tl.add() 添加动画实例

    // extendTimeline: false 写法
const tl = gsap.timeline();
tl.add(
    gsap.effects.yourEffect(".class", { configProp: "value" }),
    "+=position"
);

    提示：大量在时间线序列中复用动画时，开启 extendTimeline: true 能大幅精简代码。

2.1.2 gsap.globalTimeline

gsap.globalTimeline 是驱动 GSAP 所有动画的根时间线实例。可以一次性控制页面内全部动画，是全局动画控制的强力入口。

注意：gsap.delayedCall() 在底层本质上也属于补间动画（tween）。如果对 globalTimeline 执行 pause() / 修改 timeScale()，delayedCall() 也会一同受到影响。 如果需要排除 delayedCall，使用 gsap.exportRoot()。

1. 常用方法

gsap.globalTimeline 本身就是 Timeline 对象，因此拥有 Timeline 的全部实例方法，下面是最常用的几个：

  1. gsap.globalTimeline.pause()

    暂停全局时间线，页面所有动画全部暂停。返回自身实例，支持链式调用。

    gsap.globalTimeline.pause();

  2. gsap.globalTimeline.play()

    恢复全局时间线播放，页面所有暂停动画恢复运行。返回自身实例，支持链式调用。

    gsap.globalTimeline.play();

  3. gsap.globalTimeline.paused()

    读取全局时间线暂停状态。

    • 返回 true：全局时间线处于暂停状态
    • 返回 false：全局时间线正在播放
    console.log(gsap.globalTimeline.paused());

  4. gsap.globalTimeline.timeScale()

    读取 / 设置全局时间缩放倍率，作用于页面全部动画。>

    原理：不是逐个修改每个 tween / timeline 的 timeScale，而是修改根时间线的播放速率。适合一次性全局加速、减速所有动画。

    // 设置全局动画速度为 2倍（全部动画变快）
gsap.globalTimeline.timeScale(2);

// 设置全局动画速度为 0.5倍（全部动画变慢）
gsap.globalTimeline.timeScale(0.5);

// 获取当前全局时间缩放值
console.log(gsap.globalTimeline.timeScale());

  5. 关键提示

    • 影响范围：页面所有 GSAP tween、timeline、delayedCall()
    • 副作用：delayedCall() 延迟回调也会跟着暂停/变速；如果需要剥离延迟回调，使用 gsap.exportRoot()
    • 使用场景：页面全局动画开关、全局慢动作演示、全局动画加速调试

2.1.3 gsap.ticker

gsap.ticker 是 GSAP 引擎的心跳。它会在每一次 requestAnimationFrame 事件更新 gsap.globalTimeline，与浏览器渲染周期完美同步。你可以添加自定义监听函数，在每次引擎更新后执行自定义逻辑（游戏开发场景非常适用），支持添加任意数量监听回调。

1. 基础用法

  1. 添加监听回调

    // 添加监听函数
gsap.ticker.add(myFunction);

function myFunction() {
// 在引擎核心更新完成后，每一帧都会执行
}

// 移除监听函数
gsap.ticker.remove(myFunction);

  2. 回调函数参数

    监听回调会自动接收3个参数：

    1. time：Number，ticker 启动后的总时间（单位秒）。lagSmoothing 可能会向前推移 ticker 的起始时间。
    2. deltaTime：Number，距离上一帧流逝的毫秒数。可使用 gsap.ticker.deltaRatio() 获取基于目标帧率的倍率。
    3. frame：Number，帧序号，每帧自动递增。
    function myFunction(time, deltaTime, frame) {
console.log(time, deltaTime, frame);
}
gsap.ticker.add(myFunction);

  3. .add() 的高级可选参数（GSAP 3.10.0+）

    gsap.ticker.add(callback, once, prioritize)

    • once：Boolean，true 时回调仅执行一次，执行完成自动移除。
    • prioritize：Boolean，true 会将回调插入队列头部，在 GSAP 全局时间线更新之前执行。
    // 在下一次 requestAnimationFrame 触发，在全局时间线更新前，仅执行一次
gsap.ticker.add(myCallback, true, true);

  4. 标签页隐藏时的节流策略

    当用户切换到其他浏览器标签页时，ticker 更新会被大幅节流，节省电池与CPU资源。底层由浏览器对 requestAnimationFrame 做限制。

    • 正常页面：requestAnimationFrame 通常 60次/秒，现代设备最高支持120Hz。
    • 浏览器不支持 requestAnimationFrame 时，自动降级为 setTimeout 循环。

2. Ticker 的属性与方法

  1. Ticker 内置属性

    • time：Number，ticker 启动后的总时间（单位秒），lagSmoothing 会影响该值。
    • frame：Number，帧序号，每帧自动递增。

  2. gsap.ticker.fps()

    限制 ticker 的目标帧率。

    浏览器原生 requestAnimationFrame 无法被提速（一般上限60fps），因此无法通过此方法提升帧率；仅能降低帧率，ticker 会自动跳帧逼近目标值。

    // 将 ticker 节流至 30fps
gsap.ticker.fps(30);

  3. gsap.ticker.deltaRatio()

    返回基于目标帧率的帧时间倍率。用于在帧率波动时保持物体运动速度恒定。默认基准帧率为60。

    gsap.ticker.add(function () {
    // 无论帧率高低，移动速度保持恒定（以60fps为基准）
    obj.x += 3 * gsap.ticker.deltaRatio(60);
});
    • gsap.ticker.deltaRatio()：默认以60fps为基准
    • gsap.ticker.deltaRatio(30)：以30fps作为基准计算倍率

  4. gsap.ticker.lagSmoothing()

    读写 GSAP 的卡顿平滑配置，用于处理CPU阻塞、掉帧场景下的动画时间补偿。

    • 原理

      当CPU负载过高，渲染出现延迟时：

      • 普通动画引擎会向前偏移动画起始时间，牺牲动画序列同步性，stagger 错开动画会错乱。
      • GSAP 默认优先保证动画同步；lagSmoothing 在检测到大延迟时，修改内部时钟，避免动画时间一次性大幅跳跃，所有动画（tween、timeline、delayedCall）保持同步。

    • 参数

      gsap.ticker.lagSmoothing(threshold, adjustedLag)

      • threshold：毫秒。两帧间隔超过该阈值，触发平滑补偿。默认 500。
      • adjustedLag：毫秒。触发补偿时，引擎模拟的流逝时间。默认 33。
      // 自定义配置：间隔大于1000ms才触发补偿，补偿时模拟流逝16ms
gsap.ticker.lagSmoothing(1000, 16);

// 关闭 lagSmoothing
gsap.ticker.lagSmoothing(0);

      注意：不要将两个参数设置得过低。会让动画看起来变慢，delayedCall 也会受到影响。默认 500,33 适合绝大多数场景，既防御长时间卡顿，又不会在小幅帧率波动时拖慢动画。

2.1.4 gsap.utils

gsap.utils 是 GSAP 内置工具集，提供一系列通用数学、数组、颜色、DOM 处理工具函数。很多工具支持返回可复用函数，可以直接传入 Tween 配置，常用于动画插值、数值映射、批量元素处理、随机值生成等场景。

1. 工具方法列表

  1. checkPrefix()

    获取 CSS 属性对应的浏览器厂商前缀版本。

    gsap.utils.checkPrefix("transform");
gsap.utils.checkPrefix("backdropFilter");
    • 参数：propertyName: string CSS属性名
    • 返回：带前缀的属性名，若不需要前缀则返回原名称

  2. clamp()

    将数值限制在 [min, max] 区间。超出上限返回最大值，低于下限返回最小值。支持直接求值，也可以返回可复用函数。

    // 直接求值
gsap.utils.clamp(0, 100, 120); // 100
gsap.utils.clamp(0, 100, -10); // 0

// 返回可复用函数
const clamp0To100 = gsap.utils.clamp(0, 100);
clamp0To100(200); //100

  3. distribute()

    根据元素在数组/网格中的索引批量分配数值，支持基准值、偏移总量、起始位置、网格模式、缓动曲线。常用于多元素错落动画。

    const distributor = gsap.utils.distribute({
  base: 0,
  amount: 200,
  from: "center",
  ease: "power1.out"
});
const boxes = gsap.utils.toArray(".box");
boxes.forEach((el, i) => {
  gsap.to(el, {x: distributor(i, boxes.length, el)});
});

    配置项：

    • base：基础起始值
    • amount：总偏移量
    • from：起始位置，支持 start / center / end / edges / random
    • grid：网格模式 [rows,columns]，auto 自动推断
    • axis：x / y，仅在网格模式生效
    • ease：缓动函数，控制数值分布曲线

  4. getUnit()

    提取字符串中的单位。

    gsap.utils.getUnit("20px"); // "px"
gsap.utils.getUnit("50%"); // "%"
gsap.utils.getUnit("300"); // ""

  5. interpolate()

    插值函数，支持数字、带单位字符串、颜色、数组、对象。可直接计算，也返回可复用函数接收 progress(0~1)。

  6. mapRange()

    值域映射，将一个区间内的值映射到另一个区间。

    // mapRange(inMin, inMax, outMin, outMax, value)

// 返回可复用映射函数

mapper(400);

  7. normalize()

    将给定区间的值归一化到 0~1。是 mapRange 的简化版本。

const norm = gsap.utils.normalize(10, 50);

  8. pipe()

    函数管道，依次执行传入函数，前一个函数返回值作为下一个函数输入。

  x => x * 2,
  x => x + 10

  9. random()

    生成随机值。支持区间、步长、随机数组取值。

    gsap.utils.random(0, 100);

gsap.utils.random(["red", "green", "blue"]); //随机取数组元素

  10. selector()

    生成带作用域的选择器函数，限定查询范围在指定DOM内部。

    const scopedSelector = gsap.utils.selector("#container");
scopedSelector(".item"); //等价于 document.querySelector("#container .item")

  11. shuffle()

    原地打乱数组（修改原数组）。

    const arr = [1,2,3,4];
gsap.utils.shuffle(arr);

  12. snap()

    数值吸附，把传入值吸附到最近的刻度值，可以是固定步长或者数组。

// 吸附到数组内最近值

  13. splitColor()

    解析颜色字符串，拆分为 [r,g,b] 或 [r,g,b,a] 数组。支持 HEX、rgb、颜色名称。

    gsap.utils.splitColor("red"); // [255,0,0]

2.2.1 gsap.config()

gsap.config() 用于配置 GSAP 全局层面的基础设置，配置不属于单个补间（Tween）的选项，例如 autoSleep、force3D、units 等。

提示：如果需要配置被单个补间继承的属性，请使用 gsap.defaults()，而非 gsap.config()。

1. 使用方式

  1. 语法

    gsap.config(settingsObject);

    只需传入需要修改的配置项；未传入的配置保持原有默认值。

  2. 配置项说明

    • autoSleep

      内部检测的帧间隔。GSAP 会按此间隔检查是否可以关闭内部 ticker，以此节省系统资源与移动端电量。

      • 默认值：120（大约每2秒检测一次）

    • force3D

      控制 transform 动画是否使用 3D 变换开启GPU加速。

      • "auto"（默认）：动画运行时自动使用 translate3d() 启用GPU加速；动画结束后，会切回2D translate()，释放GPU内存。
      • false：全程禁用3D变换，不自动切换。
      • true：强制所有 transform 相关补间使用3D变换，动画结束后不会切回2D。

    • nullTargetWarn

      当目标元素不存在（null），尝试执行动画时是否抛出控制台警告。

      • 默认：true（开启警告）
      • 设置为 false 可关闭该警告。

    • units

      设置各类CSS属性在未携带单位时使用的默认单位。 例如默认 left:100 会被解析为 100px。 可以单独修改指定属性的默认单位，仅配置的属性会被覆盖。

      • 大多数数值属性默认单位：px
      • 旋转相关属性默认单位：deg

    • trialWarn

      关闭GSAP试用版本相关的控制台提示。

  3. 示例

    gsap.config({
  autoSleep: 60,
  force3D: false,
  nullTargetWarn: false,
  trialWarn: false,
  units: { 
    left: "%", 
    top: "%", 
    rotation: "rad" 
  }
});

  4. 使用要点

    1. 全局一次性配置：建议在项目最开始、创建任何动画之前调用 gsap.config()。
    2. 作用域区分
      • gsap.config()：引擎全局底层配置，不作用于Tween参数继承。
      • gsap.defaults()：为所有新建Tween/Timeline设置默认参数（duration、ease等动画参数）。
    3. units仅影响未写单位的数值；如果写了 left:50px，单位不会被覆盖。

2.2.2 gsap.context()

gsap.context() 用于创建一个 GSAP 上下文环境，批量收集该上下文内创建的所有动画（Tween / Timeline），方便一次性销毁、清理，避免内存泄漏。在框架（Vue / React）组件销毁场景极其有用。

核心价值：自动追踪在回调函数内创建的所有GSAP动画，调用 .revert() 即可全部回滚并清理。

1. 使用方式

  1. 语法

    gsap.context((context) => {
  // 在回调内部创建的所有 tween / timeline 都会被当前上下文收集
  gsap.to(".box", { x: 100 });
}, root);

  2. 参数

    1. callback：函数，上下文回调。回调参数 context 为当前上下文实例。所有在此回调内定义的动画会被自动收集。
    2. root（可选）：DOM根节点 / 选择器字符串。用于限定选择器作用域，回调内的选择器只会在 root 节点内部查找元素。

2. Context 实例方法

  1. revert()

    回滚上下文内所有动画，恢复元素初始状态，并销毁动画。

    const ctx = gsap.context(() => {
  gsap.to(".box", {x:200});
});
// 清理
ctx.revert();

    可重复调用；revert 之后上下文不会失效，可以再次执行 revert。

  2. add()

    手动添加动画/时间线到当前上下文（用于回调外部创建的动画）。

    const tl = gsap.timeline();
ctx.add(tl);

  3. remove()

    手动从上下文移除指定动画/时间线。

    ctx.remove(tl);

  4. select()

    上下文内置的作用域选择器，等价于 gsap.utils.selector(root)。

    gsap.context((ctx) => {
  const box = ctx.select(".box");
  gsap.to(box, {x:100});
}, "#container");

3. 其他

  1. 基础示例

    // 创建上下文
const ctx = gsap.context(() => {
  gsap.to(".box", { x: 200, duration: 1 });
  gsap.from(".text", { opacity: 0, y: 20 });
});

// 一次性全部回滚清理
ctx.revert();

  2. 带 root 作用域示例

    限定选择器只在 #container 内部查找元素，防止跨DOM污染：

    const ctx = gsap.context((ctx) => {
  // 只会查找 #container 内部 .box
  gsap.to(ctx.select(".box"), { rotation: 360 });
}, "#container");

  3. 框架组件典型用法（React/Vue 思路）

    组件挂载创建上下文，组件卸载执行 revert，防止残留动画持续运行、内存泄漏：

    // 组件挂载时
const ctx = gsap.context(() => {
  gsap.to(".box", {x:100});
});

// 组件卸载时调用
onUnmounted(() => {
  ctx.revert();
});

  4. 关键说明

    1. 自动收集范围：回调函数内部同步创建的 gsap.to / gsap.from / gsap.fromTo / gsap.timeline()。

    2. 异步创建动画不会自动收集（setTimeout / Promise then 里面的动画），需要手动用 ctx.add() 添加。

      const ctx = gsap.context((ctx) => {
setTimeout(() => {
    const tween = gsap.to(".box", {x:100});
    ctx.add(tween); // 异步动画必须手动add
}, 100);
});

    3. revert() 会恢复元素样式到动画之前的状态，不是单纯暂停动画。

    4. 支持嵌套 context。

4. 完整实例

  • 代码示例

<html lang="zh-CN">

<head>
  <meta charset="UTF-8">

  <style>
    .box {
      width: 100px;
      height: 100px;
      background: #4285f4;
    }

    .ctrl button {
      margin: 4px;
    }
  </style>
  <script src="../js/gsap.min.js"></script>

    <button onclick="playAnim()">播放动画</button>

    }
  </script>

2.2.3 gsap.defaults()

gsap.defaults() 用于设置所有新建 Tween / Timeline 的全局默认配置。设置之后，后续创建的 gsap.to()、gsap.from()、gsap.fromTo() 都会自动继承这些参数；在单个动画里传入相同配置项时，可以覆盖全局默认值。

区分：gsap.config() 是 GSAP 引擎底层全局配置，不作用于动画参数；gsap.defaults() 专门用于动画实例的默认参数继承。

1. 使用方式

  1. 语法

    gsap.defaults(defaultObj);
    • defaultObj：对象，动画配置参数（duration、ease、delay 等）
    • 不传参数调用 gsap.defaults()，返回当前已设置的默认配置对象

  2. 基础示例

    // 设置全局默认：时长1秒，缓动 power2.out
gsap.defaults({
  duration: 1,
  ease: "power2.out"
});

// 不需要再写 duration 和 ease，自动继承
gsap.to(".box1", { x: 200 });
// 单个动画可以覆盖默认值
gsap.to(".box2", { x: 200, duration: 2 });

  3. 常用可配置参数

    • duration：动画时长，单位秒
    • ease：缓动函数
    • delay：动画延迟播放时间
    • repeat：重复次数
    • yoyo：是否往返播放
    • onComplete：动画完成回调>

    所有 Tween 支持的配置项都可以放在 defaults 中。

  4. 读取当前默认配置

    const currentDefaults = gsap.defaults();
console.log(currentDefaults);

  5. 清空默认配置

    传入空对象即可重置：

    gsap.defaults({});

  6. 作用范围与优先级

    1. 只影响调用 default 之后新创建的 Tween / Timeline；已经存在的动画不会受到影响。
    2. 优先级：单个动画配置 > gsap.defaults() > GSAP 内置原始默认值。
    3. Timeline 内添加的子动画同样继承 defaults。

  7. 注意事项

    1. gsap.defaults() 全局生效，建议在项目初始化阶段一次性配置。
    2. 不能用来设置 target（目标元素），defaults 只作用于动画配置属性。
    3. Timeline 本身也会继承 defaults，但 Timeline 的 defaults 属性优先级高于全局 gsap.defaults()。

    示例：Timeline 局部默认覆盖全局

    gsap.defaults({duration:1});
const tl = gsap.timeline({defaults:{duration:0.5}});
tl.to(".box", {x:100}); // 使用 tl 的 duration:0.5

2.2.4 gsap.delayedCall()

gsap.delayedCall() 用于创建延迟执行回调的Tween，等待指定秒数后运行回调函数。它属于GSAP时间体系，支持暂停、继续、销毁，会受全局时间缩放timeScale和pause控制。

区分：原生setTimeout不受GSAP时间线控制；gsap.delayedCall()和动画时间统一，适合动画序列编排。

1. 使用方式

  1. 语法

    gsap.delayedCall(delay, callback, params, scope);
    • delay：Number，等待时长，单位秒
    • callback：Function，延时结束执行的回调函数
    • params：Array 可选，传递给回调的参数数组
    • scope：Object 可选，回调函数内this指向的对象
    • 返回值：Tween实例，拥有Tween通用控制方法（pause、resume、kill、timeScale等）

  2. 基础示例

    // 延迟2秒执行回调
gsap.delayedCall(2, () => {
  console.log("2秒后执行回调");
});

// 带参数传递
function logMsg(text) {
  console.log(text);
}
gsap.delayedCall(1, logMsg, ["延迟1s的消息"]);

  3. 控制延时实例

    // 保存延时实例用于控制
const delayTask = gsap.delayedCall(3, () => {
  console.log("3秒触发");
});

delayTask.pause();      // 暂停倒计时
delayTask.resume();     // 恢复倒计时
delayTask.kill();       // 销毁任务，回调不再执行
delayTask.timeScale(2); // 倒计时速度放大2倍

  4. 加入Timeline序列

    const tl = gsap.timeline();
tl.to(".box", { x: 200, duration: 1 })
  // 在当前时间0.5位置添加延时回调
  .add(gsap.delayedCall(0.5, () => console.log("动画中途执行")))
  .to(".box", { y: 100 });

  5. 作用特点

    1. 本质是无属性动画的Tween，会被gsap.globalTimeline全局暂停/时间缩放影响。
    2. 回调只会执行一次。
    3. 调用kill()可以取消回调，页面销毁时建议销毁实例，避免内存泄漏。
    4. 如果需要不受全局时间线影响的延时，可以使用gsap.exportRoot()。

2.2.5 gsap.exportRoot()

gsap.exportRoot() 将当前挂载在 globalTimeline 上所有现有的Tween、Timeline（可选是否包含delayedCall）转移封装到一个全新的Timeline实例中。之后你可以单独控制这个新Timeline，不会影响调用 exportRoot 之后新建的动画。

区分：gsap.globalTimeline.pause() / timeScale() 会影响全部动画；exportRoot() 只是把执行那一刻已存在的动画打包到新时间线，打包之后新创建的动画依旧挂载在 globalTimeline，不受这个打包出来的Timeline控制。

1. 使用方式

  1. 语法

    gsap.exportRoot(includeDelayedCalls);
    • includeDelayedCalls：Boolean，可选，默认true。设置为false时，打包时会排除delayedCall。
    • 返回值：Timeline实例

  2. 基础示例

    // 创建两个动画，此时挂载在 globalTimeline
gsap.to(".box1", { x: 200, duration: 1 });
gsap.to(".box2", { y: 100, duration: 1 });

// 将上面已存在动画打包转移到新timeline
const rootTl = gsap.exportRoot();

// 单独控制打包出来的动画，只影响box1、box2
gsap.to(rootTl, { timeScale: 0.2, duration: 0.5 });

// exportRoot之后新建的动画，不受 rootTl 的控制
gsap.to(".box3", { rotation: 360, duration: 2 });

  3. 排除 delayedCall

    // 这个delayedCall会被打包（默认includeDelayedCalls:true）
gsap.delayedCall(2, ()=>console.log("call1"));
const rootTl = gsap.exportRoot(false); 
// false，打包时不包含已存在的 delayedCall

  4. 核心逻辑说明

    1. gsap.globalTimeline.pause() 依然会影响所有动画，包括exportRoot打包出来的Timeline。exportRoot不是脱离globalTimeline，而是做一次动画迁移隔离：打包后的动画归新Timeline管理；打包之后新建动画不受rootTl操作影响。
    2. 典型场景：游戏动画整体减速，但是弹窗动画保持正常速度。
    // 游戏内已有大量动画

// 游戏动画变慢

// 弹窗动画是exportRoot之后创建，不受gameTl.timeScale影响
gsap.from(".modal", { scale: 0, duration: 1 });

  5. 作用特点

    1. 执行时机很关键：只捕获调用瞬间已经存在的动画；之后新增动画不会自动进入这个rootTl。
    2. exportRoot() 返回的Timeline拥有Timeline全部API：pause、resume、timeScale、kill等。
    3. globalTimeline 的全局暂停/时间缩放依然作用于exportRoot返回的Timeline，因为它本身还是globalTimeline的子时间线。
    4. 页面销毁时，可对rootTl调用.kill()，释放打包的所有动画。

2.2.6 gsap.from()

gsap.from() 创建一个补间动画，从你定义的起始属性值，动画到元素当前的状态。相当于反向的 gsap.to()，非常适合入场动画，元素最终样式直接写在CSS中，动画只需要定义“从哪个状态进入页面”。

区分：gsap.to() 从当前状态，动画到目标值；gsap.from() 从指定起始值，动画回元素当前状态。

1. 使用方式

  1. 语法

    gsap.from(target, vars);
    • target：目标元素，可以是选择器字符串、DOM元素、数组、NodeList
    • vars：对象，动画配置与属性（duration、ease、opacity、x等）
    • 返回值：Tween实例，可以调用 pause()、resume()、kill()、timeScale() 等控制方法

  2. 基础示例

    // 元素从透明度0、向下偏移50px，动画回到自身原始状态
gsap.from(".box", {
  opacity: 0,
  y: 50,
  duration: 1
});

  3. 多元素 stagger 交错入场

    gsap.from(".item", {
  opacity: 0,
  scale: 0.8,
  y: 30,
  duration: 0.6,
  stagger: 0.15 // 每个元素动画间隔0.15秒
});

  4. 保存实例用于控制

    const tween = gsap.from(".box", {
  opacity: 0,
  x: -100,
  duration: 2,
  delay: 0.5
});

tween.pause();
tween.play();
tween.restart();

  5. 在 Timeline 中使用

    const tl = gsap.timeline();
tl.from(".title", { opacity: 0, y: -20 })
  .from(".content", { opacity: 0, y: 20 });

  6. 常用配置说明

    • duration：动画时长，单位秒
    • ease：缓动函数
    • delay：动画延迟播放
    • stagger：多目标动画错开时间
    • immediateRender：布尔值，默认true，动画立即渲染起始状态；设置false，则等到动画开始时才应用起始值（解决延时from动画闪烁问题）
    • onStart / onComplete：动画生命周期回调

  7. 作用特点

    1. 默认会立刻渲染起始状态，所以延时的from动画可能页面一加载就看到起始样式，此时设置 immediateRender: false。
    2. 动画终点依赖元素实时当前样式；重复执行动画时，如果元素样式被其他动画修改，效果会变化。这种场景推荐改用 gsap.fromTo()。
    3. 属于标准Tween，会受 globalTimeline 的 pause、timeScale 影响。

2.2.7 gsap.fromTo()

gsap.fromTo() 创建补间动画，同时手动定义动画起始值和结束值，不受元素当前状态干扰。适合动画状态需要精准控制的场景，不用担心元素当前样式被其他动画改变带来的效果异常。

区分：gsap.from() 终点为元素当前状态；gsap.to() 起点为元素当前状态；gsap.fromTo() 起点、终点全部由开发者指定。

1. 使用方式

  1. 语法

    gsap.fromTo(target, fromVars, toVars);
    • target：目标元素，可以是选择器字符串、DOM元素、数组、NodeList
    • fromVars：对象，动画起始属性配置
    • toVars：对象，动画结束属性配置
    • 返回值：Tween实例，可以调用 pause()、resume()、kill()、timeScale() 等控制方法

  2. 基础示例

    // 从透明度0、x偏移-100，动画到透明度1、x偏移0
gsap.fromTo(".box",
  { opacity: 0, x: -100 }, // from 起始状态
  { opacity: 1, x: 0, duration: 1, ease: "power2.out" } // to 结束状态
);

  3. 多元素 stagger 交错动画

    gsap.fromTo(".item",
  { opacity: 0, scale: 0.5 },
  { opacity: 1, scale: 1, duration: 0.6, stagger: 0.2 }
);

  4. 保存实例用于控制

    const tween = gsap.fromTo(".box",
  { rotation: 0 },
  { rotation: 360, duration: 2, delay: 0.5 }
);

tween.pause();
tween.play();
tween.restart();

  5. 在 Timeline 中使用

    const tl = gsap.timeline();
tl.fromTo(".title", {opacity:0,y:-30}, {opacity:1,y:0})
  .fromTo(".desc", {opacity:0,y:20}, {opacity:1,y:0});

  6. 常用配置说明

    • duration：动画时长，单位秒，写在 toVars 内
    • ease：缓动函数，写在 toVars 内
    • delay：动画延迟播放，写在 toVars 内
    • stagger：多目标动画错开时间，写在 toVars 内
    • immediateRender：布尔值，默认false；设为true会立即渲染起始状态
    • onStart / onComplete：动画生命周期回调，写在 toVars 内

  7. 作用特点

    1. 起始和结束属性完全固定，不受元素实时样式影响，可重复稳定播放动画。
    2. 动画时长、缓动、回调等配置必须写在第二个对象 toVars，fromVars 只放属性值。
    3. 属于标准Tween，会受 globalTimeline 的 pause、timeScale 影响。

2.2.8 gsap.getById()

gsap.getById() 通过动画实例的 id 获取对应的 Tween / Timeline 对象。在创建动画时配置 id 字段，之后就可以在任意位置通过这个id拿到动画实例，无需手动保存变量。

区分：保存实例变量是本地引用；getById() 是全局查找，适合跨函数、跨模块获取动画实例。

1. 使用方式

  1. 语法

    gsap.getById(id);
    • id：String，创建动画时定义的id名称
    • 返回值：Tween / Timeline 实例；找不到对应id时返回 null

  2. 基础示例

    // 创建动画，设置 id
gsap.to(".box", {
  x: 200,
  duration: 1,
  id: "boxAnim"
});

// 通过id获取动画实例
const anim = gsap.getById("boxAnim");
anim.pause();
anim.resume();

  3. Timeline 使用示例

    gsap.timeline({id:"mainTl"})
  .to(".box",{x:100})
  .to(".box",{y:100});

const tl = gsap.getById("mainTl");
tl.restart();

  4. 找不到实例返回 null

    const anim = gsap.getById("notExistId");
console.log(anim); // null

  5. 常用特点

    1. id 字符串区分大小写，同一个id只能对应一个动画实例，后创建的会覆盖。
    2. 动画被 kill() 销毁后，getById() 会返回 null。
    3. 适合大型项目，避免到处传递动画实例变量。
    4. 不推荐滥用，频繁查找会有微小性能开销；简单场景优先直接保存实例变量。

2.2.9 gsap.getProperty()

gsap.getProperty() 获取目标元素的指定属性值，可以读取 GSAP 动画正在修改的属性（包含transform：x/y/rotation等），也能读取元素的计算样式。相比原生 getComputedStyle，可以直接拿到 transform 分解后的独立数值，不用手动解析矩阵。

区分：原生 getComputedStyle 获取 transform 会返回矩阵字符串，难以直接拿到 x、y、rotation；gsap.getProperty() 可以直接读取分解后的变换数值。

1. 使用方式

  1. 语法

    gsap.getProperty(target, property, unit);
    • target：目标元素，可以是选择器字符串、DOM元素
    • property：字符串，要读取的属性名（x、y、rotation、opacity、width等）
    • unit：可选布尔值，默认false。true则返回带单位字符串（如"200px"）；false返回纯数字
    • 返回值：属性数值（默认数字）或带单位字符串

  2. 基础示例

    // 获取元素当前x值，返回数字
const xVal = gsap.getProperty(".box", "x");
console.log(xVal);

// 获取宽度，返回带px单位字符串
const widthStr = gsap.getProperty(".box", "width", true);
console.log(widthStr);

  3. 读取动画过程中的实时属性

    gsap.to(".box", { x: 200, duration: 3 });

// 定时器读取动画实时x值
setInterval(() => {
  console.log(gsap.getProperty(".box", "x"));
}, 100);

  4. 读取旋转属性

    gsap.to(".box", { rotation: 180, duration: 2 });
// 获取rotation数值
const rot = gsap.getProperty(".box", "rotation");
console.log(rot);

  5. 常用特点

    1. 支持读取 GSAP 特有的变换属性：x、y、xPercent、yPercent、rotation、scale等。
    2. 读取CSS普通属性同样生效：opacity、backgroundColor、height。
    3. 如果目标选择器匹配多个元素，只会读取第一个匹配元素的值。
    4. 可以读取动画运行中的实时渲染值。

2.2.10 gsap.getTweensOf()

gsap.getTweensOf() 获取目标元素上正在运行、等待运行或者已暂停的所有Tween实例，返回Tween数组。可以批量控制元素身上所有动画，例如一次性暂停、杀死某个元素的全部动画。

区分：gsap.getById() 通过id查找单个动画；gsap.getTweensOf() 通过DOM目标查找该元素绑定的全部动画集合。

1. 使用方式

  1. 语法

    gsap.getTweensOf(target, includeTimelines);
    • target：目标元素，可以是选择器字符串、DOM元素、DOM数组、NodeList
    • includeTimelines：Boolean，可选，默认false。true则会把Timeline内的子动画也一并纳入查找结果
    • 返回值：Tween实例数组，无动画时返回空数组

  2. 基础示例

    // 创建两个作用在.box上的动画
gsap.to(".box", { x: 200, duration: 2 });
gsap.to(".box", { y: 100, duration: 3, delay: 1 });

// 获取.box上所有tween
const tweens = gsap.getTweensOf(".box");
console.log(tweens);

// 批量暂停该元素所有动画
tweens.forEach(tween => tween.pause());

  3. 包含Timeline内部子动画

    const tl = gsap.timeline();
tl.to(".box", { x: 200 }).to(".box", { rotation: 180 });

// includeTimelines:true 会找到tl里面的子tween
const tweens = gsap.getTweensOf(".box", true);

  4. 批量销毁元素所有动画

    const tweens = gsap.getTweensOf(".box");
tweens.forEach(tween => tween.kill());

  5. 常用特点

    1. 返回数组包含：播放中、暂停、延迟等待中的动画；已经kill()销毁的动画不会出现在结果内。
    2. 默认只查找直接绑定在目标上的Tween；Timeline内部动画默认不返回，需要开启第二个参数。
    3. 如果传入多个DOM元素，会收集所有匹配元素上的动画。
    4. 适合交互场景：点击时先清除元素旧动画，防止动画叠加冲突。

2.2.11 gsap.isTweening()

gsap.isTweening() 判断目标元素当前是否正在执行动画，返回布尔值。常用于防止重复触发动画、做动画状态判断。

区分：gsap.getTweensOf() 返回元素所有动画数组；gsap.isTweening() 仅做布尔判断，使用更简洁。

1. 使用方式

  1. 语法

    gsap.isTweening(target);
    • target：目标元素，可以是选择器字符串、DOM元素
    • 返回值：true 代表正在动画中；false 无正在运行的动画（暂停、等待延迟的动画不算正在tweening）

  if(gsap.isTweening(".box")) return;

  4. 常用特点

    1. 仅判断正在运动的动画；处于pause()暂停状态、还未开始的延迟动画，都会返回false。
    2. 如果传入选择器匹配多个元素，只要其中任意一个元素在动画，就返回true。

2.2.12 gsap.killTweensOf()

2.2.13 gsap.matchMedia()

gsap.matchMedia() 基于媒体查询条件创建响应式动画，在匹配媒体查询时注册动画；媒体查询条件变化（窗口大小改变）时自动清理对应动画，方便做移动端/桌面端不同的动画逻辑。

区分：原生 window.matchMedia 只做条件判断，需要手动监听窗口变化、手动销毁动画；gsap.matchMedia() 自动管理动画生命周期，条件不匹配自动kill动画。

1. 使用方式

  1. 语法

    gsap.matchMedia().add(mediaQuery, callback);
    • mediaQuery：字符串，媒体查询语句，和CSS媒体查询写法一致
    • callback：函数，媒体查询满足时执行，回调参数包含一个context对象，在里面创建动画
    • 返回值：MatchMedia实例，可调用.remove()销毁全部注册的媒体动画

  2. 基础示例

    // 窗口宽度 >=768px 执行桌面端动画
gsap.matchMedia().add("(min-width:768px)", (context) => {
  // context内部创建的动画会在媒体条件不满足时自动销毁
  context.add(() => {
    gsap.to(".box", { x: 300, duration: 1 });
  });
});

  3. 多媒体查询同时注册

    const mm = gsap.matchMedia();

// 桌面端
mm.add("(min-width:768px)", (context) => {
  context.add(() => {
    gsap.to(".box", { x: 300, rotation: 180 });
  });
});
// 移动端
mm.add("(max-width:767px)", (context) => {
  context.add(() => {
    gsap.to(".box", { y: 200, scale: 0.8 });
  });
});

  4. 手动销毁全部matchMedia动画

    const mm = gsap.matchMedia();
// ...注册动画
mm.remove();

  5. 常用特点

    1. 窗口尺寸切换，自动销毁不再匹配的动画，不会出现多套动画叠加冲突。
    2. 动画代码必须写在 context.add() 的回调内，才能被自动管理。
    3. 支持多个媒体查询分支，互不干扰。
    4. 适合响应式网站，不同屏幕尺寸播放不一样的入场/交互动画。

2.2.14 gsap.matchMediaRefresh()

gsap.matchMediaRefresh() 强制刷新所有 gsap.matchMedia() 的媒体查询状态，重新评估媒体查询条件并执行对应的动画逻辑。窗口尺寸变化时 matchMedia 默认会自动触发更新，但某些场景下手动调用此方法强制重新校验。

区分：gsap.matchMedia() 用来注册多套响应式动画；gsap.matchMediaRefresh() 是主动触发一次媒体查询重新匹配，强制更新已注册的 matchMedia 实例。

1. 使用方式

  1. 语法

    gsap.matchMediaRefresh();
    • 无参数
    • 返回值：无返回值

  2. 基础示例

    // 注册媒体查询动画

mm.add("(min-width:768px)", (context) => {
  context.add(() => {
    gsap.to(".box", { x: 300, duration: 1 });
  });
});

// 手动强制刷新媒体查询匹配状态
gsap.matchMediaRefresh();

  3. 适用场景示例

  document.body.classList.toggle("compact-layout");
  // 布局发生变化，主动刷新matchMedia
  gsap.matchMediaRefresh();
};

  4. 常用特点

    1. 浏览器窗口 resize 时，gsap.matchMedia() 会自动执行匹配，一般不需要手动调用。
    2. 当页面布局改变不是由窗口大小变化引起（例如容器缩放、DOM结构变化、CSS类切换），媒体查询条件发生变化但不会自动触发时，调用该方法。
    3. 会对页面上所有已注册的 matchMedia 实例统一刷新，不是单独某一个实例。
    4. 会自动销毁不再匹配的动画，新建满足条件的动画，和自动触发的行为完全一致。

2.2.15 gsap.parseEase()

gsap.parseEase() 将缓动函数字符串（如 "power2.out"）或者缓动函数对象，解析成一个缓动计算函数。该函数接收一个0~1的进度值，返回对应插值结果，方便你在自定义渲染逻辑中复用GSAP的缓动算法。

区分：GSAP内置缓动直接写在动画配置里即可；parseEase() 用于脱离Tween，单独拿到缓动计算函数，在canvas、自定义ticker动画等场景使用。

1. 使用方式

  1. 语法

    gsap.parseEase(ease);
    • ease：String | Function，缓动名称字符串（"power2.out"、"elastic.out(1,0.3)"）或者缓动函数
    • 返回值：Function，接收单个参数progress（0~1），返回插值结果

  2. 基础示例

    // 解析缓动字符串得到缓动函数
const easeFn = gsap.parseEase("power2.out");

// progress范围0~1
console.log(easeFn(0));   // 0
console.log(easeFn(0.5)); // 0.75
console.log(easeFn(1));   // 1

  3. 在gsap.ticker自定义动画中使用

    const easeFn = gsap.parseEase("elastic.out(1,0.3)");
let progress = 0;

gsap.ticker.add(() => {
  progress += 0.01;
  if(progress > 1) progress = 0;
  const val = easeFn(progress) * 200;
  gsap.set(".box", { x: val });
});

  4. 常用特点

    1. 支持全部GSAP内置缓动，包括带参数的elastic、back缓动。
    2. 输入为函数时，直接原封不动返回该函数。
    3. 仅做数学计算，不会创建任何Tween，不操作DOM，纯计算工具。
    4. 进度参数必须是0到1之间，超出范围也会计算，适合回弹类缓动。

2. 完整实例

  • 代码示例

    <!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <style>
    .box {
      width: 80px;

      const now = performance.now();
      progress = (now - startTime) / (duration * 1000);
      if (progress > 1) {
        progress = 0;
        startTime = now;
      }
      const x = easeFn(progress) * 250;
      gsap.set(box, { x });
    });
  </script>

2.2.16 gsap.quickSetter()

1. 使用方式

  1. 语法

    • 返回值：Setter函数，调用时传入属性值即可更新元素

    3. 不创建Tween动画，仅即时赋值修改元素样式。

2.2.18 gsap.registerEase()

gsap.registerEase() 用于注册自定义缓动函数，注册完成后就可以像使用GSAP内置缓动（power2.out）一样，直接在动画配置中通过名称调用自定义缓动。

区分：gsap.parseEase() 是读取并解析已存在的缓动；gsap.registerEase() 是把你自己编写的缓动逻辑注册到GSAP全局，提供给所有Tween/Timeline使用。

1. 使用方式

  1. 语法

    gsap.registerEase(name, easeFunction);
    • name：String，自定义缓动的名称，后续动画中直接填写这个名字
    • easeFunction：Function，缓动函数，接收一个progress参数（范围01），返回01之间的插值结果
    • 返回值：无返回值

  2. 基础示例

    // 注册自定义缓动：二次曲线 easeIn
gsap.registerEase("myEaseIn", function(progress) {
  return progress * progress;
});

// 在动画中直接使用注册好的自定义缓动
gsap.to(".box", {
  x: 200,
  duration: 1,
  ease: "myEaseIn"
});

  3. 带参数自定义缓动（高级用法）

    // 注册支持传参的缓动函数
gsap.registerEase("myPow", power => progress => Math.pow(progress, power));

// 使用：传入参数 3
gsap.to(".box", {
  x: 200,
  duration: 1,
  ease: "myPow(3)"
});

  4. 常用特点

    1. 注册操作建议放在项目初始化阶段，在创建动画之前执行。
    2. 缓动函数入参progress取值0（动画开始）到1（动画结束）；返回值允许超出0~1，用来实现回弹效果。
    3. 全局注册后，所有gsap.to/from/fromTo、Timeline都可以使用该缓动名称。
    4. 如果注册重名缓动，会覆盖之前同名的缓动定义。

2. 完整实例

  • 代码示例

    <!DOCTYPE html>
<html lang="zh-CN">
<head>

  <style>
    .box {
      width: 80px;

      margin: 10px;
    }
  </style>
  <script src="../js/gsap.min.js"></script>

2.2.19 gsap.registerEffect()

gsap.registerEffect() 注册可复用的动画效果，注册完成后可以通过 gsap.effects.xxx() 调用，也可以直接在 Timeline 链上调用（配置 extendTimeline:true）。用于封装一套固定动画逻辑，一处定义，多处复用。

区分：普通函数封装动画每次都要手动传入目标和配置；registerEffect 将动画封装为GSAP全局effect，支持默认参数、参数覆盖，可直接在timeline链式调用。

1. 使用方式

  1. 语法

    gsap.registerEffect({
  name: String,
  effect: (targets, config) => {
    // 返回Tween / Timeline实例
  },
  defaults: Object,
  extendTimeline: Boolean
});
    • name：effect名称，注册后使用 gsap.effects.[name]
    • effect：核心回调函数。targets 是传入的动画目标；config 是传入的配置，会合并defaults。必须返回Tween或Timeline实例
    • defaults：可选，effect默认配置参数，调用effect时传入的参数会覆盖默认值
    • extendTimeline：可选，默认false；设为true，就可以直接在Timeline实例上链式调用 .effectName()

  2. 基础示例

    // 注册一个入场动画效果
gsap.registerEffect({
  name: "fadeInUp",
  defaults: {duration:0.6, y:30},
  effect: (targets, config) => {
    return gsap.from(targets, {
      opacity:0,
      y: config.y,
      duration: config.duration
    });
  }
});

// 调用effect，使用默认参数
gsap.effects.fadeInUp(".box");

// 调用effect，覆盖默认配置
gsap.effects.fadeInUp(".box", {duration:1, y:50});

  3. extendTimeline:true 在Timeline链式调用

    gsap.registerEffect({
  name: "fadeInUp",
  defaults: {duration:0.6, y:30},
  extendTimeline:true,
  effect: (targets, config) => {
    return gsap.from(targets, {opacity:0, y:config.y, duration:config.duration});
  }
});

const tl = gsap.timeline();
tl.fadeInUp(".title")
  .fadeInUp(".content", {duration:0.8});

  4. 常用特点

    1. 注册建议放在项目初始化，在调用effect之前执行。
    2. effect 回调必须返回动画实例，Timeline才能识别插入时间线。
    3. 支持多目标传入，GSAP内部自动处理targets数组。
    4. 可在effect内部组合多个tween，封装复杂动画序列。
    5. 重名effect会覆盖之前注册的同名effect。

2.2.20 gsap.registerPlugin()

gsap.registerPlugin() 注册GSAP插件，注册之后插件功能才可以在项目中使用。GSAP很多扩展能力（ScrollTrigger、ScrollToPlugin、MotionPath等）都属于插件，需要先引入插件JS文件，再调用本方法注册。

区分：gsap.registerEffect() 注册自定义动画效果；gsap.registerPlugin() 注册GSAP插件，用来扩展GSAP原生能力。

1. 使用方式

  1. 语法

    gsap.registerPlugin(plugin1, plugin2, ...);
    • 参数：插件对象，可一次性传入多个插件，逗号分隔
    • 返回值：无返回值

  2. 基础示例

    // 引入插件后，进行注册
gsap.registerPlugin(ScrollTrigger);

// 注册完成，就可以使用ScrollTrigger功能
gsap.to(".box", {
  x: 300,
  scrollTrigger: {
    trigger: ".box",
    start: "top center",
    end: "bottom center",
    scrub: true
  }
});

  3. 一次性注册多个插件

    gsap.registerPlugin(ScrollTrigger, ScrollToPlugin, MotionPathPlugin);

  4. 常用特点

    1. 必须先加载插件脚本，再执行registerPlugin，否则插件对象不存在会报错。
    2. 注册操作全局生效，项目内只需要注册一次，建议放在入口文件。
    3. 不注册插件的情况下，插件对应的配置项不会生效，部分插件会抛出警告。
    4. 核心GSAP基础能力（to/from/fromTo等）不需要注册插件，插件只是扩展功能。

2. 完整实例

2.2.21 gsap.set()

gsap.set() 立刻设置目标元素属性，没有动画过渡，本质等同于时长为0的 gsap.to()。多用于初始化元素状态、预先设置样式，不会产生tween动画播放过程。

区分：gsap.to() 带过渡动画；gsap.set() 直接赋值，瞬间完成修改，不会占用时间。

1. 使用方式

  1. 语法

    gsap.set(target, vars);
    • target：目标元素，可以是选择器字符串、DOM元素、数组、NodeList
    • vars：对象，要设置的属性集合（x、y、opacity、scale、rotation等）
    • 返回值：Tween实例，虽然没有动画，但仍然可以调用kill()等方法

  2. 基础示例

    // 瞬间把box移动到x:200，透明度0.5，无动画
gsap.set(".box", {
  x: 200,
  opacity: 0.5
});

  3. 多元素批量设置

    gsap.set(".item", {
  y: 30,
  scale: 0.8,
  stagger: 0.1
});

  4. 在动画前初始化状态（高频场景）

    // 先设置初始状态
gsap.set(".box", { opacity:0, y:50 });
// 再播放入场动画
gsap.to(".box", { opacity:1, y:0, duration:1 });

  5. 常用特点

    1. 即时应用属性，不会有动画耗时，duration 参数会被忽略。
    2. 支持GSAP transform属性：x/y/scale/rotation/xPercent/yPercent。
    3. 返回Tween实例，可以调用kill()清除设置效果。
    4. 适合动画开始前，预先摆放元素位置、设置透明度。

2. 完整实例

2.2.22 gsap.timeline()

gsap.timeline() 创建时间线实例，用于编排多个动画的执行顺序，控制一组动画整体播放、暂停、重播。可以链式添加 tween，自由控制动画之间的时间偏移，实现复杂动画序列。

区分：gsap.to/from/fromTo 是单个补间动画；timeline 是动画容器，用来批量管理多个动画的时间关系。

1. 使用方式

  1. 语法

    gsap.timeline(vars);
    • vars：可选对象，时间线全局配置，如 duration、delay、repeat、yoyo、defaults
    • 返回值：Timeline实例，支持链式调用 .to() .from() .fromTo() 等方法

  2. 基础示例

    // 创建空时间线
const tl = gsap.timeline();

// 顺序执行动画：第一个结束后，第二个开始
tl.to(".box1", { x: 200, duration: 1 })
  .to(".box2", { y: 100, duration: 1 });

  3. 时间偏移控制（重叠动画）

    const tl = gsap.timeline();
tl.to(".box1", { x: 200, duration:1 })
  // "-=0.5"：在上一个动画结束前0.5秒就开始
  .to(".box2", { y:100, duration:1 }, "-=0.5");

  4. 时间线全局配置

    // 给整个timeline设置默认参数，内部所有tween继承
const tl = gsap.timeline({
  delay: 0.5,
  repeat: 2,
  yoyo: true,
  defaults: { duration: 0.8, ease: "power2.out" }
});
tl.to(".box1", { x:200 })
  .to(".box2", { rotation:180 });

  5. Timeline实例常用控制方法

    const tl = gsap.timeline();
tl.play();
tl.pause();
tl.restart();
tl.seek(0.5); // 跳转到0.5秒位置
tl.kill();

  6. 常用特点

    1. 默认按顺序播放，支持时间标签、偏移量，实现动画重叠、穿插。
    2. 时间线本身就是一个动画实例，可以整体控制播放/暂停/循环。
    3. 支持嵌套 timeline，把复杂动画拆分成多个子时间线。
    4. 可以搭配 gsap.context() 自动销毁，防止内存泄漏。

2.2.23 gsap.to()

gsap.to() 是GSAP最常用的补间动画方法，从元素当前状态开始，动画过渡到你定义的目标属性值。

区分：gsap.from() 从指定值动画到元素当前状态；gsap.fromTo() 同时定义起点和终点；gsap.set() 无过渡，直接设置属性。

1. 使用方式

  1. 语法

    gsap.to(target, vars);
    • target：目标元素，支持选择器字符串、DOM元素、DOM数组、NodeList
    • vars：对象，动画配置，包含目标属性、时长、缓动、回调、repeat等
    • 返回值：Tween实例，可调用play()、pause()、restart()、kill()等控制动画

  2. 基础示例

    // 从当前位置，动画到x=200，时长1秒
gsap.to(".box", {
  x: 200,
  duration: 1,
  ease: "power2.out"
});

  3. 循环往复动画示例

    gsap.to(".box", {
  x: 250,
  duration: 1.2,
  repeat: -1, // -1代表无限循环
  yoyo: true, // 往返动画
  ease: "sine.inOut"
});

  4. 保存实例，外部控制

    const anim = gsap.to(".box", {
  rotation: 360,
  duration: 2,
  paused: true // 创建时暂停，手动触发播放
});
anim.play();

  5. 常用特点

    1. 起点自动读取元素实时状态，不需要手动写起始属性。
    2. 支持GSAP变换属性：x、y、scale、rotation、xPercent、yPercent。
    3. 可配置回调函数：onStart、onUpdate、onComplete。
    4. 可直接嵌入Timeline时间线做序列动画。

2.2.24 gsap.updateRoot()

gsap.updateRoot() 强制立即更新全局根时间线（globalTimeline），手动触发一次所有动画的计算与渲染。GSAP 默认依靠 ticker 在浏览器每一帧自动更新，极少需要手动调用。

区分：gsap.ticker 自动按浏览器帧更新动画；gsap.updateRoot() 是手动强制单次更新，用于某些同步场景。

1. 使用方式

  1. 语法

    gsap.updateRoot(force);
    • force：Boolean，可选。true 强制更新，忽略内部时间判断；默认 false
    • 返回值：无返回值

  2. 基础示例

    // 手动触发一次全局动画更新
gsap.updateRoot();

// 强制更新，跳过内部时间校验
gsap.updateRoot(true);

  3. 典型使用场景

    gsap.to(".box", { x: 200, duration: 1, paused:true });
// 立即把动画跳转到0.5秒位置
gsap.getById("boxAnim").seek(0.5);
// 手动更新DOM渲染，立刻看到跳转后的状态
gsap.updateRoot();

  4. 常用特点

    1. 正常播放动画时，完全不需要调用，浏览器帧会自动驱动更新。
    2. 场景：动画暂停后调用 seek() / time() 跳转时间点，需要立刻同步渲染DOM，而不是等下一帧。
    3. 会更新所有GSAP动画（包含tween、timeline、delayedCall）。
    4. 频繁调用会带来性能损耗，不要放在循环、ticker回调里重复执行。
