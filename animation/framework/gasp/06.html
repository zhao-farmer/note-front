六、缓动相关-Easing

6.1 快速认识Easing

缓动（Ease）：控制动画速度变化曲线，决定动画质感。GSAP 默认缓动：power1.out。 语法格式：ease: "名称.方向"；方向分为 .in / .out / .inOut；.out 可省略不写

  • .in：先慢后快（启动缓慢，结尾加速）
  • .out：先快后慢（启动迅速，结尾减速，UI最常用）
  • .inOut：两头慢，中间快（进入和退出都平滑，适合转场）
gsap.to(".box", {
  x: 300,
  duration: 1,
  ease: "power2.out" // 示例
})

6.2 核心内置缓动

核心共嗯那个，无需单独引入

  1. 幂次类（UI首选，最常用）

    缓动说明
    power1轻微加速度，等价于Quad，柔和
    power2中等加速度，等价于Cubic，网页UI首选
    power3较强加速度，等价于Quart
    power4极强加速度，等价于Quint，冲击力强

    示例：power1.in / power2.out / power4.inOut

  2. 平滑曲线类

    缓动说明
    sine正弦曲线，非常柔和，变化平缓
    circ圆形曲线，加速/减速有圆弧质感
    expo指数曲线，速度变化非常剧烈

  3. 弹性/回弹类（带溢出效果）

    缓动说明
    back先往回退一点，再冲向目标（回弹溢出）
    elastic弹簧橡皮筋效果，可传参 elastic(振幅,周期)
    bounce小球落地弹跳效果
    // elastic 传参：振幅、周期
ease: "elastic(1, 0.5)"

  4. 阶梯与线性

    • none（等价linear）：匀速，速度全程不变，无缓动

    • steps(n)：阶梯动画，n=分段数量，一步一步跳变

      ease: "steps(5)"

6.2 GSAP 高级缓动系列

6.2.1 GSAP CustomBounce 自定义弹跳缓动

CustomBounce 用于高度自定义弹跳动画，原生bounce只能使用固定弹跳曲线；CustomBounce可以自由控制弹跳强度、弹跳次数、挤压形变，甚至实现物体起跳落回起点的效果。

依赖：必须同时引入并注册CustomEase，否则无法使用。

  1. 核心参数

    1. strength：0~1，弹跳强度。数值越大弹跳次数越多，默认0.7。0.9弹跳丰富；0.2几乎只有一次轻弹。
    2. squash：挤压形变系数，模拟物体落地压扁的物理感，默认0（关闭挤压）。数值越大，落地挤压持续时间越长。
    3. endAtStart：布尔值。true代表动画结束回到起点，适合物体跳起再落回原位。默认false。
    4. id：自定义缓动名称，创建后在tween中直接引用。

  2. 代码示例

    // 注册插件
import { gsap, CustomEase, CustomBounce } from "gsap/all";
gsap.registerPlugin(CustomEase, CustomBounce);

// 创建自定义弹跳曲线
CustomBounce.create("myBounce", {
  strength: 0.8,
  squash: 2,
  endAtStart: false
});

// 使用
gsap.to(".ball", {
  y: 200,
  duration: 1.5,
  ease: "myBounce"
})

  3. 适用场景

    • 游戏物体下落弹跳、弹性小球
    • 弹窗落地回弹、卡片掉落动效
    • 需要精细控制弹跳次数/挤压形变的物理动画

  4. 注意事项

    1. 必须加载CustomEase，依赖底层能力。
    2. 不要和原生bounce混用，二者底层实现完全不同。
    3. 挤压squash只会改变缓动曲线，不会自动生成scale挤压变形，需要自己额外写scale属性配合。

6.2.2 GSAP CustomEase 自定义贝塞尔缓动

CustomEase是GSAP自定义缓动的底层核心插件，可以通过SVG路径字符串，绘制任意形状的缓动曲线，实现内置缓动做不到的速度变化。CustomBounce、CustomWiggle都基于它构建。

  1. 核心能力

    1. 支持SVG path字符串定义曲线，可在GSAP Ease Visualizer可视化绘制，直接导出path代码。
    2. 一次创建命名缓动，全局多处复用，不用重复写长串path。
    3. 支持标准cubic-bezier贝塞尔曲线。

  2. 代码示例

    import { gsap, CustomEase } from "gsap/all";
gsap.registerPlugin(CustomEase);

// 创建自定义缓动曲线
CustomEase.create("myCustomCurve", "M0,0 C0.2,0.1 0.6,1 1,1");

gsap.to(".box", {
  x: 300,
  duration: 2,
  ease: "myCustomCurve"
})

  3. 适用场景

    • 品牌专属动效，需要独一无二的速度曲线
    • 复杂转场、产品宣传片高精度动画
    • 作为CustomBounce / CustomWiggle的前置依赖

  4. 注意事项

    1. 属于会员付费插件。
    2. path的坐标系：起点M0,0，终点必须1,1。
    3. 曲线不要出现大幅度越界，否则动画会超出目标值。

6.2.3 GSAP CustomWiggle 自定义抖动缓动

CustomWiggle 用于生成往复震荡、抖动类缓动，可自由控制抖动次数、抖动风格。适合震动、摇晃、弹簧往复效果。

依赖：必须引入CustomEase。

  1. 核心参数

    1. wiggles：抖动往复次数，默认10。
    2. type：抖动风格
      • easeOut：抖动幅度逐渐衰减（最常用）
      • easeInOut：两头衰减，中间抖动最强
      • anticipate：先反向预拉，再开始抖动
      • uniform：抖动幅度全程一致
      • random：随机不规则抖动
    3. amplitudeEase：振幅衰减曲线，精细控制抖动强弱变化。

  2. 代码示例

    import { gsap, CustomEase, CustomWiggle } from "gsap/all";
gsap.registerPlugin(CustomEase, CustomWiggle);

CustomWiggle.create("shakeIt", {
  wiggles: 6,
  type: "easeOut"
});

gsap.to(".panel", {
  rotation: 10,
  duration: 1,
  ease: "shakeIt"
})

  3. 适用场景

    • 表单错误提示抖动、警告摇晃
    • 弹簧往复晃动、设备震动反馈
    • 加载时的小幅摇摆动画

  4. 注意事项

    1. 依赖CustomEase，注册时两个插件都要注册。
    2. 这是缓动曲线，不是持续循环动画；如需无限抖动，搭配repeat:-1。

6.2.4 GSAP ExpoScaleEase 缩放补偿缓动

ExpoScaleEase专门解决缩放/变焦动画的视觉非线性问题。

问题背景：scale数值线性变化时，人眼感知速度不是匀速。比如从scale:1放大到scale:10，虽然数值匀速，但视觉上会感觉前半段飞快，后半段变慢。 ExpoScaleEase用对数曲线补偿，让人眼感知缩放是匀速平滑变焦。

  1. 语法

    ease: "expoScale(startScale, endScale, baseEase)"

    • startScale：动画起始scale
    • endScale：动画结束scale
    • baseEase：基础缓动，如expo.out

  2. 代码示例

    import { gsap, ExpoScaleEase } from "gsap/EasePack";
gsap.registerPlugin(ExpoScaleEase);

gsap.to(".image", {
  scale: 10,
  duration: 3,
  ease: "expoScale(1, 10, expo.out)"
})

  3. 适用场景

    • 地图变焦、图片放大缩小
    • 首页Hero大背景缩放转场
    • 任何scale跨度很大的镜头推拉动画

  4. 注意事项

    1. 在EasePack包内，不需要CustomEase。
    2. 参数startScale和endScale必须和tween的scale起始/终点保持一致。
    3. 仅针对scale变焦优化，位移动画不推荐使用。

6.2.5 GSAP RoughEase 粗糙锯齿缓动

RoughEase 打破平滑插值，生成锯齿、抖动、不规则的运动轨迹，模拟粗糙、故障、颠簸的效果。属于EasePack内置。

  1. 核心参数

    • points：锯齿分段数量，数值越大，抖动越密集。
    • strength：扰动强度，0~1，越大偏移越剧烈。
    • template：底层基础缓动，如power1.out。
    • randomize：是否随机扰动；关闭则生成规则往复摆动。

  2. 代码示例

    import { gsap, RoughEase } from "gsap/EasePack";
gsap.registerPlugin(RoughEase);

gsap.to(".glitch", {
  x: 200,
  duration: 2,
  ease: "rough({points:30, strength:0.4, template:power1.out, randomize:true})"
})

  3. 适用场景

    • 故障风glitch动画、电流抖动
    • 颠簸震动、手绘手绘粗糙感动效
    • 机械卡顿、老旧设备抖动

  4. 注意事项

    1. 属于EasePack，无需CustomEase。
    2. points不要设置过大，会增加计算开销。
    3. 关闭randomize可以得到均匀往复摆动，不随机。

6.2.6 GSAP SlowMo 慢动作缓动

SlowMo（slow），三段式缓动：先减速 → 中间一段匀速保持 → 末尾再加速。专门用来做“慢镜头停留”，让物体移动中途保持静止匀速，方便用户看清内容。

原生GSAP如果不使用SlowMo，要实现相同效果需要写3段timeline拼接，SlowMo一段tween即可完成。

  1. 参数

    slow(linearRatio, easeStrength)

    1. linearRatio：0~1，匀速阶段占整个动画时长的比例。0.5代表50%时间保持匀速。
    2. easeStrength：前后两端加减速的强度。

  2. 代码示例

    import { gsap, SlowMo } from "gsap/EasePack";
gsap.registerPlugin(SlowMo);

gsap.to(".text", {
  x: 400,
  duration: 3,
  ease: "slow(0.6, 0.8)"
})

  3. 适用场景

    • 文字飞入，中途短暂停留展示文字，再飞出
    • 长镜头平移，中间画面稳定供用户阅读
    • 宣传片慢镜头平移

  4. 注意事项

    1. EasePack内置，无需CustomEase。
    2. linearRatio=0等价普通缓动；linearRatio=1全程匀速。

6.2.7 GSAP SteppedEase 阶梯步进缓动

SteppedEase 阶梯式动画，不会平滑插值，而是跳变到分段节点。类似CSS steps()，GSAP版本可控性更强，最常用于精灵图逐帧动画。

  1. 参数

    SteppedEase.config(steps, immediate)

    • steps：总跳变步数。从起点到终点，一共多少次跳跃。
    • immediate：布尔值，是否立刻跳第一步。

  2. 代码示例

    import { gsap, SteppedEase } from "gsap/EasePack";
gsap.registerPlugin(SteppedEase);

// 5步跳变
gsap.to(".sprite", {
  backgroundPosition: "-500px 0",
  duration: 1,
  ease: "steps(5)"
})

  3. 适用场景

    • 精灵图、帧动画、雪碧图逐帧播放
    • 数字分段跳变、点阵扫描、打字机分段效果
    • 像素风、复古8bit动画

  4. 注意事项

    1. EasePack内置。
    2. 步数等于帧数量，做sprite动画时，步数=总帧数。
    3. 和CSS steps逻辑相似，但GSAP的SteppedEase时序控制更稳定，不受浏览器渲染差异影响。
