1.2 声明数据

1.2.1 变量常量声明

  1. 变量声明-var

    • 场景: 当一个人的年龄从20岁变成21岁，存储数据发生变化，需要用变量来进行声明
    • 关键字: var
    • 语法: var变量名=值/表达式;
    • 注意: 使用var声明的变量，其类型在第一次赋值之后确定，不能再赋值其他类型的值
    void main(List<String> args){
    var age = 20; // 第一次复制之后 类型被确定  后面不允许更改类型
    print(age);
    age = 21;
    print(age);
    var age1 = 20 + 21;
    print(age1);
}

  2. 常量声明const

    • 场景:当做圆形计算的时候，n的值一开始就是被确定的，且不允许更改，使用const进行声明
    • 关键字:const
    • 语法:const 属性名=值/表达式;
    • 特点:const是代码编译前被确定，不允许表达式中有变量存在，必须为常量或者固定值
    void main(List<String> args){
    const num = 3.1415926;
    const num1 = num;
    // 半径为5 计算圆的周长
    const length = 2 * 5 * num;

    print(length);
    // const 表达式里面的值不允许有变量值
}

  3. 常量声明 final

    • 场景:当我们需要当前时间作为当前唯一的操作时间，时间一旦被确定就不可以被修改。
    • 关键字:final
    • 语法:final属性名=值/表达式;
    • 特点:final变量在运行时被初始化，其值设置后不可更改
    void main(List<String> args){
    final time = DateTime.now();
    print(time);
}

1.2.2 具体数据类型

  1. 常用类型-String

    • 基础使用

      • 场景:当我们需要用一个变量来描述一段文本，就可以使用String来声明。
      • 关键字:String
      • 语法:String属性名='文本内容';
      • 特点:引号支持双引号或者单引号，支持拼接及模板字符串

    • 模板字符串

      • 场景:当String类型的变量当前时间来显示，可以使用模板字符串或者拼接实现。
      • 需求:打印出我要在(具体时间)的时候吃早饭
      • 语法:String属性名='文本内容$变量名';或 String变量名='文本内容${变量名)';
      • 注意:当存在模板中的内容是一个表达式的时候需要使用${}，更推荐使用${}
    void main(List<String> args) {
    String text = "今天是个好日子";
    print(text);
    text = "明天是个好日子";
    print(text);

    // 模板字符串
    String content = '我要在${DateTime.now()}吃饭';
    print(content);
    String flag = "张三";
    String content1 = '我和$flag是好朋友';
    print(content1);
}

  2. Dart中的数字类型 - int/num/double

    • int/num/double三种数字类型
      • 场景:当我们需要描述一个数字类型的时候，需要使用int/num/double
      • 区别:int-整型数字，num-可整型可小数，double-小数
      • 语法:int/num/double属性名=数值;
    • 赋值转换
      • 注意:数字之间的赋值关系
        • double和int不能直接赋值
        • num不能直接给double赋值
        • double可直接给num赋值
    void main(List<String> args){
    int friendCount = 3;
    print('我有$friendCount');
    num rest = 1.5;
    print('我有$rest月的假期');
    double appleCount = 1.5;
    print('我买了$appleCount斤苹果');

    // friendCount = appleCount;// int和double不允许直接赋值
    friendCount = appleCount.toInt();// int和double 转化之后可以赋值
    appleCount = friendCount.toDouble();
    rest = appleCount;  // doubLe可以直接给num赋值
    appleCount = rest.toDouble(); // num给double賦值需要转化
}

  3. Dart中的布尔类型-bool

    • 场景:当我们需要一个属性来表示当前为真(true)或假(false)的时候，需要使用bool关键字声明
    • 需求:声明当前自己是否已经完成作业
    • 语法:bool属性名=true/false;
    void main(List<String> args){
    bool isFinishWork = false;
    print('我完成作业的状态为$isFinishWork');
}

1.2.3 复杂数据类型

  1. 列表类型

    • 基础定义

      • 场景:当一个变量需要存储多个值的时候，可以使用列表类型
      • List需求:一个班级的学生用List存储，支持对学生的查找、新增、删除、循环
      • 语法:List属性名=['学生1'，'学生2];

    • List的常用操作方法

      • 在尾部添加-add(内容)
      • 在尾部添加一个列表-addAll(列表)
      • 删除满足内容的第一个-remove(内容)
      • 删除最后一个-removeLast()
      • 删除索引范围内数据-removeRange(start,end)
      • 循环-forEach((item){});
      • 是否都满足条件-every((item){ return 布尔值 });
      • 筛选出满足条件的数据-where((item){ return 布尔值 });

    • List的常用属性

      • 列表的长度(属性)-length
      • 最后一个元素(属性)-last
      • 第一个元素(属性)-first
      • 是否为空(属性)-isEmpty

    • 代码示例

      void main(List<String> args){
    List studdents = ["张三","李四","王五"];
    print(studdents);
    studdents.add("新同学"); // 在尾部进行添加
    studdents.add("新同学"); // 在尾部进行添加
    print(studdents);
    studdents.addAll(["新来的同学1","新来的同学2"]);
    print(studdents);
    studdents.remove("新同学");
    print(studdents);
    // 删除最后一个同学
    studdents.removeLast(); // 删除最后一个
    print(studdents);
    // 删除前两个同学
    // start开始的索引 end结束的索引
    studdents.removeRange(0,2);
    print(studdents);

    // 是不是所有同学都以新为开头
    var result1 = studdents.every((item){
        return item.toString().startsWith("新");
    });
    print(result1);

    // 赛选出所有以新开头的同学
    var result2 = studdents.where((item){
        return item.toString().startsWith("新");
    });
    print(result2);

    // 列表的长度
    print(studdents.length);
    // 最后一个元素
    print(studdents.last);
    // 第一个元素
    print(studdents.first);
    // 是否为空列表
    print(studdents.isEmpty);
}

  2. 字典类型-Map

    • 基础使用

      • 场景:当存储的英文需要找到对应的中文描述，需要使用键值对类型Map
      • 需求:需要定义一个英文对应中文的描述，并可以通过英文找到对应的中文
      • 语法1:Map 属性名 = {key:value};
      • 语法2:字典[key]可以取值和赋值

    • Map的常用操作方法

      • 循环-forEach
      • 在添加一个字典-addAll
      • 是否包含某个key-containsKey
      • 删除某个key-remove
      • 清空-clear

    • 代码示例

      void main(List<String> args){
    Map transMap = {"lanch":"午饭","moring":"早上","hello":"你好"};
    print(transMap["hello"]);
    transMap["hello"] = "你非常好";
    print(transMap["hello"]);

    // 循环
    transMap.forEach((key,value){
        print('$key,$value');
    });
    // 添加一个字典
    transMap.addAll({"fine":"很好"});
    // 是否包含某一个key
    transMap.containsKey("fine");
    // 删除某个key
    transMap.remove("fine");
    // 清空字典
    transMap.clear();
}

  3. 动态类型-dynamic

    • 基础使用

      • 定义:Dart语言中，dynamic用来声明动态类型
      • 特点:允许变量运行时自由改变类型，同时绕过编译时的静态检查
      • 语法1:dynamic属性名=值;
      void main(List<String> args){
    // 自由设置类型
    dynamic free = 1;
    free = "";
    free = false;
    free = [];
    free = {};
}

    • dynamic和var的区别

      • dynamic:运行时可自由改变类型，无编译检查，方法和属性直接调用
      • var:根据初始值进行推断类型，确定类型后类型确定，有编译检查，仅限推断的属性和方法
      void main(List<String> args){
    // 自愈设置类型
    var text = 1;
    text.toDouble();
    dynamic text1 = 1;
    text1.startsWith(""); // 虽然运行保持但是绕过编译，不会提示
}

1.2.4 空的安全机制

  • 定义:在Dart语言中，通过编译静态检查将运行时空指针提前暴露

  • 特点:将空指针异常从运行时提前至编译时，减少线上崩溃

  • 常用空安全操作符

    操作符符号作用示例
    可空类型?声明可空变量String? → 允许 String 或 null
    安全访问?.对象为 null 时跳过操作，返回 nulluser?.name → 若 user 为 null 则返回 null
    非空断言!.开发者保证变量非空（否则运行时崩溃）name!.length → 断言 name 非空
    空合并??左侧为 null 时返回右侧默认值name ?? "Guest" → name 为 null 时返回 "Guest"

  • 代码示例

    void main(List<String> args){
    String? username = null;     // ? 表示变量可以是null
    username?.startsWith("新"); // 安全访问

    // 客观判断
    // username = "张三"
    // 主观判断-开发者认为username一定不为null
    username!.startsWith("新");

    // 要保证别人一定能够显示用户名
    String displayName = username ?? "老高";
}

1.3 运算符

1.3.1 算术运算符

  • 定义:在Dart语言中，对数字进行加减乘除运算采用算术运算符

  • 表格展示

    运算符作用
    +加
    -减
    *乘
    /除
    ~/整除
    %取余数

  • 代码示例

    void main(List<String> args) {
    double item = 10.99; // 商品单价
    double allPrice = item * 4; // 乘法
    double money = 100;
    double lastMoney = money - allPrice; // 减法
    double everyMoney1 = lastMoney / 4; // 除法
    int everyMoney2 = lastMoney ~/ 4; // 整除
    int everyMoney3 = 10 % 4; //  取余数
    print('$allPrice $lastMoney $everyMoney1 $everyMoney2 $everyMoney3');
}

1.3.2 赋值运算符

  • 定义:在Dart语言中，对数据进行赋值运算采用赋值运算符

  • 表格展示

    运算符作用
    =赋值操作
    +=加等，a += b 相等于 a = a + b
    -=减等，a -= b 相等于 a = a - b
    *=乘等，a *= b 相等于 a = a * b
    /=除等，a /= b 相等于 a = a / b

  • 代码示例

    void main(List<String> args) {
    int a = 10;
    int b = 3;
    
    print('初始值: a = $a, b = $b');
    
    // 赋值操作
    a = 20;
    print('赋值后: a = $a');
    
    // 加等操作
    a += b;  // 等价于 a = a + b
    print('a += b 后: a = $a');  // a = 23
    
    // 减等操作
    a -= b;  // 等价于 a = a - b
    print('a -= b 后: a = $a');  // a = 20
    
    // 乘等操作
    a *= b;  // 等价于 a = a * b
    print('a *= b 后: a = $a');  // a = 60
    
    // 除等操作（注意：对于整数，/= 会返回 double）
    double x = 60.0;
    x /= b;  // 等价于 x = x / b
    print('x /= b 后: x = $x');  // x = 20.0
}

1.3.3 比较运算符

  • 定义:在Dart语言中，对数值进行比较操作实用比较运算符

  • 特点:比较运算符的结果都是布尔类型

  • 表格展示

    运算符作用
    ==判断两个值是否相等
    !=判断两个值是否不等
    >判断左侧值是否大于右侧值
    >=判断左侧值是否大于等于右侧值
    <判断左侧值是否小于右侧值
    <=判断左侧值是否小于等于右侧值

  • 代码示例

    void main() {
    int a = 10;
    int b = 5;
    int c = 10;
    
    print('a = $a, b = $b, c = $c');
    print('a == b: ${a == b}');  // false
    print('a == c: ${a == c}');  // true
    print('a != b: ${a != b}');  // true
    print('a > b: ${a > b}');    // true
    print('a >= c: ${a >= c}');  // true
    print('a < b: ${a < b}');    // false
    print('a <= c: ${a <= c}');  // true
    
    // 字符串比较
    String str1 = "hello";
    String str2 = "world";
    print('str1 == str2: ${str1 == str2}');  // false
    
    // 列表比较
    List<int> list1 = [1, 2, 3];
    List<int> list2 = [1, 2, 3];
    print('list1 == list2: ${list1 == list2}');  // false（比较引用）
    print('list1 内容相同: ${list1[0] == list2[0] && list1[1] == list2[1] && list1[2] == list2[2]}');  // true
}

1.3.4 逻辑运算符

  • 定义:在Dart语言中，需要对于bool类型的值进行逻辑运算，需要使用逻辑运算符

  • 注意:使用逻辑运算符必须保证参与的变量为布尔类型

  • 表格展示

    运算符作用
    &&逻辑与，a && b，a和b同时true，得true
    ||逻辑或，a || b，a和b有一个true，得true
    !逻辑非，!a，对a变量进行取反

  • 代码示例

    void main() {
    bool a = true;
    bool b = false;
    
    print('a = $a, b = $b');
    
    // 逻辑与 (&&) - 两个都为 true 时才返回 true
    print('a && b: ${a && b}');      // false
    print('a && a: ${a && a}');      // true
    print('b && b: ${b && b}');      // false
    
    // 逻辑或 (||) - 有一个为 true 就返回 true
    print('a || b: ${a || b}');      // true
    print('a || a: ${a || a}');      // true
    print('b || b: ${b || b}');      // false
    
    // 逻辑非 (!) - 取反操作
    print('!a: ${!a}');              // false
    print('!b: ${!b}');              // true
    print('!!a: ${!!a}');            // true（双重否定）
}

1.3 流程控制结构

1.3.1 if分支语句

  • 定义:在Dart语言中，if分支语句可以进行不同逻辑的判断和处理

  • 表格展示

    if 分支类型语法格式作用描述
    单分支if (条件) { ... }单个条件判断，条件为真时执行
    双分支if (条件) { ... } else { ... }两个条件判断，二选一执行
    多分支if (条件1) { ... } else if (条件2) { ... } else { ... }多个条件判断，多选一执行

  • 代码示例

    void main() {
    int score = 61;
    // 单条件情况
    if(score > 60){
        print("恭喜你及格");
    }

    bool isMarry = false;
    if(isMarry){
        print("恭喜你结婚");
    }else{
        print("还没有结婚");
    }

    if(score > 80){
        print("优秀");
    }else if(score > 60){
        print("及格");
    }else{
        print("不及格");
    }
}

1.3.2 三元运算符

  • 意义：替代if-else

  • 语法：条件 ? 表达式1 : 表达式2

  • 代码示例

    void main() {
    int score = 85;
    
    // 基本用法
    String result = score >= 60 ? "及格" : "不及格";
    print(result);  // 输
}

1.3.3 switch/case

  • 定义:在Dart语言中，如果分支条件很多，且条件是判断相等,可以使用switch case语句

  • 语法

    switch (表达式) {
    case 值1:
        // 代码块1
        break;
    case 值2:
        // 代码块2
        break;
    default:
        // 默认代码块
}

  • 代码示例

    void main() {
    int state = 100;  // 1待付款 2待发货 3待收货 4待评价 5未知状态
    switch(state){
        case 1:
            print("待付款");
            break;
        case 2:
            print("待发货");
            break;
        case 3:
            print("待收货");
            break;
        case 4:
            print("待评价");
            break;
        default:
            print("未知状态");
    }
}

1.3.4 while循环

  • 定义:在Dart语言中，循环主要使用while循环和for循环

  • 特点:只有条件满足，括号中逻辑一直执行

  • 语法

    • while语法

      while (条件表达式) {
    // 循环体
    // 循环变量更新
}

    • do-while语法

      do {
    // 循环体 - 至少执行一次
} while (条件表达式);

  • 代码示例

    void main() {
    int i = 1;
    while (i <= 5) {
        print("i当前值: $i");
        i++; // 不要忘记更新循环变量
    }
    int y = 5;
    do {
        print("y当前值: $y");
        y--;
    } while (y >= 1);
}

1.3.5 for循环

  • 定义:在Dart语言中，for循环可以对列表类型进行遍历

  • 特点:只有小括号逻辑满足，大括号逻辑一直执行

  • 语法：

    • for循环语法

      for (初始化; 条件判断; 循环后操作) {
    // 循环体
}

    • forin循环语法

      for (var 元素 in 可迭代对象) {
    // 循环体
}

  • 代码示例:

    void main() {
    // 示例1：基本 for 循环
    for (int i = 1; i <= 5; i++) {
        print("当前值: $i");
    }
    // 遍历 Set
    Set<int> numbers = {1, 2, 3, 4, 5};
    for (int num in numbers) {
        print("数字: $num");
    }
}

1.3.6 while与for的跳出

  • break是跳出整个while循环，continue是跳出当前迭代，进入下一次迭代

  • 代码示例

    void main(List<String> args) {
    // break 示例
    for (int i = 1; i <= 10; i++) {
        if (i == 6) {
            print("遇到 6，提前结束循环");
            break;
        }
        print("当前值: $i");
    }
    // 输出：1 2 3 4 5 遇到 6，提前结束循环

    // while 中使用 break
    int i = 1;
    while (true) {
        // 无限循环
        print("i = $i");
        if (i == 5) {
            break; // 跳出循环
        }
        i++;
    }
    // continue 示例
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            print("跳过 3");
            continue; // 跳过本次循环
        }
        print("当前值: $i");
    }
    // 输出：1 2 跳过 3 4 5
}

1.4 函数

1.4.1 函数定义

  1. 基础定义

    • 定义:在Dart语言中，函数是代码组合和复用的核心单元

      返回类型 函数名(参数列表) {
    // 函数体
    return 返回值; // 如果有返回值
}

    • 场景:应用程序中很多地方需要做两数之和的运算，可以定义函数来组织代码

  2. 函数的返回值

    • 分类:函数返回值分为有返回值和无返回值
    • 有返回值:具体类型 函数名称(){}
    • 无返回值:void 函数名称(){}
    • 注意:返回值类型可省略，Dart会自动推断类型为dynamic

  3. 示例代码

    void main() {
    add(1, 2, 3);
    test();
}
// 返回类型 函数名称 参数 函数题
int add(int a, int b, int c){
    return a + b + c;
}

void test(){
    print("测试无返回值数据");
}

getValue(){
    return 1 * 2;
}

1.4.2 函数参数

分类：函数的参数分为必传参数，可选位置参数，可选命名参数

  1. 必传参数

    • 特点：必传参数不能为空

  2. 可选位置参数

    • 特点：可选位置参数必须位于必传参数后面，采用中括号包裹
    • 语法：函数名(String a,[String?b,...]),传递时按照顺序传递
    • 使用场景：参数少且顺序固定时
    • 默认值：可选参数可以设置默认值

  3. 可选命名参数

    • 特点：可选参数必须位于必传参数后面，采用大括号包裹
    • 语法：函数名(String a,{Sring? a,...}),传递时按照 参数名：值的方式进行传递，无需关注顺序
    • 使用场景：参数多且需明确定义时
    • 默认值：可选参数可以设置默认值

  4. 代码示例：

    void main() {
    add(1, 2);
    combine("1");
    combine("1","2","3");
    showPerson("zhangsan");
}

int add(int a,int b){
    return a + b;
}

// 合并字符串
String combine(String a,[String? b = "b",String? c = "c"]){
    return a + (b ?? "") + (c ?? "");
}

void showPerson(String username, {int age = 18,String? sex = "男"}){
    print('姓名：$username,年龄：$age,性别：$sex');
}

1.4.3 匿名函数

  • 特点:可以声明一个没有名称的函数赋值给变量，进行调用

  • 语法:Function 变量名=(){};

  • 注意:函数的类型使用Function来声明

  • 代码示例

    void main(List<String> args) {
    onTest(test); // 调用函数 传递匿名函数
}

// 声明匿名函数
Function test = () {
    print("测试");
};

// 定义一个参数接受一个函数
void onTest(Function callBack) {
    callBack();
}

1.4.4 箭头函数

  • 特点:当函数体只有一行代码时，可以使用箭头函数编写

  • 语法:函数名()=>代码逻辑

  • 注意:使用箭头函数可以省略return关键字

  • 代码示例

    void main() {
    print(add(1, 2));
}

int add(int a, int b) => a + b;

1.5 类-class

1.5.1 类的定义

  • 定义:Dart语言中，类(class)是面向对象编程的核心，类包含属性和方法来定义对象的行为和状态

  • 需求:定义一个Person类，属性包括姓名、年龄、性别，包括学习的方法

  • 定义类语法:class Person{属性方法}

  • 实例化对象:Person变量=Person();

  • 属性和方法:变量.属性/方法()

  • 代码示例
