三、orm相关

3.1 Sequelize

Sequelize 是 Node.js 中最流行的 基于 Promise 的 ORM（对象关系映射）库，支持 MySQL、PostgreSQL、SQLite、MariaDB、MSSQL 等主流数据库。它允许你用 JavaScript/TypeScript 类和方法 操作数据库，而无需手写原始 SQL，同时提供迁移（Migration）、关联（Association）、事务、钩子（Hooks）等高级功能。

  • 官网: https://sequelize.org/
  • GitHub: https://github.com/sequelize/sequelize
  • CLI 文档: https://sequelize.org/docs/v6/other-topics/migrations/

3.1.1 快速上手

  1. 安装

    # 安装 Sequelize + 数据库驱动（以 MySQL 为例）
npm install sequelize mysql2

    注意：

    • MySQL → mysql2
    • PostgreSQL → pg pg-hstore
    • SQLite → sqlite3

  2. 基础连接与模型定义

    // db.js
const { Sequelize } = require('sequelize');

// 创建 Sequelize 实例
const sequelize = new Sequelize('database_name', 'username', 'password', {
  host: 'localhost',
  dialect: 'mysql', // 或 'postgres', 'sqlite', 'mariadb', 'mssql'
  logging: false,   // 是否打印 SQL 日志（开发时可设为 true）
  define: {
    timestamps: true, // 自动添加 createdAt/updatedAt
    underscored: true // 字段名使用下划线（如 created_at）
  }
});

// 测试连接
(async () => {
  try {
    await sequelize.authenticate();
    console.log('数据库连接成功');
  } catch (error) {
    console.error('连接失败:', error);
  }
})();

module.exports = sequelize;

  3. 定义模型（Model）

    // models/User.js
const { DataTypes } = require('sequelize');
const sequelize = require('../db');

const User = sequelize.define('User', {
  // 主键 id 会自动生成（除非你禁用）
  name: {
    type: DataTypes.STRING,
    allowNull: false
  },
  email: {
    type: DataTypes.STRING,
    allowNull: false,
    unique: true,
    validate: {
      isEmail: true
    }
  },
  age: {
    type: DataTypes.INTEGER,
    validate: {
      min: 0,
      max: 120
    }
  }
}, {
  tableName: 'users', // 指定表名（默认是复数形式）
  timestamps: true    // 启用 createdAt/updatedAt
});

module.exports = User;

    Sequelize 会自动将 User 模型映射到 users 表。

  4. 同步模型到数据库（开发用）

    // sync.js
const sequelize = require('./db');
const User = require('./models/User');

// 警告：force: true 会 DROP 表！仅用于开发
sequelize.sync({ force: false }).then(() => {
  console.log('模型已同步到数据库');
});

    生产环境不要用 sync()！应使用 Migration（迁移）。

3.1.2 CRUD 操作示例

  1. 创建

    const user = await User.create({
  name: 'Alice',
  email: 'alice@example.com',
  age: 25
});
console.log(user.id); // 自动生成的 ID

  2. 查询

    // 查找单条
const user = await User.findByPk(1); // 主键查询
const user = await User.findOne({ where: { email: 'alice@example.com' } });

// 查找多条
const users = await User.findAll({
  where: {
    age: { [Op.gt]: 18 } // Op.gt = >
  },
  limit: 10,
  offset: 0,
  order: [['createdAt', 'DESC']]
});

// 查询字段
const users = await User.findAll({
  attributes: ['name', 'email'] // 只查指定字段
});

  3. 更新

    // 方式1：实例更新
const user = await User.findByPk(1);
user.name = 'New Name';
await user.save();

// 方式2：批量更新
const [affectedCount] = await User.update(
  { name: 'Updated Name' },
  { where: { id: 1 } }
);

  4. 删除

    // 软删除（如果启用 paranoid: true）
await user.destroy(); // 设置 deletedAt

// 硬删除
await user.destroy({ force: true });

// 批量删除
await User.destroy({ where: { id: 1 } });

3.1.3 关联

  1. 一对多（User → Posts）

    // models/Post.js
const Post = sequelize.define('Post', {
  title: DataTypes.STRING,
  content: DataTypes.TEXT
});

// 关联
User.hasMany(Post, { foreignKey: 'userId' });
Post.belongsTo(User, { foreignKey: 'userId' });

  2. 查询带关联数据

    const user = await User.findByPk(1, {
  include: [Post] // 加载用户的帖子
});

console.log(user.Posts); // 数组

  3. 多对多（User ↔ Role）

    const Role = sequelize.define('Role', { name: DataTypes.STRING });
User.belongsToMany(Role, { through: 'UserRoles' });
Role.belongsToMany(User, { through: 'UserRoles' });

  2. 钩子

  user.email = user.email.toLowerCase();

  // 清理关联数据
});

  3. 作用域

    const User = sequelize.define('User', {
  // ...
}, {
  scopes: {

  4. 原始查询

    const [results, metadata] = await sequelize.query(
  'SELECT * FROM users WHERE age > ?',
  { replacements: [18], type: sequelize.QueryTypes.SELECT }
);

3.2 TypeORM

TypeORM 是一个受 Hibernate、Doctrine 和 Entity Framework 启发的 TypeScript ORM（对象关系映射）库，支持 Active Record 和 Data Mapper 两种模式，兼容 MySQL、PostgreSQL、SQLite、MariaDB、MSSQL、Oracle、MongoDB 等数据库。它深度集成 TypeScript 装饰器（Decorators），实现“代码即模型”。

特性说明
纯 TypeScript 设计利用装饰器定义模型，类型安全
双模式支持Active Record（简单）或 Data Mapper（解耦）
强大的关系映射一对一、一对多、多对多、级联操作
迁移系统自动生成/执行数据库变更
查询构建器链式语法，支持原生 SQL
广泛数据库支持包括 MongoDB（通过特殊驱动）

适用场景：

  • NestJS 官方推荐 ORM
  • 复杂领域模型（DDD）
  • 需要高度解耦的大型项目
  • 官网: https://typeorm.io/
  • GitHub: https://github.com/typeorm/typeorm

3.2.1 安装与初始化

  1. 安装

    # 核心 + 数据库驱动（以 MySQL 为例）
npm install typeorm mysql2 reflect-metadata

# 开发依赖（CLI）
npm install --save-dev @types/node ts-node

    必须安装 reflect-metadata 并在入口文件引入！

  2. 配置 tsconfig.json

    {
  "compilerOptions": {
    "target": "es2021",
    "module": "commonjs",
    "lib": ["es2021"],
    "experimentalDecorators": true,      // 启用装饰器
    "emitDecoratorMetadata": true,       // 启用元数据反射
    "outDir": "./dist"
  }
}

  3. 初始化项目结构

    npx typeorm init --name MyProject --database mysql

    生成：

    src/
  ├── entity/
  ├── migration/
  └── index.ts
ormconfig.json

3.2.2 定义实体

  1. 基础实体（使用 Data Mapper 模式）

    // src/entity/User.ts
import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn } from 'typeorm';

@Entity() // 标记为实体
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column({ length: 100 })
  name: string;

  @Column({ unique: true })
  email: string;

  @Column({ nullable: true })
  age?: number;

  @CreateDateColumn()
  createdAt: Date;

  @UpdateDateColumn()
  updatedAt: Date;
}

  2. 关系示例（一对多）

    // src/entity/Post.ts
import { Entity, PrimaryGeneratedColumn, Column, ManyToOne, JoinColumn } from 'typeorm';
import { User } from './User';

@Entity()
export class Post {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  title: string;

  @ManyToOne(() => User, user => user.posts)
  @JoinColumn({ name: 'author_id' }) // 外键字段名
  author: User;
}

// 在 User.ts 中添加反向关系
@Entity()
export class User {
  // ... 其他字段

  @OneToMany(() => Post, post => post.author)
  posts: Post[];
}

3.2.3 数据库连接配置

  • 方式 1：ormconfig.json（简单项目）

    {
  "type": "mysql",
  "host": "localhost",
  "port": 3306,
  "username": "root",
  "password": "password",
  "database": "test_db",
  "synchronize": true,        // 自动同步实体到 DB（仅开发！）
  "logging": false,
  "entities": ["src/entity/**/*.ts"],
  "migrations": ["src/migration/**/*.ts"],
  "subscribers": ["src/subscriber/**/*.ts"],
  "cli": {
    "entitiesDir": "src/entity",
    "migrationsDir": "src/migration"
  }
}

  • 方式 2：编程式配置（推荐，尤其 NestJS）

    // src/data-source.ts
import { DataSource } from 'typeorm';
import { User } from './entity/User';
import { Post } from './entity/Post';

export const AppDataSource = new DataSource({
  type: 'mysql',
  host: 'localhost',
  port: 3306,
  username: 'root',
  password: 'password',
  database: 'test_db',
  synchronize: false, // 生产环境必须 false！
  logging: true,
  entities: [User, Post],
  migrations: ['src/migration/**/*.ts'],
});

生产环境务必关闭 synchronize，改用 Migration。

3.2.5 CRUD 操作

  1. 获取 Repository

    import { AppDataSource } from './data-source';
import { User } from './entity/User';

const userRepository = AppDataSource.getRepository(User);

  2. 创建

    const user = new User();
user.name = 'Alice';
user.email = 'alice@example.com';

const savedUser = await userRepository.save(user);
console.log(savedUser.id); // 自动生成 ID

  3. 查询

    // 查找单条
const user = await userRepository.findOneBy({ id: 1 });
const user = await userRepository.findOne({ where: { email: 'alice@example.com' } });

// 查找多条
const users = await userRepository.find({
  where: { age: MoreThan(18) },

  skip: 0

user.name = 'New Name';

await userRepository.delete({ email: 'old@example.com' }); // 按条件

3.2.6 高级功能

  1. 事务

    await AppDataSource.transaction(async (manager) => {
  const userRepo = manager.getRepository(User);
  const postRepo = manager.getRepository(Post);

  const user = await userRepo.save({ name: 'Tx User', email: 'tx@example.com' });
  await postRepo.save({ title: 'In Transaction', author: user });
});

  2. 监听器

    @Entity()
export class User {
  // ...

  @BeforeInsert()
  setEmailLowercase() {
    this.email = this.email.toLowerCase();
  }

  @AfterLoad()
  logUser() {
    console.log('Loaded user:', this.name);
  }
}

  3. 自定义存储库

    // src/repository/UserRepository.ts
import { EntityRepository, Repository } from 'typeorm';
import { User } from '../entity/User';

@EntityRepository(User)
export class UserRepository extends Repository<User> {
  async findAdults(): Promise<User[]> {
    return this.find({ where: { age: MoreThan(18) } });
  }
}

// 使用
const customRepo = AppDataSource.getCustomRepository(UserRepository);
const adults = await customRepo.findAdults();

    注意：TypeORM v0.3+ 已弃用 @EntityRepository，改用 扩展 Repository：

    export class UserRepository extends Repository<User> { /* ... */ }

3.3 Prisma

Prisma 是一个 现代化、类型安全、高性能 的 Node.js/TypeScript ORM（对象关系映射器），它采用 声明式 Schema + 自动生成查询客户端 的方式，彻底改变了数据库交互体验。相比 Sequelize，Prisma 更轻量、更安全、对 TypeScript 支持一流，并内置迁移、数据建模、类型推导等能力。

  • 官网: https https://www.prisma.io/
  • 文档: https://www.prisma.io/docs
  • GitHub: https://github.com/prisma/prisma
  • Playground: https://playground.prisma.io/
特性说明
类型安全自动生成 TS 类型，编译时检查查询
自动完成IDE 智能提示（字段、方法、关联）
零 SQL 注入查询构建器完全参数化
直观的 API链式语法，易读易写
内置迁移prisma migrate 管理数据库变更
支持主流数据库PostgreSQL, MySQL, SQLite, SQL Server, MongoDB（Preview）

适用场景：全栈 TypeScript 项目、快速原型开发、需要端到端类型安全。

3.3.1 安装与初始化

  1. 安装 CLI

    npm install prisma --save-dev
npx prisma init

    生成目录结构：

    prisma/
  ├── schema.prisma   # 数据模型定义
  └── migrations/     # 数据库迁移文件
.env                  # 数据库连接 URL

  2. 配置 .env

    # .env
DATABASE_URL="mysql://user:password@localhost:3306/mydb"

    支持格式：

    • MySQL: mysql://user:pass@host:3306/db
    • PostgreSQL: postgresql://user:pass@host:5432/db
    • SQLite: file:./dev.db

3.3.2 定义数据模型（schema.prisma）

// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "mysql" // 或 postgresql, sqlite, sqlserver
  url      = env("DATABASE_URL")
}

model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String?
  posts Post[]
  createdAt DateTime @default(now())
}

model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User     @relation(fields: [authorId], references: [id])
  authorId  Int
}

关键语法：

  • @id：主键
  • @default(...)：默认值
  • @unique：唯一约束
  • @relation：定义外键关系

3.3.3 在代码中使用 Prisma Client

  1. 初始化客户端

    // lib/prisma.ts
import { PrismaClient } from '@prisma/client'

const globalForPrisma = global as unknown as { prisma: PrismaClient }

export const prisma =
  globalForPrisma.prisma ||
  new PrismaClient()

if (process.env.NODE_ENV !== 'production') globalForPrisma.prisma = prisma

    使用全局单例避免开发模式下热重载导致连接泄漏。

  2. CRUD 操作示例（TypeScript）

    • 创建

      const user = await prisma.user.create({
  data: {
    email: 'alice@example.com',
    name: 'Alice',
    posts: {
      create: { title: 'Hello World' } // 同时创建关联文章
    }
  }
})

    • 查询

      // 查找单个用户（含关联文章）
const user = await prisma.user.findUnique({
  where: { email: 'alice@example.com' },
  include: { posts: true }
})

// 条件查询
const posts = await prisma.post.findMany({
  where: {
    published: true,
    author: { name: { contains: 'Ali' } }
  },
  orderBy: { createdAt: 'desc' },
  take: 10,
  skip: 0
})

    • 更新

      // 更新用户
await prisma.user.update({
  where: { id: 1 },
  data: { name: 'Alice Smith' }
})

// 原子操作（+1）
await prisma.post.update({
  where: { id: 1 },
  data: { views: { increment: 1 } }
})

    • 删除

      await prisma.user.delete({ where: { id: 1 } })

3.3.4 关系操作（Relations）

  1. 创建带关联

    // 方法1：嵌套 create
await prisma.user.create({
  data: {
    email: 'bob@example.com',
    posts: {
      create: [{ title: 'Post 1' }, { title: 'Post 2' }]
    }
  }
})

// 方法2：先创建用户，再关联
const user = await prisma.user.create({ data: { email: '...' } })
await prisma.post.create({
  data: {
    title: 'New Post',
    authorId: user.id // 直接设外键
  }
})

  2. 更新关联

    // 将文章分配给新作者
await prisma.post.update({
  where: { id: 1 },
  data: { author: { connect: { id: 2 } } }
})

// 断开关联（设 authorId 为 null）
await prisma.post.update({
  where: { id: 1 },
  data: { author: { disconnect: true } }
})

3.3.5 高级功能

  1. 事务

    await prisma.$transaction([
  prisma.user.create({ data: { email: 'tx@example.com' } }),
  prisma.post.create({ data: { title: 'In Transaction', authorId: 1 } })
])

  2. 原始查询

    // 执行 SQL
const users = await prisma.$queryRaw`SELECT * FROM User WHERE email = ${email}`

// 执行命令
await prisma.$executeRaw`UPDATE Post SET views = views + 1 WHERE id = ${postId}`

    注意：$queryRaw 返回原始数据，无类型安全！

  3. 软删除

    // 在 schema 中添加 deletedAt
model User {
  id        Int
  deletedAt DateTime? @map("deleted_at")
  // ...
}

// 查询时过滤
const activeUsers = await prisma.user.findMany({
  where: { deletedAt: null }
})

    Prisma 官方暂不支持 paranoid（软删除），需手动实现。
