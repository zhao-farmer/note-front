六、图片处理

6.1 sharp 图片调整

sharp 是 Node.js 中最快、最高效的图像处理库，基于高性能的 libvips C 库构建。它支持 JPEG、PNG、WebP、AVIF、GIF、SVG、TIFF 等多种格式，常用于：

  • 图片缩放/裁剪/旋转
  • 格式转换（如 PNG → WebP）
  • 水印添加
  • 响应式图片生成（多尺寸）
  • 图片压缩优化（减小体积）

优势：

  • 速度比 ImageMagick 快 4–8 倍
  • 内存占用低（流式处理）
  • 支持 Promise / async/await
  • 无需全局安装依赖（预编译二进制）

6.1.1 安装

npm install sharp

注意：

  • 首次安装会下载平台对应的 libvips 二进制（约 10–30MB）
  • 若网络慢，可配置镜像：SHARP_DIST_BASE_URL=https://npmmirror.com/mirrors/sharp-libvips/

6.1.2 基础用法（核心 API）

  1. 读取图片

    const sharp = require('sharp');

// 从文件读取
const image = sharp('input.jpg');

// 从 Buffer 读取（如上传的文件）
const buffer = fs.readFileSync('input.png');
const image = sharp(buffer);

  2. 链式操作 + 输出

    await sharp('input.jpg')
  .resize(300, 200)        // 调整尺寸
  .jpeg({ quality: 80 })   // 设置 JPEG 质量
  .toFile('output.jpg');   // 保存到文件

  3. 获取处理后的 Buffer

    const outputBuffer = await sharp('input.png')
  .webp({ quality: 75 })
  .toBuffer(); // 返回 Buffer，适合 HTTP 响应或上传到云存储

6.1.3 常用操作示例

  1. 调整尺寸（Resize）

    // 按宽度缩放，高度自动（保持比例）
sharp('photo.jpg').resize(800).toFile('photo-800w.jpg');

// 指定宽高（可能变形）
sharp('photo.jpg').resize(800, 600).toFile('photo-800x600.jpg');

// 裁剪模式（cover = 居中裁剪填充）
sharp('photo.jpg')
  .resize(300, 300, { fit: 'cover', position: 'center' })
  .toFile('thumbnail.jpg');

    fit 选项：

    • cover：裁剪填充（默认）
    • contain：完整包含（留白）
    • fill：拉伸填充（可能变形）
    • inside：最大尺寸内缩放
    • outside：最小尺寸外缩放

  2. 格式转换 & 压缩

    // PNG → WebP（更小体积）
await sharp('image.png').webp({ quality: 80 }).toFile('image.webp');

// JPEG 压缩
await sharp('photo.jpg').jpeg({ quality: 60, progressive: true }).toFile('photo-compressed. jpg');

// AVIF（现代高效格式）
await sharp('input.jpg').avif({ quality: 50 }).toFile('output.avif');

    质量建议：

    • JPEG: 60–80
    • WebP: 75–85
    • AVIF: 40–60（同等画质下比 WebP 小 20%）

  3. 裁剪（Extract）

    // 从 (left=100, top=50) 裁剪 400x300 区域
sharp('input.jpg')
  .extract({ left: 100, top: 50, width: 400, height: 300 })
  .toFile('cropped.jpg');

  4. 旋转 & 翻转

    // 自动根据 EXIF 旋转（推荐！）
sharp('photo.jpg').rotate().toFile('rotated.jpg');

// 手动旋转 90 度
sharp('photo.jpg').rotate(90).toFile('rotated-90.jpg');

// 水平翻转
sharp('photo.jpg').flip().toFile('flipped.jpg');

  5. 添加水印

    const watermark = await sharp('watermark.png')
  .resize(200, 100)
  .toBuffer();

await sharp('background.jpg')
  .composite([{ input: watermark, gravity: 'southeast' }]) // 右下角
  .toFile('watermarked.jpg');

    gravity 位置：
    north, northeast, east, southeast, south, southwest, west, northwest, center

  6. 生成多尺寸响应式图片

    const sizes = [320, 640, 1024, 1920];

for (const width of sizes) {
  await sharp('original.jpg')
    .resize(width)
    .jpeg({ quality: 80 })
    .toFile(`responsive-${width}.jpg`);
}

6.1.4 高级功能

  1. 获取图片元数据

    const metadata = await sharp('image.jpg').metadata();
console.log(metadata);
// { 
//   format: 'jpeg',
//   width: 1920,
//   height: 1080,
//   space: 'srgb',
//   channels: 3,
//   ...
// }

  2. 调整颜色

    sharp('photo.jpg')
  .modulate({ brightness: 1.2, saturation: 1.1 })
  .gamma(2.2)
  .toFile('enhanced.jpg');

  3. 模糊/锐化

    // 高斯模糊
sharp('image.jpg').blur(5).toFile('blurred.jpg');

// 锐化
sharp('image.jpg').sharpen().toFile('sharpened.jpg');

6.1.5 在 Express 中直接返回处理后的图片

app.get('/thumbnail/:filename', async (req, res) => {
  try {
    const { filename } = req.params;
    const thumbnail = await sharp(`uploads/${filename}`)
      .resize(200, 200, { fit: 'cover' })
      .jpeg({ quality: 80 })
      .toBuffer();

    res.set('Content-Type', 'image/jpeg');
    res.set('Cache-Control', 'public, max-age=31536000'); // 缓存 1 年
    res.send(thumbnail);
  } catch (err) {
    res.status(404).send('Image not found');
  }
});

6.1.6 与 Multer（文件上传）集成

const multer = require('multer');
const upload = multer({ dest: 'uploads/' });

app.post('/upload', upload.single('avatar'), async (req, res) => {
  const { path } = req.file;
  
  // 生成缩略图
  await sharp(path)
    .resize(150, 150, { fit: 'cover' })
    .jpeg({ quality: 80 })
    .toFile(`public/avatars/${req.file.filename}.jpg`);

  res.json({ message: 'Avatar uploaded' });
});

6.1.7 常见问题 & 最佳实践

  • 问题 1：中文路径/文件名报错

    • 原因：Windows 路径编码问题
    • 解决：使用绝对路径 + path.resolve()
      const inputPath = path.resolve(__dirname, '图片.jpg');

  • 问题 2：内存泄漏（大量并发处理）

    • 解决：限制并发数（用 p-limit）
      const pLimit = require('p-limit');
const limit = pLimit(5); // 最多 5 个并发

const tasks = files.map(file => 
  limit(() => sharp(file).resize(800).toFile(...))
);
await Promise.all(tasks);

  • 最佳实践：

    1. 始终指定输出格式（避免意外格式）
      .jpeg() // 显式转为 JPEG
    2. 先 resize 再压缩（顺序影响质量）
    3. 生产环境缓存处理结果（避免重复计算）
    4. 使用 AVIF/WebP 提升性能（需检测浏览器支持）

6.2 Squoosh 图片压缩

Squoosh 是由 Google Chrome 团队开发的开源图像压缩工具，专注于极致压缩现代图像格式（如 WebP、AVIF、JPEG XL），同时保持高视觉质量。它提供：

  • Web 界面：https://squoosh.app（在线使用）
  • CLI 工具：@squoosh/cli（集成到构建流程）
  • 库：@squoosh/lib（在 Node.js/浏览器中编程调用）

核心优势：

  • 支持 AVIF（比 WebP 小 20%）、MozJPEG（优化 JPEG）、OxiPNG（无损 PNG 压缩）
  • 比 ImageMagick/sharp 压缩率更高（尤其对照片类图像）
  • 可视化对比压缩效果（Web 版）

6.2.1 安装 Squoosh CLI

# 全局安装（推荐）
npm install -g @squoosh/cli

# 或项目内安装
npm install --save-dev @squoosh/cli

注意：

  • 首次运行会自动下载编解码器（约 50–100MB）
  • 需要 Node.js ≥ 14

6.2.2 基础命令行使用

  1. 基本压缩

    # 将 input.jpg 压缩为 AVIF（默认高质量）
squoosh-cli input.jpg

# 输出到指定目录
squoosh-cli input.jpg -d output/

    输出文件：output/input.avif（自动选择最佳格式）

  2. 指定输出格式和参数

    # 转为 WebP，质量 75
squoosh-cli image.png --webp '{"quality":75}'

# 转为 AVIF，质量 50，速度优先
squoosh-cli photo.jpg --avif '{"quality":50, "speed":8}'

# 无损压缩 PNG
squoosh-cli diagram.png --oxipng '{}'

    常用编码器参数：

    格式参数示例说明
    --avif{"quality":60, "speed":6}speed: 0（慢/高压缩）~ 10（快/低压缩）
    --webp{"quality":80, "alphaQuality":100}alphaQuality 控制透明通道质量
    --mozjpeg{"quality":75, "progressive":true}优化 JPEG
    --oxipng{"level":6}无损 PNG 压缩（level 1–6）

  3. 批量处理

    # 处理整个目录
squoosh-cli images/*.jpg -d compressed/

# 递归子目录（需 shell 支持）
squoosh-cli **/*.png -d output/

6.2.3 高级用法

  1. 保留原始文件名（不加后缀）

    # 默认输出为 input.avif，但你可能想要 input.jpg → input.webp
squoosh-cli input.jpg --webp -d output/ --output-name '{name}.webp'

  2. 多格式输出（响应式图片）

    # 同时生成 WebP 和 AVIF
squoosh-cli photo.jpg \
  --webp '{"quality":80}' \
  --avif '{"quality":60}' \
  -d output/

    输出：output/photo.webp + output/photo.avif

  3. 调整尺寸后再压缩

    Squoosh CLI 不支持 resize！

    需先用 sharp/imagemagick 调整尺寸，再用 Squoosh 压缩：

    # 步骤 1: 用 sharp 调整尺寸
npx sharp-cli --input photo.jpg --resize 1200 --output temp.jpg

# 步骤 2: 用 squoosh 压缩
squoosh-cli temp.jpg --avif -d final/

6.2.4 在 Node.js 中编程调用（@squoosh/lib）

适用于需要精细控制的场景（如根据图片内容动态选择参数）

  • 安装

    npm install @squoosh/lib

  • 示例：压缩单张图片

    import { encode } from '@squoosh/lib';
import { readFile, writeFile } from 'fs/promises';

async function compressImage(inputPath, outputPath) {
  const imageBuffer = await readFile(inputPath);

  // 自动检测格式并压缩
  const { binary } = await encode({
    // 输入数据
    data: new Uint8Array(imageBuffer),
    // 编码配置
    avif: { quality: 60 }
  });

  await writeFile(outputPath, Buffer.from(binary));
  console.log('Compressed:', outputPath);
}

compressImage('photo.jpg', 'photo.avif');

  • 批量压缩（带进度）

    import { encode } from '@squoosh/lib';
import { readdir, readFile, writeFile } from 'fs/promises';
import path from 'path';

async function batchCompress(dir) {
  const files = await readdir(dir);
  const imageFiles = files.filter(f => /\.(jpe?g|png)$/i.test(f));

  for (const file of imageFiles) {
    const input = path.join(dir, file);
    const output = path.join(dir, file.replace(/\.\w+$/, '.avif'));

    const buf = await readFile(input);
    const { binary } = await encode({
      data: new Uint8Array(buf),
      avif: { quality: 55 }
    });

    await writeFile(output, Buffer.from(binary));
    console.log(`${file} → ${path.basename(output)}`);
  }
}

batchCompress('./images');

注意：

  • @squoosh/lib 会自动下载 WASM 编解码器（首次运行较慢）
  • 不支持流式处理（大文件需足够内存）

6.2.5 Web 版 Squoosh（在线使用）

访问 https://squoosh.app：

  1. 拖入图片
  2. 左右滑动对比原始图 vs 压缩图
  3. 实时调整参数（质量、分辨率等）
  4. 下载压缩结果

💡 适合场景：

  • 快速压缩单张图片
  • 学习不同格式/参数的效果
  • 无开发环境时临时使用

6.2.6 最佳实践建议

场景推荐方案
构建时优化静态资源squoosh-cli（Gatsby/Next.js/Vite 插件）
用户上传图片实时处理sharp（快速 resize） + squoosh（后台压缩）
需要最高压缩率优先 AVIF → WebP → JPEG
兼容旧浏览器仅生成 WebP + JPEG

Next.js 集成示例（next.config.js）

// 构建后自动压缩 public/images 下的图片
const { execSync } = require('child_process');

module.exports = {
  async onBuildManifest() {
    execSync('npx @squoosh/cli public/images/*.jpg --avif -d public/images/');
  }
}

6.3 image-size 图片大小

image-size 是一个轻量级的 JavaScript 库，用于获取图片文件的尺寸（宽度和高度）而无需完整加载整个图像。这对于优化网页加载性能特别有用，因为它允许你在不牺牲用户数据的情况下快速获取到图片的尺寸信息。

  1. 安装

    npm install image-size

  2. 在 Node.js 中使用

    以下是如何在 Node.js 脚本中使用 image-size 获取本地图片文件的尺寸：

    const sizeOf = require('image-size');

sizeOf('path/to/your/image.jpg', function (err, dimensions) {
  if (err) {
    console.error(err);
  } else {
    console.log(dimensions); // 输出: { width: 1920, height: 1080 }
  }
});

    对于异步操作，你也可以使用 Promise 风格的调用方式：

    const sizeOf = require('image-size');

async function getImageDimensions(imagePath) {
  try {
    const dimensions = await new Promise((resolve, reject) => {
      sizeOf(imagePath, (err, dimensions) => {
        if (err) reject(err);
        else resolve(dimensions);
      });
    });
    console.log(dimensions); // 输出: { width: 1920, height: 1080 }
  } catch (error) {
    console.error(error);
  }
}

getImageDimensions('path/to/your/image.jpg');

image-size 是一个非常有用的工具，尤其是在你需要处理大量图片文件并希望优化性能时。它可以让你在 Node.js 环境中轻松获取图片尺寸，从而更好地控制资源加载和布局调整。对于浏览器环境，考虑使用原生的解决方案可能会更加简便高效。
