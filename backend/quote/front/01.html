一、数据处理

1.1 TanStack 数据获取

TanStack（原 React Query / Vue Query / Solid Query 等）是一组用于数据获取（data fetching）的现代化状态管理库，为不同前端框架提供一致的 API 和核心能力（缓存、去重、后台刷新、乐观更新等）。

  • 官网：https://tanstack.com/query
  • React 教程：React Query Essentials

  1. 它解决了传统前端应用中 服务端状态（server state） 管理的痛点，如：

    • 自动缓存与去重请求
    • 后台刷新（stale-while-revalidate）
    • 乐观更新（optimistic updates）
    • 分页、无限滚动、依赖查询等高级模式

  2. 核心思想（所有框架通用）

    • 服务端状态 ≠ 客户端状态：TanStack 只管理来自 API 的数据
    • 自动缓存：相同查询只请求一次
    • Stale-While-Revalidate：先返回缓存，再后台拉新
    • 基于 queryKey 的缓存键：必须是稳定、可序列化的数组

    所有框架共享同一套 query-core 逻辑，API 高度一致。

  3. TanStack 生态概览

    库名用途对应框架
    @tanstack/react-query数据获取 + 缓存React
    @tanstack/vue-query数据获取 + 缓存Vue 3
    @tanstack/solid-query数据获取 + 缓存SolidJS
    @tanstack/svelte-query数据获取 + 缓存Svelte
    @tanstack/query-core核心逻辑（无 UI 绑定）任意 JS

React：@tanstack/react-query

  1. 安装

    npm install @tanstack/react-query

  2. 全局配置（App.tsx）

    import {
  QueryClient,
  QueryClientProvider
} from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000, // 5分钟内不重新请求
      gcTime: 10 * 60 * 1000,   // 10分钟后从内存移除
      retry: 1                  // 失败重试1次
    }
  }
});

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <YourApp />
    </QueryClientProvider>
  );
}

  3. 基础用法

    import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

// 获取数据
const { data, isLoading } = useQuery({
  queryKey: ['todos'],
  queryFn: () => axios.get('/api/todos').then(res => res.data)
});

// 写操作
const queryClient = useQueryClient();
const mutation = useMutation({
  mutationFn: (newTodo) => axios.post('/api/todos', newTodo),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['todos'] });
  }
});

  4. 高级模式

    1. 依赖查询（Dependent Queries）

      // 先获取项目ID，再获取项目详情
const projectId = useSomeHook();

const projectQuery = useQuery({
  queryKey: ['project', projectId],
  queryFn: () => fetchProject(projectId!),
  enabled: !!projectId // 仅当 projectId 存在时请求
});

    2. 并行查询

      const [usersQuery, postsQuery] = useQueries({
  queries: [
    { queryKey: ['users'], queryFn: fetchUsers },
    { queryKey: ['posts'], queryFn: fetchPosts }
  ]
});

    3. 分页

      const {
  data,
  fetchNextPage,
  hasNextPage,
  isFetchingNextPage
} = useInfiniteQuery({
  queryKey: ['projects'],
  queryFn: ({ pageParam = 1 }) => fetchProjects(pageParam),
  getNextPageParam: (lastPage, allPages) => {
    return lastPage.hasNextPage ? allPages.length + 1 : undefined;
  }
});

    4. 乐观更新

      const updateTodo = useMutation({
  mutationFn: updateTodoApi,
  onMutate: async (newTodo) => {
    // 1. 取消正在进行的查询
    await queryClient.cancelQueries({ queryKey: ['todos'] });

    // 2. 快照当前状态
    const previousTodos = queryClient.getQueryData(['todos']);

    // 3. 乐观更新缓存
    queryClient.setQueryData(['todos'], (old: any) =>
      old.map(t => t.id === newTodo.id ? newTodo : t)
    );

    // 4. 返回上下文（用于回滚）
    return { previousTodos };
  },
  onError: (err, newTodo, context) => {
    // 失败时回滚
    queryClient.setQueryData(['todos'], context.previousTodos);
  },
  onSettled: () => {
    // 无论成功失败，都重新验证
    queryClient.invalidateQueries({ queryKey: ['todos'] });
  }
});

  5. 特色功能

    • Suspense 模式：useQuery({ suspense: true })
    • 自定义 Hook 封装：
      const useTodos = () => useQuery({ queryKey: ['todos'], queryFn: fetchTodos });

Vue 3：@tanstack/vue-query

  1. 安装

    npm install @tanstack/vue-query

  2. 全局配置（main.ts）

    import { createApp } from 'vue';
import { VueQueryPlugin, type VueQueryPluginOptions } from '@tanstack/vue-query';

const vueQueryConfig: VueQueryPluginOptions = {
  queryClientConfig: {
    defaultOptions: {
      queries: { staleTime: 5000 }
    }
  }
};

createApp(App).use(VueQueryPlugin, vueQueryConfig).mount('#app');

  3. 组件中使用（Composition API）

    <script setup lang="ts">
import { useQuery, useMutation, useQueryClient } from '@tanstack/vue-query';

// 获取数据
const { data, isLoading } = useQuery({
  queryKey: ['todos'],
  queryFn: () => axios.get('/api/todos').then(res => res.data)
});

// 写操作
const queryClient = useQueryClient();
const mutation = useMutation({
  mutationFn: (newTodo: Todo) => axios.post('/api/todos', newTodo),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['todos'] });
  }
});
</script>

<template>
  <div v-if="isLoading.value">Loading...</div>
  <ul v-else>
    <li v-for="todo in data.value" :key="todo.id">{{ todo.title }}</li>
  </ul>
</template>

  4. 注意事项

    • 所有返回值都是 ref 对象（需 .value 访问）
    • 支持 <script setup> 和 Options API

SolidJS：@tanstack/solid-query

  1. 安装

    npm install @tanstack/solid-query

  2. 全局配置（App.tsx）

    import { QueryClient, QueryClientProvider } from '@tanstack/solid-query';

const queryClient = new QueryClient();

export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <YourApp />
    </QueryClientProvider>
  );
}

  3. 组件中使用

    import { createQuery, createMutation, useQueryClient } from '@tanstack/solid-query';

function TodoList() {
  // 获取数据
  const query = createQuery(() => ({
    queryKey: ['todos'],
    queryFn: () => axios.get('/api/todos').then(res => res.data)
  }));

  // 写操作
  const queryClient = useQueryClient();
  const mutation = createMutation(() => ({
    mutationFn: (newTodo: Todo) => axios.post('/api/todos', newTodo),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['todos'] });
    }
  }));

  return (
    <div>
      {query.isLoading && <p>Loading...</p>}
      <ul>
        {query.data?.map(todo => (
          <li>{todo.title}</li>
        ))}
      </ul>
    </div>
  );
}

  4. 特点

    • 使用 createQuery / createMutation（符合 Solid 的 reactive 函数风格）
    • 返回值是 signal-like 对象（直接解构使用）

Svelte：@tanstack/svelte-query

  1. 安装

    npm install @tanstack/svelte-query

  2. 全局配置（src/app.html 或根组件）

    <!-- 在根组件中 -->
<script>
  import { setContext } from 'svelte';
  import { QueryClient, QueryClientProvider } from '@tanstack/svelte-query';

  const queryClient = new QueryClient();
  setContext('queryClient', queryClient);
</script>

<QueryClientProvider {queryClient}>
  <slot />
</QueryClientProvider>

  3. 页面中使用

    <script>
  import { queryOptions, useQuery, useMutation, useQueryClient } from '@tanstack/svelte-query';

  // 定义查询
  const todosQuery = queryOptions({
    queryKey: ['todos'],
    queryFn: () => axios.get('/api/todos').then(res => res.data)
  });

  // 使用查询
  const { data, isLoading } = useQuery(todosQuery);

  // 写操作
  const queryClient = useQueryClient();
  const mutation = useMutation({
    mutationFn: (newTodo) => axios.post('/api/todos', newTodo),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['todos'] });
    }
  });
</script>

{#if $isLoading}
  <p>Loading...</p>
{:else}
  <ul>
    {#each $data as todo}
      <li>{todo.title}</li>
    {/each}
  </ul>
{/if}

  4. 注意事项

    • 使用 $store 语法（Svelte 的 store 自动订阅）
    • 查询需先通过 queryOptions 定义

关键一致性：

  • queryKey 格式完全相同
  • queryFn / mutationFn 签名一致
  • 缓存行为、重试策略、staleTime 等配置通用

通用最佳实践（所有框架）

  1. 封装 API 层

    // api/todos.ts
export const fetchTodos = () => axios.get('/api/todos').then(res => res.data);
export const createTodo = (todo: Todo) => axios.post('/api/todos', todo);

  2. 自定义 Hook/函数（避免重复）

    // React
export const useTodos = () => useQuery({ queryKey: ['todos'], queryFn: fetchTodos });

// Vue
export const useTodos = () => useQuery({ queryKey: ['todos'], queryFn: fetchTodos });

// Solid
export const useTodos = () => createQuery(() => ({ queryKey: ['todos'], queryFn: fetchTodos }));

  3. 合理设置缓存时间

    // 静态数据（如国家列表）
staleTime: 1000 * 60 * 60 // 1小时

// 动态数据（如消息）
staleTime: 1000 // 1秒

  4. 错误边界处理

    • React：用 ErrorBoundary
    • Vue：用 onErrorCaptured
    • 其他：在 onError 回调中统一处理

常见陷阱（跨框架）

  1. queryKey 不稳定

    // 错误：每次渲染生成新对象
queryKey: ['user', { id: userId }]

// 正确：使用原始值
queryKey: ['user', userId]

  2. 忘记条件请求

    // 当 userId 为空时仍会请求
useQuery({ queryKey: ['user', userId], queryFn: () => fetchUser(userId) })

// 应添加 enabled
useQuery({ 
  queryKey: ['user', userId], 
  queryFn: () => fetchUser(userId),
  enabled: !!userId 
})

  3. 过度使用 invalidateQueries

    • 优先用 setQueryData 直接更新缓存
    • 仅当无法预测变更时才使查询失效

1.2 urql

urql（发音为 "Urkel"）是一个轻量、可定制、适用于多种前端框架的 GraphQL 客户端，由 Formidable Labs 开发。它专注于 简洁性、可组合性和性能，支持 React、Vue、Svelte、SolidJS 等主流框架。

  • 官网：https://formidable.com/open-source/urql/
  • 文档：https://urql.dev/
  • GitHub：https://github.com/urql-graphql/urql
  • CodeSandbox 示例：https://codesandbox.io/s/urql-react-example

核心优势：

  • 比 Apollo Client 更小（~10KB vs ~70KB）
  • 插件化架构（通过 exchanges 扩展功能）
  • 内置缓存、请求去重、离线支持
  • 与 TanStack Query 类似的设计哲学（但专为 GraphQL）

1.2.1 安装

  • 基础包（必须）

    npm install urql graphql

  • 框架绑定（按需安装）

    框架包名
    React@urql/core + urql（已包含）
    Vue 3@urql/vue
    Svelte@urql/svelte
    SolidJS@urql/solid

    urql 默认导出 React 绑定，其他框架需单独安装对应包。

1.2.2 React 中使用（最常见）

  1. 全局配置（App.tsx）

    import { Provider, createClient, cacheExchange, fetchExchange } from 'urql';

// 创建客户端
const client = createClient({
  url: 'https://your-graphql-endpoint.com/graphql',
  exchanges: [cacheExchange, fetchExchange], // 核心插件
});

function App() {
  return (
    <Provider value={client}>
      <YourApp />
    </Provider>
  );
}

  2. 查询数据（useQuery）

    import { gql, useQuery } from 'urql';

const GET_USERS = gql`
  query GetUsers {
    users {
      id
      name
      email
    }
  }
`;

function UserList() {
  const [result] = useQuery({ query: GET_USERS });

  const { data, fetching, error } = result;

  if (fetching) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {data.users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

  3. 执行变更（useMutation）

    import { gql, useMutation } from 'urql';

const CREATE_USER = gql`
  mutation CreateUser($name: String!) {
    createUser(input: { name: $name }) {
      id
      name
    }
  }
`;

function CreateUserForm() {
  const [result, executeMutation] = useMutation(CREATE_USER);
  const [name, setName] = useState('');

  const handleSubmit = (e: FormEvent) => {
    e.preventDefault();
    executeMutation({ name }); // 传入 variables
  };

  if (result.fetching) return <p>Creating...</p>;
  if (result.error) return <p>Error: {result.error.message}</p>;
  if (result.data) return <p>Created: {result.data.createUser.name}</p>;

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={e => setName(e.target.value)} />
      <button type="submit">Create</button>
    </form>
  );
}

1.2.3 核心概念

  1. Exchanges（插件系统）

    urql 的功能通过 exchanges（中间件）实现，按顺序处理请求/响应：

    Exchange作用
    cacheExchange缓存查询结果（基于 GraphQL AST）
    fetchExchange发送 HTTP 请求
    dedupExchange请求去重（相同查询只发一次）
    retryExchange失败重试
    authExchange添加认证头
    devtoolsExchange启用 DevTools

    自定义 Exchanges 示例（添加 Token）

    import { authExchange } from '@urql/exchange-auth';

const client = createClient({
  url: '/graphql',
  exchanges: [
    cacheExchange,
    dedupExchange,
    authExchange({
      addAuthToOperation: ({ authState, operation }) => {
        if (!authState || !authState.token) return operation;
        return {
          ...operation,
          context: {
            ...operation.context,
            fetchOptions: {
              headers: { Authorization: `Bearer ${authState.token}` }
            }
          }
        };
      },
      willAuthError: ({ authState }) => !authState,
      getAuth: async () => ({ token: localStorage.getItem('token') })
    }),
    fetchExchange
  ]
});

  2. 缓存机制

    • 自动缓存：基于查询的 GraphQL AST 结构（不是 URL）
    • 部分更新：变更（mutation）会自动更新相关查询缓存
    • 手动更新：通过 cache.updateQuery
    // 手动更新缓存（乐观更新）
const [result, executeMutation] = useMutation(CREATE_USER);

executeMutation(
  { name },
  { 
    optimisticData: { 
      createUser: { id: 'temp-id', name, __typename: 'User' } 
    },
    update: (cache, result) => {
      // 手动将新用户加入 users 列表
      cache.updateQuery({ query: GET_USERS }, data => ({
        ...data,
        users: [...data.users, result.createUser]
      }));
    }
  }
);
