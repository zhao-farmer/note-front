七、markdown插件

7.1 ByteMD（项目已停止维护）

@bytemd 是一个基于 ByteMD 的开源 Markdown 编辑器，由 Bytedance（字节跳动） 团队开发，不过目前已经被放弃，也没有官网了。

  • https://github.com/pd4d10/bytemd

7.1.1 安装

  1. 使用 npm 安装

    npm install @bytemd/vue  # Vue 2 版本
npm install @bytemd/vue-next # Vue 3 版本
npm install @bytemd/react  # React 版本
npm install bytemd  # Svelte/Vanilla JS组件

7.1.2 在 Vue 3 中使用（最常见场景）

  1. 基础用法（带预览、工具栏）

    <template>
  <ClientOnly> <!-- 如果用 Nuxt 3，建议包一层 -->
    <ByteMd v-model="value" :plugins="plugins" />
  </ClientOnly>
</template>

<script setup>
import { ref } from 'vue'
import ByteMd from '@bytemd/vue'
import 'bytemd/dist/index.css' // 必须引入样式

// 引入你需要的插件（官方提供很多）
import gfm from '@bytemd/plugin-gfm' // GitHub 风格 Markdown
import highlight from '@bytemd/plugin-highlight-ssr' // 代码高亮
import mermaid from '@bytemd/plugin-mermaid' // 流程图支持

const value = ref('# Hello Bytemd\nThis is a **demo**.')

const plugins = [
  gfm(),
  highlight(),
  mermaid(),
  // 可继续添加其他插件...
]
</script>

    @bytemd/plugin-highlight-ssr 支持服务端渲染（SSR），普通项目也可用 @bytemd/ plugin-highlight。

7.1.3 常用插件列表

插件用途
@bytemd/plugin-gfm支持 GitHub Flavored Markdown（表格、任务列表等）
@bytemd/plugin-highlight / -ssr代码块语法高亮
@bytemd/plugin-mermaid支持 Mermaid 图表（流程图、时序图）
@bytemd/plugin-mathLaTeX 数学公式（KaTeX）
@bytemd/plugin-footnote脚注支持
@bytemd/plugin-frontmatterYAML frontmatter
@bytemd/plugin-youtube嵌入 YouTube 视频
@bytemd/plugin-emoji表情符号（如 :smile:）

所有插件：https://github.com/bytedance/bytemd/tree/main/packages

7.1.4 自定义配置

  1. 隐藏某些工具栏按钮

    const plugins = [
  gfm({
    // 禁用某些 GFM 功能
    taskList: false,
    strikethrough: false
  }),
  highlight()
]

// 或通过 locale 自定义按钮文字（支持 i18n）

  2. 自定义上传图片

    import gfm from '@bytemd/plugin-gfm'

const plugins = [
  gfm({
    uploadImages(files) {
      // files 是 File[]，返回 Promise<string[]>（图片 URL 列表）
      return uploadToYourServer(files).then(res => res.urls)
    }
  })
]

  3. 只读模式（仅预览）

    <ByteMd :value="markdownContent" :mode="'preview'" />

    或

    <ByteMd :value="markdownContent" :editable="false" />

7.1.5 注意事项

  1. 样式必须引入

    import 'bytemd/dist/index.css'

    否则界面会错乱。

  2. SSR 问题（Nuxt 3 / Vite SSR）
    使用 <ClientOnly> 包裹组件，避免服务端渲染报错。

  3. 中文输入法兼容性好
    Bytemd 基于 svelte + codemirror，对中文输入支持良好。

7.1.6 完整示例（Vue 3 + Vite）

npm create vue@3
cd my-app
npm install @bytemd/vue-next @bytemd/plugin-gfm @bytemd/plugin-highlight-ssr

src/App.vue:

<template>
  <div style="width: 800px; margin: 20px auto;">
    <ByteMd v-model="content" :plugins="plugins" />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import ByteMd from '@bytemd/vue'
import 'bytemd/dist/index.css'
import gfm from '@bytemd/plugin-gfm'
import highlight from '@bytemd/plugin-highlight-ssr'

const content = ref('# 欢迎使用 Bytemd\n- 支持 **加粗**\n- 表格\n- 代码高亮')

const plugins = [gfm(), highlight()]
</script>

7.2 Vditor

Vditor 是一款由国内开发者 b3log 团队开源的 现代化 Markdown 编辑器，支持所见即所得（WYSIWYG）、即时渲染（IR）和分屏预览三种模式，功能强大、体验流畅，特别适合技术博客、文档系统、笔记类应用。

官网：https://vditor.b3log.org/ GitHub：https://github.com/Vanessa219/vditor 特点：中文友好、TypeScript 编写、插件丰富、支持 LaTeX / Mermaid / Emoji 等

7.2.1 快速上手（原生 JS）

引入方式CDN（最快）

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8" />
  <!-- Vditor 样式 -->
  <link rel="stylesheet" href="https://unpkg.com/vditor@latest/dist/index.css" />
</head>
<body>
  <div id="vditor"></div>

  <!-- Vditor 核心 -->
  <script src="https://unpkg.com/vditor@latest/dist/index.js"></script>

  <script>
    const vditor = new Vditor('vditor', {
      height: 400,
      placeholder: '请输入 Markdown 内容...',
      mode: 'wysiwyg', // 可选: 'sv' (分屏), 'ir' (即时渲染), 'wysiwyg' (所见即所得)
      toolbar: [
        'emoji',
        'headings',
        'bold',
        'italic',
        'strike',
        'link',
        '|',
        'list',
        'ordered-list',
        'check',
        'outdent',
        'indent',
        '|',
        'quote',
        'code',
        'inline-code',
        'insert-before',
        'insert-after',
        '|',
        'upload',
        'table',
        'undo',
        'redo'
      ],
      // 图片上传配置
      upload: {
        url: '/api/upload',
        fieldName: 'file',
        max: 5 * 1024 * 1024, // 5MB
        linkToImgUrl: '/api/link-to-img' // 可选：将链接转为图片
      },
      after: () => {
        console.log('Vditor 初始化完成')
      }
    })

    // 获取内容
    document.getElementById('getContent').onclick = () => {
      console.log('Markdown:', vditor.getValue())
      console.log('HTML:', vditor.getHTML())
    }
  </script>

  <button id="getContent">获取内容</button>
</body>
</html>

7.2.2 在 Vue 3 中使用

  1. 安装
npm install vditor

  1. 封装为组件

    <template>
  <div>
    <div ref="vditorRef" class="vditor-wrapper"></div>
    <button @click="getContent">获取 Markdown</button>
  </div>
</template>

<script setup>
import { onMounted, onBeforeUnmount, ref } from 'vue'
import Vditor from 'vditor'
import 'vditor/dist/index.css'

const vditorRef = ref(null)
let vditorInstance = null

onMounted(() => {
  vditorInstance = new Vditor(vditorRef.value, {
    height: 400,
    mode: 'wysiwyg', // 或 'sv' / 'ir'
    placeholder: '开始输入...',
    toolbarConfig: {
      pin: true // 工具栏固定顶部
    },
    cache: {
      enable: false // 关闭本地缓存（默认开启）
    },
    upload: {
      url: '/api/upload-image',
      fieldName: 'file',
      max: 10 * 1024 * 1024, // 10MB
      // 自定义上传处理（可选）
      handler(files) {
        const formData = new FormData()
        formData.append('file', files[0])
        return fetch('/api/upload-image', {
          method: 'POST',
          body: formData
        }).then(res => res.json()).then(data => {
          if (data.url) {
            return data.url
          }
          throw new Error('上传失败')
        })
      }
    },
    after() {
      // 可设置初始内容
      vditorInstance.setValue('# 欢迎使用 Vditor\n这是一个 **Markdown** 编辑器。')
    }
  })
})

onBeforeUnmount(() => {
  if (vditorInstance) {
    vditorInstance.destroy()
  }
})

const getContent = () => {
  console.log('Markdown:', vditorInstance.getValue())
  console.log('HTML:', vditorInstance.getHTML())
}
</script>

<style scoped>
.vditor-wrapper {
  border: 1px solid #e0e0e0;
  border-radius: 6px;
  padding: 8px;
}
</style>

7.2.3 核心特性与配置

  1. 三种编辑模式

    模式配置值说明
    所见即所得'wysiwyg'类似富文本，直接编辑渲染后效果
    即时渲染'ir'左侧写 Markdown，右侧实时预览（单栏）
    分屏预览'sv'左侧 Markdown，右侧 HTML 预览

  2. 内置强大功能

    • 代码高亮（Prism.js）
    • LaTeX 数学公式（KaTeX）
    • 流程图 / 时序图（Mermaid）
    • 图表（ECharts）
    • 任务列表（- [x]）
    • Emoji 表情（:smile: → 😊）
    • 大纲导航（TOC）
    • 快捷键丰富（Ctrl+B 加粗等）

  3. 自定义工具栏

    toolbar: [
  'emoji',
  'headings',
  'bold',
  'italic',
  'strike',
  'link',
  'upload',
  '|',
  'list',
  'ordered-list',
  'check',
  '|',
  'quote',
  'code',
  'inline-code',
  '|',
  'undo',
  'redo',
  'export', // 导出 PDF / Markdown
  'help'
]

  4. 获取内容

    vditor.getValue() // 返回 Markdown 字符串
vditor.getHTML()  // 返回渲染后的 HTML

7.2.4 图片上传配置详解

  • 方式一：通过 url 自动处理

    upload: {
  url: '/api/upload',
  fieldName: 'file',
  // 后端需返回 { msg: "", code: 0, data: { errFiles: [], succMap: { "filename": "url" } } }
}

  • 方式二：通过 handler 自定义逻辑（推荐）

    upload: {
  handler(files) {
    // files: File[]，只处理第一张
    const file = files[0]
    const formData = new FormData()
    formData.append('image', file)

    return fetch('/api/upload', {
      method: 'POST',
      body: formData
    })
    .then(res => res.json())
    .then(data => {
      if (data.success) {
        return data.url // 必须返回字符串 URL
      }
      throw new Error(data.message || '上传失败')
    })
  }
}

handler 必须返回 Promise<string>（图片 URL）
