# 二、记录问题

## 2.1 左边的y轴数据不全

- 情况1：Y轴标签文字向左溢出，被画布边缘截断

    修改 `grid.left` 增大左侧边距

    ```js
    grid: {
        left: 80, // 调大，给y轴文字预留空间
        right: 30,
        top: 40,
        bottom: 60
    }
    ```

- 情况2：Y轴数值本身太长，标签自动换行/重叠，单纯加大left不够
    
    需要搭配 `yAxis.axisLabel` 配置：

    ```js
    yAxis: {
        axisLabel: {
            // 方案A：文字缩短，加单位
            formatter: '{value} 万',
            // 方案B：文字旋转
            rotate: 30,
            // 方案C：限制宽度，自动换行
            width: 60,
            overflow: 'break'
        }
    }
    ```

- 情况3：数值超出y轴范围，图形顶部/底部被截断（最容易混淆）

    要调整 `yAxis.min` / `yAxis.max`，或者设置自动适配：

    ```js
    yAxis: {
        min: 'dataMin',
        max: 'dataMax'
    }
    ```

## 2.2 如何定义两条折线

1. ECharts 两条折线基础写法

    核心：**`series` 数组里面放两个对象，`type:'line'`**，每一项对应一条折线。

    ```javascript
    option = {
      xAxis: {
        type: 'category',
        data: ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
      },
      yAxis: {
        type: 'value'
      },
      series: [
        // 第一条折线
        {
          name: '销量',
          type: 'line',
          data: [120, 200, 150, 80, 70, 110, 130]
        },
        // 第二条折线
        {
          name: '库存',
          type: 'line',
          data: [60, 80, 120, 190, 150, 70, 90]
        }
      ]
    };
    ```

2. 区分线条样式（颜色、虚实线）

    ```js
    series: [
      {
        name: '销量',
        type: 'line',
        data: [120, 200, 150, 80, 70, 110, 130],
        lineStyle: { color: '#228be6', width:2 },
        itemStyle: {color:'#228be6'}
      },
      {
        name: '库存',
        type: 'line',
        data: [60, 80, 120, 190, 150, 70, 90],
        lineStyle: { color: '#fa5252', type:'dashed' }, // 虚线
        itemStyle: {color:'#fa5252'}
      }
    ]
    ```

3. 双Y轴（两条折线数值量级差距巨大时使用，解决你刚才Y轴数值过大问题）

    > 一条折线使用左侧yAxis，另一条绑定右侧第二个yAxis
    ```js
    option = {
      xAxis: {
        type: 'category',
        data: ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
      },
      yAxis: [
        { type: 'value', name:'销量' },
        { type: 'value', name:'库存', position:'right' } // 右侧Y轴
      ],
      series: [
        {
          name: '销量',
          type: 'line',
          yAxisIndex: 0, // 绑定第一个y轴（左）
          data: [120, 200, 150, 80, 70, 110, 130]
        },
        {
          name: '库存',
          type: 'line',
          yAxisIndex: 1, // 绑定第二个y轴（右）
          data: [6000, 8000, 12000, 19000, 15000, 7000, 9000]
        }
      ]
    };
    ```

4. 关键要点
    1. 多条折线，直接在 `series` 数组追加对象，每个对象代表一条线
    2. `name` 用于图例 legend，名字相同会合并
    3. 数值差距悬殊 → 启用**双y轴** `yAxisIndex`，不要单纯硬调grid.left
    4. legend 图例默认自动读取series.name，不需要额外配置



## 2.3 折线图如何处理不连贯的数据 

> 
> **`connectNulls: true`**：折线遇到 `null` 空数据点时，**跨过空点，把前后有效点直接连起来**；默认是 false，遇到 null 会断开折线。
> 只作用于 `type:'line'` 折线系列，写在 `series` 里面，**不是在xAxis/yAxis**。

1. 最简片段

    ```js
    series: [
      {
        name: "销售量",
        type: "line",
        connectNulls: true, // 开启：空数据不中断线条
        data: [150, null, 224, 218, null, 147, 260]
      },
      {
        name: "库存量",
        type: "line",
        connectNulls: true, // 多条折线各自单独配置
        data: [80, 120, null, 160, 90, 110, null]
      }
    ]
    ```

2. 关键要点

    1. 生效条件：数据必须是 **`null`**，不是 `undefined`、`''`空字符串、`0`。`0` 会当成有效值。

        ```js
        // 识别为空点
        data: [100, null, 200]
        //  无效，不会断开，会当成0/有效值
        data: [100, '', 200]
        ```
    2. 当 `connectNulls: false`（默认）：遇到 `null`，线条直接断开。
    3. 多条折线，**每条series独立控制**，想全部连线就要每条都写 `connectNulls:true`。
    4. 搭配你之前的brush框选完全兼容，互不冲突。


## 2.4 ECharts 解决图例切换时图表左右宽度抖动问题

1. 问题现象

    在使用 ECharts 多Y轴图表时，点击图例（legend）隐藏/显示系列，**图表左右宽度会发生变化，两侧边距不一致**，视觉出现抖动。
    根源：Y轴刻度标签默认渲染在 `grid` 绘图区域**外侧**；当数据变化，Y轴刻度文字长度动态改变，ECharts会自动重新计算并修改`grid.left`、`grid.right`，导致绘图区宽度变化。开启`containLabel:true`会加剧该现象，它的作用就是自动预留标签所需的左右边距。

2. 解决方案思路

    将Y轴刻度标签放到绘图区域**内部渲染**，固定grid的left、right为固定像素值，不再让坐标轴标签占用grid外侧空间，关闭`containLabel`。

    1. `yAxis.axisLabel.inside: true`：刻度文字绘制到坐标轴内侧（grid绘图区内）
    2. `margin: -10`：向内偏移，控制文字与轴线距离
    3. `align` 区分左右Y轴：左侧Y轴`align:'right'`，右侧Y轴`align:'left'`，让文字紧贴轴线
    4. `grid` 设置固定 `left/right`，删除`containLabel:true`> 
    > 效果：图例点击切换、数据变更，grid边界固定，画布宽度保持稳定，不再左右抖动。
    > 风险：标签放在内部，**数值文字有可能和折线/图形重叠**，可通过数值缩写、限制文字宽度规避。

3. Demo1【错误版：会抖动】

    ```html
    <!DOCTYPE html>
    <html lang="zh-CN">
    <head>
      <meta charset="UTF-8">
      <title>错误版-宽度抖动</title>
      <script src="../js/echarts.min.js"></script>
    </head>
    <body>
      <div id="chart" style="width:800px;height:500px;"></div>
      <script>
        const myChart = echarts.init(document.getElementById('chart'));
        const option = {
          legend: {
            data: ['股票价值','每日基准']
          },
          grid: {
            left: 80,
            right: 80,
            top: 60,
            bottom: 60,
            containLabel: true // 元凶：自动根据标签宽度调整grid左右
          },
          xAxis: {
            type: 'category',
            data: ['周一','周二','周三','周四','周五','周六','周日']
          },
          yAxis: [
            {
              type: 'value',
              name: '股票价值',
              nameLocation: 'end',
              // axisLabel 默认在外侧，不设置inside
            },
            {
              type: 'value',
              name: '每日基准',
              nameLocation: 'end',
              position: 'right'
            }
          ],
          series: [
            {
              name: '股票价值',
              type: 'line',
              yAxisIndex: 0,
              data: [12000, 20000, 15000, 8000, 7000, 11000, 13000]
            },
            {
              name: '每日基准',
              type: 'line',
              yAxisIndex: 1,
              data: [120, 200, 150, 80, 70, 110, 130]
            }
          ]
        };
        myChart.setOption(option);
      </script>
    </body>
    </html>
    ```

5. 对比小结

    | 版本 | 核心配置 | 现象 |
    | --- | --- | --- |
    | 错误版 | `containLabel:true`，标签在外侧 | 点击图例，Y轴文字长度变化，grid左右自动变化，图表宽度抖动 |
