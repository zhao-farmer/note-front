# 三、属性快速查询

> 拆分：根配置、title、legend、visualMap、toolbox、tooltip、dataZoom、grid、xAxis、yAxis、polar、radiusAxis、angleAxis、series通用、bar、line、pie、scatter、radar、map、candlestick、markPoint、markLine

## 3.1 root｜顶层全局配置

```js
// ECharts 顶层全局 option 配置
const rootOption = {
  backgroundColor: 'transparent', // 画布背景色，支持rgba/hex，transparent透明
  color: ['#5470C6', '#EE6666', '#73C0DE', '#3BA272', '#FC8452'], // 全局调色盘
  textStyle: { // 全局文字默认样式
    fontFamily: 'sans-serif',
    fontSize: 12,
    color: '#333'
  },
  animation: true, // 全局动画总开关
  animationThreshold: 2000, // 图形数量阈值，超过自动关闭动画优化性能
  animationDuration: 1000, // 基础动画时长 ms
  animationEasing: 'exponentialOut', // 动画缓动函数
  animationUpdate: 300, // 数据更新动画时长 ms
  animationDelay: 0, // 动画延迟 ms
  symbolList: ['circle', 'rect', 'triangle', 'diamond', 'emptyCircle'], // 内置标记图形
  loading: {}, // loading加载动画样式
  media: [] // 响应式媒体查询，适配多屏幕
};
```

