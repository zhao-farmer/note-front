# 一、 认识 anime.js

> 
> Anime.js 是轻量JS动画库，可驱动 DOM / SVG / CSS / JS 对象属性动画，**v4 是 ESM 优先版本，核心API是 `animate()`**（v3 旧版是 `anime()`，注意区分）

## 1.2 官方章节内容


1. **入门**
    
    快速上手，安装、基础示例、核心概念，Hello World 动画。
2. **计时器（Timer）**
    
    底层时间控制器，控制时间、暂停/播放、帧率、时间缩放，所有动画的时间基座。
3. **动画（Animation）**
    
    基础 `anime()` 动画实例，单个目标属性补间（位移、透明度、宽高、颜色等），属性目标、时长、方向、循环。
4. **时间轴（Timeline）**
    
    多动画编排，按顺序/重叠并行播放一组动画；适合序列动画、分镜，是做复杂动效最常用模块。
5. **可动画（Animatable）**
    
    定义**可被驱动的目标对象**，DOM元素、SVG、普通JS对象、数组属性，指定哪些属性参与动画。
6. **可拖拽（Draggable）**
    
    内置拖拽交互，元素拖动、限制边界、吸附，适合编辑器画布、弹窗拖拽。
7. **布局（Layout）**
    
    自动布局辅助，动画过程中读取/更新元素布局位置，支持流式布局动画。
8. **作用域（Scope）**
    
    动画作用域分组，批量管理一组动画实例，统一暂停、销毁、重置，隔离动画上下文。
9. **事件（Events）**
    
    动画生命周期回调：`begin` / `update` / `complete`，鼠标、交互事件钩子。
10. **SVG**
    
    SVG专用动画：path路径绘制、stroke描边、SVG形变、路径运动（motion along path）。
11. **文本**
    
    文字逐字/逐词动画，打字机效果、字符打散动画。
12. **实用工具（Utils）**
    
    内置工具函数：插值、随机数、数值映射、颜色转换。
13. **缓动（Easing）**
    
    缓动函数，easeIn / easeOut / spring弹簧、弹跳、自定义缓动曲线，控制动画节奏。
14. **WAAPI**
    
    Web Animations API 适配器，可切换底层引擎为浏览器原生WAAPI，高性能。
15. **引擎（Engine）**
    
    渲染引擎模块，默认是 `requestAnimationFrame`，自定义渲染循环、切换渲染后端。

## 1.3 快速认识

### 1.3.1 最简示例

```html
<div class="box" style="width:80px;height:80px;background:#36f"></div>
<script>
import { animate } from 'animejs';

// animate(targets, params)
animate('.box', {
  x: 200, // translate X
  rotate: 360,
  duration: 1000, // 毫秒
  ease: 'easeOutQuad',
});
</script>
```

### 1.3.2 核心参数说明

```js
animate('.box', {
  // 动画属性（支持 transform、opacity、color、width 等）
  x: 200,
  y: [0, 120], // [from, to]
  opacity: [1, 0.2],
  rotate: '1turn', // 1turn = 360deg

  // 时间
  duration: 800,    // 动画总时长 ms
  delay: 100,       // 整体延迟
  loop: 2,          // 循环次数，true=无限循环
  loopDelay: 500,   // 每次循环之间延迟

  // 缓动
  ease: 'inOutCubic',
  // 物理弹簧动画
  // ease: spring({ bounce:0.4 }),

  // 交错动画：多个元素依次延迟出场
  delay: stagger(60),

  // 回调
  onBegin(anim) { console.log('开始'); },
  onUpdate(anim) { /* 每一帧执行 */ },
  onComplete(anim) { console.log('结束'); }
})
```

- `targets`：目标，可以是选择器字符串 / DOM元素 / DOM数组
- 可动画属性：`x/y/rotate/scale/opacity/backgroundColor`，支持 SVG 的 path、points 等属性

### 1.3.3 常用能力

1. 关键帧动画

    同一属性多段动画：

    ```js
    animate('.box', {
      x: [
        { to: 100, duration:300 },
        { to: 200, duration:500 },
        { to: 0, duration:400 }
      ],
      rotate: [0, 180, 360],
      duration: 1200
    })
    ```

2. stagger 交错多元素

    多个元素按间隔依次播放，列表入场最常用：

    ```html
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
    <script>
    animate('.item', {
      y: 40,
      opacity: [0,1],
      delay: stagger(100), // 每个元素间隔100ms
      duration: 600
    })
    </script>
    ```

3. 动画实例控制

    `animate()` 返回动画实例，可手动播放/暂停/反转：

    ```js
    const anim = animate('.box', {
      x:300,
      paused:true // 默认暂停
    });

    anim.play();
    anim.pause();
    anim.reverse();
    anim.restart();
    ```

4. 文本拆分动画 splitText

    ```js
    import { animate, splitText } from 'animejs';
    const txt = splitText('h1');
    animate(txt.words, {
      opacity:[0,1],
      delay: stagger(80)
    })
    ```
