# 一、快速介绍

GSAP 是业界最主流、高性能 JS 动画库，**框架无关**（原生 JS / Vue / React / Svelte 都能用），零依赖，可以驱动 DOM、CSS、SVG、Canvas、WebGL 属性动画。
核心优势：**时间线编排、精确控制、性能强、兼容性好**，复杂官网、滚动叙事页、SVG 动效大量使用。

## 1.1 认识GASP

1. 补间动画(Tween)

    ```js
    gsap.to(".box", { x: 200 })
    ```

    像这样**单个动画就叫做 Tween（补间动画）**。

    这个 Tween 的含义是：“请给 class 为 `.box` 的元素做动画，把它的 x 值变化到 200px（效果等同于 `transform: translateX(200px)`）。”

## 1.2 Tween 动画方法

Tween 是 GSAP 的基础动画单元，共4种：

| 方法 | 说明 |
| ---- | ---- |
| `gsap.to()` | 最常用。**从元素当前状态，动画到目标定义值** |
| `gsap.from()` | 反向的 `to()`。**从定义的起始值动画，结束在元素当前状态** |
| `gsap.fromTo()` | 同时自定义**起始值 + 结束值**，完全控制首尾状态 |
| `gsap.set()` | 直接设置属性，**无动画（等同于时长为0的to动画）** |

## 1.3 Target 动画目标

告诉 GSAP 要对谁做动画。底层使用 `document.querySelectorAll()`，支持多种目标传入方式：

1. 选择器字符串（class / id / 复合CSS选择器）
2. DOM元素变量
3. 元素数组（同时动画多个对象）

```js
// class / id
gsap.to(".box", { x: 200 });

// 复杂CSS选择器
gsap.to("section > .box", { x: 200 });

// DOM变量
let box = document.querySelector(".box");
gsap.to(box, { x: 200 });

// 元素数组，同时动画多个目标
let square = document.querySelector(".square");
let circle = document.querySelector(".circle");
gsap.to([square, circle], { x: 200 });
```

## 1.4 Vars 配置对象

第二个参数是 `vars` 对象，存放动画所有配置，分为两类：

1. **需要动画的属性**（位移、旋转、透明度等）
2. **特殊控制属性**（时长、回调、重复次数等）

```js
gsap.to(target, {
  // 待动画属性
  x: 200,
  rotation: 360,
  // 动画控制特殊属性
  duration: 2
})
```

## 1.5 可动画属性

GSAP**几乎可以动画任意数值、颜色、带数字的字符串，没有固定白名单**。
推荐优先使用：`transform` 变换属性 + `opacity`，性能更好，不会触发页面重排（layout）。

> 建议：能用 transform / opacity 做动画，就不要用 `top` / `left` / `margin` 这类会影响布局的属性，动画更流畅。

### 1.5.1 Transform 简写对照表

GSAP内置，替代CSS transform

| GSAP 属性 | 等价CSS transform |
| ---- | ---- |
| `x: 100` | `transform: translateX(100px)` |
| `y: 100` | `transform: translateY(100px)` |
| `xPercent: 50` | `transform: translateX(50%)` |
| `yPercent: 50` | `transform: translateY(50%)` |
| `scale: 2` | `transform: scale(2)` |
| `scaleX: 2` | `transform: scaleX(2)` |
| `scaleY: 2` | `transform: scaleY(2)` |
| `rotation: 90` | `transform: rotate(90deg)` |
| `rotation: "1.25rad"` | `transform: rotate(1.25rad)` |
| `skew: 30` | `transform: skew(30deg)` |
| `skewX: 30` | `transform: skewX(30deg)` |
| `skewY: "1.23rad"` | `transform: skewY(1.23rad)` |
| `transformOrigin: "center 40%"` | `transform-origin: center 40%` |
| `opacity: 0` | 透明度 |
| `autoAlpha: 0` | opacity + visibility 组合简写 |

### 1.5.2 单位使用

GSAP 默认：transform 使用 `px`、角度使用 `deg`，同时支持多种单位、相对值、函数动态求值：

```js
x: 200,          // 默认px
x: "+=200",      // 相对值（在当前值基础上增加200）
x: '40vw',       // 字符串传入其它单位
x: () => window.innerWidth / 2, // 函数式动态计算
rotation: 360,   // 默认deg角度
rotation: "1.25rad" // 弧度
```

### 1.5.3 其他可动画内容

1. **CSS属性**

    属性名要改成驼峰写法：`background-color` → `backgroundColor`
    > 警告：虽然GSAP支持filter、boxShadow动画，但浏览器渲染开销大，低端设备注意测试。**优先transform + opacity**
2. **SVG属性**

    支持transform简写；也可动画 width、height、fill、stroke、cx、viewBox 等SVG属性。
3. **普通JS对象（不限DOM元素）**

    GSAP 不需要DOM也能动画对象的任意数值属性，常用于Canvas、Pixi.js、Three.js动画：

    ```js
    let obj = { myNum: 10, myColor: "red" };
    gsap.to(obj, {
      myNum: 200,
      myColor: "blue",
      onUpdate: () => console.log(obj.myNum, obj.myColor)
    });
    ```
4. Canvas / Pixi / ThreeJS 场景

    动画存储在对象里的坐标，每一帧 `onUpdate` 更新画布渲染，是游戏/WebGL项目常用方式。

## 1.6 特殊控制属性

控制动画的行为，完整列表查阅官方文档：https://gsap.com/docs/v3/GSAP/Tween

| 属性 | 说明 |
| ---- | ---- |
| `duration` | 动画时长，单位秒。默认：0.5 |
| `delay` | 动画**开始前**延迟多少秒 |
| `repeat` | 动画重复播放次数。`repeat:-1` 代表无限循环 |
| `yoyo` | 布尔值。true：每次重复时反向播放（悠悠球来回效果），默认false |
| `stagger` | 多目标动画时，每个目标动画启动之间的间隔（秒） |
| `ease` | 缓动函数，控制动画速率曲线，决定动画运动质感。默认 `power1.out` |
| `onComplete` | 动画**全部完成**时执行的回调函数 |

### 补充说明

- `repeatDelay`：每次循环重复之间的间隔延迟（和delay不同，delay只在第一次启动前生效）
- `yoyo` 一般配合 `repeat` 使用，实现往返动画
