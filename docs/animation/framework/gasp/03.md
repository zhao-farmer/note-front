# 三、区间动画-Tween

## 3.1 属性

### 3.1.1 .data 属性



Tween 实例的 `.data` 属性，用于在动画实例上挂载自定义数据，GSAP 内部不会读取、修改这个属性，仅作为开发者的自定义存储容器。

1. 使用方式

    ```js
    // 创建动画时挂载data
    const tween = gsap.to(".box", {
      duration: 1,
      x: 100,
      data: { name: "boxAnim", type: "move" }
    });

    // 读取data
    console.log(tween.data.name);

    // 动态修改data
    tween.data.type = "slide";
    ```

    - `.data`：普通对象，完全由开发者自定义键值
    - GSAP 引擎不会使用该对象，销毁动画时不会自动清理 `data` 内引用

2. 基础示例

    ```html
    <div class="box" style="width:50px;height:50px;background:#4285f4;"></div>
    <script>
    const boxTween = gsap.to(".box", {
      x: 200,
      duration: 2,
      data: { id: 1, desc: "方块平移动画" },
      onComplete() {
        console.log(this.data.desc, "执行完成");
      }
    });

    // 访问自定义数据
    console.log(boxTween.data.id);
    </script>
    ```

3. 适用场景

    - 给动画打上标记、绑定业务ID、备注信息
    - 在 `onStart` / `onUpdate` / `onComplete` 回调中读取业务数据
    - 区分多个同目标动画实例，配合 `gsap.getTweensOf()` 遍历识别动画

4. 注意点

    - `.data` 不是动画配置属性，不会影响动画渲染、时间、缓动
    - `kill()` 杀死 tween 不会清空 `.data`，如有大对象引用需要手动释放避免内存泄漏
    - Timeline 同样拥有 `.data` 属性，用法和 Tween 一致

### 3.1.2 .ratio 属性

`Tween.ratio` 代表当前补间动画的**原始进度比例**，取值范围 `0 ~ 1`，不受 `timeScale`、`repeat`、`yoyo`、`delay` 影响，只反映动画主体时间轴的归一化进度。

> 
> 区分：`tween.progress()` 是受 `timeScale` / repeat / delay 影响的播放进度；`.ratio` 只计算动画核心时长部分，忽略延迟、重复循环等附加时间。

#### 1. 使用方式

1. 语法

    ```javascript
    const ratio = tween.ratio;
    ```

    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 读属性：**只读**，不能直接赋值修改，仅用于获取当前动画原始进度
    - 返回值：`number`，`0`（动画主体开始）~ `1`（动画主体结束）

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      repeat: 2,
      delay: 1
    });

    // 实时获取 ratio
    gsap.ticker.add(() => {
      console.log("ratio:", tween.ratio);
    });
    ```

> 
> delay阶段：ratio 保持 0；动画主体播放：0→1；单次动画结束后 ratio=1；repeat 不会重置 ratio，需要手动处理。

3. 和 progress() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1,
      timeScale: 0.5
    });

    gsap.ticker.add(() => {
      console.log("progress", tween.progress());
      console.log("ratio", tween.ratio);
    });
    ```

    - `progress()`：包含 delay、repeat、timeScale，整体播放进度
    - `.ratio`：仅当前单次动画本体进度，不受 delay / repeat / timeScale 干扰

4. 高频使用场景：动画进度驱动自定义逻辑

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
    });

    gsap.ticker.add(() => {
      // 使用 ratio 驱动自定义属性，不受repeat/timeScale干扰
      const val = gsap.utils.mapRange(0,1,0,200, tween.ratio);
      console.log(val);
    });
    ```

5. 常用特点
    
    1. **只读属性**，不可写入修改，只能读取。
    2. 只计算动画主体时长，**忽略 delay、repeat、yoyo、timeScale**。
    3. 取值区间固定 `0~1`，动画主体还没开始=0，主体播放完成=1。
    4. yoyo 往复动画，ratio 依旧是 0→1单向增长，不会自动回退 1→0。
    5. 适合做基于单次动画本体进度的自定义计算、着色、波形映射。

- 代码示例

### 3.1.3 .scrollTrigger 滚动触发器

`Tween.scrollTrigger` 是 GSAP ScrollTrigger 插件挂载在 Tween 实例上的引用对象，代表**绑定到此补间动画的滚动触发器实例**，用于读取/控制当前滚动触发相关信息。

> 
> 区分：`ScrollTrigger.create()` 创建独立触发器；`gsap.to(target, { scrollTrigger: {} })` 会自动把触发器挂载到生成的 tween 实例上，通过 `tween.scrollTrigger` 获取。

#### 1. 使用方式

1. 语法

    ```js
    const st = tween.scrollTrigger;
    ```

    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象，配置项包含 `scrollTrigger`）
    - 读属性：**只读引用**，不能直接赋值替换触发器实例，仅用于获取触发器、调用触发器方法
    - 返回值：`ScrollTrigger | undefined`，有绑定滚动触发器则返回实例，无绑定为 `undefined`

2. 基础示例

    ```js
    // 创建带 scrollTrigger 的滚动动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      scrollTrigger: {
        trigger: ".box",
        start: "top 80%",
        end: "top 20%",
        scrub: true
      }
    });
    // 获取绑定的 ScrollTrigger 实例
    const st = tween.scrollTrigger;
    // 读取滚动进度
    gsap.ticker.add(() => {
      console.log("scroll progress:", st.progress);
    });
    ```

    > 
    > 未配置 `scrollTrigger` 的普通 tween，`tween.scrollTrigger` 为 `undefined`；动画销毁 `tween.kill()` 后，触发器也会同步销毁。

3. 常用属性 & 方法（tween.scrollTrigger）

    ```js
    const st = tween.scrollTrigger;

    // 属性
    st.progress       // 滚动触发器进度 0~1（scrub 模式下和动画进度联动）
    st.start          // 触发器开始位置（像素值）
    st.end            // 触发器结束位置（像素值）
    st.scroll         // 当前滚动位置
    st.isActive       // 是否处于激活区间内 true/false

    // 方法
    st.refresh()      // 重新计算触发器位置（DOM变化、resize时调用）
    st.kill()         // 销毁该滚动触发器
    st.getVelocity()  // 获取滚动速度
    ```

5. 和独立 ScrollTrigger.create() 对比示例

    ```js
    // 方式1：tween内声明，自动挂载到 tween.scrollTrigger
    const tweenA = gsap.to(".box-a", {
      x: 300,
      duration: 1,
      scrollTrigger: { trigger: ".box-a", scrub: true }
    });

    // 方式2：独立创建 ScrollTrigger，不会自动挂载到 tween
    const tweenB = gsap.to(".box-b", { x:300, duration:1 });
    const stB = ScrollTrigger.create({
      trigger: ".box-b",
      start: "top 80%",
      animation: tweenB,
      scrub: true
    });
    // tweenB.scrollTrigger === undefined，需要手动持有 stB 引用

    gsap.ticker.add(() => {
      console.log("tweenA st progress", tweenA.scrollTrigger.progress);
      // console.log(tweenB.scrollTrigger); // undefined
    });
    ```

    - 内联写法：`scrollTrigger` 写在 tween 参数里 → 实例自动挂载到 `tween.scrollTrigger`
    - 独立创建：`ScrollTrigger.create({animation: tween})` → tween 不会自动拥有 `.scrollTrigger` 属性，需要自己保存触发器变量

6. 高频使用场景：滚动进度驱动自定义逻辑

    ```js
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      scrollTrigger: {
        trigger: ".box",
        start: "top 80%",
        end: "top 20%",
        scrub: true
      }
    });
    gsap.ticker.add(() => {
      const st = tween.scrollTrigger;
      if (!st) return;
      // 使用滚动触发器进度做额外映射
      const val = gsap.utils.mapRange(0,1,0,180, st.progress);
      console.log("rotate deg:", val);
    });
    ```

7. 常用特点

    1. **实例引用只读**，不能 `tween.scrollTrigger = xxx` 覆盖，只能读取和调用实例方法。
    2. 仅当创建 tween 时传入 `scrollTrigger` 配置项才会存在，普通时间轴动画无此属性。
    3. `tween.kill()` 会连带销毁绑定的 ScrollTrigger，避免内存泄漏。
    4. `scrub:true` 时，`tween.scrollTrigger.progress` 和 `tween.progress()` 保持同步；非 scrub（pin / toggleActions）模式下两者不一定相等。
    5. 窗口 resize、DOM 布局变动时，调用 `tween.scrollTrigger.refresh()` 重新计算锚点。

### 3.1.4 .vars 属性

`Tween.vars` 代表创建 Tween 时传入的**原始配置对象**，保存初始化该补间动画时所有参数，包括目标属性、duration、scrollTrigger、ease、onUpdate 等。

> 
> 区分：`tween.targets()` 获取动画目标DOM；`.vars` 是创建动画时传入的配置源对象。修改 `.vars` 不会自动实时更新正在运行的动画，仅作为原始配置的引用。

#### 1. 使用方式

1. 语法

    ```js
    const vars = tween.vars;
    ```

    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 读属性：**可读可写**，但修改后不会自动同步到当前正在播放的动画实例；仅作为原始配置对象
    - 返回值：`object`，创建动画传入的配置对象副本引用

2. 基础示例

    ```js
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      ease: "power2.out",
      scrollTrigger: { trigger: ".box", scrub: true }
    });
    // 获取原始配置
    console.log(tween.vars.duration);
    console.log(tween.vars.ease);
    console.log(tween.vars.scrollTrigger);
    ```

    > 
    > 注意：修改 `tween.vars.x = 500` 不会让正在运行的动画目标x变成500；vars只是保存创建时的配置，动画运行参数不会自动响应vars变更。

3. 和动态修改动画参数对比示例

    ```js
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      ease: "power2.out"
    });

    // 修改 vars，动画不会变化
    tween.vars.x = 600;

    // 想要更新动画目标值，需要使用 tween.updateTo()
    tween.updateTo({ x: 600 }, true);

    gsap.ticker.add(() => {
      console.log("原始配置x:", tween.vars.x);
    });
    ```

    - `.vars`：静态原始配置存储，只用于读取初始参数
    - `updateTo()`：动态修改正在运行的动画属性，实时生效

4. 高频使用场景：读取动画元信息、批量动画校验

    ```js
    const tweens = gsap.utils.toArray(".box").map((el, idx) => {
      return gsap.to(el, {
        y: idx * 100,
        duration: 1 + idx * 0.2
      });
    });

    // 遍历读取每个tween原始配置
    tweens.forEach(tween => {
      console.log("duration:", tween.vars.duration);
    });
    ```

5. 常用特点
    1. 可读可写，但**修改不会实时驱动动画**，仅修改配置存储对象。
    2. 包含所有创建时配置项：`duration`、`delay`、`ease`、`repeat`、`scrollTrigger`、`onUpdate`、`onComplete` 等。
    3. 不包含动态运行时状态（`progress`、`ratio`），仅保存初始化参数。
    4. 当使用 `tween.updateTo()` 更新动画，**不会同步更新 tween.vars**，vars依旧保留最开始创建动画的配置。
    5. 适合做动画列表信息读取、调试打印、批量读取动画初始参数。

## 3.2 方法

### 3.2.1 delay() 方法

`Tween.delay()` 是 Tween 实例方法，用于**读取或设置动画的延迟时间**。

> 
> 区分：`tween.vars.delay` 是创建动画时传入的原始延迟配置；`delay()` 方法可以动态读取和修改当前动画延迟，修改会实时生效。

#### 1. 使用方式

1. 语法

    ```js
    // 获取当前延迟
    const currentDelay = tween.delay();
    // 设置新延迟
    tween.delay(newDelayValue);
    ```

    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`newDelayValue`，可选，数字类型，单位秒
    - 返回值：不传参时返回当前延迟数值；传参时返回 tween 自身，支持链式调用

2. 基础示例

    ```js
    // 创建动画，初始 delay 为 1s
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    // 读取当前延迟
    console.log(tween.delay()); // 1

    // 修改延迟为 0.5s
    tween.delay(0.5);

    // 链式调用
    tween.delay(0.2).play();
    ```

    > 
    > 注意：**动画已经开始播放后，调用 delay() 修改延迟不会对当前正在执行的动画生效**；仅在动画未启动前修改延迟有效。

3. 和 tween.vars.delay 对比示例

    ```js
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    console.log(tween.vars.delay); // 原始配置：1
    console.log(tween.delay());    // 当前延迟：1

    // 通过方法修改延迟
    tween.delay(0.3);

    console.log(tween.vars.delay); // vars 仍然保留原始值 1
    console.log(tween.delay());    // 当前延迟更新为 0.3
    ```

    - `tween.vars.delay`：只读原始配置，修改不影响动画
    - `tween.delay(val)`：实例方法，修改运行时延迟（动画未播放时生效）

4. 高频使用场景：批量动态调整动画延迟

    ```js
    const targets = gsap.utils.toArray(".box-item");
    const tweens = targets.map((el, i) => {
      return gsap.to(el, {
        y: 100,
        duration: 1,
        delay: i * 0.2,
        paused: true
      });
    });

    // 批量重置所有动画延迟
    tweens.forEach((tween, idx) => {
      tween.delay(idx * 0.15);
    });
    ```

5. 常用特点
    1. 支持读写，无参调用获取延迟，传入数字设置延迟，支持链式调用。
    2. 修改延迟仅对**尚未开始播放**的动画生效；动画一旦开始，此修改无效。
    3. 修改 `delay()` **不会更新 tween.vars.delay**，vars 始终保留创建时的初始配置。
    4. 单位为秒，支持小数；不能传入负数。
    5. 适合批量预调整动画序列延迟，常用于入场动画编排。

### 3.2.2 duration() 方法

`Tween.duration()` 是 Tween 实例方法，用于**读取或设置动画主体时长**（不包含 delay）。
>
> 区分：`tween.vars.duration` 是创建动画时传入的原始时长配置；`duration()` 方法可以动态读取和修改动画主体时长，修改会实时生效。

1. 语法

    ```javascript
    // 获取当前动画主体时长
    const currentDur = tween.duration();
    // 设置新的主体时长
    tween.duration(newDurationValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`newDurationValue`，可选，数字类型，单位秒
    - 返回值：不传参时返回当前主体时长数值；传参时返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画，初始 duration 为 2s
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    // 读取当前主体时长
    console.log(tween.duration()); // 2

    // 修改主体时长为 4s
    tween.duration(4);

    // 链式调用
    tween.duration(1.5).play();
    ```
    >
    > 注意：修改 duration 会改变动画播放速度；动画播放过程中修改也会立即生效。该方法只作用于动画主体时长，不会影响 delay。

3. 和 tween.vars.duration 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    console.log(tween.vars.duration); // 原始配置：2
    console.log(tween.duration());    // 当前主体时长：2

    // 通过方法修改时长
    tween.duration(0.5);

    console.log(tween.vars.duration); // vars 仍然保留原始值 2
    console.log(tween.duration());    // 当前主体时长更新为 0.5
    ```
    - `tween.vars.duration`：原始配置，修改不影响动画运行
    - `tween.duration(val)`：实例方法，动态修改动画主体时长，实时生效

4. 高频使用场景：动态调速、根据交互调整动画快慢

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused: true
    });
    // 鼠标移入，动画放慢
    document.querySelector(".box").addEventListener("mouseenter", () => {
      tween.duration(4);
    });
    // 鼠标移出，动画恢复原速度
    document.querySelector(".box").addEventListener("mouseleave", () => {
      tween.duration(2);
    });
    tween.play();
    ```

5. 常用特点

    1. 支持读写，无参调用获取时长，传入数字设置时长，支持链式调用。
    2. 修改作用于动画主体时长，**不包含 delay**；播放中途修改也会立即生效。
    3. 修改 `duration()` **不会更新 tween.vars.duration**，vars 始终保留创建时的初始配置。
    4. 单位为秒，支持小数，不能传入负数。
    5. 调整时长会改变动画播放速率，不改变动画起止目标值。


### 3.2.3 progress() 方法

`Tween.progress()` 是 Tween 实例方法，用于**读取或设置动画整体播放进度**，取值范围 `0 ~ 1`，会包含 delay、repeat、timeScale 等影响。
>
> 区分：`tween.ratio` 只代表动画主体归一化进度，不受 delay / repeat / timeScale 影响；`progress()` 是包含所有附加时间的整体播放进度。


1. 语法

    ```javascript
    // 获取当前整体播放进度
    const currentProg = tween.progress();
    // 设置新的播放进度，跳转到对应位置
    tween.progress(newProgressValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`newProgressValue`，可选，数字类型，范围 `0 ~ 1`
    - 返回值：不传参时返回当前进度数值；传参时返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1
    });

    // 读取当前进度
    console.log(tween.progress());

    // 跳转到动画50%位置
    tween.progress(0.5);

    // 链式调用
    tween.progress(0.2).play();
    ```
    >
    > 注意：设置 progress 会直接跳转动画快照；进度是包含 delay、repeat 的整体时间线进度，和 `ratio` 的计算口径不一样。

3. 和 tween.ratio 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1
    });

    gsap.ticker.add(() => {
      console.log("progress:", tween.progress());
      console.log("ratio:", tween.ratio);
    });
    ```
    - `tween.progress()`：整体时间线进度，包含 delay、repeat、timeScale
    - `tween.ratio`：仅动画主体部分进度，忽略 delay、repeat、timeScale

4. 高频使用场景：滑块控制动画进度、手动拖拽预览动画

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused: true
    });

    // 滑块拖动控制动画进度
    const slider = document.querySelector("#slider");
    slider.addEventListener("input", () => {
      tween.progress(slider.value / 100);
    });
    ```

5. 常用特点

    1. 支持读写，无参读取进度，传入 `0~1` 数值可跳转动画快照，支持链式调用。
    2. 进度计算包含 delay、repeat、timeScale，和 `ratio` 边界行为不同。
    3. 调用 `progress(val)` 跳转时，不会触发 `onStart`，但会触发 `onUpdate`。
    4. 取值区间 `0 ~ 1`；超出范围会被自动钳位。
    5. 搭配 `paused:true` 非常适合做手动控制类动画，如滚动、滑块预览。

### 3.2.4 repeat() 方法

`Tween.repeat()` 是 Tween 实例方法，用于**读取或设置动画循环次数**，代表首次播放完成之后还要重复播放多少次。
>
> 区分：`tween.vars.repeat` 是创建动画时传入的原始循环配置；`repeat()` 方法可以动态读取和修改动画循环次数，修改实时生效。
> 注意：`repeat:1` = 播放1次本体 + 重复1次，总共播放2轮；`repeat:-1` 代表无限循环。

1. 语法

    ```javascript
    // 获取当前重复次数
    const currentRepeat = tween.repeat();
    // 设置新的重复次数
    tween.repeat(repeatCount);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`repeatCount`，可选，整数；`-1` 无限循环，`0` 不重复
    - 返回值：不传参时返回当前重复次数；传参时返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画，初始 repeat=2（一共播放3轮）
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      repeat: 2
    });

    // 读取当前重复次数
    console.log(tween.repeat()); // 2

    // 修改为无限循环
    tween.repeat(-1);

    // 链式调用，同时设置 repeat 和 yoyo
    tween.repeat(-1).yoyo(true).play();
    ```
    >
    > 注意：动态修改 repeat 会立刻生效；搭配 `yoyo:true` 可实现往复来回动画。

3. 和 tween.vars.repeat 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      repeat: 1
    });

    console.log(tween.vars.repeat); // 原始配置：1
    console.log(tween.repeat());    // 当前重复次数：1

    // 通过方法修改重复次数
    tween.repeat(3);

    console.log(tween.vars.repeat); // vars 仍然保留原始值 1
    console.log(tween.repeat());    // 当前重复次数更新为 3
    ```
    - `tween.vars.repeat`：原始配置，修改不影响动画运行
    - `tween.repeat(val)`：实例方法，动态修改动画循环次数，实时生效

4. 高频使用场景：运行时开关无限循环、动态控制循环次数

    ```javascript
    const tween = gsap.to(".box", {
      y: 100,
      duration: 1,
      repeat: -1,
      yoyo:true,
      paused:true
    });
    // 按钮停止循环，播放完当前一轮后结束
    document.querySelector("#stopBtn").onclick = ()=>{
      tween.repeat(0);
    }
    tween.play();
    ```

5. 常用特点

    1. 支持读写，无参读取重复次数，传入整数设置，支持链式调用。
    2. 数值含义：`0` 不重复；`1` 额外重复1次，总共2轮；`-1` 无限循环。
    3. 修改 `repeat()` **不会更新 tween.vars.repeat**，vars 始终保留创建时的初始配置。
    4. 动画播放过程中修改立即生效，可随时终止无限循环。
    5. 常配合 `yoyo()`、`repeatDelay()` 一起控制往复动画与循环间隔。

### 3.2.5 repeatDelay() 方法

`Tween.repeatDelay()` 是 Tween 实例方法，用于**读取或设置每次循环之间的间隔时长**，即单次动画播放结束后，到下一轮循环开始前的等待时间。
>
> 区分：`tween.vars.repeatDelay` 是创建动画时传入的原始循环间隔配置；`repeatDelay()` 方法可以动态读取和修改循环间隔，修改实时生效。
> 注意：repeatDelay 仅作用于**循环与循环之间**，首轮动画前的延迟由 `delay()` 控制，不受 repeatDelay 影响。


1. 语法

    ```javascript
    // 获取当前循环间隔
    const currentRepeatDelay = tween.repeatDelay();
    // 设置新的循环间隔
    tween.repeatDelay(delayValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`delayValue`，可选，数字类型，单位秒
    - 返回值：不传参时返回当前循环间隔数值；传参时返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画，初始 repeatDelay=0.5s
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      repeat: 2,
      repeatDelay: 0.5
    });

    // 读取当前循环间隔
    console.log(tween.repeatDelay()); // 0.5

    // 修改循环间隔为 1s
    tween.repeatDelay(1);

    // 链式调用
    tween.repeatDelay(0.2).repeat(-1).play();
    ```
    >
    > 注意：修改 repeatDelay 在动画运行时立即生效；只影响两轮动画之间的等待间隙，不改变首轮动画的前置 delay。

3. 和 tween.vars.repeatDelay 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      repeat: 2,
      repeatDelay: 0.5
    });

    console.log(tween.vars.repeatDelay); // 原始配置：0.5
    console.log(tween.repeatDelay());    // 当前循环间隔：0.5

    // 通过方法修改循环间隔
    tween.repeatDelay(1.2);

    console.log(tween.vars.repeatDelay); // vars 仍然保留原始值 0.5
    console.log(tween.repeatDelay());    // 当前循环间隔更新为 1.2
    ```
    - `tween.vars.repeatDelay`：原始配置，修改不影响动画运行
    - `tween.repeatDelay(val)`：实例方法，动态修改循环间隔，实时生效

4. 高频使用场景：动态调整循环动画的停顿间隔

    ```javascript
    const tween = gsap.to(".box", {
      y: 100,
      duration: 1,
      repeat: -1,
      yoyo:true,
      repeatDelay: 0.3,
      paused:true
    });
    // 鼠标移入，拉长循环停顿
    document.querySelector(".box").addEventListener("mouseenter", () => {
      tween.repeatDelay(1);
    });
    // 鼠标移出，恢复原有间隔
    document.querySelector(".box").addEventListener("mouseleave", () => {
      tween.repeatDelay(0.3);
    });
    tween.play();
    ```

5. 常用特点
    1. 支持读写，无参读取循环间隔，传入数字设置，支持链式调用。
    2. 仅作用于**两次循环动画中间**，首轮动画前置延迟由 `delay()` 管理。
    3. 修改 `repeatDelay()` **不会更新 tween.vars.repeatDelay**，vars 始终保留创建时的初始配置。
    4. 单位为秒，支持小数，不能传入负数。
    5. 一般配合 `repeat()`、`yoyo()` 使用，用于控制往复动画之间的暂停。



### 3.2.6 restart() 方法

`Tween.restart()` 是 Tween 实例方法，用于**重新从头启动动画**，回到动画起始位置并开始播放。
>
> 区分：`play()` 是从当前暂停位置继续播放；`restart()` 会重置到动画起点再播放。

1. 语法

    ```javascript
    // 从头重启动画（默认参数）
    tween.restart();
    // 可选参数：(immediateFlush, skipDelay)
    tween.restart(immediateFlush, skipDelay);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数
        - `immediateFlush`：布尔，可选。默认`true`；`true`立即应用起始状态，`false`在下一帧才渲染起点。
        - `skipDelay`：布尔，可选。默认`false`；`true`跳过delay，直接播放动画主体；`false`保留原delay等待。
    - 返回值：返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1
    });

    // 重启，保留delay
    tween.restart();

    // 重启并跳过delay，直接开始动画主体
    tween.restart(true, true);

    // 链式调用
    tween.restart(true, true).timeScale(1);
    ```
    >
    > 注意：restart 会重置 `progress`、循环计数；但**不会重置动态修改过的 duration / repeat / timeScale**。

3. 和 play() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused:true
    });
    tween.progress(0.6); // 跳转到60%位置

    tween.play();     // 从 0.6 的位置继续播放
    tween.restart();  // 回到 0，从头播放
    ```
    - `tween.play()`：从当前进度位置继续播放
    - `tween.restart()`：重置进度到起点，从头开始播放

4. 高频使用场景：点击按钮重复播放入场动画

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.2,
      duration:0.6,
      paused:true
    });
    // 点击元素，从头播放动画
    document.querySelector(".box").addEventListener("click", () => {
      tween.restart(true, true);
    });
    ```

5. 常用特点

    1. 无返回读取逻辑，仅执行动作，返回tween实例支持链式调用。
    2. 默认会遵守delay；传入第二个参数`true`可以跳过前置延迟直接启动。
    3. 会重置动画进度、循环计数，但**不会复原已经动态修改的参数**（duration、repeat、timeScale等保持修改后的值）。
    4. 会触发`onStart`、`onUpdate`等生命周期回调。
    5. 适合交互触发的重复入场、点击反馈动画。


### 3.2.7 resume() 方法

`Tween.resume()` 是 Tween 实例方法，用于**恢复已暂停的动画继续播放**，从当前暂停的进度位置继续。
>
> 区分：`play()` 会先把动画设置为正向播放（如果是反向播放状态会重置方向）；`resume()` 只解除暂停，**保留原有播放方向不变**。


1. 语法

    ```javascript
    tween.resume();
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：无
    - 返回值：返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建暂停状态动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused: true
    });

    // 暂停动画
    tween.pause();
    // 恢复播放，从当前位置继续，保留播放方向
    tween.resume();

    // 链式调用
    tween.resume().timeScale(1);
    ```
    >
    > 注意：resume 仅解除暂停状态；如果动画本身已经播放完毕，调用 resume 不会重新启动动画。

3. 和 play() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused:true
    });
    tween.reverse(); // 设置为反向播放
    tween.pause();

    tween.play();    // 切换为正向播放，继续播放
    tween.resume();  // 维持反向播放方向，继续播放
    ```
    - `tween.play()`：设置正向播放，然后继续
    - `tween.resume()`：仅取消暂停，保持当前播放方向（正向/反向）不变

4. 高频使用场景：暂停/恢复切换动画，保留播放方向

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused:true
    });
    // 点击切换暂停/恢复
    document.querySelector("#toggleBtn").addEventListener("click", () => {
      if(tween.paused()){
        tween.resume();
      }else{
        tween.pause();
      }
    });
    ```

5. 常用特点
    1. 无参数，执行后返回tween实例，支持链式调用。
    2. 仅解除暂停，**不会改变播放方向**，这点是和play()最核心区别。
    3. 如果动画已经自然播放结束，resume不会生效，不会自动重启。
    4. 不会重置 progress、循环计数，继续从暂停那一刻的进度继续。
    5. 适合需要保留播放方向的暂停恢复交互，例如视频式动画播放器。



### 3.2.8 reverse() 方法

`Tween.reverse()` 是 Tween 实例方法，用于**反向播放动画**，从当前播放位置向起点方向回放。
>
> 区分：`tween.play()` 正向播放；`tween.reverse()` 把播放方向切为反向并开始播放。


1. 语法

    ```javascript
    // 反向播放（默认参数）
    tween.reverse();
    // 可选参数：(immediateFlush, skipDelay)
    tween.reverse(immediateFlush, skipDelay);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数
        - `immediateFlush`：布尔，可选。默认`true`；`true`立即应用状态，`false`下一帧渲染。
        - `skipDelay`：布尔，可选。默认`false`；`true`跳过延迟，直接开始反向播放。
    - 返回值：返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused: true
    });

    // 反向播放
    tween.reverse();

    // 反向播放并跳过延迟
    tween.reverse(true, true);

    // 链式调用
    tween.reverse(true, true).timeScale(1);
    ```
    >
    > 注意：reverse 会沿用当前动画进度，从当前位置往起点回放；若动画已经在起点，调用 reverse 不会有效果。

3. 和 play() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused:true
    });
    tween.progress(0.7); // 定位到70%位置

    tween.play();    // 从70%继续正向，向终点1推进
    tween.reverse(); // 从70%反向，向起点0回退
    ```
    - `tween.play()`：正向播放，进度从当前向1推进
    - `tween.reverse()`：反向播放，进度从当前向0回退

4. 高频使用场景：鼠标移入正向、鼠标移出反向做入场退场

    ```javascript
    const tween = gsap.to(".box", {
      scale: 1.2,
      duration: 0.4,
      paused:true
    });
    const boxEl = document.querySelector(".box");
    boxEl.addEventListener("mouseenter", () => tween.play());
    boxEl.addEventListener("mouseleave", () => tween.reverse());
    ```

5. 常用特点
    1. 返回tween实例，支持链式调用。
    2. 不重置进度，在当前进度基础上切换为反向播放。
    3. 搭配 `yoyo` 循环动画时，每次循环自动切换正反方向，无需手动调用reverse。
    4. 若动画已经处于起点（progress=0），调用 reverse 不会播放。
    5. 可配合 `pause()` / `resume()` 控制，常用于hover、弹窗的出场退场动画。



### 3.2.9 reversed() 方法

`Tween.reversed()` 是 Tween 实例方法，用于**读取或设置动画的反向状态标记**。
>
> 区分：`reverse()` 是**执行反向播放动作**；`reversed()` 仅读写「是否反向」这个状态标识，不会自动开始播放。


1. 语法

    ```javascript
    // 获取当前反向状态
    const isReversed = tween.reversed();
    // 设置反向状态
    tween.reversed(isReverse);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`isReverse`，可选，布尔值。`true`标记为反向；`false`标记为正向
    - 返回值：不传参返回当前布尔状态；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused: true
    });

    // 读取反向标记
    console.log(tween.reversed()); // false，默认正向

    // 设置为反向状态
    tween.reversed(true);

    // 链式调用：标记反向，然后播放
    tween.reversed(true).play();
    ```
    >
    > 注意：`reversed(true)` 只是修改方向标记，**不会自动播放**，需要调用 `.play()` 才会开始执行。

3. 和 reverse() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      paused:true
    });

    tween.reverse();
    // reverse() = 设置reversed=true + 启动播放

    tween.reversed(true);
    // reversed(true) = 仅设置标记，动画保持暂停，不会自动播放
    ```
    - `tween.reverse()`：设置反向标记并开始反向播放
    - `tween.reversed(true)`：仅修改方向标记，动画状态不变，需要手动 play()

4. 高频使用场景：预先切换播放方向，后续统一触发播放

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.3,
      duration:0.5,
      paused:true
    });
    const boxEl = document.querySelector(".box");

    boxEl.addEventListener("mouseenter", () => {
      tween.reversed(false).play();
    });
    boxEl.addEventListener("mouseleave", () => {
      tween.reversed(true).play();
    });
    ```

5. 常用特点
    1. 支持读写，无参读取布尔状态，传入布尔值设置方向标记，支持链式调用。
    2. 仅修改方向标识，**不会自动播放或跳转进度**，动画暂停状态保持不变。
    3. `reversed(true)` 后调用 `play()`，动画会从当前进度向起点回放。
    4. 和 `yoyo` 独立：yoyo 是循环自动切换方向；reversed 是手动控制方向标记。
    5. 适合提前预设动画方向，在统一触发播放的交互场景。


### 3.2.10 revert() 方法

`Tween.revert()` 是 Tween 实例方法，用于**将目标元素恢复到动画执行前的原始状态，同时销毁当前动画实例**，会移除GSAP自动添加的行内样式。
>
> 区分：`progress(0)` 只是把动画播放头置到起点，**保留行内样式**，动画实例仍然存活；`revert()` 还原原始状态并 kill 动画，移除GSAP新增的行内样式。


1. 语法

    ```javascript
    tween.revert();
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：无
    - 返回值：返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });

    // 还原元素初始状态，销毁动画
    tween.revert();
    ```
    >
    > 注意：执行 `revert()` 之后，该tween实例已经被kill，**不能再调用 play/restart 等方法**；如需再次播放，必须重新创建tween。

3. 和 progress(0) 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });

    tween.progress(0);
    // progress(0)：回到起点，元素保留GSAP添加的行内样式，动画实例存活，可继续播放

    tween.revert();
    // revert()：移除GSAP添加的行内样式，还原动画之前的状态，动画实例被销毁，不可复用
    ```
    - `tween.progress(0)`：仅重置播放头，保留行内样式，实例保留可继续使用
    - `tween.revert()`：还原原始样式，移除行内样式，kill动画实例，实例不可复用

4. 高频使用场景：组件销毁、页面卸载时清理动画，防止残留行内样式

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.2,
      duration:0.6
    });
    // 组件卸载/页面销毁时清理动画
    function destroy(){
      tween.revert();
    }
    ```

5. 常用特点
    1. 无参数，执行后返回tween实例，支持链式调用。
    2. 会记录动画执行前元素原始行内样式，执行后移除GSAP新增的行内样式。
    3. 内部会自动执行kill，动画实例销毁，**无法再次播放**。
    4. 支持ScrollTrigger绑定的tween，revert时会同步清理触发器。
    5. 适合SPA组件生命周期卸载、窗口resize重建动画、动态DOM销毁场景，避免样式残留。


### 3.2.11 seek() 方法

`Tween.seek()` 是 Tween 实例方法，用于**跳转到动画指定时间点**（单位秒），直接定位播放头，不改变播放/暂停状态。
>
> 区分：`progress()` 是按 0~1 归一化进度跳转；`seek()` 是按**原始时间（秒）**跳转。


1. 语法

    ```javascript
    // 跳转到指定时间（秒）
    tween.seek(time);
    // 可选第二个参数：immediateFlush
    tween.seek(time, immediateFlush);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数
        - `time`：数字，目标时间点，单位秒；可传入相对字符串 `"+=1"` / `"-=0.5"`
        - `immediateFlush`：布尔，可选，默认`true`；`true`立即渲染目标状态，`false`下一帧更新
    - 返回值：返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画，duration 2s，delay 1s
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    // 跳转到总时间轴 1.5s 的位置
    tween.seek(1.5);

    // 相对时间：在当前时间基础上 +0.3s
    tween.seek("+=0.3");

    // 链式调用
    tween.seek(0.8).pause();
    ```
    >
    > 注意：`seek()` 的时间是**包含 delay 的整体时间轴**，不是单纯动画主体时间。

3. 和 progress() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    tween.progress(0.5);
    // progress(0.5) → 归一化50%，总时间轴中点

    tween.seek(2);
    // seek(2) → 直接定位到时间轴第2秒
    ```
    - `tween.seek(time)`：基于**绝对/相对时间（秒）**跳转，包含delay
    - `tween.progress(val)`：基于**0~1归一化比例**跳转

4. 高频使用场景：时间轴播放器、按时间点快速预览动画片段

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 3,
      paused:true
    });
    // 点击按钮直接跳至1.2秒位置
    document.querySelector("#jumpBtn").addEventListener("click", () => {
      tween.seek(1.2);
    });
    ```

5. 常用特点
    1. 支持绝对数字时间，也支持 `"+=n"` / `"-=n"` 相对时间字符串，返回实例支持链式调用。
    2. 时间计算包含 delay，不是仅动画主体时长。
    3. 跳转不会改变当前播放状态：正在播放则继续播放；暂停则保持暂停。
    4. 跳转时会触发 `onUpdate`，不会触发 `onStart`。
    5. 适合做自定义时间轴控制器、预览指定时间点动画。

### 3.2.12 startTime() 方法

`Tween.startTime()` 是 Tween 实例方法，用于**读取或设置动画在父时间轴上的起始时间**（单位秒）。
>
> 区分：`delay()` 是动画自身前置延迟；`startTime()` 代表该tween挂载在Timeline父容器里，**相对于父时间轴起点的开始时间**。独立Tween默认没有父时间轴。


1. 语法

    ```javascript
    // 获取当前起始时间
    const st = tween.startTime();
    // 设置新的起始时间
    tween.startTime(timeValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`timeValue`，可选，数字类型，单位秒
    - 返回值：不传参返回当前起始时间数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 独立tween
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });
    console.log(tween.startTime()); // 0

    // 放入Timeline后，修改startTime
    const tl = gsap.timeline();
    const tween = gsap.to(".box", { x:300, duration:2 });
    tl.add(tween);
    tween.startTime(1); // 在父时间轴第1秒位置开始执行
    ```
    >
    > 注意：独立创建的Tween（不在Timeline中）startTime默认为0；只有添加到Timeline时间轴时，修改startTime才有意义。

3. 和 delay() 对比示例

    ```javascript
    const tl = gsap.timeline();
    const tween = gsap.to(".box", { x:300, duration:2, delay:0.5 });
    tl.add(tween);

    console.log(tween.delay());     // 0.5，动画自身前置延迟
    console.log(tween.startTime()); // 0，在父时间轴0秒位置放入
    ```
    - `tween.startTime()`：控制**在父时间轴上何时开始**
    - `tween.delay()`：动画自身内部的等待延迟，在startTime之后再等待delay才启动动画主体

4. 高频使用场景：动态调整Timeline内部子动画的排布时序

    ```javascript
    const tl = gsap.timeline();
    const tweenA = gsap.to(".box-a", { x: 200, duration: 1 });
    const tweenB = gsap.to(".box-b", { x: 200, duration: 1 });
    tl.add(tweenA).add(tweenB);

    // 把tweenB挪到父时间轴0.3s位置，和tweenA部分重叠
    tweenB.startTime(0.3);
    ```

5. 常用特点
    1. 支持读写，无参读取起始时间，传入数字设置，支持链式调用。
    2. 只对挂载在Timeline中的tween生效；独立Tween修改该值无实际播放效果。
    3. 修改 `startTime()` **不会更新 tween.vars 原始配置**。
    4. 单位秒，支持小数，可设置为负数（在父时间轴0点之前就开始）。
    5. 多用于时间轴内动态重排子动画的先后与重叠关系。


### 3.2.13 targets() 方法

`Tween.targets()` 是 Tween 实例方法，用于**获取当前动画绑定的目标元素/对象数组**。
>
> 区分：`tween.vars` 保存动画配置；`targets()` 返回动画正在驱动的目标对象集合。


1. 语法

    ```javascript
    // 获取动画目标数组
    const targetList = tween.targets();
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：无
    - 返回值：返回包含所有目标对象的数组

2. 基础示例

    ```javascript
    // 单个DOM目标
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });
    console.log(tween.targets()); // [DOMElement]

    // 多个目标
    const tweenMulti = gsap.to([".box1", ".box2"], {
      y: 100,
      duration: 1
    });
    console.log(tweenMulti.targets()); // [box1, box2]
    ```
    >
    > 注意：返回的是**原始目标引用**，不是克隆；可以直接读取、操作数组内元素。

3. 和 tween.vars 对比示例

    ```javascript
    const tween = gsap.to(".box", { x:300, duration:2 });

    console.log(tween.vars); // 动画配置对象
    console.log(tween.targets()); // [DOM元素]
    ```
    - `tween.vars`：动画初始化配置参数
    - `tween.targets()`：被动画驱动的目标对象数组

4. 高频使用场景：遍历动画目标，批量附加额外逻辑

    ```javascript
    const tween = gsap.to(".box-item", {
      scale:1.2,
      duration:0.5
    });
    // 获取所有目标元素，添加class
    tween.targets().forEach(el => {
      el.classList.add("animate-active");
    });
    ```

5. 常用特点
    1. 只读方法，无参数，返回目标数组，**不支持链式调用**。
    2. 数组内是目标对象的真实引用，DOM目标即为DOM元素。
    3. 支持多目标动画，会把全部目标放入数组返回。
    4. 不会过滤已从DOM移除的元素，若DOM被删除，数组内依然保留旧引用。
    5. 适合调试查看动画绑定对象、批量对动画目标执行额外DOM操作。

### 3.2.14 then() 方法

`Tween.then()` 是 Tween 实例方法，返回 Promise，用于**在动画完成后执行回调**，支持异步链式写法。
>
> 区分：`onComplete` 是动画回调函数配置；`then()` 基于 Promise，支持 `async/await`、链式异步调用。


1. 语法

    ```javascript
    tween.then(onResolve, onReject);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数
        - `onResolve`：可选，动画正常完成时执行的回调
        - `onReject`：可选，动画被kill终止时执行的回调
    - 返回值：返回一个新 Promise 对象，支持链式 `.then().catch()`

2. 基础示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });

    tween.then(() => {
      console.log("动画正常播放完成");
    });

    // 链式 then
    tween.then(() => console.log("完成1"))
         .then(() => console.log("完成2"));
    ```
    >
    > 注意：如果动画被 `kill()` / `revert()` 提前终止，Promise 会进入 reject 状态；无限循环 `repeat:-1` 的动画永远不会 resolve。

3. 和 onComplete 对比示例

    ```javascript
    // onComplete 回调写法
    const tween = gsap.to(".box", {
      x:300,
      duration:2,
      onComplete: () => console.log("onComplete 触发")
    });

    // then Promise写法
    tween.then(() => console.log("then resolve"));
    ```
    - `onComplete`：GSAP原生回调，写在vars配置内，同步回调
    - `then()`：Promise封装，支持async await、捕获kill终止异常

4. 高频使用场景：async await 串行编排动画

    ```javascript
    async function runAnimate() {
      const tween = gsap.to(".box", { x: 300, duration: 1 });
      await tween;
      console.log("动画结束，执行后续逻辑");
    }
    runAnimate();
    ```

5. 常用特点
    1. 接收 resolve / reject 回调，返回Promise，**不返回tween实例，不能链式调用GSAP动画方法**。
    2. 动画正常结束触发 resolve；动画被kill/revert会触发 reject。
    3. `repeat:-1` 无限循环动画不会resolve，`then`回调永远不执行。
    4. 暂停、seek、reverse不会触发Promise状态变更，只有动画结束或被kill才会改变。
    5. 适合异步串行动画编排，配合async/await替代多层onComplete嵌套。



### 3.2.15 time() 方法

`Tween.time()` 是 Tween 实例方法，用于**读取或设置动画当前时间轴位置**（单位秒），代表动画自身时间（不含父Timeline偏移，包含delay）。
>
> 区分：`seek()` 是跳转时间点的动作方法；`time()` 可读可写获取/设置当前动画时间；`duration()` 是动画主体时长。


1. 语法

    ```javascript
    // 获取当前动画时间
    const currentTime = tween.time();
    // 设置动画当前时间
    tween.time(timeValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`timeValue`，可选，数字类型，单位秒
    - 返回值：不传参返回当前时间数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    // 读取当前时间
    console.log(tween.time());

    // 设置当前时间到1.5秒
    tween.time(1.5);

    // 链式调用
    tween.time(0.8).pause();
    ```
    >
    > 注意：`time()` 包含delay，代表这个tween内部的总时间；和 `seek()` 行为非常接近，但`seek()`额外支持`"+=n"`/`"-=n"`相对时间字符串。

3. 和 seek() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1
    });

    tween.time(1.2); // 仅支持数字，设置动画当前时间
    tween.seek("+=0.3"); // 支持数字、相对时间字符串
    ```
    - `tween.time(val)`：仅接收数字，读写当前时间，返回tween实例
    - `tween.seek(val)`：支持数字/相对时间字符串，跳转播放头，支持第二个immediateFlush参数

4. 高频使用场景：读取动画当前时间，自定义时间控制器

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 3,
      paused:true
    });
    gsap.ticker.add(() => {
      console.log("当前动画时间：", tween.time());
    });
    ```

5. 常用特点
    1. 支持读写，无参读取当前时间，传入数字设置，支持链式调用。
    2. 时间包含delay，单位秒，只接受数字，不支持`+=`相对字符串。
    3. 设置time不会修改播放状态，暂停则保持暂停，播放则继续播放。
    4. 修改time会触发`onUpdate`，不会触发`onStart`。
    5. 多用于实时读取动画时间、自定义进度条，和seek功能重叠但入参限制不同。


### 3.2.16 timeScale() 方法

`Tween.timeScale()` 是 Tween 实例方法，用于**读取或设置动画的时间缩放倍率**，用来整体加速或减速动画。
>
> 区分：`duration()` 修改动画总时长；`timeScale()` 修改播放速率，倍率越大播放越快。


1. 语法

    ```javascript
    // 获取当前时间缩放倍率
    const scale = tween.timeScale();
    // 设置时间缩放倍率
    tween.timeScale(scaleValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`scaleValue`，可选，数字类型；`1` = 正常速度，小于1放慢，大于1加速
    - 返回值：不传参返回当前倍率数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });

    // 读取当前倍率
    console.log(tween.timeScale()); // 1

    // 2倍速播放
    tween.timeScale(2);

    // 0.5倍速，放慢一半
    tween.timeScale(0.5);

    // 链式调用
    tween.timeScale(1.5).play();
    ```
    >
    > 注意：timeScale 会同时作用于 delay、动画主体、repeatDelay；倍率为0等价于暂停动画。

3. 和 duration() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2
    });

    tween.duration(4);
    // 修改duration：目标总时长变成4s，以正常速度播放

    tween.timeScale(0.5);
    // 修改timeScale：时长不变，播放速度减半，实际耗时翻倍
    ```
    - `tween.duration()`：修改动画本体的目标时长
    - `tween.timeScale()`：修改播放速率，不改变原始duration

4. 高频使用场景：动态调速、根据交互改变动画快慢

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.2,
      duration:0.6,
      paused:true
    });
    // 鼠标移入加速
    document.querySelector(".box").addEventListener("mouseenter", () => {
      tween.timeScale(2);
    });
    // 鼠标移出恢复正常速度
    document.querySelector(".box").addEventListener("mouseleave", () => {
      tween.timeScale(1);
    });
    tween.play();
    ```

5. 常用特点
    1. 支持读写，无参读取倍率，传入数字设置倍率，支持链式调用。
    2. 影响全部时间相关部分：delay、主体动画、repeatDelay。
    3. 修改 `timeScale()` **不会更新 tween.vars.duration**，vars 保留原始配置。
    4. 数值不能为负数；若想要反向播放，使用 `reverse()` / `reversed()`。
    5. 适合游戏、交互动画做动态变速，也可用于全局控制一组动画播放快慢。


### 3.2.17 totalDuration() 方法

`Tween.totalDuration()` 是 Tween 实例方法，用于**读取或设置动画完整总时长**，包含 delay、所有循环、repeatDelay，是从头到尾完整跑完所有循环需要的总时间。
>
> 区分：`duration()` 仅动画主体单次时长；`totalDuration()` 包含前置delay、全部循环次数与循环间隔的完整总时间。


1. 语法

    ```javascript
    // 获取完整总时长
    const totalDur = tween.totalDuration();
    // 设置完整总时长
    tween.totalDuration(totalTimeValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`totalTimeValue`，可选，数字类型，单位秒
    - 返回值：不传参返回当前总时长数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 单次主体2s，delay1s，repeat=1，repeatDelay=0.5
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1,
      repeatDelay: 0.5
    });

    console.log(tween.duration());        // 2（单次主体时长）
    console.log(tween.totalDuration());   // 1 + 2 + 0.5 + 2 = 5.5

    // 设置总完整时长为4秒，GSAP自动缩放内部时间参数
    tween.totalDuration(4);
    ```
    >
    > 注意：调用 `totalDuration(val)` 设置总时长时，GSAP会自动缩放内部所有时间（duration、delay、repeatDelay），保持原有时间比例不变；无限循环 `repeat:-1` 时，`totalDuration()` 返回 `Infinity`。

3. 和 duration() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat:2,
      repeatDelay:0.3
    });

    tween.duration(1);
    // 仅修改单次动画主体时长，delay、repeatDelay不变

    tween.totalDuration(6);
    // 整体缩放全部时间，delay / duration / repeatDelay 同步按比例变化
    ```
    - `tween.duration()`：只修改单次动画主体时长
    - `tween.totalDuration()`：修改整套动画（含delay、循环、循环间隔）的总耗时，整体等比缩放

4. 高频使用场景：统一约束整套动画总耗时，固定总播放时长

    ```javascript
    const tween = gsap.to(".box", {
      y:100,
      duration:1,
      delay:0.2,
      repeat:2,
      repeatDelay:0.2,
      paused:true
    });
    // 强制整套动画完整跑完总时长固定为3秒
    tween.totalDuration(3);
    tween.play();
    ```

5. 常用特点
    1. 支持读写，无参读取总时长，传入数字设置，支持链式调用。
    2. 计算范围包含 delay、所有循环、repeatDelay；无限循环返回 `Infinity`。
    3. 设置totalDuration会等比缩放内部所有时间参数，维持原有时间比例。
    4. 修改 `totalDuration()` **不会更新 tween.vars 原始配置**。
    5. 适合要求整套动画（含循环）必须在固定总时间内完成的场景。


### 3.1.18 totalProgress() 方法

`Tween.totalProgress()` 是 Tween 实例方法，用于**读取或设置包含全部循环的完整动画归一化进度**，取值范围 `0 ~ 1`。
>
> 区分：`progress()` 是单次动画本体的进度；`totalProgress()` 把**所有循环、delay、repeatDelay**全部纳入计算，代表整套动画的全局进度。


1. 语法

    ```javascript
    // 获取整套动画全局进度
    const totalProg = tween.totalProgress();
    // 设置整套动画全局进度，跳转播放头
    tween.totalProgress(value);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`value`，可选，数字类型，范围 `0 ~ 1`
    - 返回值：不传参返回当前全局进度数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 主体2s，repeat:1，一共两轮播放
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      repeat: 1
    });

    console.log(tween.progress());        // 单次动画本体进度
    console.log(tween.totalProgress());   // 包含两轮循环的整套动画进度

    // 跳转到整套动画70%位置
    tween.totalProgress(0.7);
    ```
    >
    > 注意：无限循环 `repeat:-1` 时，`totalProgress()` 可以持续大于1；设置 `totalProgress(val)` 会自动定位到对应循环内的播放位置。

3. 和 progress() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      repeat:1,
      paused:true
    });
    tween.totalProgress(0.6);
    // totalProgress=0.6：整套两轮动画走到60%，自动落在第二轮动画内

    tween.progress(0.6);
    // progress=0.6：仅当前这一轮动画走到60%，不关心是第几轮循环
    ```
    - `tween.progress()`：仅当前单轮动画本体进度，0~1
    - `tween.totalProgress()`：包含delay、全部循环与循环间隔的整套动画全局进度

4. 高频使用场景：滚动驱动整套带循环动画，全局进度条

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.5,
      duration:1,
      repeat:2,
      paused:true
    });
    // 根据滑块控制整套动画的全局进度
    slider.addEventListener("input", () => {
      tween.totalProgress(slider.value / 100);
    });
    ```

5. 常用特点
    1. 支持读写，无参读取全局进度，传入`0~1`数值跳转播放头，支持链式调用。
    2. 计算包含 delay、所有循环、repeatDelay，是整套动画的完整进度。
    3. 跳转时会触发`onUpdate`，不会触发`onStart`。
    4. 无限循环动画读取 `totalProgress()` 可以超过1；设置超过1的值会钳位到1。
    5. 适合ScrollTrigger、滑块控制器，需要把整套带循环动画映射到0~1区间的场景。



### 3.2.19 totalTime() 方法

`Tween.totalTime()` 是 Tween 实例方法，用于**读取或设置整套动画的总时间**（单位秒），包含 delay、全部循环、repeatDelay。
>
> 区分：`time()` 是当前单轮动画内部时间；`totalTime()` 是包含所有循环、间隔的整套动画累计时间。


1. 语法

    ```javascript
    // 获取整套动画累计总时间
    const totalT = tween.totalTime();
    // 设置整套动画总时间，跳转播放头
    tween.totalTime(timeValue);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`timeValue`，可选，数字类型，单位秒
    - 返回值：不传参返回当前总时间数值；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // duration:2，delay:1，repeat:1，repeatDelay:0.5
    const tween = gsap.to(".box", {
      x: 300,
      duration: 2,
      delay: 1,
      repeat: 1,
      repeatDelay: 0.5
    });

    console.log(tween.time());        // 当前单轮动画内部时间
    console.log(tween.totalTime());   // 包含delay+全部循环+循环间隔的累计总时间

    // 跳转到整套动画3秒位置
    tween.totalTime(3);
    ```
    >
    > 注意：无限循环 `repeat:-1` 时，`totalTime()` 可以持续无限增长；设置 `totalTime(val)` 会自动定位到对应循环内的播放位置。

3. 和 time() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x:300,
      duration:2,
      repeat:1,
      delay:0.5,
      paused:true
    });

    tween.time(1);
    // time(1)：定位到当前这一轮动画内的1秒位置

    tween.totalTime(2);
    // totalTime(2)：定位到整套动画累计总时间2秒，自动计算落在第几轮循环
    ```
    - `tween.time()`：单轮动画内的时间，仅当前循环
    - `tween.totalTime()`：整套动画累计时间，包含delay、所有循环与repeatDelay

4. 高频使用场景：按总时间点预览带循环的整套动画

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.5,
      duration:1,
      repeat:2,
      delay:0.2,
      repeatDelay:0.3,
      paused:true
    });
    // 点击按钮直接跳转到整套动画2.5秒处
    document.querySelector("#jumpBtn").addEventListener("click", () => {
      tween.totalTime(2.5);
    });
    ```

5. 常用特点
    1. 支持读写，无参读取累计总时间，传入数字跳转播放头，支持链式调用。
    2. 时间计算包含 delay、所有循环、repeatDelay。
    3. 设置totalTime不会改变播放状态，暂停则保持暂停，播放则继续播放。
    4. 跳转仅触发`onUpdate`，不会触发`onStart`。
    5. 适合带循环动画的时间轴控制器，按全局总时间定位播放头。



### 3.2.20 yoyo() 方法

`Tween.yoyo()` 是 Tween 实例方法，用于**读取或设置循环动画是否开启yoyo往复模式**。开启后，每完成一轮循环就自动反向播放。
>
> 区分：`reversed()` 是手动设置播放方向标记；`yoyo()` 是控制循环时自动正反切换的开关，仅在存在循环（repeat>0或repeat=-1）时生效。


1. 语法

    ```javascript
    // 获取当前yoyo状态
    const isYoyo = tween.yoyo();
    // 设置yoyo开关
    tween.yoyo(enable);
    ```
    - `tween`：GSAP Tween实例（`gsap.to` / `gsap.from` / `gsap.fromTo` 返回对象）
    - 参数：`enable`，可选，布尔值，`true`开启往复，`false`关闭
    - 返回值：不传参返回当前布尔状态；传参返回 tween 自身，支持链式调用

2. 基础示例

    ```javascript
    // 创建无限循环动画
    const tween = gsap.to(".box", {
      x: 300,
      duration: 1,
      repeat: -1
    });

    // 读取yoyo状态
    console.log(tween.yoyo()); // false

    // 开启yoyo往复
    tween.yoyo(true);

    // 链式调用
    tween.yoyo(true).repeat(-1).play();
    ```
    >
    > 注意：yoyo仅对循环生效；`repeat:0` 不循环时，开启yoyo不会有任何效果。

3. 和 reversed() 对比示例

    ```javascript
    const tween = gsap.to(".box", {
      x:300,
      duration:1,
      repeat:-1,
      paused:true
    });

    tween.yoyo(true);
    // yoyo(true)：循环过程自动切换正反方向，无需手动调用reverse

    tween.reversed(true);
    // reversed(true)：仅设置单次播放方向标记，不会自动切换
    ```
    - `tween.yoyo()`：循环自动来回切换方向，属于循环行为配置
    - `tween.reversed()`：手动读写当前播放方向标记，不具备自动切换逻辑

4. 高频使用场景：运行时开关循环动画的往复效果

    ```javascript
    const tween = gsap.to(".box", {
      scale:1.2,
      duration:0.5,
      repeat:-1,
      paused:true
    });
    // 点击按钮切换yoyo开关
    document.querySelector("#toggleBtn").addEventListener("click", ()=>{
      tween.yoyo( !tween.yoyo() );
    });
    tween.play();
    ```

5. 常用特点
    1. 支持读写，无参读取布尔状态，传入布尔值设置，支持链式调用。
    2. 只有存在循环（repeat>0 / repeat=-1）时，yoyo才会生效。
    3. 修改 `yoyo()` **不会更新 tween.vars.yoyo**，vars保留原始配置。
    4. 开启yoyo后，一轮正向播放结束，下一轮自动反向回放。
    5. 常配合 `repeat()`、`repeatDelay()` 一起控制往复循环动画。
