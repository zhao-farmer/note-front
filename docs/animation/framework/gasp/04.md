# 四、时间线-Timeline

## 4.1 属性

### 4.1.1 .autoRemoveChildren

`autoRemoveChildren` 是 Timeline 实例的布尔配置项，用于控制**时间轴完成后是否自动移除内部子动画（Tween/Timeline）**，不属于全局 `gsap.config()`，是 Timeline 构造参数。


1. 语法

    ```javascript
    gsap.timeline({ autoRemoveChildren: Boolean });
    ```
    在创建 Timeline 时传入；也可在实例创建后修改 `tl.autoRemoveChildren = true`。

2. 配置项说明

    - autoRemoveChildren
        
        时间轴播放完成（且没有重复`repeat:0`）时，自动清理、移除所有子补间。
        
        - 默认值：`true`
        - `true`：时间轴完成后，子动画从时间轴上被移除，释放引用。子动画实例会被垃圾回收，后续无法再用 `tl.getChildren()` 获取。
        - `false`：子动画保留在时间轴内，播放完成后依然存在，可以反复调用 `tl.restart()` 重播。
        
3. 示例

    ```js
    // 创建时间轴，关闭自动移除子动画
    const tl = gsap.timeline({
      autoRemoveChildren: false
    });

    tl.to(".box", { x: 300, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    tl.play();
    ```

4. 使用要点

    1. **作用对象：Timeline 实例**，不是全局 GSAP 配置，不能写在 `gsap.config()`。
    2. 生效时机：**时间轴完整播放结束（到达结束时间点）**，暂停/反向播放不会触发移除。
    3. repeat 影响：
    - `repeat > 0`：时间轴会循环，`autoRemoveChildren` 不会在单次循环结束时清理；只有所有循环全部结束才触发。
    - `repeat:-1`（无限循环）：永远不会触发子动画移除。
    4. 常见场景
    - 默认 `true`：一次性动画，播放完销毁子动画节省内存。
    - 设置 `false`：需要反复 `restart()`、动态查询子动画、多次复用这条时间轴。
    5. 副作用：`autoRemoveChildren:true` 完成后调用 `tl.getChildren()` 返回空数组。

    > 区分：`autoRemoveChildren` 只移除**时间轴上的子动画引用**，不会删除页面 DOM 元素。


### 4.1.2 .data

`.data` 是 Timeline 实例上的**实例属性**，用于挂载任意自定义数据，初始化时会读取构造参数 `vars.data`。
> 提示：GSAP 的 `data` 属性属于所有 Animation 实例（Tween / Timeline），用于业务自定义数据存储，GSAP 内部不会读取、修改该属性。


1. 语法

    ```javascript
    // 创建 timeline 时，在 vars 传入 data，会自动赋值给 tl.data
    const tl = gsap.timeline({
      data: { id: "anim-01", name: "入场动画" }
    });

    // 读取 .data 属性
    console.log(tl.data.id); // anim-01

    // 直接修改 .data 属性
    tl.data.status = "playing";
    tl.data = { id: "anim-02" }; // 整体覆盖
    ```

2. 属性说明

    - `tl.data`：任意类型，默认值 `undefined`；创建时传入 `vars.data` 则初始化为对应值。
    - GSAP 内部完全不消费这个属性，仅作为开发者自定义数据容器。

    ```javascript
    // 完整示例
    const tl = gsap.timeline({
    data: { type: "fade", duration: 1 }
    })
    .to(".box", { opacity: 1 });

    // 在回调里读取 timeline.data
    tl.eventCallback("onComplete", () => {
    console.log(tl.data.type);
    tl.data.finished = true;
    });
    ```

3. 要点

    - 是**属性**，不是方法，不要写 `tl.data()`。
    - 数据挂载在 timeline 实例上，timeline 被 `kill()` 销毁后实例引用消失，data 一同释放。
    - 区分：`vars.data` 是创建时的配置项；`.data` 是实例上的属性。


### 4.1.3 .labels

`.labels` 是 Timeline 实例的只读属性，存储时间轴上所有标签（label）的键值映射对象，标签用于标记时间点，方便跳转到指定位置播放。

1. 语法

    ```javascript
    // 获取全部标签映射
    tl.labels;

    // 获取单个标签对应的时间值
    tl.labels["myLabel"];
    ```
    > 提示：`.labels` 是**只读属性**，不能直接赋值修改；新增/删除标签请使用 `.addLabel()`。

2. 属性说明

    对象类型，`{ labelName: time }`，key 为标签名称，value 为标签对应的时间轴时间（单位：秒）。

    - 标签通过 `addLabel(name, time)` 或时间轴链式 `.add("labelName", time)` 添加。
    - 时间值是相对于 Timeline 根起点的绝对时间。
    - 只读：`tl.labels = {}` 不会生效。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .addLabel("midPoint", 1) // 在1秒位置添加标签 midPoint
      .to(".box", { y: 200, duration: 1 }, "midPoint");

    // 读取所有标签
    console.log(tl.labels); // { midPoint: 1 }
    // 读取指定标签时间
    console.log(tl.labels.midPoint); // 1

    // 跳转到标签位置播放
    tl.play("midPoint");
    ```

4. 使用要点

    1. **作用域：仅 Timeline 实例拥有，Tween 没有 labels 属性**。
    2. 动态更新：调用 `addLabel()` 新增标签后，`tl.labels` 对象会自动更新。
    3. 标签查找：可用来遍历所有时间标记，批量校验时间点。
    4. 区分：
        - `.labels`：读取标签集合；
        - `.addLabel()`：新增标签；
        - `.removeLabel()`：移除指定标签。
    5. 注意：标签名称字符串区分大小写。


### 4.1.4 .parent

`.parent` 是 Timeline 实例的只读属性，指向当前时间轴的父级时间轴；如果当前 Timeline 是根时间轴，`parent` 值为 `null`。

1. 语法

    ```javascript
    // 获取父时间轴
    tl.parent;
    ```
    > 提示：`.parent` 为只读属性，不能直接赋值修改父子关系；嵌套时间轴请使用 `.add()` 或直接传入父时间轴。

2. 属性说明

    类型：`Timeline|null`
    
    - 当当前时间轴被 `add()` 添加到另一个 Timeline 时，`parent` 指向这个父 Timeline。
    - 根时间轴（没有被添加到任何其他时间轴）：`parent = null`。
    - 只读，无法手动赋值修改。
    - 多层嵌套时，可以链式向上查找：`tl.parent.parent`。

3. 示例

    ```js
    // 父时间轴
    const parentTl = gsap.timeline();
    // 子时间轴
    const childTl = gsap.timeline();

    parentTl.add(childTl); // 将子时间轴加入父时间轴

    console.log(childTl.parent === parentTl); // true
    console.log(parentTl.parent); // null，根时间轴
    ```

4. 使用要点

    1. **作用域：仅 Timeline 实例拥有，Tween 没有 parent 属性**。
    2. 父子关系由 `.add()` 建立，不是创建实例时绑定。
    3. 常见用途：递归遍历时间轴树结构，向上查找根时间轴。
    4. 解除父子关系：调用 `.remove()` 将子时间轴从父级移除后，`childTl.parent` 会变为 `null`。
    5. 区分：
        - `.parent`：向上获取父 Timeline；
        - `.getChildren()`：向下获取当前时间轴所有子补间/子时间轴。

### 4.1.5 .scrollTrigger

`.scrollTrigger` 是 Timeline 实例上的属性，指向绑定到该时间线的 ScrollTrigger 实例，仅在创建 timeline 时传入 `scrollTrigger` 配置才会存在。
> 提示：GSAP 的 ScrollTrigger 是插件，使用前必须通过 `gsap.registerPlugin(ScrollTrigger)` 注册。

1. 语法

    ```javascript
    // 创建带 scrollTrigger 的 timeline
    const tl = gsap.timeline({
      scrollTrigger: {
        trigger: ".box",
        start: "top center",
        end: "bottom center",
        scrub: true
      }
    });

    // 读取 timeline 的 scrollTrigger 实例
    const st = tl.scrollTrigger;
    ```
2. 属性说明

    - `tl.scrollTrigger`：获取绑定在当前 timeline 的 ScrollTrigger 对象，可以调用 ScrollTrigger 的方法如 `.refresh()`、`.kill()`、`.getVelocity()` 等。
    - 如果 timeline 创建时没有配置 scrollTrigger，则该属性为 `undefined`。

    ```javascript
    // 示例：通过 timeline.scrollTrigger 调用 ScrollTrigger API
    const tl = gsap.timeline({
      scrollTrigger: {
        trigger: ".box",
        scrub: 1
      }
    })
    .to(".box", { x: 300 });

    // 访问 scrollTrigger 实例
    console.log(tl.scrollTrigger);
    tl.scrollTrigger.refresh(); // 刷新滚动触发器
    // tl.scrollTrigger.kill(); // 销毁触发器
    ```

3. 要点
    - 只读引用，**不能直接赋值**替换 `scrollTrigger`，如需修改触发器配置，在创建时配置或者操作 ScrollTrigger 实例本身。
    - 当 timeline 被 `kill()` 销毁时，关联的 scrollTrigger 不会自动销毁，需要单独 `tl.scrollTrigger.kill()`。
    - 一个 timeline 只能绑定**单个 ScrollTrigger**。

### 4.1.6 .smoothChildTiming

`smoothChildTiming` 是 Timeline 构造参数，同时也是 Timeline 实例可读写属性，用于控制子动画时间计算模式，对嵌套时间轴场景影响明显。

1. 语法

    ```javascript
    // 创建时配置
    const tl = gsap.timeline({ smoothChildTiming: Boolean });

    // 实例创建后读写
    tl.smoothChildTiming;
    tl.smoothChildTiming = Boolean;
    ```

2. 属性说明
    - 类型：`Boolean`
    - 默认值：`false`
    - `false`：子补间/子时间轴的时间位置**固定不变**。当父时间轴发生反向播放、时间跳转、动态修改子动画起始时间时，子动画的起始时间点保持原始值。适合大多数常规时序动画。
    - `true`：启用平滑子时间计算。父时间轴反向、跳时间、动态调整时，GSAP 会自动重新计算子动画的时间位置，保持视觉上连续平滑过渡。适合嵌套时间轴、动态修改时间、来回拖拽播放头的场景（例如 ScrollTrigger）。

3. 示例

    ```js
    // 开启平滑子时间计算
    const tl = gsap.timeline({
      smoothChildTiming: true
    });

    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    console.log(tl.smoothChildTiming); // true
    tl.smoothChildTiming = false; // 运行时关闭
    ```

4. 使用要点

    1. **作用域：仅 Timeline 实例，Tween 没有该属性**。
    2. 典型适用场景：ScrollTrigger、拖拽播放头、反复正反播放、动态增删子动画。
    3. 代价：开启后有微小性能开销；简单固定时序动画建议保持默认 `false`。
    4. 行为差异
        - `false`：子动画时间锚点固定，跳转播放头时子动画可能出现“跳变”。
        - `true`：播放头来回移动时，子动画时间会自动重映射，过渡更顺滑。
    5. 注意：仅影响**子动画时间计算逻辑**，不会改变动画本身的 duration、ease。


### 4.1.7 .vars

`.vars` 是 Timeline（以及 Tween）实例上的可读写属性，保存创建实例时传入的原始配置对象。


1. 语法

    ```javascript
    // 创建时间轴时传入vars配置
    const tl = gsap.timeline({ paused: true, autoRemoveChildren: false });

    // 读取原始配置对象
    tl.vars;

    // 修改vars内属性（部分配置支持运行时修改）
    tl.vars.paused = false;
    ```
    > 提示：`.vars` 是实例存储的原始配置对象，但**并不是所有属性修改后都会自动生效**。

2. 属性说明
    - 类型：`Object`
    - 保存实例初始化时传入的全部配置项，例如 `paused`、`repeat`、`autoRemoveChildren`、`smoothChildTiming` 等。
    - 是创建 Timeline 时传入的对象引用，不是副本。
    - 部分属性修改后实时生效；部分属性（如 `smoothChildTiming`）在实例创建后修改才会生效；**有些配置一旦创建实例就无法变更**。

3. 示例

    ```js
    const tl = gsap.timeline({
      paused: true,
      repeat: 2,
      autoRemoveChildren: false
    });

    console.log(tl.vars);
    // { paused: true, repeat: 2, autoRemoveChildren: false }

    // 读取单个配置
    console.log(tl.vars.repeat); // 2

    // 修改支持运行时更新的参数
    tl.vars.repeat = 1;
    ```

4. 使用要点

    1. **作用域：Timeline / Tween 实例都拥有 vars 属性**。
    2. 不要混淆：
        - `tl.vars`：实例构造配置（时间轴本身的设置，paused、repeat等）
        - 子tween的vars：子动画的属性（x、y、duration等）
    3. 限制：直接修改 `tl.vars` 里的配置，**不是全部选项都能动态更新**。例如时间轴创建后修改 `tl.vars.smoothChildTiming` 会生效，但部分底层配置修改无效。稳妥做法：优先使用实例提供的方法修改， 而不是直接改 `.vars`。
    4. 用途：运行时读取动画原始配置、批量复制动画配置，调试查看实例初始化参数。
    5. 注意：`.vars` 不会包含通过链式 `.to()` 添加的子动画配置，仅存储 Timeline 自身构造参数。


## 4.2 方法

### 4.2.1 `.add()`

`.add()` 是 Timeline 实例方法，用于向时间线内添加补间、子时间线、回调函数或标签，支持指定插入时间位置，是 Timeline 底层核心方法。

1. 语法

    ```javascript
    // 添加动画/回调/标签
    timeline.add(target, position);
    ```
2. 属性说明
    - 参数：
        - `target`：`Tween | Timeline | Function | string`
            - Tween / Timeline：添加子动画实例
            - Function：添加时间点回调函数
            - string：添加时间标签（label）
        - `position`【可选】：`number | string`，默认追加到时间线末尾；支持绝对秒数、相对位置 `"+=1"` / `"-=0.5"`、已有标签名作为插入锚点
    - 返回值：当前 Timeline 实例，支持链式调用

3. 示例

    ```js
    const tl = gsap.timeline();
    // 添加补间，追加末尾
    tl.add(gsap.to(".box", { x: 200, duration: 1 }));
    // 在1秒位置插入子动画
    tl.add(gsap.to(".box", { y: 100, duration: 0.5 }), 1);
    // 相对位置插入，上一个动画结束后延迟0.3s
    tl.add(gsap.to(".box", { opacity: 0 }), "+=0.3");
    // 添加回调函数
    tl.add(() => console.log("到达该时间点"), 0.8);
    // 添加时间标签
    tl.add("middlePoint", 1.5);
    ```

### 4.2.2 .addLabel()

`.addLabel()` 是 Timeline 实例方法，用于在时间轴指定时间位置添加时间标签，方便后续跳转到该时间点。

1. 语法

    ```javascript
    // 添加标签
    tl.addLabel(labelName, position);
    ```
    > 提示：标签会存入 timeline 的 `.labels` 对象；也可以使用 `.add()` 传入字符串实现同样添加标签效果。

2. 属性说明

    - 参数：
        - `labelName`：`string`，标签名称，不能重复；重复添加同名标签会覆盖原有时间位置。
        - `position`【可选】：`number | string`，默认值 `"+=0"`；支持绝对秒数、相对位置、已有标签作为锚点。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    // 在 1.5s 位置添加标签
    tl.addLabel("mid", 1.5);
    // 在上一个动画结束后延迟0.2s添加标签
    tl.to(".box", { x: 200 })
      .addLabel("endAnim", "+=0.2");

    // 使用标签控制动画跳转
    tl.seek("mid");
    console.log(tl.labels.mid); // 1.5
    ```
4. 使用要点

    1. 标签仅为时间标记，不会产生动画，存储在 `tl.labels` 对象中。
    2. 重复名称标签会覆盖旧标签时间。
    3. 支持使用标签名作为 `.add()`、`.seek()`、`.play()` 等方法的位置参数。
    4. 移除标签：直接使用 `delete tl.labels.labelName`。
    5. 区分：
        - `.addLabel(name, pos)`：方法，新增标签；
        - `.labels`：实例属性，读取全部标签键值对。

### 4.2.3 .addPause()

`.addPause()` 是 Timeline 实例方法，用于在时间轴指定时间位置插入暂停点，播放头运行到该位置时动画自动暂停。

1. 语法

    ```javascript
    // 添加暂停点
    tl.addPause(position, callback, params);
    ```
    > 提示：暂停点本质是在指定时间注册暂停行为；继续播放需要调用 `.resume()`。

2. 属性说明

    - 参数：
        - `position`【可选】：`number | string`，默认值 `"+=0"`；支持绝对秒数、相对位置、已有标签作为锚点。
        - `callback`【可选】：`Function`，到达暂停点时触发的回调函数。
        - `params`【可选】：`Array`，传递给回调函数的参数数组。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    // 在 1s 位置添加暂停点
    tl.to(".box", { x: 200, duration: 1 })
      .addPause(1, () => {
        console.log("到达暂停点");
      })
      .to(".box", { y: 200, duration: 1 });

    tl.play();
    // 播放头走到1秒处暂停，执行回调
    // tl.resume(); // 恢复继续播放
    ```
4. 使用要点
    1. 暂停点属于时间轴内的时间标记，播放头正向/反向播放经过该时间点都会触发暂停。
    2. 一个时间轴可以添加多个 `.addPause()`。
    3. 移除暂停点：使用 `.removePause()`，传入暂停所在位置或标签名。
    4. 区分：
        - `.addPause()`：在时间轴内嵌入暂停行为；
        - `.pause()`：立即暂停当前正在播放的动画，不是时间轴上的标记点。

### 4.2.4 .call()

`.call()` 是 Timeline 实例方法，用于在时间轴指定时间位置插入回调函数，播放头到达该时间点时执行函数。

1. 语法

    ```javascript
    tl.call(callback, params, position);
    ```
    > 提示：`.call()` 底层基于 `.add()` 封装，本质是添加回调到时间线；回调执行不占用时间轴时长。

2. 属性说明

    - 参数：
        - `callback`：`Function`，播放头到达指定时间点要执行的回调函数。
        - `params`【可选】：`Array`，传递给回调函数的参数数组。
        - `position`【可选】：`number | string`，默认值 `"+=0"`；支持绝对秒数、相对位置、已有标签作为锚点。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      // 在上一个动画结束后执行回调
      .call(() => {
        console.log("box 移动完成");
      })
      .to(".box", { y: 200, duration: 1 })
      // 在 2.5s 位置执行回调，并传入参数
      .call((msg) => {
        console.log(msg);
      }, ["到达2.5秒"], 2.5);
    ```
4. 使用要点
    1. 回调函数执行**不会占用时间**，仅为时间轴上一个瞬时触发点。
    2. 正向播放、反向回退播放头经过该时间点，都会触发回调。
    3. 回调不会阻塞动画渲染，内部不要写耗时同步代码。
    4. 区分：
        - `.call()`：时间轴内嵌入回调，播放头到达时间点触发；
        - `eventCallback("onComplete", fn)`：时间轴实例生命周期回调（整体动画完成才触发）。

### 4.2.5 .clear()

`.clear()` 是 Timeline 实例方法，用于清空当前时间轴内所有子动画、标签、暂停点、回调等内容，时间轴实例本身保留。

1. 语法

    ```javascript
    tl.clear();
    ```
    > 提示：`.clear()` 只会清空子项，不会销毁 Timeline 实例；实例上的 vars、data、scrollTrigger、事件回调等属性仍然保留。

2. 属性说明

    - 参数：无
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline({ data: { name: "demo" } });
    tl.to(".box", { x: 200 })
      .addLabel("mid", 1)
      .call(() => console.log("callback"));

    tl.clear();
    // 此时 tl 内部所有子动画、标签、call 全部清空
    console.log(tl.data.name); // demo，data 属性保留
    tl.to(".box", { opacity: 1 }); // 可以继续添加新动画
    ```
4. 使用要点

    1. 仅清除时间轴内部子内容，**不会销毁 timeline 实例本身**。
    2. 被清除掉的子动画/子时间轴会被 kill。
    3. 实例自身配置、`.data`、事件回调、`.scrollTrigger` 不会被清除。
    4. 区分：
        - `.clear()`：清空内部所有子元素，实例保留，可继续复用；
        - `.kill()`：销毁整个时间轴实例，停止动画，释放实例。

### 4.2.6 .currentLabel()

`.currentLabel()` 是 Timeline 实例方法，获取播放头当前所在位置对应的标签名称。

1. 语法

    ```javascript
    tl.currentLabel();
    ```
    > 提示：返回当前播放头位置之前最近的标签；播放头在两个标签之间时，返回左侧临近标签。没有匹配标签返回 `null`。

2. 属性说明

    - 参数：无
    - 返回值：`string | null`，当前命中的标签名，不存在则返回 null。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("start", 0)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("middle", 2)
      .to(".box", { y: 200, duration: 2 })
      .addLabel("end", 4);

    tl.seek(1);
    console.log(tl.currentLabel()); // "start"

    tl.seek(3);
    console.log(tl.currentLabel()); // "middle"

    tl.seek(-0.5);
    console.log(tl.currentLabel()); // null
    ```
4. 使用要点
    1. 标签匹配规则：取**小于等于当前播放时间**的最近标签。
    2. 播放头跳转到标签时间点，会命中该标签。
    3. 反向播放同样遵循该规则。
    4. 区分：
        - `.currentLabel()`：方法，读取播放头当前对应的标签；
        - `.labels`：实例属性，存储全部标签与对应时间的键值对象。


### 4.2.7 .delay()

`.delay()` 是 Timeline 实例方法，用于读取或设置时间轴的延迟时长，控制动画开始前等待的秒数。

1. 语法

    ```javascript
    // 获取当前 delay 值
    tl.delay();
    // 设置 delay 值
    tl.delay(value);
    ```
    > 提示：设置 delay 不会改变时间轴内部子动画的时间位置，仅控制整体动画何时开始播放。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，单位秒。不传参数则为读取；传入数值则设置延迟。
    - 返回值：不传参返回当前 delay 数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline({ delay: 1 });
    console.log(tl.delay()); // 读取：1

    tl.delay(2); // 修改延迟为2秒
    tl.to(".box", { x: 200, duration:1 });
    ```
4. 使用要点

    1. delay 是**动画整体启动延迟**，不是时间轴内部的时间偏移。
    2. 动画已经开始播放后，修改 delay 不会产生任何效果。
    3. 负数 delay 允许动画播放头提前启动（跳过前面部分）。
    4. 区分：
        - `.delay()`：读写实例的启动延迟；
        - `.duration()`：读写动画本身总时长，不含延迟。

### 4.2.8 .duration()

`.duration()` 是 Timeline 实例方法，用于读取或设置时间轴的持续时长（不包含 delay）。

1. 语法

    ```javascript
    // 获取当前 duration 值
    tl.duration();
    // 设置 duration 值
    tl.duration(value);
    ```
    > 提示：设置 duration 会缩放时间轴内所有子动画的时间，以适配新的总时长；delay 不属于 duration 的一部分。
2. 属性说明

    - 参数：
        - `value`【可选】：`number`，单位秒。不传参数则为读取；传入数值则设置总时长。
    - 返回值：不传参返回当前 duration 数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    console.log(tl.duration()); // 读取：2
    tl.duration(4); // 将整体时长缩放为4秒，内部动画自动拉长
    console.log(tl.duration()); // 4
    ```
4. 使用要点

    1. duration 是时间轴本体动画时长，**不包含 delay**；`totalDuration()` 才是包含 delay 的总时长。
    2. 修改 duration 会对时间轴内所有子补间、子时间轴进行时间缩放。
    3. 若时间轴设置了 `repeat`，duration 指单次循环的时长。
    4. 区分：
        - `.duration()`：单次动画时长，不含延迟；
        - `.totalDuration()`：包含 delay + repeat 的完整总时长。


### 4.2.9 .endTime()

`.endTime()` 是 Timeline 实例方法，获取时间轴的结束时间（相对于父时间轴）。

1. 语法

    ```javascript
    tl.endTime(includeRepeats);
    ```
    > 提示：默认不包含 repeat，返回单次播放的结束时间；该方法**只读，不能传入数值修改**。
2. 属性说明

    - 参数：
        - `includeRepeats`【可选】：`boolean`，默认值 `false`。`true` 时包含重复次数计算最终结束时间。
    - 返回值：`number`，单位秒。

3. 示例

    ```js
    const tl = gsap.timeline({repeat: 2});
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    console.log(tl.endTime()); // 2，单次结束时间
    console.log(tl.endTime(true)); // 6，包含2次repeat：2 * (2+1)
    ```
4. 使用要点

    1. 时间轴无父级时，endTime 等价于自身 duration；存在父时间轴时，返回在父时间轴上的结束点位。
    2. `includeRepeats: true` 会把 repeat、repeatDelay 一并纳入计算。
    3. 仅用于读取，不支持传数字设置结束时间。
    4. 区分：
        - `.endTime()`：在父时间轴坐标系下的结束时间；
        - `.duration()`：时间轴自身单次时长；
        - `.totalDuration()`：包含 delay / repeat / repeatDelay 的总时长。

### 4.2.10 .eventCallback()

`.eventCallback()` 是 Timeline 实例方法，用于读取、添加或移除时间轴生命周期事件回调。

1. 语法

    ```javascript
    // 设置回调
    tl.eventCallback(type, callback, params);
    // 读取已有回调
    tl.eventCallback(type);
    // 移除回调
    tl.eventCallback(type, null);
    ```
    > 提示：支持的事件类型：`onStart`、`onUpdate`、`onComplete`、`onReverseComplete`、`onRepeat`；也可在创建 timeline 的 vars 中直接配置。

2. 属性说明

    - 参数：
        - `type`：`string`，事件名称（`onStart` / `onUpdate` / `onComplete` / `onReverseComplete` / `onRepeat`）
        - `callback`【可选】：`Function|null`，传入函数则绑定；传入 `null` 移除回调；不传则读取当前绑定函数
        - `params`【可选】：`Array`，传递给回调函数的参数数组
    - 返回值：读取回调时返回绑定的函数；设置/移除回调时返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    // 设置 onComplete 回调
    tl.eventCallback("onComplete", (msg) => {
      console.log(msg);
    }, ["动画播放完成"]);

    // 读取回调函数
    console.log(tl.eventCallback("onComplete"));

    // 移除回调
    tl.eventCallback("onComplete", null);
    ```
4. 使用要点

    1. `onUpdate` 在每一帧播放头更新时持续触发，注意性能开销。
    2. 回调绑定在时间轴实例上，调用 `.kill()` 会自动清除事件回调。
    3. 反向播放回到起点时触发 `onReverseComplete`，正向播放结束触发 `onComplete`。
    4. 区分：
        - `.eventCallback()`：实例方法动态增删生命周期回调；
        - `.call()`：在时间轴**特定时间点**插入瞬时回调，属于时间轴内子项。

### 4.2.11 .from()

`.from()` 是 Timeline 实例方法，用于向时间轴添加**from补间动画**，定义动画起始状态，目标元素从该起始状态过渡到当前DOM样式状态。

1. 语法

    ```javascript
    tl.from(target, vars, position);
    ```
    > 提示：底层内部调用 `.add()` 来添加补间；`from()` 是从设置的属性值**回到元素现有状态**，和 `to()` 方向相反。

2. 属性说明

    - 参数：
        - `target`：`string | HTMLElement | NodeList | Array`，动画目标元素/选择器字符串
        - `vars`：`object`，动画配置对象（duration、ease、opacity、x 等属性）
        - `position`【可选】：`number | string`，默认值 `"+=0"`；支持绝对秒数、相对位置、标签锚点，用来控制该补间插入时间轴的位置
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    // 元素从 x:300，opacity:0 过渡到页面原始状态
    tl.from(".box", { x: 300, opacity: 0, duration: 1 })
      .from(".circle", { y: 200, opacity: 0, duration: 1 }, "-=0.5");
    ```
4. 使用要点

    1. `.from()` 动画起点是配置内属性，终点为元素当前渲染样式。
    2. 支持 `from()` 的变体 `.fromTo()`，同时自定义起点与终点。
    3. position 参数控制动画插入时间轴的位置，实现动画重叠。
    4. 区分：
        - `.from()`：起始属性由代码定义，终点使用元素现有样式；
        - `.to()`：起始使用元素现有样式，终点由代码定义；
        - `.fromTo()`：同时手动指定起始属性与结束属性。

### 4.2.12 .fromTo()

`.fromTo()` 是 Timeline 实例方法，用于向时间轴添加 fromTo 补间动画，同时手动指定动画起始状态与结束状态。

1. 语法

    ```javascript
    tl.fromTo(target, fromVars, toVars, position);
    ```
    > 提示：底层内部调用 `.add()` 添加补间；不会读取元素当前样式作为起点或终点，完全由 fromVars 和 toVars 控制。

2. 属性说明
    - 参数：
        - `target`：`string | HTMLElement | NodeList | Array`，动画目标元素/选择器字符串
        - `fromVars`：`object`，动画起始属性配置
        - `toVars`：`object`，动画结束属性配置（duration、ease 等动画参数写在此对象）
        - `position`【可选】：`number | string`，默认值 `"+=0"`；支持绝对秒数、相对位置、标签锚点，用来控制该补间插入时间轴的位置
    - 返回值：当前 Timeline 实例，支持链式调用。
3. 示例

    ```js
    const tl = gsap.timeline();
    // 元素从 x:0 opacity:0 过渡到 x:200 opacity:1
    tl.fromTo(".box",
      { x: 0, opacity: 0 },
      { x: 200, opacity: 1, duration: 1 }
    )
    .fromTo(".circle",
      { y: 0, scale: 0.5 },
      { y: 150, scale: 1, duration: 1 },
      "-=0.5"
    );
    ```
4. 使用要点

    1. `.fromTo()` 不会采样元素当前样式，起点终点都由开发者定义，样式控制更稳定。
    2. 动画时长、缓动函数等动画配置必须放在 `toVars` 对象内，`fromVars` 只写起始属性。
    3. position 参数可设置重叠动画，支持绝对时间、相对偏移、标签位置。
    4. 区分：
        - `.fromTo()`：同时自定义起始、结束属性；
        - `.from()`：自定义起始属性，终点取自元素现有样式；
        - `.to()`：自定义结束属性，起点取自元素现有样式。


### 4.2.13 .getById()

`.getById()` 是 Timeline 实例方法，根据 id 查找当前时间轴内匹配的子动画（Tween / Timeline）。

1. 语法

    ```javascript
    tl.getById(id);
    ```
    > 提示：仅在当前 Timeline 的子项中搜索，不会递归深入嵌套子时间轴；id 在创建动画时通过 vars.id 指定。
2. 属性说明

    - 参数：
        - `id`：`string`，要查找的动画唯一标识
    - 返回值：`Tween | Timeline | null`，找到则返回对应动画实例，找不到返回 `null`
3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1, id: "boxAnim" })
      .to(".circle", { y: 200, duration: 1, id: "circleAnim" });

    const boxTween = tl.getById("boxAnim");
    console.log(boxTween);
    const notFound = tl.getById("test");
    console.log(notFound); // null
    ```
4. 使用要点

    1. 只搜索**直接子级**，不会递归遍历嵌套 timeline 内部的子动画。
    2. id 在创建补间/时间轴时，在 vars 对象里配置。
    3. 匹配到第一个 id 相同的实例就返回。
    4. 区分：
        - `.getById()`：按 id 查找直接子动画；
        - `.getChildren()`：获取所有直接子动画组成数组。


### 4.2.14 .getChildren()

`.getChildren()` 是 Timeline 实例方法，获取当前时间轴的直接子项集合，子项可以是 Tween、Timeline、回调等动画实例。

1. 语法

    ```js
    tl.getChildren(nested);
    ```

    > 
    > 提示：默认只返回直接子级；传入 nested=true 会递归取出所有嵌套层级的子动画。

 2. 属性说明

    - 参数：
        - `nested`【可选】：`boolean`，默认值 `false`。`false` 仅获取直接子项；`true` 递归遍历所有嵌套子时间轴，返回全部子动画。
    - 返回值：`Array<Tween | Timeline | Callback>`，子动画实例数组。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 });
    const subTl = gsap.timeline();
    subTl.to(".circle", { y: 100, duration: 1 });
    tl.add(subTl);

    // 获取直接子项
    const directChildren = tl.getChildren();
    console.log(directChildren);

    // 递归获取所有嵌套子项
    const allChildren = tl.getChildren(true);
    console.log(allChildren);
    ```

4. 使用要点
    5. 返回的数组是**快照**，对子项数组增删不会影响原时间轴。
    6. 包含添加的回调、标签暂停点等时间轴子项，不只是补间动画。
    7. 常用于批量操作子动画，例如批量 kill、批量修改时间缩放。
    8. 区分：
        - `.getChildren()`：获取子动画数组；
        - `.getById()`：按 id 查找单个直接子动画。


### 4.2.15 .getTweensOf()

`.getTweensOf()` 是 Timeline 实例方法，检索时间轴内作用于指定目标元素的所有补间（Tween）实例。

1. 语法

    ```js
    tl.getTweensOf(target, nested);
    ```

    >提示：默认仅查找当前时间轴直接子级；开启 nested 参数可递归遍历嵌套子 Timeline。仅返回 Tween，不会返回子 Timeline。
    
    
 2. 属性说明

    - 参数：
        - `target`：`string | HTMLElement | NodeList | Array`，目标元素或选择器
        - `nested`【可选】：`boolean`，默认值 `false`。`false` 只查直接子项；`true` 递归遍历所有嵌套时间轴
    - 返回值：`Array<Tween>`，匹配的补间实例数组，无匹配则返回空数组

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });
    const subTl = gsap.timeline();
    subTl.to(".box", { scale: 1.2, duration: 1 });
    tl.add(subTl);

    // 获取直接子级中 .box 的补间
    const boxTweens = tl.getTweensOf(".box");
    console.log(boxTweens);

    // 递归嵌套时间轴，获取全部 .box 补间
    const allBoxTweens = tl.getTweensOf(".box", true);
    console.log(allBoxTweens);
    ```

4. 使用要点
    5. 只筛选 **Tween**，不会返回 Timeline、callback、label 等其他子项。
    6. target 支持多个元素，可传入 DOM 数组、NodeList。
    7. 常用于批量修改目标元素动画、获取目标的所有动画时长。
    8. 区分：
        - `.getTweensOf()`：按目标元素筛选，只返回Tween；
        - `.getChildren()`：获取全部子项（Tween/Timeline/call等）。

### 4.2.16 .globalTime()

`.globalTime()` 是 Timeline 实例方法，读取该时间轴播放头对应的**全局时间**（相对于根ticker的绝对时间）。

1. 语法

    ```javascript
    tl.globalTime();
    ```

    > 提示：该方法为只读，不可传入数值进行设置；全局时间不受当前时间轴的时间缩放、偏移影响。

2. 属性说明

    - 参数：无
    - 返回值：`number`，单位秒，当前播放头对应的全局时间戳
3. 示例

    ```js
    const tl = gsap.timeline({ timeScale: 0.5 });
    tl.to(".box", { x: 200, duration: 2 });
    tl.seek(1);

    console.log(tl.time()); // 1，timeline本地时间
    console.log(tl.globalTime()); // 对应全局时间
    ```
4. 使用要点

    1. `.time()` 是**当前timeline本地时间**，受 `timeScale`、嵌套偏移影响；`.globalTime()` 是全局基准时间。
    2. 多层嵌套时间轴场景下，不同子时间轴同一 globalTime 代表真实同一帧时刻。
    3. 适合多时间轴同步，判断多个动画是否处于真实同一时间点。
    4. 区分：
        - `.globalTime()`：全局基准时间，不受自身timeScale影响；
        - `.time()`：时间轴本地播放时间，受timeScale、父级时间变换影响。

### 4.2.17 .invalidate()

`.invalidate()` 是 Timeline 实例方法，清空动画的初始缓存状态，强制在下一次渲染时重新读取元素起始属性。

1. 语法

    ```javascript
    tl.invalidate();
    ```
    > 提示：GSAP 会缓存动画开始时元素的属性值；当 DOM 样式手动变更后，调用 invalidate() 清除缓存，重新采样。

2. 属性说明

    - 参数：无
    - 返回值：当前 Timeline 实例，支持链式调用。
3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 });

    // 手动修改元素样式
    document.querySelector(".box").style.x = "100px";
    // 清除缓存，下次播放重新读取元素起始状态
    tl.invalidate();
    tl.restart();
    ```
4. 使用要点
    1. 清除该时间轴内所有子补间的初始值缓存，不修改时间轴结构、标签、回调。
    2. 当元素样式被 JS / CSS 手动改动，想要动画从新状态开始播放时使用。
    3. 不会重置播放头、pause、reverse 等播放状态。
    4. 区分：
        - `.invalidate()`：清除属性缓存，重新采样元素状态；
        - `.restart()`：重置播放头到起点并播放，**不会清除属性缓存**。


### 4.2.18 .isActive()
`.isActive()` 是 Timeline 实例方法，判断当前时间轴是否处于**活跃播放状态**。

1. 语法

    ```javascript
    tl.isActive();
    ```
    > 提示：只要时间轴正在被 ticker 更新（播放、暂停但播放头仍在有效区间、等待 delay / repeatDelay），都会判定为 active；仅完全结束或 kill 后返回 false。

2. 属性说明
    - 参数：无
    - 返回值：`boolean`，`true` 代表活跃，`false` 代表非活跃
3. 示例

    ```js
    const tl = gsap.timeline({ delay: 1, repeat: 2 });
    tl.to(".box", { x: 200, duration: 1 });

    tl.play();
    console.log(tl.isActive()); // true

    // 动画全部播放完成后
    console.log(tl.isActive()); // false
    ```
4. 使用要点
    1. 处于 delay 等待阶段、repeatDelay 等待阶段，`isActive()` 同样返回 `true`。
    2. 调用 `.pause()` 暂停，但播放头还在动画时间范围内，仍然是 active。
    3. 动画播放完毕、调用 `.kill()` 销毁实例，返回 `false`。
    4. 区分：
        - `.isActive()`：是否被GSAP ticker追踪更新（含等待、暂停在动画区间内）；
        - `.paused()`：读取是否处于暂停状态，只代表播放开关。

### 4.2.19 .iteration()

`.iteration()` 是 Timeline 实例方法，用于读取或设置当前循环次数索引。

1. 语法

    ```javascript
    // 获取当前 iteration
    tl.iteration();
    // 设置 iteration
    tl.iteration(value);
    ```
    > 提示：iteration 从 0 开始计数；第一次播放为 0，第一次重复循环为 1，以此类推。
2. 属性说明

    - 参数：
        - `value`【可选】：`number`，循环索引。不传参数为读取；传入数值则设置当前循环索引。
    - 返回值：不传参返回当前 iteration 数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline({ repeat: 2 });
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    tl.play();
    // 读取当前循环索引
    console.log(tl.iteration());

    // 跳转到第1次重复循环
    tl.iteration(1);
    ```
4. 使用要点
    1. 循环索引起始值为 0，代表第一次播放；repeat 次数为 N，则最大 iteration 为 N。
    2. 设置 iteration 会跳转播放头到对应循环片段，可配合 seek 使用。
    3. 仅在配置了 `repeat` 的时间轴才有意义；无 repeat 时固定为 0。
    4. 区分：
        - `.iteration()`：读写当前所在循环索引；
        - `.repeat()`：读写总共要循环多少次。

### 4.2.20 .kill()

`.kill()` 是 Timeline 实例方法，销毁时间轴实例，停止动画并释放相关资源。

1. 语法

    ```javascript
    // 销毁整个时间轴
    tl.kill();
    // 只销毁指定目标的动画
    tl.kill(target);
    ```
    > 提示：kill 之后时间轴不再被 ticker 追踪，内部子动画一并销毁；和 clear() 仅清空子项不同，kill 会废弃实例。
2. 属性说明
    - 参数：
        - `target`【可选】：`string | HTMLElement | NodeList | Array`，指定要销毁动画的目标元素，不传则销毁整个时间轴。
    - 返回值：`null`
3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".circle", { y: 200, duration: 1 });

    // 销毁全部动画，整个时间轴失效
    // tl.kill();

    // 仅销毁 .box 相关的补间，保留时间轴与其他子动画
    tl.kill(".box");
    ```
4. 使用要点
    1. 不传参调用 `kill()`，会销毁时间轴本身，内部所有子Tween、子Timeline全部被kill，事件回调一并清除。
    2. 传入target时，仅销毁时间轴内作用于该目标的补间，Timeline实例本身保留。
    3. kill后的实例不要再调用play、seek等方法，行为不可预期。
    4. 区分：
        - `.kill()`：销毁实例/指定目标动画，释放资源；
        - `.clear()`：清空内部子项，Timeline实例仍然可用。

### 4.2.21 .killTweensOf()

`.killTweensOf()` 是 Timeline 实例方法，销毁时间轴内作用于指定目标元素的所有补间动画。

1. 语法

    ```javascript
    tl.killTweensOf(target, nested);
    ```

    > 提示：仅销毁Tween补间，不会销毁Timeline实例本身；默认只查找直接子级，可开启nested递归嵌套子时间轴。

2. 属性说明

    - 参数：
        - `target`：`string | HTMLElement | NodeList | Array`，目标元素或选择器
        - `nested`【可选】：`boolean`，默认值 `false`。`false` 仅查找直接子项；`true` 递归遍历所有嵌套子时间轴
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });
    const subTl = gsap.timeline();
    subTl.to(".box", { scale: 1.2, duration: 1 });
    tl.add(subTl);

    // 销毁直接子项里 .box 的补间
    tl.killTweensOf(".box");

    // 递归嵌套时间轴，销毁全部 .box 补间
    // tl.killTweensOf(".box", true);
    ```
4. 使用要点
    1. 只销毁目标对应的Tween，时间轴实例、标签、call回调、子Timeline容器本身保留。
    2. 销毁后的补间不再参与动画渲染，播放头仍可正常运行。
    3. 适合只清除某个元素动画，保留时间轴其他内容继续使用。
    4. 区分：
        - `.killTweensOf()`：仅杀死指定目标的Tween，Timeline实例保留；
        - `.kill(target)`：效果近似，但`.kill()`不传参时直接销毁整个时间轴实例。

### 4.2.22 .nextLabel()

`.nextLabel()` 是 Timeline 实例方法，获取播放头当前位置之后**最近的下一个标签名称**。

1. 语法

    ```javascript
    tl.nextLabel();
    ```
    > 提示：返回大于当前播放时间的最近标签；播放头在最后一个标签之后，返回 `null`。

2. 属性说明
    - 参数：无
    - 返回值：`string | null`，下一个临近标签名，不存在则返回 null。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("start", 0)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("middle", 2)
      .to(".box", { y: 200, duration: 2 })
      .addLabel("end", 4);

    tl.seek(1);
    console.log(tl.nextLabel()); // "middle"

    tl.seek(3);
    console.log(tl.nextLabel()); // "end"

    tl.seek(4.5);
    console.log(tl.nextLabel()); // null
    ```
4. 使用要点
    1. 匹配规则：取**大于当前播放头时间**的最近标签。
    2. 反向播放时，依然按时间轴时间大小判断，不是播放方向。
    3. 常用于实现“跳转到下一章节”的交互逻辑。
    4. 区分：
        - `.nextLabel()`：获取播放头后方最近标签；
        - `.currentLabel()`：获取播放头所在区间对应的标签；
        - `.previousLabel()`：获取播放头前面最近的标签。

### 4.2.23 .pause()

`.pause()` 是 Timeline 实例方法，暂停时间轴播放，停止播放头继续前进。

1. 语法

    ```javascript
    tl.pause(atTime, suppressEvents);
    ```
    > 提示：暂停会停留在当前播放位置；可以可选指定跳转时间再暂停，suppressEvents 控制是否屏蔽事件回调触发。

2. 属性说明

    - 参数：
        - `atTime`【可选】：`number | string`，跳转至该时间/标签位置后暂停。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 时跳转过程不触发 `onUpdate`、`onStart` 等事件回调。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    tl.play();
    // 在当前位置直接暂停
    // tl.pause();

    // 跳转到1秒位置然后暂停，不触发事件
    tl.pause(1, true);
    ```
4. 使用要点
    1. 暂停后实例仍然保持 active 状态，调用 `.resume()` 即可从当前位置继续播放。
    2. 不传参数仅暂停，播放头保持现有位置不动。
    3. `suppressEvents=true` 适合静默跳转，避免 onUpdate 等回调不必要执行。
    4. 区分：
        - `.pause()`：暂停播放，保留当前播放位置；
        - `.paused()`：读取/设置暂停状态的读写方法；
        - `.addPause()`：在时间轴内预置暂停标记点，播放头走到该点自动暂停。


### 4.2.24 .paused()

`.paused()` 是 Timeline 实例方法，用于读取或设置时间轴的暂停状态。

1. 语法

    ```javascript
    // 获取暂停状态
    tl.paused();
    // 设置暂停状态
    tl.paused(value);
    ```
    > 提示：传入布尔值修改暂停状态；不传参为读取当前暂停标记。和 `.pause()` / `.resume()` 功能同源，只是函数调用形式不同。

2. 属性说明

    - 参数：
        - `value`【可选】：`boolean`，`true` 暂停，`false` 恢复播放。不传参数则读取状态。
    - 返回值：不传参返回布尔状态；传入参数返回当前 Timeline 实例，支持链式调用。
3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    tl.play();
    console.log(tl.paused()); // false

    tl.paused(true); // 等价于 tl.pause()
    console.log(tl.paused()); // true

    tl.paused(false); // 等价于 tl.resume()
    ```
4. 使用要点
    1. 读取的是暂停标记，`isActive()` 才用来判断动画是否被 ticker 追踪更新。
    2. 修改 `paused(false)` 会从当前播放头位置继续播放。
    3. 支持链式连续调用。
    4. 区分：
        - `.paused()`：读写暂停状态（getter/setter）；
        - `.pause()`：方法，可附带跳转时间、suppressEvents 参数暂停；
        - `.resume()`：仅恢复播放的简写方法。

### 4.2.25 .play()

`.play()` 是 Timeline 实例方法，从当前播放头位置开始播放时间轴。

1. 语法

    ```javascript
    tl.play(fromTime, suppressEvents);
    ```
    > 提示：默认从当前播放位置继续播放；可指定跳转时间点后再播放，suppressEvents 控制跳转时是否屏蔽事件回调。

2. 属性说明
    - 参数：
        - `fromTime`【可选】：`number | string`，跳转至该时间或者标签位置，之后开始播放。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转阶段不会触发 `onStart`、`onUpdate` 等事件。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    // 从当前位置继续播放
    tl.play();

    // 跳转到标签 middle 位置，静默跳转后播放
    // tl.play("middle", true);
    ```
4. 使用要点
    1. 如果播放头已经在末尾，调用 `play()` 不会自动重播，需要使用 `.restart()`。
    2. 当时间轴处于暂停状态时，`play()` 等同于取消暂停继续运行。
    3. `suppressEvents` 适合程序驱动跳转，避免多余回调执行。
    4. 区分：
        - `.play()`：开始/继续播放，可附带跳转点位；
        - `.restart()`：重置到起点并播放；
        - `.resume()`：仅恢复播放，不能指定跳转时间。

### 4.2.26 .previousLabel()

`.previousLabel()` 是 Timeline 实例方法，获取播放头当前位置之前最近的标签名称。

1. 语法

    ```javascript
    tl.previousLabel();
    ```
    > 提示：返回小于当前播放时间的最近标签；播放头在第一个标签之前，返回 `null`。

2. 属性说明
    - 参数：无
    - 返回值：`string | null`，上一个临近标签名，不存在则返回 null。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("start", 0)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("middle", 2)
      .to(".box", { y: 200, duration: 2 })
      .addLabel("end", 4);

    tl.seek(3);
    console.log(tl.previousLabel()); // "middle"

    tl.seek(1);
    console.log(tl.previousLabel()); // "start"

    tl.seek(-0.5);
    console.log(tl.previousLabel()); // null
    ```
    4. 使用要点
    1. 匹配规则：取**小于当前播放头时间**的最近标签。
    2. 不受播放方向影响，始终基于时间轴时间数值判断。
    3. 常用于实现“跳转到上一章节”交互。
    4. 区分：
        - `.previousLabel()`：播放头前面最近标签；
        - `.currentLabel()`：播放头当前所在区间标签；
        - `.nextLabel()`：播放头后面最近标签。

### 4.2.27 .progress()

`.progress()` 是 Timeline 实例方法，用于读取或设置时间轴的播放进度（0 ~ 1）。

1. 语法

    ```javascript
    // 获取进度
    tl.progress();
    // 设置进度
    tl.progress(value, suppressEvents);
    ```

    > 提示：`0` 代表时间轴起点，`1` 代表时间轴单次播放终点；进度是相对于单次 duration，不包含 delay。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，取值范围 0~1。不传参数为读取；传入数值设置播放进度。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 时跳转不触发 `onUpdate` 等事件回调。
    - 返回值：不传参返回进度数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    console.log(tl.progress()); // 读取，默认 0

    tl.progress(0.5); // 直接跳到50%进度
    console.log(tl.progress()); // 0.5

    tl.progress(1, true); // 跳到终点，静默不触发事件
    ```
4. 使用要点
    1. progress 只代表单次动画的完成比例，不受 repeat、repeatDelay 影响。
    2. 适合进度条、拖拽控制动画的交互场景。
    3. 设置 progress 不会自动播放，仅移动播放头位置。
    4. 区分：
        - `.progress()`：0~1 归一化播放比例；
        - `.time()`：本地播放时间（单位秒）；
        - `.totalProgress()`：包含 delay、repeat 的整体归一化进度。

### 4.2.28 .recent()

`.recent()` 是 Timeline 实例方法，获取**最后添加**的子项（Tween / Timeline / Callback），不受子项在时间轴上的时间位置影响。

1. 语法

    ```javascript
    tl.recent();
    ```

    > 提示：按**添加顺序**取最新子项，不是按时间轴播放先后顺序；常用于接续上一个添加的动画来计算插入时间。

2. 属性说明
    - 参数：无
    - 返回值：`Tween | Timeline | Callback`，最近添加的子动画实例

3. 示例

    ```js
    const tl = gsap.timeline();
    // 第1个添加的动画
    tl.to(".box1", { x: 100, duration: 2 });
    // 第2个添加的动画，插入到时间0.5s位置
    tl.to(".box2", { y: 100, duration: 1 }, 0.5);
    // 在box2动画结束后3秒添加新动画，利用recent拿到刚添加的box2
    tl.to(".box3", { scale:1.2, duration:1 }, tl.recent().endTime() + 3);
    ```
4. 使用要点
    1. 只记录**添加顺序**，即使把动画插入到时间轴靠前位置，`recent()` 依然返回最后代码添加的子项。
    2. 可链式读取子项属性，例如 `tl.recent().endTime()` 获取上一个添加动画的结束时间。
    3. 时间轴为空时调用会返回 `undefined`。
    4. 区分：
        - `.recent()`：代码层面最后添加的子项；
        - `.getChildren()`：获取所有直接子项数组，按时间顺序排列。

### 4.2.29 .remove()

`.remove()` 是 Timeline 实例方法，从当前时间轴移除指定子项（Tween / Timeline / Callback），子项本身不会被销毁。

1. 语法

    ```javascript
    tl.remove(child);
    ```

    > 提示：仅将子项从 timeline 的子列表剥离，不会执行 kill；移除后的动画实例可添加到其他时间轴复用。

2. 属性说明
    - 参数：
        - `child`：`Tween | Timeline | Callback`，要移除的子动画实例
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    const boxTween = tl.to(".box", { x: 200, duration: 1 });
    const subTl = gsap.timeline();
    subTl.to(".circle", { y: 100, duration: 1 });
    tl.add(subTl);

    // 将boxTween从时间轴中移除
    tl.remove(boxTween);
    ```
4. 使用要点
    1. 移除后子项仍然保留，只是不再属于该时间轴，可通过 `add()` 添加到别的 timeline。
    2. 若子项正在播放，移除后会立即脱离当前时间轴的时间控制。
    3. 仅支持传入子项实例，不能直接传选择器字符串。
    4. 区分：
        - `.remove()`：剥离子项，实例保留可复用；
        - `.kill()`：销毁动画实例，释放资源，实例不可继续使用。

### 4.2.30 .removeLabel()

`.removeLabel()` 是 Timeline 实例方法，删除时间轴上指定名称的标签。

1. 语法

    ```javascript
    tl.removeLabel(name);
    ```

    > 提示：仅移除标签，不会删除时间轴上的动画子项；标签不存在时不会报错。

2. 属性说明
    - 参数：
        - `name`：`string`，需要删除的标签名称
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("intro", 0)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("outro", 2);

    // 删除名为 outro 的标签
    tl.removeLabel("outro");
    ```
4. 使用要点
    1. 只移除标签记录，不会修改时间轴里任何补间、回调、子时间轴。
    2. 删除后，`tl.labels` 对象中将不再包含该标签。
    3. 若传入不存在的标签名，无任何操作，不会抛出异常。
    4. 区分：
        - `.removeLabel()`：删除单个指定标签；
        - `.addLabel()`：在指定时间点新增标签。

### 4.2.31 .removePause()

`.removePause()` 是 Timeline 实例方法，移除通过 `.addPause()` 添加在时间轴指定点位的预置暂停标记。

1. 语法

    ```javascript
    tl.removePause(position);
    ```

    > 提示：仅移除预置暂停标记，不会删除该位置的动画；只对 `addPause()` 创建的暂停生效，不影响代码手动调用 `pause()`。

2. 属性说明
    - 参数：
        - `position`：`number | string`，时间点（秒）或者标签名称，代表待移除暂停标记所在位置
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      // 在1秒处添加预置暂停
      .addPause(1)
      .to(".box", { opacity: 0, duration: 1 });

    // 删除1秒位置的预置暂停标记
    tl.removePause(1);

    // 也可以传入标签名移除暂停
    // tl.removePause("stage1");
    ```
4. 使用要点
    1. 必须传入添加暂停时对应的时间/标签，无法直接删除运行时手动触发的暂停。
    2. 移除后，播放头走到该点位将不再自动暂停，动画连续播放。
    3. 指定位置不存在暂停标记时，无操作、不报错。
    4. 区分：
        - `.removePause()`：删除时间轴上预置的 `addPause()` 暂停点；
        - `.addPause()`：在时间轴某个时间点插入自动暂停标记；
        - `.pause()`：代码手动暂停播放，不属于时间轴内置暂停标记。

### 4.2.32 .repeat()

`.repeat()` 是 Timeline 实例方法，用于读取或设置时间轴的重复播放次数。

1. 语法

    ```javascript
    // 获取repeat值
    tl.repeat();
    // 设置repeat值
    tl.repeat(value);
    ```

    > 提示：repeat 代表完整循环次数；`0` 不重复，`-1` 代表无限循环。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，循环次数。不传参数为读取；传入数值设置重复次数。
    - 返回值：不传参返回 repeat 数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    tl.repeat(2); // 完整播放2次重复，总共播放3轮
    console.log(tl.repeat());

    tl.repeat(-1); // 设置无限循环
    ```
4. 使用要点
    1. repeat 计数是**额外重复次数**。repeat:2 → 播放 1(首次)+2(重复) = 3 轮动画。
    2. 设置 `-1` 会永久循环，需要手动调用 `pause()` / `kill()` 停止。
    3. 可在动画运行中动态修改 repeat 值，实时生效。
    4. 区分：
        - `.repeat()`：读写额外循环次数；
        - `.repeatDelay()`：每次循环结束后等待的间隔时长；
        - `.iteration()`：读写当前正在执行的循环索引。

### 4.2.33 .repeatDelay()

`.repeatDelay()` 是 Timeline 实例方法，用于读取或设置每次循环结束后，到下一轮循环开始前的等待时长（单位：秒）。

1. 语法

    ```javascript
    // 获取 repeatDelay 值
    tl.repeatDelay();
    // 设置 repeatDelay 值
    tl.repeatDelay(value);
    ```

    > 提示：仅在开启 repeat 循环时生效；delay 是**首次播放前**等待，repeatDelay 是**每轮循环之间**等待。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，间隔秒数。不传参数为读取；传入数值设置循环间隔。
    - 返回值：不传参返回 repeatDelay 数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    tl.repeat(2);
    tl.repeatDelay(1.5); // 每轮循环结束，等待1.5秒再开启下一轮
    console.log(tl.repeatDelay());
    ```
4. 使用要点
    1. 不会作用于第一次播放，只在每一轮循环完成后生效。
    2. 可在动画运行期间动态修改，实时更新间隔。
    3. 若 `repeat:0`（不循环），repeatDelay 设置无效。
    4. 区分：
        - `.repeatDelay()`：循环与循环之间的等待时间；
        - `.repeat()`：读写循环重复次数；
        - `.delay()`：动画首次开始前的延迟。

### 4.2.34 .restart()

`.restart()` 是 Timeline 实例方法，将播放头重置到起点并开始播放。

1. 语法

    ```javascript
    tl.restart(includeDelay, suppressEvents);
    ```

    > 提示：默认会跳过初始 delay；可通过参数控制是否启用初始延迟，suppressEvents 控制跳转阶段是否屏蔽事件回调。

2. 属性说明

    - 参数：
        - `includeDelay`【可选】：`boolean`，默认值 `false`。`true` 代表重启时保留初始 delay 等待；`false` 直接立刻开始播放。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 重置跳转过程不触发 `onStart`、`onUpdate` 等事件回调。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline({ delay: 1 });
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { y: 200, duration: 1 });

    // 重置到起点，直接播放，跳过初始delay
    tl.restart();

    // 重置并保留初始delay，静默跳转
    // tl.restart(true, true);
    ```
4. 使用要点
    1. 重启不会自动调用 `invalidate()`，元素属性缓存保留；如需重新采样DOM起始状态，要手动执行 `tl.invalidate()`。
    2. 会重置 `iteration()` 循环索引，回到第一轮。
    3. 无论动画当前是播放/暂停/播放完毕状态，都可以执行重启。
    4. 区分：
        - `.restart()`：回到起点 + 播放；
        - `.play()`：从当前位置播放，不会重置播放头；
        - `.seek(0)`：跳到起点，但不会自动播放。

### 4.2.35 .resume()

`.resume()` 是 Timeline 实例方法，恢复已暂停的时间轴，从当前播放头位置继续播放。

1. 语法

    ```javascript
    tl.resume(suppressEvents);
    ```

    > 提示：仅解除暂停状态，不能跳转播放位置；仅对处于暂停状态的时间轴生效。

2. 属性说明
    - 参数：
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 恢复播放时不触发 `onStart` 事件回调。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    tl.play();
    tl.pause();

    // 从暂停位置继续播放
    tl.resume();

    // 静默恢复，不触发onStart
    // tl.resume(true);
    ```
4. 使用要点
    1. 如果时间轴本身未暂停，调用 `resume()` 无任何效果。
    2. 和 `play()` 不同，`resume()` 不支持传入时间点/标签来跳转位置。
    3. 不会重置播放头、循环索引。
    4. 区分：
        - `.resume()`：仅解除暂停，无跳转；
        - `.play()`：可附带跳转点位然后播放；
        - `.pause()`：暂停时间轴。

### 4.2.36 .reverse()

`.reverse()` 是 Timeline 实例方法，让时间轴反向播放，从当前播放头位置往起点方向运行。

1. 语法

    ```javascript
    tl.reverse(fromTime, suppressEvents);
    ```

    > 提示：反向播放会将时间轴播放方向翻转；可可选指定跳转时间点后再反向播放，suppressEvents 控制跳转阶段是否屏蔽事件回调。

2. 属性说明

    - 参数：
        - `fromTime`【可选】：`number | string`，跳转至该时间或者标签位置，之后开始反向播放。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转阶段不会触发 `onStart`、`onUpdate` 等事件。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    tl.play();
    // 从当前位置开始反向播放
    tl.reverse();

    // 跳转到标签 middle 位置，静默跳转后反向播放
    // tl.reverse("middle", true);
    ```
4. 使用要点
    1. 若播放头已经在起点位置，调用 `reverse()` 不会自动重播，需要使用 `.restart()`。
    2. 反向播放依然遵循 `timeScale`、`repeatDelay` 等配置。
    3. 当时间轴处于暂停状态时，`reverse()` 会开启反向播放。
    4. 区分：
        - `.reverse()`：开启反向播放，可附带跳转点位；
        - `.reversed()`：读写时间轴的反向标记状态；
        - `.play()`：正向播放。


### 4.2.37 .reversed()

`.reversed()` 是 Timeline 实例方法，用于读取或设置时间轴的**反向播放标记状态**。

1. 语法

    ```javascript
    // 获取 reversed 状态
    tl.reversed();
    // 设置 reversed 状态
    tl.reversed(value);
    ```

    > 提示：`true` 代表反向模式，`false` 代表正向模式；设置后不会自动播放，仅修改播放方向标记。

2. 属性说明

    - 参数：
        - `value`【可选】：`boolean`。不传参数为读取状态；传入布尔值设置方向。
    - 返回值：不传参返回布尔状态；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    tl.play();
    console.log(tl.reversed()); // false，正向播放

    tl.reversed(true); // 切换为反向模式
    console.log(tl.reversed()); // true
    ```
4. 使用要点
    1. 仅修改方向标记，不会自动开始播放；如需立刻反向播放，可配合 `.play()` 或者使用 `.reverse()`。
    2. 改变 reversed 不会移动当前播放头位置。
    3. 反向模式下，动画会从当前播放位置向时间起点推进。
    4. 区分：
        - `.reversed()`：读写方向状态（getter/setter）；
        - `.reverse()`：方法，切换为反向并支持跳转点位。

### 4.2.38 .revert()

`.revert()` 是 Timeline 实例方法，将动画目标元素恢复到**动画执行前原始状态**，移除动画新增的行内样式，并销毁当前时间轴。

1. 语法

    ```javascript
    tl.revert();
    ```

    > 提示：GSAP 3.11.0 新增；内部会执行 kill，执行后时间轴不可再播放；会清除动画添加的 inline style，区别于单纯 `progress(0)`。

2. 属性说明
    - 参数：无
    - 返回值：当前 Timeline 实例，支持链式调用。
3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });

    // 恢复元素原始状态，移除动画行内样式，销毁timeline
    tl.revert();
    ```
4. 使用要点
    1. 恢复的是**动画创建那一刻**记录的DOM原始样式，并且删除由该动画新增的行内样式。
    2. 执行后时间轴被kill，`play()` / `seek()` 等方法不再可用。
    3. 适合组件销毁、动画卸载清理场景。
    4. 区分：
        - `.revert()`：还原DOM样式、移除inline样式、kill实例；
        - `.kill()`：仅销毁动画，不会清理行内样式，元素保持动画结束时样式；
        - `progress(0)`：回到起点数值，但保留行内样式，不会销毁实例。

### 4.2.39 .seek()

`.seek()` 是 Timeline 实例方法，将播放头直接跳转到指定的时间点/标签位置，**不会自动播放**。

1. 语法

    ```javascript
    tl.seek(time, suppressEvents);
    ```

    > 提示：仅移动播放头，不改变暂停/播放状态；支持秒数或标签名作为目标位置。

2. 属性说明
    - 参数：
        - `time`：`number | string`，目标时间（秒）或者标签名称。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转过程不触发 `onUpdate`、`onStart` 等事件回调。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("mid", 2)
      .to(".box", { x: 200, duration: 2 })
      .to(".box", { y: 200, duration: 2 });

    // 跳转到2秒位置
    tl.seek(2);

    // 跳转到标签 mid，静默跳转不触发事件
    // tl.seek("mid", true);
    ```

4. 使用要点
    1. `seek()` 只是定位播放头，不会启动播放；如需跳转后自动播放，使用 `.play(time)`。
    2. 超出时间轴范围的值会被钳位到 0 ~ 总时长之间。
    3. 常用于拖拽进度条、点击标签跳转等交互场景。
    4. 区分：
        - `.seek()`：仅跳转播放头，不自动播放；
        - `.play(fromTime)`：跳转 + 开始播放；
        - `.progress()`：按 0~1 比例跳转播放头。

### 4.2.40 .set()

`.set()` 是 Timeline 实例方法，在时间轴指定位置设置目标属性，**无过渡动画（瞬时生效）**，本质是零时长补间。

1. 语法

    ```javascript
    tl.set(target, vars, position);
    ```

    > 提示：不产生动画过渡，直接设置样式/属性；可接收位置参数控制在时间轴的插入点位。

2. 属性说明

    - 参数：
        - `target`：`string | object | array`，动画目标，DOM元素选择器、对象或数组。
        - `vars`：`object`，要设置的属性集合。
        - `position`【可选】：`number | string`，插入时间位置，支持数字、`"+=1"`、`"-=1"` 相对时间。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    // 在时间0秒直接设置x与opacity，无动画
    tl.set(".box", { x: 100, opacity: 0.5 });
    // 在2秒位置瞬时设置属性
    tl.set(".box", { scale: 1.5 }, 2);
    // 在上一个子项结束后0.5s设置
    // tl.set(".box", { rotation: 90 }, "+=0.5");
    ```
4. 使用要点
    1. `set` 是 duration=0 的 tween，不会产生插值过渡，属性瞬间生效。
    2. 常用于动画前置初始化状态、瞬间切换视觉状态。
    3. 位置参数规则和 `to()` / `from()` 完全一致。
    4. 区分：
        - `.set()`：瞬时设置属性，无动画；
        - `.to()`：带过渡动画，从当前值变化到目标值；
        - `.from()`：带过渡动画，从目标值变化到当前值。

### 4.2.41 .shiftChildren()

`.shiftChildren()` 是 Timeline 实例方法，批量移动时间轴内所有子项（Tween/Timeline）的起始时间，整体偏移。

1. 语法

    ```javascript
    tl.shiftChildren(amount, adjustLabels, shiftLabels);
    ```

    > 提示：批量平移全部子项的开始时间；可选择同步移动标签，常用于整体拉长/前移一段动画序列。

2. 属性说明

    - 参数：
        - `amount`：`number`，偏移秒数。正数向后推迟，负数向前提前。
        - `adjustLabels`【可选】：`boolean`，默认值 `false`。`true` 时，标签会跟随子项边界自动适配。
        - `shiftLabels`【可选】：`boolean`，默认值 `false`。`true` 时所有标签一起偏移 `amount`。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box1", { x: 100, duration: 1 })
      .to(".box2", { y: 100, duration: 1 }, 1);

    // 所有子项整体向后推迟0.5秒，标签也一起偏移
    tl.shiftChildren(0.5, false, true);
    ```
4. 使用要点
    1. 仅修改子项在时间轴上的**起始时间**，不会修改子项本身时长。
    2. 负数偏移会把子项往前挪，注意不要让子项起始时间小于0。
    3. 仅作用于直接子项，嵌套子Timeline内部的子元素不会单独偏移。
    4. 区分：
        - `.shiftChildren()`：批量平移全部直接子项；
        - 单独修改单个子项 `startTime()`：只移动某一个子动画。

### 4.2.42 .startTime()

`.startTime()` 是 Timeline 实例方法，用于读取或设置该时间轴在**父级时间轴内的开始时间**。

1. 语法

    ```javascript
    // 获取 startTime
    tl.startTime();
    // 设置 startTime
    tl.startTime(value);
    ```
    > 提示：如果该 Timeline 是根时间轴（没有父级），startTime 固定为0；修改它只会改变它在父Timeline中的排布位置，不会修改内部子项相对时间。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，时间秒数。不传参数为读取；传入数值设置开始时间。
    - 返回值：不传参返回时间数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const parentTl = gsap.timeline();
    const childTl = gsap.timeline();
    childTl.to(".box", { x: 200, duration: 1 });

    parentTl.add(childTl);
    console.log(childTl.startTime()); // 0

    // 将子时间轴在父级中延后1.5秒开始
    childTl.startTime(1.5);
    ```
4. 使用要点
    1. `startTime` 是**相对于父容器**的时间，不是子Timeline内部的本地时间。
    2. 修改后仅移动这个timeline整体，内部所有子动画之间的相对时序保持不变。
    3. 根Timeline不存在父级，设置 startTime 无效。
    4. 区分：
        - `.startTime()`：当前实例在父时间轴的起始位置；
        - `.duration()`：当前时间轴自身总时长；
        - `.shiftChildren()`：移动当前timeline**内部**所有子项。

### 4.2.43 .then()

`.then()` 是 Timeline 实例方法，返回 Promise，在时间轴**正常完成**时触发回调，支持异步 await。

1. 语法

    ```javascript
    tl.then(onFulfilled, onRejected);
    ```

    > 提示：GSAP Timeline 实现了 Promise 接口；当动画被 `kill()` / `revert()` 中断时 Promise 会 reject；循环动画（repeat:-1）永远不会 resolve。

2. 属性说明

    - 参数：
        - `onFulfilled`【可选】：`Function`，动画正常播放完成后的回调函数。
        - `onRejected`【可选】：`Function`，动画被中断、kill 时的拒绝回调函数。
    - 返回值：`Promise` 对象

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });

    tl.then(() => {
      console.log("timeline 播放完成");
    }).catch((err) => {
      console.log("动画被中断", err);
    });

    // 也可配合 await
    // await tl;
    // console.log("播放结束");
    ```
4. 使用要点
    1. 当设置 `repeat > 0`，会在**所有循环全部结束**后才 resolve。
    2. 反向播放（reversed）播放到起点也视为完成，触发 resolve。
    3. `seek()`、`pause()` 单纯暂停跳转**不会**触发 reject；只有 `kill()` / `revert()` 才会 reject promise。
    4. 区分：
        - `.then()`：Promise 风格，用于异步等待动画完成；
        - `onComplete`：timeline 配置里的回调选项，属于同步回调；
        - `.catch()`：捕获动画中断 reject 场景。

### 4.2.44 .time()

`.time()` 是 Timeline 实例方法，用于读取或设置时间轴**本地当前播放时间（单位秒）**。

1. 语法

    ```javascript
    // 获取当前本地时间
    tl.time();
    // 设置本地时间
    tl.time(value, suppressEvents);
    ```

    > 提示：代表时间轴内部本地时间，不受 `timeScale` 影响；区别于 `totalTime()`。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，目标本地时间（秒）。不传参数为读取；传入数值设置播放时间。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转过程不触发 `onUpdate`、`onStart` 等事件回调。
    - 返回值：不传参返回时间数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });

    console.log(tl.time()); // 读取当前本地时间

    tl.time(1.2); // 设置本地播放时间到1.2秒

    // 静默跳转，不触发事件
    // tl.time(0.5, true);
    ```
4. 使用要点
    1. `time()` 只看单次动画的本地时间，不包含 `repeatDelay` 和重复循环的累计时长。
    2. 修改 `time()` 会直接移动播放头，行为类似 `seek()`。
    3. 超出 `duration()` 的值会被钳位到 `0 ~ duration`。
    4. 区分：
        - `.time()`：单次动画本地时间，不含循环与repeatDelay；
        - `.totalTime()`：包含循环、repeatDelay 的完整总时间；
        - `.progress()`：0~1归一化进度。

### 4.2.45 .timeScale()

`.timeScale()` 是 Timeline 实例方法，用于读取或设置时间轴的播放速率。

1. 语法

    ```javascript
    // 获取 timeScale 值
    tl.timeScale();
    // 设置 timeScale 值
    tl.timeScale(value);
    ```

    > 提示：`1` 为正常速度；大于1加速，小于1减速；可动态修改，实时生效。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，播放倍率。不传参数为读取；传入数值设置播放速度。
    - 返回值：不传参返回倍率数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });

    tl.timeScale(0.5); // 减速，0.5倍速
    console.log(tl.timeScale());

    tl.timeScale(2); // 加速，2倍速
    ```
4. 使用要点
    1. 倍率会递归作用于内部所有子Tween、子Timeline。
    2. 不会改变 `duration()` 数值，只改变实际播放耗时。
    3. 支持动态在动画运行中修改，立刻生效。
    4. 区分：
        - `.timeScale()`：修改播放速度；
        - `.time()`：读写本地播放时间；
        - `.seek()`：跳转播放头位置，不改变速率。

### 4.2.46 .to()

`.to()` 是 Timeline 实例方法，向时间轴添加一个**正向过渡补间**，从目标当前属性值动画变化到设置的目标属性。

1. 语法

    ```javascript
    tl.to(target, vars, position);
    ```

    > 提示：最常用的动画方法；自动读取元素当前状态作为动画起始值，过渡到vars里定义的目标值。

2. 属性说明

    - 参数：
        - `target`：`string | object | array`，动画目标，DOM选择器、对象或对象数组。
        - `vars`：`object`，动画配置对象，包含目标属性、duration、ease等。
        - `position`【可选】：`number | string`，插入位置，支持绝对秒数、`"+=n"`/`"-=n"`相对时间。
    - 返回值：当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    // 从当前位置移动到x:200，时长1秒
    tl.to(".box", { x: 200, duration: 1 });
    // 在上一个动画结束后额外延迟0.5s再执行
    tl.to(".box", { opacity: 0, duration: 1 }, "+=0.5");
    ```
4. 使用要点
    1. 自动采集动画执行瞬间目标的初始属性，无需手动写起始值。
    2. `position` 相对时间语法：`"+=1"` 在上一个子项结束后等待1s；`"-=1"` 和上一个子项重叠1s。
    3. vars内可配置ease、delay、onComplete等补间参数。
    4. 区分：
        - `.to()`：当前值 → 目标值
        - `.from()`：目标值 → 当前值
        - `.fromTo()`：自定义起始值与结束值

### 4.2.47 .totalDuration()

`.totalDuration()` 是 Timeline 实例方法，用于读取或设置包含循环、repeatDelay在内的**完整总时长（单位秒）**。

1. 语法

    ```javascript
    // 获取 totalDuration
    tl.totalDuration();
    // 设置 totalDuration
    tl.totalDuration(value);
    ```

    > 提示：`duration()` 是单次播放时长；`totalDuration()` 会把 repeat、repeatDelay 全部纳入计算。

2. 属性说明
    - 参数：
        - `value`【可选】：`number`，目标总时长。不传参数为读取；传入数值会自动缩放 timeScale 来匹配目标总时长。
    - 返回值：不传参返回时长数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });
    tl.repeat(2);
    tl.repeatDelay(0.5);

    console.log(tl.duration()); // 单次时长 2
    console.log(tl.totalDuration()); // 2 + (2 + 0.5)*2 = 7
    tl.totalDuration(10); // 自动调整timeScale，让完整总时长等于10秒
    ```
4. 使用要点
    1. 计算公式：`totalDuration = duration + (duration + repeatDelay) * repeat`。
    2. 当 `repeat:-1`（无限循环），`totalDuration()` 返回 `Infinity`。
    3. 赋值修改 totalDuration 不会改变内部子项时序，只会修改 `timeScale` 整体缩放播放速度。
    4. 区分：
        - `.totalDuration()`：包含repeat、repeatDelay 的全部总时长；
        - `.duration()`：单次一轮动画的基础时长，不包含循环；
        - `.totalTime()`：当前播放头对应的累计总时间。

### 4.2.48 .totalProgress()

`.totalProgress()` 是 Timeline 实例方法，用于读取或设置**包含所有循环、repeatDelay 的整体归一化进度**，取值范围 `0 ~ 1`。

1. 语法

    ```javascript
    // 获取 totalProgress
    tl.totalProgress();
    // 设置 totalProgress
    tl.totalProgress(value, suppressEvents);
    ```

    > 提示：`totalProgress` 对应 `totalDuration` 的进度；而 `progress` 仅为单次一轮动画的进度。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，进度值（0~1）。不传参数为读取；传入数值跳转播放头。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转过程不触发 `onUpdate`、`onStart` 等事件回调。
    - 返回值：不传参返回进度数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });
    tl.repeat(2);
    tl.repeatDelay(0.5);

    console.log(tl.totalProgress());
    tl.totalProgress(0.5); // 跳转到全部完整动画的50%位置
    // tl.totalProgress(0.5, true); // 静默跳转
    ```

4. 使用要点
    1. 进度 `0` 代表整个完整动画起点，`1` 代表全部循环+repeatDelay 播放完毕。
    2. 支持超出0~1范围赋值，数值会自动钳位。
    3. 无限循环 `repeat:-1` 时，`totalProgress` 不可用，因为 `totalDuration` 为无穷大。
    4. 区分：
        - `.totalProgress()`：包含循环、repeatDelay 的全局总进度；
        - `.progress()`：仅当前单轮动画的进度；
        - `.totalTime()`：对应的总时间（秒）而非0~1比例。

### 4.2.49 .totalTime()

`.totalTime()` 是 Timeline 实例方法，用于读取或设置包含循环、repeatDelay 的**累计总播放时间（单位秒）**。

1. 语法

    ```javascript
    // 获取 totalTime
    tl.totalTime();
    // 设置 totalTime
    tl.totalTime(value, suppressEvents);
    ```

    > 提示：`totalTime` 是包含所有循环与循环间隔的全局时间；`time()` 仅代表单轮内本地时间。

2. 属性说明

    - 参数：
        - `value`【可选】：`number`，目标累计总时间（秒）。不传参数为读取；传入数值跳转播放头。
        - `suppressEvents`【可选】：`boolean`，默认值 `false`。`true` 跳转过程不触发 `onUpdate`、`onStart` 等事件回调。
    - 返回值：不传参返回时间数值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
      .to(".box", { opacity: 0, duration: 1 });
    tl.repeat(1);
    tl.repeatDelay(0.5);

    console.log(tl.totalTime());
    tl.totalTime(2.5); // 跳转到全局总时间2.5秒位置
    // tl.totalTime(2.5, true); // 静默跳转，不触发回调事件
    ```
4. 使用要点
    1. 当动画多次循环，`totalTime` 会叠加每一轮动画时长和 `repeatDelay`。
    2. 赋值会直接定位播放头到全局时间点，超出 `totalDuration` 的值会被钳位。
    3. 无限循环 `repeat:-1` 时，`totalTime` 可以持续无限增长。
    4. 区分：
        - `.totalTime()`：包含循环、repeatDelay 的全局累计时间；
        - `.time()`：仅当前单轮动画内部本地时间；
        - `.totalProgress()`：总时间对应的0~1归一化进度。


### 4.2.50 .tweenFromTo()

`.tweenFromTo()` 是 Timeline 实例方法，创建一个临时补间，**在当前时间轴内从一个时间点平滑动画到另一个时间点**，常用于 scrub 时间轴播放头。

1. 语法

    ```javascript
    tl.tweenFromTo(fromTime, toTime, vars);
    ```

    > 提示：返回一个 Tween 实例；fromTime / toTime 支持数字（秒）或标签名；用来平滑驱动时间轴播放头在两个点位之间移动。

2. 属性说明
    - 参数：
        - `fromTime`：`number | string`，起始位置，秒数或标签名称。
        - `toTime`：`number | string`，结束位置，秒数或标签名称。
        - `vars`【可选】：`object`，补间配置（duration、ease、onUpdate 等）。
    - 返回值：Tween 实例

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("start", 0)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("end", 2);

    // 从标签start平滑过渡到end，时长1秒
    const scrubTween = tl.tweenFromTo("start", "end", {
      duration: 1,
      ease: "power2.inOut"
    });
    ```

4. 使用要点
    1. 本质是生成一个独立补间，在执行过程中持续修改 timeline 的 `time`。
    2. `fromTime` 大于 `toTime` 时，会反向移动播放头。
    3. 此补间和 timeline 相互独立，kill 原 timeline 不会自动 kill 这个 tween。
    4. 区分：
        - `.tweenFromTo()`：生成补间，平滑驱动播放头在两点间滑动；
        - `.seek()`：直接瞬间跳转播放头，无过渡动画；
        - `.tweenTo()`：只指定终点，从当前播放头位置平滑过渡到目标点。


### 4.2.51 .tweenTo()

`.tweenTo()` 是 Timeline 实例方法，创建临时补间，**从当前播放头位置平滑动画到目标时间点/标签**，常用于拖拽、滚动驱动播放头。

1. 语法

    ```javascript
    tl.tweenTo(toTime, vars);
    ```

    > 提示：返回 Tween 实例；toTime 支持秒数或标签名；只需要传入终点，起点自动取 timeline 当前播放位置。

2. 属性说明
    - 参数：
        - `toTime`：`number | string`，目标位置，秒数或标签名称。
        - `vars`【可选】：`object`，补间配置（duration、ease、onUpdate 等）。
    - 返回值：Tween 实例

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.addLabel("mid", 1)
      .to(".box", { x: 200, duration: 2 })
      .addLabel("end", 2);

    // 从当前播放位置平滑过渡到标签mid，时长0.8秒
    const scrubTween = tl.tweenTo("mid", {
      duration: 0.8,
      ease: "power3.out"
    });
    ```
4. 使用要点
    1. 生成独立Tween，运行期间持续更新 timeline 的 `time`。
    2. 目标位置小于当前播放头时，自动反向滑动播放头。
    3. 该补间独立于原timeline，kill timeline 不会自动销毁这个tween。
    4. 区分：
        - `.tweenTo()`：起点为当前播放头，平滑移动到目标点位
        - `.tweenFromTo()`：手动指定起点与终点，两点之间平滑过渡
        - `.seek()`：瞬时跳转播放头，没有过渡动画

### 4.2.52 .yoyo()

`.yoyo()` 是 Timeline 实例方法，用于读取或设置 yoyo 开关；开启后，每一轮循环播放完成后会**反向回放**，往复运动。

1. 语法

    ```javascript
    // 获取 yoyo 值
    tl.yoyo();
    // 设置 yoyo 值
    tl.yoyo(value);
    ```

    > 提示：仅在 `repeat > 0` 时生效；yoyo 不改变总时长，只改变循环播放方向。

2. 属性说明
    - 参数：
        - `value`【可选】：`boolean`。不传参数为读取；传入布尔值开启/关闭yoyo。
    - 返回值：不传参返回布尔值；传入参数返回当前 Timeline 实例，支持链式调用。

3. 示例

    ```js
    const tl = gsap.timeline();
    tl.to(".box", { x: 200, duration: 1 })
    tl.repeat(2);
    tl.yoyo(true); // 开启往复，正向→反向→正向

    console.log(tl.yoyo());
    ```
4. 使用要点
    1. yoyo 只影响循环的下一轮播放方向，首轮永远正向播放。
    2. 开启 yoyo 后，`repeat` 计数依然代表额外重复次数。`repeat:2, yoyo:true`：正向 → 反向 → 正向。
    3. 可在动画运行中动态修改，实时生效。
    4. 区分：
        - `.yoyo()`：控制循环是否折返反向播放；
        - `.repeat()`：设置循环重复次数；
        - `.reversed()`：全局固定播放方向，和循环yoyo无关。
