# 五、css插件

CSSPlugin 内置在 GSAP 核心包，无需额外引入；**不需要写`css:{}`包装层**，直接写 CSS 属性即可做动画

## 5.1 普通CSS属性动画

### 5.1.1 css属性介绍

1. 命名规则

    - 短横线CSS属性转为**小驼峰**：`background‑color` → `backgroundColor`，`font‑size` → `fontSize`
    - 支持绝大多数可动画CSS属性；也支持部分原生CSS不可动画属性。

    ```js
    gsap.to(element, {
      backgroundColor: "red",
      fontSize: 12,
      boxShadow: "0px 0px 20px 20px red",
      borderRadius: "50% 50%",
      height: "auto" // auto ↔ px 之间动画
    })
    ```

2. 不可动画属性行为

    > 例如`position:"absolute"`、`borderStyle:"solid"`这类属性没有中间插值状态
    1. 大部分：**在动画开始瞬间直接赋值生效**
    2. `display:"none"`：在**动画结束时**才生效
    3. 像`background‑image`属于二元属性，无法插值过渡；布局类复杂属性交给 **FLIP插件** 处理

3. 复杂字符串 & 单位

    - 支持`boxShadow`、`borderRadius`、`border`这类复合字符串动画，自动处理浏览器前缀
    - 单位默认值：
        - `x/y`默认`px`；`rotation`默认`deg`
        - 自定义单位用字符串包裹：`x:"20vw"`、`rotation:"1.25rad"`
    - GSAP自动做单位转换，例如直接从`width:"50%"`过渡到`width:"200px"`

### 5.1.2 完整实例

- 代码示例

    ```html
    <!DOCTYPE html>
    <html lang="zh-CN">
    <head>
      <meta charset="UTF-8">
      <title>GSAP CSSPlugin Demo</title>
      <style>
        .box {
          width: 100px;
          height: 100px;
          background: #3388ff;
          margin: 30px;
          padding: 10px;
        }
      </style>
    </head>
    <body>
      <div class="box">测试盒子</div>
      <button id="runBtn">执行动画</button>

      <script src="../js/gsap.min.js"></script>
      <script>
        const box = document.querySelector('.box');
        const runBtn = document.querySelector('#runBtn');

        runBtn.addEventListener('click', () => {
          gsap.to(box, {
            // 1. 普通CSS属性，小驼峰命名，不需要 css:{}
            backgroundColor: "red",
            fontSize: 12,
            boxShadow: "0px 0px 20px 20px red",
            borderRadius: "50% 50%",
            height: "auto", // auto 和 px 之间动画

            // 2. 带不同单位，GSAP自动单位换算
            width: "200px",
            x: "10vw", // 自定义单位

            // 3. 不可插值属性（无中间过渡，直接赋值）
            position: "absolute", // 动画开始瞬间生效

            // 4. display: none 动画结束瞬间才生效
    ```

## 5.2 Transform变换

> 不要手写`transform:"translate(…)"`字符串；使用GSAP内置别名，性能更高、变换顺序固定一致

### 5.2.1 2D变换简写对照表

| GSAP属性 | 等价CSS transform |
|---|---|
| `x:100` | `translateX(100px)` |
| `y:100` | `translateY(100px)` |
| `xPercent:50` | `translateX(50%)`（相对于元素自身宽度） |
| `yPercent:50` | `translateY(50%)`（相对于元素自身高度） |
| `scale:2` | `scale(2)` |
| `scaleX:2` | `scaleX(2)` |
| `scaleY:2` | `scaleY(2)` |
| `rotation:90` | `rotate(90deg)` |
| `skew:30` | `skew(30deg)` |
| `skewX:30` | `skewX(30deg)` |
| `skewY:30` | `skewY(30deg)` |

> 注意：
> - 百分比位移请用`xPercent/yPercent`，而不是`x/y`（x/y默认px）
> - 属性书写顺序不影响最终变换结果；GSAP固定执行顺序：`x,y,z → scale → rotationX → rotationY → skew → rotation(Z)`
> - 支持相对值：`rotation:"+=30"`

### 5.2.3 3D变换

1. 属性：`rotationX` / `rotationY` / `rotationZ`（等同于`rotation`） / `z`

    ```js
    gsap.to(element, {
        duration:2,
        rotationX:45,
        scaleX:0.8,
        z:-300
    })
    ```

2. 透视 perspective

    1. **父容器设置`perspective:500`**：一组元素共享同一个消失点（推荐）
 
        ```js
        gsap.set(container, {perspective:500})
        ```
    2. **单个元素`transformPerspective:500`**：等价于CSS `transform:perspective(500px) …`，仅作用于当前元素
    
        > 值越小透视扭曲越强，常用区间200‑1000

3. force3D

    - 默认`force3D:"auto"`：动画期间自动启用`translate3d`提升到GPU合成层；动画结束切回2D释放显存
    - `force3D:true`：强制保持3D模式
    - `force3D:false`：尽量使用2D变换

4. transformOrigin 变换原点

    支持关键词`"left top"`、px、百分比；还支持3D原点第三个参数。

    ```js
    //围绕左上角旋转
    gsap.to(el, {duration:2, rotation:360, transformOrigin:"left top"})
    //3D原点
    gsap.to(el, {rotationY:360, transformOrigin:"50% 50% -400px"})
    ```

## 5.3 SVG专属变换


1. **`svgOrigin`**：仅SVG元素；使用SVG画布**全局坐标系**，而不是元素本地坐标系；不能和`transformOrigin`同时使用，不支持百分比。
    ```js
    gsap.to(svgEl, {duration:1, rotation:270, svgOrigin:"250 100"})
    ```
2. **`smoothOrigin`**：解决修改原点时SVG元素“跳动”问题，默认开启。

    ```js
    //单动画关闭
    gsap.to(svgEl, {rotation:180, smoothOrigin:false})
    //全局关闭
    CSSPlugin.defaultSmoothOrigin = false
    ```

## 5.4 旋转方向控制

1. 介绍

    > 给旋转值字符串加后缀控制旋转方向，不需要引入额外插件；支持`rotation` / `rotationX` / `rotationY`

    - `_cw`：顺时针
    - `_ccw`：逆时针
    - `_short`：走角度最短路径

    ```js
    gsap.to(el, {
        duration:2,
        rotation:"-170_short",
        rotationX:"-=30_cw",
        rotationY:"1.5rad_ccw"
    })
    ```

## 5.5 特殊工具属性

1. autoAlpha

    - 等于 `opacity` + `visibility`组合。
    - `autoAlpha:0`：opacity过渡到0，同时设置`visibility:hidden`，阻止元素接收鼠标交互；
    - `autoAlpha:1`：opacity过渡到1，`visibility:inherit`（继承父级，不强制设visible）
    
    ```js
    // 淡出隐藏
    gsap.to(el, { duration:2, autoAlpha:0 })
    // 延迟2秒淡入显示
    gsap.to(el, { duration:2, autoAlpha:1, delay:2 })
    ```

2. clearProps

    动画结束后移除元素上对应的行内 style，防止行内样式覆盖 CSS class。

    - `clearProps:"all"`：清除所有行内样式
    - 注意：只要清除任意 transform 属性（scale / x / y / rotation），就会整体清除全部 transform

    ```js
    gsap.from(el, {
        duration:5,
        scale:0,
        left:200,
        backgroundColor:"red",
        clearProps:"scale,left"
    })
    ```

3. autoRound

    对 px、zIndex 数值自动四舍五入取整，优化渲染性能。

    - 默认：`autoRound:true` 开启
    - `autoRound:false` 关闭自动取整；精细像素对齐场景，搭配 SnapPlugin 使用

    ```js
    // 关闭自动取整，保留小数像素
    gsap.to(el, {
        duration:2,
        x: 123.45,
        autoRound: false
    })
    ```
