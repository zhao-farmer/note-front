# 三、layout插件

## 3.1 @pixi/layout介绍

**PixiJS官方Userland库，不是内置，需要单独安装，基于Yoga引擎实现CSS‑Flexbox布局。**


1. 核心是什么

    `@pixi/layout` 给PixiJS的Container/Sprite/Text增加**网页Flexbox能力**：

    - 支持 `flexDirection、justifyContent、alignItems、gap、flexGrow、padding、borderRadius、overflow:scroll` 这些CSS熟悉属性
    - 自动计算子元素 x/y/size，不用你手写大量 `child.x=xxx`
    - 支持滚动容器（overflow:scroll，自带鼠标滚轮/触摸滚动），可以做列表、轨道面板、侧边栏
    - 版本：**v3 专门适配 Pixi‑JS v8**，2025年大版本重写，TypeScript完整类型

2. 官网地址

    官网：[https://pixijs.io/layout/](https://pixijs.io/layout/)
    github: [https://github.com/pixijs/layout](https://github.com/pixijs/layout)

3. 安装插件

    ```sh
    # 安装 pixi8
    npm install @pixi/layout
    ```

## 3.2 示例代码

### 3.2.1 最简单横向布局

1. 代码示例

    ```vue
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application,Container,Graphics } from 'pixi.js'
    import '@pixi/layout';

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      // 1. 创建 Pixi 应用
      app = new Application();
      await app.init({
        width: 500,
        height: 300,
        backgroundColor: 0x111,
      })
      pixiContainer.value.appendChild(app.canvas)

      // 2. 创建布局根容器
      const layout = new Container({
        layout: {
          flexDirection: 'row',
          gap: 20,
          padding: 20,
          alignItems: 'center',
        }
      })
      app.stage.addChild(layout)
      layout.x = 50
      layout.y = 50

      // 3. 添加红色方块
      const rect1 = new Graphics()
      rect1.layout = true
      rect1.rect(0, 0, 80, 80)
      rect1.fill(0xff3333)
      layout.addChild(rect1)

      // 4. 添加蓝色方块
      const rect2 = new Graphics()
      rect2.layout = true
      rect2.rect(0, 0, 120, 60)
      rect2.fill(0x3366ff)
      layout.addChild(rect2)
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null         // 必须置空！非常关键
    })
    </script>
    ```

### 3.2.3 响应式布局 flexGrow

1. 代码示例

    ```vue
    <template>
      <div ref="pixiContainer" style="width: 600px; height: 300px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Container, Graphics } from 'pixi.js'
    import '@pixi/layout';

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application();
      await app.init({
        width: 600,
        height: 300,
        backgroundColor: 0x111,
      })
      pixiContainer.value.appendChild(app.canvas)

      const root = new Container({
        layout: {
          flexDirection: 'row',
          width: 500,
          height: 200,
          gap: 10,
          padding: 10,
        }
      })
      app.stage.addChild(root)
      root.x = 50
      root.y = 50

      const left = new Container({
        layout: { width: 120 }
      })
      const g1 = new Graphics()
      g1.rect(0, 0, 120, 180)
      g1.fill(0x666666)
      left.addChild(g1)

      // 右侧容器，自动填充剩余空间
      const right = new Container({
        layout: { flexGrow: 1 }
      })
      const g2 = new Graphics()
      g2.rect(0, 0, 100, 180)
      g2.fill(0x33ccff)
      right.addChild(g2)

      root.addChild(left, right)
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 3.2.4 嵌套布局（卡片横向排列）

1. 代码示例

    ```vue
   <template>
      <div ref="pixiContainer" style="width: 700px; height: 400px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Container, Graphics, Text } from 'pixi.js'
    import '@pixi/layout';

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application();
      await app.init({
        width: 700,
        height: 400,
        backgroundColor: 0x111,
      })
      pixiContainer.value.appendChild(app.canvas)

      const root = new Container({
        layout: {
          flexDirection: 'column',
          width: 600,
          height: 300,
          gap: 15,
          padding: 20,
        }
      })
      app.stage.addChild(root)
      root.x = 50
      root.y = 50

      const title = new Text({
        text: '嵌套卡片布局',
        style: { fontSize: 26, fill: 0xffffff },
        layout: { marginBottom: 20 }
      })
      root.addChild(title)

      const row = new Container({
        layout: {
          flexDirection: 'row',
          gap: 20,
          flexGrow: 1,
          alignItems: 'stretch',
        }
      })
      root.addChild(row)

      const card1 = new Container({ layout: { flexGrow:1 } })
      const g1 = new Graphics()
      g1.rect(0,0,180,180)
      g1.fill(0xff6666)
      card1.addChild(g1)
      card1.addChild(new Text({ text:'卡片1', style:{ fill:'#fff' } }))

      const card2 = new Container({ layout: { flexGrow:1 } })
      const g2 = new Graphics()
      g2.rect(0,0,180,180)
      g2.fill(0x66ff66)
      card2.addChild(g2)
      card2.addChild(new Text({ text:'卡片2', style:{ fill:'#222' } }))

      const card3 = new Container({ layout: { flexGrow:1 } })
      const g3 = new Graphics()
      g3.rect(0,0,180,180)
      g3.fill(0x6666ff)
      card3.addChild(g3)
      card3.addChild(new Text({ text:'卡片3', style:{ fill:'#fff' } }))

      row.addChild(card1, card2, card3)
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 3.2.5 头部 + 侧边栏 + 内容 + 底部

1. 代码示例

    ```vue
   <template>
      <div ref="pixiContainer" style="width: 800px; height: 500px;"></div>
    </template>
    
    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Container, Graphics, Text } from 'pixi.js'
    import '@pixi/layout';
    
    const pixiContainer = ref(null)
    let app = null
    
    onMounted(async () => {
      app = new Application();
      await app.init({
        width: 800,
        height: 500,
        backgroundColor: 0x111,
      })
      pixiContainer.value.appendChild(app.canvas)
    
      const root = new Container({
        layout: {
          flexDirection: 'column',
          width: 750,
          height: 450,
          gap: 0,
        }
      })
      app.stage.addChild(root)
      root.x = 25
      root.y = 25
    
      // 头部
      const header = new Container({ layout: { height:60 } })
      const bgHeader = new Graphics()
      bgHeader.rect(0,0,750,60)
      bgHeader.fill(0x2c3e50)
      header.addChild(bgHeader)
      header.addChild(new Text({
        text:'头部导航',
        style:{ fontSize:24, fill:'#fff' },
        position: { x:20, y:15 }
      }))
    
      // 中间
      const middle = new Container({
        layout: { flexDirection:'row', flexGrow:1 }
      })
    
      const sidebar = new Container({ layout: { width:120 } })
      const bgSide = new Graphics()
      bgSide.rect(0,0,120,330)
      bgSide.fill(0x34495e)
      sidebar.addChild(bgSide)
      sidebar.addChild(new Text({ text:'侧边栏', style:{ fill:'#fff' }, position:{x:10,y:10} }))
    
      const content = new Container({
        layout: { flexGrow:1, padding:20 }
      })
      const bgContent = new Graphics()
      bgContent.rect(0,0,610,290)
      bgContent.fill(0xecf0f1)
      content.addChild(bgContent)
      content.addChild(new Text({
        text:'主内容区域',
        style:{ fontSize:22, fill:'#222' },
        position: { x:10, y:10 }
      }))
    
      middle.addChild(sidebar, content)
    
      // 底部
      const footer = new Container({ layout: { height:60 } })
      const bgFooter = new Graphics()
      bgFooter.rect(0,0,750,60)
      bgFooter.fill(0x2c3e50)
      footer.addChild(bgFooter)
      footer.addChild(new Text({
        text:'底部信息',
        style:{ fill:'#fff' },
        position: { x:20, y:20 }
      }))
    
      root.addChild(header, middle, footer)
    })
    
    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```
