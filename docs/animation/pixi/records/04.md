# 四、UI插件

## 4.1 @pixi/ui 介绍


一套**预制交互UI组件库**，在Pixi画布内直接生成按钮、滑块、输入框、滚动列表、复选框、进度条等交互控件，全部跑在WebGL/WebGPU画布内，不是DOM HTML。


1. 核心是什么

    PixiJS内核只负责渲染，**原生没有任何交互UI控件**：
    1. 不用自己手写：按钮hover/按下状态、点击事件、滑块拖拽、滚动容器、输入框逻辑。
    2. 所有UI直接在Pixi画布内渲染，和画布内图形（你的轨道、素材）深度融合，不会出现DOM和WebGL层级错位问题。
    3. 组件自带交互事件、状态管理（normal/hover/pressed/disabled）。

    > 内置组件清单：
    `Button、FancyButton、Slider、DoubleSlider、ProgressBar、CheckBox、Switcher、RadioGroup、Input文本输入框、ScrollBox滚动容器、List列表、Select下拉框、MaskedFrame`

2. 官网地址

    官网：[https://pixijs.io/ui/](https://pixijs.io/ui//)
    github: [https://github.com/pixijs/ui](https://github.com/pixijs/ui)

3. 安装插件

    - PixiJS v8 → **@pixi/ui@2.x**
    - PixiJS v7 → @pixi/ui@1.x

    ```bash
    npm install @pixi/ui
    ```

    >**PixiJS Userland官方生态库，不是第三方民间库；包名 `@pixi/ui`，不是 `pixi‑ui`**。

## 4.2 代码示例

### 4.2.1 基础按钮（Button）

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Container, Graphics, Text } from 'pixi.js'
    import { Button } from '@pixi/ui'

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application()
      await app.init({
        width: 500,
        height: 300,
        backgroundColor: 0x111111,
      })
      pixiContainer.value.appendChild(app.canvas)

      // 创建按钮背景
      const btnView = new Container()
      btnView.x = 160
      btnView.y = 120
      const btnBg = new Graphics()
      btnBg.rect(0, 0, 160, 50)
      btnBg.fill(0x4285f4)

      // 按钮文字
      const btnText = new Text({
        text: '点击我',
        style: { fill: 0xffffff, fontSize: 20 },
        x: 45,
        y: 13,
      })
      btnView.addChild(btnBg, btnText)

      // 创建 @pixi/ui 按钮
      const button = new Button(btnView)

      // 点击事件
      button.onPress.connect(() => {
        console.log('Pixi UI 按钮被点击了！');
      })

      app.stage.addChild(button.view)
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.2 带状态的按钮

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>
    
    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Container, Graphics, Text } from 'pixi.js'
    import { Button } from '@pixi/ui'
    
    const pixiContainer = ref(null)
    let app = null
    let button = null
    
    // 三个状态视图
    let defaultView, hoverView, pressedView
    let btnText // 按钮文字
    
    onMounted(async () => {
      app = new Application()
      await app.init({ 
        width: 500, 
        height: 300, 
        backgroundColor: 0x111111 
      })
      pixiContainer.value.appendChild(app.canvas)
    
      // 1. 创建三个状态的背景
      defaultView = new Graphics().rect(0, 0, 180, 55).fill(0x3498db)
      hoverView = new Graphics().rect(0, 0, 180, 55).fill(0x2980b9)
      pressedView = new Graphics().rect(0, 0, 180, 55).fill(0x1f618d)
    
      // 2. 创建文字
      btnText = new Text({
        text: '状态按钮',
        style: {
          fill: 0xffffff,
          fontSize: 22,
        },
      })
      btnText.anchor.set(0.5)
      btnText.x = 90
      btnText.y = 27.5
    
      // 3. 创建按钮容器（默认显示 defaultView）
      const btnContainer = new Container()
      btnContainer.addChild(defaultView, btnText)
      btnContainer.x = 150
      btnContainer.y = 120
    
      // 4. 创建 @pixi/ui Button
      button = new Button(btnContainer)
    
      // 5. 监听事件（你要的版本，已修复）
      button.onPress.connect(() => {
        console.log('点击触发！')
      })
    
      button.onDown.connect(() => {
        console.log('onDown → 按下')
        pressButton()
      })
    
      button.onUp.connect(() => {
        console.log('onUp → 抬起')
        defaultButton()
      })
    
      button.onHover.connect(() => {
        console.log('onHover → 悬停')
        hoverButton()
      })
    
      button.onOut.connect(() => {
        console.log('onOut → 离开')
        defaultButton()
      })
    
      button.onUpOut.connect(() => {
        console.log('onUpOut → 在外部抬起')
        defaultButton()
      })
    
      //6. 添加到舞台
      app.stage.addChild(button.view)
    })
    
    // ==========================================
    // 按钮状态切换方法
    // ==========================================
    function pressButton() {
      defaultView.visible = false
      hoverView.visible = false
      pressedView.visible = true
      btnText.parent.addChildAt(pressedView, 0)
    }
    
    function hoverButton() {
      defaultView.visible = false
      hoverView.visible = true
      pressedView.visible = false
      btnText.parent.addChildAt(hoverView, 0)
    }
    
    function defaultButton() {
      defaultView.visible = true
      hoverView.visible = false
      pressedView.visible = false
      btnText.parent.addChildAt(defaultView, 0)
    }
    
    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.5 输入框(DomContainer)

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, DOMContainer, Graphics } from 'pixi.js'
    import '@pixi/layout'

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application()
      await app.init({
        width: 500,
        height: 300,
        backgroundColor: 0x111,
        eventFeatures: {
          pointer: true,
          touch: true
        }
      })
      pixiContainer.value.appendChild(app.canvas)
    
      // 1. 输入框背景（别挡住输入框！）  
      const bg = new Graphics()
      bg.rect(0, 0, 320, 50).fill(0xffffff)
      bg.x = 90   // 和输入框一致
      bg.y = 120
      app.stage.addChild(bg)

      // 2. 原生 HTML input
      const inputDom = document.createElement('input')
      inputDom.type = 'text'
      inputDom.placeholder = '请输入内容（支持中英文）'
      inputDom.style.width = '320px'
      inputDom.style.height = '50px'
      inputDom.style.fontSize = '20px'
      inputDom.style.padding = '0 12px'
      inputDom.style.border = 'none'
      inputDom.style.outline = 'none'
      inputDom.style.background = 'transparent'
      inputDom.style.position = 'absolute' // 必须！

      // 3. DOMContainer（支持中文输入）
      const domContainer = new DOMContainer({
        element: inputDom,
        x: 90,     // Pixi 坐标
        y: 120,
        width: 320, // 必须！否则 HTML 元素不会显示
        height: 50
      })

      app.stage.addChild(domContainer)

      // 4. 输入事件
      inputDom.addEventListener('input', (e) => {
        console.log('输入：', e.target.value)
      })
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.6 进度条 ProgressBar

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Graphics } from 'pixi.js'
    import { ProgressBar } from '@pixi/ui'
    import '@pixi/layout'

    const pixiContainer = ref(null)
    let app = null
    let progress = null
    let value = 1 // 百分制

    onMounted(async () => {
      app = new Application()
      await app.init({ 
        width: 500, 
        height: 300, 
        backgroundColor: 0x111 
      })
      pixiContainer.value.appendChild(app.canvas)

      // 背景条
      const barBg = new Graphics()
      barBg.rect(0, 0, 380, 30).fill(0x444444)

      // 填充条
      const barFill = new Graphics()
      barFill.rect(0, 0, 380, 30).fill(0xffffff)

      // 进度条
      progress = new ProgressBar({
        bg: barBg,
        fill: barFill,
        progress: value,
      })
      progress.x = 60
      progress.y = 130
      app.stage.addChild(progress)

      app.ticker.add(() => {
        if(value >= 100) {
          value = 0
        }    
        value += 0.1
        progress.progress = value
      })
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.7 滑块 Slider

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 300px;"></div>
    </template>
    
    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Graphics } from 'pixi.js'
    import { Slider } from '@pixi/ui'
    import '@pixi/layout'
    
    const pixiContainer = ref(null)
    let app = null
    
    onMounted(async () => {
      app = new Application()
      await app.init({ 
        width: 500, 
        height: 300, 
        backgroundColor: 0x111,
        // 开启抗锯齿渲染
        antialias: true,
      })
      pixiContainer.value.appendChild(app.canvas)
    
      const width = 360
      const height = 12
      const radius = 6
    
      const bg = new Graphics()
        .roundRect(0, 0, width, height, radius)
        .fill(0x444)
    
      const fill = new Graphics()
        .roundRect(0, 0, width, height, radius)
        .fill(0x2ecc71)
    
      const slider = new Graphics()
        .circle(0, 0, 16)
        .fill(0xffffff)
    
      // 官方 Slider 正确参数
      const uiSlider = new Slider({
        bg: bg,       // 轨道背景
        fill: fill,   // 已填充部分
        slider: slider, // 滑块
        min: 0,
        max: 100,
        value: 50,
        showValue: true,
        valueTextStyle: {
          fill: 0xffffff,
          fontSize: 18
        }
      })
    
      uiSlider.x = 70
      uiSlider.y = 140
    
      uiSlider.onUpdate.connect((v) => {
        console.log('值：', Math.round(v))
      })
    
      app.stage.addChild(uiSlider)
    })
    
    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.8 列表 List

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 500px; height: 400px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Graphics, Text } from 'pixi.js'
    import { List, FancyButton } from '@pixi/ui'
    import '@pixi/layout'

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application()
      await app.init({ 
        width: 500, 
        height: 400, 
        backgroundColor: 0x111 
      })
      pixiContainer.value.appendChild(app.canvas)

      // 列表 List（完全按官网）
      const list = new List({
        type: 'vertical',
        elementsMargin: 10,
        leftPadding: 10,
        topPadding: 10,
      })

      const menus = ['首页', '设置', '个人中心', '关于我们', '退出登录']

      menus.forEach((menu, index) => {
        const btnWidth = 200
        const btnHeight = 50
        const radius = 10

        // 按钮三个状态（官网标准写法）
        const defaultView = new Graphics()
          .roundRect(0, 0, btnWidth, btnHeight, radius)
          .fill(0x3e82fc)

        const hoverView = new Graphics()
          .roundRect(0, 0, btnWidth, btnHeight, radius)
          .fill(0x2a68e2)

        const pressedView = new Graphics()
          .roundRect(4, 4, btnWidth, btnHeight, radius)
          .fill(0x1d4fb2)

        // 文字
        const text = new Text({
          text: menu,
          style: {
            fontSize: 20,
            fill: 0xffffff
          }
        })

        // FancyButton（官网写法）
        const btn = new FancyButton({
          defaultView,
          hoverView,
          pressedView,
          text,
        })

        // 按压时文字偏移（官网效果）
        btn.onDown.connect(() => {
          text.x += 2
          text.y += 2
        })
        btn.onUp.connect(() => {
          text.x -= 2
          text.y -= 2
        })
        btn.onUpOut.connect(() => {
          text.x -= 2
          text.y -= 2
        })

        // 点击事件
        btn.onPress.connect(() => {
          console.log('点击菜单：', menu)
          alert(`你选择了：${menu}`)
        })

        //  正确添加
        list.addChild(btn)
      })

      list.x = 150
      list.y = 40

      app.stage.addChild(list)
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```

### 4.2.9 弹窗 Dialog

1. 代码示例

    ```html
    <template>
      <div ref="pixiContainer" style="width: 800px; height: 600px;"></div>
    </template>

    <script setup>
    import { ref, onMounted, onUnmounted } from 'vue'
    import { Application, Graphics, Text } from 'pixi.js'
    import { Dialog, FancyButton } from '@pixi/ui'
    import '@pixi/layout'

    const pixiContainer = ref(null)
    let app = null

    onMounted(async () => {
      app = new Application()
      await app.init({
        width: 800,    // 画布宽度
        height: 600,   // 画布高度
        backgroundColor: 0x111827,
      })
      pixiContainer.value.appendChild(app.canvas)

      // 打开按钮 —— 放在画布正中间
      const openBtn = new FancyButton({
        defaultView: new Graphics().roundRect(0,0,220,55,12).fill(0x2563eb),
        hoverView: new Graphics().roundRect(0,0,220,55,12).fill(0x3b82f6),
        pressedView: new Graphics().roundRect(0,0,220,55,12).fill(0x1d4ed8),
        text: new Text({
          text: '打开弹窗',
          style: { fill: 0xffffff, fontSize: 20 }
        }),
      })
      // 按钮放在画布正中间
      openBtn.x = (app.screen.width - 220) / 2
      openBtn.y = app.screen.height / 2 + 150
      app.stage.addChild(openBtn)

      // 弹窗按钮
      const okBtn = {
        text: new Text({ text: '确定', style: { fill: 0xffffff, fontSize:18 } }),
        defaultView: new Graphics().roundRect(0,0,120,50,8).fill(0x10b981),
        hoverView: new Graphics().roundRect(0,0,120,50,8).fill(0x059669),
        pressedView: new Graphics().roundRect(0,0,120,50,8).fill(0x047857),
      }

      const cancelBtn = {
        text: new Text({ text: '取消', style: { fill: 0xffffff, fontSize:18 } }),
        defaultView: new Graphics().roundRect(0,0,120,50,8).fill(0x4b5563),
        hoverView: new Graphics().roundRect(0,0,120,50,8).fill(0x6b7280),
        pressedView: new Graphics().roundRect(0,0,120,50,8).fill(0x374151),
      }

      // 弹窗背景
      const dialogBg = new Graphics()
        .roundRect(0,0,400,260,20)
        .fill(0x1f2937)
        .stroke({ color:0x4b5563, width:1 })

      // Dialog 弹窗
      const dialog = new Dialog({
        background: dialogBg,
        title: new Text({
          text: '确认操作',
          style: { fill:0xffffff, fontSize:28, fontWeight:'bold' }
        }),
        content: new Text({
          text: '确定要执行此操作吗？',
          style: { fill:0xd1d5db, fontSize:18, align:'center' }
        }),
        buttons: [okBtn, cancelBtn],
        buttonList: { elementsMargin: 25 },
        width: 400,
        height: 260,
        padding: 30,
        closeOnBackdropClick: true,
        backdropAlpha: 0.6,
      })

      // 弹窗在 800x600 画布中完美居中
      dialog.x = app.screen.width / 2
      dialog.y = app.screen.height / 2

      app.stage.addChild(dialog)

      // 打开弹窗
      openBtn.onPress.connect(() => {
        dialog.open()
      })

      // 按钮点击
      dialog.onSelect.connect((idx) => {
        console.log('选择了按钮：', idx)
        dialog.close()
      })
    })

    onUnmounted(() => {
      app?.destroy(true)
      app = null
    })
    </script>
    ```
