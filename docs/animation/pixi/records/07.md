# 七、骨骼动画-spine

## 7.1 PIXI + Spine 集成

`pixi‑spine` 是 Spine 官方提供的 PIXI 运行时，用于加载、渲染、驱动 Spine 骨骼动画（json/binary+atlas）。

> 
> 版本匹配很关键：**Spine编辑器版本、spine运行时版本、pixi版本三者必须对齐**。
> Spine 4.2 → pixi‑[spine@4.2.x](mailto:spine@4.2.x)；Spine4.1 → pixi‑[spine@4.1.x](mailto:spine@4.1.x)，版本错配直接解析报错。

1. 安装引入

    ```sh
    # pixi v8 对应
    npm install pixi.js @pixi/spine
    ```

    浏览器CDN方式：

    ```html
    <script src="./js/pixi.js"></script>
    <script src="./js/pixi‑spine.js"></script>
    ```

2. 资源文件

	Spine导出需要3个文件：

	1. `xxx.json` / `xxx.skel`：骨骼数据（json 或二进制 skel）
	2. `xxx.atlas`：图集描述
	3. 图集png图片

	> 
	> 导出设置：选 `JSON` 或者 `Binary`，导出Atlas，不要勾选压缩多余选项。

3. 基础加载&运行示例

	```js
	import { Application, Assets } from 'pixi.js';
	import { Spine } from '@pixi/spine';

	const app = new Application();
	await app.init({ width:1280, height:720 });
	document.body.appendChild(app.canvas);

	// 加载spine资源
	await Assets.add({
		alias:"hero",
		src: {
			skeleton: "./spine/hero.json",
			atlas: "./spine/hero.atlas"
		}
	});
	const spineData = await Assets.load("hero");
	const spineChar = new Spine(spineData);

	app.stage.addChild(spineChar);
	spineChar.scale.set(0.5);
	spineChar.position.set(640,360);

	// 播放动画：动画名，是否循环
	spineChar.state.setAnimation(0, "idle", true);

	// ticker交给pixi驱动，内部会自动更新骨骼时间
	app.ticker.add(dt=>{
		spineChar.update(dt.deltaTime);
	});
	```

3. 常用API

	```js
	// 轨道0播放idle循环
	spineChar.state.setAnimation(0,"idle",true);

	// 混合过渡：当前动画播完后，衔接walk，混合时长0.2s
	spineChar.state.addAnimation(0,"walk",true,0.2);

	// 设置皮肤
	spineChar.skeleton.setSkinByName("skinName");
	spineChar.skeleton.setSlotsToSetupPose();

	// 获取插槽，挂载pixi对象到骨骼点
	const slot = spineChar.skeleton.findSlot("weaponSlot");
	slot.container.addChild(anotherSprite);

	// 事件监听（spine里面自定义事件）
	spineChar.state.addListener({
		event: (_,event)=>{
			console.log("触发事件",event.data.name);
		},
		complete:()=>{
			console.log("动画完成");
		}
	});
	```

4. 常见踩坑

	1. **版本不匹配**：Spine编辑器导出版本高于运行时，直接解析失败，报错非法数据。
	2. **atlas路径错误**：atlas文件内部png相对路径不对，图片白块，看不到角色。
	3. **忘记调用 `update(deltaTime)`**：骨骼不动，画面静止。
	4. **缩放翻转**：`skeleton.scaleX=-1` 水平翻转角色，不要用sprite scale，会破坏骨骼计算。
	5. **滤镜叠加**：Spine实例本质是Container，可以直接设置 `spineChar.filters=[xxxFilter]`，前面SimplexNoiseFilter、TwistFilter均可直接作用整个骨骼角色。
	6. 性能：大量Spine实例开销高；复杂角色注意控制实例数量。

	每个状态键都维护着 3 个跟踪属性：

	- `pressed`：标记该按键是否处于按下状态。
	- `doubleTap`：标记按键松开后，是否在短时间内被快速连击。
	- `timestamp`：内部时间戳，用来判断本次按键是否属于双击。

	注意：我们已经在按键映射里把 W、A、S、D 设置为方向输入，它们的行为和方向键保持一致。

2. 按键按下处理器
	
	逻辑：把对应按键状态里的 `pressed` 设置为 `true`。
	
	对于双击判断：如果当前时间减去该按键记录的时间戳，差值小于阈值（本例为300毫秒），则判定为双击。
	
	> 注意：长按按键时，按键按下回调会持续触发。因此一旦判定为双击，后续回调里 `doubleTap` 需要保持为 `true`；时间戳只会在按键抬起时重置，不受长按影响。

	```js
	const key = keyMap[event.code];
	if (!key) return;
	const now = Date.now();
	this.keys[key].pressed = true;
	this.keys[key].doubleTap = this.keys[key].doubleTap || now - this.keys[key].timestamp < 300;
	```

3. 按键抬起处理器

	逻辑：按键抬起时，把对应按键的 `pressed` 置为 `false`。
	
	如果此前是双击状态，则清空 `doubleTap`；否则更新时间戳，用于下一次按键的双击校验。

	```js
	const key = keyMap[event.code];
	if (!key) return;
	const now = Date.now();
	this.keys[key].pressed = false;
	if (this.keys[key].doubleTap) this.keys[key].doubleTap = false; 
	else this.keys[key].timestamp = now;
	```

4. 使用控制器（Using Controller）

	和角色的实例化方式一样，在主文件 `index.js` 的立即执行函数（IIFE）内创建控制器实例：
	
	```js
	const controller = new Controller();
	```

	然后把控制器状态和角色的行走动画绑定。我们先只绑定**右方向键**，放在应用的 `ticker` 帧更新回调里。
	这里临时保存当前播放的动画标识，保证每次切换只触发一次动画设置（动画本身配置为循环播放），在 `idle`（待机）和 `walk`（行走）两个动画之间切换。
	
	```js
	let currentAnimation;
	app.ticker.add((time) => {
		// 判断左键的状态
		const rightPressed = controller.keys.right.pressed;
		// 是走还是停
		const animationName = rightPressed ? 'walk' : 'idle';
		const loop = true;
		if (currentAnimation !== animationName) {
			currentAnimation = animationName;
			spineBoy.spine.state.setAnimation(0, animationName, loop);
		}
	});
	```

## 7.5 角色动画状态管理

1. 动画映射表
	这里列出角色内置的全部可用动画。每个动画配置包含 `name`，对应 Spine 骨骼数据里的动画名称；还可以配置可选参数 `loop`（是否循环）和 `timeScale`（动画播放速率）。

	```javascript
	const animationMap = {
		idle: { // 待机
			name: 'idle',
			loop: true,
		},
		walk: { // 行走
			name: 'walk',
			loop: true,
		},
		run: { // 奔跑
			name: 'run',
			loop: true,
		},
		jump: { // 跳跃
			name: 'jump',
			timeScale: 1.5,
		},
		hover: { // 悬浮/滑板
			name: 'hoverboard',
			loop: true,
		},
		spawn: { // 生成/入场
			name: 'portal',
		},
	};
	```

2. 辅助方法

	- **`playAnimation(animation)`**
	封装 Spine state 的 `setAnimation(track, name, loop)`，使用动画映射表里的配置播放动画；内置判断，避免同一动画重复叠加播放。

	- **`isAnimationPlaying(animation)`**
	判断动画是否正在播放。读取 Spine state 主轨道，检查轨道条目动画名称是否匹配，并且动画尚未播放完成。

	- **`spawn()`**
	播放传送门入场动画，由外部代码调用触发。

	- **`isSpawning()`**
	基于 `isAnimationPlaying(animation)`，判断入场生成动画是否还在播放。

3. 方向处理 

	Spine 实例外层包了一层 `directionalView` 容器，再添加到场景主视图。目的是做变换隔离，专门用来控制水平翻转：根据输入，把容器 `scale.x` 设置为 `1`（朝右）或 `-1`（朝左）。同时封装了方向的 getter / setter 方便读写。

4.  Spine 动画默认混合 

	```javascript
	this.spine.state.data.defaultMix = 0.2
	```
	
	设置**所有动画之间过渡的混合时长（单位秒）**，动画切换时骨骼姿态做交叉淡入平滑过渡。

5. 更新循环

	在 `update()` 方法里，根据角色状态实时切换动画，**优先级顺序**：
	
	1. 跳跃（jump）优先级最高；即使跳跃状态取消，也要等跳跃动画完整播放完毕才允许切换其他动画。
	2. 其余动画优先级：**hover（悬浮） > run（奔跑） > walk（行走） > idle（待机）**

	> 注意：多个状态可以同时为 true。例如同时按住左右方向键时，walk 状态会为 true。

	```javascript
	if (this.state.jump) this.playAnimation(animationMap.jump);
	if (this.isAnimationPlaying(animationMap.jump)) return;
	if (this.state.hover) this.playAnimation(animationMap.hover);
	else if (this.state.run) this.playAnimation(animationMap.run);
	else if (this.state.walk) this.playAnimation(animationMap.walk);
	else this.playAnimation(animationMap.idle);
	```

6. 绑定输入控制器

	回到 `index.js`：页面启动时播放角色入场动画；在应用的 ticker 帧回调里做逻辑。

	规则：**入场动画播放期间，跳过角色状态更新与角色自身 update 逻辑**。入场结束后，把键盘输入映射到角色状态：
	- left / right 按键按下：开启 `walk`，同时修改角色 `direction`，水平翻转角色朝向
	- doubleTap（双击/连按）：开启 `run` 奔跑状态，同样更新朝向
	- down 按键：开启 `hover` 悬浮状态
	- space 空格：开启 `jump` 跳跃状态

	```javascript
	spineBoy.spawn();
	app.ticker.add(() => {
	  if (spineBoy.isSpawning()) return;
	  spineBoy.state.walk = controller.keys.left.pressed || controller.keys.right.pressed;
	  if (spineBoy.state.run && spineBoy.state.walk) spineBoy.state.run = true;
	  else spineBoy.state.run = controller.keys.left.doubleTap || controller.keys.right.doubleTap;
	  spineBoy.state.hover = controller.keys.down.pressed;
	  if (controller.keys.left.pressed) spineBoy.direction = -1;
	  else if (controller.keys.right.pressed) spineBoy.direction = 1;
	  spineBoy.state.jump = controller.keys.space.pressed;
	  spineBoy.update();
	});
	```

## 7.6 设置场景


场景的构建逻辑比较简单：包含一张天空静态精灵 `Sprite`，以及三层用于视差滚动的平铺精灵 `TilingSprite`，三层分别是远景背景、中景、地面平台。

我们单独新建一个 `Scene` 类来管理场景，并创建一个视图容器。资源已经提前预加载完成，可以直接开始构建。

场景元素**从下往上**创建，所有元素锚点统一设置在右下角。

1. 天空图层

	创建天空精灵，设置锚点为右下角，使用传入的场景宽高，让天空铺满整个画布。

	```javascript
	this.sky = Sprite.from('sky');
	this.sky.anchor.set(0, 1);
	this.sky.width = width;
	this.sky.height = height;
	```

2. 视差滚动图层

	先从预加载资源获取三张图层纹理：

	```javascript
	const backgroundTexture = Texture.from('background');
	const midgroundTexture = Texture.from('midground');
	const platformTexture = Texture.from('platform');
	```

	计算平台目标高度：取场景高度的40%，同时不能超过平台纹理本身的原始高度。
	再计算缩放系数，平台纹理使用该缩放达到目标高度；为保持画面比例统一，其余视差图层也复用这个缩放值。

	```javascript
	const maxPlatformHeight = platformTexture.height;
	const platformHeight = Math.min(maxPlatformHeight, height * 0.4);
	const scale = (this.scale = platformHeight / maxPlatformHeight);
	```

	基于纹理与参数创建三层平铺精灵，抽离公共配置：

	```javascript
	const baseOptions = {
		tileScale: { x: scale, y: scale },
		anchor: { x: 0, y: 1 },
		applyAnchorToTexture: true,
	};

	this.background = new TilingSprite({
		texture: backgroundTexture,
		width,
		height: backgroundTexture.height * scale,
		...baseOptions,
	});

	this.midground = new TilingSprite({
		texture: midgroundTexture,
		width,
		height: midgroundTexture.height * scale,
		...baseOptions,
	});

	this.platform = new TilingSprite({
		texture: platformTexture,
		width,
		height: platformHeight,
		...baseOptions,
	});
	```

	平台纹理内部包含路灯等装饰元素，纹理底部并不是真实地面。需要手动计算**平台底部到地面表面**的真实高度，保存为成员变量 `floorHeight`，供外部角色逻辑使用。

	将远景、中景图层向上偏移，对齐地面，最后把所有图层添加到场景主容器：

	```javascript
	this.floorHeight = platformHeight * 0.43;
	this.background.y = this.midground.y = -this.floorHeight;
	this.view.addChild(this.sky, this.background, this.midground, this.platform);
	```

3. 在 index.js 挂载场景

	实例化场景，**先添加场景，再添加角色**（保证角色渲染在场景上层）：

	```javascript
	const scene = new Scene(app.screen.width, app.screen.height);
	app.stage.addChild(scene.view, spineBoy.view);
	```

	场景容器定位到屏幕底部，角色坐标与缩放需要结合场景地面高度和场景缩放重新计算：

	```javascript
	scene.view.y = app.screen.height;
	spineBoy.view.x = app.screen.width / 2;
	spineBoy.view.y = app.screen.height - scene.floorHeight;
	spineBoy.spine.scale.set(scene.scale * 0.32);
	```

	      // 创建一个包含环境的场景
	      const scene = new Scene(app.screen.width, app.screen.height);

	      scene.view.y = app.screen.height;
	      spineBoy.view.x = app.screen.width / 2;
	      spineBoy.view.y = app.screen.height - scene.floorHeight;
	      spineBoy.spine.scale.set(scene.scale * 0.32);

	      // 在舞台上添加场景和角色
	      app.stage.addChild(scene.view, spineBoy.view);

	      spineBoy.spawn();
	      app.ticker.add(() => {
	        if (spineBoy.isSpawning()) return;
	        spineBoy.state.walk = controller.keys.left.pressed || controller.keys.right.pressed;
	        if (spineBoy.state.run && spineBoy.state.walk) spineBoy.state.run = true;
	        else spineBoy.state.run = controller.keys.left.doubleTap || controller.keys.right.doubleTap;
	        spineBoy.state.hover = controller.keys.down.pressed;
	        if (controller.keys.left.pressed) spineBoy.direction = -1;
	        else if (controller.keys.right.pressed) spineBoy.direction = 1;
	        spineBoy.state.jump = controller.keys.space.pressed;
	        spineBoy.update();
	      });
	    })();
	  </script>

## 7.7 设置动画场景


1. 根据角色位置设置场景位置

	首先，我们在 `Scene` 类中创建一个统一的 `positionX` 属性。对于 getter，它只需返回平台 `TilingSprite` 的 `tilePosition.x`；同样地，对于 setter，我们直接设置其 `tilePosition.x`，但同时也以递减的比例设置中景和背景 `TilingSprite` 的 `tilePosition.x`。这样，当平台的水平位置发生变化时，背景层就能产生视差滚动效果。

	**Getter**

	```javascript
	return this.platform.tilePosition.x;
	```

	**Setter**

	```javascript
	this.background.tilePosition.x = value * 0.1;
	this.midground.tilePosition.x = value * 0.25;
	this.platform.tilePosition.x = value;
	```

2. 更新中设置

	然后，在主 `index.js` 文件中，让我们在应用程序的 ticker 回调末尾操作这个 `positionX` 属性，以相应地实现滚动动画。这里，我们将为角色的行走、奔跑和悬浮状态使用 3 种不同的滚动速度。我们还需要根据方向来增加或减少该属性值。

	```javascript
	let speed = 1.25;

	if (spineBoy.state.hover) speed = 7.5;
	else if (spineBoy.state.run) speed = 3.75;

	if (spineBoy.state.walk) {
		scene.positionX -= speed * scene.scale * spineBoy.direction;
	}
	```
