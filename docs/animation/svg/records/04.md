# 处理文字阴影描边

## 1. 需求：需要完成一个描边阴影

1. 示例图

    ![](/animation/svg/records/image/011.png)
2. 难点

    不管是css还是svg都是没有直接给阴影家边框的，阴影是阴影边框是边框，这里就很麻烦

## 2. 使用html进行处理

1. 示例代码

    ```html
    <div style="background:#000;padding:40px 20px;text-align:center;font-family:'Microsoft Yahei',sans-serif;">
        <div style="
            font-size:90px;
            font-weight:bold;
            color:#fff;
            text-shadow:4px 4px 0px #000, 5px 5px 0 #ffffff;
            margin-bottom:12px;
        ">科技回调“黄金坑”</div>
        <div style="
            font-size: 96px;
            font-weight: bold;
            background: linear-gradient(#BBE5F0, #7FD8F0);
            background-clip: text;
            color: transparent;
            -webkit-text-stroke: 1px #eee;
        ">布局良机不错过</div>
    </div>
    ```

## 3. 使用svg直接处理

1. 代码示例

    ```html
    <svg width="640" height="150" viewBox="0 0 640 150" xmlns="http://www.w3.org/2000/svg">
        <rect width="100%" height="100%" fill="#000"/>
        <defs>
            <!-- 文字渐变 -->
            <linearGradient id="blueGrad" x1="0%" y1="0%" x2="0%" y2="100%">
                <stop offset="0%" stop-color="#e0f4ff"/>
                <stop offset="100%" stop-color="#86d8ff"/>
            </linearGradient>
            <!-- 阴影滤镜：右下偏移0.8，无模糊=实黑边 -->
            <filter id="textShadow" x="-10%" y="-10%" width="120%" height="120%">
                <feDropShadow dx="3" dy="3" stdDeviation="0" flood-color="#949494"/>
            </filter>
        </defs>
    
        <!-- 第一行白色文字，直接绑定阴影滤镜，无需双层 -->
        <text x="320" y="50" font-size="50" font-family="Microsoft YaHei Black,sans-serif" text-anchor="middle" letter-spacing="3" fill="#ffffff" filter="url(#textShadow)">
            科技回调“黄金坑”
        </text>

        <!-- 第二行渐变文字，共用同一个阴影滤镜 -->
        <text x="320" y="130" font-size="70" font-family="Microsoft YaHei Black,sans-serif" text-anchor="middle" letter-spacing="3" fill="url(#blueGrad)" filter="url(#textShadow)">
            布局良机不错过
        </text>
    </svg>
    ```

## 4. 使用双层文字进行处理

1. 代码示例

    ```html
    <svg width="640" height="150"  viewBox="0 0 640 150" xmlns="http://www.w3.org/2000/svg">
  
      <!-- 黑色背景 -->
      <rect width="100%" height="100%" fill="#000"/>

      <defs>
        <!-- 浅蓝色渐变定义 -->
        <linearGradient id="blueGrad" x1="0%" y1="0%" x2="0%" y2="100%">
          <stop offset="0%" stop-color="#e0f4ff"/>
          <stop offset="100%" stop-color="#86d8ff"/>
        </linearGradient>
      </defs>

      <!-- ========== 第一组：科技回调“黄金坑” ========== -->
      <!-- 底层阴影（右下偏移3px深色） -->

        <tspan dx="3" dy="2">科技回调“黄金坑”</tspan>
      </text>
      <!-- 上层白色主文字 -->
      <text x="320" y="50" font-size="50" font-family="Microsoft YaHei Black,sans-serif" text-anchor="middle" letter-spacing="4" fill="#ffffff">
        科技回调“黄金坑”
      </text>

      <!-- ========== 第二组：布局良机不错过 ========== -->
      <!-- 底层阴影（右下偏移3px深蓝） -->
    ```

## 5. 使用滤镜处理


1. 代码示例

    ```html
    <svg width="640" height="150" viewBox="0 0 640 150" xmlns="http://www.w3.org/2000/svg">
      <!-- 黑色背景 -->
      <rect width="100%" height="100%" fill="#000"/>
      <defs>
        <!-- 文字渐变 -->
        <linearGradient id="blueGrad" x1="0%" y1="0%" x2="0%" y2="100%">
          <stop offset="0%" stop-color="#e0f4ff"/>
          <stop offset="100%" stop-color="#86d8ff"/>
        </linearGradient>
        <filter id="shadowWithBorder" x="-20%" y="-20%" width="140%" height="140%">
          <!-- 1. 提取文字透明通道 -->
          <feAlpha in="SourceGraphic" result="textAlpha"/>
          <!-- 2. 放大一点，作为阴影主体 -->
          <feMorphology in="textAlpha" operator="dilate" radius="1.0" result="shadowShape"/>
          <!-- 3. 填充阴影颜色 -->
          <feFlood flood-color="#112a40" result="shadowColor"/>
          <feComposite in="shadowColor" in2="shadowShape" operator="in" result="shadowLayer"/>
          <!-- 4. 再外扩一圈，生成阴影的描边 -->
          <feMorphology in="shadowShape" operator="dilate" radius="0.8" result="shadowBorderShape"/>
          <!-- 5. 生成阴影描边颜色 -->
          <feFlood flood-color="#ffffff" result="borderColor"/>
          <feComposite in="borderColor" in2="shadowBorderShape" operator="in" result="borderLayer"/>
          <!-- 6. 只保留外轮廓，去掉中间实心阴影 -->
          <feComposite in="borderLayer" in2="shadowShape" operator="out" result="shadowBorderOnly"/>
          <!-- 7. 阴影整体右下偏移 -->
          <feOffset in="shadowLayer" dx="3" dy="3" result="offsetShadow"/>
          <feOffset in="shadowBorderOnly" dx="3" dy="3" result="offsetShadowBorder"/>
          <!-- 8. 合并：阴影描边最外 → 实心阴影 → 原文字 -->
          <feMerge>
            <feMergeNode in="offsetShadowBorder"/>
            <feMergeNode in="offsetShadow"/>
            <feMergeNode in="SourceGraphic"/>
          </feMerge>
        </filter>
      </defs>
      <!-- 第一行白色文字，直接绑定阴影滤镜，无需双层 -->
      <text x="320" y="50" font-size="50" font-family="Microsoft YaHei Black,sans-serif" text-anchor="middle" letter-spacing="3" fill="#ffffff" filter="url(#shadowWithBorder)">
        科技回调“黄金坑”
      </text>
      <!-- 第二行渐变文字，共用同一个阴影滤镜 -->
      <text x="320" y="130" font-size="70" font-family="Microsoft YaHei Black,sans-serif" text-anchor="middle" letter-spacing="3" fill="url(#blueGrad)" filter="url(#shadowWithBorder)">
        布局良机不错过
      </text>
    </svg>
    ```

2. 展示效果
