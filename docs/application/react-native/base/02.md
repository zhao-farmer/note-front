# 二、样式

## 2.1 react样式与StyleSheet

1. RN中的样式与CSS的不同

    - 没有继承性

        RN中的集成只发生在Text组件上
    - 样式名采用小驼峰命名

        fontSize(RN) VS font-size(CSS)
    - 所有尺寸都没有单位

        width:100
    - 有些特殊的样式名不能使用

        marginHorizontal(水平外边距)，marginVertical(迟滞外边距)
2. RN样式的声明方式

    - 通过 style 属性直接声明
        - 属性值为对象：`<组件 style={{样式}}/>`
        - 属性值为数组：`<组件 style={[{样式1},...,{样式N}]}/>`
    - 在 style 属性中调用StyleSheet 声明的样式
        - 引入：`import {Style,View} from 'react-native'`
        - 声明：`const styles = StyleSheet.create({foo:{样式1},bar:{样式2}})`
        - 使用：`<View style={[styles.foo,styles.bar]}>内容</View>`

3. 代码示例

    - app.tsx

        ```tsx
        import Index from './src_01_StyleSheet';
        function App() {
            return <Index />;
        }
        export default App;
        ```
    - src_01_StyleSheet/index.tsx

        ```tsx
        import { View, Text, StyleSheet } from 'react-native';
        import React from 'react';

        export default function index() {
            return (
                <View>
                    <Text style={{ fontSize: 30 }}>测试对象类型样式</Text>
                    <Text style={[{ color: 'red' }, { color: 'green', fontSize: 25 }]}>
                        测试数组类型样式
                    </Text>

                    <Text style={styles.h1}>测试StyleSheet创建的样式</Text>
                </View>
            );
        }

        const styles = StyleSheet.create({
            h1: {
                fontSize: 40,
                fontWeight: 'bold',
                color: 'blue',
            },
            h2: {
                fontSize: 30,
                fontWeight: 'bold',
            },
        });
        ```

## 2.2 FlexBox

1. flexbox - 术语

    - 容器（container）

        采用flex布局的元素，称为flex容器（flex container）,简称“容器”
    - 项目（item）

        容器所有子元素，称为flex项目（flex item），简称”项目“
    - 主轴（main axis）
    - 交叉轴（cross axis）

2. flex web与rn的区别

    - flex web

    - flex rn

3. flexbox - 属性

    - flexDirection

        声明主轴方向：row (web默认) | column(TN默认)

        - 代码示例

                                <View style={[styles.container]}>
                                    <Text style={[styles.itemBase]}>刘备</Text>
                                    <Text style={[styles.itemBase]}>关羽</Text>
                                    <Text style={[styles.itemBase]}>张飞</Text>
                                </View>
                                <Text style={[styles.h3]}>FlexDorection:'column-reverse'</Text>
                                <View style={[styles.container,styles.flexColumnReverse]}>
                                    <Text style={[styles.itemBase]}>刘备</Text>
                                    <Text style={[styles.itemBase]}>关羽</Text>
                                    <Text style={[styles.itemBase]}>张飞</Text>

                                <Text style={[styles.h3]}>FlexDorection:'row'</Text>
                                <View style={[styles.container,styles.flexRow]}>
                                    <Text style={[styles.itemBase]}>刘备</Text>
                                    <Text style={[styles.itemBase]}>关羽</Text>
                                    <Text style={[styles.itemBase]}>张飞</Text>
                                </View>
                                <Text style={[styles.h3]}>FlexDorection:'row-reverse'</Text>
                                <View style={[styles.container,styles.flexRowReverse]}>
                                    <Text style={[styles.itemBase]}>刘备</Text>
                                    <Text style={[styles.itemBase]}>关羽</Text>
                                    <Text style={[styles.itemBase]}>张飞</Text>
                                </View>
                            </ScrollView>
                        </View>
                    )
                }
            }

            const styles = StyleSheet.create({
                container:{ 
                    height:150,
                    margin:10,
                    borderWidth:1,
                    borderColor:'red',
                },
                h2:{
                    fontSize:30,
                    marginHorizontal:10,
                },
                h3:{
                    fontSize:24,
                    marginHorizontal:10,
                },
                itemBase:{
                    height:30,
                    borderWidth:1,
                    borderColor:'#dfb',

                    textAlign:'center',

                    flexDirection:'column', // 列

                flexColumnReverse:{
                    flexDirection:'column-reverse', // 列翻转

                    flexDirection:'row-reverse', // 行翻转
                },
            })

## 2.3 响应式布局

1. Dimensions：获取屏幕的宽高

    ```js
    import { Dimensions } from 'react-native';
    const windowWidth = Dimensions.get('window').width;
    const windowHeight = Dimensions.get('window').height;
    ```
