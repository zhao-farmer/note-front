# 六、npm发包记录

## 6.1 修改webav并发布

### 6.1.1 修改文件并打包

1. 下载github 包

    github地址：[https://github.com/WebAV-Tech/WebAV](https://github.com/WebAV-Tech/WebAV)

2. 修改文件

    在 `.\packages\av-canvas\av-canvas.ts` 下，新增方法

    ```js
    /**
     * @param opts - 播放选项
     * @param opts.fps - 帧率
     */
    playPlus(opts: { start: number; end?: number; playbackRate?: number; fps?: number}) {
      const spriteTimes = this.#spriteManager
        .getSprites({ time: false })
        .map((s) => s.time.offset + s.time.duration);
      const end =
        opts.end ??
        (spriteTimes.length > 0 ? Math.max(...spriteTimes) : Infinity);

      if (opts.start >= end || opts.start < 0) {
        throw Error(
          `Invalid time parameter, ${JSON.stringify({ start: opts.start, end })}`,
        );
      }

      

      this.#updateRenderTime(opts.start);
      this.#autoPreFrame.reset();

      this.#playState.start = opts.start;
      this.#playState.end = end;
      // AVCanvas 30FPS，将播放速率转换成步长
      this.#playState.step = (opts.playbackRate ?? 1) * (1000 / (opts.fps ?? 30)) * 1000;
      this.#audioCtx.resume();
      this.#playState.audioPlayAt = 0;

      this.#evtTool.emit('playing');
      Log.info('AVCanvs play by:', this.#playState);
    }
    ```

3. 修改配置  `package.json`

    - 改 `name`：比如改成 `@你的npm账号/av-canvas` 或者 `my-av-canvas`（不能和原包重名）
    - 改 `version`：比如 `1.2.8.1`（加个自定义后缀，避免和原版本冲突）
    - 改 `repository`: 自己的github地址，或者为空
    - 确保 `main`/`module`/`exports` 这些字段指向的文件路径正确

4. 构建程序

    ```sh
    pnpm install
    pnpm build
    ```

    确认你的修改已经在 `dist/av-canvas.js` 里（如果源码改了，需要重新构建）

### 6.1.2 准备账户

1. 进入创建令牌页面

    1. 打开 [npm 官网](https://www.npmjs.com/) 登录你的账号
    2. 进入个人主页 → **Access Tokens**
    3. 点击 **Generate New Token**
