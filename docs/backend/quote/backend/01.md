# 一、数据校验

## 1.1 joi 插件

`joi` 本身是一个独立的、功能强大的 **JavaScript 数据校验库**（由 Sideway 维护，曾是 Hapi.js 的一部分），它**不需要插件即可直接使用**。但根据你的开发场景（如 Express、Koa、Fastify、NestJS 等），社区提供了 **集成 joi 的中间件或装饰器**，以便在 Web 框架中更方便地做请求参数校验。


### 1.1.1 使用介绍

1. 基础结构

    ```js
    const Joi = require('joi');

    // 定义 schema
    const schema = Joi.object({
      name: Joi.string().required(),
      age: Joi.number().min(0).max(120)
    });

    // 校验
    const { error, value } = schema.validate(data);
    ```


2. 通用方法（所有类型都支持）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.required()` | 必填字段 | `Joi.string().required()` |
    | `.optional()` | 可选（默认） | `Joi.string().optional()` |
    | `.forbidden()` | 禁止出现该字段 | `Joi.string().forbidden()` |
    | `.description('...')` | 添加描述（用于文档/错误） | `Joi.string().description('用户名')` |
    | `.label('name')` | 自定义字段名（错误信息中显示） | `Joi.string().label('姓名')` |
    | `.example(value)` | 提供示例值 | `Joi.string().example('john')` |
    | `.notes(['...'])` | 添加注释 | `Joi.string().notes(['必须是字母'])` |
    | `.meta({})` | 附加元数据 | `Joi.string().meta({ group: 'user' })` |
    | `.when(ref, options)` | 条件校验 | 见下文 |

3. 字符串（`Joi.string()`）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.min(len)` | 最小长度 | `.min(3)` |
    | `.max(len)` | 最大长度 | `.max(30)` |
    | `.length(len)` | 固定长度 | `.length(10)` |
    | `.alphanum()` | 仅字母数字 | `.alphanum()` |
    | `.token()` | 字母数字 + 下划线 | `.token()` |
    | `.email()` | 邮箱格式 | `.email()` |
    | `.uri()` | URL 格式 | `.uri()` |
    | `.ip()` | IP 地址 | `.ip({ version: ['ipv4', 'ipv6'] })` |
    | `.pattern(regex)` | 正则匹配 | `.pattern(/^[a-z]+$/)`) |
    | `.lowercase()` / `.uppercase()` | 强制大小写 | `.lowercase()` |
    | `.trim()` | 去除首尾空格 | `.trim()` |
    | `.creditCard()` | 信用卡号 | `.creditCard()` |
    | `.isoDate()` | ISO 8601 日期字符串 | `.isoDate()` |

4. 数字（`Joi.number()`）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.min(n)` / `.max(n)` | 范围 | `.min(0).max(100)` |
    | `.greater(n)` / `.less(n)` | 严格大于/小于 | `.greater(0)` |
    | `.integer()` | 整数 | `.integer()` |
    | `.positive()` / `.negative()` | 正数/负数 | `.positive()` |
    | `.precision(n)` | 小数位数 | `.precision(2)` |
    | `.multiple(base)` | 倍数 | `.multiple(5)` → 5, 10, 15... |
    | `.port()` | 端口号 (0-65535) | `.port()` |


5. 日期（`Joi.date()`）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.min(date)` / `.max(date)` | 时间范围 | `.min('now')` |
    | `.iso()` | ISO 8601 字符串 | `.iso()` |
    | `.timestamp(type)` | 时间戳（`'javascript'` 或 `'unix'`） | `.timestamp('unix')` |
    | `.format(string)` | 自定义格式 | `.format('YYYY-MM-DD')` |

    > 注意：`Joi.date()` 默认接受 `Date` 对象、时间戳、ISO 字符串。



6. 布尔值（`Joi.boolean()`）

    | 方法 | 说明 |
    |------|------|
    | 无特殊方法，但可配合 `.truthy()` / `.falsy()` 自定义真/假值 |

    ```js
    Joi.boolean().truthy('yes').falsy('no'); // 'yes' → true, 'no' → false
    ```


7. 对象（`Joi.object()`）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.keys(schema)` | 定义字段（通常直接传对象） | `Joi.object({ name: Joi.string() })` |
    | `.pattern(pattern, schema)` | 动态键名校验 | `.pattern(Joi.string(), Joi.number())` → 所有值  为 number |
    | `.unknown(bool)` | 是否允许未知字段 | `.unknown(false)`（默认 `true`） |
    | `.min(n)` / `.max(n)` | 最少/最多字段数 | `.min(1)` |
    | `.length(n)` | 固定字段数 | `.length(2)` |
    | `.rename(from, to)` | 字段重命名 | `.rename('usr', 'user')` |
    | `.assert(ref, schema, [message])` | 断言子字段关系 | `.assert('password', Joi.ref('confirmPassword'), '密码不一致')` |

    **嵌套对象**

    ```js
    const schema = Joi.object({
      user: Joi.object({
        name: Joi.string().required(),
        contact: Joi.object({
          email: Joi.string().email()
        })
      })
    });
    ```

8. 数组（`Joi.array()`）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `.items(type)` | 元素类型 | `.items(Joi.string())` |
    | `.min(n)` / `.max(n)` | 长度限制 | `.min(1).max(10)` |
    | `.length(n)` | 固定长度 | `.length(5)` |
    | `.unique()` | 元素唯一 | `.unique()` |
    | `.ordered(...types)` | 按位置指定类型 | `.ordered(Joi.string(), Joi.number())` |

    ```js
    // 混合类型数组
    Joi.array().items(Joi.string(), Joi.number());
    ```


9. 联合类型（Alternatives）

    | 方法 | 说明 | 示例 |
    |------|------|------|
    | `Joi.alternatives()` | 多种可能类型 | `Joi.alternatives(Joi.string(), Joi.number())` |
    | `.try(...types)` | 添加可选类型 | 同上 |
    | `.conditional(ref, options)` | 条件分支 | 见下文 |

    条件校验（`.when()`）

    ```js
    const schema = Joi.object({
      role: Joi.string().valid('admin', 'user'),
      adminLevel: Joi.when('role', {
        is: 'admin',
        then: Joi.number().required(),
        otherwise: Joi.forbidden()
      })
    });
    ```

10. 引用与上下文（Advanced）

    | 方法 | 说明 |
    |------|------|
    | `Joi.ref('key')` | 引用同级字段 | `Joi.string().valid(Joi.ref('username'))` |
    | `Joi.context(key)` | 引用外部上下文（`validate(data, { context })`） |
    | `Joi.valid(...values)` | 枚举值 | `.valid('A', 'B', 'C')` |
    | `Joi.invalid(...values)` | 禁止值 | `.invalid('root', 'admin')` |
    | `Joi.allow(...values)` | 允许特殊值（如 null） | `.allow(null)` |


11. 校验选项（`validate()` 第二个参数）

```js
schema.validate(data, {
  abortEarly: false,     // 一次返回所有错误（默认 true）
  convert: true,         // 自动类型转换（如 "123" → 123）
  stripUnknown: true,    // 删除未知字段（object 有效）
  presence: 'required',  // 全局必填策略
  context: { userId: 1 } // 供 Joi.context 使用
});
```

12. 实用技巧

    1. 自定义错误消息
    ```js
    Joi.string()
      .min(3)
      .messages({
        'string.min': '用户名至少 {#limit} 个字符'
      });
    ```

    2. 扩展 Joi（自定义规则）
    ```js
    const myJoi = Joi.extend({
      type: 'phoneNumber',
      base: Joi.string(),
      messages: {
        'phoneNumber.invalid': '手机号格式错误'
      },
      validate(value, helpers) {
        const regex = /^1[3-9]\d{9}$/;
        if (!regex.test(value)) {
          return { value, errors: helpers.error('phoneNumber.invalid') };
        }
        return { value };
      }
    });

    myJoi.phoneNumber(); // 可用！
    ```
13. 总结

    Joi 的方法设计非常**链式、声明式、可读性强**，覆盖了几乎所有数据校验场景。掌握以下核心即可应对 90% 需求：

    - **基础类型**：`string()`, `number()`, `boolean()`, `date()`
    - **容器类型**：`object()`, `array()`
    - **约束**：`required()`, `min/max`, `valid/invalid`
    - **高级**：`when()`, `ref()`, `alternatives()`

### 1.1.2 原生 Joi（无需插件）

- 先安装：

    ```bash
    npm install joi
    ```

- 基本用法：

    ```js
    const Joi = require('joi');

    const schema = Joi.object({
      username: Joi.string().alphanum().min(3).max(30).required(),
      email: Joi.string().email().required(),
      age: Joi.number().integer().min(0).max(120)
    });

    const { error, value } = schema.validate({ username: 'abc', email: 'test@example.com' });
    if (error) {
      console.log(error.details[0].message); // 校验失败信息
    }
    ```

    > **Joi 本身是通用库，不依赖任何框架**。


### 1.1.3 在 Web 框架中的“插件式”集成

-  Express + `express-joi-validation`

    这是一个轻量中间件，用于自动校验 `req.body`、`req.query`、`req.params`。

-  安装

    ```bash
    npm install joi express-joi-validation
    ```

- 使用

    ```js
    const express = require('express');
    const Joi = require('joi');
    const { createValidator } = require('express-joi-validation');

    const app = express();
    app.use(express.json());

    const validator = createValidator();

    const userSchema = Joi.object({
      name: Joi.string().required(),
      email: Joi.string().email().required()
    });

    // 自动校验 req.body
    app.post('/users', validator.body(userSchema), (req, res) => {
      res.json({ success: true, data: req.body });
    });

    // 错误处理中间件（可选）
    app.use((err, req, res, next) => {
      if (err.type === 'VALIDATION_ERROR') {
        return res.status(400).json({ error: err.message });
      }
      next(err);
    });
    ```

### 1.1.4 Koa + `koa-joi-validator`

1. 安装

    ```bash
    npm install joi koa-joi-validator
    ```

2. 使用

    ```js
    const Koa = require('koa');
    const Joi = require('joi');
    const joiValidator = require('koa-joi-validator');

    const app = new Koa();

    const schema = Joi.object({
      id: Joi.number().integer().positive().required()
    });

    app.use(joiValidator({
      params: schema // 校验 URL 参数 /users/:id
    }));

    app.use(async ctx => {
      ctx.body = { id: ctx.params.id };
    });
    ```

### 1.1.5 Fastify + 内置支持

Fastify **原生支持 Joi**（也支持 JSON Schema）作为路由校验器。

1. 安装

    ```bash
    npm install fastify joi
    ```

2. 使用
    ```js
    const fastify = require('fastify')();
    const Joi = require('joi');

    fastify.post('/users', {
      schema: {
        body: Joi.object({
          name: Joi.string().required(),
          email: Joi.string().email().required()
        }).required()
      }
    }, async (request, reply) => {
      return { success: true, data: request.body };
    });

    // 自动返回 400 错误，无需手动处理
    ```

    >  Fastify 对 Joi 支持最优雅，**无需额外插件**。


### 1.1.6 NestJS + `@nestjs/joi`（官方集成）

NestJS 官方提供了 `ValidationPipe` 与 `class-validator` 集成，但也可用 Joi。

-  方式 1：自定义 Pipe（推荐）
    ```ts
    // joi-validation.pipe.ts
    import { PipeTransform, Injectable, BadRequestException } from '@nestjs/common';
    import * as Joi from 'joi';

    @Injectable()
    export class JoiValidationPipe implements PipeTransform {
      constructor(private readonly schema: Joi.ObjectSchema) {}

      transform(value: any) {
        const { error } = this.schema.validate(value);
        if ( error ) {
          throw new BadRequestException('Validation failed');
        }
        return value;
      }
    }
    ```

- 使用

    ```ts
    // user.controller.ts
    import { Body, Controller, Post } from '@nestjs/common';
    import { JoiValidationPipe } from './joi-validation.pipe';
    import * as Joi from 'joi';

    const createUserSchema = Joi.object({
      name: Joi.string().required(),
      email: Joi.string().email().required()
    });

    @Controller('users')
    export class UserController {
      @Post()
      create(@Body(new JoiValidationPipe(createUserSchema)) dto: any) {
        return dto;
      }
    }
    ```

    > 注意：NestJS 社区更常用 `class-validator` + `class-transformer`，但 Joi 依然可用。


### 1.1.7 安全建议

- **永远不要信任前端数据**，后端必须校验
- 使用 `.strict()` 防止未知字段（可选）
  ```js
  Joi.object({ name: Joi.string() }).unknown(false) // 默认 unknown(true)
  ```
- 敏感字段（如密码）应单独校验并加密



## 1.2 Zod 插件

`Zod` 是一个 **TypeScript 优先、零依赖、高性能** 的数据校验库，其最大优势是：**Schema 即类型（Schema → TypeScript Type 自动推导）**，实现真正的端到端类型安全。


- **官网**: [https://zod.dev/](https://zod.dev/)
- **GitHub**: [https://github.com/colinhacks/zod](https://github.com/colinhacks/zod)
- **API 文档**: [https://zod.dev/?id=quickstart](https://zod.dev/?id=quickstart)

> **适用场景**：  
> 
> - 全栈 TypeScript 项目  
> - 需要端到端类型安全  
> - 表单校验、API 输入校验、配置文件校验



### 1.2.1 快速上手

1. 安装

    ```bash
    npm install zod
    ```

2. 基础示例

    ```ts
    import { z } from 'zod';

    // 定义 schema
    const UserSchema = z.object({
      name: z.string().min(1, "姓名不能为空"),
      age: z.number().int().positive().lte(120, "年龄不能超过120岁"),
      email: z.string().email("邮箱格式不正确").optional(), // 可选字段
    });

    // 自动推导 TypeScript 类型！
    type User = z.infer<typeof UserSchema>;

    // 校验数据
    const userData = { name: "张三", age: 25 };
    const result = UserSchema.safeParse(userData);

    if (result.success) {
      console.log(result.data); // { name: "张三", age: 25 }
      // result.data 的类型是 User！
    } else {
      console.log(result.error.format()); // 友好错误信息
    }
    ```

### 1.2.2 核心类型与方法

1. 字符串

    ```ts
    z.string()
      .min(3)                // 最小长度
      .max(50)               // 最大长度
      .email()               // 邮箱
      .url()                 // URL
      .regex(/^[a-z]+$/)     // 正则
      .startsWith('user_')   // 以...开头
      .endsWith('@example.com')
      .trim()                // 去空格
      .toLowerCase()         // 转小写（校验后自动转换）
    ```

2. 数字

    ```ts
    z.number()
      .int()                 // 整数
      .positive()            // > 0
      .negative()            // < 0
      .min(0)                // ≥ 0
      .max(100)              // ≤ 100
      .multipleOf(5)         // 5 的倍数
    ```

3. 日期

    ```ts
    z.date()                 // 接受 Date 对象
      .min(new Date('1900-01-01'))
      .max(new Date());

    // 或解析字符串为日期
    z.string().datetime();   // ISO 8601 格式
    ```

4. 对象

    ```ts
    const PersonSchema = z.object({
      name: z.string(),
      address: z.object({    // 嵌套对象
        street: z.string(),
        city: z.string()
      }).optional(),         // 整个 address 可选
    });
    ```

5. 数组

    ```ts
    z.array(z.string())      // string[]
      .min(1)                // 至少1项
      .max(10)               // 最多10项
      .nonempty()            // 至少1项（同 min(1)）

    // 元组（固定长度+类型）
    z.tuple([z.string(), z.number()]); // [string, number]
    ```

6. 联合类型（Union）

    ```ts
    // 字符串或数字
    z.union([z.string(), z.number()]);

    // 简写
    z.string().or(z.number());
    ```

7. 可选/Nullable

    ```ts
    z.string().optional();   // string | undefined
    z.string().nullable();   // string | null
    z.string().nullish();    // string | null | undefined
    ```

8. 枚举

    ```ts
    // 字面量联合
    z.enum(['admin', 'user', 'guest']);

    // 或从数组生成
    const roles = ['admin', 'user'] as const;
    z.enum(roles);
    ```

### 1.2.3 高级功能

1. 条件校验（`.refine()`）

    ```ts
    const PasswordSchema = z.string()
      .min(8)
      .refine((value) => /[A-Z]/.test(value), "必须包含大写字母")
      .refine((value) => /\d/.test(value), "必须包含数字");
    ```

2. 异步校验（`.superRefine()`）

    ```ts
    const usernameSchema = z.string().superRefine(async (val, ctx) => {
      const exists = await checkUsernameExists(val);
      if (exists) {
        ctx.addIssue({
          code: 'custom',
          message: '用户名已存在'
        });
      }
    });
    ```
3. 默认值（`.default()`）

    ```ts
    z.string().default("guest"); // 如果字段缺失，设为 "guest"
    ```

4. 转换（`.transform()`）

    ```ts
    // 将字符串转为数字
    z.string().transform((str) => parseInt(str));

    // 或结合校验
    z.string()
      .regex(/^\d+$/)
      .transform(Number);
    ```

5. 条件分支（`.when()`）

    ```ts
    const schema = z.object({
      role: z.enum(['admin', 'user']),
      adminLevel: z.number().optional()
    }).refine(data => {
      if (data.role === 'admin' && data.adminLevel === undefined) {
        return false;
      }
      return true;
    }, { message: "管理员必须设置等级", path: ['adminLevel'] });
    ```

    >  Zod 没有直接的 `.when()`，但可用 `.refine()` 或 `.superRefine()` 实现。

### 1.2.4 与框架集成

1. Next.js / API Routes

    ```ts
    // pages/api/user.ts
    import { z } from 'zod';

    const UserSchema = z.object({ name: z.string() });

    export default function handler(req, res) {
      const result = UserSchema.safeParse(req.body);
      if (!result.success) {
        return res.status(400).json({ error: result.error.format() });
      }
      // result.data 类型安全！
    }
    ```

2. tRPC（完美搭档）

    ```ts
    import { z } from 'zod';
    import { createTRPCRouter, publicProcedure } from '~/server/api/trpc';

    export const userRouter = createTRPCRouter({
      create: publicProcedure
        .input(z.object({ name: z.string() }))
        .mutation(async ({ input }) => {
          // input 类型自动推导为 { name: string }
        }),
    });
    ```

3. React Hook Form

    ```tsx
    import { useForm } from 'react-hook-form';
    import { zodResolver } from '@hookform/resolvers/zod';

    const schema = z.object({ email: z.string().email() });

    function MyForm() {
      const { register, handleSubmit } = useForm({
        resolver: zodResolver(schema)
      });
    }
    ```

### 1.2.5 错误处理

1. 获取结构化错误

    ```ts
    const result = UserSchema.safeParse(invalidData);
    if (!result.success) {
      console.log(result.error.flatten());
      // {
      //   fieldErrors: { name: ['姓名不能为空'] },
      //   formErrors: []
      // }
    }
    ```

2. 自定义错误消息

    ```ts
    z.string({
      required_error: "此字段必填",
      invalid_type_error: "必须是字符串"
    }).min(1, "至少1个字符");
    ```


### 1.2.6 实用技巧

1. 复用 Schema

    ```ts
    const IdSchema = z.string().uuid();
    const UserSchema = z.object({ id: IdSchema });
    const PostSchema = z.object({ authorId: IdSchema });
    ```

2. 扩展 Schema

    ```ts
    const BaseUser = z.object({ name: z.string() });
    const AdminUser = BaseUser.extend({ role: z.literal('admin') });
    ```

3. 严格模式（禁止未知字段）

    ```ts

    ```

4. 生成 Mock 数据（需 `@anatine/zod-mock`）

    ```ts
    import { zodMock } from '@anatine/zod-mock';
    const mockUser = zodMock(UserSchema);
    ```

## 1.3 Ajv 插件

`Ajv`（Another JSON Schema Validator）是 **JavaScript 中最流行、性能最强的 JSON Schema 校验库**，广泛用于 API 网关、OpenAPI/Swagger 集成、配置校验等场景。它严格遵循 [JSON Schema](https://json-schema.org/) 国际标准（支持 Draft 04/06/07/2019-09/2020-12），并支持自定义关键字、异步校验、编译优化等高级功能。

`Ajv` 是 **企业级、标准化、高性能** 数据校验的首选，特别适合：

- 微服务 API 输入校验
- OpenAPI/Swagger 工具链集成
- 配置文件校验（如 YAML/JSON 配置）
- 需要跨语言一致性的场景（因 JSON Schema 是通用标准）

### 1.3.1 快速上手

1. 安装

    ```bash
    npm install ajv
    ```

2. 基础示例

    ```js
    const Ajv = require('ajv');
    const ajv = new Ajv(); // 创建校验器实例

    // 定义 JSON Schema
    const userSchema = {
      type: 'object',
      properties: {
        name: { type: 'string', minLength: 1 },
        age: { type: 'integer', minimum: 0, maximum: 120 },
        email: { type: 'string', format: 'email' }
      },
      required: ['name', 'age'],
      additionalProperties: false // 禁止额外字段
    };

    // 编译 schema（生成高效校验函数）
    const validate = ajv.compile(userSchema);

    // 校验数据
    const userData = { name: '张三', age: 25, email: 'zhang@example.com' };
    const valid = validate(userData);

    if (!valid) {
      console.log(validate.errors); // 错误详情
    } else {
      console.log('校验通过！');
    }
    ```

> **核心流程**：  
> `new Ajv()` → `ajv.compile(schema)` → `validate(data)`

### 1.3.2 JSON Schema 核心语法速查

| 功能 | Schema 写法 |
|------|-----------|
| **必填字段** | `"required": ["name"]` |
| **字符串长度** | `"minLength": 3, "maxLength": 50` |
| **数字范围** | `"minimum": 0, "maximum": 100` |
| **整数** | `"type": "integer"` |
| **邮箱格式** | `"format": "email"` |
| **URL 格式** | `"format": "uri"` |
| **正则匹配** | `"pattern": "^[a-z]+$"` |
| **枚举值** | `"enum": ["admin", "user"]` |
| **禁止额外字段** | `"additionalProperties": false` |
| **可选字段** | 不在 `required` 中即为可选 |

> 注意：`format` 关键字默认**不启用**，需配置 `ajv.addFormat()` 或使用 `ajv-formats` 插件。

### 1.3.3 常用配置选项

```js
const Ajv = require('ajv');
const ajv = new Ajv({
  strict: true,           // 严格模式（推荐开启）
  allErrors: true,        // 返回所有错误（默认只返回第一个）
  verbose: true,          // 错误包含 schema 路径
  coerceTypes: true,      // 自动类型转换（如 "123" → 123）
  useDefaults: true,      // 自动填充 default 值
  removeAdditional: true  // 自动删除 unknown 字段
});
```

### 1.3.4 插件与扩展

1. 启用 `format` 校验（邮箱、URL 等）

    ```js
    const Ajv = require('ajv');
    const addFormats = require('ajv-formats');

    const ajv = new Ajv();
    addFormats(ajv); // 启用 email, uri, date, ipv4 等格式

    const schema = {
      type: 'object',
      properties: {
        email: { type: 'string', format: 'email' }
      },
      required: ['email']
    };
    ```

    > 安装：`npm install ajv-formats`

2. 支持 OpenAPI/Swagger（使用 `ajv-oai`）

    ```js
    const Ajv = require('ajv');
    const addOAIFormats = require('ajv-oai');

    const ajv = new Ajv();
    addOAIFormats(ajv);
    ```

3. 自定义关键字（如 `customKeyword`）

    ```js
    ajv.addKeyword({
      keyword: 'myCustomRule',
      validate: function (schema, data) {
        return data.length > schema.minLength;
      },
      errors: false
    });

    const schema = {
      type: 'string',
      myCustomRule: { minLength: 5 }
    };
    ```

### 1.3.5 错误处理

1. 获取结构化错误

    ```js
    if (!validate(data)) {
      validate.errors.forEach(err => {
        console.log(
          `字段 ${err.instancePath || 'root'} 错误: ${err.message}`
        );
        // 示例输出: 字段 /email 错误: must match format "email"
      });
    }
    ```

2. 自定义错误消息

    ```js
    // 方法1：替换 message
    ajv.addKeyword({
      keyword: 'myEmail',
      validate: (schema, data) => /\S+@\S+\.\S+/.test(data),
      error: {
        message: '必须是有效的邮箱地址'
      }
    });

    // 方法2：使用 i18n（需额外库）
    ```

### 1.3.6 高性能技巧

1. 预编译 Schema（避免重复解析）

    ```js
    //  好：编译一次，多次使用
    const validateUser = ajv.compile(userSchema);
    app.post('/users', (req, res) => {
      if (!validateUser(req.body)) {
        return res.status(400).json({ errors: validateUser.errors });
      }
    });
    ```

2. 使用 `standalone` 代码生成（极致性能）

    ```js
    const standaloneCode = ajv.compileSchema(userSchema).source;
    // 生成独立 JS 函数，无需 Ajv 运行时
    ```
3. 启用 `$async`（异步校验）

    ```js
    const schema = {
      type: 'string',
      async: true,
      validate: async (data) => {
        return await checkInDatabase(data);
      }
    };

    const validate = ajv.compile(schema);
    const valid = await validate(data); // 注意：返回 Promise
    ```

### 1.3.7 与框架集成

1. Express 中间件

    ```js
    function validateBody(schema) {
      const validate = ajv.compile(schema);
      return (req, res, next) => {
        if (!validate(req.body)) {
          return res.status(400).json({ errors: validate.errors });
        }
        next();
      };
    }

    app.post('/users', validateBody(userSchema), (req, res) => {
      res.json(req.body);
    });
    ```

2. Fastify（内置支持 JSON Schema）

    ```js
    fastify.post('/users', {
      schema: {
        body: userSchema // 直接使用 JSON Schema
      }
    }, async (request, reply) => {
      return request.body;
    });
    ```

3. NestJS（配合 class-validator 或直接使用）

    ```ts
    // 在 Guard 或 Pipe 中使用
    @Injectable()
    export class ValidationPipe implements PipeTransform {
      transform(value: any, metadata: ArgumentMetadata) {
        const schema = getSchemaFor(metadata.metatype); // 自定义映射
        const validate = ajv.compile(schema);
        if (!validate(value)) throw new BadRequestException(validate.errors);
        return value;
      }
    }
    ```
