# 五、加密工具

## 5.1 哈希加密 bcryptjs

`bcryptjs` 是 Node.js 中用于 **安全哈希和比对密码** 的流行库。它基于 **bcrypt 算法**，专为密码存储设计，具有 **自适应计算强度（salt rounds）** 和 **内置盐值（salt）**，能有效抵御彩虹表攻击和暴力破解。

> **为什么不用 MD5/SHA1？**  
> 它们是**快速哈希算法**，适合校验文件完整性，但**不适合密码存储**——攻击者可用 GPU 每秒尝试数十亿次破解。  
> 而 `bcrypt` 是**慢速哈希**（故意计算耗时），大幅增加破解成本。

### 5.1.1 安装

```bash
npm install bcryptjs
```

> TypeScript 用户建议安装类型定义：
> ```bash
> npm install --save-dev @types/bcryptjs
> ```

### 5.1.2 核心 API

1. `bcrypt.hash(password, saltRounds)` → 生成哈希密码（异步）

    ```ts
    import * as bcrypt from 'bcryptjs';

    const password = 'mySecretPassword123';
    const saltRounds = 12; // 推荐 10~14（越高越安全，但越慢）

    // 异步方式（推荐）
    const hashedPassword = await bcrypt.hash(password, saltRounds);
    console.log(hashedPassword);
    // $2a$12$VrXqZ6vJ7K8L9M0N1O2P3Q4R5S6T7U8V9W0X1Y2Z3a4b5c6d7e8f9g0h
    ```

    同步方式（不推荐，阻塞事件循环）
    
    ```ts
    const hashedPassword = bcrypt.hashSync(password, saltRounds);
    ```

    >  **saltRounds 选择**：  
    > - `10`：约 100ms（平衡安全与性能）  
    > - `12`：约 400ms（更安全，现代服务器可接受）  
    > - `>15`：可能超时（谨慎使用）



2. `bcrypt.compare(plainPassword, hashedPassword)` → 验证密码（异步）

    ```ts
    const isMatch = await bcrypt.compare('userInputPassword', hashedPassword);

    if (isMatch) {
      console.log('密码正确');
    } else {
      console.log('密码错误');
    }
    ```

    同步方式

    ```ts
    const isMatch = bcrypt.compareSync('userInputPassword', hashedPassword);
    ```

    > **关键优势**：  
    > `compare` 会自动从 `hashedPassword` 中提取 salt 和 rounds，无需额外存储！



3. 其他工具方法（较少用）

    | 方法 | 说明 |
    |------|------|
    | `bcrypt.genSalt(rounds)` | 手动生成 salt（通常不需要） |
    | `bcrypt.getRounds(hashed)` | 获取哈希的 rounds 值 |

### 5.1.3 在用户注册/登录中的完整流程

**场景：Express + TypeScript 示例**


1. 用户注册（哈希密码后存入数据库）

    ```ts
    // POST /register
    app.post('/register', async (req, res) => {
      const { email, password } = req.body;

      // 1. 验证输入（省略）
      if (!email || !password) {
        return res.status(400).json({ error: 'Email and password required' });
      }

      try {
        // 2. 哈希密码
        const hashedPassword = await bcrypt.hash(password, 12);

        // 3. 保存到数据库（伪代码）
        const user = await db.createUser({
          email,
          password: hashedPassword // 存储哈希值！
        });

        res.status(201).json({ message: 'User created', userId: user.id });
      } catch (err) {
        res.status(500).json({ error: 'Registration failed' });
      }
    });
    ```

2. 用户登录（比对密码）

    ```ts
    // POST /login
    app.post('/login', async (req, res) => {
      const { email, password } = req.body;

      try {
        // 1. 从数据库查用户
        const user = await db.findUserByEmail(email);
        if (!user) {
          return res.status(401).json({ error: 'Invalid credentials' });
        }

        // 2. 比对密码
        const isPasswordValid = await bcrypt.compare(password, user.password);
        if (!isPasswordValid) {
          return res.status(401).json({ error: 'Invalid credentials' });
        }

        // 3. 生成 JWT 或 Session（此处省略）
        res.json({ message: 'Login successful', userId: user.id });
      } catch (err) {
        res.status(500).json({ error: 'Login failed' });
      }
    });
    ```

### 5.1.4 安全最佳实践

| 实践 | 说明 |
|------|------|
| **永远不要存储明文密码** | 即使是临时日志也不行 |
| **使用足够高的 saltRounds** | 推荐 `12`（2024 年标准） |
| **密码长度限制** | bcrypt 最多处理 72 字节，超长部分被忽略 → 建议前端限制 ≤ 72 字符 |
| **不要自己实现 salt** | `bcrypt.hash()` 自动生成唯一 salt |
| **升级旧哈希** | 如果用户很久未登录，可用更高 rounds 重新哈希（平滑升级） |

> **为什么 bcrypt 只处理 72 字节？**  
> 这是算法设计限制。解决方案：先用 SHA-256 哈希密码，再传给 bcrypt：
> ```ts
> const sha256Password = crypto.createHash('sha256').update(password).digest('hex');
> const hashed = await bcrypt.hash(sha256Password, 12);
> ```
> 但 **一般不需要**，72 字符已足够安全。


### 5.1.5 在 NestJS 中使用

1. 安装

    ```bash
    npm install bcryptjs
    npm install --save-dev @types/bcryptjs
    ```

2. 创建密码服务

    ```ts
    // auth/password.service.ts
    import { Injectable } from '@nestjs/common';
    import * as bcrypt from 'bcryptjs';

    @Injectable()
    export class PasswordService {
      async hashPassword(password: string): Promise<string> {
        return bcrypt.hash(password, 12);
      }

      async comparePassword(plain: string, hashed: string): Promise<boolean> {
        return bcrypt.compare(plain, hashed);
      }
    }
    ```

3. 在 Auth 模块中使用

    ```ts
    // auth.service.ts
    @Injectable()
    export class AuthService {
      constructor(private passwordService: PasswordService) {}

      async register(email: string, password: string) {
        const hashedPassword = await this.passwordService.hashPassword(password);
        return this.usersService.create({ email, password: hashedPassword });
      }

      async validateUser(email: string, password: string) {
        const user = await this.usersService.findByEmail(email);
        if (user && await this.passwordService.comparePassword(password, user.password)) {
          return user;
        }
        return null;
      }
    }
    ```

### 5.1.6 常见错误

- 错误 1：同步方法阻塞服务器

    ```ts
    // 危险！高并发下会阻塞事件循环
    const hashed = bcrypt.hashSync(password, 12);
    ```
    **始终用 `async/await`**

- 错误 2：重复使用 salt

    ```ts
    // 错误！每个密码必须有唯一 salt
    const salt = bcrypt.genSaltSync(12);
    const hash1 = bcrypt.hashSync('password1', salt);
    const hash2 = bcrypt.hashSync('password2', salt); // 相同 salt！
    ```
    **直接调用 `bcrypt.hash(password, rounds)`**（自动处理 salt）

- 错误 3：密码验证逻辑泄露信息

    ```ts
    // 危险！通过响应时间可判断用户是否存在
    if (!user) return res.status(401).send('User not found'); // 快速返回
    const valid = await bcrypt.compare(password, user.password); // 慢
    ```
    **统一响应时间**：

    ```ts
    // 即使用户不存在，也执行一次 compare
    const dummyHash = '$2a$10$...'; // 无效哈希
    const isValid = user 
      ? await bcrypt.compare(password, user.password)
      : await bcrypt.compare(password, dummyHash);

    if (!isValid) {
      return res.status(401).json({ error: 'Invalid credentials' });
    }
    ```

## 5.2 md5 加密

`MD5`（Message-Digest Algorithm 5）是一种广泛使用的 **哈希算法**，可将任意长度的数据映射为 **128 位（16 字节）的固定长度哈希值**，通常以 **32 位十六进制字符串** 表示。

重要警告：**MD5 不适合用于密码存储！**

| 用途 | 是否推荐 | 原因 |
|------|--------|------|
| **密码哈希** | 绝对不要 | 计算极快，易被彩虹表/暴力破解 |
| **文件校验** | 可用（但有更好选择） | 检测意外损坏（非恶意篡改） |
| **生成唯一 ID / 缓存键** |可用 | 非安全敏感场景 |
| **数字签名 / 安全认证** |  不要 | 已被证明存在碰撞漏洞 |

> **密码存储请使用 `bcrypt`、`scrypt` 或 `argon2`**  
> **文件完整性校验推荐 `SHA-256`**


### 5.2.1 Node.js 中使用 MD5

Node.js 内置 `crypto` 模块，无需安装第三方库：

```js
const crypto = require('crypto');

function md5(str) {
  return crypto.createHash('md5').update(str).digest('hex');
}

console.log(md5('hello')); 
// 输出: 5d41402abc4b2a76b9719d911017c592
```

**支持 Buffer 或字符串**

```js
// 字符串（默认 UTF-8）
md5('hello')

// 指定编码
md5(Buffer.from('hello', 'utf8'))

// 文件流（大文件）
const fs = require('fs');
const hash = crypto.createHash('md5');
fs.createReadStream('file.txt').pipe(hash);
hash.on('readable', () => {
  const digest = hash.read();
  console.log(digest.toString('hex'));
});
```

### 5.2.2 常见使用场景（非密码）

1. 生成缓存键（Cache Key）

    ```js
    // 根据 API 参数生成唯一缓存 ID
    const cacheKey = md5(JSON.stringify({ userId: 123, lang: 'en' }));
    redis.get(cacheKey);
    ```

2. 文件内容校验（检测传输错误）

    ```js
    // 下载文件后校验
    const localFileHash = md5(fs.readFileSync('downloaded.zip'));
    if (localFileHash === expectedHashFromServer) {
      console.log(' 文件完整');
    }
    ```

    > **注意**：MD5 无法防御**恶意篡改**（攻击者可同时修改文件和哈希值），需配合数字签名。

3. 生成 Gravatar 头像 URL

    ```js
    // Gravatar 使用邮箱的 MD5 作为头像 ID
    const email = 'alice@example.com';
    const gravatarUrl = `https://www.gravatar.com/avatar/${md5(email.toLowerCase().trim())}`;
    // https://www.gravatar.com/avatar/5d41402abc4b2a76b9719d911017c592
    ```

4. 简单数据指纹（去重）

    ```js
    // 判断两段文本是否相同
    if (md5(text1) === md5(text2)) {
      console.log('内容可能相同');
    }
    ```

    > **注意**：存在极低概率的**哈希碰撞**（不同内容产生相同 MD5），关键场景需二次验证。
