# 七、日志相关

## 7.1 pino

`pino` 是一个 **超高速、低开销、JSON 格式优先** 的 Node.js 日志库，专为现代高性能应用设计。它比 `winston`、`bunyan` 等传统日志库快 3–6 倍，且内存占用极低，被 Fastify、Next.js（可选）、Vercel 等广泛采用。


- GitHub: [https://github.com/pinojs/pino](https://github.com/pinojs/pino)
- 文档: [https://getpino.io/#/](https://getpino.io/#/)
- 生态插件: [https://getpino.io/#/docs/ecosystem](https://getpino.io/#/docs/ecosystem)
- 性能基准: [https://github.com/pinojs/pino/blob/master/benchmarks.md](https://github.com/pinojs/pino/blob/master/benchmarks.md)


> **核心优势**：  
> - 极致性能（每秒百万级日志）  
> - 默认输出结构化 JSON（便于 ELK/Splunk/Grafana 分析）  
> - 插件化（支持传输、格式化、序列化扩展）  
> - 内置日志级别、子记录器、红acted（敏感字段脱敏）  


### 7.1.1 安装与基础用法

1. 安装

    ```bash
    npm install pino
    ```
2. 最简示例

    ```js
    // logger.js
    const pino = require('pino');

    // 创建 logger 实例
    const logger = pino();

    // 输出日志（默认写入 stdout）
    logger.info('Hello Pino!');
    logger.error({ err: new Error('Oops') }, 'Something went wrong');
    ```

    **输出（JSON 格式）**：
    ```json
    {"level":30,"time":1705658400000,"pid":12345,"hostname":"my-pc","msg":"Hello Pino!"}
    {"level":50,"time":1705658401000,"pid":12345,"hostname":"my-pc","err":{"type":"Error",  "message":"Oops",...},"msg":"Something went wrong"}
    ```

    > **日志级别**：  
    > `fatal` (60) > `error` (50) > `warn` (40) > `info` (30) > `debug` (20) > `trace` (10)

### 7.1.2 常用配置选项

1. 自定义输出目标

    ```js
    const logger = pino({
      // 写入文件（不推荐生产环境直接写文件）
      transport: {
        target: 'pino-pretty', // 开发环境美化输出
        options: { colorize: true }
      },
      // 或直接指定 stream
      // stream: fs.createWriteStream('/var/log/app.log')
    });
    ```

2. 开发环境美化日志（推荐）

    ```bash
    npm install pino-pretty
    ```

    ```js
    const logger = pino({
      transport: {
        target: 'pino-pretty',
        options: {
          colorize: true,
          translateTime: 'SYS:standard',
          ignore: 'pid,hostname' // 隐藏字段
        }
      }
    });
    ```

    **美化后输出**：

    ```
    [19:00:00.000] INFO (12345 on my-pc): Hello Pino!
    [19:00:01.000] ERROR (12345 on my-pc): Something went wrong
        err: {
          "type": "Error",
          "message": "Oops",
          ...
        }
    ```

3. 生产环境配置（JSON + 文件轮转）

    ```bash
    npm install pino-rotating-file-stream
    ```

    ```js
    const pino = require('pino');
    const rotatingFileStream = require('pino-rotating-file-stream');

    const logger = pino({
      level: 'info', // 只记录 info 及以上级别
      serializers: {
        err: pino.stdSerializers.err // 标准化错误对象
      }
    }, rotatingFileStream({
      file: '/var/log/app.log',
      rotate: '1d', // 每天轮转
      maxSize: '100M'
    }));
    ```

### 7.1.3 高级功能

1. 子记录器（Child Logger）

    用于添加上下文（如请求 ID、用户 ID）

    ```js
    const httpLogger = logger.child({ service: 'http' });

    app.use((req, res, next) => {
      const reqId = generateId();
      req.log = httpLogger.child({ reqId });
      req.log.info('Request received');
      next();
    });

    // 在路由中
    app.get('/', (req, res) => {
      req.log.info('Handling request');
      res.send('OK');
    });
    ```

2. 敏感字段脱敏（Redact）

    自动隐藏密码、token 等字段

    ```js
    const logger = pino({
      redact: ['password', 'accessToken', 'user.creditCard']
    });

    logger.info({
      user: { name: 'Alice', password: 'secret123', creditCard: '1234' }
    });
    // 输出: { user: { name: 'Alice', password: '[Redacted]', creditCard: '[Redacted]' } }
    ```

3. 自定义序列化器

    ```js
    const logger = pino({
      serializers: {
        user: (user) => ({
          id: user.id,
          email: user.email // 隐藏其他字段
        })
      }
    });

    logger.info({ user: { id: 1, email: 'a@example.com', password: 'xxx' } });
    // 输出: { user: { id: 1, email: 'a@example.com' } }
    ```


### 7.1.4 在 Web 框架中集成

- Express 示例

    ```js
    const express = require('express');
    const pino = require('pino');
    const expressPino = require('express-pino-logger');

    const logger = pino({ level: process.env.LOG_LEVEL || 'info' });
    const app = express();

    // 使用中间件自动记录 HTTP 请求
    app.use(expressPino({ logger }));

    app.get('/', (req, res) => {
      req.log.info('Custom log in route');
      res.send('Hello');
    });

    app.listen(3000);
    ```

- Fastify（原生集成）

    ```js
    const fastify = require('fastify')({
      logger: {
        level: 'info',
        transport: { target: 'pino-pretty' } // 仅开发环境
      }
    });

    fastify.get('/', async (request, reply) => {
      request.log.info('Handling request');
      return { hello: 'world' };
    });

    fastify.listen({ port: 3000 });
    ```

- NestJS

    ```ts
    // main.ts
    import { Logger } from 'nestjs-pino';

    async function bootstrap() {
      const app = await NestFactory.create(AppModule, {
        bufferLogs: true, // 缓冲启动日志
      });
      app.useLogger(app.get(Logger)); // 使用 Pino 作为全局 logger
      await app.listen(3000);
    }
    ```

### 7.1.5 日志分析与监控

1. 与 ELK Stack 集成

    **Filebeat** 收集 JSON 日志 → **Logstash**（可选处理） → **Elasticsearch** → **Kibana** 可视化

2. 与 Grafana Loki

    使用 `pino-loki` 直接推送日志到 Loki

    ```bash
    npm install pino-loki
    ```

    ```js
    const pino = require('pino');
    const { createWriteStream } = require('pino-loki');

    const stream = createWriteStream({
      host: 'http://loki:3100',
      labels: { job: 'my-app' }
    });

    const logger = pino(stream);
    ```

3. 结构化查询示例（Kibana/Loki）

    ```sql
    -- 查找所有 error 日志
    level: "error"

    -- 查找特定用户操作
    user.id: "123" AND msg: "login"
    ```


## 7.2 winston


`winston` 是 Node.js 生态中最流行、功能最全面的 **日志记录库** 之一，支持多传输（Transports）、多格式（Formats）、日志级别控制、异常捕获、日志轮转等高级特性。虽然性能略逊于 `pino`，但其灵活性和插件生态使其在企业级应用中广泛使用。

- GitHub: [https://github.com/winstonjs/winston](https://github.com/winstonjs/winston)
- 文档: [https://github.com/winstonjs/winston/blob/master/README.md](https://github.com/winstonjs/winston/blob/master/README.md)
- Transports 列表: [https://github.com/winstonjs/winston/blob/master/docs/transports.md](https://github.com/winstonjs/winston/blob/master/docs/transports.md)
- 社区插件: [https://www.npmjs.com/search?q=winston](https://www.npmjs.com/search?q=winston)



### 7.1.1 安装与基础用法

1. 安装

    ```bash
    npm install winston
    ```

2. 最简示例

    ```js
    const winston = require('winston');

    // 创建 logger 实例（默认输出到 console）
    const logger = winston.createLogger({
      level: 'info',
      format: winston.format.json(),
      transports: [new winston.transports.Console()]
    });

    logger.info('Hello Winston!');
    logger.error('Something went wrong', { error: new Error('Oops') });
    ```

    **JSON 输出**：
    ```json
    {"level":"info","message":"Hello Winston!","timestamp":"2026-01-19T10:00:00.000Z"}
    {"level":"error","message":"Something went wrong","error":{},"timestamp":"2026-01-19T10:00:01.000Z"}
    ```

### 7.1.2 核心概念

| 概念 | 说明 |
|------|------|
| **Logger** | 日志记录器实例，可配置级别、格式、传输方式 |
| **Transports** | 日志输出目标（Console、File、HTTP、数据库等） |
| **Formats** | 日志格式化方式（JSON、简单文本、颜色、时间戳等） |
| **Levels** | 日志级别（`error` > `warn` > `info` > `http` > `verbose` > `debug` > `silly`） |

> Winston 默认级别顺序（从高到低）：  
> `error` → `warn` → `info` → `http` → `verbose` → `debug` → `silly`


### 7.1.3 常用配置示例

1. 开发环境：带颜色的简洁日志

    ```js
    const logger = winston.createLogger({
      level: 'debug',
      format: winston.format.combine(
        winston.format.colorize(),      // 添加颜色
        winston.format.timestamp(),     // 添加时间戳
        winston.format.simple()         // 简单文本格式
      ),
      transports: [new winston.transports.Console()]
    });

    logger.info('User logged in'); 
    // 输出: info: User logged in {"timestamp":"2026-01-19T10:00:00.000Z"}
    ```

2. 生产环境：JSON + 文件轮转

    ```bash
    npm install winston-daily-rotate-file
    ```

    ```js
    const DailyRotateFile = require('winston-daily-rotate-file');

    const logger = winston.createLogger({
      level: 'info',
      format: winston.format.json(),
      transports: [
        new winston.transports.Console(),
        new DailyRotateFile({
          filename: 'logs/application-%DATE%.log',
          datePattern: 'YYYY-MM-DD',
          zippedArchive: true,
          maxSize: '20m',
          maxFiles: '14d'
        })
      ]
    });
    ```

3. 多传输（同时输出到文件和控制台）

    ```js
    const logger = winston.createLogger({
      level: 'info',
      format: winston.format.combine(
        winston.format.timestamp(),
        winston.format.json()
      ),
      transports: [
        new winston.transports.File({ filename: 'error.log', level: 'error' }),
        new winston.transports.File({ filename: 'combined.log' }),
        new winston.transports.Console({
          format: winston.format.simple()
        })
      ]
    });
    ```


### 7.1.4 敏感信息脱敏（Redaction）

Winston 本身不直接支持字段脱敏，但可通过自定义格式实现：

```js
const redactFormat = winston.format((info) => {
  if (info.password) info.password = '[REDACTED]';
  if (info.token) info.token = '[REDACTED]';
  return info;
});

const logger = winston.createLogger({
  format: winston.format.combine(
    redactFormat(),
    winston.format.json()
  ),
  transports: [new winston.transports.Console()]
});

logger.info({ user: 'alice', password: 'secret123' });
// 输出: {"user":"alice","password":"[REDACTED]"}
```

>  更强大的方案：结合 `pino` 的 `redact` 或使用中间件预处理日志对象。

### 7.1.5 异常与未捕获错误处理

自动捕获未处理的 Promise rejection 和异常

```js
const logger = winston.createLogger({
    transports: [new winston.transports.File({ filename: 'exceptions.log' })]
});

// 捕获未处理的异常
process.on('uncaughtException', (err) => {
    logger.error('Uncaught Exception:', err);
    process.exit(1);
});

// 捕获未处理的 Promise rejection
process.on('unhandledRejection', (reason, promise) => {
    logger.error('Unhandled Rejection at:', promise, 'reason:', reason);
    process.exit(1);
});
```

> **最佳实践**：在生产环境中必须处理这两类错误，避免进程静默退出。


### 7.1.6 在 Web 框架中集成

**Express 示例**

```js
const express = require('express');
const app = express();

// 全局 logger
app.locals.logger = logger;

app.use((req, res, next) => {
    req.log = logger.child({ requestId: Date.now() }); // 子 logger（需 winston@3.3+）
    req.log.info('Request received');
    next();
});

app.get('/', (req, res) => {
    req.log.info('Handling request');
    res.send('OK');
});
```

> 注意：Winston 原生不支持 `child()`，需使用 `winston.createLogger({ ... })` 手动创建子实例，或使用 `winston-container`。
