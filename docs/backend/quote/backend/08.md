# 八、API文档


## 8.1 swagger文档

`swagger-jsdoc` + `swagger-ui-express` 是在 **Node.js（Express）项目中自动生成和展示 OpenAPI（Swagger）文档** 的经典组合。它允许你通过 **JSDoc 注释** 描述 API，自动聚合生成 OpenAPI 规范，并通过 Web UI 可视化交互式文档。

- swagger-jsdoc: [https://github.com/Surnet/swagger-jsdoc](https://github.com/Surnet/swagger-jsdoc)
- swagger-ui-express: [https://github.com/scottie1984/swagger-ui-express](https://github.com/scottie1984/swagger-ui-express)
- OpenAPI 3.0 规范: [https://swagger.io/specification/](https://swagger.io/specification/)
- Swagger Editor（在线编辑）: [https://editor.swagger.io/](https://editor.swagger.io/)


> **最佳实践总结**：  
> **1. 将 `@swagger` 注释紧贴路由处理函数**  
> **2. 复用 `components.schemas` 避免重复定义模型**  
> **3. 生产环境禁用 Swagger UI（或加身份验证）**  
> **4. 结合 `express-validator` 自动生成参数校验文档**


> **优势**：  
> - 代码即文档（避免文档与实现脱节）  
> - 自动生成交互式 UI（支持在线测试 API）  
> - 符合 OpenAPI 3.0 标准  
> - 无缝集成 Express  

### 8.1.1 安装依赖

```bash
npm install swagger-jsdoc swagger-ui-express
```

> 如果使用 TypeScript，建议额外安装类型定义：
> ```bash
> npm install -D @types/swagger-jsdoc @types/swagger-ui-express
> ```


### 8.1.2 基础配置步骤

1. 创建 Swagger 配置文件（`swaggerOptions.js`）

    ```js
    // config/swaggerOptions.js
    const swaggerJsdoc = require('swagger-jsdoc');

    const options = {
      definition: {
        openapi: '3.0.0',
        info: {
          title: 'My API',
          version: '1.0.0',
          description: 'A sample API with Swagger',
        },
        servers: [
          {
            url: 'http://localhost:3000', // 开发环境
            description: 'Development server'
          },
          {
            url: 'https://api.example.com', // 生产环境
            description: 'Production server'
          }
        ],
        components: {
          securitySchemes: {
            bearerAuth: {
              type: 'http',
              scheme: 'bearer',
              bearerFormat: 'JWT',
            }
          }
        },
        security: [{ bearerAuth: [] }] // 全局安全策略（可选）
      },
      apis: ['./routes/*.js'], // 指向包含 JSDoc 注释的路由文件
    };

    const swaggerSpec = swaggerJsdoc(options);
    module.exports = swaggerSpec;
    ```

    >  **关键字段说明**：
    > - `openapi`: 使用 OpenAPI 3.0（推荐）
    > - `servers`: API 基础路径（支持多环境）
    > - `components.securitySchemes`: 定义认证方式（如 JWT）
    > - `apis`: **必须指定** 包含 JSDoc 的文件路径（支持 glob）


2. 在路由文件中编写 JSDoc 注释


    ```js
    // routes/users.js
    const express = require('express');
    const router = express.Router();

    /**
     * @swagger
     * /users:
     *   get:
     *     summary: 获取用户列表
     *     tags: [Users]
     *     responses:
     *       200:
     *         description: 用户列表
     *         content:
     *           application/json:
     *             schema:
     *               type: array
     *               items:
     *                 $ref: '#/components/schemas/User'
     */
    router.get('/users', (req, res) => {
      res.json([{ id: 1, name: 'Alice' }]);
    });

    /**
     * @swagger
     * /users/{id}:
     *   get:
     *     summary: 根据 ID 获取用户
     *     tags: [Users]
     *     parameters:
     *       - in: path
     *         name: id
     *         required: true
     *         schema:
     *           type: integer
     *     responses:
     *       200:
     *         description: 单个用户
     *         content:
     *           application/json:
     *             schema:
     *               $ref: '#/components/schemas/User'
     *       404:
     *         description: 用户不存在
     */
    router.get('/users/:id', (req, res) => {
      const { id } = req.params;
      res.json({ id, name: 'Alice' });
    });

    /**
     * @swagger
     * components:
     *   schemas:
     *     User:
     *       type: object
     *       required:
     *         - id
     *         - name
     *       properties:
     *         id:
     *           type: integer
     *           example: 1
     *         name:
     *           type: string
     *           example: Alice
     */
    module.exports = router;
    ```

    > **JSDoc 规则**：
    > - 必须以 `@swagger` 开头
    > - 结构严格遵循 [OpenAPI 3.0 规范](https://swagger.io/specification/)
    > - 使用 `$ref` 引用复用组件（如 `User` 模型）

3. 在 Express 应用中集成 Swagger UI


    ```js
    // app.js
    const express = require('express');
    const swaggerUi = require('swagger-ui-express');
    const swaggerSpec = require('./config/swaggerOptions');

    const app = express();

    // 挂载 Swagger UI
    app.use('/api-docs', swaggerUi.serve, swaggerUi.setup(swaggerSpec));

    // 挂载你的路由
    app.use('/api', require('./routes/users'));

    app.listen(3000, () => {
      console.log('Server running on http://localhost:3000');
      console.log('Swagger docs available at http://localhost:3000/api-docs');
    });
    ```

### 8.1.3 访问 Swagger UI

启动应用后，访问：

```
http://localhost:3000/api-docs
```

你将看到：
- 交互式 API 文档
- 支持直接在浏览器中 **发送请求测试**
- 自动填充认证 Token（如果配置了安全方案）
- 按 `tags` 分组（如 `Users`）



### 8.1.4 添加 JWT 认证支持

1. 在 JSDoc 中为特定接口启用认证
 
    ```js
    /**
     * @swagger
     * /profile:
     *   get:
     *     summary: 获取当前用户资料（需认证）
     *     security:
     *       - bearerAuth: []
     *     responses:
     *       200:
     *         description: 用户资料
     */
    router.get('/profile', (req, res) => {
      res.json({ id: 1, name: 'Alice' });
    });
    ```

    > 注意：如果全局已设置 `security`，这里可省略；否则需显式声明。

2. 在 UI 中输入 Token

    - 点击右上角 **"Authorize"** 按钮
    - 输入 `Bearer <your-jwt-token>`（例如：`Bearer eyJhbGciOiJIUzI1NiIs...`）
    - 后续请求会自动携带 `Authorization: Bearer ...` 头


### 8.1.5 高级技巧

1. 动态服务器 URL（根据环境切换）

    ```js
    // config/swaggerOptions.js
    const servers = [];
    if (process.env.NODE_ENV === 'production') {
      servers.push({ url: 'https://api.example.com', description: 'Production' });
    } else {
      servers.push({ url: `http://localhost:${process.env.PORT || 3000}`, description:  'Development' });
    }

    const options = {
      definition: {
        // ...
        servers
      },
      // ...
    };
    ```

2. 隐藏某些路由（如健康检查）

    - 不在 `apis` 路径中包含该文件
    - 或不在路由上写 `@swagger` 注释

3. 自定义 UI 主题

    ```js
    app.use('/api-docs', swaggerUi.serve, swaggerUi.setup(swaggerSpec, {
      customCss: '.swagger-ui .topbar { display: none }', // 隐藏顶部栏
      customSiteTitle: 'My Custom API Docs'
    }));
    ```

4. 导出 OpenAPI JSON/YAML

    ```js
    // 提供原始规范下载
    app.get('/api-docs-json', (req, res) => {
      res.json(swaggerSpec);
    });
    ```

### 8.1.6 常见问题排查

| 问题 | 解决方案 |
|------|--------|
| **Swagger UI 显示空白** | 检查 `apis` 路径是否正确，确保文件被扫描到 |
| **JSDoc 未生效** | 确认注释以 `@swagger` 开头，且结构符合 OpenAPI |
| **中文乱码** | 确保文件编码为 UTF-8 |
| **生产环境暴露文档** | 仅在开发环境挂载 `/api-docs`：`if (process.env.NODE_ENV !== 'production') { app.use('/api-docs', ...) }` |
