# 一、axios的使用

`axios` 是一个基于 Promise 的 **HTTP 客户端**，可用于浏览器和 Node.js 环境，用于发送 HTTP 请求（GET、POST、PUT、DELETE 等）。它功能强大、API 简洁、支持拦截器、自动转换 JSON、取消请求等特性，是现代前端/后端开发中最流行的 HTTP 库之一。

## 1.1 安装

- 浏览器（通过 CDN）

    ```html
    <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
    ```

- Node.js / 前端工程化（npm / yarn）

    ```bash
    npm install axios
    # 或
    yarn add axios
    ```

## 1.2 基础用法

1. GET 请求

    ```js
    // 方式 1：直接调用
    axios.get('/api/users')
      .then(response => {
        console.log(response.data);
      })
      .catch(error => {
        console.error('Error:', error);
      });

    // 方式 2：使用 async/await（推荐）
    async function fetchUsers() {
      try {
        const response = await axios.get('/api/users');
        console.log(response.data);
      } catch (error) {
        console.error('请求失败:', error.message);
      }
    }
    ```

2. POST 请求（发送数据）

    ```js
    axios.post('/api/login', {
      email: 'user@example.com',
      password: '123456'
    })
    .then(res => console.log(res.data))
    .catch(err => console.error(err));
    ```

3. 其他方法

    ```js
    axios.put('/api/user/1', { name: 'Alice' });
    axios.delete('/api/user/1');
    axios.patch('/api/user/1', { active: true });
    ```

## 1.3 配置选项

你可以传入一个配置对象来定制请求：

```js
axios({
  method: 'post',
  url: '/api/upload',
  data: {
    file: fileData
  },
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  timeout: 5000 // 5秒超时
})
.then(response => { /* ... */ });
```

常用配置项：
| 选项 | 说明 |
|------|------|
| `url` | 请求地址（必填） |
| `method` | 请求方法（默认 `'get'`） |
| `baseURL` | 基础 URL（用于 API 前缀） |
| `headers` | 自定义请求头 |
| `params` | URL 查询参数（GET 用） |
| `data` | 请求体数据（POST/PUT 用） |
| `timeout` | 超时时间（毫秒） |
| `withCredentials` | 是否携带 Cookie（跨域时设为 `true`） |


## 1.4 高级功能

1. 设置全局默认配置

    ```js
    // 设置 baseURL（所有请求自动加前缀）
    axios.defaults.baseURL = 'https://api.example.com';

    // 设置默认请求头
    axios.defaults.headers.common['Authorization'] = 'Bearer xxx';
    ```

2. 创建实例（推荐用于大型项目）

    ```js
    const apiClient = axios.create({
      baseURL: 'https://api.example.com',
      timeout: 10000,
      headers: { 'X-Custom-Header': 'foobar' }
    });

    // 使用实例
    apiClient.get('/users').then(...);
    ```

3. 拦截器（Interceptors）


    - 请求拦截器

        ```js
        axios.interceptors.request.use(
          config => {
            // 在发送请求前做些什么（如加 token）
            const token = localStorage.getItem('token');
            if (token) {
              config.headers.Authorization = `Bearer ${token}`;
            }
            return config;
          },
          error => {
            return Promise.reject(error);
          }
        );
        ```

    - 响应拦截器

        ```js
        axios.interceptors.response.use(
          response => {
            // 对响应数据做处理
            return response.data; // 直接返回 data（简化调用）
          },
          error => {
            // 统一错误处理（如 401 跳转登录）
            if (error.response?.status === 401) {
              window.location.href = '/login';
            }
            return Promise.reject(error);
          }
        );
        ```

    > **技巧**：通过响应拦截器返回 `response.data`，可让调用方直接获取数据，无需写 `.data`。

4. 取消请求

    - 使用 AbortController（现代方式，推荐）

        ```js
        const controller = new AbortController();

        axios.get('/api/data', {
          signal: controller.signal
        })
        .then(...);

        // 取消请求
        controller.abort();
        ```

    - 旧版 CancelToken（已废弃，不推荐）

        ```js
        const CancelToken = axios.CancelToken;
        const source = CancelToken.source();

        axios.get('/api/data', { cancelToken: source.token });

        // 取消
        source.cancel('Operation canceled by the user.');
        ```

## 1.5 在浏览器 vs Node.js 中的区别

| 特性 | 浏览器 | Node.js |
|------|--------|--------|
| **请求库** | XMLHttpRequest / Fetch | HTTP / HTTPS 模块 |
| **Cookie 支持** | 自动（同域） | 需手动设置 `withCredentials: true` |
| **FormData** | 原生支持 | 需用 `form-data` 包 |
| **文件上传** | `File` 对象 | `fs.createReadStream()` |

- Node.js 上传文件示例

    ```js
    const FormData = require('form-data');
    const fs = require('fs');

    const form = new FormData();
    form.append('file', fs.createReadStream('photo.jpg'));

    axios.post('/upload', form, {
      headers: form.getHeaders() // 自动设置 Content-Type
    });
    ```

## 1.6 常见场景示例

1. 带查询参数的 GET

    ```js
    axios.get('/api/search', {
      params: {
        q: 'javascript',
        page: 1
      }
    });
    // → /api/search?q=javascript&page=1
    ```

2. 发送表单数据（application/x-www-form-urlencoded）

    ```js
    const params = new URLSearchParams();
    params.append('name', 'Alice');
    params.append('email', 'alice@example.com');

    axios.post('/api/form', params);
    ```

3. 下载文件（Blob / Buffer）

    ```js
    // 浏览器：下载图片
    axios.get('/api/image.jpg', { responseType: 'blob' })
      .then(res => {
        const url = URL.createObjectURL(res.data);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'image.jpg';
        a.click();
      });

    // Node.js：保存文件
    axios.get('/api/file.pdf', { responseType: 'stream' })
      .then(res => {
        res.data.pipe(fs.createWriteStream('downloaded.pdf'));
      });
    ```

## 1.7 错误处理

Axios 错误对象结构：

```js
axios.get('/error')
  .catch(error => {
    if (error.response) {
      // 服务器返回了错误状态码（4xx, 5xx）
      console.log(error.response.status);     // 404
      console.log(error.response.data);       // 错误详情
      console.log(error.response.headers);    // 响应头
    } else if (error.request) {
      // 请求已发出但无响应（网络错误）
      console.log(error.request);
    } else {
      // 其他错误（如配置错误）
      console.log('Error', error.message);
    }
  });
```

## 1.8 最佳实践

1. **使用实例隔离不同 API**
   ```js
   // 用户服务
   const userApi = axios.create({ baseURL: '/api/users' });
   // 商品服务
   const productApi = axios.create({ baseURL: '/api/products' });
   ```

2. **统一错误提示**
   ```js
   // 在响应拦截器中弹出错误消息
   error => {
     alert(error.response?.data?.message || '请求失败');
     return Promise.reject(error);
   }
   ```

3. **避免内存泄漏**
   - 在 React/Vue 组件销毁时取消未完成的请求（使用 `AbortController`）

4. **不要硬编码 URL**
   - 使用环境变量管理 API 地址
   ```js
   baseURL: process.env.VUE_APP_API_BASE_URL
   ```
