# 二、rsa加密

## 2.1 node中的crypto

在 Node.js 中使用内置的 `crypto` 模块实现 **RSA 非对称加密**，主要包括以下核心操作：

1. **生成 RSA 密钥对（公钥 + 私钥）**  
2. **用公钥加密数据**  
3. **用私钥解密数据**  
4. **用私钥签名 + 公钥验证（更常用）**

> **重要前提**：  
> - RSA **不能直接加密大文件**（2048 位密钥最多加密约 190 字节）  
> - 实际应用中通常用于 **加密对称密钥（如 AES 密钥）** 或 **数字签名**

### 2.1.1 生成 RSA 密钥对

```js
const { generateKeyPairSync } = require('crypto');

// 同步生成（推荐用于初始化）
const { publicKey, privateKey } = generateKeyPairSync('rsa', {
  modulusLength: 2048, // 密钥长度（2048 是当前安全标准）
  publicKeyEncoding: {
    type: 'spki',   // 推荐格式（SubjectPublicKeyInfo）
    format: 'pem'   // PEM 格式（Base64 文本）
  },
  privateKeyEncoding: {
    type: 'pkcs8',  // 推荐格式（PKCS#8）
    format: 'pem',
    // 可选：用密码保护私钥
    // cipher: 'aes-256-cbc',
    // passphrase: 'your-secret-passphrase'
  }
});

console.log('公钥 (PEM):\n', publicKey);
console.log('私钥 (PEM):\n', privateKey);
```

**私钥加密存储（增强安全）**

```js
const { publicKey, privateKey } = generateKeyPairSync('rsa', {
  modulusLength: 2048,
  publicKeyEncoding: { type: 'spki', format: 'pem' },
  privateKeyEncoding: {
    type: 'pkcs8',
    format: 'pem',
    cipher: 'aes-256-cbc',        // 加密算法
    passphrase: 'my-strong-pass'  // 密码（必须保管好！）
  }
});
```

### 2.1.2 RSA 加密与解密（小数据）

1. 加密（使用公钥）

    ```js
    const crypto = require('crypto');

    const data = 'Secret message'; // ≤ 190 字节（2048 位密钥）

    const encrypted = crypto.publicEncrypt(
      {
        key: publicKey, // PEM 格式的公钥字符串
        padding: crypto.constants.RSA_PKCS1_OAEP_PADDING // 安全填充方案
      },
      Buffer.from(data) // 转为 Buffer
    ).toString('base64'); // 通常转为 Base64 便于传输

    console.log('加密结果 (Base64):', encrypted);
    ```

2. 解密（使用私钥）

    ```js
    const decrypted = crypto.privateDecrypt(
      {
        key: privateKey, // PEM 格式的私钥字符串
        // 如果私钥加密了，需提供 passphrase
        // passphrase: 'my-strong-pass',
        padding: crypto.constants.RSA_PKCS1_OAEP_PADDING
      },
      Buffer.from(encrypted, 'base64') // Base64 转回 Buffer
    ).toString(); // 转为原始字符串

    console.log('解密结果:', decrypted); // "Secret message"
    ```

    > **填充方案说明**：  
    > - **`RSA_PKCS1_OAEP_PADDING`**：现代安全标准（推荐）  
    > - `RSA_PKCS1_PADDING`：旧方案（有漏洞，避免使用）

### 2.1.3 RSA 数字签名与验证

> **为什么签名比加密更常用？**  
> - 签名无长度限制（对数据哈希后签名）  
> - 用于 JWT、证书、代码签名等场景

1. 签名（使用私钥）

    ```js
    const dataToSign = 'This is a critical transaction';

    const sign = crypto.createSign('SHA256'); // 使用 SHA256 哈希
    sign.update(dataToSign); // 添加数据
    sign.end(); // 结束输入

    // 生成签名（Hex 或 Base64）
    const signature = sign.sign(
      {
        key: privateKey,
        // passphrase: 'my-strong-pass', // 如果私钥加密
        padding: crypto.constants.RSA_PKCS1_PSS_PADDING // PSS 填充（推荐）
      },
      'hex' // 输出格式
    );

    console.log('签名 (Hex):', signature);
    ```

2. 验证（使用公钥）

    ```js
    const verify = crypto.createVerify('SHA256');
    verify.update(dataToSign);
    verify.end();

    const isVerified = verify.verify(
      {
        key: publicKey,
        padding: crypto.constants.RSA_PKCS1_PSS_PADDING
      },
      signature,
      'hex'
    );

    console.log('签名有效:', isVerified); // true
    ```

    > **签名流程**：  
    > `原始数据 → SHA256 哈希 → 用私钥加密哈希值 = 签名`  
    > 验证时：`用公钥解密签名 → 与原始数据的哈希比对`

### 2.1.4 完整示例：安全传输 AES 密钥

实际中 RSA 用于加密**对称密钥**，再用对称加密处理大数据：

```js
const crypto = require('crypto');

// === 步骤 1: 生成密钥对 ===
const { publicKey, privateKey } = crypto.generateKeyPairSync('rsa', {
  modulusLength: 2048,
  publicKeyEncoding: { type: 'spki', format: 'pem' },
  privateKeyEncoding: { type: 'pkcs8', format: 'pem' }
});

// === 步骤 2: 发送方操作 ===
// 2.1 生成随机 AES 密钥
const aesKey = crypto.randomBytes(32); // 256 位

// 2.2 用 RSA 公钥加密 AES 密钥
const encryptedAesKey = crypto.publicEncrypt(
  { key: publicKey, padding: crypto.constants.RSA_PKCS1_OAEP_PADDING },
  aesKey
).toString('base64');

// 2.3 用 AES 加密实际数据
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv('aes-256-cbc', aesKey, iv);
let encryptedData = cipher.update('Large sensitive file content...', 'utf8', 'base64');
encryptedData += cipher.final('base64');

// 发送: { encryptedAesKey, encryptedData, iv }

// === 步骤 3: 接收方操作 ===
// 3.1 用 RSA 私钥解密 AES 密钥
const decryptedAesKey = crypto.privateDecrypt(
  { key: privateKey, padding: crypto.constants.RSA_PKCS1_OAEP_PADDING },
  Buffer.from(encryptedAesKey, 'base64')
);

// 3.2 用 AES 密钥解密数据
const decipher = crypto.createDecipheriv('aes-256-cbc', decryptedAesKey, iv);
let decryptedData = decipher.update(encryptedData, 'base64', 'utf8');
decryptedData += decipher.final('utf8');

console.log('最终数据:', decryptedData);
```

### 2.1.5 关键注意事项

1. **密钥长度**

    - **2048 位**：当前安全标准（有效期至 2030 年）  
    - **3072 位+**：高安全需求（如政府系统）  
    - **< 2048 位**：不安全（如 1024 位已破解）

2. **填充方案**

    | 场景 | 推荐填充 |
    |------|---------|
    | **加密** | `RSA_PKCS1_OAEP_PADDING` |
    | **签名** | `RSA_PKCS1_PSS_PADDING` |

3. **私钥安全**

    - 永远不要提交到 Git
    - 文件权限设为 `600`（`chmod 600 private.pem`）
    - 生产环境考虑 HSM（硬件安全模块）

4. **性能**
    - RSA 加解密慢（比 AES 慢 1000 倍以上）
    - **只用于加密小数据（如密钥）或签名**
    
5. 密钥格式说明

    | 格式 | 用途 | 示例开头 |
    |------|------|---------|
    | **PEM (Base64)** | 人类可读，通用 | `-----BEGIN PUBLIC KEY-----` |
    | **DER (Binary)** | 二进制，紧凑 | 无法直接阅读 |
    | **SPKI** | 公钥标准格式 | PEM 中为 `BEGIN PUBLIC KEY` |
    | **PKCS#8** | 私钥标准格式 | PEM 中为 `BEGIN PRIVATE KEY` |

    > Node.js 默认使用 **SPKI（公钥）** 和 **PKCS#8（私钥）**，兼容性最好。

## 2.2 web crypto

`Web Crypto API` 是浏览器原生提供的 **加密、解密、签名、哈希、密钥生成** 等功能的标准化接口。它运行在 **安全上下文（HTTPS 或 localhost）** 中，性能高、安全性强，且无需引入第三方库。

> **优势**：  
> - 原生支持（Chrome/Firefox/Safari/Edge）  
> - 比 `node-forge` 等 JS 库快 10~100 倍  
> - 密钥永不暴露给 JavaScript（部分操作在安全模块中执行）

### 2.2.1 核心能力概览

| 功能 | 方法 |
|------|------|
| **生成密钥** | `crypto.subtle.generateKey()` |
| **导入/导出密钥** | `importKey()` / `exportKey()` |
| **加密/解密** | `encrypt()` / `decrypt()` |
| **签名/验证** | `sign()` / `verify()` |
| **哈希** | `digest()` |
| **派生密钥** | `deriveKey()` / `deriveBits()` |

> **限制**：  
> - 仅在 **安全上下文** 中可用（`https://` 或 `http://localhost`）  
> - 所有方法返回 **Promise**（异步）


### 2.2.2 常用场景代码示例

- 场景 1：SHA-256 哈希（如生成 Gravatar ID）

    ```js
    async function sha256(message) {
      const msgBuffer = new TextEncoder().encode(message);
      const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer);
      const hashArray = Array.from(new Uint8Array(hashBuffer));
      return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    }

    // 使用
    const hash = await sha256('alice@example.com');
    console.log(hash); // e.g., "d9e...a3f"
    ```

- 场景 2：AES-GCM 对称加密（加密大文件/消息）

    ```js
    // 1. 生成密钥
    const key = await crypto.subtle.generateKey(
      { name: 'AES-GCM', length: 256 },
      true, // 可导出
      ['encrypt', 'decrypt']
    );

    // 2. 加密
    async function encryptData(plaintext, key) {
      const iv = crypto.getRandomValues(new Uint8Array(12)); // 96-bit IV
      const encoded = new TextEncoder().encode(plaintext);
      const ciphertext = await crypto.subtle.encrypt(
        { name: 'AES-GCM', iv },
        key,
        encoded
      );
      return { iv, ciphertext };
    }

    // 3. 解密
    async function decryptData(iv, ciphertext, key) {
      const decrypted = await crypto.subtle.decrypt(
        { name: 'AES-GCM', iv },
        key,
        ciphertext
      );
      return new TextDecoder().decode(decrypted);
    }

    // 使用
    const { iv, ciphertext } = await encryptData('Secret message', key);
    const plaintext = await decryptData(iv, ciphertext, key);
    console.log(plaintext); // "Secret message"
    ```

    > **AES-GCM 优势**：同时提供加密 + 认证（防篡改）


- 场景 3：RSA-OAEP 非对称加密（前端安全传密码）

    - 步骤 2：前端用 Web Crypto 导入公钥并加密

## 2.3 用户加密示例

以下是一个 **完整的 Web Crypto + Node.js RSA 加密通信模板**，用于实现 **安全的用户登录流程**：

>  **核心思想**：  
> - 前端使用 **Web Crypto API** 通过后端提供的 **RSA 公钥** 加密密码  
> - 后端使用 **Node.js `crypto` 模块** 用私钥解密，并验证密码（配合 `bcrypt`）  
> - 所有通信走 HTTPS（本地开发可用 `localhost`）

### 2.3.2 生成 RSA 密钥对（后端）

### 2.3.3 后端服务（Node.js + Express）

1. `backend/package.json`

    ```json
    {
      "name": "secure-login-backend",
      "type": "module",
      "scripts": {
        "start": "node index.js"
      },
      "dependencies": {
        "express": "^4.18.2",
        "bcryptjs": "^2.4.3",
        "cors": "^2.8.5"
      }
    }
    ```

- `backend/index.js`

    ```js
    import express from 'express';
    import cors from 'cors';
    import bcrypt from 'bcryptjs';
    import fs from 'fs';
    import { createServer } from 'https'; // 本地开发可改用 http（但需 localhost）
    import { fileURLToPath } from 'url';
    import { dirname, join } from 'path';

    const __filename = fileURLToPath(import.meta.url);
    const __dirname = dirname(__filename);

    const app = express();
    app.use(express.json());
    app.use(cors({ origin: 'http://localhost:8080' })); // 前端地址

    // 模拟用户数据库（实际用 MongoDB/PostgreSQL）
    let users = [];

    // 1. 提供公钥（前端用于加密）
    app.get('/api/public-key', (req, res) => {
      const publicKey = fs.readFileSync(join(__dirname, 'keys/public.pem'), 'utf8');
      res.json({ publicKey });
    });

    // 2. 注册（明文密码 → bcrypt 哈希）
    app.post('/api/register', async (req, res) => {
      const { email, password } = req.body;
      if (!email || !password) {
        return res.status(400).json({ error: 'Email and password required' });
      }

      // 检查是否已存在
      if (users.some(u => u.email === email)) {
        return res.status(409).json({ error: 'User already exists' });
      }

      // 哈希密码（bcrypt）
      const hashedPassword = await bcrypt.hash(password, 12);
      users.push({ email, password: hashedPassword });
      res.status(201).json({ message: 'User registered' });
    });

    // 3. 登录（接收 RSA 加密的密码）
    app.post('/api/login', async (req, res) => {
      const { encryptedPassword } = req.body;
      if (!encryptedPassword) {
        return res.status(400).json({ error: 'Encrypted password required' });
      }

      try {
        // 解密密码
        const privateKey = fs.readFileSync(join(__dirname, 'keys/private.pem'), 'utf8');
        const buffer = Buffer.from(encryptedPassword, 'base64');
        const decryptedPassword = crypto.privateDecrypt(
          {
            key: privateKey,
            padding: crypto.constants.RSA_PKCS1_OAEP_PADDING
          },
          buffer
        ).toString();

        // 验证用户（此处简化：假设只有一个测试用户）
        const user = users[0]; // 实际应查数据库
        if (!user || !(await bcrypt.compare(decryptedPassword, user.password))) {
          return res.status(401).json({ error: 'Invalid credentials' });
        }

        // 登录成功 → 返回 JWT 或 Session（此处简化）
        res.json({ success: true, message: 'Login successful' });
      } catch (err) {
        console.error('Decryption failed:', err);
        res.status(400).json({ error: 'Invalid encrypted data' });
      }
    });

    // 启动服务器（HTTPS 示例，本地开发可改用 http.createServer）
    const PORT = process.env.PORT || 3000;
    app.listen(PORT, () => {
      console.log(`🚀 后端运行在 http://localhost:${PORT}`);
    });
    ```

>  **本地开发提示**：  
> 若不想配置 HTTPS，可将 `createServer` 改为 `app.listen`（因 `localhost` 被视为安全上下文）

    ```js
    // 后端地址（根据你的配置调整）
    const API_BASE = 'http://localhost:3000/api';

    // 1. 从 PEM 字符串提取 Base64 内容
    function pemToBase64(pem) {
      return pem
        .replace(/-----BEGIN PUBLIC KEY-----|-----END PUBLIC KEY-----/g, '')
        .replace(/\s/g, '');
    }

    // 2. 将 Base64 转为 ArrayBuffer
    function base64ToArrayBuffer(base64) {
      const binary = atob(base64);
      return Uint8Array.from(binary, c => c.charCodeAt(0)).buffer;
    }

    // 3. 用 Web Crypto 加密密码
    async function encryptPasswordWithPublicKey(password, pemPublicKey) {
      // 导入公钥
      const base64 = pemToBase64(pemPublicKey);
      const spki = base64ToArrayBuffer(base64);
      const publicKey = await window.crypto.subtle.importKey(
        'spki',
        spki,
        { name: 'RSA-OAEP', hash: 'SHA-256' },
        true,
        ['encrypt']
      );

      // 加密
      const encoded = new TextEncoder().encode(password);
      const encrypted = await window.crypto.subtle.encrypt(
        { name: 'RSA-OAEP' },
        publicKey,
        encoded
      );

      // 转为 Base64 传输
      return btoa(String.fromCharCode(...new Uint8Array(encrypted)));
    }

    // 4. 注册（明文，仅演示）
    async function register() {
      const email = document.getElementById('regEmail').value;
      const password = document.getElementById('regPassword').value;
      const res = await fetch(`${API_BASE}/register`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email, password })
      });
      const msgEl = document.getElementById('regMessage');
      if (res.ok) {
        msgEl.className = 'success';
        msgEl.textContent = 'Registered! Now try logging in.';
      } else {
        const data = await res.json();
        msgEl.className = 'error';
        msgEl.textContent = data.error;
      }
    }

    // 5. 安全登录（RSA 加密）
    async function login() {
      const email = document.getElementById('loginEmail').value;
      const password = document.getElementById('loginPassword').value;

      // 获取公钥
      const keyRes = await fetch(`${API_BASE}/public-key`);
      const { publicKey } = await keyRes.json();

      // 加密密码
      const encryptedPassword = await encryptPasswordWithPublicKey(password, publicKey);

      // 发送加密后的密码
      const loginRes = await fetch(`${API_BASE}/login`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ encryptedPassword })
      });

      const msgEl = document.getElementById('loginMessage');
      if (loginRes.ok) {
        msgEl.className = 'success';
        msgEl.textContent = ' Login successful!';
      } else {
        const data = await loginRes.json();
        msgEl.className = 'error';
        msgEl.textContent = data.error;
      }
    }
    ```

### 2.3.6 安全增强建议（生产环境）

| 风险 | 解决方案 |
|------|----------|
| **公钥被篡改** | 通过 HTTPS 传输 + 公钥指纹校验 |
| **重放攻击** | 在加密数据中加入一次性 nonce |
| **XSS 窃取明文** | 严格 CSP + 输入过滤 |
| **私钥泄露** | 使用 HSM 或云 KMS |
| **密钥长期有效** | 定期轮换密钥对（如 30 天） |

防重放示例（在加密前加 nonce）：

```js
// 前端
const nonce = Date.now().toString();
const payload = `${nonce}:${password}`;
const encrypted = await encrypt(payload, publicKey);

// 后端
const [nonce, password] = decrypted.split(':');
// 检查 nonce 是否已使用（用 Redis 记录）
```
