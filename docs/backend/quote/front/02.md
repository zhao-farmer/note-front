# 二、瀑布流

## 2.1 react-infinite-scroll-component

`react-infinite-scroll-component` 是一个轻量、简单易用的 React 组件，用于实现**无限滚动（Infinite Scroll）** 功能——当用户滚动到页面底部时，自动加载更多内容（如分页数据、动态列表等）。

- GitHub: [https://github.com/ankeetmaini/react-infinite-scroll-component](https://github.com/ankeetmaini/react-infinite-scroll-component)
- NPM: [https://www.npmjs.com/package/react-infinite-scroll-component](https://www.npmjs.com/package/react-infinite-scroll-component)

> **适用场景**：  
> - 社交媒体动态流（如微博、Twitter）  
> - 商品/文章列表懒加载  
> - 聊天消息历史加载  

### 2.1.1 一、安装

```bash
npm install react-infinite-scroll-component
```

> 注意：该库仅支持 **React（16.8+）**，依赖 `useState` 和 `useEffect`。


### 2.1.2 基础用法

0 最简示例

```jsx
import InfiniteScroll from 'react-infinite-scroll-component';

function App() {
  const [items, setItems] = useState(Array.from({ length: 20 }, (_, i) => i + 1));

  const fetchMoreData = () => {
    // 模拟 API 请求
    setTimeout(() => {
      setItems(prev => [
        ...prev,
        ...Array.from({ length: 10 }, (_, i) => prev.length + i + 1)
      ]);
    }, 1500);
  };

  return (
    <div>
      <h1>Infinite Scroll Demo</h1>
      <InfiniteScroll
        dataLength={items.length}        // 当前列表长度（必填）
        next={fetchMoreData}             // 加载更多函数（必填）
        hasMore={items.length < 100}     // 是否还有更多数据（必填）
        loader={<h4>Loading...</h4>}    // 加载中提示
      >
        {items.map((item) => (
          <div key={item} style={{ height: '100px', border: '1px solid #ccc' }}>
            Item {item}
          </div>
        ))}
      </InfiniteScroll>
    </div>
  );
}
```


### 2.1.3 核心 Props 详解

| Prop | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dataLength` | `number` | 是 | **当前已渲染的数据项总数**（用于判断是否触发加载） |
| `next` | `() => void` | 是 | **加载更多数据的函数**（通常调用 API） |
| `hasMore` | `boolean` | 是 | **是否还有更多数据可加载**（`false` 时停止监听滚动） |
| `loader` | `ReactNode` | 否 | 加载中的 UI（如 spinner） |
| `endMessage` | `ReactNode` | 否 | 数据加载完毕的提示（如 "没有更多了"） |
| `scrollableTarget` | `string \| HTMLElement` | 否 | 自定义滚动容器（默认为 `window`） |


### 2.1.4 高级用法

1. 自定义滚动容器（非 window）

    当列表在**固定高度的容器内滚动**时：

    ```jsx
    function App() {
      return (
        <div>
          {/* 滚动容器 */}
          <div
            id="scrollableDiv"
            style={{ height: '400px', overflow: 'auto', border: '1px solid #000' }}
          >
            <InfiniteScroll
              dataLength={items.length}
              next={fetchMoreData}
              hasMore={hasMore}
              loader={<div>Loading...</div>}
              scrollableTarget="scrollableDiv" // 关联容器 ID
            >
              {items.map(item => (
                <div key={item} style={{ height: '100px' }}>
                  Item {item}
                </div>
              ))}
            </InfiniteScroll>
          </div>
        </div>
      );
    }
    ```

2. 结合 API 分页（真实场景）

    ```jsx
    function UserList() {
      const [users, setUsers] = useState([]);
      const [page, setPage] = useState(1);
      const [hasMore, setHasMore] = useState(true);

      useEffect(() => {
        // 初始加载
        fetchUsers(1);
      }, []);

      const fetchUsers = async (pageNum) => {
        try {
          const res = await axios.get(`/api/users?page=${pageNum}&limit=10`);
          const newUsers = res.data;

          setUsers(prev => [...prev, ...newUsers]);
          setPage(pageNum + 1);

          // 假设后端返回 total_count
          if (users.length + newUsers.length >= res.data.total_count) {
            setHasMore(false);
          }
        } catch (error) {
          console.error('Failed to fetch users', error);
        }
      };

      const loadMore = () => {
        fetchUsers(page);
      };

      return (
        <InfiniteScroll
          dataLength={users.length}
          next={loadMore}
          hasMore={hasMore}
          loader={<Spinner />}
          endMessage={<p>No more users!</p>}
        >
          {users.map(user => (
            <UserCard key={user.id} user={user} />
          ))}
        </InfiniteScroll>
      );
    }
    ```

3. 防抖与错误处理

    ```jsx
    const [error, setError] = useState(null);

    const fetchMoreData = useCallback(async () => {
      if (loading) return; // 防止重复请求

      setLoading(true);
      setError(null);

      try {
        const newData = await api.getMoreData();
        setData(prev => [...prev, ...newData]);
      } catch (err) {
        setError('加载失败，请重试');
      } finally {
        setLoading(false);
      }
    }, [loading]);

    // 在组件中显示错误
    {error && <button onClick={fetchMoreData}>Retry</button>}
    ```


### 2.1.5 常见问题与解决方案

- 问题 1：滚动到底部不触发 `next`
    - **原因**：`dataLength` 未正确更新，或容器高度不足
    - **解决**：
      - 确保 `dataLength` 是**当前渲染的总项数**
      - 检查滚动容器是否有足够高度（至少 > 单个 item 高度）

- 问题 2：多次触发 `next`
    - **原因**：快速滚动或网络慢导致重复请求
    - **解决**：添加 loading 状态锁
      ```js
      const [loading, setLoading] = useState(false);
    
      const fetchMoreData = () => {
        if (loading || !hasMore) return;
        setLoading(true);
        // ...请求后 setLoading(false)
      };
      ```

- 问题 3：与 `position: sticky` 冲突
    - **原因**：某些 CSS 布局影响滚动检测
    - **解决**：使用 `scrollableTarget` 明确指定滚动容器


### 2.1.6 最佳实践

1. **始终提供 `hasMore`**  
   避免无限请求（即使后端无数据也应返回 `hasMore: false`）

2. **显示加载状态**  

   ```jsx
   loader={<div className="spinner">Loading...</div>}
   ```
3. **处理加载失败**  

   提供“重试”按钮，提升用户体验
4. **避免在 `next` 中 setState 同步操作**  

   使用函数式更新：`setItems(prev => [...prev, ...newItems])`
5. **结合防抖/节流（极端情况）** 

   虽然组件内部有防抖，但高频率滚动仍可加额外保护


## 2.2 vue-waterfall-plugin

`vue-waterfall-plugin` 是一个专为 **Vue 3** 设计的轻量级瀑布流组件，基于 Composition API 实现，支持响应式布局、动态列数、懒加载、服务端渲染（SSR）等特性。


- GitHub: [https://github.com/AlexZou14/vue-waterfall-plugin](https://github.com/AlexZou14/vue-waterfall-plugin)
- 文档: [https://vue-waterfall-plugin.alexzou.com/](https://vue-waterfall-plugin.alexzou.com/)
- Demo: [https://vue-waterfall-plugin.alexzou.com/examples](ttps://vue-waterfall-plugin.alexzou.com/examples)

> **核心优势**：
> - 体积小（~5KB）
> - 无 jQuery / Masonry.js 依赖
> - 支持 `v-model` 控制滚动位置
> - 内置加载更多（Load More）事件
> - 完整 TypeScript 支持



> **终极提示**：  
> **瀑布流的核心是“已知高度”——无论是通过 API 返回、图片预加载，还是 CSS 固定，确保每个 item 的高度在渲染前确定，是布局稳定的关键。**

### 2.2.1 安装

```bash
npm install vue-waterfall-plugin
```

> 注意：仅支持 **Vue 3.2+**（需 `<script setup>` 和 `ref` 等新特性）

### 2.2.2 基础用法

1. 全局注册（可选）

    ```js
    // main.js
    import { createApp } from 'vue';
    import App from './App.vue';
    import { Waterfall } from 'vue-waterfall-plugin';
    import 'vue-waterfall-plugin/dist/style.css'; // 样式必须引入

    const app = createApp(App);
    app.component('Waterfall', Waterfall);
    app.mount('#app');
    ```

2. 局部使用（推荐）

    ```vue
    <template>
      <Waterfall
        :data="items"
        :width="250"
        :gap="10"
        :cols="3"
      >
        <template #item="{ item }">
          <div class="waterfall-item" :style="{ height: item.height + 'px' }">
            {{ item.title }}
          </div>
        </template>
      </Waterfall>
    </template>

    <script setup>
    import { ref } from 'vue';
    import { Waterfall } from 'vue-waterfall-plugin';
    import 'vue-waterfall-plugin/dist/style.css';

    const items = ref([
      { id: 1, title: 'Item 1', height: 200 },
      { id: 2, title: 'Item 2', height: 300 },
      { id: 3, title: 'Item 3', height: 250 },
      // ... 更多数据
    ]);
    </script>

    <style scoped>
    .waterfall-item {
      background: #f0f0f0;
      border-radius: 8px;
      display: flex;
      align-items: center;
      justify-content: center;
      font-size: 18px;
    }
    </style>
    ```

### 2.2.3 核心 Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `data` | `Array` | `[]` | **必填**：渲染的数据列表 |
| `width` | `number` | `200` | 每列的宽度（px） |
| `gap` | `number` | `0` | 列间距和行间距（px） |
| `cols` | `number` | `3` | 列数（可被响应式覆盖） |
| `responsive` | `Object` | `{}` | 响应式断点配置（见下文） |
| `ssr` | `boolean` | `false` | 是否启用 SSR 模式 |
| `ssr-columns` | `number` | `1` | SSR 时的默认列数 |
| `loading` | `boolean` | `false` | 是否显示加载中 |
| `complete` | `boolean` | `false` | 是否已加载全部数据 |

### 2.2.4 响应式布局

通过 `responsive` prop 实现不同屏幕尺寸下的列数变化：

```vue
<template>
  <Waterfall
    :data="items"
    :width="200"
    :gap="10"
    :responsive="{
      1200: 4,   // >=1200px 时 4 列
      900: 3,    // >=900px 时 3 列
      600: 2,    // >=600px 时 2 列
      0: 1       // <600px 时 1 列
    }"
  >
    <template #item="{ item }">
      <div :style="{ height: item.height + 'px' }">
        {{ item.title }}
      </div>
    </template>
  </Waterfall>
</template>
```

> **注意**：断点值为 **最小宽度**，按降序排列。

### 2.2.5 加载更多（无限滚动）

组件提供 `@loadmore` 事件，用于实现“滚动到底部加载更多”：

```vue
<template>
  <Waterfall
    :data="items"
    :width="250"
    :gap="10"
    :cols="3"
    :loading="isLoading"
    :complete="!hasMore"
    @loadmore="loadMore"
  >
    <template #item="{ item }">
      <img :src="item.url" :alt="item.title" @load="onImageLoad(item)" />
    </template>
    <template #loading>
      <div class="loading">Loading...</div>
    </template>
    <template #complete>
      <div class="complete">No more data</div>
    </template>
  </Waterfall>
</template>

<script setup>
import { ref } from 'vue';
import { Waterfall } from 'vue-waterfall-plugin';

const items = ref([]);
const page = ref(1);
const isLoading = ref(false);
const hasMore = ref(true);

const loadMore = async () => {
  if (isLoading.value || !hasMore.value) return;
  
  isLoading.value = true;
  try {
    const res = await fetch(`/api/images?page=${page.value}`);
    const newItems = await res.json();
    
    items.value.push(...newItems);
    page.value++;
    
    if (newItems.length === 0) hasMore.value = false;
  } catch (error) {
    console.error('Failed to load more', error);
  } finally {
    isLoading.value = false;
  }
};

// 图片加载后触发布局更新（可选）
const onImageLoad = (item) => {
  // 如果图片高度未知，可在 load 后更新 item.height
  // 组件会自动重新计算布局
};
</script>
```


### 2.2.6 图片瀑布流最佳实践

1. 问题：图片高度未知导致布局错乱
    
    **解决方案**：在图片加载完成后更新高度

    ```js
    // 方法 1：预获取图片尺寸（推荐）
    const getImageSize = (url) => {
      return new Promise((resolve) => {
        const img = new Image();
        img.onload = () => resolve({ width: img.width, height: img.height });
        img.src = url;
      });
    };

    // 在数据加载时处理
    const fetchImages = async () => {
      const data = await api.getImages();
      const itemsWithHeight = await Promise.all(
        data.map(async (item) => {
          const { height } = await getImageSize(item.url);
          return { ...item, height };
        })
      );
      items.value = itemsWithHeight;
    };
    ```

2. 方法：使用 `v-memo` 优化重渲染

    ```vue
    <template #item="{ item }">
      <img
        v-memo="[item.url]"
        :src="item.url"
        :style="{ height: item.height + 'px' }"
      />
    </template>
    ```

### 2.2.7 服务端渲染（SSR / Nuxt 3）

1. 启用 SSR 模式

    ```vue
    <Waterfall
      :data="items"
      :ssr="true"
      :ssr-columns="2" <!-- SSR 时渲染 2 列 -->
      :width="250"
      :gap="10"
    />
    ```

2. Nuxt 3 配置

    ```ts
    // nuxt.config.ts
    export default defineNuxtConfig({
      build: {
        transpile: ['vue-waterfall-plugin']
      }
    });
    ```

> SSR 模式下，组件会在服务端渲染指定列数的静态 HTML，客户端 hydration 后再转为交互式瀑布流。


### 2.2.8 自定义样式

组件不强制样式，所有外观由你控制。但需注意：

- 每个 item 必须是 **块级元素**
- 高度必须明确（固定 px 或通过 JS 计算）
- 使用 `gap` 控制间距，避免 margin 导致布局偏移

```css
/* 推荐样式 */
.waterfall-item {
  width: 100%; /* 占满列宽 */
  border-radius: 8px;
  overflow: hidden;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}
```

### 2.2.9 常见问题

- 问题 1：布局错乱（列不对齐）
    - **原因**：item 高度未正确设置
    - **解决**：确保每个 item 有明确的 `height` 样式

-  问题 2：`@loadmore` 不触发
    - **原因**：容器高度不足或未滚动到底部
    - **解决**：
        - 确保瀑布流容器有足够内容
        - 检查是否被父级 `overflow: hidden` 截断

- 问题 3：图片闪烁/重排
    - **解决**：
        - 预加载图片尺寸
        - 使用 `v-memo` 减少不必要的重渲染
