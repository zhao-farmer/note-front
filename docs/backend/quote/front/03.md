# 三、图片处理

## 3.1 medium-zoom

`medium-zoom` 是一个轻量级（~5KB）、无依赖的 JavaScript 库，用于为网页中的图片添加 **Medium 风格的点击放大效果** —— 点击图片后以平滑动画全屏展示，支持缩放、拖拽关闭、键盘导航等交互。

- GitHub: [https://github.com/francoischalifour/medium-zoom](https://github.com/francoischalifour/medium-zoom)
- Demo: [https://medium-zoom.francoischalifour.com/](https://medium-zoom.francoischalifour.com/)
- 文档: [https://github.com/francoischalifour/medium-zoom#readme](https://github.com/francoischalifour/medium-zoom#readme)


> **核心优势**：
> - 极简 API（一行代码启用）
> - 无 jQuery / React / Vue 依赖（纯 JS）
> - 支持 SSR（服务端渲染安全）
> - 可定制样式和行为
> - 支持动态加载的图片


### 3.1.1 安装

- 方式 1：npm（推荐）

    ```bash
    npm install medium-zoom
    ```
- 方式 2：CDN（快速原型）

    ```html
    <script src="https://cdn.jsdelivr.net/npm/medium-zoom@1.0.8/dist/medium-zoom.min.js"></script>
    ```

### 3.1.2 基础用法（原生 JS）

1. 为所有图片启用缩放

    ```js
    import mediumZoom from 'medium-zoom';

    // 选择所有 <img> 标签
    mediumZoom('img');
    ```
2. 为特定图片启用（推荐）

    ```js
    // 只放大带 .zoomable 类的图片
    mediumZoom('.zoomable');

    // 或使用更精确的选择器
    mediumZoom('[data-zoomable]');
    ```

    **HTML 示例**：

    ```html
    <img src="photo.jpg" class="zoomable" alt="风景">
    <img src="diagram.png" data-zoomable alt="图表">
    ```


### 3.1.3 Vue 中使用（Vue 2 / Vue 3）

- 方案 A：全局指令（推荐）

    ```js
    // plugins/mediumZoom.js
    import mediumZoom from 'medium-zoom';

    export default {
      install(app) {
        app.directive('zoom', {
          mounted(el) {
            // 仅当元素是图片时启用
            if (el.tagName === 'IMG') {
              mediumZoom(el, {
                background: 'rgba(0, 0, 0, 0.9)',
                margin: 40
              });
            }
          },
          unmounted(el) {
            // 清理（防止内存泄漏）
            const zoom = mediumZoom(el);
            zoom.detach();
          }
        });
      }
    };
    ```

    ```js
    // main.js
    import { createApp } from 'vue';
    import App from './App.vue';
    import mediumZoomPlugin from './plugins/mediumZoom';

    createApp(App).use(mediumZoomPlugin).mount('#app');
    ```

    ```vue
    <!-- 组件中使用 -->
    <template>
      <img v-zoom src="example.jpg" alt="示例" />
    </template>
    ```

- 方案 B：在组件内手动初始化（适用于动态内容）

    ```vue
    <template>
      <div v-for="img in images" :key="img.id">
        <img :src="img.url" :ref="el => imgRefs[img.id] = el" />
      </div>
    </template>

    <script setup>
    import { onMounted, ref } from 'vue';
    import mediumZoom from 'medium-zoom';

    const images = ref([...]);
    const imgRefs = ref({});

    onMounted(() => {
      // 为所有图片启用 zoom
      Object.values(imgRefs.value).forEach(img => {
        if (img) mediumZoom(img);
      });
    });
    </script>
    ```

> **注意**：对于通过 AJAX 动态加载的图片，需在图片插入 DOM 后**重新调用 `mediumZoom()`**。

### 3.1.4 React 中使用

- 方案 A：自定义 Hook（推荐）

    ```tsx
    // hooks/useMediumZoom.ts
    import { useEffect, DependencyList } from 'react';
    import mediumZoom from 'medium-zoom';

    export const useMediumZoom = (
      selector: string = 'img[data-zoomable]',
      deps: DependencyList = []
    ) => {
      useEffect(() => {
        const zoom = mediumZoom(selector, {
          background: 'rgba(0, 0, 0, 0.9)',
          margin: 40,
        });

        return () => {
          zoom.detach(); // 清理避免内存泄漏
        };
      }, deps);
    };
    ```

    **使用示例**

    ```tsx
    // components/Gallery.tsx
    import { useMediumZoom } from '@/hooks/useMediumZoom';

    const images = [
      { id: 1, src: '/img1.jpg', alt: '图1' },
      { id: 2, src: '/img2.jpg', alt: '图2' },
    ];

    export default function Gallery() {
      // 依赖 images 变化（适用于动态加载）
      useMediumZoom('img[data-zoomable]', [images]);

      return (
        <div>
          {images.map((img) => (
            <img
              key={img.id}
              src={img.src}
              alt={img.alt}
              data-zoomable // 标记可缩放
              style={{ maxWidth: '100%' }}
            />
          ))}
        </div>
      );
    }
    ```

- 方案 B：直接在组件内初始化（简单场景）

    ```tsx
    import { useEffect } from 'react';
    import mediumZoom from 'medium-zoom';

    export default function PostContent({ contentHtml }: { contentHtml: string }) {
      useEffect(() => {
        mediumZoom('.post-content img');
      }, []);

      return <div className="post-content" dangerouslySetInnerHTML={{ __html: contentHtml }} />;
    }
    ```

> **注意**：若使用 `dangerouslySetInnerHTML`，需确保在 HTML 插入后调用 `mediumZoom`（可用 `useLayoutEffect` 或监听 DOM 变化）。

### 3.1.5 Svelte 中使用

- 方案 A：`onMount` + Action（推荐）

    ```svelte
    <!-- lib/zoom.js -->
    import mediumZoom from 'medium-zoom';

    export function zoom(node, options = {}) {
      let zoomInstance;

      const update = (newOptions) => {
        if (zoomInstance) zoomInstance.detach();
        zoomInstance = mediumZoom(node, newOptions);
      };

      update(options);

      return {
        update,
        destroy() {
          if (zoomInstance) zoomInstance.detach();
        }
      };
    }
    ```

    - 使用示例

### 3.1.6 SolidJS 中使用

- 方案 A：`createEffect` + 自定义指令（推荐）

    ```tsx
    // utils/zoom.ts
    import mediumZoom from 'medium-zoom';

    export const zoom = (el: HTMLImageElement, options?: Parameters<typeof mediumZoom>[1]) => {
      const zoomInstance = mediumZoom(el, options);
      return () => zoomInstance.detach(); // cleanup
    };
    ```

    **使用示例**

    ```tsx
    // components/Gallery.tsx
    import { createEffect, onCleanup } from 'solid-js';
    import { zoom } from '../utils/zoom';

    const images = [
      { id: 1, src: '/img1.jpg', alt: '图1' },
      { id: 2, src: '/img2.jpg', alt: '图2' }
    ];

    export default function Gallery() {
      let containerRef: HTMLDivElement | undefined;

      createEffect(() => {
        if (containerRef) {
          const imgs = containerRef.querySelectorAll('img[data-zoomable]');
          const cleanups = Array.from(imgs).map(img => zoom(img, {
            background: 'rgba(0,0,0,0.9)'
          }));

          onCleanup(() => {
            cleanups.forEach(cleanup => cleanup());
          });
        }
      });

      return (
        <div ref={containerRef}>
          {images.map(img => (
            <img
              src={img.src}
              alt={img.alt}
              data-zoomable
              style={{ "max-width": "100%" }}
            />
          ))}
        </div>
      );
    }
    ```

- 方案 B：单张图片指令

    ```tsx
    // 直接在 img 上使用
    <img
      src="/example.jpg"
      alt="示例"
      use:zoom={{ margin: 50 }}
    />
    ```

> SolidJS 中可通过 `use:` 指令实现类似 Svelte 的行为（需配合编译器插件或手动封装）。


### 3.1.7 配置选项

```js
mediumZoom(selector, {
  // 背景遮罩颜色
  background: 'rgba(255, 255, 255, 0.9)',

  // 图片边缘留白（px）
  margin: 40,

  // 缩放过渡时间（ms）
  scrollOffset: 40,

  // 容器（默认为 document.body）

  // 自定义模板（高级用法）

});
```

**常用配置示例**：

```js
// 深色背景 + 更大留白

```

### 3.1.9 常见问题

- 问题 1：图片未放大
    - **原因**：选择器未匹配到图片，或图片未加载完成
    - **解决**：
      ```js
      // 确保图片已加载
      const img = document.querySelector('.zoomable');
      if (img.complete) {
        mediumZoom(img);
      } else {
        img.onload = () => mediumZoom(img);
      }
      ```

- 问题 2：与 CSS 冲突（如 `max-width: 100%`）

    - **解决**：`medium-zoom` 会自动处理，但需确保图片**原始尺寸足够大**（缩略图可能模糊）

-  问题 3：动态内容（如评论区图片）不生效
    - **解决**：在新内容插入后重新初始化

      ```js
      // 例如使用 Vue 的 nextTick
      nextTick(() => {
        mediumZoom('.newly-added-images img');
      });
      ```

## 3.2 lightgallery

`lightgallery` 是一个功能强大、**完全免费（MIT 许可证）**、无 jQuery 依赖的现代 JavaScript 灯箱库，支持图片、视频、HTML 内容、响应式设计、触摸手势、键盘导航等，适用于 **商业和开源项目**。

- 官网: [https://www.lightgalleryjs.com/](https://www.lightgalleryjs.com/)
- GitHub: [https://github.com/sachinchoolur/lightgalleryjs](https://github.com/sachinchoolur/lightgalleryjs)
- 插件列表: [https://www.lightgalleryjs.com/docs/plugins/](https://www.lightgalleryjs.com/docs/plugins/)

> **核心优势**：
> - **MIT 开源协议**（可免费用于任何项目）
> - **轻量**（~25KB gzipped，按需加载插件可更小）
> - **TypeScript 支持**
> - **Vue / React / Svelte 友好**
> - **高度模块化**（核心 + 插件）

### 3.2.1 安装与引入

1. 安装

2. 同时需安装所需插件（如缩略图、全屏等）：

### 3.2.3 Vue 3 中使用

- 方案 A：组合式函数（Composable）

    ```js
    // composables/useLightGallery.js
    import { onMounted, onUnmounted } from 'vue';
    import LightGallery from 'lightgallery';
    import lgThumbnail from 'lg-thumbnail';
    import lgZoom from 'lg-zoom';

    export function useLightGallery(selector, options = {}) {
      let gallery = null;

      onMounted(() => {

      return { gallery };
    ```

### 3.2.4 React 中使用

- 方案 A：自定义 Hook（推荐）

    ```tsx
    // hooks/useLightGallery.ts
    import { useEffect, useRef } from 'react';
    import LightGallery from 'lightgallery';
    import lgThumbnail from 'lg-thumbnail';
    import lgZoom from 'lg-zoom';

    interface UseLightGalleryProps {
      elementId: string;
      options?: Parameters<typeof LightGallery>[1];
    }

    export const useLightGallery = ({ elementId, options = {} }: UseLightGalleryProps) => {
      const galleryRef = useRef<ReturnType<typeof LightGallery> | null>(null);

      useEffect(() => {
        const element = document.getElementById(elementId);
        if (element) {
          galleryRef.current = LightGallery(element, {
            plugins: [lgThumbnail, lgZoom],
            thumbnail: true,
            zoomFromOrigin: true,
            ...options,
          });
        }

        return () => {
          if (galleryRef.current) {
            galleryRef.current.destroy();
            galleryRef.current = null;
          }
        };
      }, [elementId]);
    };
    ```

### 3.2.5 svelte 中使用

    ```js
    // lib/lightgallery.js
    import LightGallery from 'lightgallery';
    import lgThumbnail from 'lg-thumbnail';
    import lgZoom from 'lg-zoom';

    export function lightgallery(node, options = {}) {
      let instance = null;

      const init = (opts) => {
        if (instance) instance.destroy();
    ```

### 3.2.7 核心配置选项

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `speed` | `number` | `400` | 动画速度（ms） |
| `thumbnail` | `boolean` | `false` | 是否显示缩略图 |
| `zoomFromOrigin` | `boolean` | `true` | 缩放动画从原图位置开始 |
| `allowMediaOverlap` | `boolean` | `false` | 允许媒体重叠（适合宽屏） |
| `loop` | `boolean` | `true` | 循环播放 |
| `escKey` | `boolean` | `true` | 按 ESC 关闭 |
| `keyPress` | `boolean` | `true` | 键盘左右键切换 |

## 3.3 viewerjs

`Viewer.js` 是一个专注于 **图片查看体验** 的 MIT 开源库（免费商用），支持 **缩放、旋转、翻转、全屏、触摸手势** 等操作。它无框架依赖，可轻松集成到 Vue、React、Svelte、SolidJS 中。

- GitHub: [https://github.com/fengyuanchen/viewerjs](https://github.com/fengyuanchen/viewerjs)
- Demo: [https://fengyuanchen.github.io/viewerjs/](https://fengyuanchen.github.io/viewerjs/)
- 文档: [https://github.com/fengyuanchen/viewerjs#options](https://github.com/fengyuanchen/viewerjs#options)


### 3.3.1 通用前提

    ```bash
    npm install viewerjs
    ```

### 3.3.2 Vue 3

1. 封装 Composable

    ```ts
    // composables/useViewer.ts
    import { onMounted, onUnmounted } from 'vue';
    import Viewer from 'viewerjs';

    export function useViewer(selector: string, options = {}) {
      let viewerInstance: Viewer | null = null;

      onMounted(() => {
        const el = document.querySelector(selector);
        if (el) {
          viewerInstance = new Viewer(el, {
            navbar: true,
            toolbar: true,
            ...options
          });
        }
      });

      onUnmounted(() => {
        if (viewerInstance) {
          viewerInstance.destroy();
        }
      });
    }
    ```

### 3.3.3 React（Hooks）

1. 自定义 Hook

    ```tsx
    // hooks/useViewer.ts
    import { useEffect, useRef } from 'react';
    import Viewer from 'viewerjs';

    export const useViewer = (selector: string, options = {}) => {
      const viewerRef = useRef<Viewer | null>(null);

      useEffect(() => {
        const element = document.querySelector(selector);
        if (element) {
          viewerRef.current = new Viewer(element, {
            navbar: true,
            toolbar: true,
            ...options
          });
        }

        return () => {
          if (viewerRef.current) {
            viewerRef.current.destroy();
            viewerRef.current = null;
          }
        };
      }, [selector]);
    };
    ```

2. 组件使用

    ```tsx
    // components/ImageViewer.tsx
    import { useViewer } from '@/hooks/useViewer';

    const images = [
      { thumb: '/thumb1.jpg', full: '/full1.jpg', title: '图1' },
      { thumb: '/thumb2.jpg', full: '/full2.jpg', title: '图2' }

    export default function ImageViewer() {
      useViewer('#image-gallery');

      return (
        <div id="image-gallery">
          {images.map((img, index) => (
            <img
              key={index}
              src={img.thumb}
              data-original={img.full}
              alt={img.title}
            />
          ))}
        </div>
      );
    }
    ```

### 3.3.4 Svelte（Action）

1. 创建 Action

    ```js
    // lib/viewer.js
    import Viewer from 'viewerjs';

    export function viewer(node, options = {}) {
      let instance = null;

      const init = (opts) => {
        if (instance) instance.destroy();
        instance = new Viewer(node, {
          navbar: true,
          toolbar: true,
          ...opts
        });
      };

      init(options);

      return {
        update(newOptions) {
          init(newOptions);
        },
        destroy() {
          if (instance) instance.destroy();
        }
      };
    }
    ```

2. 组件使用

### 3.3.5 SolidJS（Reactive）

1. 封装工具函数

    ```ts
    // utils/viewer.ts
    import Viewer from 'viewerjs';

    export const createViewer = (element: HTMLElement, options = {}) => {
      const instance = new Viewer(element, {
        navbar: true,
        toolbar: true,
        ...options
      });

      return () => instance.destroy(); // cleanup
    };
    ```

2. 组件使用

    ```tsx
    // components/ImageViewer.tsx
    import { createEffect, onCleanup } from 'solid-js';
    import { createViewer } from '../utils/viewer';

    const images = [
      { thumb: '/thumb1.jpg', full: '/full1.jpg', title: '图1' },
      { thumb: '/thumb2.jpg', full: '/full2.jpg', title: '图2' }
    ];

    export default function ImageViewer() {
      let galleryRef: HTMLDivElement | undefined;

      createEffect(() => {
        if (galleryRef) {
          const cleanup = createViewer(galleryRef, {
            toolbar: {
              zoomIn: 4,
              zoomOut: 4,
              rotateLeft: 2,
              rotateRight: 2
            }
          });
          onCleanup(cleanup);
        }
      });

      return (
        <div ref={galleryRef!}>
          {images.map(img => (
            <img
              src={img.thumb}
              data-original={img.full}
              alt={img.title}
            />
          ))}
        </div>
      );
    }
    ```
