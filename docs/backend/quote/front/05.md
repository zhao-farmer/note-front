# 五、时间插件

## 5.1 timeago.js

`timeago.js` 是一个轻量级（~2KB）、无依赖的 JavaScript 库，用于将**时间戳或日期**自动转换为 **“相对时间”**（如 “3分钟前”、“2天前”、“刚刚”），并支持**自动刷新**和**多语言国际化**。

- GitHub: [https://github.com/hustcc/timeago.js](https://github.com/hustcc/timeago.js)
- Demo: [https://timeago.org/](https://timeago.org/)
- 语言列表: [https://github.com/hustcc/timeago.js/tree/master/src/lang](https://github.com/hustcc/timeago.js/tree/master/src/lang)

> **典型场景**：社交媒体动态、评论时间、消息列表、通知中心等。

### 5.1.1 安装与基础用法

1. 安装

    ```bash
    npm install timeago.js
    ```

2. 基础使用（原生 JS）

    ```js
    import { format, render, cancel } from 'timeago.js';

    // 1. 格式化为字符串（静态）
    const str = format('2025-01-18T10:00:00Z'); // "2天前"（假设今天是 2025-01-20）

    // 2. 自动刷新 DOM（推荐）
    const domElement = document.getElementById('time');
    render(domElement, '2025-01-18T10:00:00Z'); // 自动每 30 秒更新一次

    // 3. 取消自动刷新（可选）
    cancel(domElement);
    ```

    >  `render()` 会自动监听元素，并定期更新内容，非常适合动态列表。

### 5.1.2 多语言支持（i18n）

- 内置语言

    `timeago.js` 内置 **40+ 种语言**（包括中文、英文、日文、西班牙文等）。

- 使用中文

    ```js
    import { format, render, register } from 'timeago.js';
    import * as zhLocale from 'timeago.js/lib/lang/zh_CN';

    // 注册中文（只需一次）
    register('zh_CN', zhLocale);

    // 使用
    format('2025-01-18T10:00:00Z', 'zh_CN'); // "2天前"

    // 或在 render 中指定
    render(document.getElementById('time'), '2025-01-18T10:00:00Z', 'zh_CN');
    ```

- 常见语言代码

    | 语言 | 代码 |
    |------|------|
    | 简体中文 | `zh_CN` |
    | 英语 | `en` |
    | 日语 | `ja` |
    | 西班牙语 | `es` |
    | 法语 | `fr` |

> **切换语言**：只需改变 `render()` 的第三个参数即可。


### 5.1.3 自定义格式（高级）

你可以完全自定义时间文本：

```js
import { register } from 'timeago.js';

// 自定义中文格式
register('my_zh', (number, index) => {
  const texts = [
    ['刚刚', '片刻后'],
    ['%s秒前', '%s秒后'],
    ['1分钟前', '1分钟后'],
    ['%s分钟前', '%s分钟后'],
    ['1小时前', '1小时后'],
    ['%s小时前', '%s小时后'],
    ['1天前', '1天后'],
    ['%s天前', '%s天后'],
    ['1周前', '1周后'],
    ['%s周前', '%s周后'],
    ['1月前', '1月后'],
    ['%s月前', '%s月后'],
    ['1年前', '1年后'],
    ['%s年前', '%s年后']
  ];
  return texts[index][0]; // 只显示“过去”形式
});

// 使用
format(new Date(Date.now() - 60000), 'my_zh'); // "1分钟前"
```

>  `index` 对应时间区间（0=刚刚，1=秒，2=1分钟，3=多分钟...）

### 5.1.4 在主流框架中使用

**通用原则**

- 使用 `render()` 实现自动刷新
- 在组件销毁时调用 `cancel()` 避免内存泄漏


#### 1. Vue 3（Composition API）

```vue
<!-- components/TimeAgo.vue -->
<template>
  <span ref="timeRef"></span>
</template>

<script setup>
import { onMounted, onUnmounted, ref } from 'vue';
import { render, cancel } from 'timeago.js';
import * as zhLocale from 'timeago.js/lib/lang/zh_CN';
import { register } from 'timeago.js';

register('zh_CN', zhLocale);

const props = defineProps({
  datetime: { type: [String, Date], required: true }
});

const timeRef = ref(null);

onMounted(() => {
  render(timeRef.value, props.datetime, 'zh_CN');
});

onUnmounted(() => {
  if (timeRef.value) {
    cancel(timeRef.value);
  }
});
</script>
```

**使用**：
```vue
<TimeAgo :datetime="comment.createdAt" />
```

#### 2. React（Hooks）

```tsx
// hooks/useTimeAgo.ts
import { useEffect, useRef } from 'react';
import { render, cancel } from 'timeago.js';
import * as zhLocale from 'timeago.js/lib/lang/zh_CN';
import { register } from 'timeago.js';

register('zh_CN', zhLocale);

export const useTimeAgo = (element: HTMLElement | null, datetime: string | Date) => {
  const locale = 'zh_CN';

  useEffect(() => {
    if (element) {
      render(element, datetime, locale);
    }

    return () => {
      if (element) {
        cancel(element);
      }
    };
  }, [element, datetime, locale]);
};
```

```tsx
// components/TimeAgo.tsx
import { useRef } from 'react';
import { useTimeAgo } from '@/hooks/useTimeAgo';

export default function TimeAgo({ datetime }: { datetime: string | Date }) {
  const spanRef = useRef<HTMLSpanElement>(null);
  useTimeAgo(spanRef.current, datetime);

  return <span ref={spanRef}></span>;
}
```

#### 3. Svelte（Action）

```js
// lib/timeago.js
import { render, cancel } from 'timeago.js';
import * as zhLocale from 'timeago.js/lib/lang/zh_CN';
import { register } from 'timeago.js';

register('zh_CN', zhLocale);

export function timeago(node, datetime) {
  render(node, datetime, 'zh_CN');

  return {
    update(newDatetime) {
      // 重新渲染（内部会自动 cancel + render）
      render(node, newDatetime, 'zh_CN');
    },
    destroy() {
      cancel(node);
    }
  };
}
```

```svelte
<!-- App.svelte -->
<script>
  import { timeago } from './lib/timeago';
  const createdAt = '2025-01-18T10:00:00Z';
</script>

<span use:timeago={createdAt}></span>
```

#### 4. SolidJS

```tsx
// utils/timeago.ts
import { render, cancel } from 'timeago.js';
import * as zhLocale from 'timeago.js/lib/lang/zh_CN';
import { register } from 'timeago.js';

register('zh_CN', zhLocale);

export const createTimeAgo = (element: HTMLElement, datetime: string | Date) => {
  render(element, datetime, 'zh_CN');
  return () => cancel(element);
};
```

```tsx
// components/TimeAgo.tsx
import { createEffect, onCleanup } from 'solid-js';
import { createTimeAgo } from '../utils/timeago';

export default function TimeAgo(props: { datetime: string | Date }) {
  let spanRef: HTMLSpanElement | undefined;

  createEffect(() => {
    if (spanRef) {
      const cleanup = createTimeAgo(spanRef, props.datetime);
      onCleanup(cleanup);
    }
  });

  return <span ref={spanRef!}></span>;
}
```

### 5.1.5 常见问题

- 问题 1：时间不更新

    - **原因**：未使用 `render()`，只用了 `format()`
    - **解决**：用 `render(dom, date)` 实现自动刷新

- 问题 2：内存泄漏

    - **原因**：未在组件销毁时 `cancel()`
    - **解决**：务必在 `onUnmounted` / `useEffect cleanup` / `destroy` 中调用 `cancel(element)`

- 问题 3：语言未生效

    - **解决**：确保已 `register()` 语言包

### 5.1.6 自动刷新机制

- `render()` 默认 **每 30 秒** 检查一次是否需要更新
- 当时间从 “29秒前” → “30秒前” 时，会变为 “1分钟前”
- 无需手动管理定时器


## 5.2 date-fns

`date-fns` 是一个现代化、轻量级、函数式风格的 **JavaScript 日期处理库**，专为解决原生 `Date` 对象的痛点而设计。它采用 **不可变数据、Tree-shaking 友好、模块化导入** 的理念，已成为现代前端项目处理日期的首选。


- 官网: [https://date-fns.org/](https://date-fns.org/)
- GitHub: [https://github.com/date-fns/date-fns](https://github.com/date-fns/date-fns)
- 文档: [https://date-fns.org/docs/Getting-Started](https://date-fns.org/docs/Getting-Started)
- 格式化规则: [https://date-fns.org/docs/format](https://date-fns.org/docs/format)


### 5.2.1 安装与基础用法

1. 安装

    ```bash
    npm install date-fns
    ```

2. 基础使用（按需导入）

    ```js
    // 推荐：只导入需要的函数（支持 Tree-shaking）
    import { format, addDays, isAfter, parseISO } from 'date-fns';

    const today = new Date();
    const tomorrow = addDays(today, 1);
    console.log(format(tomorrow, 'yyyy-MM-dd')); // "2025-01-20"

    // 解析 ISO 字符串
    const date = parseISO('2025-01-18T10:00:00Z');
    console.log(isAfter(today, date)); // true
    ```

    > **不要这样用**（会打包整个库）：
    > ```js
    > import * as dateFns from 'date-fns'; // 避免！
    > ```


### 5.2.2 国际化（多语言支持）

1. 使用中文

    ```js
    import { format } from 'date-fns';
    import { zhCN } from 'date-fns/locale';

    format(new Date(), 'yyyy年MM月dd日 EEEE', { locale: zhCN });
    // 输出："2025年01月19日 星期日"
    ```

2. 动态切换语言

    ```js
    import { enUS, es, fr, ja } from 'date-fns/locale';

    const locales = { en: enUS, es, fr, ja, zh: zhCN };

    function formatDate(date, formatStr, lang = 'en') {
      return format(date, formatStr, { locale: locales[lang] });
    }
    ```

>  所有格式化函数（`format`, `formatDistance`, `formatRelative` 等）都支持 `locale` 选项。


### 5.2.3 常用函数分类

1. **格式化**

    | 函数 | 说明 |
    |------|------|
    | `format(date, 'yyyy-MM-dd')` | 自定义格式 |
    | `formatDistance(date1, date2)` | “2天前”、“3小时后” |
    | `formatRelative(date, baseDate)` | “昨天”、“下周三” |

    ```js
    import { formatDistance, formatRelative } from 'date-fns';
    import { zhCN } from 'date-fns/locale';

    formatDistance(new Date(2025, 0, 18), new Date(), { locale: zhCN }); // "1天前"
    formatRelative(new Date(2025, 0, 21), new Date(), { locale: zhCN }); // "下周二"
    ```

2. **解析与构造**

    | 函数 | 说明 |
    |------|------|
    | `parseISO('2025-01-18T10:00:00Z')` | 解析 ISO 8601 字符串 |
    | `parse('02/14/2025', 'MM/dd/yyyy', new Date())` | 自定义格式解析 |
    | `newDate(year, month, day)` | 安全创建日期（避免月份从0开始的问题）|

3. **计算与操作**

    | 函数 | 说明 |
    |------|------|
    | `addDays(date, 7)` | 加7天 |
    | `subMonths(date, 1)` | 减1个月 |
    | `startOfDay(date)` | 获取当天 00:00:00 |
    | `endOfWeek(date)` | 获取本周最后时刻 |

    ```js
    import { addWeeks, startOfMonth, isWithinInterval } from 'date-fns';

    const nextMonth = addWeeks(new Date(), 4);
    const monthStart = startOfMonth(new Date());
    const isActive = isWithinInterval(new Date(), { start: monthStart, end: nextMonth });
    ```

4. **比较与判断**

    | 函数 | 说明 |
    |------|------|
    | `isAfter(date1, date2)` | date1 是否在 date2 之后 |
    | `isSameDay(date1, date2)` | 是否同一天 |
    | `isWeekend(date)` | 是否周末 |
    | `isValid(date)` | 日期是否有效 |


### 5.2.4 在主流框架中使用

**通用优势**
- **无副作用**：所有函数返回新 `Date` 对象（不可变）
- **类型安全**：完美支持 TypeScript
- **轻量**：每个函数 ~1–3KB，按需引入


#### 1. Vue 3（Composition API + TypeScript）

```vue
<!-- components/EventCard.vue -->
<template>
  <div>
    <h3>{{ event.title }}</h3>
    <p>开始时间：{{ formattedStart }}</p>
    <p v-if="isFuture">即将开始</p>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue';
import { format, isFuture } from 'date-fns';
import { zhCN } from 'date-fns/locale';

interface Event {
  title: string;
  startTime: string; // ISO string
}

const props = defineProps<{ event: Event }>();

const formattedStart = computed(() =>
  format(new Date(props.event.startTime), 'yyyy年MM月dd日 HH:mm', { locale: zhCN })
);

const isFutureTime = computed(() =>
  isFuture(new Date(props.event.startTime))
);
</script>
```

### 5.2.5 常见陷阱与解决方案

- 陷阱 1：原生 `Date` 月份从 0 开始

    ```js
    // 危险！
    new Date(2025, 1, 1); // 实际是 2025-02-01（不是1月！）

    // 安全方案
    import { newDate } from 'date-fns';
    newDate(2025, 1, 1); // 正确创建 2025-01-01
    ```

- 陷阱 2：时区问题

    - `date-fns` **不处理时区**（基于本地时间）
    - 如需时区支持 → 结合 `Intl` 或使用 **Luxon**

- 陷阱 3：无效日期
    
    ```js
    // 检查日期有效性
    import { isValid } from 'date-fns';
    
    const date = new Date('invalid');
    if (isValid(date)) {
      // 安全使用
    }
    ```
