# 六、产品引导

## 6.1 intro.js 使用

`intro.js` 是一个功能强大、用户友好的 **产品引导/新手教程（Onboarding Tour）** JavaScript 库，可帮助你为网站或应用创建交互式引导流程（Step-by-step walkthrough），支持高亮元素、添加说明、导航控制、键盘快捷键等。


- 官网: https://introjs.com/  
- GitHub: https://github.com/usablica/intro.js  
- 文档: https://introjs.com/docs/  
- Demo: https://introjs.com/demo/

> **免费 vs 付费**：  
> - **开源版（MIT）**：完全免费，支持所有核心功能  
> - **Pro 版（收费）**：提供高级模板、团队协作、分析等（非必需）

> **核心优势**：
> - 支持高亮页面任意 DOM 元素
> - 提供“下一步/上一步/跳过”标准 UI
> - 支持键盘导航（← → Esc）
> - 响应式设计（适配移动端）
> - 可定制主题和行为
> - 支持 Vue / React / Svelte / SolidJS 等框架

### 6.1.1 安装与基础用法

1. 安装

    ```bash
    npm install intro.js
    ```

2. 引入资源

    ```js
    // JS
    import introJs from 'intro.js';
    // CSS（必须）
    import 'intro.js/introjs.css';
    ```
3. 基础 HTML 示例

    ```html
    <h1 id="step1">欢迎使用我们的产品</h1>
    <button id="step2">点击这里开始</button>
    <div id="step3">这是重要功能区</div>
    ```

4. 初始化引导

    ```js
    introJs().setOptions({
      steps: [
        {
          element: '#step1',
          intro: '这是标题区域',
          position: 'bottom'
        },
        {
          element: '#step2',
          intro: '点击按钮开始操作',
          position: 'right'
        },
        {
          intro: '这是没有绑定元素的全局提示（居中显示）'
        }
      ]
    }).start();
    ```

> 如果不指定 `element`，提示框将居中显示（适合介绍整体功能）。


### 6.1.2 核心配置选项

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `steps` | `Array` | `[]` | 引导步骤数组 |
| `nextLabel` | `string` | `'Next'` | “下一步”按钮文本 |
| `prevLabel` | `string` | `'Back'` | “上一步”按钮文本 |
| `skipLabel` | `string` | `'Skip'` | “跳过”按钮文本 |
| `doneLabel` | `string` | `'Done'` | “完成”按钮文本 |
| `showStepNumbers` | `boolean` | `true` | 是否显示步骤编号 |
| `exitOnOverlayClick` | `boolean` | `true` | 点击遮罩层是否退出 |
| `exitOnEsc` | `boolean` | `true` | 按 Esc 是否退出 |
| `keyboardNavigation` | `boolean` | `true` | 启用键盘导航 |
| `tooltipPosition` | `string` | `'bottom'` | 默认提示位置（top/bottom/left/right）|

**步骤对象字段**

```ts
{
  element?: string;     // CSS 选择器（如 "#btn"）
  intro: string;        // 提示内容（支持 HTML）
  position?: 'top' | 'bottom' | 'left' | 'right' | 'floating';
  tooltipClass?: string; // 自定义 tooltip 类名
  highlightClass?: string; // 自定义高亮区域类名
}
```

### 6.1.3 自定义样式

1. 覆盖默认样式

    ```css
    /* 修改提示框背景 */
    .introjs-tooltip {
      background-color: #3b82f6 !important;
      color: white !important;
    }

    /* 修改按钮样式 */
    .introjs-button {
      background-color: #1d4ed8 !important;
      border-color: #1d4ed8 !important;
    }

    /* 修改高亮遮罩透明度 */
    .introjs-overlay {
      background-color: rgba(0, 0, 0, 0.7) !important;
    }
    ```

2. 使用 CSS 变量（v7+）

    ```css
    :root {
      --introjs-tooltip-background-color: #3b82f6;
      --introjs-tooltip-color: white;
      --introjs-button-background-color: #1d4ed8;
    }
    ```

### 6.1.4 事件与回调

```js
introJs()
  .onbeforechange((targetElement) => {
    console.log('即将切换到:', targetElement);
  })
  .onchange((targetElement) => {
    console.log('已切换到:', targetElement);
  })
  .oncomplete(() => {
    console.log('引导完成');
    // 例如：标记用户已完成引导
    localStorage.setItem('onboarding_done', 'true');
  })
  .onexit(() => {
    console.log('用户跳过或关闭引导');
  })
  .start();
```


### 6.1.5 在主流框架中使用

通用原则
- 在组件挂载后初始化
- 在组件销毁时清理（避免内存泄漏）
- 动态内容需确保 DOM 已渲染


#### 1. Vue 3（Composition API）

```vue
<!-- components/OnboardingTour.vue -->
<template>
  <div>
    <h1 ref="titleRef">欢迎</h1>
    <button ref="btnRef">开始</button>
  </div>
</template>

<script setup>
import { onMounted, onUnmounted } from 'vue';
import introJs from 'intro.js';
import 'intro.js/introjs.css';

let tour = null;

onMounted(() => {
  tour = introJs().setOptions({
    steps: [
      {
        element: titleRef.value,
        intro: '这是标题',
        position: 'bottom'
      },
      {
        element: btnRef.value,
        intro: '点击开始',
        position: 'right'
      }
    ]
  });
  
  // 可选：自动启动
  // tour.start();
});

onUnmounted(() => {
  if (tour) tour.exit();
});
</script>
```

#### 2. React（Hooks）

```tsx
// hooks/useIntroJs.ts
import { useEffect, useRef } from 'react';
import introJs from 'intro.js';

export const useIntroJs = (steps: any[], autoStart = false) => {
  const tourRef = useRef<any>(null);

  useEffect(() => {
    tourRef.current = introJs().setOptions({ steps });

    if (autoStart) {
      tourRef.current.start();
    }

    return () => {
      if (tourRef.current) {
        tourRef.current.exit();
      }
    };
  }, [steps]);

  return {
    start: () => tourRef.current?.start(),
    exit: () => tourRef.current?.exit()
  };
};
```

```tsx
// App.tsx
import { useIntroJs } from './hooks/useIntroJs';

export default function App() {
  const { start } = useIntroJs([
    { element: '#header', intro: '顶部导航' },
    { element: '#main-btn', intro: '主操作按钮' }
  ]);

  return (
    <div>
      <h1 id="header">Header</h1>
      <button id="main-btn" onClick={start}>开始引导</button>
    </div>
  );
}
```

> 全局引入 CSS：
> ```tsx
> // main.tsx
> import 'intro.js/introjs.css';
> ```

#### 3. Svelte（Action）

```js
// lib/introjs.js
import introJs from 'intro.js';

export function introjs(node, options) {
  let instance = null;

  const start = () => {
    if (instance) instance.exit();
    instance = introJs().setOptions(options);
    instance.start();
  };

  start();

  return {
    update(newOptions) {
      // 可选：支持动态更新
    },
    destroy() {
      if (instance) instance.exit();
    }
  };
}
```

```svelte
<!-- App.svelte -->
<script>
  import { introjs } from './lib/introjs';

  const steps = [
    { element: '#title', intro: '标题' },
    { element: '#btn', intro: '按钮' }
  ];
</script>

<div use:introjs={{ steps }}>
  <h1 id="title">Hello</h1>
  <button id="btn">Click</button>
</div>

<style>
  @import 'intro.js/introjs.css';
</style>
```

#### 4. SolidJS

```tsx
// utils/introjs.ts
import introJs from 'intro.js';

export const createIntroJs = (steps: any[]) => {
  const instance = introJs().setOptions({ steps });
  return () => instance.exit(); // cleanup
};
```

```tsx
// App.tsx
import { createEffect, onCleanup } from 'solid-js';
import { createIntroJs } from './utils/introjs';

let titleRef: HTMLHeadingElement | undefined;
let btnRef: HTMLButtonElement | undefined;

createEffect(() => {
  if (titleRef && btnRef) {
    const cleanup = createIntroJs([
      { element: titleRef, intro: '标题' },
      { element: btnRef, intro: '按钮' }
    ]);
    onCleanup(cleanup);
  }
});

return (
  <>
    <h1 ref={titleRef!}>Title</h1>
    <button ref={btnRef!}>Button</button>
  </>
);
```

### 6.1.6 高级用法

1. 动态步骤（根据用户状态）

    ```js
    const steps = [];
    if (!user.hasSeenFeatureA) {
      steps.push({ element: '#feature-a', intro: '新功能 A' });
    }
    if (!user.hasSeenFeatureB) {
      steps.push({ element: '#feature-b', intro: '新功能 B' });
    }

    introJs().setOptions({ steps }).start();
    ```

2. 条件跳转

    ```js
    introJs()
      .onchange((target) => {
        if (target.id === 'conditional-step') {
          // 根据条件跳过下一步
          if (someCondition) {
            introJs().goToStep(5); // 跳转到第 5 步
          }
        }
      })
      .start();
    ```

3. 本地存储记录

    ```js
    // 启动前检查
    if (!localStorage.getItem('onboarding_v2_done')) {
      introJs().oncomplete(() => {
        localStorage.setItem('onboarding_v2_done', 'true');
      }).start();
    }
    ```

### 6.1.7 常见问题

- 问题 1：元素未找到（控制台警告）
    - **原因**：DOM 尚未渲染
    - **解决**：确保在 `onMounted` / `useEffect` 中初始化

- 问题 2：样式未加载

    **解决**：显式引入 CSS

    ```js
    import 'intro.js/introjs.css';
    ```

- 问题 3：多次初始化

    **解决**：始终在销毁时调用 `.exit()`
