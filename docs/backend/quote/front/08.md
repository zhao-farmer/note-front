# 八、富文本

## 8.1 Tinymce 

TinyMCE 是富文本编辑器领域的头部玩家之一，主流富文本编辑器，功能非常全，你需要的大多数功能它都支持。排出复杂又美观文章样式，代码高亮等都是基础功能。它甚至有点像在线版的 Word，可以在顶部的各种菜单中找到你要的功能。但它的优势也恰恰是它的劣势，如此之多的功能都放上来导致整个编辑器非常重，如果只是需要简单功能，上这么复杂的编辑器，大材小用。

中文文档：[http://tinymce.ax-z.cn/more-plugins/axupimgs.php](http://tinymce.ax-z.cn/more-plugins/axupimgs.php)
英文官网：[https://www.tiny.cloud/](https://www.tiny.cloud/)

### 8.1.1 安装

1. vue2

    ```sh
    #安装tinymce
    npm install tinymce@5.10.3 -S  #或npm install tinymce@5

    #安装tinymce-vue
    npm install @tinymce/tinymce-vue@3.0.1 -S
    ```    
    vue2不支持5以上的版本，5版本还在一直更新使用没问题

2. vue3

    ```sh
    #安装tinymce
    npm install tinymce -S
    #安装tinymce-vue
    npm install @tinymce/tinymce-vue -S
    ```

### 8.1.6 上传图片视频

Tinymce富文本编辑器在vue项目中的使用；引入第三方插件和上传视频、图片等

![](/backend/quote/front/image/007.png)

- 第一步：安装依赖 

	```sh
	npm install tinymce@5.0.12
	```
- 第二步：在项目中的public文件夹中新建tinymce文件夹（因为我的项目是脚手架创建的，所以公共文件夹是public）；在node_modules中找到skins文件夹复制到tinymce文件夹中

- 第三步：第三方插件的引入（数学公式、导入word）：
	
	1. 最后两行是另外下载的插件（数学公式、导入word）,上面的二和三步的tinymce文件夹里面新建plugins文件夹，下载的两个插件就丢这里面;

		- 数学公式： kityformula-editor 
		- 下载地址： `http://tinymce.ax-z.cn/more-plugins/kityformula-editor.php`
		
		- 导入word：importword 
		- 下载地址：`https://github.com/Five-great/tinymce-plugins`

## 8.2 Editor.js
	
`Editor.js` 是一个现代化的 **块状结构（Block-based）富文本编辑器**，由 [Codex Team](https://codex.so/) 开发。它的最大特点是：

- **输出为结构化 JSON**（而非 HTML），便于存储、解析和二次处理  
- 每个内容单元是一个“块”（Block）：段落、标题、图片、列表、代码等  
- 插件即“工具”（Tool），高度模块化  
- 无冗余 HTML，SEO 友好，适合 CMS、知识库、文档系统等场景

- 官网：[https://editorjs.io/](https://editorjs.io/)
- GitHub：[https://github.com/codex-team/editor.js](https://github.com/codex-team/editor.js)
- 工具列表：[https://github.com/editor-js](https://github.com/editor-js)
- 在线 Demo：[https://editorjs.io/examples](https://editorjs.io/examples)

## 8.3 Tiptap

`Tiptap` 是一个基于 **ProseMirror** 的现代化、**无头（Headless）** 富文本编辑器框架，具有**高度可定制性**、**TypeScript 友好**、**插件化架构**，适用于 Vue、React 等现代前端框架。

>  官网：[https://tiptap.dev]
>  GitHub：[https://github.com/ueberdosis/tiptap]


### 8.3.1 核心特点

| 特性 | 说明 |
|------|------|
| **Headless** | 不强制 UI，完全由你控制工具栏、菜单等 |
| **输出干净 HTML 或 JSON** | 避免冗余标签（如 `<font>`、内联样式） |
| **协作编辑支持** | 通过 `y-prosemirror` 实现多人实时协同 |
| **撤销/重做、历史记录** | 内置强大状态管理 |
| **Vue / React 官方支持** | 提供专用绑定包 |
| **扩展性强** | 可自定义节点（Node）、标记（Mark）、命令（Command） |

## 8.4 wangEditer（已停止维护）

`wangEditor` 原版（通常指 **v4 或 v5**）是由国内开发者王福朋（@wangeditor-team）开发的一款轻量级、中文友好的富文本编辑器。虽然 **官方已于 2023–2024 年停止维护**，但因其简单易用、文档完善，仍被大量老项目使用。



### 8.4.1 安装

```bash

npm install wangeditor@5
```

或通过 CDN（快速测试）：
```html

```

### 8.4.2 基本用法（原生 JS）

- HTML 结构

	```html
	<div id="editor-container" style="border: 1px solid #ccc; height: 400px;"></div>
	<button onclick="getEditorContent()">获取内容</button>
	```

- 初始化编辑器

	```js
	const E = window.wangEditor
	const editor = new E('#editor-container')

	// 配置（可选）
	editor.config.placeholder = '请输入内容...'

	// 自定义图片上传（重要！）
	editor.config.uploadImgServer = '/api/upload' // 后端接口
	editor.config.uploadFileName = 'file'         // 文件字段名
	editor.config.uploadImgMaxSize = 2 * 1024 * 1024 // 2MB
	editor.config.uploadImgMaxLength = 5           // 最多传 5 张

	// 监听内容变化
	editor.config.onchange = (newHtml) => {
	  console.log('当前 HTML 内容:', newHtml)
	}

	// 创建编辑器
	editor.create()

	// 获取内容函数
	function getEditorContent() {
	  const html = editor.txt.html()
	  console.log('最终内容:', html)
	}
	```

> 编辑器会自动将 `#editor-container` 替换为工具栏 + 编辑区域。
