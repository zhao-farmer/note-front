## 2.1 渲染模式



### 2.1.1 渲染模式概述

三种主要的渲染模式：

- **客户端渲染 (CSR)** - 传统的 Angular 渲染方式，在浏览器中渲染应用。
- **服务器端渲染 (SSR)** - 在服务器上渲染应用，然后将静态 HTML 发送到客户端。
- **静态站点生成 (SSG)** - 在构建时预渲染页面，生成静态 HTML 文件。

### 2.2.2 统一架构

1. 项目配置

    在 `angular.json` 中，你可以配置渲染模式：

    ```json
    {
      "projects": {
        "my-app": {
          "projectType": "application",
          "architect": {
            "build": {
              "builder": "@angular-devkit/build-angular:application",
              "configurations": {
                "production": {
                  "ssr": {
                    "enabled": true
                  },
                  "prerender": true
                }
              }
            }
          }
        }
      }
    }
    ```

2. 服务器入口点

    Angular 使用一个服务器入口点来处理 SSR：

    ```typescript
    // main.server.ts
    import { bootstrapApplication } from '@angular/platform-browser';
    import { AppComponent } from './app/app.component';
    import { config } from './app/app.config.server';

    const bootstrap = () => bootstrapApplication(AppComponent, config);

    export default bootstrap;
    ```
3. 服务器配置

    ```typescript
    // app.config.server.ts
    import { mergeApplicationConfig, ApplicationConfig } from '@angular/core';
    import { provideServerRendering } from '@angular/platform-server';
    import { appConfig } from './app.config';

    const serverConfig: ApplicationConfig = {
      providers: [
        provideServerRendering()
      ]
    };

    export const config = mergeApplicationConfig(appConfig, serverConfig);
    ```

### 2.2.3 水合（Hydration）

Angula改进了水合过程，提供了非破坏性水合（Non-destructive hydration），这意味着在客户端激活过程中不会破坏现有的 DOM 元素，从而避免闪烁和保持状态。

1. 启用水合

    在应用配置中提供水合支持：

    ```typescript
    // app.config.ts
    import { ApplicationConfig, provideZoneChangeDetection } from '@angular/core';
    import { provideClientHydration, withEventReplay } from '@angular/platform-browser';

    export const appConfig: ApplicationConfig = {
      providers: [
        provideZoneChangeDetection({ eventCoalescing: true }),
        provideClientHydration(withEventReplay()) // 启用事件重放
      ]
    };
    ```

2. 水合优化


    ```typescript
    import { Component, SkipHydration } from '@angular/core';

    @Component({
      selector: 'app-example',
      template: `<div>一些内容</div>`
    })
    export class ExampleComponent {
      // 跳过水合
      @SkipHydration() skipHydration = true;
    }
    ```

### 2.2.4 延迟加载和部分水合

Angular支持延迟加载组件，并且可以结合部分水合，只水合关键部分，其余部分延迟水合。

1. 延迟加载组件

    使用 `@defer` 指令延迟加载组件：

    ```js
    @defer (when loadComponent) {
    
    } @placeholder {
    
    }
    ```

2. 部分水合

    通过延迟加载，可以实现部分水合，即只水合当前可见的组件，而延迟水合其他组件。

### 2.2.5 静态站点生成（SSG）

Angular 增强了 SSG 功能，可以预渲染整个应用或部分路由。

1. 配置预渲染路由

    在 `angular.json` 中配置需要预渲染的路由：

    ```json
    {
      "projects": {
        "my-app": {
          "architect": {
            "build": {
              "configurations": {
                "production": {
                  "prerender": true,
                  "routes": [
                    "/",
                    "/about",
                    "/contact"
                  ]
                }
              }
            }
          }
        }
      }
    }
    ```

2. 动态参数预渲染

    对于动态路由，可以使用脚本来生成路由列表：

    ```javascript
    // prerender-routes.js
    module.exports = [
      '/',
      '/about',
      '/products/1',
      '/products/2'
    ];
    ```

    然后在配置中引用：

    ```json
    "routesFile": "./prerender-routes.js"
    ```

### 2.2.6 混合渲染模式

Angular允许在同一应用中使用混合渲染模式。例如，某些路由使用 SSR，某些使用 CSR，某些使用 SSG。

1. 路由级渲染模式

    通过路由配置指定渲染模式：

    ```typescript
    const routes: Routes = [
      {
        path: '',
        component: HomeComponent,
        data: { 
          ssr: true, 
          prerender: true 
        }
      },
      {
        path: 'dashboard',
        component: DashboardComponent,
        data: { 
          ssr: false  // 仅客户端渲染
        }
      },
      {
        path: 'products/:id',
        component: ProductDetailComponent,
        data: { 
          ssr: true, 
          prerender: false  // 不预渲染，但使用 SSR
        }
      }
    ];
    ```

2. 条件性渲染

    在组件中可以根据环境条件性渲染内容：

    ```typescript
    import { isPlatformBrowser, isPlatformServer } from '@angular/common';
    import { PLATFORM_ID, Inject } from '@angular/core';

    @Component({...})
    export class MyComponent {
      constructor(@Inject(PLATFORM_ID) private platformId: any) {}

      get isBrowser(): boolean {
        return isPlatformBrowser(this.platformId);
      }

      get isServer(): boolean {
        return isPlatformServer(this.platformId);
      }
    }
    ```

    在模板中：

    ```js
    @if (isBrowser) {
    
    }

    @if (isServer) {
    
    }
    ```
