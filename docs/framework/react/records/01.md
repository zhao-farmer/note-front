# 错误记录

## 1. react19 操作后执行两次 


### 1. 开发模式的严格模式（Strict Mode）【最常见】

这是最可能的原因。React 19 默认在 `create-react-app`或 `Vite`新项目中启用了严格模式（`<React.StrictMode>`）。

​**​原因​**​：严格模式会​**​故意双重调用​**​以下函数，以帮助发现不纯的渲染逻辑：

*    组件函数体（包括 `useState`初始化器、`useReducer`初始化器）
    
*    `useEffect`, `useLayoutEffect`的清理和设置函数
    
*   其他 Hooks
    

​**​目的​**​：确保你的组件是“纯”的，即多次调用渲染不会产生不同的结果或副作用。

​**​解决方案​**​：

1.  ​**​不要立即禁用严格模式！​**​ 首先检查你的代码是否有副作用。
    
2.  ​**​检查 `src/index.js`或 `src/main.jsx`​**​：
    
    ```jsx
    // 查找这段代码
    const root = ReactDOM.createRoot(document.getElementById('root'));
    root.render(
        <React.StrictMode> // <- 就是这个家伙
            <App />
        </React.StrictMode>
    );
    ```

3.  ​**​临时注释掉以确认问题​**​：

    ```jsx
    root.render(
    // <React.StrictMode> 
        <App />
    // </React.StrictMode>
    );
    ```

4. ​**​如果重复执行消失​**​：说明你的代码在渲染过程中有副作用。你应该修复它，而不是永久移除严格模式。

### 2. 错误的 `useEffect`依赖项

不正确的依赖项数组会导致 `useEffect`在不应执行时执行，甚至陷入循环。

​**​问题代码示例​**​：

```jsx
function MyComponent() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    // 一些操作，比如 API 调用
    console.log('Effect ran', count);
    // 错误：在 effect 内部更新依赖项 state，且没有正确设置依赖
    // setCount(count + 1); // 这会导致无限循环或多次执行
  }, [count]); // 依赖项包含 count，count 一变 effect 就再次运行

  return <div>Count: {count}</div>;
}
```

​**​解决方案​**​：

*   ​**​仔细检查依赖项​**​：确保 `useEffect`的依赖项数组只包含真正需要监听变化的变量。
    
*   ​**​使用 `useCallback`和 `useMemo`​**​：如果依赖项是函数或对象，使用它们来保持引用稳定。

```jsx
// 正确的做法：如果只想执行一次，使用空依赖数组
useEffect(() => {
  console.log('This will run only once on mount');
}, []); // <- 空依赖数组

// 或者，使用 setter 的函数形式来避免将 state 作为依赖
const [data, setData] = useState(null);
useEffect(() => {
  fetchData().then(newData => {
    setData(prevData => ({ ...prevData, ...newData })); // 使用函数更新
  });
}, []); // 无需依赖 data 或 setData
```

### 3. 事件处理函数被错误绑定

如果在渲染过程中直接创建并绑定函数，每次渲染都会创建一个新的函数实例，可能导致重复绑定。

​**​问题代码示例​**​：

```jsx
function MyComponent() {
  return (
    <button onClick={() => { // 箭头函数在每次渲染时都是新的
      console.log('Clicked');
      // 某些操作执行了两次
    }}>
      Click Me
    </button>
  );
}
```

虽然这本身不会直接导致执行两次，但如果与其他问题结合，可能会加剧情况。

​**​解决方案​**​：

*    ​**​使用 `useCallback`​**​ 包装事件处理程序以确保其稳定性。

```jsx
function MyComponent() {
  const handleClick = useCallback(() => {
    console.log('Clicked');
    // 你的操作
  }, []); // 依赖项为空，函数只创建一次

  return (
    <button onClick={handleClick}>
      Click Me
    </button>
  );
}
```
