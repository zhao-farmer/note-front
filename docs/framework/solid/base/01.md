# 一、认识solid

SolidJS 是一个**高性能、细粒度响应式的前端 UI 库**，其核心理念是 **“像写原生 JavaScript 一样构建 UI”**。它不使用 Virtual DOM，而是通过**编译时优化 + 响应式系统（Signals）** 实现极致性能，语法上类似 React（JSX），但运行时更轻量、更新更精准。

## 1.1 SolidJS 核心特点

| 特性 | 说明 |
|------|------|
| **无 Virtual DOM** | 直接操作真实 DOM，更新精准到单个绑定 |
| **响应式基于 Signals** | 使用 `createSignal` 管理状态，自动追踪依赖 |
| **编译时优化** | JSX 在编译时转为高效 DOM 操作指令 |
| **类 React 语法** | 使用 JSX、Hooks 风格 API（但机制完全不同） |
| **极小体积** | 运行时仅 ~7KB（gzip） |
| **支持 SSR / Streaming** | 官方提供 Solid Start（全栈框架） |

> **与 React 的关键区别**：  
> - React：状态变化 → 重新渲染整个组件 → reconciler diff → 更新 DOM  
> - Solid：状态变化 → **直接更新绑定的 DOM 节点**（无 diff）

## 1.4 使用JSX或TSX

.tsx 和 .jsx 是现代前端开发中常见的两种文件扩展名，它们的核心作用是：让开发者可以在 JavaScript/TypeScript 代码中直接编写类似 HTML 的结构（即 JSX）来描述 UI 界面。

1. React JSX → React.createElement() 调用

    ```jsx
    // 你写的代码
    <div>Hello {name}</div>

    // 编译后（React 17+）
    import { jsx as _jsx } from 'react/jsx-runtime';
    _jsx("div", { children: ["Hello ", name] });
    ```

    - 每次组件渲染都会重新创建整个 VNode 树
    - 后续由 Reconciler（协调器） 对比新旧 VNode，计算出最小 DOM 更新（diff 算法）

2. Solid JSX → 直接 DOM 操作 + 细粒度绑定

    ```jsx
    // 你写的代码
    <div>Hello {name()}</div>

    // 编译后（简化示意）
    const el = document.createElement("div");
    el.textContent = "Hello ";
    const textNode = document.createTextNode("");
    el.appendChild(textNode);
    createEffect(() => (textNode.nodeValue = name())); // 响应式更新
    ```

    - 编译时就确定哪些是静态节点、哪些是动态绑定
    - 运行时只更新变化的部分（如 name() 变化 → 仅更新那个文本节点）
    - 无 Virtual DOM，无 diff 过程
    >性能优势：Solid 更新速度 ≈ 手写原生 DOM 操作
