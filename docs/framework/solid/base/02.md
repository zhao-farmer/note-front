# 二、核心语法

## 2.1 **信号（Signals）**

在 SolidJS 中，Signals 是响应式的状态单元，它们允许你创建可观察的状态，当这些状态发生变化时，依赖于它们的UI部分会自动更新。

`createSignal` 创建一对 **读取器和设置器**。

```tsx
import { createSignal } from "solid-js";

const [count, setCount] = createSignal(0);

// 读取：必须加 () → count()
// 更新：setCount(newValue) 或 setCount(prev => newValue)
```

**关键规则**：

-   **Signal 是函数**：读取推荐使用写 `count()`， `count` 也能正常读取
-   **自动追踪依赖**：在 JSX 或 `createEffect` 中访问 `count()`，会自动注册依赖
-   **批量更新**：Solid 自动批处理多次 `setCount`，避免重复渲染

```tsx
import { createSignal } from "solid-js";

export default function Counter() {
    const [count, setCount] = createSignal(0);

    return (
        <div>
            <p>count值: {count()}</p>
            <button onClick={() => setCount(c => c + 1)}>自增</button>
        </div>
    );
}
```

## 2.2 **响应式表达式(createMemo)**

- 创建响应式表达式：使用 createMemo 函数。
- 响应式表达式将自动跟踪其内部使用的任何信号，并在相关信号更新时重新计算。
- 相当于vue中的计算属性 computed

```tsx{5,9}
import { createSignal,createMemo } from "solid-js";

export default function Counter() {
  const [count, setCount] = createSignal(0);
  const double = createMemo(() => count() * 2);

  return (
    <div>
      <p>count值: {count()}</p>
      <p>double值: {double}</p>
      <button onClick={() => setCount(c => c + 1)}>
        自增
      </button>
    </div>
  );
}
```

## 2.3 **副作用(`createEffect`)**

Effects（副作用） 是响应式系统的核心机制之一，用于在状态变化时执行同步的副作用操作（如日志、DOM 操作、订阅、发送分析数据等）。Solid 的 Effects 与 React 的 useEffect 有相似目的，但实现方式和行为有本质区别。

1. 基础使用

	> Effect = 响应式依赖追踪 + 自动执行的副作用函数
	- Effect 自动追踪其内部访问的所有 Signals（信号）
	- 当任一依赖的 Signal 更新时，Effect 自动重新运行
	- 无需手动声明依赖数组（如 React 的 useEffect(..., [deps])）

	```jsx{6-9}
	import { createSignal,createMemo,createEffect } from "solid-js";

	export default function Counter() {
	  const [count, setCount] = createSignal(0);
	  const double = createMemo(() => count() * 2);
	  createEffect(() => {
	    console.log("Count changed to:", count());
	    // 自动追踪 count()，仅当 count 变化时执行
	  });
	  return (
	    <div>
	      <p>count值: {count()}</p>
	      <p>double值: {double}</p>
	      <button onClick={() => setCount(c => c + 1)}>
	        自增
	      </button>
	    </div>
	  );
	}
	```

2. 返回清理函数

	Effect 可返回一个函数，在下一次运行前或组件销毁时执行：

	```tsx
	createEffect(() => {
	  const timer = setInterval(() => tick(), 1000);
	
	  // 清理上一次的定时器
	  return () => clearInterval(timer);
	});
	```

	> 注意：
	> 
	> - 清理函数在 Effect 重新运行前 调用（不是之后！）
	> - 组件卸载时也会调用最后一次清理函数

## 2.4 **条件渲染**

### 2.4.1 函数包裹

- 错误：`{condition && <El />}`
- 正确：`{() => condition && <El />}` 或使用内置 `<Show>` 组件
- 直接写 `{condition && <El />}` 会被视为静态表达式，`condition` 变化时不会触发更新
- 函数提供了一个“响应式边界”，Solid 能在运行时追踪 `condition` 的变化

```jsx
import { createSignal } from 'solid-js';

export default function Test() {
    
    const [show, setShow] = createSignal(true);
    return (
        <div>
            {/* 正确：函数确保响应式更新 */}
            {() => show() && <p>当show为真时显示</p>}
            
            {/* 切换按钮 */}
            <button onClick={() => setShow(s => !s)}>
                切换
            </button>
        </div>
    );
}
```

### 2.4.2 使用 `<Show>` 组件

Solid 提供内置 `<Show>` 组件，更高效、更语义化

- when：条件判断
	- 接收任意值，遵循 JavaScript 真值规则
	- 如果是 Signal，Solid 会自动追踪其变化
	- 如果是 对象/数组，即使内容变化但引用不变，可能不会触发更新（需配合 keyed）
- fallback：else 分支
	- 当 when 为假值时，渲染 fallback
	- 类似于三元运算符中的 : elsePart
- keyed： 对象、数组或其他引用类型的更新
	- 将 when 的值作为 key
	- 当 when 的引用变化（或首次渲染），创建新内容
	- 通过函数参数 u 访问当前值（u 是一个 Signal）
- children：参数内容
	- 必须配合 keyed 使用，否则 u 没有意义

```jsx
import { createSignal, Show } from 'solid-js';

export default function Test() {

    const [currentUser, setCurrentUser] = createSignal({
        name: '张三',
        age: 18
    });

    return (
        <Show
            when={currentUser()}
            fallback={<p>数据不存在</p>}
            keyed
        >
            {/* 注意：这里 user 是值，不是函数 */}
            {(user) => (
                <>
                    <p>用户名：{user.name}</p>  {/* 直接访问属性 */}
                    <p>年龄：{user.age}</p>
                </>
            )}
        </Show>
    )
}
```

## 2.5 **列表渲染**

Solid 提供内置 `<For>` 组件高效处理列表，**自动处理 key 和更新**。

```tsx
import { createSignal,For } from 'solid-js';

export default function Test() {

    const [items, setItems] = createSignal([
        { id: 1, name: 'Apple' },
        { id: 2, name: 'Banana' }
    ]);

    return (
        <For each={items()}>
            {(item, index) => (
                <div>
                    {index() + 1}. {item.name}
                </div>
            )}
        </For>
    )
}
```

**关键点：**

- each 必须是数组（或类数组）
- 子组件必须是函数：(item, index) => JSX
- index 是一个 Signal（所以要写 index()）

**索引值**

- Solid 会自动提取 item.id 作为 key（无需额外配置）通过 item => item.id
- 如果没有唯一 ID，Solid 会回退到索引作为 key，但会导致性能下降（插入/删除时 DOM 重建）

## 2.6 **事件绑定**

在 Solid.js 中，**事件绑定**（Event Binding）是连接用户交互与响应式状态的核心机制。Solid 的事件系统结合了**原生 DOM 事件**的灵活性与**响应式上下文**的自动追踪能力，同时通过**智能事件委托**实现高性能。

### 2.6.1 基础事件绑定

**基本语法**

```tsx
<button onClick={(e) => console.log('Clicked!', e)}>
  Click me
</button>
```

**关键特性**

- **`e` 是原生 `MouseEvent`**（不是 React 的 SyntheticEvent）
- **直接访问 Signal 获取最新值**：

> **无闭包陷阱**：不像 React 需要 `useCallback` 或依赖数组，Solid 的事件处理器总能读取最新状态。


### 2.6.2 事件委托 vs 本地绑定

1. **委托事件默认**

	- **自动用于标准 DOM 事件**（如 `click`, `input`, `keydown` 等）
	- 事件监听器注册在 `document` 上（内存高效）
	- 通过编译时标记匹配目标元素

	```tsx
	// ✅ 高效：即使 1000 个按钮，document 只有一个 click 监听器
	<For each={items()}>
	  {(item) => (
	    <button onClick={() => handleEdit(item.id)}>
	      Edit {item.name}
	    </button>
	  )}
	</For>
	```

2. **本地事件**

	- **触发条件**：
		- 自定义事件（如 `onMyEvent`）
		- 事件名含大写字母
		- 动态处理器（如 `onClick={props.handler}`）
	- **或显式禁用委托**：使用 `$` 后缀

	```tsx
	// 强制本地绑定（阻止冒泡等场景）
	<button onClick$={(e) => {
	  e.stopPropagation(); // 阻止事件冒泡到 document
	  doSpecialAction();
	}}>
	  Special Button
	</button>
	```

	> **规则**：  
	> - **小写标准事件名** → 自动委托（如 `onClick`）  
	> - **带 `$` 的事件名** → 强制本地绑定（如 `onClick$`）

### 2.6.3 传递参数

- 推荐：箭头函数（清晰安全）

	```tsx
	<button onClick={() => deleteItem(itemId)}>
	  Delete
	</button>
	```

- 避免：`.bind()`（不必要）

	```tsx
	{/* 不推荐：每次渲染创建新函数（虽无性能问题但冗余） */}
	<button onClick={deleteItem.bind(null, itemId)}>
	  Delete
	</button>
	```

- 错误：立即调用

	```tsx
	{/* ❌ 会在渲染时立即执行！ */}
	<button onClick={deleteItem(itemId)}>
	  Delete
	</button>
	```

- 获取表单值

	```tsx
	const [name, setName] = createSignal('');

	<input 
	  value={name()} 
	  onInput={(e) => setName(e.currentTarget.value)}
	  placeholder="Enter name"
	/>
	```
	注意：使用 `e.currentTarget`（而非 `e.target`）确保类型安全

### 2.6.4 测试案例

```jsx
import { createSignal} from 'solid-js';

export default function Test() {

    const [count, setCount] = createSignal(0);
    const [text, setText] = createSignal('');

    const handleClick = () => {
        setCount(count() + 1);
    };

    const handleInput = (e) => {
        setText(e.currentTarget.value);
    };

    return (
        <div>
            <button onClick={handleClick}>
                点击次数: {count()}
            </button>
            <br />
            <p>你输入了: {text()}</p>
            <input
                type="text"
                value={text()}
                onInput={handleInput}
                placeholder="输入内容"
            />
         
        </div>
    );
}
```


## 2.7 案例 todoList

```jsx
// src/TodoApp.jsx
import {
  createSignal,
  createEffect,
  For,
  Show,
} from 'solid-js';
import "./test.css"

export default function TodoApp() {
  // 1. 响应式状态
  const [newTodo, setNewTodo] = createSignal('');
  const [todos, setTodos] = createSignal([
    { id: 1, text: '学习 Solid 基础', completed: true },
    { id: 2, text: '练习响应式编程', completed: false },
    { id: 3, text: '掌握组件通信', completed: false }
  ]);
  const [filter, setFilter] = createSignal('all'); // 'all', 'active', 'completed'
  const [editId, setEditId] = createSignal(null);
  const [editText, setEditText] = createSignal('');

  // 2. 派生状态（用 createMemo 更优，但这里用函数也高效）
  console.log(todos());
  
  const remaining = () => todos().filter(todo => !todo.completed).length;
  const completedCount = () => todos().filter(todo => todo.completed).length;
  const totalCount = () => todos().length;

  // 3. 自动聚焦编辑框
  createEffect(() => {
    if (editId()) {
      // 使用 requestAnimationFrame 确保 DOM 已更新
      requestAnimationFrame(() => {
        const input = document.querySelector('.edit-input') ;
        if (input) input.focus();
      });
    }
  });

  // 4. 事件处理函数
  const addTodo = () => {
    const text = newTodo().trim();
    if (!text) return;
    setTodos([...todos(), { id: Date.now(), text, completed: false }]);
    setNewTodo('');
  };

  const removeTodo = (id) => {
    setTodos(todos().filter(todo => todo.id !== id));
  };

  const toggleTodo = (id) => {
    setTodos(todos().map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ));
  };

  const startEdit = (todo) => {
    setEditId(todo.id);
    setEditText(todo.text);
  };

  const saveEdit = () => {
    const text = editText().trim();
    if (!text) {
      cancelEdit();
      return;
    }
    setTodos(todos().map(todo =>
      todo.id === editId() ? { ...todo, text } : todo
    ));
    cancelEdit();
  };

  const cancelEdit = () => {
    setEditId(null);
    setEditText('');
  };

  const clearCompleted = () => {
    setTodos(todos().filter(todo => !todo.completed));
  };

  const toggleAll = () => {
    const allCompleted = todos().every(todo => todo.completed);
    setTodos(todos.map(todo => ({ ...todo, completed: !allCompleted })));
  };

  // 5. 键盘事件
  const handleKeydown = (e) => {
    if (e.key === 'Enter') {
      addTodo();
    } else if (e.key === 'Escape') {
      setNewTodo('');
    }
  };

  // 6. 过滤后的列表
  const filteredTodos = () => {
    const f = filter();
    return todos().filter(todo => {
      if (f === 'all') return true;
      if (f === 'active') return !todo.completed;
      if (f === 'completed') return todo.completed;
      return true;
    });
  };

  return (
    <div class="todo-app">
      {/* 标题 */}
      <h1>Solid TodoList</h1>

      {/* 统计信息 */}
      <div class="stats">
        <span>总计: {totalCount()}</span>
        <span>待完成: {remaining()}</span>
        <span>已完成: {completedCount()}</span>
      </div>

      {/* 添加新任务 */}
      <div class="add-todo">
        <input
          type="text"
          placeholder="输入新任务，按回车添加"
          value={newTodo()}
          onInput={(e) => setNewTodo(e.currentTarget.value)}
          onKeyDown={handleKeydown}
          class="new-input"
        />
        <button onClick={addTodo} disabled={!newTodo().trim()}>
          添加
        </button>
      </div>

      {/* 过滤选项 */}
      <div class="filters">
        <label>
          <input
            type="radio"
            value="all"
            checked={filter() === 'all'}
            onChange={() => setFilter('all')}
          />
          全部 ({totalCount()})
        </label>
        <label>
          <input
            type="radio"
            value="active"
            checked={filter() === 'active'}
            onChange={() => setFilter('active')}
          />
          进行中 ({remaining()})
        </label>
        <label>
          <input
            type="radio"
            value="completed"
            checked={filter() === 'completed'}
            onChange={() => setFilter('completed')}
          />
          已完成 ({completedCount()})
        </label>
      </div>

      {/* 控制按钮 */}
      <div class="controls">
        <button onClick={toggleAll}>
          {todos().length > 0 && todos().every(t => t.completed)
            ? '全部取消'
            : '全部完成'}
        </button>
        <button onClick={clearCompleted} disabled={completedCount() === 0}>
          清除已完成 ({completedCount()})
        </button>
      </div>

      {/* 条件渲染：空状态 vs 列表 */}
      <Show when={todos().length === 0}>
        <div class="empty-state">
          <p>没有待办事项！</p>
          <p>添加你的第一个任务吧！</p>
        </div>
      </Show>

      <Show when={todos().length > 0 && filteredTodos().length === 0}>
        <div class="empty-state">
          <p>
            {filter() === 'active'
              ? '没有进行中的任务！'
              : '还没有完成的任务！'}
          </p>
        </div>
      </Show>

      <Show when={filteredTodos().length > 0}>
        <ul class="todo-list">
          <For each={filteredTodos()}>{(todo) => (
            <li
              classList={{
                completed: todo.completed,
                editing: editId() === todo.id
              }}
            >
              <Show when={editId() === todo.id}>
                <div class="edit-mode">
                  <input
                    type="text"
                    value={editText()}
                    onInput={(e) => setEditText(e.currentTarget.value)}
                    onKeyDown={(e) => e.key === 'Enter' && saveEdit()}
                    onBlur={saveEdit}
                    class="edit-input"
                  />
                  <div class="edit-actions">
                    <button onClick={saveEdit}>保存</button>
                    <button onClick={cancelEdit}>取消</button>
                  </div>
                </div>
              </Show>

              <Show when={editId() !== todo.id}>
                <div class="view-mode">
                  <input
                    type="checkbox"
                    checked={todo.completed}
                    onChange={() => toggleTodo(todo.id)}
                    class="todo-checkbox"
                  />
                  <span
                    role="button"
                    tabIndex="0"
                    onDblClick={() => startEdit(todo)}
                    classList={{
                      'todo-text': true,
                      completed: todo.completed
                    }}
                  >
                    {todo.text}
                  </span>
                  <div class="actions">
                    <button onClick={() => startEdit(todo)} title="编辑">
                      编辑
                    </button>
                    <button onClick={() => removeTodo(todo.id)} title="删除">
                      删除
                    </button>
                  </div>
                </div>
              </Show>
            </li>
          )}</For>
        </ul>
      </Show>
    </div>
  );
}
```
