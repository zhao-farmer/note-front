# 三、数据通信

| 场景 | 推荐方案 |
|------|----------|
| 父 → 子 | **Props**（直接传递 Signal/值） |
| 子 → 父 | **回调函数**（Callback Props） |
| 兄弟组件 | **共享状态**（提升到公共父级 或 使用 Context） |
| 跨层级（深层嵌套） | **Context API** |
| 全局状态 | **Context + createStore** 或 **独立状态模块** |


## 3.1 父 → 子：Props 传递

1. 基础用法

    - 父组件

        ```jsx 
        import { createSignal } from 'solid-js';
        import Child from './Child';

        export default function Parent(){
          const [count, setCount] = createSignal(0);
          return (
            <div>
              <Child count={count()} />
              <button onClick={() => setCount(c => c + 1)}>+</button>
            </div>
          );
        };
        ```
    - 子组件

        ```jsx
        export default function Child(props) {    
            // props.count 是普通值（非响应式）
            return (
                <div>
                    Count值: {props.count}
                </div>
            );
        };
        ```

    >  **注意**：`props.count` 是**快照值**，并非响应式，不能再利用这个值进行计算！

2. 传递响应式能力（传递 Signal 本身）

    - 父组件

        ```jsx
        import { createSignal } from 'solid-js';
        import Child from './Child';

        export default function Parent(){
          const [count, setCount] = createSignal(0);
          return (
            <div>
              <Child count={count} />
              <button onClick={() => setCount(c => c + 1)}>+</button>
            </div>
          );
        };
        ```

    - 子组件

        ```jsx
        import { createMemo } from "solid-js";

        export default function Child(props) {    
            // 响应式值 计算属性
            const double = createMemo(() => props.count() * 2);
            return (
                <div>
                    Count值: {props.count}
                    <br />
                    double值: {double()}
                </div>
            );
        };
        ```

    > **优势**：子组件始终读取最新状态，无需额外订阅。

## 3.2 子 → 父：回调函数

- 父组件

    ```jsx
    import { createSignal } from 'solid-js';
    import Child from './Child';

    export default function Parent() {
      const [todos, setTodos] = createSignal([
        {id:1,text:"zhangsan"},
        {id:2,text:"lisi"}
      ]);

      const addTodo = (text) => {
        setTodos([...todos(), { id: Date.now(), text }]);
      };

      return (
        <>
          <Child onAdd={addTodo} />
          <For each={todos()}>
            {(item, index) => (
              <div>
                {index() + 1}. {item.text}
              </div>
            )}
          </For>
        </>
      );
    };
    ```

- 子组件

    ```jsx
    import { createSignal } from 'solid-js';
    export default function Child(props) {    
      const [input, setInput] = createSignal('');

      const handleSubmit = () => {
        if (input().trim()) {
          props.onAdd(input().trim()); // 调用父级回调
          setInput('');
        }
      };

      return (
        <input
          value={input()}
          onInput={(e) => setInput(e.currentTarget.value)}
          onKeyDown={(e) => e.key === 'Enter' && handleSubmit()}
        />
      );
    };
    ```

> **最佳实践**：回调函数命名以 `on` 开头（如 `onUpdate`, `onDelete`）

## 3.3 兄弟组件通信


- 父组件

    ```jsx
    import { createSignal } from 'solid-js';
    import Child1 from './Child1';
    import Child2 from './Child2';

    export default function Parent() {
      const [sharedValue, setSharedValue] = createSignal('');

      return (
        <>
          <Child1 value={sharedValue} onChange={setSharedValue} />
          <Child2 value={sharedValue} />
        </>
      );
    };
    ```
- 子组件1

    ```jsx
    const Child1 = (props) => (
      <input
        value={props.value()}
        onInput={(e) => props.onChange(e.currentTarget.value)}
      />
    );
    export default Child1
    ```

- 子组件2

    ```jsx
    const Child2 = (props) => <p>Value: {props.value()}</p>;

    export default Child2
    ```

> **适用场景**：兄弟组件较少、逻辑简单


## 3.4 跨层级通信：Context API

在 **SolidJS** 中，`createContext` 和 `useContext` 是用于跨组件树共享状态的机制，类似于 React 的 Context API。它能避免“prop drilling”（层层传递 props），特别适合主题、用户信息、语言等全局状态。


### 3.4.1 基本用法

1. 创建 Context

```js
import { createContext } from 'solid-js';

const MyContext = createContext(defaultValue?);
```
- `defaultValue` 是可选的，当组件树中没有 `Provider` 时使用。
- 如果不提供默认值且未包裹 `Provider`，`useContext` 将返回 `undefined`。

---

2. 提供 Context（Provider）

```jsx
<MyContext.Provider value={someValue}>
  <Child />
</MyContext.Provider>
```
- `value` 可以是任意值：对象、函数、信号（signal）、store 等。
- **注意**：SolidJS 的 `Provider` 不会自动响应式更新，除非你传入的是 **响应式数据源**（如 `createSignal` 的 getter 或 `createStore` 的 state）。

---

3. 消费 Context（useContext）

```js
import { useContext } from 'solid-js';

const value = useContext(MyContext);
```
- 在组件内部调用，获取最近的 `Provider` 提供的值。
- 如果嵌套多个同名 `Provider`，会取**最近的父级**。

### 3.4.2 代码示例

1. 创建Context对象 

    ```js
    // context/UserContext.js
    import { createContext } from 'solid-js';

    // 创建并导出 Context（只创建一次！）
    const UserContext = createContext();

    export default UserContext;
    ```
2. 祖先组件

    ```jsx
    import { createSignal } from 'solid-js';
    import Child1 from './Child1';
    import UserContext from '../context/UserContext'; 

    export default function Parent() {

      // 传递的用户
      const [user, setUser] = createSignal({
        name: "李四",
        role: "访客"
      });

      // 模拟登录（3秒后切换角色）
      setTimeout(() => {
        setUser({ name: "李四", role: "管理员" });
      }, 3000);

      return (
        // 提供消费 Provider
        <UserContext.Provider value={user}>
          <Child1/>
        </UserContext.Provider>
      );
    };
    ```
3. 中间组件

    ```jsx
    import Child2 from "./Child2";
    export default function Child1() {
      return <Child2/>
    }
    ```
4. 后代组件

    ```jsx
    import { useContext } from 'solid-js';
    import UserContext from '../context/UserContext'; 
    export default function Child2() {

        const userSignal = useContext(UserContext); // 获取的是信号函数 user

        return (
            <div>
                <p>姓名: {userSignal().name}</p>
                <p>角色: {userSignal().role}</p>
            </div>
        );
    }
    ```

## 3.5 全局状态管理

- 新建状态脚本

    ```tsx
    // store/CounterStore.js
    import { createStore } from 'solid-js/store';

    // 1. 创建 Store（返回 [state, setState]）
    const [countState, setCountState] = createStore({
      count: 0,
      history: []
    });

    // 2. 导出状态和更新方法
    export { countState };

    export const increment = () => {
      setCountState('count', c => c + 1);
      setCountState('history', h => [...h, countState.count + 1]);
    };

    export const decrement = () => {
      if (countState.count > 0) {
        setCountState('count', c => c - 1);
      }
    };

    export const reset = () => {
      setCountState({ count: 0, history: [] });
    };
    ```
- Counter.jsx

    ```jsx
    import { countState, increment, decrement, reset } from '../stores/CounterStore';

    function Counter() {
      return (
        <div>
          <h2>计数器: {countState.count}</h2>
          <button onClick={increment}>+1</button>
          <button onClick={decrement}>-1</button>
          <button onClick={reset}>重置</button>
    
          <div>
            <h3>历史记录:</h3>
            <ul>
              {countState.history.map((val, i) => (
                <li key={i}>第 {i + 1} 次: {val}</li>
              ))}
            </ul>
          </div>
        </div>
      );
    }
    
    export default Counter;
    ```
