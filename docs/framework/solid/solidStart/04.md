# 四、其他相关

## 4.1 渲染模式

1. `app.config.ts` 基础结构

    ```ts
    // app.config.ts
    import { defineConfig } from 'solid-start';

    export default defineConfig({
      // 1. 渲染模式配置
      ssr: true, // 默认 true，开启 SSR
      adapter: 'vercel', // 或 'static', 'cloudflare', 'node'

      // 2. 路由级配置（2026 新特性）
      routes: {
        // 按路径配置渲染模式
        'src/routes/(dashboard)': { ssr: false }, // CSR
        'src/routes/blog/[slug]': { ssg: true }, // SSG
      }
    });
    ```

2. 分类

    | 需求 | 配置方式 | 最佳实践 |
    |------|----------|--------------|
    | **默认 SSR** | 无需配置 | 无需任何设置 |
    | **静态博客** | `route.preload` + `adapter: solidStartStatic()` | 无需额外配置 |
    | **管理后台** | `(group)` 分组 |  **推荐** |
    | **混合渲染** | `routes` 配置 | 框架自动优化 |
    | **关闭全局 SSR** | 避免使用 | 用 `(group)` 或 `routes` |



3. 默认 SSR（服务端渲染）- **无需配置**

    ```ts
    // app.config.ts
    export default defineConfig({
      // ssr: true (默认值，可省略)
      adapter: 'vercel' // 或其他适配器
    });
    ```


4. 静态站点生成（SSG）

    ```ts
    // app.config.ts
    import { solidStartStatic } from 'solid-start/static';

    export default defineConfig({
      ssr: true,
      adapter: solidStartStatic() // 指定 SSG 适配器
      routes: {
        // 为博客文章启用 SSG
        'src/routes/blog/[slug]': { ssg: true },
      }
    });
    ```

5. 客户端渲染（CSR）

    ```ts
    // app.config.ts
    export default defineConfig({
      ssr: true,
      adapter: 'vercel',
      routes: {
        'src/routes/(dashboard)': { ssr: false } // 显式关闭 SSR
      }
    });
    ```
6. 目录结构

    ```bash
    src/
    ├── routes/
    │   ├── index.tsx             # 默认 SSR (SEO 优先)
    │   ├── blog/
    │   │   ├── [slug].tsx        # SSG (通过 route.preload)
    │   │   └── index.tsx         # SSR (动态内容)
    │   ├── (dashboard)/          # CSR (通过 (group) 分组)
    │   │   └── index.tsx
    │   └── api/
    │       └── posts.ts          # API 路由
    ├── components/
    ├── contexts/
    ├── lib/
    └── root.tsx
    ```

## 4.2 入口文件

1. entry-client.tsx

    - 初始化客户端应用：在浏览器中挂载 SolidJS 应用
    - 处理客户端交互：使应用在浏览器中可交互
    - 完成水合（Hydration）：将服务端生成的 HTML 转为可交互的 SPA


    ```txt
    浏览器 → 加载 index.html
       ↓
    执行 entry-client.tsx
           ↓
    挂载应用到 DOM（#app）
           ↓
    应用开始响应用户交互
    ```
2. entry-server.tsx

    - 生成初始 HTML：在服务端渲染整个应用
    - 支持 SSR：为爬虫和 SEO 提供完整 HTML
    - 数据预加载：与 createRouteData 配合，获取数据

    ```txt
    服务器收到请求 → 执行 entry-server.tsx
       ↓
    生成完整 HTML（包含数据）
           ↓
    返回 HTML 给浏览器
           ↓
    浏览器显示内容 → 执行 entry-client.tsx 水合
    ```
