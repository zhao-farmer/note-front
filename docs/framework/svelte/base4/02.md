# 二、核心语法

## 2.1 响应式变量

Svelte 的核心哲学：**赋值即更新**。  
无需 `useState`、`ref` 或 `$set` —— 直接修改变量，UI 自动同步。

```svelte
<script>
  let count = 0;

  function increment() {
    count += 1; //  自动触发 UI 更新！
  }
</script>

<button on:click={increment}>
  Count: {count}
</button>
```

> 注意：必须是 **顶层变量**（在 `<script>` 中声明），且通过 **赋值操作**（`=`、`+=` 等）修改。

## 2.2 响应式语句—— `$:`

当某个值依赖其他变量时，用 `$:` 声明自动重新计算。

1. 基础用法

    ```svelte
    <script>
      let firstName = '张';
      let lastName = '三';

      // 当 firstName 或 lastName 变化 → fullName 自动更新
      $: fullName = `${firstName} ${lastName}`;
    </script>

    <input bind:value={firstName} />
    <input bind:value={lastName} />
    <h1>Hello, {fullName}!</h1>
    ```

2. 多行逻辑 & 副作用

    ```js
    $: {
      if (fullName) {
        console.log('Name updated:', fullName);
        document.title = fullName; // 同步到页面标题
      }
    }
    ```

3. 依赖链（自动追踪）

    ```js
    let a = 1;
    $: b = a * 2;
    $: c = b + 10; // 当 a 变 → b 变 → c 变
    ```

    > 编译器在构建时静态分析依赖关系，运行时无性能开销。

## 2.3 双向绑定

使用 `bind:` 指令实现 **DOM ↔ 变量** 的自动同步。

1. 常见绑定类型


    | 元素  | 绑定语法 | 说明  |
    | --- | --- | --- |
    | `<input>` / `<textarea>` | `bind:value={var}` | 文本输入 |
    | `<input type="checkbox">` | `bind:checked={bool}` | 勾选状态 |
    | `<input type="radio">` | `bind:group={var}` | 单选组 |
    | `<select>` | `bind:value={var}` | 下拉选择 |
    | 任意元素 | `bind:this={domRef}` | 获取 DOM 引用 |

2. 示例

    ```svelte
    <script>
      let name = '';
      let agreed = false;
      let color = 'red';
      let inputEl;
    </script>

    <!-- 文本双向绑定 -->
    <input bind:value={name} placeholder="你的名字" />

    <!-- Checkbox -->
    <label>
      <input type="checkbox" bind:checked={agreed} />
      我同意
    </label>

    <!-- Radio Group -->
    <label><input type="radio" bind:group={color} value="red" /> 红</label>
    <label><input type="radio" bind:group={color} value="blue" /> 蓝</label>

    <!-- 获取 DOM 元素 -->
    <input bind:this={inputEl} />
    {#if inputEl}
      <p>表单宽度: {inputEl.offsetWidth}px</p>
    {/if}

    <p>名字: {name}, 是否同意: {agreed ? 'Yes' : 'No'}, 颜色: {color}</p>
    ```

>  `bind:this` 常用于集成第三方库（如地图、图表）。

## 2.4 条件渲染

使用 `{#if}`、`{:else if}`、`{:else}` 控制元素显示。

```svelte
<script>
  let user = null;
  let isLoading = true;
</script>

{#if isLoading}
  <p>Loading...</p>
{:else if user}
  <p>Welcome, {user.name}!</p>
  <button on:click={() => user = null}>Logout</button>
{:else}
  <button on:click={() => {
    user = { name: 'Guest' };
    isLoading = false;
  }}>Login</button>
{/if}
```

> 支持任意表达式：`{#if count > 0 && visible}`


## 2.5 列表渲染

使用 `{#each}` 遍历数组或类数组对象。

1. 基础语法

    ```svelte
    <script>
      let items = [
        { id: 1, name: 'Apple' },
        { id: 2, name: 'Banana' }
      ];
    </script>

    <ul>
      {#each items as item (item.id)}
        <li>{item.name}</li>
      {/each}
    </ul>
    ```

2. 关键点

    *   `(item.id)` 是 **key**（用于高效更新，类似 React 的 `key`）
    *   可解构：`{#each items as { id, name }}`
    *   可获取索引：`{#each list as item, index}`

3. 空状态处理

    ```svelte
    {#each posts as post}
      <article>{post.title}</article>
    {:else}
      <p>No posts available.</p>
    {/if}
    ```

> 修改列表时，**必须创建新数组**（不能直接 `push`）：

    ```js
    // 无效（引用未变）
    items.push({ id: 3, name: 'Cherry' });

    // 正确
    items = [...items, { id: 3, name: 'Cherry' }];
    ```


## 2.6 事件处理

1. 基础事件绑定

    ```svelte
    <button on:click={handleClick}>Click</button>
    <input on:input={handleInput} />
    <div on:mousemove={handleMove}></div>
    ```

2. 事件修饰符

    | 修饰符 | 描述  | 对应 DOM API |
    | --- | --- | --- |
    | **`preventDefault`**​ | 阻止默认行为 | `event.preventDefault()` |
    | **`stopPropagation`**​ | 阻止事件冒泡 | `event.stopPropagation()` |
    | **`stopImmediatePropagation`**​ | 阻止后续事件处理器 | `event.stopImmediatePropagation()` |
    | **`passive`**​ | 优化滚动性能 | 传递 `{ passive: true }`选项 |
    | **`nonpassive`**​ | 非被动模式 | 传递 `{ passive: false }`选项 |
    | **`capture`**​ | 使用捕获阶段 | 在捕获阶段处理事件 |
    | **`once`**​ | 只触发一次 | 自动移除监听器 |
    | **`self`**​ | 仅当 `event.target`是元素自身时触发 | 检查 `event.target === event.currentTarget` |
    | **`trusted`**​ | 仅用户触发的事件 | 检查 `event.isTrusted` |


    ```svelte
    <!-- 自动 preventDefault -->
    <form on:submit|preventDefault={handleSubmit}>
      <button type="submit">Submit</button>
    </form>

    <!-- 仅触发一次 -->
    <button on:click|once={showIntro}>Show Intro</button>
    ```

3. 组件事件（子 → 父通信）

    ```svelte
    <!-- Child.svelte -->
    <script>
      import { createEventDispatcher } from 'svelte';
      const dispatch = createEventDispatcher();

      function notify() {
        dispatch('customEvent', { message: 'Hello!' });
      }
    </script>
    <button on:click={notify}>Send</button>
    ```


    ```svelte
    <!-- Parent.svelte -->
    <script>
      function handleEvent(e) {
        console.log(e.detail.message); // 数据在 e.detail
      }
    </script>
    <Child on:customEvent={handleEvent} />
    ```

    > 子组件用 `dispatch('eventName', data)`  
    > 父组件用 `on:eventName={handler}` 监听



## 2.7 完整实战：Todo App 核心逻辑

```svelte
<script>
  // 1. 响应式变量
  let newTodo = '';
  let todos = [
    { id: 1, text: '学习 Svelte 基础', completed: true },
    { id: 2, text: '练习响应式编程', completed: false },
    { id: 3, text: '掌握组件通信', completed: false }
  ];
  let filter = 'all'; // 'all', 'active', 'completed'
  let editId = null;
  let editText = '';

  // 2. 响应式语句
  $: remaining = todos.filter(todo => !todo.completed).length;
  $: completedCount = todos.filter(todo => todo.completed).length;
  $: totalCount = todos.length;
  
  // 自动聚焦编辑输入框
  $: if (editId) {
    setTimeout(() => {
      const input = document.querySelector('.edit-input');
      if (input && input instanceof HTMLInputElement) input.focus();
    }, 0);
  }

  // 事件处理函数
  function addTodo() {
    if (!newTodo.trim()) return;
    
    todos = [
      ...todos,
      {
        id: Date.now(),
        text: newTodo.trim(),
        completed: false
      }
    ];
    newTodo = '';
  }

  function removeTodo(id) {
    todos = todos.filter(todo => todo.id !== id);
  }

  function toggleTodo(id) {
    todos = todos.map(todo => 
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    );
  }

  function startEdit(todo) {
    editId = todo.id;
    editText = todo.text;
  }

  function saveEdit() {
    if (!editText.trim()) {
      cancelEdit();
      return;
    }
    
    todos = todos.map(todo => 
      todo.id === editId ? { ...todo, text: editText.trim() } : todo
    );
    cancelEdit();
  }

  function cancelEdit() {
    editId = null;
    editText = '';
  }

  function clearCompleted() {
    todos = todos.filter(todo => !todo.completed);
  }

  function toggleAll() {
    const allCompleted = todos.every(todo => todo.completed);
    todos = todos.map(todo => ({ ...todo, completed: !allCompleted }));
  }

  // 键盘事件处理
  function handleKeydown(event) {
    if (event.key === 'Enter') {
      addTodo();
    } else if (event.key === 'Escape') {
      newTodo = '';
    }
  }
</script>

<div class="todo-app">
  <!-- 标题 -->
  <h1>Svelte TodoList</h1>
  
  <!-- 统计信息 -->
  <div class="stats">
    <span>总计: {totalCount}</span>
    <span>待完成: {remaining}</span>
    <span>已完成: {completedCount}</span>
  </div>

  <!-- 添加新任务 -->
  <div class="add-todo">
    <!-- 双向绑定 -->
    <input
      type="text"
      placeholder="输入新任务，按回车添加"
      bind:value={newTodo}  
      on:keydown={handleKeydown}
      class="new-input"
    />
    <button on:click={addTodo} disabled={!newTodo.trim()}>
      添加
    </button>
  </div>

  <!-- 过滤选项 -->
  <div class="filters">
    <label>
      <input type="radio" value="all" bind:group={filter} />
      全部 ({totalCount})
    </label>
    <label>
      <input type="radio" value="active" bind:group={filter} />
      进行中 ({remaining})
    </label>
    <label>
      <input type="radio" value="completed" bind:group={filter} />
      已完成 ({completedCount})
    </label>
  </div>

  <!-- 控制按钮 -->
  <div class="controls">
    <button on:click={toggleAll}>
      {todos.length > 0 && todos.every(t => t.completed) ? '全部取消' : '全部完成'}
    </button>
    <button on:click={clearCompleted} disabled={completedCount === 0}>
      清除已完成 ({completedCount})
    </button>
  </div>

  <!-- 3. 条件渲染：空状态 -->
  {#if todos.length === 0}
    <div class="empty-state">
      <p>没有待办事项！</p>
      <p>添加你的第一个任务吧！</p>
    </div>
  {:else if todos.filter(t => filter === 'all' || (filter === 'active' && !t.completed) || (filter === 'completed' && t.completed)).length === 0}
    <div class="empty-state">
      <p>
        {#if filter === 'active'}
          没有进行中的任务！
        {:else if filter === 'completed'}
          还没有完成的任务！
        {/if}
      </p>
    </div>
  {:else}
    <!-- 4. 列表渲染 -->
    <ul class="todo-list">
      {#each todos.filter(todo => 
        filter === 'all' || 
        (filter === 'active' && !todo.completed) || 
        (filter === 'completed' && todo.completed)
      ) as todo (todo.id)}
        <li class:completed={todo.completed} class:editing={editId === todo.id}>
          {#if editId === todo.id}
            <!-- 编辑模式 -->
            <div class="edit-mode">
               <!-- 双向绑定 -->
              <input
                type="text"
                bind:value={editText} 
                on:keydown={(e) => e.key === 'Enter' && saveEdit()}
                on:blur={saveEdit}
                class="edit-input"
              />
              <div class="edit-actions">
                <button on:click={saveEdit}>保存</button>
                <button on:click={cancelEdit}>取消</button>
              </div>
            </div>
          {:else}
            <!-- 查看模式 -->
            <div class="view-mode">
               <!-- 双向绑定 -->
              <input
                type="checkbox"
                checked={todo.completed} 
                on:change={() => toggleTodo(todo.id)}
                class="todo-checkbox"
              />
              
              <span
                role="button"
                tabindex="0"
                on:dblclick={() => startEdit(todo)}
                class="todo-text {todo.completed ? 'completed' : ''}"
              >
                {todo.text}
              </span>
              
              <div class="actions">
                <button on:click={() => startEdit(todo)} title="编辑">
                  编辑
                </button>
                <button on:click={() => removeTodo(todo.id)} title="删除">
                  删除
                </button>
              </div>
            </div>
          {/if}
        </li>
      {/each}
    </ul>
  {/if}
</div>
```
