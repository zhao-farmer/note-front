# 三、数据传递

## 3.1 父子通信

### 3.1.1 父 → 子：属性传递

子组件通过 `export let` 声明接收的 props。

- 子组件：`Child.svelte`

    ```svelte
    <script>
      // 声明可接收的 props（带默认值）
      export let name = 'Guest';
      export let age;
    </script>

    <p>你好, {name}! 您的年龄是： {age} </p>
    ```

-  父组件：`Parent.svelte`

    ```svelte
    <script>
      import Child from './Child.svelte';
      let user = { name: '张三', age: 30 };
    </script>

    <!-- 传递 props -->
    <Child name={user.name} age={user.age} />

    <!-- 或简写（当 prop 名 == 变量名） -->
    <Child {...user} />
    ```
- 根组件 `App.svelte`

    ```svelte
    <script>
      import Parent from './lib/Parent.svelte'
    </script>

    <main>
        <Parent />
    </main>
    ```

- 运行结果

    ![](/framework/svelte/base4/006.png)

> `export let` 是 Svelte 特有语法，表示“这是一个 prop”。



### 3.1.2 子 → 父：事件

子组件使用 `createEventDispatcher` 发送事件，父组件监听。

1. 子组件：`Child.svelte`

    ```svelte
    <script>
      import { createEventDispatcher } from 'svelte';
      const dispatch = createEventDispatcher();

      let count = 0;

      function increment() {
        count += 1;
        // 向上传递事件和数据
        dispatch('update', { count });
      }
    </script>

    <button on:click={increment}>Count: {count}</button>
    ```

2. 父组件：`Parent.svelte`


    ```svelte
    <script>
      import Child from './Child.svelte';

      function handleUpdate(event) {
        console.log('New count:', event.detail.count); // 注意：数据在 event.detail
      }
    </script>

    <Child on:update={handleUpdate} />
    ```
- 运行结果

    ![](/framework/svelte/base4/007.gif)

>  关键点：
> 
> *   事件名自定义（如 `'update'`）
> *   数据通过 `event.detail` 访问
> *   支持多个事件：`dispatch('save')`, `dispatch('cancel')`


### 3.1.3 父直接调用子方法：`bind:this`

父组件获取子组件实例，直接调用其方法（慎用）。

- 子组件：`Child.svelte`

    ```svelte
    <script>
      export function focusInput() {
        inputEl.focus(); // 假设有一个 input
      }

      let inputEl;
    </script>

    <input bind:this={inputEl} />
    ```

- 父组件

    ```svelte
    <script>
      import Child from './Child.svelte';
      let childRef;
    </script>

    <Child bind:this={childRef} />

    <button on:click={() => childRef.focusInput()}>
      聚焦到子组件
    </button>
    ```

- 运行结果

    ![](/framework/svelte/base4/009.gif)

>  仅用于必要场景（如聚焦、播放视频），**避免破坏组件封装性**。



## 3.2 插槽

插槽允许父组件向子组件“注入”自定义内容。

### 3.2.1 默认插槽

最简单的插槽形式：子组件预留一个 `<slot>`，父组件的内容会插入其中。

如果父组件不传内容，则显示`<slot>` 内的默认内容。

-  子组件：`Child.svelte`

    ```svelte
   <div class="card">
        <slot>
            <!-- 默认插槽 -->
            <p>默认内容</p>
        </slot>
    </div>
    ```
-  父组件：`Parent.svelte`

    ```svelte
    <script>
        import Child from "./Child.svelte";
    </script>

    <Child>
        <h2>我的标题</h2>
        <p>这是自定义内容！</p>
    </Child>
    ```
- 运行结果

    ![](/framework/svelte/base4/010.png)

>  渲染结果：`<div class="card"><h2>...</h2><p>...</p></div>`



### 3.2.2 具名插槽

当需要多个插入点时，使用 name 属性区分。

- 子组件：`Child.svelte`

    ```svelte
    <div class="modal">
        <header>
            <slot name="title">默认标题</slot>
        </header>
        <main>
            <slot />
            <!-- 默认插槽 -->
        </main>
        <footer>
            <slot name="actions">
                <button>OK</button>
            </slot>
        </footer>
    </div>
    ```

-  父组件：`Parent.svelte`

    ```svelte
    <script>
        import Child from "./Child.svelte";
    </script>

    <Child>
        <!-- 默认插槽 -->
        <p>这是模态框主体内容。</p>

        <!-- 具名插槽 -->
        <span slot="title">重要提示</span>
        <div slot="actions">
            <button>取消</button>
            <button>确认</button>
        </div>
    </Child>
    ```

- 运行结果

    ![](/framework/svelte/base4/011.png)

> 子组件：`<slot name="xxx">`
> 父组件：`<元素 slot="xxx">内容</元素>`
> 注意：具名插槽必须显式指定 slot="name"，否则会被视为默认插槽内容

### 3.2.3 作用域插槽——插槽传值给父

子组件可向插槽内容**传递数据**（类似 Vue 的 scoped slot）。

- 子组件：`UserList.svelte`

    ```svelte
    <script>
        export let users = [];
        console.log(users);
    </script>

    {#each users as user, index}
        <div class="user-item">
            <!-- 向插槽暴露 user 和 index -->
            <slot {user} {index} />
        </div>
    {/each}
    ```

- 父组件：

    ```svelte
    <script>
        import Child from "./Child.svelte";
        let people = [
            { id: 1, name: "Alice" },
            { id: 2, name: "Bob" },
        ];
    </script>
    <!-- 直接在子组件标签上使用 let:user let:index -->
    <Child users={people} let:user let:index>
        <div>
            <strong>{index + 1}. {user.name}</strong>
            <button on:click={() => alert(`编辑 ${user.name}`)}> 编辑 </button>
        </div>
    </Child>
    ```

- 运行结果

    ![](/framework/svelte/base4/012.png)

> 关键语法：
> 
> *   子：`<slot prop={value} />`
> *   父：`<div let:prop>... {prop} ...</div>`


## 3.3 状态管理

Svelte 的 **Stores** 是其内置的、轻量级但功能强大的**全局状态管理机制**，用于在组件之间共享和同步状态。它不依赖虚拟 DOM，而是基于 **响应式订阅模型**，由 Svelte 编译器在构建时自动处理订阅与取消订阅，开发者只需关注状态逻辑本身。

### 3.3.1 核心理念

> **Store = 一个带有 `subscribe` 方法的对象**

只要一个对象实现了 **Store Contract（存储契约）**：

```js
{
  subscribe: (run: (value) => void) => () => void
}
```

subscribe是浏览器自带的数据状态管理

它就是一个合法的 Store，可被 Svelte 自动订阅（通过 `$store` 语法）。

Svelte 在 `svelte/store` 模块中提供了三种标准实现：


| 类型  | 用途  | 是否可写 |
| --- | --- | --- |
| `writable` | 可读写状态（如计数器、表单数据） | 是   |
| `readable` | 只读状态（如时间、鼠标位置） | 否   |
| `derived` | 派生状态（基于其他 store 计算得出） | 否   |


### 3.3.2 `writable` —— 可读写状态

1. 创建 `stores/counter.js`

    ```js
    import { writable } from 'svelte/store';

    // 方式1：直接导出
    export const count = writable(0);

    // 方式2：封装方法（推荐用于复杂逻辑）
    function createCounter() {
        const { subscribe, set, update } = writable(0);

        return {
            subscribe,
            increment: () => update(n => n + 1),
            decrement: () => update(n => n - 1),
            reset: () => set(0),
            // 隐藏 set/update，防止外部随意修改
        };
    }

    export const counter = createCounter();
    ```

2. 在组件中使用 App.svelte

    ```svelte
    <script>
        import { count, counter } from './stores/counter.js';
    </script>

    <!-- 读取：$ 前缀自动订阅 -->
    <p>Count: {$count}</p>
    <p>Counter: {$counter}</p>

    <!-- 写入 -->
    <button on:click={() => count.update(n => n + 1)}>+1 (直接修改)</button>
    <button on:click={counter.increment}>+1 (方法修改)</button>
    ```

- 运行结果

    ![](/framework/svelte/base4/013.gif)


### 3.3.3 `readable` —— 只读状态

适用于由**外部事件驱动**的状态（如定时器、WebSocket、传感器数据）。

1. 创建 `stores/time.js`

    ```js
    import { readable } from 'svelte/store';

    export const time = readable(new Date(), function start(set) {
      // 首次有订阅者时调用
      const interval = setInterval(() => {
        set(new Date()); // 更新值
      }, 1000);

      // 返回清理函数（最后订阅者取消时调用）
      return function stop() {
        clearInterval(interval);
      };
    });
    ```

2. 组件中使用

    ```svelte
    <script>
      import { time } from './stores/time.js';
    </script>

    <p>当前时间：{$time.toLocaleTimeString()}</p>
    ```

3. 运行结果

    ![](/framework/svelte/base4/014.gif)

>  外部无法调用 `set()` 或 `update()`，只能通过 `start` 函数内部更新。


### 3.3.4 `derived` —— 派生状态

从一个或多个现有 store **计算得出新值**，自动响应依赖变化。

1. 单依赖 `stores/math.js`

    ```js
    import { derived } from 'svelte/store';
    import { count } from './counter.js';

    export const doubled = derived(count, ($count) => $count * 2);
    ```

2. 多依赖

    ```js
    import { writable, derived } from 'svelte/store';

    export const width = writable(100);
    export const height = writable(50);

    // 注意：依赖项需放在数组中，回调参数是解构后的值数组
    export const area = derived([width, height], ([$width, $height]) => {
      return $width * $height;
    });
    ```

3. 异步派生（高级）

    ```js
    export const userGreeting = derived(authStore, async ($auth, set) => {
      if (!$auth.user) {
        set('Please log in');
        return;
      }
    
      // 异步获取数据
      const name = await fetchUserName($auth.user.id);
      set(`Welcome, ${name}!`);
    
      // 可选：返回清理函数
    }, 'Loading...'); // 初始值
    ```

    >  `derived` 的第三个参数是**初始值**，避免 undefined。

4. 组件中使用

    ```svelte
    <script>
      import { count } from './stores/counter.js';
      import { doubled } from './stores/math.js';
    </script>

    <p>Count 值是： {$count} </p>
    <p>Doubled 值是： {$doubled} </p>
    <button on:click={() => count.update(n => n + 1)}>count+1</button>
    ```
5. 运行结果

    ![](/framework/svelte/base4/015.gif)

### 3.3.5 手动订阅（非 `$` 语法）

1. 组件中使用

    ```svelte
    <script>
      import { count } from './stores/counter.js';
      import { onDestroy } from 'svelte';

      let countValue;

      // 手动订阅
      const unsubscribe = count.subscribe(value => {
        console.log('Count changed:', value);
        countValue = value;
      });

      // 组件销毁时取消订阅（防止内存泄漏）
      onDestroy(unsubscribe);
    </script>

    <p>Count 值是： {$count} </p>
    <p>手动订阅 count: {countValue}</p>
    <button on:click={() => count.update(n => n + 1)}>count+1</button>
    ```

2. 运行结果

    ![](/framework/svelte/base4/016.gif)

>  **必须调用 `onDestroy` 取消订阅**，否则会导致内存泄漏！
