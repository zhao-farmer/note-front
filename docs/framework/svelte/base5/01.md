# 一、认识svelte

## 1.1 Svelte是什么

Svelte 在构建（build）阶段将你的组件代码编译成高效的、 imperative（命令式）的原生 JavaScript，直接操作 DOM —— 运行时无需虚拟 DOM，也无需框架本身。

## 1.3 项目目录结构

```txt
my-svelte-app/
├── node_modules/         # 依赖包
├── public/               # 静态资源目录
├── src/                  # 源代码目录
│   ├── assets/           # 可压缩处理静态资源
│   ├── lib               # 共享组件/工具
│   ├── app.html          # 根 HTML 模板
│   ├── app.css           # 总体css
│   └── main.js           # 入口文件
├── index.html            # 主 HTML 文件
├── package.json          # 项目配置和依赖
├── pnpm-lock.yaml        # pnpm 锁文件
├── README.md             # 项目说明
├── svelte.config.js      # Svelte 配置
└── vite.config.js        # Vite 配置
```

## 1.4 .svelet 文件

```html
<!-- 1. 脚本逻辑（Script） -->
<script>
  // JavaScript / TypeScript 代码
</script>

<!-- 2. 模板（Markup） -->
<!-- HTML + Svelte 语法扩展 -->
<h1>Hello {name}!</h1>
<button on:click={handleClick}>Click me</button>

<!-- 3. 样式（Style） - 可选 -->
<style>
  h1 {
    color: blue;
  }
</style>
```
