# 二、核心语法


## 2.1 符文使用Runes(符文) 详解

### 2.1.1 Svelte 4 → Svelte 5 迁移对比

| Svelte 4 语法               | Svelte 5 语法                           | 说明     |
| --------------------------- | --------------------------------------- | -------- |
| `let count = 0`             | `let count = $state(0)`                 | 状态声明 |
| `$: doubled = count * 2`    | `let doubled = $derived(count * 2)`     | 计算属性 |
| `$: { console.log(count) }` | `$effect(() => { console.log(count) })` | 副作用   |
| `export let name`           | `let { name } = $props()`               | 组件属性 |
| `$: console.log(count)`     | `$inspect(count)`                       | 调试     |


### 2.1.2 `$state`- 响应式状态


1. 代码示例

    ```svelte
    <script>
    	//  声明响应式状态
    	let count = $state(0);
    	let user = $state({
    		name: '张三',
    		age: 25,
    		email: 'zhangsan@example.com'
    	});
    	let todos = $state(['吃饭', '睡觉', '写代码']);
    </script>

    <button onclick={() => count++}>
    	点击次数: {count}
    </button>

    <p>用户名: {user.name}</p>
    <button onclick={() => user.name = '李四'}>
    	改名
    </button>

    <ul>
    {#each todos as todo}
    	<li>{todo}</li>
    {/each}
    </ul>
    ```

2. 运行结果

	![](/framework/svelte/base5/006.gif) 

3. **特点**：

    *  取代了 Svelte 4 的 `let`变量自动响应
    *  可以用于对象、数组、基本类型
    *  支持深层响应式



### 2.1.3 `$derived`- 派生状态

1.  代码示例

	```svelte
	<script>
	  let price = $state(10);
	  let quantity = $state(2);

	  //  计算属性
	  let total = $derived(price * quantity);

	  //  复杂的派生逻辑
	  let discountedTotal = $derived({
	    // 计算逻辑
	    get value() {
	      let total = price * quantity;
	      if (total > 100) {
	        return total * 0.9; // 9折
	      }
	      return total;
	    }
	  });
	</script>

	<p>单价: {price}</p>
	<p>数量: {quantity}</p>
	<p>总计: {total}</p>
	<p>折后价: {discountedTotal.value}</p>
	```
2. 运行结果

	![](/framework/svelte/base5/007.png)

3. **特点**：
	- 取代了 Svelte 4 的 `$: 计算属性`
	- 自动追踪依赖
	- 惰性计算

### 2.1.4 `$effect`- 副作用

1. 代码示例

	```svelte
	<script>
	  let count = $state(0);
	  let previousCount = 0;

	  // 副作用 - DOM 更新后执行
	  $effect(() => {
	    console.log(`计数从 ${previousCount} 变为 ${count}`);
	    previousCount = count;
	  });

	  // 清理函数
	  $effect(() => {
	    const interval = setInterval(() => {
	      console.log('定时器运行中...');
	    }, 1000);

	    return () => {
	      console.log('清理定时器');
	      clearInterval(interval);
	    };
	  });
	</script>

	<button on:click={() => count++}>
	  计数: {count}
	</button>
	```
2. 运行结果

	![](/framework/svelte/base5/008.png)

3. **特点**：

	-   取代了 Svelte 4 的 `$: { 代码块 }`
	-   自动追踪依赖
	-   支持清理函数
	-   在 DOM 更新后执行

### 2.1.7 `$inspect`- 调试工具


## 2.2 事件相关

### 2.2.1 Svelte 4 → Svelte 5 迁移对比

| 特性  | Svelte 4 语法 | Svelte 5 新语法 | 说明与解读 |
| --- | --- | --- | --- |
| **DOM 事件绑定**​ | `on:click={handler}` | `onclick={handler}` | 弃用 `on:`指令，采用更标准的属性写法<br><br>1<br><br>4<br><br>。 |
| **组件事件通信**​ | `createEventDispatcher` | **回调函数作为属性**​ | 父组件通过传递函数属性的方式与子组件通信，事件处理逻辑更集中<br><br>2<br><br>3<br><br>6<br><br>。 |
| **事件修饰符**​ | `on:click\\|once\\|preventDefault` | **使用工具函数包装**​ | 内置修饰符被移除，鼓励在事件处理函数中直接调用相应方法（如 `event.preventDefault()`）或创建自定义工具函数<br><br>2<br><br>4<br><br>8<br><br>。 |
| **多个事件处理程序**​ | `on:click={one} on:click={two}` | `onclick={(e) => { one(e); two(e); }}` | 同一元素上的同一事件不再允许绑定多个处理程序，需合并到一个函数内执行<br><br>3<br><br>8<br><br>。 |



### 2.2.2  DOM 事件绑定

新语法将事件监听器当作普通的HTML属性来处理，只需去掉冒号 `:`


```svelte
<!-- Svelte 5 -->
<script>
	let count = $state(0);
	function handleClick() {
	count++;
	}
</script>

<!-- 方式一：内联函数 -->
<button onclick={() => count++}>点击了 {count} 次</button>

<!-- 方式二：函数引用（可使用简写） -->
<button onclick={handleClick}>点击我</button>
<button {handleClick}>简写形式</button>
```

### 2.2.3 组件事件通信：回调属性

Svelte 5 弃用了 `createEventDispatcher`，转而采用更直接的**回调属性（Callback Props）**。子组件通过 `$props`接收父组件传递的函数，并在适当时机调用。


- **子组件 (`Child.svelte`)**

	```svelte
	<script>
	  // 声明一个名为 onMessage 的回调属性
	  let { onMessage } = $props();

	  function sendData() {
	    // 调用父组件传递过来的函数，并传递数据
	    if (onMessage) {
	      onMessage('Hello from child!');
	    }
	  }
	</script>

	<button onclick={sendData}>发送消息</button>
	```

- **父组件 (`Parent.svelte`)**

	```svelte
	<script>
	  import Child from './Child.svelte';

	  let receivedMessage = $state('');

	  // 这个函数将传递给子组件
	  function handleChildMessage(message) {
	    receivedMessage = message;
	  }
	</script>

	<Child onMessage={handleChildMessage} />
	<p>收到子组件消息：{receivedMessage}</p>
	```

这种方式让数据流非常清晰，类似于React中传递props的方式，也获得了更好的类型安全支持

### 2.2.4 事件修饰符的替代方案

Svelte 5 不再支持事件指令的修饰符（如 `preventDefault`, `once`等），而是推荐在事件处理函数中直接使用对应的DOM方法，或者创建自定义的工具函数

```svelte
<script>
  function handleSubmit(event) {
    // 直接阻止默认行为，替代 |preventDefault
    event.preventDefault();
    // ... 提交逻辑
  }

  // 自定义工具函数，替代 |once
  function once(fn) {
    return function (event) {
      if (fn) fn.call(this, event);
      fn = null; // 执行一次后，将原函数置空
    };
  }

  function handleClick() {
    console.log('这个只会打印一次');
  }
</script>

<form onsubmit={handleSubmit}>
  <button type="submit">提交</button>
</form>

<button onclick={once(handleClick)}>只点击一次</button>
```

对于 `capture`这类修饰符，可以使用新语法 `onclickcapture`



## 2.3 完整示例：TodoList with Runes

- 代码示例

	```svelte
	<script>
	  // 使用 $props 接收属性
	  let { initialTodos = [] } = $props();

	  // 使用 $state 声明状态
	  let todos = $state([...initialTodos]);
	  let newTodoText = $state('');
	  let filter = $state('all');

	  // 使用 $derived 计算属性
	  let filteredTodos = $derived({
	    get value() {
	      if (filter === 'active') {
	        return todos.filter(t => !t.completed);
	      }
	      if (filter === 'completed') {
	        return todos.filter(t => t.completed);
	      }
	      return todos;
	    }
	  });

	  let remainingCount = $derived(
	    todos.filter(t => !t.completed).length
	  );

	  // 使用 $effect 副作用
	  $effect(() => {
	    console.log(`待办事项数量: ${todos.length}`);
	    console.log(`未完成数量: ${remainingCount}`);

	    // 清理函数
	    return () => {
	      console.log('清理效果');
	    };
	  });

	  // 使用 $inspect 调试
	  $inspect(todos, '待办事项');
	  $inspect(filter, '过滤器');

	  // 操作方法
	  function addTodo() {
	    if (!newTodoText.trim()) return;

	    todos.push({
	      id: Date.now(),
	      text: newTodoText.trim(),
	      completed: false
	    });
	    newTodoText = '';
	  }

	  function toggleTodo(id) {
	    const todo = todos.find(t => t.id === id);
	    if (todo) {
	      todo.completed = !todo.completed;
	    }
	  }
	</script>

	<div>
	  <h1>Todo List (Svelte 5 Runes)</h1>

	  <!-- 添加新任务 -->
	  <input
	    type="text"
	    bind:value={newTodoText}
	    placeholder="输入新任务"
	    on:keydown={(e) => e.key === 'Enter' && addTodo()}
	  />
	  <button on:click={addTodo} disabled={!newTodoText.trim()}>
	    添加
	  </button>

	  <!-- 过滤 -->
	  <div>
	    <label>
	      <input type="radio" value="all" bind:group={filter} />
	      全部 ({todos.length})
	    </label>
	    <label>
	      <input type="radio" value="active" bind:group={filter} />
	      进行中 ({remainingCount})
	    </label>
	    <label>
	      <input type="radio" value="completed" bind:group={filter} />
	      已完成 ({todos.length - remainingCount})
	    </label>
	  </div>

	  <!-- 列表 -->
	  <ul>
	    {#each filteredTodos.value as todo (todo.id)}
	      <li>
	        <input
	          type="checkbox"
	          checked={todo.completed}
	          on:change={() => toggleTodo(todo.id)}
	        />
	        <span class:completed={todo.completed}>
	          {todo.text}
	        </span>
	      </li>
	    {/each}
	  </ul>
	</div>

	<style>
	  .completed {
	    text-decoration: line-through;
	    color: #999;
	  }
	</style>
	```
