
# 四、模板语法

## 4.1 语法说明

1. 控制结构

	| 语法  | 说明  | 示例  |
	| --- | --- | --- |
	| `{#if ...}` | 条件渲染 | `{#if user} <p>欢迎, {$user.name}</p> {/if}` |
	| `{#each ...}` | 遍历数组 | `{#each items as item} <li>{$item}</li> {/each}` |
	| `{#key ...}` | 优化列表重排（性能关键） | `{#key id} <div>{$id}</div> {/key}` |
	| `{#await ...}` | 异步数据加载 | `{#await promise} 加载中... {:then value} {$value} 	{:catch error} 错误{/await}` |

	> **重点提示**：
	> 
	> *   `#key` 是 **Svelte 5 性能优化的核心**，必须为动态列表添加唯一 key。
	> *   `#await` 支持 `{:then}` 和 `{:catch}`，可替代 `try/catch`。

2. 片段与渲染

	| 语法  | 说明  | 示例  |
	| --- | --- | --- |
	| `{#snippet ...}` | 命名插槽（Svelte 5 新增） | `{#snippet header()} <header>头部</	header> {/snippet}` |
	| `@render ...` | 渲染函数（类似 JSX） | `@render header()` |
	| `@html ...` | 安全注入 HTML 字符串 | `@html unsafeHtml`（ 有 XSS 风险） |
	| `@attach ...` | 绑定事件或属性到 DOM | `@attach click="handleClick"` |
	| `@const ...` | 定义常量（避免重复表达式） | `@const sum = a + b` |
	| `@debug ...` | 调试输出（开发模式） | `@debug user, items` |

	> **关键点**：
	> 
	> *   `{#snippet}` 是 Svelte 5 的“命名插槽”机制，比 `<slot name="xxx">` 更灵活。
	> *   `@render` 可以渲染任意组件或函数，支持嵌套。
	> *   `@html` **不要用于用户输入**，否则易受 XSS 攻击。


3. 绑定相关

	| 语法  | 说明  | 示例  |
	| --- | --- | --- |
	| `bind:` | 绑定 DOM 属性或值 | `bind:value={inputValue}` |
	| `use:` | 应用 action（如聚焦、动画） | `use:focus` |
	| `transition:` | 添加过渡动画 | `transition:fade` |
	| `in:` 和 `out:` | 进入/退出动画 | `in:slide`, `out:scale` |
	| `animate:` | 动画（基于 CSS 或 JS） | `animate:scale` |
	| `style:` | 动态样式 | `style:color={$theme === 'dark' ? 'white' : 'black'}` |
	| `class:` | 动态类名 | `class:active={isActive}` |
	| `await:` | 等待异步操作完成 | `await:fetchData` |

	> 注意：
	> 
	> *   `bind:` 只能绑定原生 DOM 属性（如 `value`, `checked`, `innerHTML`），不能绑定自定义	属性。
	> *   `use:` 是 Svelte 5 的核心 —— 用于封装 DOM 行为（如 `focus`, `resize`, `scroll`）。

## 4.2 控制模板

### 4.2.1 条件渲染

- 代码结构 `{#if ...} {:else if ...} {:else}` 

- 代码示例

	```svelte
	<script>
		let isLoggedIn = $state(false);
	</script>

	{#if isLoggedIn}
		<p>你好，欢迎回来！</p>
	{:else}
		<p>请先登录。</p>
	{/if}

	<button onclick={() => isLoggedIn = !isLoggedIn}>
		{isLoggedIn ? '登出' : '登录'}
	</button>
	```
- 运行结果

	![](/framework/svelte/base5/020.gif)

- 注意
	- 不支持 else if 连写（必须用 {:else if}）
	- 条件表达式会自动响应 `$state、$derived` 等响应式变量

### 4.2.2 列表遍历

- 代码结构 `{#each ... as ... (key)}`

- 代码示例

	```svelte
	<script>
		let todos = $state([
			{ id: 1, text: '学习 Svelte 5' },
			{ id: 2, text: '写代码' },
			{ id: 3, text: '休息' }
		]);
	</script>

	<ul>
		{#each todos as todo (todo.id)}
			<li>{todo.text}</li>
		{/each}
	</ul>
	```
- 运行结果

	![](/framework/svelte/base5/021.png)

- 注意: `(todo.id) 是 key`，用于高效更新 DOM（必加！）。

### 4.2.3 异步加载

- 代码结构: `{#await ...}` 
- 功能作用：优雅处理 Promise 的三种状态：pending / fulfilled / rejected。
- 代码示例

	```svelte
	<script>
		async function fetchUser() {
		await new Promise(r => setTimeout(r, 1000)); // 模拟网络延迟
			return { name: 'Alice', age: 28 };
		}

		let userPromise = $state(fetchUser());
	</script>

	{#await userPromise}
		<p>正在加载用户信息...</p>
	{:then user}
		<p>姓名: {user.name}, 年龄: {user.age}</p>
	{:catch error}
		<p>加载失败: {error.message}</p>
	{/await}
	```
- 运行结果

	![](/framework/svelte/base5/022.gif)

### 4.2.4 常量定义

- 代码结构: `{@const ...` 
- 代码示例
	```svelte
	<script>
		let price = 100;
		let quantity = 3;
		let taxRate = 0.1;

		let users = [
			{ name: '张三', age: 25 },
			{ name: '李四', age: 30 },
			{ name: '王五', age: 28 }
		];
	</script>

	<!-- 定义常量避免重复计算 -->
	{#if true}
		{@const subtotal = price * quantity}
		{@const area =price * quantity}
		{@const tax = subtotal * taxRate}
		{@const total = subtotal + tax}

		<span>单价: {price}</span>
		<span>数量: {quantity}</span>
		<span>小计: {subtotal}</span>
		<span>税额: {tax}</span>
		<span>总计: {total}</span>

	{/if}

	<ul>
		{#each users as user, index}
			<!-- 定义局部常量 -->
			{@const isAdult = user.age >= 18}
			{@const className = isAdult ? 'adult' : 'minor'}

			<li class={className}>
				{user.name} ({user.age}岁) - {isAdult ? '成年人' : '未成年人'}
			</li>
		{/each}
	</ul>
	```
- 运行结果

	![](/framework/svelte/base5/026.png)

- 注意：`@const` 只能在 `{#if ...}`, `{#each ...}`, `{#snippet ...}`中使用

## 4.3 代码渲染

### 4.3.1 强制重新创建 DOM

当 expression 变化时，销毁并重建整个块内的 DOM 和组件。

- 代码结构:  `{#key expression}`
- 代码示例

	```svelte
	<script>
		let keyValue = $state(0);

		const resetForm = () => {
			keyValue = Math.random(); // 改变 key 值，强制重置
		};
	</script>

	<button onclick={resetForm}>重置表单</button>

	{#key keyValue}
		<input type="text" placeholder="输入内容..." />
	{/key}
	```
- 运行结果

	![](/framework/svelte/base5/023.gif)

### 4.3.2 插槽与渲染

- 代码结构: `{#snippet ...}` 与 `@render ...` 

- 代码示例

	```svelte
	{#snippet header()}
		<h2>页面标题</h2>
	{/snippet}

	{#snippet content()}
		<p>这是主要内容</p>
	{/snippet}

	<!-- 定义带参数的 snippet -->
	{#snippet userCard(user)}
		<div class="user-card">
		<h3>{user.name}</h3>
		<p>{user.email}</p>
		</div>
	{/snippet}

	<!-- 使用 -->
	{@render header()}
	{@render content()}
	{@render userCard({ name: '张三', email: 'zhang@example.com' })}
	```
- 运行结果

	![](/framework/svelte/base5/024.png)

### 4.3.3 HTML解析

- 代码结构: `@html ...` 
- 代码示例

	```svelte
	<script>
		let htmlContent = '<strong>加粗文本</strong> 和 <span style="color: red;">红色文本</	span>';
	</script>

	<!-- 渲染 HTML -->
	<div>{@html htmlContent}</div>

	<!-- 内联 HTML -->
	```

### 4.3.4 调试输出

- 代码结构: `@debug ...`- 

- 代码示例

	```svelte
	<script>
		let count = 0;
		let user = { name: '张三', age: 25 };
		let isLoading = false;
	</script>

	<!-- 调试多个变量 -->
	{@debug count, user, isLoading}

	<!-- 条件调试 -->

	{/if}
	```

## 4.4 绑定相关

### 4.4.1 bind:双向绑定

- 代码示例

	```svelte
	<script>
		let name = $state('');
		let age = $state(18);
		let checked = $state(false);
		let selected = $state('A');
	</script>

	<!-- 文本输入 -->
	<input bind:value={name} placeholder="输入姓名" />
	<p>姓名: {name}</p>

	<!-- 数字输入 -->
	<input type="number" bind:value={age} />
	<p>年龄: {age}</p>

	<!-- 复选框 -->
	<label>
		<input type="checkbox" bind:checked={checked} />
		是否同意
	</label>

	<!-- 单选按钮 -->
	<label>
		<input type="radio" bind:group={selected} value="A" /> 选项A
	</label>
	<label>
		<input type="radio" bind:group={selected} value="B" /> 选项B
	</label>

	<!-- 下拉选择 -->
	<select bind:value={selected}>
		<option value="A">A</option>
		<option value="B">B</option>
	</select>
	```
- 运行结果

	![](/framework/svelte/base5/028.png)


### 4.4.2 `use:`动作

- 代码示例

	```svelte
	<script>
		// 自动聚焦动作
		function autoFocus(node) {
			node.focus();
		}

		// 点击外部关闭动作
		function clickOutside(node, callback) {
			function handleClick(event) {
				if (!node.contains(event.target)) {
					callback();
				}
			}

			document.addEventListener('click', handleClick, true);

			return {
				destroy() {
					document.removeEventListener('click', handleClick, true);
				}
			};
		}
	</script>

	<!-- 自动聚焦 -->
	<input use:autoFocus placeholder="自动获得焦点" />

	<!-- 点击外部关闭 -->
	<div use:clickOutside={() => console.log('点击了外部')}>
		点击这个区域外部
	</div>
	```
- 运行结果

	![](/framework/svelte/base5/029.gif)

### 4.4.3 `transition:`过渡

- 代码示例

	```svelte
	<script>
		import { fade, fly } from 'svelte/transition';
		let visible = $state(true);
	</script>

	<button onclick={() => visible = !visible}>
		{visible ? '隐藏' : '显示'}
	</button>

	{#if visible}
		<!-- 淡入淡出 -->
		<div transition:fade>淡入淡出效果</div>

		<!-- 飞入飞出 -->
		<div transition:fly={{ y: 20 }}>飞入飞出效果</div>
	{/if}
	```

### 4.4.4 `in:`和 `out:`进入/退出

### 4.4.5 `animate:`动画

- 代码示例

	```svelte
	<script>
		import { flip } from 'svelte/animate';
		let items = $state([1, 2, 3]);
	</script>

	<button onclick={() => items = [...items].reverse()}>
		反转顺序
	</button>

	<div>
		{#each items as item (item)} <!-- 关键：提供 key -->
			<div animate:flip={{ duration: 300 }}>
				{item}
			</div>
		{/each}
	</div>

	<style>
		div > div {
			padding: 8px;
			margin: 4px 0;
			background: #f0f0f0;
			border: 1px solid #ccc;
		}
	</style>
	```

- 运行结果

### 4.4.6 `style:`动态样式

- 代码示例

	```svelte
	<script>
	  let isRed = $state(false);
	  let fontSize = $state(16);
	  let rotate = $state(0);
	</script>

	<!-- 切换样式 -->
	<label>
	  <input type="checkbox" bind:checked={isRed} />
	  红色文本
	</label>

	<!-- 控制大小 -->
	<input type="range" bind:value={fontSize} min="12" max="32" />

	<!-- 控制旋转 -->
	<input type="range" bind:value={rotate} min="0" max="360" />

	<!-- 应用动态样式 -->
	<div
	  style:color={isRed ? 'red' : 'black'}
	  style:font-size={`${fontSize}px`}
	  style:transform={`rotate(${rotate}deg)`}
	>
	  动态样式文本
	</div>
	```

- 运行结果

	![](/framework/svelte/base5/033.gif)

### 4.4.8 `await:`异步等待

- 代码示例

	```svelte
	<script>
	  async function fetchData() {
	    await new Promise(resolve => setTimeout(resolve, 1000));
	    return { name: '张三', age: 25 };
	  }

	  // 使用 $state 声明响应式 promise
	  let promise = $state(null);
	</script>

	<button onclick={() => promise = fetchData()}>
	  加载数据
	</button>

	{#if promise}
	  {#await promise}
	    <p>加载中...</p>
	  {:then data}
	    <!--  现在 data 是有效的 -->
	    <p>姓名: {data.name}, 年龄: {data.age}</p>
	  {:catch error}
	    <p>加载失败: {error.message || '未知错误'}</p>
	  {/await}
	{:else}
	  <p>点击按钮加载数据</p>
	{/if}
	```
- 运行结果

	![](/framework/svelte/base5/035.gif)
