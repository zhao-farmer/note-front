# 一、快速创建项目

## 1.1 命令创建

1. 创建项目

    ```sh
    npx sv create 01-project
    ```

    ![](/framework/svelte/svelteKit/001.png)

2. 启动项目

    ```sh
    cd 01-project 
    npm run dev
    ```

    ![](/framework/svelte/svelteKit/002.png)


## 1.2 项目结构

```txt
my-sveltekit-app/           # 项目根目录
├── src/                    # 源代码目录
│   ├── lib/               # 可复用代码库
│   │   ├── components/    # 可复用组件
│   │   │   ├── Button.svelte
│   │   │   ├── Header.svelte
│   │   │   ├── Card.svelte
│   │   │   └── index.js   # 组件导出入口
│   │   ├── server/        # 服务端专用代码（不会打包到客户端）
│   │   │   ├── database.ts  # 数据库连接
│   │   │   ├── auth.ts      # 认证逻辑
│   │   │   └── api/        # API工具函数
│   │   ├── stores/        # 状态管理
│   │   │   ├── user.store.ts
│   │   │   └── cart.store.ts
│   │   ├── utils/         # 工具函数
│   │   │   ├── helpers.ts
│   │   │   └── formatters.ts
│   │   └── styles/        # 样式文件
│   │       ├── global.css
│   │       └── variables.css
│   ├── routes/           # 应用路由（核心目录）
│   │   ├── +layout.svelte     # 根布局组件
│   │   ├── +layout.server.js  # 根布局数据加载
│   │   ├── +page.svelte      # 首页组件 (/)
│   │   ├── +error.svelte     # 根错误页面
│   │   ├── about/           # 关于页路由
│   │   │   ├── +page.svelte
│   │   │   └── +page.server.js
│   │   ├── blog/           # 博客路由
│   │   │   ├── +page.svelte       # 博客列表页 (/blog)
│   │   │   ├── +page.server.js    # 列表页数据
│   │   │   └── [slug]/           # 动态路由
│   │   │       ├── +page.svelte   # 博客详情页
│   │   │       └── +page.server.js
│   │   ├── api/            # API 路由
│   │   │   ├── users/      # 用户相关API
│   │   │   │   ├── +server.js
│   │   │   │   └── [id]/
│   │   │   │       └── +server.js
│   │   │   └── posts/
│   │   │       └── +server.js
│   │   └── (auth)/         # 分组路由（不显示在URL中）
│   │       ├── login/
│   │       │   └── +page.svelte
│   │       └── register/
│   │           └── +page.svelte
│   ├── params/            # 路由参数验证器
│   │   ├── integer.ts     # 验证整数参数
│   │   └── slug.ts        # 验证slug格式
│   ├── app.html           # HTML主模板
│   ├── app.css            # 全局样式
│   ├── hooks.client.js    # 客户端钩子
│   ├── hooks.server.js    # 服务端钩子
│   └── service-worker.js  # PWA支持
├── static/                # 静态资源目录
│   ├── favicon.ico       # 网站图标
│   ├── robots.txt        # 爬虫规则
│   ├── manifest.json     # PWA清单
│   ├── images/           # 图片资源
│   │   ├── logo.png
│   │   └── avatar.png
│   └── fonts/            # 字体文件
│       └── custom.woff2
├── tests/                # 测试目录
│   ├── unit/            # 单元测试
│   │   └── example.test.js
│   ├── integration/     # 集成测试
│   │   └── api.test.js
│   └── e2e/             # 端到端测试
│       └── app.test.js
├── .env                  # 环境变量
├── .env.example         # 环境变量示例
├── package.json         # 项目配置和依赖
├── package-lock.json    # 依赖锁文件
├── svelte.config.js     # SvelteKit配置
├── vite.config.js      # Vite配置
├── tsconfig.json       # TypeScript配置
├── jsconfig.json       # JavaScript配置
├── tailwind.config.js  # Tailwind CSS配置
├── postcss.config.js   # PostCSS配置
├── dockerfile          # Docker容器配置
├── docker-compose.yml  # Docker Compose配置
├── README.md           # 项目说明文档
├── CHANGELOG.md        # 更新日志
└── .gitignore          # Git忽略文件
```
