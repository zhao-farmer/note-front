# 二、采样与样本

## 2.1 原始采样

### 2.1.1 文档介绍

1. EncodedPacketSink 是什么

    **EncodedPacketSink** 是 Mediabunny 中最基础、最通用的媒体数据接收器（Sink）。
    作用：**从任意轨道（视频/音频/字幕）中直接提取原始编码数据包（EncodedPacket）**。

    适用场景：
    - 只想读取时间戳、帧类型、时长等元数据
    - 自己实现解码逻辑
    - 封装、转封装、切片媒体数据


2. 创建 EncodedPacketSink

    ```javascript
    import { EncodedPacketSink } from "../../js/mediabunny.1.42.mjs";

    // 从任意轨道创建
    const sink = new EncodedPacketSink(track);
    ```
3. 核心 API 方法


    1. 获取指定时间戳的数据包

        ```javascript
        // 获取 ≤ 该时间戳的最后一个数据包
        const packet = await sink.getPacket(seconds, options);
        ```

        **参数：**
        - `seconds`：时间（秒）
        - `options`（可选）：
            - `metadataOnly: boolean`：只获取元数据，不加载数据
            - `verifyKeyPackets: boolean`：验证关键帧（确保是真关键帧）

        **返回：**
        `EncodedPacket | null`


    2. 只获取关键帧数据包

        ```javascript
        const keyPacket = await sink.getKeyPacket(5, options);
        ```
        返回 ≤ 5秒的**最后一个关键帧（I帧）**。

    3. 获取第一个数据包（解码顺序）

        ```javascript
        const first = await sink.getFirstPacket();
        ```

    4. 获取第一个关键帧

        ```javascript
        const firstKey = await sink.getFirstKeyPacket();
        ```

    5. 获取最后一个数据包

        ```javascript
        const last = await sink.getPacket(Infinity);
        ```

    6. 获取下一个数据包（解码顺序）

        ```javascript
        const next = await sink.getNextPacket(currentPacket);
        ```

    7. 获取下一个关键帧

        ```javascript
        const nextKey = await sink.getNextKeyPacket(currentPacket);
        ```

    8. 遍历所有数据包（解码顺序）

        ```javascript
        for await (const packet of sink.packets(start, end, options)) {
        // 处理 packet
        }
        ```

        **参数：**
        - `start`：起始包
        - `end`：结束包（不含）
        - `options`：`verifyKeyPackets`、`metadataOnly`


4. EncodedPacket 结构

    ```ts
    interface EncodedPacket {
        type: 'key' | 'delta';       // 关键帧 / 非关键帧
        timestamp: number;          // 时间戳（秒）
        duration: number;            // 时长（秒）
        data: Uint8Array;            // 编码数据
        isMetadataOnly: boolean;     // 是否仅元数据
        track: InputTrack;           // 所属轨道
    }
    ```

5. 重要选项说明


    1. metadataOnly（仅元数据）

        只读取包头信息，**不读取媒体数据**，速度极快。
        ```javascript
        await sink.getPacket(5, { metadataOnly: true });
        ```
        packet.data 为空数组。

    2. verifyKeyPackets（验证关键帧）

        有些文件元数据错误，把非关键帧标记为关键帧。
        开启后确保返回真关键帧。
        ```javascript
        await sink.getKeyPacket(5, { verifyKeyPackets: true });
        ```

6. 典型使用示例（官方标准）


    - 遍历轨道所有数据包

        ```javascript
        const sink = new EncodedPacketSink(track);

        let current = await sink.getFirstPacket();
        while (current) {
            console.log(`时间: ${current.timestamp}s 类型: ${current.type}`);
            current = await sink.getNextPacket(current);
        }
        ```

    - 遍历所有关键帧

        ```javascript
        const sink = new EncodedPacketSink(track);

        let current = await sink.getFirstKeyPacket();
        while (current) {
            console.log(`关键帧 @ ${current.timestamp}s`);
            current = await sink.getNextKeyPacket(current);
        }
        ```

    - 只遍历元数据（高性能）

        ```javascript
        for await (const pkt of sink.packets(undefined, undefined, {
            metadataOnly: true
        })) {
            console.log(pkt.timestamp, pkt.type);
        }
        ```

7. 官方要点总结

    1. **EncodedPacketSink = 原始编码数据包读取器**
    2. 适用于**所有轨道类型**（video/audio/subtitle）
    3. 按**解码顺序**提供数据
    4. 高性能：支持仅读取元数据
    5. 可精确定位时间戳、关键帧
    6. 适合：转码、封装、分析、自定义解码


### 2.1.2 EncodedPacketSink解码顺序

1. 为什么顺序是乱的？

    **EncodedPacketSink 输出的是【解码顺序】，不是【显示顺序】**
    - **解码顺序（decode order）**：解码器要吃的顺序（可能乱序）
    - **显示顺序（presentation order）**：你看到的时间顺序（0s → 1s → 2s）

    很多视频编码（如 IPB 帧）会把**后面的帧放到前面传输**，所以时间戳会乱跳。

    官方文档明确写了：
    > **EncodedPacketSink returns packets in decode order** – not presentation order.


2. 手动排序

    ```js
    const packets = [];
    for await (const pkt of sink.packets()) {
        packets.push(pkt);
        if (packets.length >= 50) break;
    }

    // 排序
    packets.sort((a, b) => a.timestamp - b.timestamp);
    ```

## 2.2 视频采样

### 2.2.1 VideoSampleSink采样

#### 1. 使用说明

`VideoSampleSink` 是 MediaBunny 中**专门用于从视频轨道提取已解码视频帧（VideoSample）** 的核心 Sink，自动完成解码，所有操作基于**呈现顺序（按时间戳排序）**。


1. 核心定位

    - 作用：从 `InputVideoTrack` 提取**解码后的视频帧**，无需手动处理编码/解码逻辑。
    - 继承：`BaseMediaSampleSink`。
    - 适用：视频帧读取、帧遍历、关键帧提取、缩略图生成等场景。

2. 构造函数

    ```typescript
    import { VideoSampleSink } from 'mediabunny';

    // 从视频轨道创建实例
    const videoTrack = await input.getPrimaryVideoTrack();
    const sink = new VideoSampleSink(videoTrack);
    ```

    - 构造**无IO开销**，不读取媒体数据，仅绑定轨道。
    - 每个轨道建议只创建一个实例，多次复用。

3. 核心方法

    1. `getSample(timestamp, options?) → Promise<VideoSample | null>`

        **获取指定时间戳对应的单帧**

        - 规则：返回**呈现顺序中 ≤ 目标时间戳的最后一帧**；时间戳早于首帧返回 `null`。
        - 常用场景：取某一时刻帧、首帧、末帧。

        ```typescript
        // 取 5 秒处的帧
        const sample = await sink.getSample(5);

        // 取首帧
        const firstTs = await videoTrack.getFirstTimestamp();
        const firstSample = await sink.getSample(firstTs);

        // 取末帧
        const lastSample = await sink.getSample(Infinity);
        ```

    2. `samples(start?, end?, options?) → AsyncGenerator<VideoSample>`

        **按时间范围遍历连续帧**

        - 默认：遍历全片（start=0，end=Infinity）。
        - 特性：智能预解码，遍历高效；支持 `break` 提前退出并释放资源。

        ```typescript
        // 遍历全片所有帧
        for await (const sample of sink.samples()) {
            console.log(sample.timestamp);
            sample.close(); // 用完释放帧资源
        }

        // 遍历 5~10 秒区间帧（含5，不含10）
        for await (const sample of sink.samples(5, 10)) {
            sample.close();
        }
        ```

    3. `samplesAtTimestamps(timestamps, options?) → AsyncGenerator<VideoSample | null>`

        **批量获取离散时间戳的帧（高效稀疏读取）**

        - 优势：时间戳单调递增时**优化解码流水线**，每个包只解码一次，远快于循环 `getSample`。
        - 输入：数组、Set、生成器、异步生成器等可迭代对象。

        ```typescript
        // 批量取固定时间点帧
        const timestamps = [0, 1.5, 3, 4.5, 6];
        for await (const sample of sink.samplesAtTimestamps(timestamps)) {
            sample?.close();
        }

        // 异步生成时间戳（如提取所有关键帧）
        const keyFrameSamples = sink.samplesAtTimestamps(async function* () {
            const packetSink = new EncodedPacketSink(videoTrack);
            let pkt = await packetSink.getFirstKeyPacket();
            while (pkt) {
                yield pkt.timestamp;
                pkt = await packetSink.getNextKeyPacket(pkt);
            }
        });

        for await (const sample of keyFrameSamples) {
            sample?.close();
        }
        ```

4. 通用参数说明
    - `timestamp`：时间戳，单位**秒**。
    - `startTimestamp`：起始时间（含），默认 0。
    - `endTimestamp`：结束时间（不含），默认 Infinity。

#### 2. 代码-三个方法

1. 代码示例

### 2.2.2 CanvasSink采样

#### 1. 使用说明

`CanvasSink` 是 MediaBunny 中**直接输出 Canvas（HTMLCanvasElement/OffscreenCanvas）** 的专用 Sink，内置**解码+缩放+旋转+裁剪**，比 `VideoSampleSink` 更适合直接渲染/导出图像。

1. 核心定位

    - 作用：从 `InputVideoTrack` 提取解码帧，**自动渲染到 Canvas**，支持尺寸适配、旋转、裁剪。
    - 输出：DOM 环境返回 `HTMLCanvasElement`；WebWorker 环境返回 `OffscreenCanvas`。
    - 继承：`BaseMediaSampleSink`。
    - 适用：帧预览、缩略图生成、视频截图、Canvas 实时渲染、帧导出为图片。

2. 构造函数与配置项

    1. 构造函数

        ```typescript
        import { CanvasSink } from 'mediabunny';

        // 基础创建
        const videoTrack = await input.getPrimaryVideoTrack();
        const sink = new CanvasSink(videoTrack, {
            width: 640,
            height: 360,
            fit: 'contain',
            rotation: 0,
            alpha: false
        });
        ```

    2. CanvasSinkOptions 配置项（完整）

        ```typescript
        type CanvasSinkOptions = {
            alpha?: boolean;        // 透明通道，默认 false（黑底）
            width?: number;         // 输出宽度（px），默认原视频宽
            height?: number;        // 输出高度（px），默认原视频高
            fit?: 'fill' | 'contain' | 'cover'; // 适配模式（宽高都设时必填）
            rotation?: 0 | 90 | 180 | 270; // 旋转角度，默认 0
            crop?: { left: number; top: number; width: number; height: number }; // 裁剪区域
            poolSize?: number;      // Canvas 池大小，默认自动
        };
        ```

        适配模式（fit）说明

        - `contain`：完整显示，**黑边填充**（默认推荐）。
        - `cover`：填满画布，**裁剪超出部分**。
        - `fill`：拉伸填满，**可能变形**。


3. 核心方法

    1. `getCanvas(timestamp) → Promise<WrappedCanvas | null>`

        **获取指定时间戳的单帧 Canvas**

        - 规则：返回**≤ 目标时间戳的最后一帧**；时间戳早于首帧返回 `null`。
        - 输出：`{ canvas: HTMLCanvasElement/OffscreenCanvas, timestamp: number }`。

        ```typescript
        // 取 3 秒处的帧
        const frame = await sink.getCanvas(3);
        if (frame) {
            console.log(frame.canvas); // 直接用于渲染/导出
        }
        ```

    2. `canvases(start?, end?) → AsyncGenerator<WrappedCanvas>`

        **按时间范围遍历所有帧（连续）**
        - 默认：遍历全片（start=0，end=Infinity）。
        - 高效：内置预解码，支持 `break` 释放资源。

        ```typescript
        // 遍历 0~5 秒所有帧
        for await (const frame of sink.canvases(0, 5)) {
            // 处理每一帧
            frame.canvas.toBlob(blob => {/* 导出图片 */}, 'image/png');
        }
        ```

    3. `canvasesAtTimestamps(timestamps) → AsyncGenerator<WrappedCanvas | null>`

        **批量获取离散时间戳的 Canvas（高效稀疏读取）**

        - 优势：时间戳**单调递增**时优化解码，每个包只解码一次，远快于循环 `getCanvas`。
        - 输入：数组、Set、生成器等可迭代对象。

        ```typescript
        // 批量取关键时间点
        const timestamps = [0, 1, 2, 4, 8];
        for await (const frame of sink.canvasesAtTimestamps(timestamps)) {
            if (frame) console.log(frame.timestamp);
        }
        ```

4. WrappedCanvas 类型

    所有方法返回的 Canvas 包装对象：

    ```typescript
    type WrappedCanvas = {
        canvas: HTMLCanvasElement | OffscreenCanvas;
        timestamp: number; // 帧时间戳（秒）
        duration: number;   // 持续时间（秒）
    };
    ```

### 2.2.3 采样对比


1. 核心定位与用途

    1. VideoSampleSink
        - **定位**：**底层视频帧提取器**，输出解码后的原始视频帧数据。
        - **作用**：从视频轨道解码，得到 `VideoSample`（对 WebCodecs `VideoFrame` 的轻量封装）。
        - **典型场景**：帧数据分析、像素级处理、AI 推理、自定义渲染、离屏批量处理。

    2. CanvasSink
        - **定位**：**高层视频渲染器**，直接输出可绘制的 `<canvas>`（或 `OffscreenCanvas`）。
        - **作用**：解码 → 自动渲染到 Canvas → 可配置宽高、适配、旋转、裁切。
        - **典型场景**：播放器画面预览、实时绘制、缩略图生成、DOM 直接展示、简单变换（缩放/旋转）。

2. 输出类型对比

    | 特性 | VideoSampleSink | CanvasSink |
    |---|---|---|
    | 输出对象 | `VideoSample`（封装 `VideoFrame`） | `HTMLCanvasElement` / `OffscreenCanvas` |
    | 数据形式 | 原始像素数据、时间戳、宽高、旋转 | 已渲染的画布，可直接绘制/展示 |
    | 可直接 DOM 展示 | 需手动绘制到 Canvas | 直接插入 DOM 即可显示 |
    | 资源占用 | 内存占用低（仅解码数据） | 显存/内存更高（Canvas 缓冲区） |
    | 适用场景 | 帧数据分析/二次编码 | 预览/截图/导出 |

3. 能力对比（功能差异）

    1. VideoSampleSink
        -  访问**原始像素数据**（`sample.data` / `VideoFrame`）
        -  拿到**原始宽高、旋转、时间戳、时长**
        -  可**自由绘制到任意 Canvas**、上传到 WebGL、传给 AI 模型
        -  不自动做缩放/适配/旋转校正，需自己处理
    2. CanvasSink
        - 内置**缩放、裁切、适配（fit）、旋转校正**
        - 直接输出**指定宽高**的 Canvas（配置 `width`/`height`）
        - 自动处理**旋转元数据**，画面方向正确
        - 不直接暴露原始像素（需从 Canvas 用 `getImageData` 读取，有开销）

## 2.3 音频采样

### 2.3.1 AudioSampleSink采样

#### 1. 使用说明

`AudioSampleSink` 是 MediaBunny 中**提取解码后原始音频样本（AudioSample）** 的专用 Sink，自动处理解码，适合底层音频分析、波形绘制、自定义音频处理。


1. 核心定位
    - 作用：从 `InputAudioTrack` 提取**解码后的原始 PCM 音频样本**。
    - 输出：`AudioSample`（原始音频数据，含时间戳、采样率、通道数）。
    - 继承：`BaseMediaSampleSink`。
    - 适用：音频波形可视化、音量分析、频谱计算、自定义音频渲染、原始音频数据导出。
    - 对比 `AudioBufferSink`：
        - `AudioSampleSink`：输出**原始 AudioSample**（底层、可直接操作数据）。
        - `AudioBufferSink`：输出**Web Audio API 兼容的 AudioBuffer**（上层、直接播放）。

2. 构造函数

    ```typescript
    import { AudioSampleSink } from 'mediabunny';

    // 创建 AudioSampleSink
    const audioTrack = await input.getPrimaryAudioTrack();
    const sink = new AudioSampleSink(audioTrack);
    ```

    - 参数：`audioTrack: InputAudioTrack`（必填，音频轨道对象）。
    - 无额外配置项，自动继承轨道的采样率、通道数、编码格式。


3.  AudioSample（输出类型）

    ```typescript
    type AudioSample = {
        data: Float32Array[];    // 各通道音频数据（Float32，-1.0 ~ 1.0）
        timestamp: number;       // 样本起始时间戳（秒）
        duration: number;        // 样本时长（秒）
        sampleRate: number;      // 采样率（如 44100 Hz）
        numberOfChannels: number;// 通道数（1=单声道，2=立体声）
    };
    ```

4. 核心方法
    1. `getSample(timestamp: number) → Promise<WrappedAudioSample | null>`

        **获取指定时间戳的单个音频样本**
        - 规则：返回**≤ 目标时间戳的最后一个样本**；时间戳早于首样本返回 `null`。
        - 用途：精准时间点音频分析（如某秒音量）。

        ```typescript
        // 获取 2.5 秒处的音频样本
        const sample = await sink.getSample(2.5);
        if (sample) {
            console.log(sample.sample.data); // Float32Array[] 音频数据
        }
        ```

    2. `samples(start?: number, end?: number) → AsyncGenerator<WrappedAudioSample>`

        **按时间范围遍历所有音频样本（连续）**
        - 默认：遍历全片（start=0，end=Infinity）。
        - 高效：内置预解码，支持 `break` 释放资源。
        - 用途：波形绘制、全音频音量统计。

        ```typescript
        // 遍历 0~10 秒所有音频样本
        for await (const sample of sink.samples(0, 10)) {
        // 处理每个样本（如计算音量）
        const volume = Math.max(...sample.sample.data[0].map(Math.abs));
        }
        ```

    3. `samplesAtTimestamps(timestamps: Iterable<number>) → AsyncGenerator<WrappedAudioSample | null>`

        **批量获取离散时间戳的音频样本（高效稀疏读取）**
        - 优势：时间戳**单调递增**时优化解码，每个包只解码一次，远快于循环 `getSample`。
        - 输入：数组、Set、生成器等可迭代对象。
        - 用途：关键时间点音频采样（如每 0.5 秒取一次）。

        ```typescript
        // 批量取 0、0.5、1.0、1.5 秒的样本
        const timestamps = [0, 0.5, 1.0, 1.5];
        for await (const sample of sink.samplesAtTimestamps(timestamps)) {
            if (sample) console.log(sample.timestamp);
        }
        ```

### 2.3.2 AudioBufferSink采样

#### 1. 使用说明

AudioBufferSink 是 Mediabunny 用于**从音频轨道提取解码后的音频样本并转为 Web Audio API 可用的 AudioBuffer** 的核心工具，比直接取原始音频样本更适配 Web 音频场景。



1. 核心定位
    - 作用：从 InputAudioTrack 读取解码音频 → 输出 WrappedAudioBuffer（含 AudioBuffer、时间戳、时长）
    - 优势：直接兼容 Web Audio API，无需手动格式转换
    - 适用：音频播放、处理、可视化、混音等 Web 音频场景

2. 构造函数

    ```typescript
    constructor(audioTrack: InputAudioTrack): AudioBufferSink;
    ```
    - 传入音频轨道，创建实例
    - 构造**无 IO 开销**，不读取媒体数据

    ```ts
    import { AudioBufferSink } from "mediabunny";

    // 拿到音频轨道并实例化
    const audioTrack = await input.getPrimaryAudioTrack();
    const sink = new AudioBufferSink(audioTrack);
    ```

3. 返回类型：WrappedAudioBuffer

    ```typescript
    type WrappedAudioBuffer = {
        buffer: AudioBuffer;     // 可直接用于 Web Audio API
        timestamp: number;       // 时间戳（秒）
        duration: number;        // 时长（秒）
    };
    ```


4. 核心方法
    1. `getSample(timestamp: number): Promise<AudioBuffer | null>`

        - 根据时间戳，获取**该时间点最近解码后的 AudioBuffer**
        - 找不到对应帧返回 `null`
        - 适合：取某时间点音频片段、精准定位播放

    2. `samples(start?: number, end?: number): AsyncGenerator<AudioBuffer>`

        - 异步迭代器，遍历 **`[start, end]`** 时间范围内所有音频片段
        - 不传参默认遍历整轨全部音频
        - 适合：整轨加载、分段缓存、流式播放

        用法示例：
        ```ts
        for await (const buf of sink.samples(0, 10)) {
            // buf 就是标准 AudioBuffer
            console.log(buf.duration, buf.sampleRate);
        }
        ```
    3. `samplesAtTimestamps(timestamps: Iterable<number>): AsyncGenerator<AudioBuffer | null>`
        - 传入一组时间戳，批量获取对应位置的 AudioBuffer
        - 内部智能解码流水线，比循环 `getSample` 性能高很多
        - 适合：随机多点音频采样、节选片段提取

### 2.3.3 采样对比

1. 快速区分
    - **AudioSampleSink**：输出**底层原始分段PCM音频样本**，适合**音频分析、波形、频谱、算法处理**
    - **AudioBufferSink**：输出**浏览器标准 AudioBuffer**，适合**直接播放、WebAudio 混音、音效**

2. 核心基础对比表

    | 对比项 | AudioSampleSink | AudioBufferSink |
    |--------|-----------------|-----------------|
    | 输出类型 | `AudioSample` 原始音频分片 | 原生 `AudioBuffer`（Web Audio API 标准） |
    | 数据格式 | `Float32Array[]` 分通道原始PCM | 封装好的音频缓冲区，可直接用 `getChannelData` |
    | 数据形态 | 按媒体解码分包**一小块一小块**输出 | 自动拼接成**完整连续音频缓冲区** |
    | 依赖API | 纯MediaBunny底层封装 | 强绑定浏览器 **Web Audio API** |
    | 能否直接播放 | 不能，需手动拼接转AudioBuffer | **可以直接放进AudioContext播放** |
    | 适合场景 | 波形绘制、音量检测、频谱分析、AI音频处理 | 播放器播放、背景音乐、音频剪辑、WebAudio音效 |
    | 可控粒度 | 细粒度，逐小段遍历 | 整块缓冲区，粒度大 |



3. 详细结构差异
    1. AudioSampleSink 输出结构
        ```ts
        type AudioSample = {
            data: Float32Array[];     // 每通道原始PCM浮点数据
            timestamp: number;        // 当前片段起始时间
            duration: number;         // 当前片段时长
            sampleRate: number;
            numberOfChannels: number;
        };
        ```

        特点：

        - 是**解码后的一小块音频分片**
        - 保留媒体原生分包结构
        - 可以逐段做实时计算、波形采样

    2. AudioBufferSink 输出结构

        直接返回浏览器标准：

        ```ts
        interface AudioBuffer {
            sampleRate: number;
            length: number;
            duration: number;
            numberOfChannels: number;
            getChannelData(channel: number): Float32Array;
        }
        ```
        特点：
        - 内部自动把所有音频分片**拼接成完整缓冲区**
        - 格式标准化，完全适配 WebAudio 所有接口

## 2.4 视频样本

### 2.4.1 使用说明


`VideoSample` 代表**一帧解码后的原始视频采样帧**，是 Mediabunny 视频处理核心单元，承载单帧图像数据、时间信息、帧类型、尺寸等元数据。

1. 关键特性
    1. `VideoSample` 是**解码后**原始帧，不是编码数据包；对应编码层是 `EncodedVideoPacket`
    2. 所有时间相关字段同时提供**秒级浮点时间戳**和**高精度 PTS/DTS 大整数**
    3. 支持直接转 `ImageBitmap` 和原始像素数组，适配 Web 所有图像渲染场景
    4. 生命周期必须手动 `close()` 销毁，多帧循环渲染尤其要注意及时释放
    5. 所有涉及资源占用的操作（如 `draw()`、`toVideoFrame()`）后，**必须调用 `close()` 或使用 `using` 语法**，否则会造成严重的内存泄漏。


2. VideoSample 完整属性

    | 属性 | 类型 | 说明 |
    |------|------|------|
    | `codedHeight` | `number` | 编码时的原始高度（像素），未经过旋转/裁剪处理 |
    | `codedWidth` | `number` | 编码时的原始宽度（像素），未经过旋转/裁剪处理 |
    | `colorSpace` | `VideoSampleColorSpace` | 帧的色彩空间（如 `bt709`、`srgb` 等） |
    | `displayHeight` | `number` | 实际显示高度（已考虑旋转、像素宽高比修正） |
    | `displayWidth` | `number` | 实际显示宽度（已考虑旋转、像素宽高比修正） |
    | `duration` | `number` | 帧持续时间（秒） |
    | `format` | `VideoPixelFormat \| null` | 像素格式（如 `I420`、`RGBA` 等） |
    | `hasAlpha` | `boolean` | 是否包含 Alpha 透明通道 |
    | `microsecondDuration` | `number` | 帧持续时间（微秒） |
    | `microsecondTimestamp` | `number` | 帧 PTS（展示时间戳，微秒） |
    | `pixelAspectRatio` | `number` | 像素宽高比，用于非方形像素修正 |
    | `rotation` | `0 | 90 | 180 | 270` | 帧需要旋转的角度（顺时针） |
    | `squarePixelHeight` | `number` | 按方形像素修正后的高度（用于渲染/显示） |
    | `squarePixelWidth` | `number` | 按方形像素修正后的宽度（用于渲染/显示） |
    | `timestamp` | `number` | 帧 PTS（展示时间戳，秒） |
    | `visibleRect` | `DOMRectReadOnly` | 帧的有效可视区域（相对于 `codedWidth`/`codedHeight`） |

3. VideoSample 完整方法

    | 方法 | 说明 |
    |------|------|
    | `allocationSize()` | 获取帧数据占用的内存大小（字节） |
    | `clone()` | 创建当前 VideoSample 的深拷贝（新对象独立生命周期） |
    | `close()` | 释放帧占用的底层资源（必须调用，否则内存泄漏） |
    | `copyTo()` | 将帧数据复制到指定的 ArrayBuffer/Canvas/ImageBitmap |
    | `draw()` | 将帧绘制到 Canvas 或 OffscreenCanvas |
    | `drawWithFit()` | 将帧按指定的适配模式（contain/cover/stretch）绘制到目标 |
    | `setDuration()` | 修改帧的持续时间（微秒/秒，用于自定义时间戳） |
    | `setRotation()` | 修改帧的旋转角度 |
    | `setTimestamp()` | 修改帧的时间戳（PTS，秒/微秒） |
    | `toCanvasImageSource()` | 转换为可直接用于 Canvas 绘制的 `CanvasImageSource` |
    | `toVideoFrame()` | 转换为 WebCodecs 原生的 `VideoFrame` 对象 |
    | `[Symbol.dispose]()` | 实现 `using` 语法的资源自动释放（与 `close()` 功能一致） |

## 2.5 音频样本

### 2.5.1 使用说明


`AudioSample` 代表**一帧解码后的原始音频采样帧**，是 Mediabunny 音频处理基础单元，封装音频采样数据、格式、时间戳、声道、采样率等全部元数据与操作方法。

1. 核心特点
    1. 同时提供 **秒级 + 微秒级** 两套时间戳，适配精准时序控制；
    2. 原生支持转 Web Audio `AudioBuffer`，无缝对接网页音频开发；
    3. 必须手动 `close()` 或用 `using` 自动释放，否则持续内存泄漏；
    4. 可克隆、可拷贝原始采样数据，支持自定义音频处理、分析、导出。

1. 只读属性

    | 属性 | 类型 | 说明 |
    |------|------|------|
    | `timestamp` | `number` | 时间戳（秒） |
    | `duration` | `number` | 时长（秒） |
    | `microsecondTimestamp` | `number` | 时间戳（微秒，高精度） |
    | `microsecondDuration` | `number` | 时长（微秒，高精度） |
    | `sampleRate` | `number` | 采样率（如 48000） |
    | `channelCount` | `number` | 声道数量 |
    | `sampleFormat` | `AudioSampleFormat` | 采样格式（f32 / s16 等） |
    | `sampleCount` | `number` | 采样点总数量 |

2. 实例方法

    | 方法 | 返回值 | 功能说明 |
    |------|--------|----------|
    | `close()` | `void` | 释放底层内存资源，必须调用 |
    | `[Symbol.dispose]()` | `void` | 自动销毁接口，支持 using 语法 |
    | `clone()` | `AudioSample` | 创建当前采样的完整克隆副本 |
    | `allocationSize()` | `number` | 返回数据占用内存大小（字节） |
    | `copyTo(dest: ArrayBufferView)` | `void` | 将采样数据复制到目标缓冲区 |
    | `toAudioBuffer()` | `AudioBuffer` | 转为 Web Audio 标准 AudioBuffer |
    | `setTimestamp(us: number)` | `void` | 设置微秒级时间戳 |
    | `setDuration(us: number)` | `void` | 设置微秒级时长 |

#### 5. 转换使用

1. 代码示例

    ```html
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="utf-8">
    <title>AudioSample 转换后播放（AudioBuffer + AudioData）</title>

    </head>
    <body>
      <h2>AudioSample 转换后播放</h2>

      <!-- 两个播放按钮 -->
      <button id="playBuffer">▶ 播放 toAudioBuffer()</button>
      <button id="playData">▶ 播放 toAudioData()</button>

      <pre id="log"></pre>

      <script type="module">
        import { AudioSample } from "../../js/mediabunny.1.42.mjs";

        (async () => {
          // 加载音频
          const res = await fetch("../../audio/02.mp3");
          const arrayBuffer = await res.arrayBuffer();
          const actx = new AudioContext();
          const buffer = await actx.decodeAudioData(arrayBuffer);

          // 创建 AudioSample
          const samples = AudioSample.fromAudioBuffer(buffer, 1.0);
          const sample = samples[0];

          // 转换 1：toAudioBuffer()
          const audioBuffer = sample.toAudioBuffer();


          // 转换 2：toAudioData()
          // 注意：必须手动 close()
          const audioData = sample.toAudioData();

          // 播放按钮 1：播放 AudioBuffer
          playBuffer.onclick = () => {
            const src = actx.createBufferSource();
            src.buffer = audioBuffer;
            src.connect(actx.destination);
            src.start();
          };


          // 播放按钮 2：播放 AudioData
          // 步骤：AudioData → AudioBuffer → 播放
          playData.onclick = async () => {
            // 1. 创建新的 AudioBuffer 用于存放 AudioData 数据
            const ab = actx.createBuffer(
              audioData.numberOfChannels,
              audioData.numberOfFrames,
              audioData.sampleRate
            );

            // 2. 把 AudioData 数据复制到 AudioBuffer
            for (let i = 0; i < audioData.numberOfChannels; i++) {
              const data = ab.getChannelData(i);
              await audioData.copyTo(data, { planeIndex: i });
            }

            // 3. 播放
            const src = actx.createBufferSource();
            src.buffer = ab;
            src.connect(actx.destination);
            src.start();
          };

          // 日志输出
          log.textContent = [
            "=== 转换完成 ===",
            "toAudioBuffer() 成功",
            "toAudioData() 成功",
            "",
            "点击按钮即可播放两种格式音频",
            "",
            "⚠ 注意：AudioData 需要手动 close()"
          ].join('\n');

          // 页面关闭时释放资源
          window.onbeforeunload = () => {
            audioData.close();
            sample.close();
          };
        })();
      </script>
    </body>
    </html>
    ```
