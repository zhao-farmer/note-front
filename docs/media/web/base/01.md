# 一、流媒体-图片

## 1.1 html中标签 `<img>` 

### 1.1.1 介绍

1. 基本定义与用法

    `<img>` 标签是 HTML 用于嵌入图像的**空元素（自闭合标签）**，没有结束标签，不需要写 `</img>`。
    通过 `src` 属性指定图片地址，将图像渲染到网页中。

    > 
    > 注意：XHTML 规范要求写成 `<img />`；HTML5 中直接写 `<img>` 即可，斜杠可选。

2. 支持的图像格式

    网页主流支持：**JPEG(JPG)、PNG、GIF、WebP、AVIF、SVG**。

    - JPG：照片，有损压缩，不支持透明
    - PNG：图标素材，无损压缩，支持透明
    - GIF：动态图片，仅支持256色
    - WebP：体积更小，兼顾有损/无损、透明、动画，现代网页优先使用
    - AVIF：新一代图片格式，压缩率优于WebP
    - SVG：矢量图，放大不会模糊

3. 基本语法格式

    ```html
    <img src="图片路径" alt="替代文本">
    ```

### 1.1.2 主要属性

1. src（必选）

    - 作用：指定图片资源地址，可以是**相对路径**或者**绝对URL**。
    - 图片地址错误会显示图片加载失败占位图标。

    **代码示例**

    ```html
    <img src="./images/00.jpg" >
    ```

2. alt（强烈建议必写）

    - 作用：图片加载失败、网络异常时显示的替代文字；同时供屏幕阅读器读屏，提升无障碍访问，利于SEO。
    - 如果图片**纯装饰、无实际语义**，`alt=""` 设置为空字符串，不要省略alt属性。> 
    > 错误：不写 alt
    > 装饰图：`<img src="decorate.png" alt="">`
    > 内容图：`<img src="cat.jpg" alt="一只趴在草地上的橘猫">`

    **代码**

    ```html
    <img src="none.jpg" alt="代替图片出现">
    ```

3. width 和 height

    - 作用：设置图片的显示宽高，单位默认为**像素（px）**，只写数字，不需要写px；也支持百分比。
    - 只设置其中一个，浏览器会**自动按原始图片比例缩放**。
    - 最佳实践：HTML上写原始图片的 `width` / `height` 属性占位，CSS做布局缩放；浏览器会根据属性预留图片占位框，避免页面布局抖动（CLS）。

    > 
    > 误区：不要用HTML属性写百分比做自适应；百分比尺寸交给CSS处理。

    **html属性版本**

    ```html
    <img src="./images/00.jpg" height="200" width="800">
    ```

    **css版本（布局控制）**

    ```html
    <style>
    img{
    max-width: 100%;
    height: auto;
    }
    </style>
    <img src="./images/00.jpg" width="800" height="500">
    ```

4. title

    - 作用：鼠标悬浮在图片上时，弹出提示文本；**对屏幕阅读器无效，不做无障碍替代**。
    - 不建议依赖title传递重要信息，移动端没有鼠标悬浮，title不会显示。

    **代码**

    ```html
    <img src="./images/00.jpg" title="这是一张美女图片">
    ```

5. loading 图片懒加载

    两个取值：`lazy` / `eager`

    1. `lazy` 懒加载

        - 行为：浏览器检测图片即将滚动进入视口才加载图片；首屏外图片延迟请求。
        - 优势：减少首屏网络请求，提升页面加载速度，节省带宽。
        - 限制：**仅对向下滚动的图片生效；首屏图片不要加 lazy**，会拖慢首屏渲染。
        - 兼容性：现代浏览器全部支持；旧浏览器自动忽略该属性，直接立即加载。

    2. `eager`（默认）

        - 行为：页面解析到标签就立刻加载图片。
        - 使用场景：首屏关键图片。

    **完整示例**

    ```html
    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>HTML img loading 属性 lazy 与 eager 示例</title>
        <style>
            body {
                height: 2000px;
                padding: 20px;
            }
            img {
                display: block;
                margin: 20px auto;
                max-width: 100%;
                height: auto;
            }
        </style>
    </head>
    <body>
        <!-- 首屏图片，立即加载 -->
        <img src="./images/00.jpg"  loading="eager">

        <!-- 页面下方图片，开启懒加载 -->
        <img src="./images/005.gif"  loading="lazy">
    </body>
    </html>
    ```

6. srcset 和 sizes 响应式图片

    > 
    > 作用：根据屏幕设备（屏幕分辨率、视口宽度），浏览器自动选择最合适尺寸图片加载，高性能，避免大图在手机上浪费流量。

    1. `srcset`：提供多张图片资源 + 描述符，支持**宽度描述符 w**、**像素密度描述符 x**
    2. `sizes`：配合 `srcset` 的 w 描述符使用，告诉浏览器图片实际显示多大；单位仅支持 px / vw，不支持百分比 `%`。

    > 
    > 注意：
    > 
    > 
    > - 使用 `w` 宽度描述符，**必须写 sizes**；
    > - 使用 `x` 像素密度描述符，不需要 sizes。

    示例1：w + sizes（不同视口加载不同图）

    ```html
    <img srcset="image‑small.jpg 320w,
                image‑medium.jpg 640w,
                image‑large.jpg 1024w"
        sizes="(max‑width: 600px) 480px,
                (max‑width: 1200px) 800px,
                1024px"
        src="image‑default.jpg"
        alt="响应式图片示例">
    ```

    示例2：x 描述符，适配2倍屏、3倍屏

    ```html
    <img src="logo‑1x.png"
        srcset="logo‑1x.png 1x, logo‑2x.png 2x, logo‑3x.png 3x"
        alt="logo">
    ```

7. crossorigin 跨域图片

    当图片来自别的域名，又需要用 `canvas.drawImage()` 获取图片像素时，必须设置，否则会报跨域污染。

    ```html
    <img src="https://xxx.com/a.jpg" crossorigin="anonymous" alt="">
    ```

8. decoding 解码策略

    - `decoding="async"`：异步解码图片，不阻塞主线程渲染，优化性能。

    ```html
    <img src="test.jpg" decoding="async" alt="">
    ```

### 1.1.3 `<picture>` 元素

`<picture>` 不是图片，是图片容器；内部多个 `<source>` 提供不同格式/条件的图片，浏览器匹配成功就加载对应资源，不匹配则回退到内部 `<img>`。

常见场景：**优先加载WebP/AVIF格式，旧浏览器回退jpg**

```html
<picture>
    <!-- 优先avif格式 -->
    <source srcset="photo.avif" type="image/avif">
    <!-- 其次webp -->
    <source srcset="photo.webp" type="image/webp">
    <!-- 降级jpg，img必须写在最后 -->
    <img src="photo.jpg" alt="风景照片">
</picture>
```

> 
>  `<picture>` 里面必须包含一个 `<img>`，放在最后，作为兼容兜底；`<source>` 没有 alt 属性，alt写在img上。

### 1.1.4 文件路径

网页图片资源需要规范管理，一般单独建立 `images` / `assets` 文件夹存放图片。
路径分为**相对路径**、**绝对路径**。

1. 相对路径

    以**当前HTML文件位置**作为参考去找图片。

    | 写法 | 说明 |
    | --- | --- |
    | `./images/a.jpg` | 当前html同级的images文件夹里面图片，`./`代表当前目录，可以省略 |
    | `../images/a.jpg` | 返回上一级目录，再进入images |

    > 
    > `../` 代表向上一层目录，可以多次嵌套 `../../` 向上跳多级目录。

2. 绝对路径

    1. 网络绝对URL：完整http/https地址，例如 `https://xxx.com/img/a.jpg`，不受文件目录位置影响。
    2. 本地磁盘绝对路径（不推荐网页使用），例如 `C:/xxx/a.jpg`，线上服务器完全无法访问，禁止写在网页代码。

    > 
    >  Windows本地路径分隔符是反斜杠 `\`，**网页路径统一使用正斜杠 `/`**，不要使用 `\`，跨平台会失效。

3. 路径易错补充

    - 文件名大小写敏感：Linux服务器 `Images.jpg` 和 `images.jpg` 是两张不同文件，本地Windows不区分大小写，上线容易404。
    - 不要使用中文、空格给图片命名，上线后极易加载失败。


## 1.2 JS中 `image对象`


### 1.2.1 Image 对象

1. 创建 Image 对象

    `Image()` 是浏览器内置构造函数，用于在内存中创建 `HTMLImageElement` 图片DOM对象，等价于 `document.createElement('img')`。
    可以传入两个可选参数 `width`、`height`，设置元素的显示宽高，**不是图片原始像素尺寸**。

    ```js
    // 创建空Image对象
    const img1 = new Image();
    // 创建同时指定显示宽高
    const img2 = new Image(200, 150);

    // 等价写法
    const img3 = document.createElement('img');
    ```

    > 
    > 通过 `new Image()` 创建的对象仅存在内存，不会自动渲染到页面，需要手动插入DOM树才会显示。


2. document.images 获取对象

    `document.images` 返回 **HTMLCollection动态类数组集合**，页面中每一个 `<img>` 标签对应集合内一个Image对象。

    获取页面图片对象三种方式：

    1. `document.images[索引]`：按下标顺序访问
    2. `document.images["name属性值"]`：通过元素name属性访问，属于旧写法，不推荐
    3. `document.getElementById()` / `document.querySelector()`：标准DOM查询方式，项目开发优先使用

    ```html
    <img id="pic1" name="demo" src="test.jpg">
    <img id="pic2" src="test2.jpg">

    <script>
    // 1.按下标索引获取
    const imgA = document.images[0];
    // 2.按name属性获取（旧写法，不推荐）
    const imgB = document.images["demo"];
    // 3.标准DOM查询（推荐）
    const imgC = document.getElementById("pic1");
    const imgD = document.querySelector("#pic2");
    </script>
    ```

    > 
    > 注意：`HTMLCollection` 是动态集合，页面新增、删除`<img>`，集合会自动更新；它不是普通数组，不能直接调用数组方法。

3. 获取DOM对象转成Image对象

    1. 页面上已经存在的`<img>`标签，通过DOM查询拿到的本身就是`HTMLImageElement`（Image对象），不需要额外转换。
    2. `new Image()` 和 `document.createElement('img')` 创建出来的对象类型完全一致。
    3. 不能把其他普通DOM元素强行转为Image对象；只有img类型DOM节点才具备Image对象全部属性与事件。

    ```html
    <img id="pic" src="1.jpg">
    <script>
    // 查询出来直接就是Image对象
    const img = document.querySelector("#pic");
    console.log(img instanceof HTMLImageElement); // true

    // 内存创建Image对象
    const memImg = new Image();
    console.log(memImg instanceof HTMLImageElement); // true
    </script>
    ```

    > 
    > 区分：
    > - `new Image()`：内存新建图片对象，初始不在页面DOM树内。
    > - DOM查询得到的img对象：来自页面已经渲染的`<img>`标签，存在于DOM树。

### 1.2.2 属性相关

> 
> 废弃属性：`border`、`hspace`、`vspace`、`lowsrc` 已经从标准中废弃，边框、内外间距请使用CSS实现。

1. 读写属性

    - `src`：设置或读取图片资源URL；赋值后会立刻发起网络请求加载图片。
    - `alt`：图片替代文本，图片加载失败时展示，同时用于无障碍读屏。
    - `width`：设置/读取图片元素的显示宽度，单位像素。
    - `height`：设置/读取图片元素的显示高度，单位像素。
    - `name`：设置/读取图片元素name属性，现代项目较少使用。
    - `crossOrigin`：跨域配置，取值为 `anonymous`、`use‑credentials`；canvas绘制跨域图片必须配置该属性。
    - `title`：设置/读取图片悬浮提示文字。

    ```js
    const img = new Image();

    img.src = "test.jpg";         // 图片资源地址，赋值立即发起网络请求
    img.alt = "测试图片";          // 图片替代文本
    img.width = 400;              // 显示宽度
    img.height = 300;             // 显示高度
    img.name = "image01";         // name属性
    img.title = "鼠标悬浮提示";     // 悬浮提示文字
    img.crossOrigin = "anonymous";// 跨域设置
    ```


2. 只读属性

    - `naturalWidth`：图片原始真实像素宽度，图片未加载完成时值为0。
    - `naturalHeight`：图片原始真实像素高度，图片未加载完成时值为0。
    - `complete`：布尔值，表示图片加载流程是否走完；加载成功、加载失败都可能为true，不能单独用来判断图片加载成功。
    - `currentSrc`：浏览器实际加载使用的图片地址，配合`srcset`响应式图片时使用。

    
    ```js
    const img = new Image();
    img.src = "test.jpg";

    // 图片原始像素尺寸，加载完成后才有效，未加载为0
    console.log(img.naturalWidth);
    console.log(img.naturalHeight);

    console.log(img.complete);     // 加载流程是否走完；成功失败都可能true
    console.log(img.currentSrc);  // 浏览器实际加载的图片地址，配合srcset使用
    ```

3. 对象方法（继承自HTMLElement）

    - `decode()`：图片解码方法，返回Promise；完成解码之后再将图片插入页面，避免渲染阻塞。
    - `addEventListener()`：绑定事件监听器。
    - `removeEventListener()`：移除事件监听器。

    ```js
    const img = new Image();

    // 图片解码，返回Promise，解码完成再插入页面避免渲染卡顿
    img.decode().then(()=>{
        document.body.appendChild(img);
    });

    // 事件绑定、移除
    img.addEventListener("load",()=>{});
    img.removeEventListener("load",()=>{});
    ```

    > 
    > 重要提示：设置src之前，需要先绑定`load`、`error`事件；图片加载速度极快时，后绑定事件会造成事件丢失。

### 1.2.3 事件相关

Image对象支持图片加载专属事件，同时继承全部DOM鼠标事件。

1. 图片加载事件
    - `load`：图片**成功加载完成**时触发。
    - `error`：图片加载失败触发，404、图片损坏、跨域限制都会触发。
    - `abort`：图片加载被终止时触发。
2. 鼠标交互事件

    - `click`：鼠标单击图片触发。
    - `dblclick`：鼠标双击图片触发。
    - `mouseover`：鼠标移入图片元素触发。
    - `mouseout`：鼠标移出图片元素触发。
    - `mousedown`：鼠标在图片上按下触发。
    - `mouseup`：鼠标按键抬起触发。
    - `mousemove`：鼠标在图片内移动持续触发。

    > 
    > 开发建议：优先使用`addEventListener`进行事件绑定，不推荐行内事件属性写法。

3. 代码示例

    ```js
    const img = new Image();

    // -------- 加载事件 --------
    // 图片加载成功
    img.addEventListener('load', function(){
        console.log("图片加载成功");
    });
    // 图片加载失败：404、损坏、跨域
    img.addEventListener('error', function(){
        console.log("图片加载失败");
    });
    // 加载被终止
    img.addEventListener('abort', function(){
        console.log("图片加载被终止");
    });

    // -------- 鼠标交互事件 --------
    img.addEventListener('click',()=>{});
    img.addEventListener('dblclick',()=>{});
    img.addEventListener('mouseover',()=>{});
    img.addEventListener('mouseout',()=>{});
    img.addEventListener('mousedown',()=>{});
    img.addEventListener('mouseup',()=>{});
    img.addEventListener('mousemove',()=>{});

    // 最后设置src
    img.src = "test.jpg";
    ```
## 1.3 示例代码


- **示例1：基础预加载**

    仅在内存创建图片，让浏览器缓存资源，不渲染页面。

    ```js
    function preloadImages(urls) {
        const list = [];
        urls.forEach(url => {
            const img = new Image();
            img.src = url;
            list.push(img);
        });
        return list;
    }

    const imgs = preloadImages(["1.jpg", "2.jpg", "3.jpg"]);
    // 需要展示时再插入页面
    // document.body.appendChild(imgs[0]);
    ```

- **示例2：Promise封装单张图片加载**

    封装为Promise，支持async/await，获取内存图片对象。

    ```js
    function loadImage(url, crossOrigin) {
        return new Promise((resolve, reject) => {
            const img = new Image();
            if (crossOrigin) img.crossOrigin = crossOrigin;
            img.onload = () => resolve(img);
            img.onerror = e => reject(e);
            img.src = url;
        });
    }

    async function run() {
        try {
            const img = await loadImage("demo.jpg", "anonymous");
            console.log("原图尺寸", img.naturalWidth, img.naturalHeight);
        } catch (err) {
            console.error("加载失败", err);
        }
    }
    run();
    ```

- **示例3：操作页面已有 `<img>` 标签，动态切换图片**

    DOM获取页面上写死的`<img>`元素，修改`src`实现换图。

    ```html
    <!-- HTML页面img标签 -->
    <img id="showImg" src="default.jpg" alt="展示图">
    <button id="changeBtn">切换图片</button>

    <script>
        // 获取页面上的img DOM对象
        const showImg = document.querySelector('#showImg');
        const btn = document.querySelector('#changeBtn');

        btn.addEventListener('click', () => {
            // 修改页面img标签的src属性，更换图片
            showImg.src = "new.jpg";
        });

        // 监听页面img标签自身加载事件
        showImg.addEventListener('load', () => {
            console.log('页面上的img图片加载完成', showImg.naturalWidth);
        });
        showImg.addEventListener('error', () => {
            console.log('页面上的img图片加载出错');
        });
    </script>
    ```

- **示例4：等待多张图片全部加载完成**

    `Promise.all`批量加载，全部成功才返回，任意一张失败直接报错。

    ```js
    async function loadAll(urlList) {
        const tasks = urlList.map(url => loadImage(url));
        return await Promise.all(tasks);
    }

    loadAll(["a.jpg", "b.jpg", "c.jpg"])
    .then(images => {
        console.log("全部加载完毕", images);
    })
    .catch(err => {
        console.error("有图片加载失败", err);
    });
    ```

- **示例5：批量加载，允许个别图片失败**

    `Promise.allSettled`，容错批量加载，过滤拿到成功的图片对象。

    ```js
    async function loadAllSafe(urlList) {
        const tasks = urlList.map(url => loadImage(url));
        const results = await Promise.allSettled(tasks);
        const successImgs = results
            .filter(item => item.status === "fulfilled")
            .map(item => item.value);
        return successImgs;
    }

    loadAllSafe(["1.jpg", "error.jpg", "3.jpg"]).then(list => {
        console.log("加载成功的图片集合", list);
    });
    ```

- **示例6：解码优化，将内存Image对象挂载到页面DOM**


    使用`decode()`解码后，再把图片对象添加进页面，避免大图渲染卡顿。

    ```html
    <div id="imgBox"></div>

    <script>
        async function appendImageToBox(url) {
            const img = new Image();
            img.src = "big.jpg";
            await img.decode();
            // 将内存Image对象添加到页面容器，成为页面里的<img>标签
            document.querySelector('#imgBox').appendChild(img);
        }
        appendImageToBox();
    </script>
    ```

- **示例7：批量操作一组页面 `<img>` 标签**

    获取页面多个`<img>`，循环替换图片地址。

    ```html
    <img class="pic" src="old1.jpg">
    <img class="pic" src="old2.jpg">
    <img class="pic" src="old3.jpg">

    <script>
        // 获取页面上全部class为pic的img标签
        const picList = [...document.querySelectorAll(".pic")];
        picList.forEach((item, idx) => {
            // item就是页面<img>对应的DOM对象
            item.src = `new${idx + 1}.jpg`;
        });
    </script>
    ```

- **示例8：仅获取图片尺寸，不渲染页面**

    不需要插入DOM，仅读取图片原始宽高。

    ```js
    async function getImageSize(url) {
    const img = await loadImage(url);
    return {
        width: img.naturalWidth,
        height: img.naturalHeight
    };
    }

    getImageSize("test.jpg").then(size => {
    console.log("图片原始宽高：", size);
    });
    ```

- **示例9：图片加载超时处理**

    增加超时限制，防止图片请求长时间挂起。

    ```js
    function loadImageWithTimeout(url, timeout = 5000) {
        return Promise.race([
            loadImage(url),
            new Promise((_, reject) => {
                setTimeout(() => reject(new Error("图片加载超时")), timeout);
            })
        ]);
    }

    loadImageWithTimeout("demo.jpg", 3000)
    .then(img => console.log("加载成功"))
    .catch(e => console.error(e.message));
    ```

- **示例10：预加载后赋值给页面 `<img>` 标签**

    先在内存预加载图片，缓存完成之后，再赋值给页面img的src，消除点击时加载延迟。

    ```html
    <img id="targetImg" src="placeholder.jpg">
    <button id="loadBtn">显示预加载图片</button>

    <script>
        async function preloadAndAssign() {
            // 内存预加载
            const preImg = await loadImage("target.jpg");
            // 将预加载完成的图片地址直接赋值给页面img标签
            document.querySelector('#targetImg').src = preImg.src;
        }

        document.querySelector('#loadBtn').addEventListener('click', preloadAndAssign);
    </script>
    ```

## 1.4 注意项

1. 创建与对象类型
    1. `new Image()`、`document.createElement('img')` 创建的是**内存中的 HTMLImageElement 对象**，不会自动出现在页面，必须使用 `appendChild()` 加入DOM树，才会渲染为页面上的 `<img>` 标签。
    2. 通过 `document.querySelector()`、`document.images` 获取到的是页面上已存在的 `<img>` 对应的DOM对象，和 `new Image()` 对象属性、事件完全一样。
    3. 普通div等其他DOM元素**不能转为Image对象**，只有img标签节点才具备 `naturalWidth`、`complete`、`decode()` 等图片专属能力。
2. 加载顺序坑（高频易错）
    1. **必须先绑定 `load / error / abort` 事件，再设置 `src`**。
    如果先写 `img.src = xxx` 再绑定事件，图片加载极快（缓存）时，`load` 事件已经执行完毕，后续绑定的回调永远不会触发。
    2. `naturalWidth`、`naturalHeight` 是**图片原始像素尺寸**，图片未加载完成时值为 `0`；只能在 `load` 事件内部 / await加载完成后读取，赋值src后立刻读取得到0。
    3. `complete === true` **不代表图片加载成功**。图片加载成功、失败、终止，complete都可能为true，不能单独用complete判断是否加载成功，必须配合 `load`、`error` 事件。
3. 跨域相关（Canvas绘图场景重点）
    1. 如果需要把图片绘制到canvas，出现跨域污染：
        - JS端设置 `img.crossOrigin = "anonymous"`
        - **后端必须配置CORS响应头**，只写前端属性，后端不配置依旧跨域报错。
    2. 本地直接打开html文件（`file://`协议），跨域、部分图片加载逻辑会异常，需要开启http服务访问页面。
4. document.images 集合特点
    1. `document.images` 返回的是**动态 HTMLCollection（类数组）**，不是普通数组。页面新增/删除img标签，集合会自动变化。
    2. 不能直接调用数组 `forEach、map`；转为数组写法：`[...document.images]`。
    3. 在循环遍历集合的同时，如果代码新增、删除页面img元素，会出现遍历跳过、漏元素问题。
5. 废弃属性不要使用

    `border`、`hspace`、`vspace`、`lowsrc` 已经标准废弃。边框、内外边距全部改用CSS实现，不要操作这些属性。
6. decode()解码API
    1. `img.decode()` 返回Promise，作用是提前解码图片资源，再把元素加入DOM，避免大图插入瞬间主线程阻塞、页面闪烁卡顿。
    2. decode不能替代 `load` 事件，解码失败会进入reject。
7. 图片路径问题
    1. 图片路径不要使用中文、空格、特殊字符；Linux服务器区分大小写，路径大小写写错直接404。
    2. `src` 是代码设置的地址；`currentSrc` 只读，代表浏览器实际最终加载的图片地址，搭配 `srcset` 响应式图片使用。
8. 事件相关
    1. 优先使用 `addEventListener` 绑定事件；不推荐行内事件如 `onload="xxx()"`。
    2. `error`事件触发场景：404、图片文件损坏、跨域阻止、网络中断。
