# 三、流媒体-视频

## 3.1 视频 `<video>`

## 3.1.1 video 介绍

1. 基本概念

    `video` 元素用于在网页文档中嵌入视频内容。可以通过 `src` 属性直接指定视频资源，也可以内部嵌套一个或多个 `<source>` 标签提供多份视频文件；浏览器会自动选择自身支持的第一个视频资源进行加载播放。也可以接入媒体流实现直播流式视频播放。

    > 
    > 重要浏览器策略：现代浏览器**禁止无用户交互的自动视频播放**，`autoplay` 在没有点击、触摸等用户行为触发时会直接失效。

2. 支持的格式

    - **MP4‑H.264(video/mp4)**：兼容性最强，全平台浏览器通用，网页项目首选格式。
    - **WebM(video/webm)**：开源免费格式，压缩率优秀，Chrome、Firefox支持；部分旧版Safari支持有限，用作降级备选。
    - **OGG‑Theora(video/ogg)**：开源格式，性能一般，现代浏览器已较少使用，不建议作为主资源。
    - **MOV(video/quicktime)**：Safari原生支持，其他浏览器兼容性差，不适合网页直接播放。

    > 
    > 开发建议：主资源提供 mp4，搭配 webm 做降级兼容。

3. 基本语法格式

    ```html
    <video controls src="00.mp4"></video>
    ```

### 3.1.2 常用 HTML 属性

> 
> 布尔属性：写上属性名即代表开启，不需要写属性值；如 `controls`、`loop`，等价于 `controls="controls"`。

1. **src**

    - 作用：指定视频资源的 URL 地址，支持相对路径、网络绝对 URL。
    - 特点：只写 `src` 不会显示播放器UI；需要搭配 `controls` 属性才展示浏览器原生控制面板。
    - 如果使用了`<source>`子标签，`video` 标签上的 `src` 属性会失效。

    **代码示例**

    ```html
    <video src="00.mp4"></video>
    ```

2. **autoplay**

    - 属性类型：布尔属性
    - 作用：页面加载完成后尝试自动播放视频。> 
    > 浏览器限制：**无用户交互时autoplay会被浏览器拦截**。
    > 可行方案：`autoplay + muted` 组合，静音状态允许自动播放；带声音的自动播放几乎全部被浏览器禁用。

    ```html
    <!-- 静音自动播放，有声自动播放会被拦截 -->
    <video autoplay muted src="00.mp4"></video>
    ```

3. **controls**

    - 属性类型：布尔属性
    - 作用：展示浏览器原生视频控制面板，包含播放暂停、进度条、音量、全屏、下载按钮。> 
    > 不同浏览器原生播放器样式各不相同，**无法通过CSS精细修改原生控件**。

    ```html
    <video controls src="00.mp4"></video>
    ```

4. **loop**

    - 属性类型：布尔属性
    - 作用：视频播放结束后自动回到开头循环播放。

    ```html
    <video loop controls src="00.mp4"></video>
    ```

5. **muted**

    - 属性类型：布尔属性
    - 作用：设置视频初始为静音；只控制播放输出音量，**不会修改视频源文件本身**。

    ```html
    <video controls muted src="00.mp4"></video>
    ```

6. **preload**

    - 属性类型：枚举属性，用于设置浏览器预加载策略，仅为浏览器建议，浏览器有权忽略。> 
    > preload 对设置了 autoplay 的视频无效，自动播放视频会强制加载资源。

    属性取值：

    - `auto`：页面加载后尽可能预加载完整视频；适合大概率用户会点击播放的视频，消耗较多带宽。
    - `metadata`：只预加载视频元信息：时长、分辨率等基础信息，不下载视频二进制数据；视频文件较大时推荐使用。
    - `none`：完全不预加载；直到用户点击播放才发起网络请求；节省流量，首次点击会有加载等待。

    ```html
    <video controls preload="metadata" src="00.mp4"></video>
    ```

7. **crossorigin**

    - 作用：处理跨域视频资源；当视频来自外部域名，需要画布绘制、截图场景时，需要配置该属性，避免资源跨域限制。

    ```html
    <video controls crossorigin="anonymous" src="demo.mp4"></video>
    ```

8. **poster**

    - 属性类型：普通属性
    - 作用：视频未播放时显示的封面图片地址，视频开始播放后封面自动消失。

    ```html
    <video controls poster="cover.jpg" src="00.mp4"></video>
    ```

9. **width / height**

    - 属性类型：普通属性
    - 作用：设置视频元素显示宽高，只控制布局尺寸，不会改变视频原始分辨率；建议优先使用CSS控制。

    ```html
    <video controls width="640" height="360" src="00.mp4"></video>
    ```

10. **playsinline**

    - 属性类型：布尔属性
    - 作用：移动端Safari中，禁止视频自动进入全屏，实现页面内inline内联播放，H5播放视频必备属性。

    ```html
    <video controls playsinline src="00.mp4"></video>
    ```

### 3.1.3 结合 `<source>` 使用多格式兼容

`<source>` 作为 video 的子标签，用来提供多份不同编码视频，浏览器从上往下匹配，加载第一个自己支持的资源。

source 标签属性

- src：视频文件路径，必填。
- type：视频 MIME 类型，建议写上，帮助浏览器快速判断格式是否支持，不用发起网络请求试探。

> 
> 视频场景下 `sizes`、`srcset` 只用于图片，`<source>` 不要书写这两个属性。
> video 标签内部的普通文本，作为老旧浏览器不支持 video 标签时的降级提示文案。

```html
<video controls preload="metadata" playsinline poster="cover.jpg">
    <!-- 优先尝试 MP4，兼容性最好 -->
    <source src="video.mp4" type="video/mp4">
    <!-- 备选 WebM，支持 Firefox/Chrome -->
    <source src="video.webm" type="video/webm">

    <!-- 回退内容：当浏览器完全不支持 <video> 标签时显示 -->
    <p>您的浏览器不支持视频元素。请 <a href="video.mp4">点击下载</a> 观看。</p>
</video>
```

## 3.2 JS中video对象

### 3.2.1 Video 对象

1. 创建 Video 对象
    `Video()` 浏览器没有直接的 `new Video()` 构造函数，使用 `new Audio()` 仅用于音频；视频使用 `document.createElement('video')` 在内存创建 `HTMLVideoElement` 视频DOM对象。

    ```js
    // 创建空video对象（内存中，不在页面）
    const video1 = document.createElement('video');
    ```

    > 
    > 通过 `createElement('video')` 创建的对象仅存在内存，不会自动渲染到页面，需要手动插入DOM树才会显示。

2.  获取对象

    ```html
    <video id="vid1" src="test.mp4"></video>
    <video id="vid2" src="test2.mp4"></video>
    <script>
        // 1.按下标索引获取
        const vidA = document.getElementsByTagName('video')[0];
        // 2.标准DOM查询（推荐）
        const vidB = document.getElementById("vid1");
        const vidC = document.querySelector("#vid2");
    </script>
    ```
> 
> 区分：
> 
> - `document.createElement('video')`：内存新建视频对象，初始不在页面DOM树内。
> - DOM查询得到的video对象：来自页面已经渲染的`<video>`标签，存在于DOM树。

### 3.2.2 属性相关

> 
> video继承HTMLMediaElement媒体基类，大量属性和audio共用。

1. 读写属性

    - `src`：设置或读取视频资源URL；赋值后会立刻发起网络请求加载视频。
    - `width`：设置/读取视频元素的显示宽度，单位像素。
    - `height`：设置/读取视频元素的显示高度，单位像素。
    - `poster`：设置/读取视频封面图片地址，未播放阶段展示。
    - `controls`：布尔，是否显示浏览器原生播放控件。
    - `loop`：布尔，是否循环播放。
    - `muted`：布尔，是否静音。
    - `autoplay`：布尔，是否自动播放，受浏览器交互策略限制。
    - `preload`：预加载策略，可选 `auto` / `metadata` / `none`。
    - `crossOrigin`：跨域配置，取值为 `anonymous`、`use‑credentials`；canvas捕获视频画面必须配置该属性。
    - `playsinline`：布尔，移动端Safari内联播放，禁止自动全屏。
    - `currentTime`：读写，当前播放时间，单位秒。
    - `volume`：读写，音量，范围0‑1。
    - `playbackRate`：读写，播放倍速。

    ```js
    const video = document.createElement('video');
    video.src = "test.mp4";             // 视频资源地址，赋值立即发起网络请求
    video.poster = "cover.jpg";          // 封面图
    video.width = 640;                   // 显示宽度
    video.height = 360;                  // 显示高度
    video.controls = true;               // 显示原生控件
    video.loop = false;                  // 循环播放
    video.muted = false;                 // 静音
    video.preload = "metadata";          // 预加载策略
    video.crossOrigin = "anonymous";     // 跨域设置
    video.playsinline = true;            // 移动端内联播放
    video.currentTime = 0;               // 当前播放时间
    video.volume = 0.8;                  // 音量
    video.playbackRate = 1.0;            // 播放倍速
    ```

2. 只读属性

    - `videoWidth`：视频原始真实像素宽度，视频元数据未加载完成时值为0。
    - `videoHeight`：视频原始真实像素高度，视频元数据未加载完成时值为0。
    - `duration`：总时长，单位秒；未加载元数据为`NaN`。
    - `paused`：布尔，是否处于暂停状态。
    - `ended`：布尔，是否播放完毕。
    - `currentSrc`：浏览器实际加载使用的视频地址。
    - `buffered`：TimeRanges 对象，已缓冲的时间区间。
    - `seekable`：TimeRanges 对象，可跳转的时间区间。
    - `readyState`：媒体就绪状态。
    - `networkState`：网络加载状态。
    - `error`：加载错误对象。

    ```js
    const video = document.createElement('video');
    video.src = "test.mp4";
    // 视频原始像素尺寸，元数据加载完成后才有效，未加载为0
    console.log(video.videoWidth);
    console.log(video.videoHeight);
    console.log(video.duration);      // 总时长，未加载元数据为NaN
    console.log(video.paused);        // 是否暂停
    console.log(video.ended);         // 是否播放结束
    console.log(video.currentSrc);    // 浏览器实际加载的视频地址
    ```

3. 对象方法（继承自HTMLMediaElement、HTMLElement）

    - `play()`：开始播放，返回Promise；无用户交互会reject。
    - `pause()`：暂停播放。
    - `load()`：重新加载媒体资源，切换src后调用。
    - `canPlayType(type)`：检测浏览器是否支持该MIME视频格式。
    - `addEventListener()`：绑定事件监听器。
    - `removeEventListener()`：移除事件监听器。

    ```js
    const video = document.createElement('video');

    // 播放，捕获浏览器拦截异常
    video.play().catch(err=>{
        console.error("播放被拦截", err);
    });
    video.pause();
    video.load();
    console.log(video.canPlayType('video/mp4'));

    // 事件绑定、移除
    video.addEventListener("loadedmetadata",()=>{});
    video.removeEventListener("loadedmetadata",()=>{});
    ```

### 3.2.3 事件相关

Video对象继承媒体全部生命周期事件，同时继承全部DOM鼠标事件。

1. 媒体加载生命周期事件

    - `loadstart`：开始请求媒体资源。
    - `progress`：正在下载数据。
    - `durationchange`：总时长发生改变。
    - `loadedmetadata`：元数据加载完成，可读取videoWidth/videoHeight/duration。
    - `loadeddata`：首帧视频数据加载完成。
    - `canplay`：可以开始播放，但可能缓冲卡顿。
    - `canplaythrough`：全部缓冲完成，可以流畅播完整段视频。
    - `error`：视频加载失败触发，404、文件损坏、跨域限制都会触发。

2. 播放运行时事件

    - `play`：执行play()，即将开始播放。
    - `playing`：真正进入播放状态。
    - `pause`：视频暂停。
    - `ended`：视频播放结束。
    - `timeupdate`：播放位置更新，高频触发。
    - `waiting`：缓冲不足，播放等待。
    - `volumechange`：音量/静音发生变化。
    - `ratechange`：播放倍速发生改变。
    - `seekstart`：开始跳转时间。
    - `seeked`：跳转完成。

3. 鼠标交互事件

    - `click`：鼠标单击视频触发。
    - `dblclick`：鼠标双击视频触发。
    - `mouseover`：鼠标移入视频元素触发。
    - `mouseout`：鼠标移出视频元素触发。
    - `mousedown`：鼠标在视频上按下触发。
    - `mouseup`：鼠标按键抬起触发。
    - `mousemove`：鼠标在视频内移动持续触发。


4. 代码示例

    ```js
    const video = document.createElement('video');
    // -------- 加载事件 --------
    video.addEventListener('loadstart', function(){
        console.log("开始请求视频资源");
    });
    video.addEventListener('loadedmetadata', function(){
        console.log("元数据加载完成，宽：", video.videoWidth, "高：", video.videoHeight);
    });
    video.addEventListener('canplay', function(){
        console.log("可以开始播放");
    });
    video.addEventListener('error', function(){
        console.log("视频加载失败");
    });

    // -------- 运行时播放事件 --------
    video.addEventListener('timeupdate', function(){
        console.log("当前时间", video.currentTime);
    });
    video.addEventListener('ended', function(){
        console.log("视频播放结束");
    });

    // -------- 鼠标交互事件 --------
    video.addEventListener('click',()=>{});
    video.addEventListener('dblclick',()=>{});
    video.addEventListener('mouseover',()=>{});
    video.addEventListener('mouseout',()=>{});

    // 最后设置src
    video.src = "test.mp4";
    ```

> 
> 开发建议：优先使用`addEventListener`进行事件绑定，不推荐行内事件属性写法。设置`src`之前，需要先绑定媒体事件；资源加载极快时，后绑定事件会造成事件丢失。


## 3.3 常用示例

- **示例1：基础播放控制**

    ```html
    <button id="playBtn">播放</button>
    <button id="pauseBtn">暂停</button>
    <button id="resetBtn">回到开头</button>

    <script>
    const video = document.createElement('video');
    video.src = "demo.mp4";

    document.querySelector('#playBtn').onclick = () => {
      video.play().catch(err => console.log(err));
    };
    document.querySelector('#pauseBtn').onclick = () => {
      video.pause();
    };
    document.querySelector('#resetBtn').onclick = () => {
      video.currentTime = 0;
    };
    </script>
    ```

- **示例2：操作页面已存在video标签，调节音量**

    ```html
    <video id="player" src="demo.mp4"></video>
    <button id="volUp">音量+</button>
    <button id="volDown">音量-</button>

    <script>
    const player = document.querySelector("#player");

    document.querySelector("#volUp").onclick = () => {
      player.volume = Math.min(1, player.volume + 0.1);
    };
    document.querySelector("#volDown").onclick = () => {
      player.volume = Math.max(0, player.volume - 0.1);
    };
    </script>
    ```

- **示例3：监听播放结束，手动循环播放**

    ```html
    <script>
    const video = document.createElement('video');
    video.src = "demo.mp4";

    video.addEventListener("ended", () => {
      console.log("播放完毕，重新播放");
      video.currentTime = 0;
      video.play();
    });
    </script>
    ```

- **示例4：Promise封装，等待元数据加载完成获取视频宽高、时长**

    ```js
    function loadVideo(url) {
      return new Promise((resolve, reject) => {
        const video = document.createElement('video');
        video.preload = "metadata";
        video.addEventListener("loadedmetadata", () => resolve(video));
        video.addEventListener("error", err => reject(err));
        video.src = url;
      });
    }

    async function getVideoInfo() {
      try {
        const video = await loadVideo("demo.mp4");
        console.log("视频总时长：", video.duration);
        console.log("原始宽高：", video.videoWidth, video.videoHeight);
      } catch (e) {
        console.error("视频加载失败", e);
      }
    }
    getVideoInfo();
    ```

- **示例5：timeupdate监听实时播放进度**

    ```html
    <div>当前时间：<span id="timeText">0</span></div>

    <script>
    const video = document.createElement('video');
    video.src = "demo.mp4";
    const timeText = document.querySelector("#timeText");

    video.addEventListener("timeupdate", () => {
      timeText.innerText = video.currentTime.toFixed(1);
    });
    </script>
    ```

- **示例6：切换视频资源**

    ```html
    <button data-src="a.mp4">播放视频A</button>
    <button data-src="b.mp4">播放视频B</button>

    <script>
    const video = document.createElement('video');

    document.querySelectorAll("button").forEach(btn => {
      btn.onclick = function () {
        const src = this.dataset.src;
        video.pause();
        video.src = src;
        video.load();
        video.play().catch(e => console.log(e));
      };
    });
    </script>
    ```

- **示例7：设置播放倍速**

    ```html
    <button id="speed1">1倍速</button>
    <button id="speed2">2倍速</button>
    <button id="speed05">0.5倍速</button>

    <script>
    const video = document.createElement('video');
    video.src = "demo.mp4";

    document.querySelector("#speed1").onclick = () => video.playbackRate = 1;
    document.querySelector("#speed2").onclick = () => video.playbackRate = 2;
    document.querySelector("#speed05").onclick = () => video.playbackRate = 0.5;
    </script>
    ```

- **示例8：检测浏览器是否支持视频格式**

    ```js
    const video = document.createElement('video');
    console.log(video.canPlayType('video/mp4'));
    console.log(video.canPlayType('video/webm'));
    console.log(video.canPlayType('video/ogg'));
    ```

- **示例9：监听缓冲进度**

    ```html
    <script>
    const video = document.createElement('video');
    video.src = "demo.mp4";

    video.addEventListener("progress", () => {
      if(video.buffered.length > 0) {
        const bufferedEnd = video.buffered.end(video.buffered.length - 1);
        console.log("已缓冲到：", bufferedEnd);
      }
    });
    </script>
    ```

- **示例10：内存创建video对象挂载到页面，显示原生控件**

    ```html
    <div id="videoBox"></div>
    <script>
        const video = document.createElement('video');
        video.src = "demo.mp4";
        video.controls = true;
        video.playsinline = true;
        document.querySelector("#videoBox").appendChild(video);
    </script>
    ```

## 3.4 注意事项

1. 浏览器播放策略
    1. 自动播放限制：有声自动播放必须由用户点击、触摸等交互行为触发；`autoplay` 不带 `muted` 会直接被浏览器拦截。只有 `autoplay + muted` 静音组合可以实现页面加载自动播放。
    2. 移动端 Safari 必须设置 `playsinline`，否则视频会直接拉起系统全屏播放器，无法在页面内播放。
2. 视频格式与编码
    1. 网页优先使用 **H.264编码的MP4**，全平台兼容性最好；WebM 作为降级备选，不要把 ogg‑theora 作为主资源。
    2. 后缀名不等于编码格式，`.mp4` 文件如果编码不是 H.264，浏览器依然无法播放。
    3. 不要直接上传原始录制的大体积视频，需要做压缩转码，避免加载慢、占用带宽高。
3. DOM与内存对象
    1. `document.createElement('video')` 创建的视频对象只存在内存，**不会自动加入页面**，需要 `appendChild` 挂载到DOM树才会渲染。
    2. 切换视频资源时，建议先 `pause()`，再修改 `src`，调用 `load()`，再执行播放，防止出现播放异常。
    3. 视频销毁前调用 `pause()`，将 `src` 设置为空字符串，释放解码资源，避免内存占用持续上涨。
4. 属性读取时机
    1. `videoWidth`、`videoHeight`、`duration` 需要等待 `loadedmetadata` 事件触发后才有有效值，未加载元数据时分别为 `0`、`0`、`NaN`，不能在设置`src`后立即读取。
    2. `buffered`、`seekable` 是 `TimeRanges` 对象，不是普通数组，只能通过 `.length`、`.start(index)`、`.end(index)` 访问缓冲区间。
5. 事件相关
    1. 设置 `src` **之前绑定 load / error / loadedmetadata 等媒体事件**，视频加载速度很快时，后绑定会直接丢失事件回调。
    2. `play()` 返回 Promise，一定要捕获异常；播放被浏览器策略拦截、资源异常时会进入 reject。
    3. `timeupdate` 属于高频触发事件，回调内部不要执行大量同步耗时逻辑，避免页面卡顿。
6. 跨域场景
    1. 使用 `canvas` 绘制视频画面、截图时，视频资源必须配置 `crossOrigin="anonymous"`，同时服务端配置对应跨域响应头，否则会抛出跨域污染画布错误。
    2. 同域名下不需要设置 `crossOrigin`。
7. preload 预加载
    1. `preload` 只是给浏览器的建议，浏览器可以忽略该配置。
    2. 设置了 `autoplay` 的视频，`preload` 属性会失效，浏览器会强制加载资源。
    3. 大视频建议使用 `preload="metadata"`，仅加载元数据，减少流量消耗。
8. 原生控件

    1. 浏览器自带 `controls` 原生播放器控件，不同浏览器样式不一致，**无法使用CSS精细修改内部播放按钮、进度条、音量条**，需要自定义播放器就不要开启`controls`，自己实现UI。
