# 二、视频处理

## 2.1 功能介绍

### 2.1.1 `EncodedVideoChunk`

**压缩编码后的视频码流分片（压缩数据）**

1. 含义：一帧画面经过 H.264/H.265/AV1 压缩之后的二进制数据块，附带元数据：
	- `timestamp`：PTS 显示时间戳（微秒）；
	- `duration`：帧持续时长；
	- `type`：`key` 关键帧 / `delta` 差值帧；
2. 来源：
	- 解码链路：MP4/FLV 解封装器（你的 Mediabunny）提取出来；
	- 编码链路：`VideoEncoder` 编码输出；
3. 唯一用途：送入 `VideoDecoder.decode()` 解码，或是本地封装写入 MP4。


4. 构造参数

	```ts
	interface EncodedVideoChunkInit {
		timestamp: number;    // PTS 显示时间戳，单位：微秒 μs
		duration?: number;    // 帧时长，微秒
		type: 'key' | 'delta';// key=关键帧(I帧)，delta=普通帧(P/B帧)
		data: ArrayBuffer;    // 帧二进制码流
	}
	```

5. 使用示例

	```js
	// 方式1：从 Mediabunny EncodedPacket 直接生成
	const sink = new EncodedPacketSink(videoTrack);
	for await (const pkt of sink.packets()) {
		const chunk = pkt.toEncodedVideoChunk();
		console.log('时间戳', chunk.timestamp, '是否关键帧', chunk.type);
		decoder.decode(chunk); // 送入解码器
	}

	// 方式2：手动构造（极少场景使用）
	const buffer = new Uint8Array([0x00,0x00,0x01,...]).buffer;
	const chunk = new EncodedVideoChunk({
		timestamp: 0,
		type: "key",
		data: buffer
	});
	```


### 2.1.2 `VideoDecoder`

**视频解码器：压缩码流 → 原始裸画面帧**

1. 功能：硬件优先解码，把 `EncodedVideoChunk` 解压成可渲染的原始画面 `VideoFrame`；
2. 工作流程：
   1. `configure(VideoDecoderConfig)` 初始化（指定 codec、分辨率、`description`=SPS/PPS）；
   2. 循环调用 `decode(EncodedVideoChunk)` 喂压缩包；
   3. 解码成功触发 `output(frame)` 回调吐出 `VideoFrame`；
3. 你之前报错根源：`configure` 缺失 `description`（AVC 的 SPS/PPS），解码器无法初始化上下文，收到关键帧也无法解析。


4. 构造 & 配置参数

	```ts
	// 构造回调
	interface VideoDecoderInit {
	output: (frame: VideoFrame) => void; // 解码成功输出原始画面
	error: (err: DOMException) => void;  // 解码异常回调
	}

	// 初始化配置 VideoDecoderConfig
	interface VideoDecoderConfig {
	codec: string;                 // 编码标识，例 avc1.64001f、hev1.1.6.L93.B0
	description?: ArrayBuffer;     // 重点：AVCC格式SPS+PPS二进制（MP4必备）
	codedWidth?: number;
	codedHeight?: number;
	displayAspectWidth?: number;
	displayAspectHeight?: number;
	}
	```
5. 完整使用示例

	```js
	// 1. 创建解码器
	const decoder = new VideoDecoder({
		output(frame) {
			// 解码输出原始画面帧
			ctx.drawImage(frame, 0, 0);
			frame.close(); // ⚠️必须释放，防止内存暴涨
		},
		error(err) {
			console.error('解码失败：', err);
		}
	});

	// 2. 获取配置（Mediabunny 自动携带SPS/PPS到description）
	const decoderConfig = await videoTrack.getDecoderConfig();

	// 校验浏览器是否支持该编码配置
	const { supported } = await VideoDecoder.isConfigSupported(decoderConfig);
	if (!supported) throw new Error("编码不支持");

	// 3. 初始化解码器（SPS/PPS在此载入）
	decoder.configure(decoderConfig);

	// 4. 送入压缩数据包解码
	decoder.decode(chunk);

	// 播放结束，清空队列
	await decoder.flush();
	decoder.close();
	```
	> 关键知识点：`decoder.configure()` 阶段读取 `description` 内SPS/PPS，缺失则解码报错。


### 2.1.3 `VideoEncoder`

**视频编码器：原始画面帧 → 压缩码流**

1. 和 `VideoDecoder` 逆向：

	1. 接收原始 `VideoFrame`；
	2. 按配置（码率、分辨率、H.264/AV1）压缩；
	3. 回调输出 `EncodedVideoChunk`；

	适用场景：浏览器录屏、实时推流、画面二次编码封装。

2. 参数定义

	```ts
	interface VideoEncoderInit {
		output: (chunk: EncodedVideoChunk, metadata?: EncodedVideoChunkMetadata) => void;
		error: (err: DOMException) => void;
	}

	interface VideoEncoderConfig {
		codec: string;                  // avc1.42001E
		width: number;
		height: number;
		bitrate: number;                // 比特率 bps
		framerate: number;              // 帧率
		latencyMode?: "quality" | "realtime";
	}
	```
2. 使用示例

	```js
	// 创建编码器
	const encoder = new VideoEncoder({
		output(chunk) {
			// 编码完成输出压缩块，可以封装MP4
			console.log('生成编码帧', chunk.timestamp);
		},
		error(err) {
			console.error(err);
		}
	});

	// 编码器配置
	const encoderConfig = {
		codec: "avc1.42001E",
		width: 720,
		height: 1280,
		bitrate: 2_000_000,
		framerate: 24
	};
	const { supported } = await VideoEncoder.isConfigSupported(encoderConfig);
	encoder.configure(encoderConfig);

	// 送入原始画面帧编码
	// frame 来源：VideoDecoder output 或者 canvas生成
	encoder.encode(frame);

	// 结束编码
	await encoder.flush();
	encoder.close();
	```

### 2.1.4 `VideoFrame`

**未压缩的原始图像帧（裸画面）**

1. 本质：解码后可以直接渲染的像素数据（YUV/RGB），携带画面尺寸、时间戳、色彩信息；
2. 来源：
   - `VideoDecoder` 解码产出；
   - 画布/摄像头/Canvas 手动构造新建；
3. 去向：
   - 绘制到 Canvas / WebGL 页面展示；
   - 送入 `VideoEncoder` 做编码压缩；
4. 重要：使用完必须调用 `.close()` 释放显存内存，否则内存泄漏。

5. 常用构造方式

	```ts
	// 常用属性
	frame.timestamp;    // PTS μs
	frame.codedWidth;
	frame.codedHeight;
	frame.displayWidth;
	frame.displayHeight;
	frame.colorSpace;   // VideoColorSpace 对象
	```
6.  使用示例

	```js
	// 场景1：解码器输出获取（你当前播放流程）
	const decoder = new VideoDecoder({
		output(frame) {
			// 绘制到画布
			ctx.drawImage(frame, 0, 0);
			
			// 读取色彩信息
			console.log(frame.colorSpace.primaries);
			
			// 如果需要二次编码，可以直接送入VideoEncoder
			// encoder.encode(frame);

			frame.close(); // 强制释放显存！
		}
	});

	// 场景2：从Canvas手动创建VideoFrame
	const frame = new VideoFrame(canvas, {
		timestamp: performance.now() * 1000
	});
	encoder.encode(frame);
	frame.close();
	```


### 2.1.5 `VideoColorSpace`

**视频色彩空间描述对象，依附于 VideoFrame**

1. 作用：定义这一帧画面的色彩标准：色域、位深、转换矩阵、传输函数（BT.709、sRGB、BT.2020 等）；
2. 挂载位置：每个 `VideoFrame.colorSpace` 自带该实例；
3. 业务影响：
	- 播放器：正确色彩还原，避免画面偏色、过亮/发灰；
	- 编码器：告诉 `VideoEncoder` 该按何种色彩标准编码；
4. 注意：日常播放普通 MP4 一般不用手动配置，解码器会自动继承流自带色彩信息。

5. 参数定义

	```ts
	interface VideoColorSpaceInit {
		primaries?: PredefinedColorSpacePrimaries;      // 色域 BT.709 / BT.2020
		transfer?: PredefinedColorSpaceTransfer;         // 电光转换函数
		matrix?: PredefinedColorSpaceMatrix;             // YUV→RGB转换矩阵
		fullRange?: boolean;                             // 是否全范围YUV
	}
	```

6. 使用示例

	```js
	const decoder = new VideoDecoder({
		output(frame) {
			// 读取帧自带色彩空间
			const cs = frame.colorSpace;
			console.log({
				primaries: cs.primaries,
				transfer: cs.transfer,
				matrix: cs.matrix,
				fullRange: cs.fullRange
			});
			
			frame.close();
		}
	});

	// 手动创建色彩空间对象（编码时指定）
	const colorSpace = new VideoColorSpace({
		primaries: "bt709",
		transfer: "bt709",
		matrix: "bt709",
		fullRange: false
	});
	```

### 2.1.6 `SPS / PPS`

1. SPS（序列参数集）——整个视频流共用一份

	存放整条视频序列全局信息：
	
	- 视频分辨率（宽、高）
	- 帧率、参考帧最大数量
	- 色度格式（YUV420等）
	- 位深、profile/level（avc1.64001f 这类参数来源）
	- 帧裁剪参数

  	**生命周期：整条视频有效**，一般在视频开头出现一次。

2. PPS（图像参数集）——每一帧图像引用

	存放单帧编码相关参数：
	- 熵编码模式（CAVLC/CABAC）
	- 量化参数范围
	- 分片模式等帧级编码配置

	视频里可以共用同一个PPS，也可以切换。

3. 核心工作机制（非常关键）
	H.264 的**I帧/P帧（关键帧、普通帧）本身不携带分辨率、编码配置**！

	画面数据包只包含像素差值信息，**必须依靠 SPS+PPS 才能解码**。

	流程：
	
	1. 解码器先读取 SPS+PPS → 知道画面尺寸、编码规则；
	2. 之后收到 I/P帧数据，才能正确还原图像；

	> `VideoDecoderConfig.description` = **二进制 SPS+PPS（AVCC格式）**
	> 如果 `description` 为空，解码器没有说明书，即便送入I帧也无法初始化，抛出报错。

4. `VideoDecoderConfig.description` = AVCC封装下的 SPS+PPS 二进制数据

	```js
	const decoderConfig = await videoTrack.getDecoderConfig();
	if (decoderConfig.description) {
		const uint8 = new Uint8Array(decoderConfig.description);
		console.log('SPS+PPS二进制长度：', uint8.length);
		// 这段二进制就是MP4 avcC box内存储的参数集
	}
	```

## 2.2 链路流程

- 链路1：视频解码播放

	```
	MP4文件 → Mediabunny解封装
			↓
	EncodedVideoChunk（压缩帧）
			↓送入
	VideoDecoder（配置包含SPS/PPS）
			↓解码输出
	VideoFrame（原始画面）
		├─ frame.colorSpace → VideoColorSpace
		└─ 绘制到Canvas展示 → frame.close()释放
	```

- 链路2：画面采集编码

	```
	Canvas/摄像头 → 生成VideoFrame
		├─ frame.colorSpace（VideoColorSpace）
		↓送入
	VideoEncoder
		↓编码输出
	EncodedVideoChunk
		↓送入MP4Box/Mediabunny封装 → 输出MP4文件
	```

- 从属关系

	1. `EncodedVideoChunk`：压缩层数据；
	2. `VideoDecoder` / `VideoEncoder`：中间处理器，双向转换「压缩块」↔「原始帧」；
	3. `VideoFrame`：未压缩画面载体；
	4. `VideoColorSpace`：**VideoFrame 的附属属性**，只用来描述这一帧的色彩规则，不参与编解码数据流转。

### 2.3.2 视频编码流程

![](/media/webcodecs/base/001.png)

将原始视频帧编码为指定格式的字节流，适用于录制、传输等场景。

- 步骤 1：创建 VideoFrame（3 种方式）

    `VideoFrame` 是视频处理的核心，可从多种来源创建：
    ```javascript
    // 方式 1：从 Canvas/ImageBitmap/VideoElement 创建
    const canvas = document.getElementById('source-canvas');
    const frame1 = new VideoFrame(canvas, {
      timestamp: performance.now() * 1000 // 必须！单位：微秒
    });

    // 方式 2：从摄像头/麦克风流提取
    const stream = await navigator.mediaDevices.getUserMedia({ video: true });
    const track = stream.getVideoTracks()[0];
    const processor = new MediaStreamTrackProcessor(track);
    const reader = processor.readable.getReader();
    const { value: frame2 } = await reader.read();

    // 方式 3：从原始像素数据创建
    const data = new Uint8Array(640 * 480 * 4); // RGBA 格式
    const frame3 = new VideoFrame(data, {
      timestamp: 0,
      codedWidth: 640,
      codedHeight: 480,
      format: 'RGBA'
    });
    ```

- 步骤 2：配置并初始化编码器

    ```javascript
    // 检查配置是否支持
    const config = {
      codec: 'avc1.42001e', // H.264 Baseline Profile Level 3.0
      width: 640,
      height: 480,
      bitrate: 2_000_000, // 2 Mbps
      framerate: 30,
      latencyMode: 'realtime' // 低延迟模式（适合视频会议）
    };

    const { supported } = await VideoEncoder.isConfigSupported(config);
    if (!supported) {
      throw new Error('不支持该编码配置');
    }

    // 创建编码器
    const encoder = new VideoEncoder({
      output: (chunk, metadata) => {
        // 处理编码后的块：发送到服务器或保存到文件
        const chunkData = new Uint8Array(chunk.byteLength);
        chunk.copyTo(chunkData);

        // 如果有解码器配置（如 H.264 的 SPS/PPS），需要单独发送
        if (metadata.decoderConfig) {
          sendDecoderConfig(metadata.decoderConfig);
        }
        sendEncodedChunk(chunk);
      },
      error: (e) => console.error('编码错误:', e)
    });

    encoder.configure(config);
    ```

- 步骤 3：编码帧并管理队列

    ```javascript
    let frameCounter = 0;

    async function encodeLoop() {
      while (true) {
        const { value: frame, done } = await reader.read();
        if (done) break;

        // 控制编码队列大小，避免内存溢出
        if (encoder.encodeQueueSize > 2) {
          frame.close(); // 必须释放！
          continue;
        }

        // 每 150 帧生成一个关键帧
        const keyFrame = frameCounter % 150 === 0;
        encoder.encode(frame, { keyFrame });
        frame.close(); // 编码后立即释放输入帧
        frameCounter++;
      }

      // 等待所有编码任务完成
      await encoder.flush();
      encoder.close();
    }

    encodeLoop();
    ```

### 2.3.3 视频解码流程

![](/media/webcodecs/base/002.png)

将编码后的字节流解码为原始视频帧并渲染，适用于播放、处理等场景。

- 步骤 1：配置并初始化解码器

    ```javascript
    const decoderConfig = {
      codec: 'avc1.42001e',
      codedWidth: 640,
      codedHeight: 480,
      // H.264 需要 AVCC 格式的描述数据（来自编码器的 metadata.decoderConfig）
      description: decoderConfigData
    };

    const { supported } = await VideoDecoder.isConfigSupported(decoderConfig);
    if (!supported) {
      throw new Error('不支持该解码配置');
    }

    // 待渲染的帧队列
    const pendingFrames = [];
    let baseTime = 0;

    const decoder = new VideoDecoder({
      output: (frame) => {
        // 将解码后的帧加入渲染队列
        pendingFrames.push(frame);
        if (pendingFrames.length === 1) {
          renderFrame();
        }
      },
      error: (e) => console.error('解码错误:', e)
    });

    decoder.configure(decoderConfig);
    ```

- 步骤 2：喂入编码块并解码

    ```javascript
    // 从服务器下载编码块
    const chunks = await downloadEncodedChunks();

    for (const chunkData of chunks) {
      const chunk = new EncodedVideoChunk({
        timestamp: chunkData.timestamp, // 微秒
        type: chunkData.isKeyFrame ? 'key' : 'delta',
        data: chunkData.data
      });
    
      decoder.decode(chunk);
    }

    // 等待所有解码任务完成
    await decoder.flush();
    decoder.close();
    ```

- 步骤 3：按时间戳渲染帧

    ```javascript
    const canvas = document.getElementById('render-canvas');
    const ctx = canvas.getContext('2d');

    async function renderFrame() {
      if (pendingFrames.length === 0) return;

      const frame = pendingFrames.shift();
    
      // 计算需要等待的时间，确保播放速度正确
      if (baseTime === 0) baseTime = performance.now();
      const mediaTime = performance.now() - baseTime;
      const waitTime = Math.max(0, frame.timestamp / 1000 - mediaTime);
    
      await new Promise(resolve => setTimeout(resolve, waitTime));
    
      // 渲染帧
      ctx.drawImage(frame, 0, 0);
      frame.close(); // 渲染后立即释放帧内存
    
      // 继续渲染下一帧
      if (pendingFrames.length > 0) {
        requestAnimationFrame(renderFrame);
      }
    }
    ```

	```html
						if (metadata?.decoderConfig && !savedDecoderConfig) {
							savedDecoderConfig = metadata.decoderConfig;
							log(`捕获解码配置 codec:${savedDecoderConfig.codec}`);
						}
						const buf = new Uint8Array(chunk.byteLength);
						chunk.copyTo(buf);
						encodedFrameList.push({
							data: buf,
							timestamp: chunk.timestamp,
							duration: chunk.duration ?? FRAME_US,
							type: chunk.type
						});
						if(chunk.type === 'key') log(`输出关键帧 PTS=${chunk.timestamp}`);
					},
					error: err => log(`编码异常：${err.message}`)
				});
				videoEncoder.configure(encConfig);
				log('VideoEncoder configure完成，开始生成测试帧');

				let frameIndex = 0;
				const startTime = performance.now();
				function loopEncode() {
					const hue = (frameIndex * FRAME_US / 1000 * 30) % 360;
					encodeCtx.fillStyle = `hsl(${hue}, 70%, 50%)`;
					encodeCtx.fillRect(0, 0, 640, 480);

					encodeCtx.fillStyle = '#fff';
					encodeCtx.font = '28px sans-serif';
					const costSec = ((performance.now() - startTime) / 1000).toFixed(1);
					encodeCtx.fillText(`录制时长：${costSec}s`, 24, 40);
					encodeCtx.fillText(`帧序号：${frameIndex}/${MAX_FRAME_COUNT}`, 24, 80);

					const ts = frameIndex * FRAME_US;
					const frame = new VideoFrame(encodeCanvas, { timestamp: ts });
					videoEncoder.encode(frame, { keyFrame: frameIndex === 0 });
					frame.close();
					frameIndex++;

					const wallTime = performance.now() - startTime;
					if (frameIndex < MAX_FRAME_COUNT && wallTime < RECORD_DURATION * 1.8) {
						requestAnimationFrame(loopEncode);
					} else {
						log(`达到目标帧数${frameIndex}帧，停止采集`);
						finishEncode();
					}
				}
				loopEncode();
			}

			async function finishEncode() {
				log('录制采集完成，执行编码器flush');
				await safeCloseEncoder();
				log(`录制结束，缓存编码包：${encodedFrameList.length}`);

				if (!savedDecoderConfig) {
					log('严重警告：未捕获到decoderConfig！解码黑屏');
					status.textContent = '执行完成';
					return;
				}

				if (encodedFrameList.length) startDecodePlay();
				else {
					log('无编码数据，跳过解码');
					status.textContent = '执行完成';
				}
			}

			async function startDecodePlay() {
				status.textContent = '解码播放中';
				feedIndex = 0;
				playBaseTime = 0;
				renderQueue.length = 0;

				const decConfig = {
					codec: savedDecoderConfig.codec,
					codedWidth: savedDecoderConfig.codedWidth,
					codedHeight: savedDecoderConfig.codedHeight,
					description: savedDecoderConfig.description
				};

				const { supported } = await VideoDecoder.isConfigSupported(decConfig);
				if (!supported) throw new Error('浏览器不支持该解码配置');
				log('解码器配置校验通过');

				videoDecoder = new VideoDecoder({
					output: (decodedFrame) => {
						renderQueue.push(decodedFrame);
					},
					error: err => log(`解码异常：${err.message}`)
				});
				videoDecoder.configure(decConfig);
				log('VideoDecoder configure完成');

				// 等待解码器就绪后启动主循环
				async function waitDecoderReady(){
					while(videoDecoder && videoDecoder.state !== "configured"){
						await new Promise(r => setTimeout(r,2));
					}
					if(!videoDecoder) return;
					log('解码器就绪，启动播放主循环');
					playBaseTime = performance.now();
					mainPlayLoop();
				}
				waitDecoderReady();
			}

			// =========【核心重构：统一主循环，发包+渲染在同一个RAF】=========
			function mainPlayLoop() {
				if (!videoDecoder) return;
				const elapsedMs = performance.now() - playBaseTime;
				const currentPlayUs = elapsedMs * 1000;

				// 1、按时间驱动送入编码包，维持缓冲，不会一次性喂完
				while (feedIndex < encodedFrameList.length) {
					const pkt = encodedFrameList[feedIndex];
					if (pkt.timestamp > currentPlayUs + DECODER_BUFFER_US) break;

					const chunk = new EncodedVideoChunk({
						timestamp: pkt.timestamp,
						type: pkt.type,
						data: pkt.data
					});
					try {
						videoDecoder.decode(chunk);
					} catch (e) {
						log(`投递数据包异常:${e.message}`);
					}
					feedIndex++;
				}

				// 2、渲染队列头部帧，不使用setTimeout嵌套
				while (renderQueue.length > 0) {
					const headFrame = renderQueue[0];
					const targetMs = headFrame.timestamp / 1000;
					if (elapsedMs >= targetMs) {
						// 到达播放时间
						const frame = renderQueue.shift();
						decodeCtx.drawImage(frame, 0, 0);
						frame.close();
					} else {
						// 这一帧还没到播放时间，跳出，下一帧再检查
						break;
					}
				}

				// 播放结束判定
				const allFed = feedIndex >= encodedFrameList.length;
				if(allFed && renderQueue.length === 0){
					videoDecoder.flush().then(()=>{
						log('全部视频帧渲染播放完毕');
						safeCloseDecoder();
						status.textContent = '播放完成';
					});
					return;
				}

				rafHandle = requestAnimationFrame(mainPlayLoop);
			}

			// 入口启动
			(async function bootstrap() {
				try {
					log('程序启动，开始录制编码流程');
					await startEncode();
				} catch (e) {
					log(`全局异常：${e.message}\n${e.stack}`);
					status.textContent = '运行出错';
					safeCloseEncoder();
					safeCloseDecoder();
				}
			})();
		</script>
	</body>
	</html>
	```

1. mp4文件解封装到解码

	- 代码示例

		```html
		<!DOCTYPE html>
		<html lang="zh-CN">

		<head>
		  <meta charset="UTF-8">
		  <title>Mediabunny+WebCodecs 固定帧率逐帧播放</title>

		  <script type="module">
		    import { Input, ALL_FORMATS, UrlSource, EncodedPacketSink } from '../../js/mediabunny.1.42.mjs';

		    const status = document.getElementById('status');
		    const logBox = document.getElementById('log');
		    const canvas = document.getElementById('canvas');
		    const ctx = canvas.getContext('2d');
		    const VIDEO_URL = '../../../media/01.mp4';

		    function log(text) {
		      const t = new Date().toLocaleTimeString();
		      logBox.textContent += `[${t}] ${text}\n`;
		      logBox.scrollTop = logBox.scrollHeight;
		    }

		    async function runDecode() {
		      let decoder = null;
		      let sink = null;
		      let allPackets = [];
		      // 手动设定标准帧率，常见25/30fps，按需修改
		      const FPS = 30;
		      const frameIntervalMs = 1000 / FPS;

		      try {
		        // 1、加载资源与轨道
		        log('初始化UrlSource加载视频');
		        const input = new Input({
		          formats: ALL_FORMATS,
		          source: new UrlSource(VIDEO_URL)
		        });
		        const videoTrack = await input.getPrimaryVideoTrack();
		        if (!videoTrack) throw new Error('无有效视频轨道');
		        log('获取视频轨道成功');

		        // 读取画面尺寸
		        const dw = await videoTrack.getDisplayWidth();
		        const dh = await videoTrack.getDisplayHeight();
		        canvas.width = dw;
		        canvas.height = dh;
		        log(`画面分辨率：${dw} × ${dh}`);

		        // 获取解码配置
		        const decoderConfig = await videoTrack.getDecoderConfig();
		        if (!decoderConfig) throw new Error('无法生成解码器配置');
		        log(`解码器配置 codec:${decoderConfig.codec}，description已内置AVC参数集`);

		        sink = new EncodedPacketSink(videoTrack);
		        log('拉取全部视频编码数据包');
		        for await (const pkt of sink.packets()) {
		          allPackets.push(pkt);
		        }
		        log(`总帧数：${allPackets.length}`);

		        // 2、初始化解码器
		        const renderQueue = [];
		        decoder = new VideoDecoder({
		          output(frame) {
		            renderQueue.push(frame);
		          },
		          error(e) {
		            log(`解码器异常：${e.message}`);
		            status.textContent = '解码失败';
		          }
		        });

		        const { supported } = await VideoDecoder.isConfigSupported(decoderConfig);
		        if (!supported) throw new Error('浏览器不支持当前解码配置');
		        decoder.configure(decoderConfig);
		        log('解码器configure完成，SPS/PPS已加载');

		        let pktIndex = 0;
		        // 按固定时间间隔一帧一帧执行
		        function nextFrame() {
		          // 1、送入当前这一帧解码
		          if (pktIndex < allPackets.length) {
		            const chunk = allPackets[pktIndex].toEncodedVideoChunk();
		            decoder.decode(chunk);
		            pktIndex++;
		          }

		          // 2、取出解码完成的最新帧渲染
		          if (renderQueue.length > 0) {
		            const frame = renderQueue.shift();
		            ctx.drawImage(frame, 0, 0);
		            frame.close();
		          }

		          // 播放结束判定
		          if (pktIndex >= allPackets.length && renderQueue.length === 0) {
		            decoder.flush().then(() => {
		              log('全部帧解码完毕');
		              decoder.close();
		              status.textContent = '播放完成';
		            });
		            return;
		          }

		          // 间隔固定毫秒执行下一帧
		          setTimeout(nextFrame, frameIntervalMs);
		        }

		        // 启动播放
		        nextFrame();

		      } catch (err) {
		        log(`整体异常：${err.message}\n${err.stack}`);
		        status.textContent = '运行出错';
		        if (decoder) decoder.close();
		      }
		    }

		    runDecode();
		  </script>
		</body>

		</html>
		```
