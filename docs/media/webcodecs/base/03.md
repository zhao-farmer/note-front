# 三、音频功能


## 3.1 音频相关接口说明

### 3.1.1 EncodedAudioChunk

压缩后的音频码流分片（压缩二进制数据包）

1. 含义：一段 PCM 音频经过 AAC / Opus 压缩后得到的二进制块，承载基础时序信息：
    - `timestamp`：音频显示时间戳，单位微秒 μs；
    - `duration`：当前音频片段持续时长，单位微秒 μs；
    > 音频不存在关键帧概念，没有 key / delta 类型字段，和视频 EncodedVideoChunk 最大区别。
2. 数据来源
    - 编码链路：AudioEncoder 编码输出回调；
    - 解封装链路：Mediabunny 这类解封装库从音频轨道解析提取。
3. 典型用途
    - 送入 AudioDecoder 进行音频解码；
    - 缓存保存，后续用于 MP4 封装写入。
4. 核心构成要素
    - timestamp：μs 级 PTS；
    - duration：片段时长；
    - data：ArrayBuffer 类型压缩音频二进制。

5. 代码示例

    ```js
    // ==============================================
    // 【音频压缩数据包】EncodedAudioChunk
    // 对应视频：EncodedVideoChunk
    // 承载AAC/Opus等压缩后的音频码流
    // ==============================================
    interface EncodedAudioChunkInit {
        timestamp: number;       // PTS 显示时间戳，单位：微秒 μs
        duration?: number;       // 当前音频片段时长，单位：微秒 μs
        data: ArrayBuffer;       // 压缩音频二进制数据
    }

    class EncodedAudioChunk {
        readonly timestamp: number;
        readonly duration?: number;
        readonly byteLength: number;

        constructor(init: EncodedAudioChunkInit);
        copyTo(destination: ArrayBufferView): void; // 拷贝二进制数据
    }
    ```

### 3.1.2 AudioDecoder

音频解码器：压缩音频码流 → 原始 PCM 音频数据

1. 功能：优先调用硬件音频解码模块，将 EncodedAudioChunk 解压为可播放的原始音频 AudioData。
2. 标准工作流程
    1. configure 完成解码器初始化，AAC 格式必须携带音频配置参数；
    2. 持续调用 decode() 送入 EncodedAudioChunk；
    3. 解码成功触发 output 回调，输出 AudioData；
    4. 解码结束执行 flush，随后关闭解码器释放资源。
3. 核心对象配置说明
    - 构造回调：包含解码成功输出回调、异常捕获回调；
    - 解码器配置 AudioDecoderConfig：
        - codec：音频编码标识，mp4a.40.2 代表 AAC-LC、opus 代表 Opus；
        - sampleRate：音频采样率；
        - numberOfChannels：声道数量；
        - description：**AAC 必需参数**，存储 ASC 音频配置二进制，Opus 通常无需该字段。
4. 关键注意点

    缺失合法 description（ASC）时，AAC 解码器无法构建解码上下文，送入压缩包也无法正常解码，对应视频缺少 SPS/PPS 黑屏现象。

5. 代码示例

    ```js
    // ==============================================
    // 【音频解码器】AudioDecoder
    // 流向：EncodedAudioChunk → AudioData
    // ==============================================
    interface AudioDecoderInit {
        output: (audioData: AudioData) => void; // 解码成功输出原始PCM
        error: (error: DOMException) => void;   // 解码异常回调
    }

    interface AudioDecoderConfig {
        codec: string;                  // 编码标识：mp4a.40.2 / opus
        sampleRate?: number;            // 采样率
        numberOfChannels?: number;      // 声道数量
        description?: ArrayBuffer;      // AAC必备：ASC音频配置二进制（对标H.264 SPS+PPS）
    }
    class AudioDecoder {
        constructor(init: AudioDecoderInit);

        readonly state: "unconfigured" | "configured" | "closed";

        configure(config: AudioDecoderConfig): void; // 初始化解码器上下文
        decode(chunk: EncodedAudioChunk): void;      // 送入压缩音频包解码
        flush(): Promise<void>;                      // 等待队列全部解码完成
        close(): void;                               // 销毁解码器，释放资源
        reset(): void;                               // 清空等待队列，保留配置

        static isConfigSupported(config: AudioDecoderConfig): Promise<{ supported: boolean }>;
    }
    ```

### 3.1.3 AudioEncoder

音频编码器：原始 PCM 音频 → 压缩音频码流

1. 功能：AudioDecoder 的反向链路，接收原始 AudioData，按照预设码率、采样参数压缩，输出 EncodedAudioChunk。
    
    适用场景：浏览器音频录制、音视频同步编码、实时流媒体推流。

2. 标准工作流程
    1. configure 设置编码参数（编码格式、采样率、声道、比特率）；
    2. 持续送入 AudioData 原始音频帧；
    3. output 回调输出 EncodedAudioChunk，编码成功时附带 metadata；
    4. metadata 内携带 decoderConfig，内含后续解码所需的 ASC 配置信息，务必持久保存；
    5. 编码结束执行 flush，关闭编码器。
3. 核心配置说明
    - codec：目标压缩格式；
    - sampleRate、numberOfChannels：原始音频参数；
    - bitrate：音频输出比特率。

4. 代码示例

    ```js
    // ==============================================
    // 【音频编码器】AudioEncoder
    // 流向：AudioData → EncodedAudioChunk
    // ==============================================
    interface EncodedAudioChunkMetadata {
        decoderConfig?: AudioDecoderConfig; // 编码输出附带解码器配置（内含ASC）
    }

    interface AudioEncoderInit {
        output: (chunk: EncodedAudioChunk, metadata?: EncodedAudioChunkMetadata) => void;
        error: (error: DOMException) => void;
    }

    interface AudioEncoderConfig {
        codec: string;               // 目标编码格式
        sampleRate: number;          // PCM采样率
        numberOfChannels: number;    // PCM声道数
        bitrate: number;             // 输出码率 bps
    }

    class AudioEncoder {
        constructor(init: AudioEncoderInit);

        readonly state: "unconfigured" | "configured" | "closed";

        configure(config: AudioEncoderConfig): void;
        encode(data: AudioData): void;   // 送入原始PCM音频帧编码
        flush(): Promise<void>;
        close(): void;
        reset(): void;

        static isConfigSupported(config: AudioEncoderConfig): Promise<{ supported: boolean }>;
    }
    ```

### 3.1.4 AudioData

未压缩原始 PCM 音频裸数据

1. 含义：未经压缩的音频采样数据（PCM），可以直接用于播放或者送入编码器压缩。
2. 数据来源
    - AudioDecoder 解码输出；
    - AudioContext 采集、手动构造 PCM 缓冲区生成。
3. 核心属性
    - timestamp：时间戳 μs；
    - sampleRate：采样率；
    - numberOfChannels：声道数；
    - numberOfFrames：当前音频块采样点总数；
    - format：采样存储格式（f32-planar / s16-planar）。
4. 强制规范
    
    AudioData 使用完成必须调用 close()，WebCodecs 内部持有内存缓冲区，不释放会持续造成内存持续上涨。
5. 使用方向
    - 读取内部 PCM 数据，交由 Web Audio API 播放；
    - 直接送入 AudioEncoder 完成编码。

6. 代码示例

    ```js
    // ==============================================
    // 【原始PCM音频帧】AudioData
    // 对应视频：VideoFrame
    // 未压缩裸音频数据，用于播放/编码
    // ==============================================
    interface AudioDataInit {
        format: "u8" | "s16" | "s32" | "f32" | "u8-planar" | "s16-planar" | "s32-planar" | "f32-planar";
        sampleRate: number;
        numberOfChannels: number;
        numberOfFrames: number; // 当前块总采样点数
        timestamp: number;      // PTS μs
        data: ArrayBufferView;  // PCM二进制缓冲区
    }

    class AudioData {
        constructor(init: AudioDataInit);

        readonly timestamp: number;
        readonly sampleRate: number;
        readonly numberOfChannels: number;
        readonly numberOfFrames: number;
        readonly format: string;

        copyTo(destination: ArrayBufferView, options?: { planeIndex?: number }): void;
        close(): void; // 【强制调用】释放内存，防止泄漏
    }
    ```

### 3.1.5 ASC / ESDS（音频参数集，对标视频 SPS+PPS）
1.  `ASC（Audio Specific Config）`
    音频序列配置块，二进制数据：

    存储整条音频流全局基础信息：
    
    - AAC Profile（LC/HE-AAC）
    - 采样率索引
    - 声道布局信息

    整条音频流共用一份，AAC 解码器初始化依赖这份配置。
    
    WebCodecs 中 AudioDecoderConfig.description 存储的二进制内容就是 ASC。

2. `ESDS`
    
    MP4 容器层面的封装结构，ASC 二进制数据被封装在 ESDS Box 内部。
    
    解封装工具会读取 ESDS，提取内部 ASC 数据供给解码器配置。

3. 配置代码

    ```js
    // ==============================================
    // 【辅助结构体】AAC 音频配置 ASC（Audio Specific Config）
    // 对标视频 SPS/PPS，AAC解码器初始化依赖
    // ==============================================
    interface AudioSpecificConfig {
        aacProfile: number;        // AAC Profile编号
        sampleRateIndex: number;   // 采样率索引
        channelConfig: number;     // 声道布局配置
    }
    ```


### 3.1.6 音视频 WebCodecs 对象完整对照清单

| 视频对象 | 音频对象 | 核心作用 |
| ---- | ---- | ---- |
| EncodedVideoChunk | EncodedAudioChunk | 压缩码流数据包 |
| VideoFrame | AudioData | 原始未压缩音/视频裸帧 |
| VideoEncoder | AudioEncoder | 原始帧 → 压缩码流 |
| VideoDecoder | AudioDecoder | 压缩码流 → 原始帧 |
| SPS+PPS | ASC（ESDS） | 解码器初始化必备参数集 |
| VideoDecoderConfig.description | AudioDecoderConfig.description | 参数集二进制载体 |



## 3.2 链路流程

- 链路 1：音频解码播放

    ```
    MP4文件 → Mediabunny解封装
            ↓
    EncodedAudioChunk（压缩音频包）
            ↓送入
    AudioDecoder（配置包含ASC音频参数集）
            ↓解码输出
    AudioData（原始PCM音频）
        └─ 送入Web Audio API播放 → audioData.close()释放
    ```

- 链路 2：音频采集编码

    ```
    麦克风/WebAudio PCM数据 → 生成AudioData
        ↓送入
    AudioEncoder
        ↓编码输出
    EncodedAudioChunk
        ↓送入MP4Box/Mediabunny封装 → 输出MP4文件
    ```

- 从属关系
    - EncodedAudioChunk：压缩层音频数据包；
    - AudioDecoder / AudioEncoder：中间处理器，双向转换「压缩音频块」↔「原始PCM音频帧」；
    - AudioData：未压缩PCM音频载体；
    - ASC（Audio Specific Config）：音频流全局配置信息，挂载在 `AudioDecoderConfig.description`，解码器初始化必需，等价视频SPS/PPS。



## 3.3 代码实例

### 3.3.1 解码与编码

1. 代码示例

    ```html
    <!DOCTYPE html>
    <html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <title>WebCodecs AAC 音频编码+解码闭环</title>
        <style>
            body { display: flex; flex-direction: column; gap: 12px; padding: 20px; margin: 0; }
            #log { height: 320px; overflow: auto; white-space: pre-wrap; background: #dddddd; color:#000; padding:8px; margin:0; }
            #status { font-size:16px; font-weight:bold; }
            button { width: 160px; padding: 8px; font-size:16px; cursor:pointer; }
        </style>
    </head>
    <body>
        <button id="startBtn">点击启动测试</button>
        <div id="status">就绪，点击上方按钮开始</div>
        <pre id="log"></pre>

        <script type="module">
            const status = document.getElementById('status');
            const logBox = document.getElementById('log');
            const startBtn = document.getElementById('startBtn');

            function log(text) {
                const t = new Date().toLocaleTimeString();
                logBox.textContent += `[${t}] ${text}\n`;
                logBox.scrollTop = logBox.scrollHeight;
            }

            // ====================== 全局配置 ======================
            const SAMPLE_RATE = 44100;
            const CHANNELS = 2;
            const FRAME_SAMPLES = 1024;
            const RECORD_SECONDS = 10;
            const DURATION_US = RECORD_SECONDS * 1_000_000;

            let audioEncoder = null;
            let audioDecoder = null;
            let savedAudioConfig = null;
            const encodedAudioList = [];

            let audioContext = null;
            let playStartTime = 0;
            let isPlaying = false;
            let isRunning = false;

            // ====================== 资源安全释放 ======================
            async function safeCloseEncoder() {
                if (!audioEncoder) return;
                try {
                    await audioEncoder.flush();
                    audioEncoder.close();
                    log('音频编码器已关闭');
                } catch (err) {
                    if (err.name !== 'AbortError') log(`编码器关闭异常：${err.message}`);
                }
                audioEncoder = null;
            }

            function safeCloseDecoder() {
                isPlaying = false;
                if (!audioDecoder) return;
                try {
                    audioDecoder.close();
                } catch (err) {
                    if (err.name !== 'AbortError') log(`解码器关闭异常：${err.message}`);
                }
                audioDecoder = null;
            }

            // ====================== 生成测试PCM（正弦波音频） ======================
            function generateTestAudioData(timestampUs, frameIndex) {
                const length = FRAME_SAMPLES * CHANNELS;
                const data = new Float32Array(length);
                const freq = 330 + frameIndex * 2;

                for (let i = 0; i < FRAME_SAMPLES; i++) {
                    const t = i / SAMPLE_RATE;
                    const val = Math.sin(2 * Math.PI * freq * t) * 0.25;
                    data[i] = val;
                    data[i + FRAME_SAMPLES] = val;
                }

                return new AudioData({
                    format: "f32-planar",
                    sampleRate: SAMPLE_RATE,
                    numberOfChannels: CHANNELS,
                    numberOfFrames: FRAME_SAMPLES,
                    timestamp: timestampUs,
                    data
                });
            }

            // ====================== 音频编码录制 ======================
            async function startEncode() {
                status.textContent = '音频编码录制中';
                log('初始化AAC音频编码器配置');
                const encConfig = {
                    codec: 'mp4a.40.2',
                    sampleRate: SAMPLE_RATE,
                    numberOfChannels: CHANNELS,
                    bitrate: 128_000
                };

                const { supported } = await AudioEncoder.isConfigSupported(encConfig);
                if (!supported) throw new Error('浏览器不支持AAC音频编码');
                log('编码器配置校验通过');

                audioEncoder = new AudioEncoder({
                    output: (chunk, metadata) => {
                        if (metadata?.decoderConfig && !savedAudioConfig) {
                            savedAudioConfig = metadata.decoderConfig;
                            log(`捕获音频解码配置，携带ASC参数集`);
                        }
                        const buf = new Uint8Array(chunk.byteLength);
                        chunk.copyTo(buf);
                        encodedAudioList.push({
                            data: buf,
                            timestamp: chunk.timestamp,
                            duration: chunk.duration,
                            type: chunk.type
                        });
                    },
                    error: err => log(`音频编码异常：${err.message}`)
                });
                audioEncoder.configure(encConfig);
                log('AudioEncoder configure完成，生成测试PCM音频');

                let frameIndex = 0;
                let currentTsUs = 0;
                const sampleDurationUs = (FRAME_SAMPLES / SAMPLE_RATE) * 1e6;

                function loopEncode() {
                    if (currentTsUs >= DURATION_US) {
                        log(`采集时长达到${RECORD_SECONDS}s，停止音频生成`);
                        finishEncode();
                        return;
                    }
                    const audioData = generateTestAudioData(currentTsUs, frameIndex);
                    audioEncoder.encode(audioData);
                    audioData.close();

                    currentTsUs += sampleDurationUs;
                    frameIndex++;
                    setTimeout(loopEncode, sampleDurationUs / 1000);
                }
                loopEncode();
            }

            async function finishEncode() {
                log('音频采集完成，执行encoder flush');
                await safeCloseEncoder();
                log(`编码结束，缓存音频包数量：${encodedAudioList.length}`);

                if (!savedAudioConfig) {
                    log('严重警告：未捕获音频decoderConfig！解码无法初始化');
                    status.textContent = '执行完成';
                    isRunning = false;
                    startBtn.disabled = false;
                    return;
                }

                if (encodedAudioList.length) {
                    startDecodePlay();
                } else {
                    log('无音频编码数据，跳过解码');
                    status.textContent = '执行完成';
                    isRunning = false;
                    startBtn.disabled = false;
                }
            }

            // ====================== 音频解码播放 ======================
            async function startDecodePlay() {
                status.textContent = '音频解码播放中';

                // 在用户手势内确保AudioContext正常启动
                if (!audioContext) {
                    audioContext = new AudioContext();
                    log('AudioContext 创建成功');
                }
                if (audioContext.state === 'suspended') {
                    await audioContext.resume();
                    log('AudioContext resume完成');
                }

                const decConfig = {
                    codec: savedAudioConfig.codec,
                    sampleRate: savedAudioConfig.sampleRate,
                    numberOfChannels: savedAudioConfig.numberOfChannels,
                    description: savedAudioConfig.description
                };

                const { supported } = await AudioDecoder.isConfigSupported(decConfig);
                if (!supported) throw new Error('浏览器不支持该音频解码配置');
                log('音频解码器配置校验通过');

                const playQueue = [];
                audioDecoder = new AudioDecoder({
                    output: (audioData) => {
                        playQueue.push(audioData);
                        if (!isPlaying) {
                            isPlaying = true;
                            playLoop(playQueue);
                        }
                    },
                    error: err => log(`音频解码异常：${err.message}`)
                });
                audioDecoder.configure(decConfig);
                log('AudioDecoder configure完成，送入音频包');

                let pktIdx = 0;
                function feedPacket() {
                    if (pktIdx >= encodedAudioList.length) {
                        log('所有音频包送入完成，执行decoder flush');
                        audioDecoder.flush();
                        return;
                    }
                    const item = encodedAudioList[pktIdx];
                    const chunk = new EncodedAudioChunk({
                        timestamp: item.timestamp,
                        duration: item.duration,
                        type: item.type,
                        data: item.data
                    });
                    audioDecoder.decode(chunk);
                    pktIdx++;
                    setTimeout(feedPacket, 1);
                }
                feedPacket();
            }

            async function playLoop(queue) {
                if (queue.length === 0) {
                    safeCloseDecoder();
                    log('音频播放全部完成');
                    status.textContent = '播放完成';
                    isRunning = false;
                    startBtn.disabled = false;
                    return;
                }
                const audioData = queue.shift();
                if (playStartTime === 0) {
                    playStartTime = performance.now();
                }

                const playedMs = performance.now() - playStartTime;
                const targetMs = audioData.timestamp / 1000;
                const delayMs = Math.max(0, targetMs - playedMs);
                await new Promise(resolve => setTimeout(resolve, delayMs));

                // AudioData → WebAudio AudioBuffer
                const abuf = audioContext.createBuffer(
                    audioData.numberOfChannels,
                    audioData.numberOfFrames,
                    audioData.sampleRate
                );
                for (let ch = 0; ch < audioData.numberOfChannels; ch++) {
                    const channelData = abuf.getChannelData(ch);
                    audioData.copyTo(channelData, { planeIndex: ch });
                }
                const src = audioContext.createBufferSource();
                src.buffer = abuf;
                src.connect(audioContext.destination);
                src.start();

                audioData.close();
                requestAnimationFrame(() => playLoop(queue));
            }

            // ====================== 用户点击启动入口 ======================
            startBtn.addEventListener('click', async () => {
                if (isRunning) return;
                isRunning = true;
                startBtn.disabled = true;
                log('用户点击按钮，启动音频Demo');
                try {
                    await startEncode();
                } catch (e) {
                    log(`全局异常：${e.message}\n${e.stack}`);
                    status.textContent = '运行出错';
                    safeCloseEncoder();
                    safeCloseDecoder();
                    isRunning = false;
                    startBtn.disabled = false;
                }
            });
        </script>
    </body>
    </html>

    ```

            const src = audioContext.createBufferSource();
            src.buffer = abuf;
            src.connect(audioContext.destination);
            src.start();
            audioData.close();
          }, delay);
        }

        async function runDecode() {
          let videoDecoder = null;
          let audioDecoder = null;
          let videoSink = null;
          let audioSink = null;
          const videoPackets = [];
          const audioPackets = [];
          const videoRenderQueue = [];

          try {
            log('初始化UrlSource加载视频');
            const input = new Input({
              formats: ALL_FORMATS,
              source: new UrlSource(VIDEO_URL)
            });
            const videoTrack = await input.getPrimaryVideoTrack();
            const audioTrack = await input.getPrimaryAudioTrack();
            if (!videoTrack) throw new Error('无有效视频轨道');
            log('获取视频轨道成功');

            // 视频信息
            const dw = await videoTrack.getDisplayWidth();
            const dh = await videoTrack.getDisplayHeight();
            canvas.width = dw;
            canvas.height = dh;
            log(`画面分辨率：${dw} × ${dh}`);
            const videoDecoderConfig = await videoTrack.getDecoderConfig();
            if (!videoDecoderConfig) throw new Error('无法获取视频解码配置');

            // 拉取视频包
            videoSink = new EncodedPacketSink(videoTrack);
            log('拉取全部视频编码数据包');
            for await (const pkt of videoSink.packets()) {
              videoPackets.push(pkt);
            }
            log(`视频总帧数：${videoPackets.length}`);

            // ====== 音频部分 ======
            let audioDecoderConfig = null;
            if (audioTrack) {
              audioSink = new EncodedPacketSink(audioTrack);
              audioDecoderConfig = await audioTrack.getDecoderConfig();
              log('拉取全部音频编码数据包');
              for await (const pkt of audioSink.packets()) {
                audioPackets.push(pkt);
              }
              log(`音频总包数：${audioPackets.length}`);
            }

            // 初始化解码器
            videoDecoder = new VideoDecoder({
              output(frame) {
                videoRenderQueue.push(frame);
              },
              error(e) {
                log(`视频解码器异常：${e.message}`);
              }
            });
            const videoSupport = await VideoDecoder.isConfigSupported(videoDecoderConfig);
            if (!videoSupport.supported) throw new Error('浏览器不支持视频解码配置');
            videoDecoder.configure(videoDecoderConfig);
            log('视频解码器configure完成');

            // 音频解码器
            let audioPktIndex = 0;
            if (audioTrack && audioDecoderConfig) {
              audioDecoder = new AudioDecoder({
                output(audioData) {
                  scheduleAudioFrame(audioData);
                },
                error(e) {
                  log(`音频解码器异常：${e.message}`);
                }
              });
              const audioSupport = await AudioDecoder.isConfigSupported(audioDecoderConfig);
              if (!audioSupport.supported) log('警告：浏览器不支持音频解码');
              else {
                audioDecoder.configure(audioDecoderConfig);
                log('音频解码器configure完成');
              }
            }

            let videoPktIndex = 0;
            function nextFrame() {
              // 送入视频包
              if (videoPktIndex < videoPackets.length) {
                const chunk = videoPackets[videoPktIndex].toEncodedVideoChunk();
                videoDecoder.decode(chunk);
                videoPktIndex++;
              }

              // 送入音频包（根据时间持续推送，不阻塞视频）
              while (audioDecoder && audioPktIndex < audioPackets.length) {
                const pkt = audioPackets[audioPktIndex];
                // 粗略时序：音频时间戳不超过当前视频进度则持续送入
                const currentVideoTs = videoPackets[Math.min(videoPktIndex, videoPackets.length - 1)].timestamp;
                if (pkt.timestamp > currentVideoTs) break;
                const chunk = pkt.toEncodedAudioChunk();
                audioDecoder.decode(chunk);
                audioPktIndex++;
              }

              // 渲染画面
              if (videoRenderQueue.length > 0) {
                const frame = videoRenderQueue.shift();
                ctx.drawImage(frame, 0, 0);
                frame.close();
              }

              // 播放结束判断
              if (videoPktIndex >= videoPackets.length && videoRenderQueue.length === 0) {
                Promise.all([
                  videoDecoder.flush(),
                  audioDecoder ? audioDecoder.flush() : Promise.resolve()
                ]).then(() => {
                  log('音视频全部解码播放完毕');
                  videoDecoder.close();
                  if (audioDecoder) audioDecoder.close();
                  status.textContent = '播放完成';
                  isRunning = false;
                  startBtn.disabled = false;
                });
                return;
              }

              setTimeout(nextFrame, frameIntervalMs);
            }

            // 启动循环
            nextFrame();

          } catch (err) {
            log(`整体异常：${err.message}\n${err.stack}`);
            status.textContent = '运行出错';
            if (videoDecoder) videoDecoder.close();
            if (audioDecoder) audioDecoder.close();
            isRunning = false;
            startBtn.disabled = false;
          }
        }

        // 用户点击启动（满足浏览器AudioContext手势策略）
        startBtn.addEventListener('click', async () => {
          if (isRunning) return;
          isRunning = true;
          startBtn.disabled = true;
          status.textContent = '加载资源中...';
          log('用户点击启动播放');

          // 在手势内创建AudioContext
          if (!audioContext) {
            audioContext = new AudioContext();
          }
          if (audioContext.state === 'suspended') {
            await audioContext.resume();
          }
          playStartTimestamp = 0;

          await runDecode();
        });
      </script>
    </body>

        class AudioRingBuffer {
          constructor(sampleRate, numChannels) {
            this.sampleRate = sampleRate;
            this.numChannels = numChannels;
            this.capacity = sampleRate * 5; // 预分配5秒缓冲
            this.buffers = [];
            for (let ch = 0; ch < numChannels; ch++) {
              this.buffers.push(new Float32Array(this.capacity));
            }
            this.writePos = 0;
            this.readPos = 0;
          }
    
          push(audioData) {
            const frames = audioData.numberOfFrames;
            for (let ch = 0; ch < this.numChannels; ch++) {
              const plane = new Float32Array(frames);
              audioData.copyTo(plane, { planeIndex: ch });
              const buf = this.buffers[ch];
              for (let i = 0; i < frames; i++) {
                buf[(this.writePos + i) % this.capacity] = plane[i];
              }
            }
            this.writePos = (this.writePos + frames) % this.capacity;
            audioData.close();
          }
    
          read(outputBuffers) {
            const framesNeeded = outputBuffers[0].length;
            const available = (this.writePos - this.readPos + this.capacity) % this.capacity;
            const toRead = Math.min(framesNeeded, available);
    
            for (let ch = 0; ch < outputBuffers.length; ch++) {
              const out = outputBuffers[ch];
              const buf = this.buffers[ch % this.numChannels];
              for (let i = 0; i < toRead; i++) {
                out[i] = buf[(this.readPos + i) % this.capacity];
              }
              // 不足部分填零，避免爆音
              for (let i = toRead; i < framesNeeded; i++) {
                out[i] = 0;
              }
            }
            this.readPos = (this.readPos + toRead) % this.capacity;
          }

            return ((this.writePos - this.readPos + this.capacity) % this.capacity) / this.sampleRate;
          }
