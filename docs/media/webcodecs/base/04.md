# 四、图片处理

## 4.1 图片像刚刚接口

ImageDecoder、ImageTrackList、ImageTrack 是 WebCodecs 标准中专用于 GIF、APNG、动态 WebP、动态 AVIF 这类图像（动图）解码的接口，仅在 Chromium 内核浏览器可用，Firefox 暂未支持。

### 4.1.1 ImageDecoder

**核心解码器，入口类**

作用：异步解析图像二进制数据、提取帧、解码图像帧。

- 关键能力

    1. 接收 `Blob | ArrayBuffer | ReadableStream` 图像原始数据；
    2. 自动识别格式（GIF/APNG/Animated WebP/AVIF）；
    3. 解析文件元信息：宽高、是否动画、循环次数、背景色；
    4. 对外暴露 `.tracks` → **ImageTrackList**；
    5. 通过 `decode(frameIndex)` 解码指定序号帧，得到 `VideoFrame`。


- 构造函数：`new ImageDecoder(initDict)`

    ```js
    const decoder = new ImageDecoder({
        // 三选一：二进制源
        data: ArrayBuffer | Uint8Array | Blob | ReadableStream,
        // 文件MIME类型
        type: "image/gif" | "image/apng" | "image/webp" | "image/avif",
        preferAnimation: true, // true：优先解析动画轨道
    });
    ```

- 重要属性
    - `.tracks`：`ImageTrackList` 实例
    - `.complete`：数据是否全部载入
    - `.type`：图像MIME类型

    ```js
    decoder.tracks;          // ImageTrackList（重点）
    decoder.complete;        // boolean，数据是否全部载入
    decoder.type;
    ```
- 方法

    - `decode({frameIndex})` → 解码某一帧
    - `close()`：释放内存（必须调用，防止VideoFrame泄漏）

    ```js
    // 解码指定帧，返回 { image: VideoFrame }
    const result = await decoder.decode({ frameIndex: number });
    const frame = result.image; // VideoFrame，绘制完必须 frame.close()

    // 释放解码器内存，销毁所有资源
    decoder.close();
    ```
- 最简示例


    ```js
    const decoder = new ImageDecoder({
        data: imageBuffer,
        type: "image/gif"
    });
    // 获取轨道列表
    const tracks = decoder.tracks;
    // 解码第0帧
    const result = await decoder.decode({ frameIndex: 0 });
    const frame = result.image; // VideoFrame
    ```

### 4.1.2 ImageTrackList

**轨道集合（一个图像文件可以有多条轨道）**

`ImageDecoder.tracks` 返回该对象。

- 作用

    1. 保存文件内所有 `ImageTrack`；
    2. 提供选中轨道的能力（`.selectedTrack`）；
    3. 监听轨道加载完成状态。

- 属性
    - `length`：轨道数量
    - `[index]`：按下标取 ImageTrack
    - `.selectedTrack`：当前选中激活的轨道（最重要）
    - `.ready`：Promise，轨道解析完成后 resolve

    > 绝大多数动图（GIF/APNG）**只有1条轨道**；
    > 多轨道一般出现在多画面AVIF文件。


- 使用方式
    
    1. 获取方式

        **不能手动 new，只能通过 `ImageDecoder.tracks` 获取**

        ```js
        const trackList = decoder.tracks;
        ```

    2. 重要异步等待

        轨道元信息解析是异步，必须等待 `.ready`

        ```js
        await trackList.ready;
        ```

    3. 属性与用法

        ```js
        trackList.length;               // 轨道数量，动图一般 = 1
        trackList.selectedTrack;        // ImageTrack，自动选中默认轨道
        trackList[0];                   // 按下标访问轨道
        ```

    4. 典型写法：

        ```js
        const trackList = decoder.tracks;
        await trackList.ready;
        const track = trackList.selectedTrack;
        ```


### 4.1.3 ImageTrack

**单条图像轨道，存储动画帧时序信息**
    
轨道 = 一组有序图像帧 + 每帧时长、循环参数。

1. 核心属性（做动图播放器全都依赖它）
    - `.frameCount`：这条轨道一共有多少帧（动图总帧数）
    - `.repetitionCount`：动画循环次数
        - `0` = 无限循环（GIF常见）
        - 正数 = 循环多少次
    - `.animated`：boolean，是否为动画（多帧图像）
    - `.selected`：是否为当前选中轨道

2. 使用方式

    
    1. 获取方式

        **不能 new，只能从 ImageTrackList 获取**

        ```
        const trackList = decoder.tracks;
        await trackList.ready;
        const track = trackList.selectedTrack;
        ```

    2. 常用只读属性（动画播放器核心参数）

        ```
        track.animated;             // boolean 是否为多帧动画
        track.frameCount;           // 总帧数
        track.repetitionCount;      // 循环次数；0 = 无限循环
        track.codedWidth;           // 原始宽
        track.codedHeight;          // 原始高
        track.selected;             // 是否当前选中轨道
        ```

    > 
    > 重大局限：**ImageTrack 不提供每一帧的延时时间！**
    > API 标准没有开放帧延迟，想要精准播放速度，需要额外解析GIF二进制。
    >  **关键区别：ImageTrack 只存时序元数据，不包含像素！**
    > 想要像素画面，依然要调用 `ImageDecoder.decode(frameIndex)`。




## 4.2 工作流程


1. 动画GIF播放器完整链路

    ```
    ArrayBuffer(GIF二进制)
        ↓
    ImageDecoder(加载数据)
        ↓
    ImageDecoder.tracks → ImageTrackList
        ↓
    ImageTrackList.selectedTrack → ImageTrack
        ↓
    读取 track.frameCount / track.repetitionCount 获取动画信息
        ↓
    循环调用 decoder.decode(frameIndex) 逐帧解码得到 VideoFrame
        ↓
    根据每帧延时渲染到Canvas
    ```

2. 三者层级关系（单向依赖）

    ```
    ImageDecoder（顶层实例）
        └── .tracks → ImageTrackList
            └── .selectedTrack → ImageTrack
    ```

## 4.3 代码案例

- 代码示例

    ```html
    <!DOCTYPE html>
    <html lang="zh-CN">

    <head>
      <meta charset="UTF-8">
      <style>
        body {
          font-family: sans-serif;
          padding: 20px;
          margin: 0;
        }

        /*  关键：block消除底部间隙，transparent去除黑底，无border/padding/margin */
        canvas {
          display: block;
          background: transparent;
          border: none;
          padding: 0;
          margin: 0;
        }

        .controls {
          display: flex;
          align-items: center;
          gap: 12px;
          margin-bottom: 10px;
        }

        label {
          font-size: 14px;
        }

        input[type=range] {
          width: 180px;
        }

        #speedVal {
          min-width: 50px;
          font-weight: bold;
          font-size: 14px;
        }

        #log {
          white-space: pre-wrap;
          background: #f5f5f5;
          padding: 8px;
          font-size: 13px;
          max-height: 200px;
          overflow-y: auto;
        }
      </style>
    </head>

    <body>

      <script>
        window.ANIM_CONFIG = {
          url: '../../../media/02.gif',
          frameDurationMs: 100,
          playbackRate: 1.0,
          showSpeedControl: true,
        };
      </script>

      <div class="controls" id="speedControl" style="display:none;">
        <label>速度:
          <input type="range" id="speedSlider" min="0.1" max="5" step="0.1" value="1">
          <span id="speedVal">1.0x</span>
        </label>
      </div>
      <canvas id="canvas"></canvas>
      <pre id="log"></pre>

      <script type="module">
        const CONFIG = window.ANIM_CONFIG || {};
        const IMG_URL = CONFIG.url || '../../../media/02.gif';
        const DEFAULT_FRAME_MS = CONFIG.frameDurationMs || 100;
        let playbackRate = CONFIG.playbackRate || 1.0;

        const canvas = document.getElementById('canvas');
        const ctx = canvas.getContext('2d');
        const logEl = document.getElementById('log');
        const speedCtrl = document.getElementById('speedControl');
        const speedSlider = document.getElementById('speedSlider');
        const speedVal = document.getElementById('speedVal');

        if (CONFIG.showSpeedControl) {
          speedCtrl.style.display = 'flex';
          speedSlider.value = playbackRate;
          speedVal.textContent = playbackRate.toFixed(1) + 'x';
          speedSlider.addEventListener('input', () => {
            playbackRate = parseFloat(speedSlider.value);
            speedVal.textContent = playbackRate.toFixed(1) + 'x';
          });
        }

        let decoder = null, track = null, frameIndex = 0, timerId = null, playing = false;

        function log(msg) {
          logEl.textContent += `[${new Date().toLocaleTimeString()}] ${msg}\n`;
          logEl.scrollTop = logEl.scrollHeight;
        }

        function guessMimeType(url, fallbackType) {
          if (fallbackType && fallbackType !== '' && fallbackType !== 'application/octet-stream') return fallbackType;
          const ext = url.split('.').pop().toLowerCase().split('?')[0];
          const map = { gif: 'image/gif', apng: 'image/apng', png: 'image/apng', webp: 'image/webp', avif: 'image/avif', jxl: 'image/jxl' };
          return map[ext] || 'image/gif';
        }

        function getFrameDurationMs(frame) {
          return (frame && frame.duration > 0) ? frame.duration / 1000 : DEFAULT_FRAME_MS;
        }

        function stop() {
          playing = false;
          if (timerId !== null) { clearTimeout(timerId); timerId = null; }
        }

        async function renderLoop() {
          if (!playing || !decoder || !track) return;
          try {
            const { image } = await decoder.decode({ frameIndex });
            ctx.drawImage(image, 0, 0);
            const delay = Math.max(1, getFrameDurationMs(image) / playbackRate);
            image.close();
            frameIndex = (frameIndex + 1) % track.frameCount;
            timerId = setTimeout(renderLoop, delay);
          } catch (e) {
            log(`解码帧 ${frameIndex} 失败: ${e.message}`);
            stop();
          }
        }

        async function startPlay() {
          stop();
          if (decoder) { try { decoder.close(); } catch (_) { } decoder = null; }
          frameIndex = 0;
          logEl.textContent = '';

          if (typeof ImageDecoder === 'undefined') { log('浏览器不支持 ImageDecoder'); return; }

          let buf, mimeType;
          try {
            const res = await fetch(IMG_URL);
            if (!res.ok) throw new Error(`HTTP ${res.status}`);
            const blob = await res.blob();
            buf = await blob.arrayBuffer();
            mimeType = guessMimeType(IMG_URL, blob.type);
            log(`${buf.byteLength}B, type=${mimeType}`);
          } catch (e) { log(`加载失败: ${e.message}`); return; }

          try {
            decoder = new ImageDecoder({ data: buf, type: mimeType, preferAnimation: true });
          } catch (e) { log(`构造失败: ${e.message}`); return; }

          try {
            await Promise.race([
              decoder.tracks.ready,
              new Promise((_, rej) => setTimeout(() => rej(new Error('tracks.ready 超时')), 5000))
            ]);
          } catch (e) { log(` ${e.message}`); decoder.close(); decoder = null; return; }

          track = decoder.tracks.selectedTrack;
          if (!track) {
            for (const t of decoder.tracks) { if (t.animated) { t.selected = true; track = t; break; } }
            if (!track && decoder.tracks.length > 0) { decoder.tracks[0].selected = true; track = decoder.tracks[0]; }
          }
          if (!track) { log(' 无可用轨道'); decoder.close(); decoder = null; return; }

          if (!track.animated) {
            const { image } = await decoder.decode({ frameIndex: 0 });
            canvas.width = image.displayWidth; canvas.height = image.displayHeight;
            ctx.drawImage(image, 0, 0); image.close();
            log(' 非动画，渲染首帧'); decoder.close(); decoder = null; return;
          }

          // 核心修复：用首帧真实尺寸设置canvas，而非codedWidth/兜底值
          const { image: firstFrame } = await decoder.decode({ frameIndex: 0 });
          canvas.width = firstFrame.displayWidth;
          canvas.height = firstFrame.displayHeight;
          ctx.drawImage(firstFrame, 0, 0);
          firstFrame.close();
          log(` Canvas精确匹配: ${canvas.width}×${canvas.height}`);

          frameIndex = 1; // 首帧已绘制，从第2帧开始
          playing = true;
          log(`播放中 (${playbackRate.toFixed(1)}x)`);
          renderLoop();
        }

        startPlay();
        window.addEventListener('beforeunload', () => { stop(); if (decoder) try { decoder.close(); } catch (_) { } });
      </script>
    </body>

    </html>
    ```
