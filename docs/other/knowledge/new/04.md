# 四、webView

WebView 是一个内嵌的浏览器组件，让应用程序能够显示网页内容，而不需要跳转到外部浏览器。

通俗理解：想象你的应用里开了一个“小窗口”，这个小窗口专门用来显示网页，就像在微信里打开文章链接一样，不需要离开微信就能看网页。


## 4.1 核心特点
1. 内嵌浏览器
    - 不需要离开应用
    - 外观和体验与应用一致
    - 可以自定义界面和交互
2. 混合开发支持
    - 用网页技术（HTML/CSS/JS）开发部分界面
    - 结合原生功能（摄像头、GPS等）
    - 一次开发，多平台使用

3. 实际应用例子
    
    ```txt
    你正在使用的微信 → 点击朋友分享的链接 → 在微信内部打开网页
                        ↑
                    这就是WebView
    ```

## 4.2 具体实例

以下是 **WebView 在 Android、iOS、Flutter、React Native 四大平台**的完整示例代码，涵盖：

- 加载网页或本地 HTML  
- **原生 ↔ Web 双向通信**（核心能力）  
- 基础配置（启用 JS、调试等）

### 4.2.1 Android（原生 Java/Kotlin）

1. 功能
    - 加载远程 URL
    - Web 调用原生方法（`showToast`）
    - 原生调用 Web JS 函数

2.  `MainActivity.java`

    ```java
    package com.example.webviewdemo;

    import android.annotation.SuppressLint;
    import android.os.Bundle;
    import android.webkit.JavascriptInterface;
    import android.webkit.WebView;
    import android.webkit.WebViewClient;
    import android.widget.Toast;
    import androidx.appcompat.app.AppCompatActivity;

    public class MainActivity extends AppCompatActivity {

        @SuppressLint("SetJavaScriptEnabled")
        @Override
        protected void onCreate(Bundle savedInstanceState) {
            super.onCreate(savedInstanceState);

            WebView webView = new WebView(this);
            setContentView(webView);

            // 启用 JS
            webView.getSettings().setJavaScriptEnabled(true);
            webView.getSettings().setDomStorageEnabled(true);

            // 允许远程调试（Chrome inspect）
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.KITKAT) {
                WebView.setWebContentsDebuggingEnabled(true);
            }

            // 注入原生接口
            webView.addJavascriptInterface(new WebAppInterface(), "Android");

            // 拦截页面跳转（避免跳转到外部浏览器）
            webView.setWebViewClient(new WebViewClient());

            // 加载本地 HTML（放在 assets/ 目录）
            webView.loadUrl("file:///android_asset/index.html");
            // 或加载远程：webView.loadUrl("https://example.com");
        }

        // 原生方法暴露给 Web
        public class WebAppInterface {
            @JavascriptInterface
            public void showToast(String msg) {
                Toast.makeText(MainActivity.this, msg, Toast.LENGTH_SHORT).show();
            }
        }
    }
    ```

3. `assets/index.html`
    ```html
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="utf-8">
      <title>Android WebView</title>
    </head>
    <body>
      <h1>Android WebView 示例</h1>
      <button onclick="callNative()">调用原生 Toast</button>
      <button onclick="updateTitle()">原生将修改标题</button>

      <script>
        function callNative() {
          window.Android.showToast("Hello from Web!");
        }

        // 原生会调用此函数
        function updateTitle(newTitle) {
          document.title = newTitle;
          document.body.innerHTML += '<p>标题已更新为: ' + newTitle + '</p>';
        }
      </script>
    </body>
    </html>
    ```

> **注意**：  
> - `@JavascriptInterface` 必须添加，否则方法不可见  
> - `assets/` 文件夹需手动创建（右键 `app/src/main` → New → Folder → Assets Folder）

### 4.2.2 iOS（Swift + WKWebView）

1. 功能

    - 加载本地 HTML
    - Web → 原生（通过 `messageHandlers`）
    - 原生 → Web（`evaluateJavaScript`）

2. `ViewController.swift`
    ```swift
    import UIKit
    import WebKit

    class ViewController: UIViewController, WKScriptMessageHandler {
        var webView: WKWebView!

        override func viewDidLoad() {
            super.viewDidLoad()

            let config = WKWebViewConfiguration()
            config.userContentController.add(self, name: "ios") // 注册消息处理器

            webView = WKVectorizer(frame: view.bounds, configuration: config)
            view.addSubview(webView)

            // 加载本地 HTML（放在 Bundle 中）
            if let url = Bundle.main.url(forResource: "index", withExtension: "html") {
                webView.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
            }
        }

        // 接收 Web 发来的消息
        func userContentController(_ userContentController: WKUserContentController, didReceive     message: WKScriptMessage) {
            if message.name == "ios" {
                if let body = message.body as? [String: Any],
                   let action = body["action"] as? String {
                    if action == "showAlert" {
                        let msg = body["message"] as? String ?? "无消息"
                        showAlert(msg)
                    }
                }
            }
        }

        func showAlert(_ message: String) {
            let alert = UIAlertController(title: "来自 Web", message: message, preferredStyle: .    alert)
            alert.addAction(UIAlertAction(title: "OK", style: .default))
            present(alert, animated: true)
        }

        // 原生调用 Web JS（例如按钮触发）
        @objc func callWebFunction() {
            let js = "updateTitle('Hello from iOS')"
            webView.evaluateJavaScript(js, completionHandler: nil)
        }
    }
    ```

3. `index.html`（拖入 Xcode 项目）

    ```html
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="utf-8">
      <title>iOS WebView</title>
    </head>
    <body>
      <h1>iOS WKWebView 示例</h1>
      <button onclick="callNative()">调用原生弹窗</button>
      <button onclick="window.webkit.messageHandlers.ios.postMessage({action:'showAlert',   message:'Hi iOS!'})">
        另一种调用方式
      </button>

      <script>
        function callNative() {
          // 推荐方式：通过 messageHandlers
          window.webkit.messageHandlers.ios.postMessage({
            action: "showAlert",
            message: "Hello from Web!"
          });
        }

        function updateTitle(newTitle) {
          document.title = newTitle;
          document.body.innerHTML += '<p>收到原生消息: ' + newTitle + '</p>';
        }
      </script>
    </body>
    </html>
    ```

> **注意**：  
> - HTML 文件需加入 Xcode 项目（勾选 Target）  
> - 调试：Safari → 开发 → [你的设备] → 查看 WebView


### 4.2.3 Flutter（使用 `webview_flutter`）

1. 功能
    - 加载 HTML
    - 双向通信（`JavascriptChannel` + `runJavascript`）

2. 添加依赖（`pubspec.yaml`）

    ```yaml
    dependencies:
    webview_flutter: ^4.8.0
    ```

3. `main.dart`

    ```dart
    import 'package:flutter/material.dart';
    import 'package:webview_flutter/webview_flutter.dart';

    class WebViewExample extends StatefulWidget {
      @override
      _WebViewExampleState createState() => _WebViewExampleState();
    }

    class _WebViewExampleState extends State<WebViewExample> {
      late WebViewController _controller;

      @override
      Widget build(BuildContext context) {
        return Scaffold(
          appBar: AppBar(title: Text("Flutter WebView")),
          body: WebView(
            initialUrl: 'about:blank',
            onWebViewCreated: (WebViewController controller) {
              _controller = controller;
              _loadHtmlFromAssets();
            },
            javascriptMode: JavascriptMode.unrestricted,
            javascriptChannels: {
              JavascriptChannel(
                name: 'Flutter',
                onMessageReceived: (JavascriptMessage message) {
                  ScaffoldMessenger.of(context).showSnackBar(
                    SnackBar(content: Text(message.message)),
                  );
                },
              ),
            },
          ),
          floatingActionButton: FloatingActionButton(
            onPressed: () {
              _controller.runJavascript("updateTitle('Hello from Flutter')");
            },
            child: Icon(Icons.refresh),
          ),
        );
      }

      _loadHtmlFromAssets() async {
        String fileText = await DefaultAssetBundle.of(context).loadString("assets/index.html");
        _controller.loadUrl(Uri.dataFromString(fileText,
                mimeType: 'text/html', encoding: Encoding.getByName('utf-8')).toString());
      }
    }
    ```

4. `assets/index.html`（同上，放入 `assets/` 文件夹）

    ```html
    <!-- 内容同 Android/iOS 示例 -->
    <script>
      function callNative() {
        Flutter.postMessage("Hello from Web to Flutter!");
      }

      function updateTitle(newTitle) {
        document.title = newTitle;
        document.body.innerHTML += '<p>' + newTitle + '</p>';
      }
    </script>
    ```

> **注意**：  
> - 在 `pubspec.yaml` 中声明 assets：  
>   ```yaml
>   flutter:
>     assets:
>       - assets/
>   ```

### 4.2.4 React Native（使用 `react-native-webview`）

1. 功能

    - 注入 JS
    - `onMessage` / `postMessage` 双向通信

2. 安装

    ```bash
    npm install react-native-webview
    # iOS 需要 pod install
    ```

3. `App.js`

    ```jsx
    import React, { useRef } from 'react';
    import { View, Button, Alert } from 'react-native';
    import { WebView } from 'react-native-webview';

    const App = () => {
      const webviewRef = useRef(null);

      const injectJS = `
        (function() {
          window.ReactNativeWebView.postMessage(JSON.stringify({
            type: 'ready'
          }));
        })();
      `;

      const onMessage = (event) => {
        const data = JSON.parse(event.nativeEvent.data);
        if (data.type === 'callNative') {
          Alert.alert('来自 Web', data.message);
        }
      };

      const callWebFunction = () => {
        webviewRef.current?.injectJavaScript(`
          updateTitle('Hello from React Native');
          true; // 必须返回值
        `);
      };

      return (
        <View style={{ flex: 1 }}>
          <WebView
            ref={webviewRef}
            source={require('./assets/index.html')}
            onMessage={onMessage}
            injectedJavaScript={injectJS}
            javaScriptEnabled={true}
            domStorageEnabled={true}
            style={{ flex: 1 }}
          />
          <Button title="原生调用 Web" onPress={callWebFunction} />
        </View>
      );
    };

    export default App;
    ```

4. `assets/index.html`（放入项目根目录 `assets/`）

    ```html
    <script>
      function callNative() {
        window.ReactNativeWebView.postMessage(JSON.stringify({
          type: 'callNative',
          message: 'Hello from Web!'
        }));
      }

      function updateTitle(newTitle) {
        document.title = newTitle;
        document.body.innerHTML += '<p>' + newTitle + '</p>';
      }
    </script>
    ```

> **注意**：  
> - iOS 需在 `Info.plist` 添加本地文件访问权限（通常默认允许）  
> - 调试：Chrome 访问 `chrome://inspect`（Android）；Safari（iOS）


### 4.2.5  总结对比

| 平台 | 通信方式 | 调试工具 | 注意事项 |
|------|--------|--------|--------|
| **Android** | `addJavascriptInterface` | Chrome DevTools | 必须加 `@JavascriptInterface` |
| **iOS** | `WKScriptMessageHandler` | Safari Web Inspector | HTML 需加入 Bundle |
| **Flutter** | `JavascriptChannel` | Chrome/Safari | 需启用 `javascriptMode` |
| **React Native** | `postMessage` / `injectJavaScript` | React Native Debugger + 浏览器 | `injectJavaScript` 必须返回值 |

---

>  **建议**：  
> 所有平台都推荐 **将 HTML 放在本地**（而非远程），以提升加载速度、支持离线、避免 CORS。
