# 一、`#shadow-root` 与 `<iframe>` 

简单来说，**`#shadow-root`（Shadow DOM）和 `<iframe>` 都是实现“隔离”的技术，但它们的隔离级别、性能和适用场景完全不同。** 你可以把 `<iframe>` 想象成一个完全独立的“另一个网页”，而 Shadow DOM 更像是主网页内部一个封装好的“组件单元”。

## 1.1 认识两种隔离技术

### 1. 一个生动的类比

假设你有一个自己的房子（这是你的主页面）。

*   **`<iframe>` 就像在你房子里嵌入了一个完全独立的、带锁的玻璃房**。这个玻璃房：
    *   **完全隔离**：有自己的地基（独立的浏览上下文）、水电系统（独立的全局变量）、甚至自己的法律（同源策略）。
    *   **通信困难**：你想给玻璃房里的人递个东西，只能通过喊话（`postMessage` API），不能直接递过去。
    *   **资源消耗大**：维护这个玻璃房需要独立的一套维护团队。

*   **`#shadow-root` (Shadow DOM) 就像给你房子的某个房间安装了一个“智能收纳舱”**。这个收纳舱：
    *   **逻辑隔离**：它有自己的收纳规则（内部的CSS和DOM），不会被客厅的扫把（外部CSS）影响，它的灰尘也不会飘到客厅。但它仍然是**你房子的一部分**。
    *   **通信方便**：你可以随时打开这个收纳舱，直接往里面放东西或拿东西。
    *   **资源消耗小**：它依附于房子本身，不需要独立的维护团队。


### 2. 技术层面的深度对比

下面这张表格从技术角度，详细拆解了它们的核心区别：

| 特性 | `#shadow-root` (Shadow DOM) | `<iframe>` (内联框架) |
| :--- | :--- | :--- |
| **核心关系** | **属于**当前文档的一部分 | **嵌入**另一个完整的独立文档 |
| **隔离级别** | **DOM 和 CSS 隔离**。内部样式不影响外部，外部样式也不影响内部（除了某些CSS属性）。 | **完全隔离**。包括 JavaScript 全局对象、执行环境、历史记录、甚至是整个浏览器上下文。 |
| **通信方式** | **直接、同步**。可以通过事件冒泡（需要稍加配置）或直接操作DOM。 | **受限、异步**。必须通过 `postMessage` API 进行跨文档通信。 |
| **资源消耗** | **轻量**。因为共享主文档的浏览上下文，创建和销毁成本很低。 | **重量**。需要创建全新的浏览上下文，内存和性能开销都大得多。 |
| **典型用途** | **Web 组件**。用于封装复杂的UI组件（如 `<video>` 控件的内部实现、或自定义的卡片组件），确保组件在不同网站上的样式和行为不被干扰 。 | **嵌入第三方内容**。用于嵌入完全不信任的第三方内容（如广告、支付页面），或需要保持绝对独立的应用（如在线文档编辑器）。 |

### 3. 如何选择？

*   **选择 `#shadow-root` (Shadow DOM) 当你想：**
    *   创建一个可复用的自定义 UI 组件（例如一个带复杂样式的日期选择器），并希望无论把它放在哪个网页上，其内部样式都保持稳定。
    *   只想隔离 DOM 和 CSS，防止样式冲突，但组件本身仍然是主应用逻辑的一部分。
    *   你的目标是现代 Web 开发中的**组件化**。

*   **选择 `<iframe>` 当你想：**
    *   嵌入一个完全由第三方提供的、不可信的、或技术栈完全不同的内容（例如展示另一个网站的地图、嵌入一个 YouTube 视频、加载一个支付页面）。
    *   需要一个完全独立的 JavaScript 运行环境来防止冲突或提高安全性。
    *   加载一个本身非常庞大且复杂的应用，不想让它影响主页面的性能。

## 1.2 `#shadow-root`的使用

### 1. 核心概念：两种类型 (Mode)

创建 Shadow Root 时，`attachShadow()` 方法接受一个 `mode` 参数，决定了外部 JavaScript 能否访问内部 DOM：

1.  **`open` (开放模式)**:
    *   **代码**: `this.attachShadow({ mode: 'open' })`
    *   **特性**: 外部可以通过 `element.shadowRoot` 访问内部的 DOM 节点。
    *   **用途**: 需要外部控制内部样式或结构，或者进行调试时使用。
2.  **`closed` (封闭模式)**:
    *   **代码**: `this.attachShadow({ mode: 'closed' })`
    *   **特性**: 外部访问 `element.shadowRoot` 会返回 `null`。只有组件内部的代码持有 shadow root 的引用。
    *   **用途**: 真正的封装，防止外部脚本意外修改内部实现细节（类似私有属性）。


### 2. 完整代码示例 (纯 HTML + JS)

下面是一个单文件示例，展示了如何创建一个自定义元素，包含两种模式的对比（实际项目中通常选一种），并演示了完整的内外通信。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>Shadow DOM 完整技术演示</title>
    <style>
        body { font-family: sans-serif; padding: 20px; }
        .light-dom-style { color: gray; font-style: italic; }
        /* 注意：这里的样式不会影响 shadow-dom 内部，除非使用 ::part 或继承属性 */
    </style>
</head>
<body>

    <h1>Shadow DOM 技术演示</h1>
    
    <!-- 使用自定义元素 -->
    <my-widget id="widgetOpen" mode-type="open"></my-widget>
    <br>
    <my-widget id="widgetClosed" mode-type="closed"></my-widget>

    <div style="margin-top: 20px; border-top: 1px solid #ccc; padding-top: 10px;">
        <h3>外部控制区 (Light DOM)</h3>
        <button onclick="updateFromOutside()">从外部更新内部文本</button>
        <button onclick="tryAccessShadowRoot()">尝试访问 shadowRoot</button>
        <p id="log" class="light-dom-style">日志将显示在这里...</p>
    </div>

    <script>
        // 定义日志辅助函数
        function log(msg) {
            const p = document.getElementById('log');
            p.innerHTML += `<br>> ${msg}`;
            console.log(msg);
        }

        // 1. 定义自定义元素类
        class MyWidget extends HTMLElement {
            constructor() {
                super();
                
                // 获取用户在 HTML 上设置的属性，决定模式
                const modeType = this.getAttribute('mode-type') || 'open';
                
                // --- 关键技术点 1: 创建 Shadow Root ---
                this._shadowRoot = this.attachShadow({ 
                    mode: modeType // 'open' 或 'closed'
                });

                // --- 关键技术点 2: 内部样式隔离 ---
                // 内部的 style 只影响 shadow DOM 内部，不影响全局
                this._shadowRoot.innerHTML = `
                    <style>
                        :host {
                            display: block;
                            border: 2px dashed #3498db;
                            padding: 15px;
                            margin: 10px 0;
                            background: #f9f9f9;
                            font-family: monospace;
                        }
                        h2 { color: #2c3e50; margin-top: 0; }
                        button {
                            background: #e74c3c;
                            color: white;
                            border: none;
                            padding: 5px 10px;
                            cursor: pointer;
                        }
                        /* 插槽样式 */
                        slot {
                            display: block;
                            border: 1px dotted #999;
                            padding: 5px;
                            margin: 5px 0;
                            color: #666;
                        }
                    </style>
                    
                    <h2>我是 Shadow DOM (<span id="mode-display">${modeType}</span> Mode)</h2>
                    
                    <!-- 关键技术点 3: Slot (内容分发) -->
                    <!-- 允许外部 HTML 插入内容到这里 -->
                    <slot name="user-content">默认插槽内容</slot>
                    
                    <p id="internal-text">内部初始文本</p>
                    <button id="internal-btn">点击我触发内部事件</button>
                `;

                // 获取内部元素引用
                this._internalText = this._shadowRoot.getElementById('internal-text');
                this._internalBtn = this._shadowRoot.getElementById('internal-btn');
                this._modeDisplay = this._shadowRoot.getElementById('mode-display');

                // --- 关键技术点 4: 内部事件监听与向外通信 ---
                this._internalBtn.addEventListener('click', () => {
                    log(`[内部] 按钮被点击，模式: ${modeType}`);
                    
                    // 修改内部状态
                    this._internalText.textContent = "内部状态已改变!";

                    // 【向外通信】发送自定义事件
                    // composed: true 是关键，允许事件穿透 Shadow DOM 边界冒泡到外部
                    const event = new CustomEvent('widget-clicked', {
                        detail: { 
                            message: 'Hello from Shadow DOM!', 
                            timestamp: Date.now() 
                        },
                        bubbles: true, 
                        composed: true 
                    });
                    this.dispatchEvent(event);
                });
            }

            // --- 关键技术点 5: 暴露公共 API (方法) ---
            // 外部可以通过 element.updateText(...) 调用
            updateText(newText) {
                if (this._internalText) {
                    this._internalText.textContent = `[外部更新] ${newText}`;
                    log(`API 调用成功: 内部文本已更新`);
                } else {
                    log(`API 调用失败: 无法访问内部元素 (可能是 closed 模式且未保存引用，但在类内部我们总是有引用的)`);
                }
            }
            
            // 观察属性变化 (可选高级技术)
            static get observedAttributes() { return ['theme']; }
            attributeChangedCallback(name, oldValue, newValue) {
                if (name === 'theme') {
                    this._shadowRoot.host.style.background = newValue === 'dark' ? '#333' : '#f9f9f9';
                    this._shadowRoot.host.style.color = newValue === 'dark' ? '#fff' : '#000';
                }
            }
        }

        // 注册元素
        customElements.define('my-widget', MyWidget);

        // --- 外部交互逻辑 ---

        function updateFromOutside() {
            const openWidget = document.getElementById('widgetOpen');
            const closedWidget = document.getElementById('widgetClosed');

            // 调用公共方法
            openWidget.updateText("外部通过 API 更新 (Open)");
            closedWidget.updateText("外部通过 API 更新 (Closed)");
        }

        function tryAccessShadowRoot() {
            const openWidget = document.getElementById('widgetOpen');
            const closedWidget = document.getElementById('widgetClosed');

            // 尝试直接访问 shadowRoot 属性
            const openRoot = openWidget.shadowRoot;
            const closedRoot = closedWidget.shadowRoot;

            if (openRoot) {
                log(`✅ Open 模式: 成功访问 shadowRoot，内部 H2 文本: "${openRoot.querySelector('h2').innerText}"`);
                // 甚至可以强行修改内部 DOM (不推荐，但技术上可行)
                openRoot.querySelector('h2').style.color = 'green';
            } else {
                log(`❌ Open 模式: 访问失败 (这不应该发生)`);
            }

            if (closedRoot) {
                log(`⚠️ Closed 模式: 居然能访问？(检查代码逻辑)`);
            } else {
                log(`🔒 Closed 模式: shadowRoot 为 null，外部无法直接访问内部 DOM 节点。只能通过 API 通信。`);
            }
        }

        // 监听来自内部的事件
        document.addEventListener('widget-clicked', (e) => {
            log(`📩 收到内部事件: ${e.detail.message} (时间: ${e.detail.timestamp})`);
            alert(`捕获到事件:\n${e.detail.message}`);
        });

    </script>
</body>
</html>
```


### 3. 技术详解：内外通信机制

在不使用框架的情况下，Shadow DOM 内外的通信主要依赖以下三种方式：

#### A. 从内向外 (Shadow → Light)
**核心机制：自定义事件 (Custom Events)**
这是最标准、解耦最好的方式。
*   **关键点**: 必须设置 `composed: true`。
    *   `bubbles: true`: 允许事件冒泡。
    *   `composed: true`: 允许事件**穿越** Shadow DOM 边界。如果设为 `false`，事件会在 Shadow Root 处停止，外部听不到。
*   **数据传递**: 通过 `detail` 对象传递任意 JSON 数据。

```javascript
// 内部代码
this.dispatchEvent(new CustomEvent('my-event', {
    detail: { foo: 'bar' },
    bubbles: true,
    composed: true // 必须为 true
}));

// 外部代码
element.addEventListener('my-event', (e) => {
    console.log(e.detail.foo); 
});
```

#### B. 从外向内 (Light → Shadow)
有三种主要方式，推荐程度依次降低：

1.  **公共方法 (Public Methods) - 推荐**
    *   在 `class` 中定义普通方法（如 `updateText()`）。
    *   外部通过 `element.updateText('data')` 调用。
    *   **优点**: 明确的 API 接口，封装性好，适用于 `closed` 模式。

2.  **属性/属性观察器 (Attributes / Observers)**
    *   外部修改 HTML 属性：`element.setAttribute('status', 'active')` 或直接 `element.status = 'active'` (需配合 getter/setter)。
    *   内部使用 `static get observedAttributes()` 和 `attributeChangedCallback` 监听变化。
    *   **优点**: 声明式，适合配置项。

3.  **直接操作 DOM (仅限 Open 模式) - 不推荐**
    *   外部：`element.shadowRoot.querySelector('.btn').click()`。
    *   **缺点**: 破坏了封装性。如果组件升级为 `closed` 模式，外部代码会立即崩溃。仅用于调试或极度特殊的场景。

#### C. 内容分发 (光投射到影)
**核心机制：`<slot>` 标签**
这不是数据通信，而是**结构通信**。允许外部 HTML 内容“流入”Shadow DOM 的指定位置。

*   **内部**: `<slot name="header">默认标题</slot>`
*   **外部**: 
    ```html
    <my-component>
        <h1 slot="header">这是外部传入的标题</h1>
    </my-component>
    ```
*   **样式注意**: 外部传入的内容（Light DOM）依然受外部 CSS 影响，但它在 Shadow DOM 中的布局位置由 Shadow CSS 控制。可以使用 `::slotted(selector)` 伪元素在 Shadow CSS 中微调插槽内容的样式（限制较多，只能针对直接子元素）。



### 4. 关键注意事项

1.  **CSS 隔离**: Shadow DOM 内部的 `<style>` 不会影响外部，外部的 `<style>` 也不会影响内部（除了继承属性如 `font-family`, `color` 等）。
2.  **事件流**: 记住 `composed: true` 是跨边界通信的钥匙。
3.  **生命周期**: 自定义元素有标准的生命周期回调：`constructor` (初始化), `connectedCallback` (插入文档), `disconnectedCallback` (移除), `attributeChangedCallback` (属性变)。
4.  **无框架依赖**: 上述所有代码均基于浏览器原生 API (`HTMLElement`, `attachShadow`, `CustomEvent`)，无需构建工具即可运行。

## 1.4 `<iframe>`的使用


### 1. 基础使用

- 最简单的示例
    ```html
    <iframe 
      src="https://example.com" 
      width="100%" 
      height="400px">
      <!-- 备选内容（浏览器不支持iframe时显示） -->
      <p>您的浏览器不支持iframe</p>
    </iframe>
    ```

- 常用属性组合

    ```html
    <iframe 
      src="page.html" 
      width="800" 
      height="600"
      frameborder="0"  <!-- 移除边框 -->
      scrolling="auto" <!-- 滚动条：yes, no, auto -->
      name="myframe"   <!-- 命名，用于target -->
      id="frame1">
    </iframe>
    ```

### 2. 样式控制

- 基础样式

    ```css
    iframe {
      border: none;           /* 移除边框 */
      border-radius: 8px;     /* 圆角 */
      box-shadow: 0 2px 8px rgba(0,0,0,0.1); /* 阴影 */
      max-width: 100%;        /* 响应式 */
      display: block;         /* 块级显示 */
    }
    ```

- 响应式iframe（保持宽高比）

    ```css
    .iframe-container {
      position: relative;
      width: 100%;
      padding-bottom: 56.25%; /* 16:9比例 */
      height: 0;
      overflow: hidden;
    }

    .iframe-container iframe {
      position: absolute;
      top: 0;
      left: 0;
      width: 100%;
      height: 100%;
    }
    ```
    ```html
    <div class="iframe-container">
      <iframe src="https://youtube.com/embed/video-id"></iframe>
    </div>
    ```

### 3. 安全配置

- 完整的sandbox使用

    ```html
    <iframe 
      src="https://example.com"
      sandbox="
        allow-scripts           <!-- 允许脚本 -->
        allow-same-origin       <!-- 保持同源 -->
        allow-forms            <!-- 允许表单 -->
        allow-popups           <!-- 允许弹窗 -->
        allow-modals           <!-- 允许模态框 -->
        allow-orientation-lock <!-- 允许旋转锁定 -->
      ">
    </iframe>
    ```

- 限制最严格的配置

    ```html
    <!-- 只允许基本内容，禁止一切 -->
    <iframe src="content.html" sandbox></iframe>
    ```

### 4. JavaScript交互

- 父页面操作iframe

    ```javascript
    // 获取iframe元素
    const iframe = document.getElementById('myframe');

    // 访问iframe内部内容（需同源）
    iframe.contentWindow.document.body.style.background = 'red';
    iframe.contentDocument.getElementById('btn').click();

    // 调用iframe内的函数
    iframe.contentWindow.myFunction();

    // 向iframe发送消息（跨域可用）
    iframe.contentWindow.postMessage('hello', 'https://example.com');
    ```

- iframe内访问父页面

    ```javascript
    // 获取父页面（需同源）
    const parentDoc = window.parent.document;

    // 调用父页面函数
    window.parent.parentFunction();

    // 向父页面发送消息
    window.parent.postMessage('来自iframe的消息', '*');
    ```

- 跨域通信

    ```javascript
    // 父页面监听消息
    window.addEventListener('message', (event) => {
      // 验证来源（安全考虑）
      if (event.origin !== 'https://example.com') return;
    
      console.log('收到消息：', event.data);
      // 可以回复消息
      event.source.postMessage('已收到', event.origin);
    });

    // 发送消息
    iframe.contentWindow.postMessage('你好', 'https://example.com');
    ```

### 5. 实际应用场景

1. 嵌入视频

    ```html
    <!-- B站视频 -->
    <iframe 
      src="//player.bilibili.com/player.html?aid=123456"
      scrolling="no"
      border="0"
      frameborder="no"
      framespacing="0"
      allowfullscreen="true">
    </iframe>

    <!-- YouTube视频（隐私增强模式） -->
    <iframe 
      src="https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ"
      allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope;  picture-in-picture"
      allowfullscreen>
    </iframe>
    ```

2. 嵌入地图

    ```html
    <!-- 百度地图 -->
    <iframe 
      width="100%" 
      height="400px" 
      src="https://map.baidu.com/">
    </iframe>

    <!-- 高德地图 -->
    <iframe 
      src="https://uri.amap.com/marker">
    </iframe>
    ```

3. PDF预览

    ```html
    <iframe 
      src="document.pdf#view=fitH"
      width="100%" 
      height="600px">
      <p>您的浏览器不支持PDF预览，请<a href="document.pdf">下载PDF</a></p>
    </iframe>
    ```

### 6. 性能优化

- 懒加载

    ```html
    <!-- 滚动到可视区域才加载 -->
    <iframe src="heavy-page.html" loading="lazy"></iframe>

    <!-- 或使用Intersection Observer -->
    <script>
    const iframe = document.querySelector('iframe');
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          iframe.src = iframe.dataset.src;
          observer.unobserve(iframe);
        }
      });
    });
    observer.observe(iframe);
    </script>
    ```

- 预加载

    ```html
    <!-- 预连接 -->
    <link rel="preconnect" href="https://example.com">

    <!-- DNS预解析 -->
    <link rel="dns-prefetch" href="https://example.com">
    ```

### 7. 常见问题解决

1. X-Frame-Options限制
    如果遇到 `Refused to display in a frame`：
    ```html
    <!-- 无法直接解决，需要被嵌入网站允许 -->
    <!-- 可以在自己的服务器做代理 -->
    <iframe src="/proxy?url=https://example.com"></iframe>
    ```

2. 自动调整高度

    ```javascript
    // 父页面监听消息
    window.addEventListener('message', (e) => {
      if (e.data.type === 'setHeight') {
        document.getElementById('myframe').style.height = e.data.height + 'px';
      }
    });

    // iframe内部
    window.parent.postMessage({
      type: 'setHeight',
      height: document.body.scrollHeight
    }, '*');
    ```

3. 防止点击劫持
```javascript
// 检查是否被嵌入
if (window.top !== window.self) {
  // 被嵌入时跳转
  window.top.location = window.self.location;
}

// 或通过X-Frame-Options
// 服务器设置：X-Frame-Options: SAMEORIGIN
```

2. 创建动态iframe

    ```javascript
    function createIframe(url, options = {}) {
      const iframe = document.createElement('iframe');
    
      iframe.src = url;
      iframe.width = options.width || '100%';
      iframe.height = options.height || '400px';
    
      if (options.sandbox) {
        iframe.sandbox = options.sandbox;
      }
    
      document.body.appendChild(iframe);
      return iframe;
    }
    ```
