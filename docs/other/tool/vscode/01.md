# 一、VSCode 安装

## 1.1 安装软件

1. 下载软件

    下载网站：[https://code.visualstudio.com/Download](https://code.visualstudio.com/Download)

    ![](/other/tool/vscode/018.png)

2. 双击进行安装




## 1.2 安装替代品 VSCodium


如果你不想拥有AI功能，与发送给微软信息，安装VSCodium

1. 下载软件

    下载地址：[VSCodiumSetup-x64-1.110.11631.exe](https://github.com/VSCodium/vscodium/releases)

2. 双击进行安装

    - 注意，将 vscode 加入Path就能 code . 直接打开代码

    ![](/other/tool/vscode/019.png)
