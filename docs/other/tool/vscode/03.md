### 3.1.3 CSS Peek

可以快速预览CSS样式，在HTML文件中，通过将鼠标悬停在样式名上，可以快速预览该样式的CSS代码，包括选择器、属性和值等。快速编辑CSS样式，在HTML文件中，通过双击样式名或属性名，可以快速跳转到CSS文件中对应的代码行，进行编辑。自动完成CSS样式，在CSS文件中，通过输入部分样式名或属性名，可以自动弹出补全选项，提高编写效率。显示CSS样式引用，在HTML文件中，通过将鼠标悬停在样式名上，可以显示该样式被哪些HTML元素引用。支持多个CSS文件，在HTML文件中，如果有多个CSS文件，可以通过切换文件进行查看和编辑。总之，CSS Peek可以提高CSS样式的编写效率和准确性，同时也方便了对CSS样式的管理和维护。

## 3.2 离线装插件

### 3.2.1 方法一

1. 到vscode官网 https://marketplace.visualstudio.com/vscode 搜索需要使用的插件名称
2. 下载对应扩展程序文件

![](/other/tool/vscode/009.png)

3. 到vscode中选择 "从VSIX安装"

![](/other/tool/vscode/010.png)


4. 选择下载的扩展文件进行安装即可


### 3.2.2 方法二

备注：如果遇见使用方法一离线安装失败的情况，建议使用该方法进行安装，如 vetur 插件下载不成功，可以使用此方法。

操作步骤：

1. 查找已安装的插件列表文件：路径一般为 C:\Users\用户名\.vscode\extensions

2. 将所需使用的插件文件复制到U盘，用U盘拷贝相关文件到需要离线安装的电脑上的 .vscode/extensions 文件夹下即可，重启vscode 即可安装成功。


### 3.2.3 新方法(20260302)

在无法访问外网或网络受限的环境下，离线安装 VS Code 插件通常采用“先下载、后安装”的方式。你需要先获取插件的 `.vsix` 文件，然后在 VS Code 中手动安装。

以下是离线安装 Vue(Official) 插件的具体步骤：

#### 第一步：获取插件的离线安装包 (.vsix 文件)

插件的安装包后缀为 `.vsix`。你可以通过以下两种方式在可以联网的电脑上下载到它：

*   **方法一：从 VS Code 插件市场下载（最推荐）**
    你可以通过拼接特定 URL 的方式，直接从微软官方市场下载任意版本的插件 。以 Vue(Official) 插件为例：
    1.  你需要知道该插件的发布者（`Vue`）和唯一标识符（`volar`）。
    2.  **下载链接格式**：`https://marketplace.visualstudio.com/_apis/public/gallery/publishers/{发布者}/vsextensions/{插件名}/{版本号}/vspackage`
    3.  **例如**：要下载 **3.0.1** 版本，完整的下载链接就是：
        `https://marketplace.visualstudio.com/_apis/public/gallery/publishers/Vue/vsextensions/volar/3.0.1/vspackage`
    在浏览器中打开这个链接，就会开始下载一个名为 `vspackage` 的文件，下载后将其重命名为 `vue-official.vsix` 或你容易识别的名称即可。

*   **方法二：从第三方 VSIX 镜像站下载**
    有一些第三方网站会存档 VS Code 插件的各种版本，你可以直接搜索并下载。例如 [VsixHub](https://www.vsixhub.com/) 这类网站 。
    *   **优点**：通常有版本历史列表，选择更直观。
    *   **缺点**：属于第三方站点，建议注意文件安全性，下载后最好校验一下 MD5 值 。

####  第二步：在 VS Code 中离线安装

将下载好的 `.vsix` 文件通过U盘或其他方式拷贝到无法联网的目标电脑上，然后按以下步骤操作：

1.  打开 VS Code。
2.  打开命令面板。使用快捷键 `Ctrl+Shift+P` （Windows/Linux） 或 `Cmd+Shift+P` （macOS） 。
3.  在命令面板中输入 `install`，从下拉列表中找到并选择 **“Extensions: Install from VSIX...”** （从 VSIX 安装...） 选项 。
4.  此时会弹出文件选择窗口，导航到你存放 `.vsix` 文件的位置，选中它并点击“安装”。
5.  安装成功后，VS Code 可能会提示你重新加载窗口以启用插件。
