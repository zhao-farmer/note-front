# 五、使用优化记录

## 5.1 新的终端无法实用

- vscode错误信息：

    ```
    The terminal process failed to launch: A native exception occurredduring launch (Cannot launch conpty).
    ```

- VSCodium错误信息：

    ```
    The terminal process failed to launch: A native exception occurred during launch (Cannot launch conpty). Winpty has been removed, see https://code.visualstudio.com/updates/v1_109#_removal-of-winpty-support for more details. You can also try enabling the terminal.integrated.windowsUseConptyDll setting.
    ```
- 原因：

    是 Visual Studio Code（VS Code）在 Windows 系统上启动终端时发生的错误，核心原因是：
    VS Code 从 v1.109 版本开始移除了对 winpty 的支持。
    原本用于兼容旧版 Windows 终端的 winpty 已被弃用，现在默认使用更现代的 ConPTY（Console Pseudo-Terminal）。
    但你的系统或环境可能不支持 ConPTY，或者配置冲突导致无法启动。

- 解决方案：

    下载低版本的VScode进行安装，只能说win11的阴谋

## 5.2 vscode 复制一直转圈圈

1. 关闭「粘贴时自动更新导入」（TS/JS 最常见）

    打开设置（Ctrl+,）→ 打开右上角 `{}`（JSON）→ 加入：
    ```json
    "typescript.updateImportsOnPaste.enabled": false,
    "javascript.updateImportsOnPaste.enabled": false
    ```
    保存后立刻见效，尤其大项目/远程项目。

2. 关闭「复制带语法高亮」

    ```json
    "editor.copyWithSyntaxHighlighting": false
    ```
    复制大段代码时能明显提速。

3. 禁用「粘贴为」智能功能

    ```json
    "editor.pasteAs.enabled": false
    ```
    避免 VS Code 自动解析粘贴内容导致卡顿。
