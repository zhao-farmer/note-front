# 一、认识JavaScript

## 1.1 JavaScript简介

JavaScript（简称JS）是一种轻量级的解释型编程语言，它是实现ECMAScript（ES）标准的一种具体方式。JavaScript主要用于为网页添加交互功能，使静态页面具备动态效果。

- **运行环境**：浏览器中默认集成了JavaScript环境，因此使用浏览器开发时不需要额外配置运行环境，开箱即用。
- **应用场景**：除了浏览器端，JavaScript还可以通过Node.js在服务器端运行，实现全栈开发。

## 1.2 Hello World

在HTML文件中，JavaScript代码需要编写到 `<script>` 标签中。以下是三种常用的输出方式：

```html
<!-- JS代码需要编写到script标签中 -->
<script>
    // 弹窗输出（浏览器弹窗提示）
    alert('hello world');
    
    // 控制台输出（在开发者工具的Console面板中显示）
    console.log('hello world');
    
    // 向文档（网页）中输出（在页面中渲染显示）
    document.write('hello world');
</script>
```

> **提示**：按 `F12` 键打开开发者工具，可以在Console面板中看到 `console.log()` 的输出结果。

## 1.3 编写位置

JavaScript代码可以在HTML文件中的多个位置编写，不同位置会影响代码的执行时机。

### 1.3.1 内部标签 — 写在HTML标签内

可以直接将JavaScript代码写在网页内部的 `<script>` 标签中，`<script>` 标签可以放置在HTML文档的不同位置：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>JavaScript编写位置</title>
    <!-- 写在head中：在页面内容加载前执行 -->
    <script>
        console.log('写在head中');
    </script>
</head>
<body>
    <!-- 写在body中：在页面内容加载过程中执行 -->
    <script>
        console.log('写在body中');
    </script>
</body>
</html>
<!-- 写在html标签外：在文档解析完成后执行（虽然有效，但不推荐） -->
<script>
    console.log('写在html标签外');
</script>
```

**浏览器展示效果：**

![](/script/JavaScript/base/001.png)

> **执行顺序说明**：
> - `<head>` 中的脚本：在页面解析 `<head>` 时执行
> - `<body>` 中的脚本：在页面解析到对应位置时执行
> - 建议将不依赖DOM元素的脚本放在 `<head>` 中，将操作DOM元素的脚本放在 `</body>` 前

### 1.3.2 外部引入 — 写在独立的 `.js` 文件中

可以将JavaScript代码编写到外部的 `.js` 文件中，然后通过 `<script>` 标签的 `src` 属性引入：

```html
<script src="./script/script.js"></script>
```

**注意事项**：
- 使用 `src` 属性引入外部文件后，该 `<script>` 标签内**不能再编写任何JavaScript代码**，否则会被忽略。
- 外部引入方式有利于代码复用和页面结构分离，是实际开发中的推荐做法。

### 1.3.3 利用属性 — 写在HTML标签的属性中

可以将简短的JavaScript代码直接写在HTML标签的事件属性或链接中：

```html
<!-- 点击按钮时弹出提示 -->
<button onclick="alert('你点我干嘛！')">点我一下</button>

<hr>

<!-- 点击超链接时执行JavaScript代码 -->
<a href="javascript:alert(123);">超链接</a>
```

> **不推荐**：这种方式将HTML结构与JavaScript逻辑混在一起，不利于代码维护，仅适用于极简场景或快速测试。

## 1.4 基本语法

掌握JavaScript的基本语法规则，有助于编写规范且不易出错的代码。

| 规则 | 说明 | 示例 |
|------|------|------|
| **注释** | 多行注释：`shift + alt + a`（VSCode）→ `/** */`<br>单行注释：`shift + /` → `//` | `// 这是单行注释`<br>`/* 这是多行注释 */` |
| **大小写敏感** | JavaScript严格区分大小写 | `myName` 和 `myName` 是同一个变量，`MyName` 是另一个变量 |
| **空格与换行** | 空格和换行会被JavaScript引擎忽略 | 可利用此特点对代码进行格式化排版，提高可读性 |
| **语句结束符** | 每条语句建议以分号 `;` 结尾 | `let a = 10;` |
| **自动分号插入（ASI）** | JavaScript具有自动添加分号的机制，即使不写分号，解释器也会在行尾自动补上 |  但某些情况下可能产生意外结果，**建议始终手动添加分号** |

### 代码示例

```javascript
// 单行注释示例
let message = 'Hello';  // 建议以分号结尾

/*
 * 多行注释示例
 * 用于函数或复杂逻辑的说明
 */
function greet(name) {
    console.log('Hello, ' + name);
}
```
