# 三、数据类型

数据类型指的是那些可以赋值给变量的值的类型。JavaScript 中的数据类型由**原始值（Primitive Values）**和**对象（Objects）**共同组成。

JavaScript 中一共包含以下 **7 种原始值**：

| 序号 | 数据类型 | 英文名称 | 说明 |
|------|----------|----------|------|
| 1 | 数值 | Number | 整数和浮点数 |
| 2 | 大整数 | BigInt | 任意精度的整数 |
| 3 | 字符串 | String | 文本数据 |
| 4 | 布尔值 | Boolean | true / false |
| 5 | 空值 | Null | 表示空对象 |
| 6 | 未定义 | Undefined | 未赋值的变量 |
| 7 | 符号 | Symbol | 唯一标识符 |

> **核心概念**：原始值在 JavaScript 中是**不可变类型（Immutable）**，一旦创建就不能被修改。任何看似"修改"的操作，实际上都是创建了一个新的值。


## 3.1 数值（Number）

1. 基本特性

    - 在 JavaScript 中，所有的整数和浮点数都是 `Number` 类型
    - JavaScript 中的数值遵循 IEEE 754 标准，使用**双精度浮点数**（64位）表示
    - 数值范围并非无限，超出安全范围后会显示为近似值

    | 特殊值 | 含义 | 说明 |
    |--------|------|------|
    | `Infinity` | 正无穷 | 超出最大正数范围时得到 |
    | `-Infinity` | 负无穷 | 超出最小负数范围时得到 |
    | `NaN` | Not a Number | 表示非法的数值运算结果 |

2. 代码示例

    ```javascript
    let a = 10;
    console.log(typeof a);  // number

    // 浮点数
    a = 10.5;
    console.log(typeof a);  // number

    // 精度问题：超过安全范围的整数会丢失精度
    a = 99999999999999991;
    console.log(a);  // 99999999999999980（精度丢失）

    // 数值运算超出范围 -> Infinity
    a = 99999 ** 99999;
    console.log(a);  // Infinity

    // 浮点数运算精度问题（经典坑）
    a = 0.1 + 0.2;
    console.log(a);  // 0.30000000000000004（而非 0.3）

    // 非法数值运算 -> NaN
    a = 1 - 'a';
    console.log(a);  // NaN
    console.log(typeof a);  // number（NaN 的类型是 number）
    ```

> **注意**：`NaN` 有一个特殊性质——它**不等于任何值**，包括它自己：
> ```javascript
> console.log(NaN === NaN);  // false
> ```


## 3.2 大整数（BigInt）

- 大整数用来表示**超出 Number 安全范围**（`-2^53` ~ `2^53`）的整数
- 大整数使用**数字末尾加 `n`** 的方式表示
- BigInt 可以表示的数值范围是**无限的**（理论上受内存限制）

```javascript
let a = 9999999999999999999999999999999999999999999999999999999999999999999999999999n;
console.log(a);  // 精确显示，不会丢失精度
console.log(typeof a);  // bigint
```

> **注意**：BigInt 与 Number 不能直接进行混合运算，需要显式转换：
> ```javascript
> let num = 10n + 5n;     // 15n
> // let num2 = 10n + 5;  // TypeError（不能混合运算）
> ```


## 3.3 不同进制的表示

| 进制 | 前缀 | 示例 | 十进制值 |
|------|------|------|----------|
| 二进制 | `0b` | `0b1010` | 10 |
| 八进制 | `0o` | `0o10` | 8 |
| 十六进制 | `0x` | `0xff` | 255 |

```javascript
let a = 0b1010;
console.log(a);  // 10

a = 0o10;
console.log(a);  // 8

a = 0xff;
console.log(a);  // 255
```


## 3.4 类型检查（typeof 运算符）

`typeof` 运算符用于检查值的类型，它会根据不同值返回对应的类型字符串。

| 值 | `typeof` 返回结果 |
|----|-------------------|
| 数字（Number） | `"number"` |
| 大整数（BigInt） | `"bigint"` |
| 字符串（String） | `"string"` |
| 布尔值（Boolean） | `"boolean"` |
| 空值（null） | `"object"` （历史遗留 bug） |
| 未定义（undefined） | `"undefined"` |
| 符号（Symbol） | `"symbol"` |
| 对象（Object） | `"object"` |
| 函数（Function） | `"function"` |

```javascript
let a = 10;
let b = 10n;
console.log(typeof a);  // number
console.log(typeof b);  // bigint
```

> **注意**：`typeof null` 返回 `"object"` 是 JavaScript 设计上的一个历史遗留 bug，虽然它不会修复，但我们需要知道这一点。


## 3.5 字符串（String）

### 3.5.1 字符串的表示

- 在 JavaScript 中，使用**单引号（`'`）**或**双引号（`"`）**来表示字符串
- 字符串是**不可变**的，任何修改操作都会创建新的字符串

```javascript
let a = 'Hello';
a = "你好";
console.log(a);  // 你好
```

### 3.5.2 转义字符

| 转义字符 | 含义 |
|----------|------|
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\\` | 反斜杠 |
| `\t` | 制表符（Tab） |
| `\n` | 换行符 |

```javascript
a = "这是一个\"字符串\"";
console.log(a);  // 这是一个"字符串"
```

### 3.5.3 模板字符串（Template String）

- 使用**反引号（`` ` ``）** 表示模板字符串
- 支持**多行文本**
- 使用 `${表达式}` 嵌入变量或表达式

```javascript
// 多行字符串
a = `今天
    天气
    很好`;
console.log(a);
/* 输出：
今天
    天气
    很好
*/

// 变量嵌入
let name = '孙悟空';
let str = `你好，${name}`;
console.log(str);  // 你好，孙悟空

let b = 10;
console.log(`b = ${b}`);  // b = 10
console.log(`b + 5 = ${b + 5}`);  // b + 5 = 15（支持表达式）
```

> **推荐**：在需要拼接字符串和变量时，优先使用模板字符串，代码更简洁可读。


## 3.6 其他数据类型

### 3.6.1 布尔值（Boolean）

- 布尔值用于**逻辑判断**
- 只有两个值：`true`（真）和 `false`（假）

```javascript
let bool = true;
console.log(bool);           // true
console.log(typeof bool);    // boolean
```

### 3.6.2 空值（Null）

- `null` 表示**空对象**，用于显式表示"没有值"
- 只有一个值：`null`
- `typeof null` 返回 `"object"`（历史遗留问题）

```javascript
let a = null;
console.log(a);           // null
console.log(typeof a);    // object（注意！）
```

### 3.6.3 未定义（Undefined）

- 当声明变量但**没有赋值**时，变量的值就是 `undefined`
- 只有一个值：`undefined`

```javascript
let d;                    // 声明但未赋值
console.log(d);           // undefined

d = undefined;            // 显式赋值
console.log(d);           // undefined
console.log(typeof d);    // undefined
```

### 3.6.4 符号（Symbol）

- `Symbol` 用于创建一个**唯一标识符**
- 即使传入相同的描述字符串，每次创建的 Symbol 也是不同的

```javascript
let c = Symbol();         // 创建 Symbol
console.log(c);           // Symbol()
console.log(typeof c);    // symbol

let s1 = Symbol('id');
let s2 = Symbol('id');
console.log(s1 === s2);   // false（每个 Symbol 都是唯一的）
```

> **应用场景**：Symbol 常用于对象的**唯一属性键**，避免属性名冲突。


## 3.7 类型转换

类型转换指将一种数据类型转换为其他类型，主要分为三种：**转换为字符串**、**转换为数值**、**转换为布尔值**。

### 3.7.1 转换为字符串

| 方法 | 语法 | 特点 |
|------|------|------|
| `toString()` 方法 | `值.toString()` | 无法处理 `null` 和 `undefined` |
| `String()` 函数 | `String(值)` | 可以处理所有类型 |

**String() 函数的转换规则**：

| 原始值 | 转换为字符串 |
|--------|-------------|
| 数字 | 对应的数字字符串（如 `123` → `"123"`） |
| 布尔值 | `true` → `"true"`，`false` → `"false"` |
| null | `"null"` |
| undefined | `"undefined"` |
| 对象 | 调用对象的 `toString()` 方法 |

```javascript
// toString() 方法 —— 无法处理 null 和 undefined
let a = 10;
a = a.toString();
console.log(typeof a, a);  // string "10"

let b = null;
// b.toString();           // 报错：Cannot read properties of null

// String() 函数 —— 推荐使用
b = String(b);
console.log(typeof b, b);  // string "null"

let c = undefined;
c = String(c);
console.log(typeof c, c);  // string "undefined"
```

> **建议**：优先使用 `String()` 函数，因为它能安全处理所有数据类型。


### 3.7.2 转换为数值

- 方法一：Number() 函数

    | 原始值 | 转换结果 | 说明 |
    |--------|----------|------|
    | 合法数字字符串 | 对应的数字 | `"123"` → `123` |
    | 非法数字字符串 | `NaN` | `"abc"` → `NaN` |
    | 空字符串 `""` | `0` | |
    | 只含空格的字符串 | `0` | |
    | `true` | `1` | |
    | `false` | `0` | |
    | `null` | `0` | |
    | `undefined` | `NaN` | |

    ```javascript
    let a = '123';
    console.log(Number(a));    // 123

    a = 'abc';
    console.log(Number(a));    // NaN

    a = '';                    // 空字符串
    console.log(Number(a));    // 0

    a = '   ';                 // 空格字符串
    console.log(Number(a));    // 0

    a = true;
    console.log(Number(a));    // 1

    a = null;
    console.log(Number(a));    // 0

    a = undefined;
    console.log(Number(a));    // NaN
    ```

- 方法二：parseInt() 和 parseFloat()

    | 方法 | 用途 | 特点 |
    |------|------|------|
    | `parseInt()` | 解析整数 | 从左到右读取有效数字，直到遇到非数字字符 |
    | `parseFloat()` | 解析浮点数 | 读取有效数字，保留小数点 |

    ```javascript
    let b = '123px';
    console.log(parseInt(b));   // 123（忽略 'px'）

    b = '3.1415cm';
    console.log(parseFloat(b)); // 3.1415（忽略 'cm'）

    b = '100.5px';
    console.log(parseInt(b));   // 100（只取整数部分）

    // 对数字取整
    let num = 3.99;
    console.log(parseInt(num)); // 3
    ```


### 3.7.3 转换为布尔值

使用 `Boolean()` 函数将其他类型转换为布尔值。

| 类型 | 转为 `false` 的值 | 转为 `true` 的值 |
|------|-------------------|------------------|
| 数字 | `0`、`NaN` | 其他所有数字（包括负数、`Infinity`） |
| 字符串 | 空字符串 `""` | 其他所有字符串（包括 `" "`、`"false"`） |
| null | `null` | 无 |
| undefined | `undefined` | 无 |
| 对象 | 无 | 所有对象（包括空对象 `{}`） |

```javascript
// 数字转布尔值
console.log(Boolean(1));          // true
console.log(Boolean(0));          // false
console.log(Boolean(-1));         // true
console.log(Boolean(NaN));        // false
console.log(Boolean(Infinity));   // true

// 字符串转布尔值
console.log(Boolean('abc'));      // true
console.log(Boolean('true'));     // true
console.log(Boolean('false'));    // true（非空字符串）
console.log(Boolean(''));         // false
console.log(Boolean(' '));        // true（包含空格）

// null 和 undefined
console.log(Boolean(null));       // false
console.log(Boolean(undefined));  // false

// 对象
console.log(Boolean({}));         // true
console.log(Boolean([]));         // true
```

> **记忆口诀**：转换为 `false` 的值有 **6 个** —— `0`、`NaN`、`""`、`null`、`undefined`、`false`。
