# 五、流程控制

**流程控制语句**用于改变程序执行的顺序，使代码能够根据条件执行不同的分支，或重复执行某段代码。

JavaScript 中的流程控制主要分为三大类：

| 类别 | 说明 | 关键词/语句 |
|------|------|-------------|
| **条件判断语句** | 根据条件决定是否执行某段代码 | `if`、`if-else`、`if-else if-else` |
| **条件分支语句** | 根据表达式的值匹配多个分支 | `switch-case` |
| **循环语句** | 重复执行某段代码 | `while`、`do-while`、`for` |


## 5.1 代码块 `{ }`

代码块使用 `{}` 创建，用于对多行代码进行**分组**。同一个代码块中的代码要么全部执行，要么全部不执行。


在 JavaScript 中，`let` 和 `var` 声明的变量在代码块中的表现不同：

| 关键字 | 作用域 | 代码块外部能否访问 |
|--------|--------|-------------------|
| `let` | **块作用域** | 不能访问 |
| `var` | 函数作用域 | 可以访问（不受块限制） |

```javascript
{
    var b = 5;      // var 不受块作用域限制
    let a = 10;     // let 只能在块内访问
}
console.log(b);     // 5（可以访问）
// console.log(a);  // 报错：a is not defined
```

> **最佳实践**：在 ES6 之后，推荐**始终使用 `let` 和 `const`**，尽量避免使用 `var`，以利用块作用域的特性防止变量污染。


## 5.2 条件判断语句 —— `if`

1. 语法

    ```javascript
    if (条件表达式) {
        语句...
    }
    ```

2. 执行流程

    1. 对 `if` 后的条件表达式进行求值判断
    2. 如果结果为 `true` → 执行 `if` 后的语句
    3. 如果结果为 `false` → 不执行

    **注意事项**：

    - `if` 语句默认只控制**紧随其后的第一行代码**
    - 要控制多行代码，必须使用 `{}` 包裹
    - **最佳实践**：即使只有一行代码，也建议使用 `{}`，使结构更清晰

    ```javascript
    let a = 10;

    // 正确写法：使用代码块
    if (a > 10) {
        alert("a 比 10 大");
    }

    // if 后的条件表达式会自动转为布尔值
    if (NaN) {
        console.log('这行不会执行');  // NaN → false
    }

    if (a === 10) {
        console.log('a 的值是 10');
    }
    ```


## 5.3 条件分支语句

### 5.3.1 `if-else` 语句

**语法**：

```javascript
if (条件表达式) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

**执行流程**：
- 条件为 `true` → 执行 `if` 后的代码块
- 条件为 `false` → 执行 `else` 后的代码块

```javascript
let age = 50;

if (age >= 60) {
    alert("你已经退休了！");
} else {
    alert("你还没有退休！");
}
```


### 5.3.2 `if-else if-else` 语句

**语法**：

```javascript
if (条件表达式1) {
    // 条件1为 true 时执行
} else if (条件表达式2) {
    // 条件1为 false，条件2为 true 时执行
} else if (条件表达式3) {
    // 条件1、2为 false，条件3为 true 时执行
} else {
    // 所有条件都为 false 时执行
}
```

**执行流程**：

1. 自上而下依次判断条件
2. 找到第一个为 `true` 的条件，执行对应的代码块
3. 执行完毕后**立即结束**，不再判断后续条件
4. 所有条件都为 `false` 时，执行 `else` 中的代码

> **注意**：`if-else if-else` 中**只会有一个代码块被执行**，因此要注意条件的**编写顺序**——范围更小的条件应该放在前面。

```javascript
let age = 50;

if (age >= 100) {
    alert('你真是一个长寿的人');
} else if (age >= 80) {
    alert('你比楼上阿伟还年轻不少');
} else if (age >= 60) {
    alert('你已经退休了');
} else if (age >= 30) {
    alert('你已经步入中年了');
} else if (age >= 18) {
    alert('你已经成年了');
} else {
    alert('你还未成年');
}
// 输出：你已经步入中年了
```


### 5.3.3 `switch` 语句

**语法**：

```javascript
switch (表达式) {
    case 值1:
        // 当表达式 === 值1 时执行
        break;
    case 值2:
        // 当表达式 === 值2 时执行
        break;
    // ... 更多 case
    default:
        // 所有 case 都不匹配时执行
}
```

**执行流程**：

1. 计算 `switch` 后的表达式
2. 将结果与各 `case` 后的值进行**全等比较（`===`）**
3. 找到匹配的 `case` 后，从该位置开始执行代码
4. 如果没有匹配的 `case`，执行 `default` 中的代码

**核心特性**：

| 特性 | 说明 |
|------|------|
| **穿透（Fall-through）** | 匹配一个 `case` 后，会继续执行后续所有 `case`，直到遇到 `break` 或结束 |
| **使用 `break`** | 在每个 `case` 末尾添加 `break` 可以阻止穿透 |
| **`default` 位置** | 可以放在任意位置，通常放在最后 |

```javascript
// 输入一个数字，转换成中文
let num = +prompt("请输入一个数字：");

switch (num) {
    case 1:
        alert("一");
        break;
    case 2:
        alert("二");
        break;
    case 3:
        alert("三");
        break;
    case 4:
        alert("四");
        break;
    default:
        alert("请输入 1~4 之间的数字");
}
```

**`switch` vs `if`**：

| 对比维度 | `if-else` | `switch` |
|----------|-----------|----------|
| 适用场景 | 范围判断、复杂条件 | 多个固定值的全等比较 |
| 可读性 | 范围判断时更灵活 | 多值匹配时结构更清晰 |
| 比较方式 | 可以比较任意表达式 | 使用 `===` 全等比较 |

> **建议**：当需要根据**同一个变量的多个具体值**进行分支时，使用 `switch` 结构更清晰；当需要进行**范围判断或复杂条件**时，使用 `if-else`。


## 5.4 循环语句

**循环**用于让指定的代码**重复执行**。

### 5.4.1 循环三要素

编写循环通常需要三个要件：

| 要素 | 说明 | 示例 |
|------|------|------|
| **初始化表达式** | 初始化循环变量 | `let i = 0` |
| **条件表达式** | 设置循环运行的条件 | `i < 5` |
| **更新表达式** | 每次循环后修改变量 | `i++` |


### 5.4.2 `while` 循环

**语法**：

```javascript
while (条件表达式) {
    // 循环体（条件为 true 时重复执行）
}
```

**示例**：

```javascript
let i = 0;

// 输出 0 到 4
while (i < 5) {
    console.log(i);
    i++;  // 更新表达式
}

// 使用 break 退出循环
let a = 0;
while (true) {    // 死循环
    console.log(a);
    a++;
    if (a === 5) {
        break;    // 满足条件时退出
    }
}
```


### 5.4.3 `do-while` 循环

**语法**：

```javascript
do {
    // 循环体
} while (条件表达式);
```

**执行流程**：

1. **先执行一次**循环体
2. 再判断条件表达式
3. 条件为 `true` → 继续执行；`false` → 结束循环

**`while` vs `do-while`**：

| 对比 | `while` | `do-while` |
|------|---------|------------|
| 判断时机 | **先判断**再执行 | **先执行**再判断 |
| 最少执行次数 | 0 次 | **至少 1 次** |

```javascript
let i = 0;

do {
    console.log(i);
    i++;
} while (i < 5);  // 输出 0 1 2 3 4

// 即使条件不满足，也会执行一次
let j = 10;
do {
    console.log(j);  // 输出 10
    j++;
} while (j < 5);
```


### 5.4.4 `for` 循环

`for` 循环与 `while` 循环**本质相同**，区别在于语法结构更紧凑、更清晰。

**语法**：

```javascript
for (初始化表达式; 条件表达式; 更新表达式) {
    // 循环体
}
```


**代码示例**：

```javascript
// while 循环写法
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

// for 循环写法（更简洁）
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

**三种表达式均可省略**：

```javascript
// 省略初始化表达式
let i = 0;
for (; i < 5; i++) {
    console.log(i);
}

// 省略更新表达式（在循环体中更新）
for (let i = 0; i < 5; ) {
    console.log(i);
    i++;
}

// 死循环（所有表达式都省略）
for (;;) {
    // 无限循环，需要 break 退出
}
```

> **作用域注意**：在 `for` 循环的 `()` 中使用 `let` 声明的变量是**局部变量**，只能在循环内部访问；使用 `var` 则可以在循环外部访问。推荐使用 `let`。


### 5.4.5 嵌套循环

当循环发生**嵌套**时，**外层循环每执行一次，内层循环会执行一个完整的周期**。

```javascript
// 打印 5×5 的星号方阵
for (let x = 0; x < 5; x++) {           // 外层：控制行数
    for (let y = 0; y < 5; y++) {       // 内层：控制每行的星号数
        document.write("*&nbsp;&nbsp;");
    }
    document.write("</br>");
}
```

**常见图形打印**：

```javascript
// 图形 1：直角三角（左下对齐）
// *
// **
// ***
// ****
// *****
for (let x = 0; x < 5; x++) {
    for (let y = 0; y <= x; y++) {
        document.write("*&nbsp;&nbsp;");
    }
    document.write("</br>");
}

// 图形 2：直角三角（左上对齐）
// *****
// ****
// ***
// **
// *
for (let x = 0; x < 5; x++) {
    for (let y = 0; y < 5 - x; y++) {
        document.write("*&nbsp;&nbsp;");
    }
    document.write("</br>");
}
```


### 5.4.6 `break` 与 `continue`

| 关键字 | 作用 | 说明 |
|--------|------|------|
| `break` | **终止**循环或 `switch` | 立即结束当前循环（离它最近的那个） |
| `continue` | **跳过**当前次循环 | 结束本次迭代，进入下一次循环判断 |

```javascript
// break：终止循环
for (let i = 0; i < 5; i++) {
    for (let j = 0; j < 5; j++) {
        if (j === 1) {
            break;  // 只终止内层循环
        }
        console.log('内层循环 ----》', j);  // 只输出 j=0
    }
}

// continue：跳过本次循环
for (let i = 0; i < 5; i++) {
    for (let j = 0; j < 5; j++) {
        if (j === 1) {
            continue;  // 跳过 j=1 这次迭代
        }
        console.log('内层循环 ----》', j);  // 输出 j=0,2,3,4
    }
}
```

> **提示**：在多层循环中，`break` 和 `continue` 默认只对**离它们最近的循环**生效。如果需要跳出外层循环，可以使用**标签（label）**，但不推荐这样做，通常可以通过重构代码来避免。
