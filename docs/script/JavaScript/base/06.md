# 六、对象（Object）

## 6.1 数据类型回顾

JavaScript 中的数据类型分为两大类：

```txt:no-line-numbers
┌─────────────────────────────────────────────────────────────┐
│                    JavaScript 数据类型                       │
├───────────────────────────┬─────────────────────────────────┤
│     原始值（7 种）         │        对象（引用类型）           │
├───────────────────────────┼─────────────────────────────────┤
│  Number    │  数值         │  Object    │  普通对象          │
│  BigInt    │  大整数       │  Array     │  数组              │
│  String    │  字符串       │  Function  │  函数              │
│  Boolean   │  布尔值       │  Date      │  日期              │
│  Null      │  空值         │  RegExp    │  正则              │
│  Undefined │  未定义       │  Error     │  错误              │
│  Symbol    │  符号         │  ...       │  其他              │
├───────────────────────────┴─────────────────────────────────┤
│  原始值不可变（Immutable），对象可变（Mutable）                │
│  原始值存储在栈中，对象存储在堆中，变量存的是地址               │
└─────────────────────────────────────────────────────────────┘
```

| 特征 | 原始值（Primitive） | 对象（Object） |
|------|---------------------|----------------|
| **存储内容** | 简单的数据值 | 多个数据的集合 |
| **数据量** | 只能表示一个值 | 可以存储多个不同类型的数据 |
| **典型场景** | 数字、字符串、布尔值等 | 表示复杂实体（如"人"的信息） |
| **可变性** | **不可变** | **可变** |

> **问题引入**：如果需要在程序中表示一个人的信息（姓名、年龄、性别、地址等），原始值无法满足需求。对象正是为了解决这个问题而诞生的。


## 6.2 认识对象

**对象（Object）** 是 JavaScript 中的一种**复合数据类型**，它相当于一个**容器**，可以在其中存储各种不同类型的数据（称为**属性**）。

### 6.2.1 创建对象

```javascript
// 方式一：使用 new Object()
let obj1 = new Object();

// 方式二：使用 Object() 函数（效果相同，但 new 更明确）
let obj2 = Object();

// 方式三：对象字面量（推荐，详见 6.4）
let obj3 = {};
```

### 6.2.2 操作属性的基本方法

| 操作 | 语法 | 示例 |
|------|------|------|
| **添加属性** | `对象.属性名 = 属性值` | `obj.name = "孙悟空"` |
| **读取属性** | `对象.属性名` | `obj.name` → `"孙悟空"` |
| **修改属性** | `对象.属性名 = 新属性值` | `obj.name = "猪八戒"` |
| **删除属性** | `delete 对象.属性名` | `delete obj.name` |

```javascript
let obj = new Object();

// 添加属性
obj.name = "孙悟空";
obj.age = 18;
obj.gender = "男";

console.log(obj);
// 输出：{ name: '孙悟空', age: 18, gender: '男' }

// 读取属性
console.log(obj.name);        // "孙悟空"
console.log(obj.address);     // undefined（不存在的属性不会报错）

// 修改属性
obj.name = "Tom sun";
console.log(obj.name);        // "Tom sun"

// 删除属性
delete obj.name;
console.log(obj.name);        // undefined
```


## 6.3 对象的属性

### 6.3.1 属性名的规则

| 属性名类型 | 写法 | 说明 |
|-----------|------|------|
| **普通字符串** | `obj.name = "孙悟空"` | 建议符合标识符命名规范 |
| **特殊字符串** | `obj["属性名"] = "值"` | 包含空格/特殊字符时使用 `[]` |
| **变量作为属性名** | `obj[变量名] = "值"` | 使用 `[]` 时可以动态指定属性名 |
| **Symbol 作为属性名** | `obj[symbol] = "值"` | 用于创建私有/唯一属性 |

```javascript
let obj = {};

// 1. 普通属性名（推荐）
obj.name = "孙悟空";
obj.age = 18;

// 2. 特殊属性名（不推荐，但语法允许）
obj["123!@#"] = "特殊属性";
obj["if"] = "不推荐使用关键字";

// 3. 使用变量作为属性名（动态属性）
let key = "address";
obj[key] = "花果山";          // 等价于 obj["address"] = "花果山"
// obj.key = "花果山"      // 这会把 "key" 当作属性名，而不是使用变量的值

// 4. 使用 Symbol 作为属性名
const mySymbol = Symbol();
obj[mySymbol] = "这是一个私有属性";
console.log(obj[mySymbol]);   // "这是一个私有属性"

console.log(obj);
```

> **最佳实践**：强烈建议属性名也遵循**标识符命名规范**（小驼峰命名法），避免使用特殊字符或关键字作为属性名。

### 6.3.2 属性值

对象的属性值可以是**任意数据类型**，包括另一个对象：

```javascript
let obj = {
    name: "孙悟空",
    age: 18,
    isStudent: true,
    score: 95.5,
    // 属性值可以是对象（嵌套对象）
    address: {
        city: "花果山",
        country: "傲来国"
    }
};

// 访问嵌套对象的属性
console.log(obj.address.city);  // "花果山"
```

### 6.3.3 属性存在的检查

使用 `in` 运算符检查对象中是否包含某个属性：

```javascript
let obj = {
    name: "孙悟空",
    age: 18
};

console.log("name" in obj);   // true
console.log("gender" in obj); // false
console.log("toString" in obj); // true（继承自 Object 原型）

// 注意：in 会检查原型链上的属性
// 如果只想检查对象自身的属性，可以使用 obj.hasOwnProperty("name")
console.log(obj.hasOwnProperty("name"));   // true
console.log(obj.hasOwnProperty("toString")); // false（原型链上的）
```

### 6.3.4 类型检查

使用 `typeof` 检查对象及其属性：

```javascript
let obj = {
    name: "孙悟空",
    age: 18
};

console.log(typeof obj);       // "object"
console.log(typeof obj.name);  // "string"
console.log(typeof obj.age);   // "number"
```


## 6.4 对象的字面量（对象简写语法）

对象字面量是创建对象最常用、最简洁的方式，使用 `{}` 直接创建。

1. 基本语法

    ```javascript
    {
        属性名: 属性值,
        属性名: 属性值,
        // ...
    }
    ```

2. 代码示例

    ```javascript
    let mySymbol = Symbol();

    let obj = {
        // 普通属性
        name: "孙悟空",
        age: 18,
        
        // 使用字符串作为属性名
        "gender": "男",
        "my-address": "花果山",  // 包含连字符，必须用引号
        
        // 使用表达式作为属性名（ES6 计算属性名）
        ["score"]: 100,
        [mySymbol]: "特殊的属性",
        
        // 属性值可以是对象（嵌套）
        contact: {
            phone: "123456789",
            email: "sun@example.com"
        }
    };

    console.log(obj);
    console.log(obj.contact.phone);  // "123456789"
    console.log(obj[mySymbol]);      // "特殊的属性"
    ```


## 6.5 枚举属性（遍历对象）

**枚举（Enumerate）** 指获取对象中的所有属性。使用 **`for-in` 语句**可以遍历对象的可枚举属性。

1. 语法

    ```javascript
    for (let propName in 对象) {
        // 循环体执行多次，次数等于可枚举属性的数量
        // propName 依次为每个属性的名称
    }
    ```

2. 代码示例

    ```javascript
    let obj = {
        name: "孙悟空",
        age: 18,
        gender: "男",
        address: "花果山",
        [Symbol()]: "测试"   // Symbol 属性默认不可枚举
    };

    for (let propName in obj) {
        console.log(propName, obj[propName]);
    }
    // 输出：
    // name 孙悟空
    // age 18
    // gender 男
    // address 花果山
    //（Symbol 属性不会出现在 for-in 中）
    ```

> **注意**：`for-in` 会遍历原型链上的可枚举属性。如果只想遍历对象自身的属性，可以使用 `Object.keys(obj)` 或 `Object.hasOwnProperty()` 配合 `for-in` 进行过滤。


## 6.6 可变类型

1. 基本类型 vs 引用类型的存储方式

    | 对比维度 | 原始值（不可变） | 对象（可变） |
    |----------|-----------------|-------------|
    | **存储位置** | 值直接存储在变量中 | 变量存储的是**内存地址**（引用） |
    | **赋值行为** | 复制**值本身** | 复制**内存地址** |
    | **比较方式** | 比较值是否相等 | 比较**内存地址**是否相同 |
    | **可变性** | 不可变（创建后无法修改） | 可变（可随时增删改属性） |

2. 内存示意图

    ```mermaid
    graph LR
        subgraph Stack["栈内存"]
            S1["obj2 ➜ 0x12"]
            S2["obj3 ➜ 0x34"]
            S3["obj4 ➜ 0x12"]
        end

        subgraph Heap["堆内存"]
            H1["0x12 ➜ { name: '孙悟空', age: 18 }"]
            H2["0x34 ➜ { }"]
        end

        S1 --> H1
        S3 --> H1
        S2 --> H2

        style Stack fill:#e3f2fd,stroke:#1565c0
        style Heap fill:#e8f5e9,stroke:#2e7d32
        style H1 fill:#fff8e1,stroke:#f9a825
        style H2 fill:#fff8e1,stroke:#f9a825
    ```

3. 代码示例

    ```javascript
    let obj = {};
    obj.name = "孙悟空";
    obj.age = 18;

    // 创建两个空对象
    let obj2 = {};
    let obj3 = {};
    console.log(obj2 == obj3);  // false（不同的内存地址）

    // 将 obj 赋值给 obj4（复制的是地址）
    let obj4 = obj;
    obj4.name = "猪八戒";

    console.log(obj4.name);  // "猪八戒"
    console.log(obj.name);   // "猪八戒"（被修改了！）
    console.log(obj4 == obj); // true（指向同一个对象）
    ```

> **关键理解**：变量存储对象时，存储的是**内存地址**。两个变量指向同一个对象时，通过任何一个变量修改对象，另一个变量也会受影响。


## 6.7 修改属性与修改变量

### 6.7.1 修改对象 vs 修改变量

| 操作 | 代码 | 影响范围 |
|------|------|----------|
| **修改对象属性** | `obj.name = "新值"` | 影响所有指向该对象的变量 |
| **修改对象引用** | `obj = 新对象` 或 `obj = null` | 只影响当前变量 |

```javascript
let obj = {
    name: '孙悟空'
};

let obj2 = obj;

// 修改对象属性 → 所有指向该对象的变量都受影响
obj2.name = '猪八戒';
console.log(obj.name);   // "猪八戒"（obj 也变了）

// 修改变量指向 → 只影响当前变量
obj2 = {};
obj2.name = '沙和尚';
console.log(obj.name);   // "猪八戒"（obj 不受影响）
console.log(obj2.name);  // "沙和尚"

// 将变量重新赋值
obj2 = null;
console.log(obj2);       // null（只影响 obj2）
console.log(obj);        // { name: '猪八戒' }（obj 不受影响）
```

### 6.7.2 使用 `const` 声明对象

**最佳实践**：声明存储对象的变量时，建议使用 `const`。

```javascript
const obj = {
    name: '猪八戒'
};

// 可以修改对象的属性
obj.name = '沙和尚';
console.log(obj.name);  // "沙和尚"

// 可以添加新属性
obj.age = 18;
console.log(obj.age);   // 18

// 不能重新赋值给变量本身
// obj = {};  // TypeError: Assignment to constant variable
// obj = null; // TypeError: Assignment to constant variable
```

> **核心理解**：
> - `const` 限制的是**变量本身的赋值**，即不能改变变量指向的内存地址
> - **对象内容（属性）的修改不受限制**，因为对象本身并没有被重新创建


## 6.8 方法（Method）

当一个对象的属性值是一个**函数**时，我们称这个函数为该对象的**方法（Method）**。

### 6.8.1 方法定义

```javascript
let obj = {};

obj.name = "孙悟空";
obj.age = 18;

// 将函数赋值给对象的属性
obj.sayHello = function() {
    alert("Hello, 我是" + this.name);
};

// 调用方法（通过对象.方法名() 的方式）
obj.sayHello();  // "Hello, 我是孙悟空"
```

### 6.8.2 对象字面量中定义方法

```javascript
let person = {
    name: "孙悟空",
    age: 18,
    // 方法定义方式一：函数表达式
    sayHello: function() {
        console.log("Hello, 我是" + this.name);
    },
    // 方法定义方式二：ES6 简写（推荐）
    sayHi() {
        console.log("Hi, 我是" + this.name);
    }
};

person.sayHello();  // "Hello, 我是孙悟空"
person.sayHi();     // "Hi, 我是孙悟空"
```

### 6.8.3 方法和函数的区别

| 对比 | 函数（Function） | 方法（Method） |
|------|-----------------|----------------|
| **定义** | 独立定义的函数 | 作为对象属性的函数 |
| **调用方式** | `函数名()` | `对象.方法名()` |
| **`this` 指向** | 取决于调用方式（严格模式/非严格模式） | 指向**调用该方法的对象** |

```javascript
// 函数
function greet() {
    console.log("你好");
}
greet();  // 函数调用

// 方法
let obj = {
    greet: function() {
        console.log("你好，我是" + this.name);
    },
    name: "孙悟空"
};
obj.greet();  // 方法调用（通过对象调用）
```
