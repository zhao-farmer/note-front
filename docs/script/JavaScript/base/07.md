# 七、函数


## 7.1 认识函数（Function）

- 核心概念
    - 函数也是一个对象。
    - 它具有其他对象的所有功能。
    - 函数中可以存储代码，且可以在需要的时候调用这些代码。

- 语法与调用

    ```js
    // 定义函数
    function 函数名() {
        // 存储的代码
    }

    // 调用函数：执行函数中存储的代码
    函数对象();
    ```
    > **注意**：使用 `typeof` 检查函数对象时，会返回 `"function"`。

- 代码示例

    ```js
    function fn() {
        console.log("你好");
        console.log('hello');
    }
    fn(); // 调用函数
    console.log(typeof fn); // "function"
    ```

## 7.2 函数的定义方式

- JavaScript 中主要有三种定义函数的方式：

    1. **函数声明**
        ```js
        function 函数名() {
            语句...
        }
        ```
    2. **函数表达式**
        ```js
        const 变量 = function() {
            语句...
        }
        ```

    3. **箭头函数(ES6+)**
        ```js
        const 变量 = () => {
            语句...
        }
        ```

- **综合示例**

    ```js
    // 1. 函数声明
    function fn() {
        console.log("函数声明所定义的函数~");
    }

    // 2. 函数表达式
    const fn2 = function () {
        console.log("函数表达式");
    }

    // 3. 箭头函数
    const fn3 = () => {
        console.log("箭头函数");
    }

    // 4. 简写箭头函数（只有一条语句时，可省略大括号）
    const fn4 = () => console.log("箭头函数简写");

    console.log(typeof fn);   // "function"
    console.log(typeof fn2);  // "function"
    console.log(typeof fn3);  // "function"
    console.log(typeof fn4);  // "function"
    ```

## 7.3 函数的参数

- 参数分类
    - **形式参数（形参）**：在定义函数时指定的参数。相当于在函数内部声明了对应的变量，但没有赋值。
    - **实际参数（实参）**：在调用函数时，在 `()` 中传递的值。实参会赋值给对应的形参。

- 实参与形参的数量关系
    1. 如果实参和形参数量相同，则对应的实参赋值给对应的形参。
    2. 如果实参多于形参，多余的实参不会被使用（但可以通过 `arguments` 对象获取）。
    3. 如果形参多于实参，多余的形参值为 `undefined`。

-  参数类型
    JS 中不会检查参数的类型，可以传递任意类型的参数（基本类型、对象、函数等）。

- 语法示例

    ```js
    // 函数声明带参数
    function 函数名([参数1, 参数2]) {
        语句...
    }

    // 函数表达式带参数
    const 变量 = function([参数1, 参数2]) {
        语句...
    }

    // 箭头函数带参数
    ([参数1, 参数2]) => {
        语句...
    }
    ```

- 代码演示

    ```js
    function fn(a, b) {
        console.log("a = ", a);
        console.log("b = ", b);
    }
    fn(1, 10);        // a=1, b=10
    fn({}, "hello");  // a={}, b="hello"

    function fn2(a, b) {
        console.log("a + b = ", a + b);
    }
    fn2(5, 5);           // 10 (数字相加)
    fn2("hello", "world"); // "helloworld" (字符串拼接)
    ```

## 7.4 参数的其他特性

1. 箭头函数的参数简写

    当箭头函数**只有一个参数**时，可以省略包裹参数的小括号 `()`。
2. 参数默认值

    定义参数时，可以为参数指定默认值。默认值会在没有对应实参（或实参为 `undefined`）时生效。

3. 代码示例

    ```js
    // 普通箭头函数
    const fn = (a, b) => {
        console.log('a=', a);
        console.log('b=', b);
    }

    // 只有一个参数时，省略小括号
    const fn2 = a => {
        console.log('a=', a);
    }
    fn2(123); // a= 123

    // 带有默认值的参数
    const fn3 = (a = 10, b = 20, c = 30) => {
        console.log('a=', a);
        console.log('b=', b);
        console.log('c=', c);
    }
    fn3(1, 2, 3); // a=1, b=2, c=3
    fn3(1, 2);    // a=1, b=2, c=30 (c使用默认值)
    fn3(1);       // a=1, b=20, c=30 (b和c使用默认值)
    ```

## 7.5 对象作为参数

在 JavaScript 中，对象是引用类型。传递对象作为参数时，传递的是**内存地址的引用**，而不是对象本身。因此，在函数内部修改对象的属性，会影响外部的原对象。

- 代码示例

    ```js
    function fn(a) {
        console.log("a = ", a);
        console.log(a.name);
        a.name = '猪八戒'; // 修改对象属性，外部指向该对象的变量也会受影响
        console.log(a);
    }

    let obj = { name: "孙悟空" };
    fn(obj); 
    console.log(obj); // { name: "猪八戒" }，原对象已被修改
    ```

- 补充：对象默认值的陷阱

    函数每次调用时，如果使用了对象作为默认值，JS 会重新创建该对象，避免多次调用之间的污染。
    ```js
    function fn2(a = { name: '沙和尚' }) {
        console.log("a = ", a);
        a.name = '唐僧';
        console.log("a = ", a);
    }
    fn2(); // 第一次：沙和尚 -> 唐僧
    fn2(); // 第二次：沙和尚 -> 唐僧 (不受第一次调用的影响)
    ```

## 7.6 函数作为参数

在 JS 中，函数是**一等公民（First-class Function）**。别的对象能做的事情，函数也可以做，包括作为参数传递给其他函数（即回调函数）。

**代码示例**

```js
function fn(a) {
    console.log("a = ", a);
    a(); // 执行传入的函数
}

function fn2() {
    console.log('我是fn2');
}

fn(fn2); // 将 fn2 作为参数传递给 fn
```


## 7.7 函数的返回值

- 在函数中，可以通过 `return` 关键字来指定函数的返回值。
- 返回值就是函数的执行结果，函数调用完毕后，返回值会作为结果返回。
- 任何值都可以作为返回值（包括基本类型、对象、函数等）。
- **规则**：
    - 如果 `return` 后不跟任何值，则相当于返回 `undefined`。
    - 如果不写 `return`，函数的返回值依然是 `undefined`。
    - `return` 执行后，函数会**立即结束**，其后的代码不再执行。

- 代码示例

    ```js
    function fn() {
        alert(123);
        return; // 函数在此处结束
        alert(456); // 这行代码永远不会执行
    }

    let result = fn();
    console.log(result); // undefined

    // 返回值可以用于链式计算
    function sum(a, b) {
        return a + b;
    }
    result = sum(123, 456);
    result = sum(result, 10);
    console.log('result = ', result); // 589
    ```


## 7.8 箭头函数的返回值

箭头函数的返回值可以直接写在箭头 `=>` 后面，此时会自动返回该表达式的值。

> **重要注意**：如果直接在箭头后使用**对象字面量**作为返回值，对象字面量必须使用小括号 `()` 括起来，否则 `{}` 会被解析为函数体的代码块。

- 代码示例

    ```js
    // 正确：返回 a + b 的结果
    const sum = (a, b) => a + b;

    // 错误写法：JS 会将 {} 当作代码块，而不是对象
    // let fn = () => { name: '孙悟空' } 

    // 正确：使用 () 包裹对象字面量
    let fn = () => ({ name: '孙悟空' });

    let result = sum(123, 456);
    console.log(result); // 579

    result = fn();
    console.log(result); // { name: '孙悟空' }
    ```


## 7.9 作用域（Scope）

作用域指的是一个变量的**可见区域**（即变量在哪里可以被访问到）。

1. 全局作用域
    - 全局作用域在网页运行时创建，在网页关闭时销毁。
    - 所有直接编写到 `<script>` 标签中的代码都位于全局作用域中。
    - 全局作用域中的变量是**全局变量**，可以在任意位置访问。

2. 局部作用域
    - **块作用域**：
        - 由 `{}`（如 `if`、`for`、`while` 等）创建。
        - 在块作用域中用 `let` 或 `const` 声明的变量是局部变量，只能在块内部访问。
    - **函数作用域**：
        - 函数作用域在函数调用时产生，调用结束后销毁。
        - 函数每次调用都会产生一个全新的函数作用域。
        - 在函数中用 `var`、`let` 或 `const` 定义的变量是局部变量，外部无法访问。

- 代码示例

    ```js
    // 全局作用域
    let a = "变量a";
    console.log(a); // 可访问

    {
        console.log(a); // 块内部可访问全局变量
    }

    function fn() {
        console.log(a); // 函数内部可访问全局变量
    }
    fn();

    // 块作用域
    {
        let b = "变量b";
        console.log(b); // 块内部可访问
    }
    // console.log(b); // 报错：b is not defined，外部无法访问

    // 函数作用域
    function fn2() {
        let c = "fn2中的变量c";
        console.log(c); // 函数内部可访问
    }
    fn2();
    // console.log(c); // 报错：c is not defined，外部无法访问
    ```


## 7.10 作用域链

当我们使用一个变量时，JS 解释器会遵循以下查找规则：
1. 优先在**当前作用域**中寻找变量。如果找到了，直接使用。
2. 如果没找到，则去**上一层作用域**中寻找。找到了则使用。
3. 如果还没找到，继续去上一层寻找，依此类推。
4. 如果一直到**全局作用域**都没有找到，则报错 `xxx is not defined`。

这种层层向上查找的机制，称为**作用域链**。

**代码示例**

```js
let a = 10;
{
    let a = "第一代码块中的a";
    {
        let a = "第二代码块中的a";
        console.log(a); // "第二代码块中的a" (优先使用当前作用域)
    }
}

let b = 33;
function fn() {
    let b = 44;
    function f1() {
        let b = 55;
        console.log(b); // 55 (当前作用域)
    }
    f1();
}
fn();
```


## 7.11 window 对象

1. window 对象简介

    - 在浏览器环境中，JS 提供了一个全局对象 `window`。
    - `window` 代表浏览器窗口，可以通过它操作浏览器。
    - `window` 负责存储 JS 中的全局对象和浏览器的宿主对象（如 `document`, `console`, `alert` 等）。
    - 全局作用域中的变量和函数，本质上都是 `window` 对象的属性和方法。访问时可以省略 `window.`。

2. var、let 与 window 的区别

    - **`var`**：在全局中使用 `var` 声明的变量，会自动作为 `window` 对象的属性保存。
    - **`function`**：使用函数声明创建的函数，会自动作为 `window` 的方法保存。
    - **`let` / `const`**：在全局中使用 `let` 或 `const` 声明的变量，**不会**存储在 `window` 对象上（它们存在于一个独立的“秘密区域”）。
    - **优先级**：如果 `window` 上有同名属性，且当前作用域有 `let` 声明的同名变量，优先访问 `let` 声明的变量。

3. 隐式全局变量

    在局部作用域中，如果没有使用 `var`、`let` 或 `const` 声明变量就直接赋值，该变量会自动成为 `window` 对象的属性（即全局变量）。**（强烈不推荐此写法）**

4. 代码示例

    ```js
    // 全局变量与 window
    var b = 20;
    console.log(window.b); // 20

    function fn() {
        console.log("执行fn");
    }
    window.fn(); // 执行fn

    // let 与 window 的区别
    let c = 33;
    window.c = 44; // 给 window 添加属性 c
    console.log(c); // 33 (优先访问 let 声明的 c)
    console.log(window.c); // 44

    // 隐式全局变量（不推荐）
    function fn2() {
        d = 10; // 没有声明，自动变成 window.d
    }
    fn2();
    console.log(d); // 10
    console.log(window.d); // 10
    ```


## 7.12 提升（Hoisting）

1. 变量的提升
    - 使用 `var` 声明的变量，会在所有代码执行前被**声明**（但不赋值）。
    - 因此，可以在变量声明前访问该变量，但值为 `undefined`。
    - **注意**：`let` 和 `const` 也存在提升，但在赋值之前处于“暂时性死区（TDZ）”，访问会报错。

2. 函数的提升

    - 使用**函数声明**创建的函数，会在其他代码执行前被**完整创建**。
    - 因此，可以在函数声明前调用该函数。
    - **注意**：使用**函数表达式**（`const fn = function(){}`）定义的函数，遵循变量的提升规则（只提升声明，不提升赋值），在赋值前调用会报错。

3. 代码示例

    ```js
    // 函数声明提升：可以提前调用
    fn(); 
    function fn() {
        alert("我是fn函数");
    }

    // var 变量提升：可以提前访问，但值为 undefined
    console.log(a); // undefined
    var a = 10;

    // let 变量提升：暂时性死区，提前访问会报错
    // console.log(b); // 报错：Cannot access 'b' before initialization
    let b = 10;
    ```


## 7.13 立即执行函数（IIFE）

立即执行函数（Immediately Invoked Function Expression, IIFE）是一个匿名函数，在定义后立即被调用，且只会调用一次。

- 作用

    利用 IIFE 创建一个一次性的函数作用域，避免变量污染全局作用域，解决变量冲突问题。

- 语法演变

    ```js
    // 1. 普通匿名函数（单独存在会报错，因为 function 开头会被解析为函数声明，而声明必须有名字）
    // function () { ... } 

    // 2. 使用小括号包裹，将其变为函数表达式
    (function () {
        let a = 10;
        console.log(111);
    })

    // 3. 在最后加 () 立即执行
    (function () {
        let a = 10;
        console.log(111);
    })();

    // 4. 另一种写法：小括号放到里面
    (function () {
        let a = 10;
        console.log(111);
    }());
    ```

    > **注意**：如果连续写多个 IIFE，建议在它们之间加上分号 `;`，防止 JS 解析器将前一个函数的返回值当作后一个函数的参数调用而报错。


## 7.14 this 关键字

- 函数在执行时，JS 解析器每次都会传递一个隐含的参数，这个参数就是 `this`。
- `this` 指向一个对象，具体指向谁**取决于函数的调用方式**。

**常见调用方式与 this 指向**

1. **以函数形式调用**：`this` 指向全局对象 `window`（严格模式下为 `undefined`）。
2. **以方法的形式调用**：`this` 指向调用该方法的对象。

**代码示例**

```js
function fn() {
    console.log(this);
}

// 1. 函数形式调用
fn(); // this 指向 window

// 2. 方法形式调用
const obj2 = { name: '猪八戒', test: fn };
obj2.test(); // this 指向 obj2 对象

const obj3 = {
    name: '沙和尚',
    sayHello: function () {
        console.log(this.name); // this 指向 obj3
    }
};
obj3.sayHello(); // "沙和尚"
```


## 7.15 箭头函数的 this

- 箭头函数语法回顾

    ```js
    // 无参
    () => 返回值

    // 一个参数（可省略括号）
    a => 返回值

    // 多个参数
    (a, b) => 返回值

    // 多行语句（需加大括号和 return）
    () => {
        // ...
        return 返回值;
    }

    // 返回对象字面量
    () => ({ key: 'value' })
    ```

- 箭头函数的 this 特性

    - **箭头函数没有自己的 `this`**。
    - 箭头函数内部的 `this` 是由**外层作用域**（定义时的上下文）决定的。
    - 箭头函数的 `this` 与它的调用方式无关，永远指向定义时所在作用域的 `this`。

- 代码示例

    ```js
    function fn() {
        console.log("fn -->", this);
    }

    const fn2 = () => {
        console.log("fn2 -->", this); // 总是指向定义时的外层 this（全局环境下为 window）
    }

    const obj = {
        name: '孙悟空',
        fn,
        fn2,
        sayHello() {
            console.log(this.name); // this 指向 obj
            
            // 普通函数 t，作为函数调用，this 指向 window
            function t() {
                console.log("t -->", this); // window
            }
            t();

            // 箭头函数 t2，this 由外层 sayHello 决定，指向 obj
            const t2 = () => {
                console.log("t2 -->", this); // obj
            }
            t2();
        }
    }

    obj.fn();   // window
    obj.fn2();  // window (因为 fn2 定义在全局)
    obj.sayHello(); 
    ```


## 7.16 严格模式（Strict Mode）

JS 运行代码有两种模式：

1. 正常模式（默认）
    - 语法检查不严格。
    - 原则是：能不报错的地方就不报错（例如允许隐式全局变量）。
    - 导致代码运行性能较差，且容易隐藏 bug。

2. 严格模式
    - 通过 `"use strict"` 指令开启。
    - 语法检查变得严格，禁止一些不安全的语法（如禁止隐式全局变量、禁止删除不可删除的属性等）。
    - 更容易暴露错误，帮助开发者在开发阶段消灭隐患。
    - 提升了代码的执行性能。

    > **建议**：在现代开发中，应该尽量使用严格模式。

    **开启方式**

    ```js
    // 1. 全局严格模式（写在脚本文件的最顶端）
    "use strict";
    var a = 10;
    console.log(a);

    // 2. 函数局部严格模式（写在函数体的第一行）
    function fn() {
        "use strict";
        // 该函数内部运行在严格模式下
        // b = 20; // 报错：b is not defined
    }
    fn();
    ```
