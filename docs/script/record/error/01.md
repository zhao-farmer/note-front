# 一、异常记录

## 1.1 三元表达式的异常

1.  下面两个打印都是 undefined 

    ```js
    console.log(useData.actorName)
    let text02 = "配音 " + useData.actorName?useData.actorName:"";
    console.log(text02)
    ```

2. 问题根源：运算符优先级 + 空字符串引号书写错误
    -  先拆解这行代码
        ```js
        let text02 = "配音 " + useData.actorName?useData.actorName:"";
        ```
    - JS 运算符优先级规则

        **加法 `+` 优先级 高于 三元运算符 `?:`**

        代码会被 JS 引擎自动解析成：

        ```js
        let text02 = ("配音 " + useData.actorName) ? useData.actorName : "";
        ```

    - 分步推演（`useData.actorName = undefined`）
        1. 先执行加法：`"配音 " + undefined` → 字符串 `"配音 undefined"`
        2. 三元判断：`"配音 undefined"` 是**非空真值字符串**，条件成立
        3. 取三元真值分支：`useData.actorName` → `undefined`
        4. 最终 `text02 = undefined`

        这就是打印出来是 `undefined` 的核心原因。

3. 第二个小问题：引号混用隐患

    你代码里混合了双引号 `"配音 "` 和双引号 `""`，虽然语法合法，但可读性差；
    关键错误还是**缺少括号包裹三元表达式**。

3. 正确写法（两种推荐）
    - 方案1：三元加括号（修复优先级）
        ```js
        let text02 = "配音 " + (useData.actorName ? useData.actorName : "");
        ```
    - 方案2：ES6 空值合并（更简洁）
        ```js
        let text02 = "配音 " + (useData.actorName ?? "");
        ```
    - 方案3：模板字符串（最优雅）
        ```js
        let text02 = `配音 ${useData.actorName ?? ""}`;
        ```

4. 补充拓展

    如果还需要同时处理 `null / "" / undefined` 空值，用短路或 `||` 也可以：

    ```js
    let text02 = "配音 " + (useData.actorName || "");
    ```

    区别：

    - `??` 仅拦截 `null / undefined`，空字符串 `""`、数字 `0` 会保留
    - `||` 拦截所有假值：`null / undefined / "" / 0 / false`
