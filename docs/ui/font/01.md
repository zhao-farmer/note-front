# 一、Web Fonts

在 Web 页面中使用自定义字体（Web Fonts）是提升 UI 美观度和品牌一致性的关键手段。以下是 **现代 Web 开发中使用字体的完整指南**，涵盖本地字体、Google Fonts、可变字体、性能优化等核心内容。


## 1.1 基本原理：`@font-face`

所有 Web 字体的核心是 CSS 的 [`@font-face`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/@font-face) 规则：

```css
@font-face {
  font-family: 'MyCustomFont';
  src: url('./fonts/MyFont.woff2') format('woff2'),
       url('./fonts/MyFont.woff') format('woff');
  font-weight: 400;
  font-style: normal;
  font-display: swap; /* 关键性能属性 */
}
```

然后在元素中使用：
```css
body {
  font-family: 'MyCustomFont', sans-serif;
}
```

>  `font-display: swap` 表示：先用系统字体显示，字体加载后再替换（避免 FOIT —— 文字不可见闪烁）


## 1.2 常用字体格式

- 优先级从高到低

| 格式 | 浏览器支持 | 特点 |
|------|-----------|------|
| **`.woff2`** | ✅ 现代浏览器（Chrome 36+, Firefox 39+） | 压缩率最高，**首选** |
| `.woff` | ✅ 广泛支持 | 兼容性好，次选 |
| `.ttf` / `.otf` | ⚠️ 移动端支持较好，桌面端一般 | 文件大，不推荐用于 Web |
| `.eot` | ❌ 仅 IE | 已淘汰 |

>  **最佳实践**：只提供 `woff2` + `woff` 即可覆盖 98% 以上用户。


## 1.3 使用方式分类

### 1.3.1 **使用 Google Fonts**

Google Fonts 提供海量免费开源字体。

步骤：

1. 访问 [fonts.google.com](https://fonts.google.com)
2. 选择字体（如 **Inter**, **Roboto**, **Noto Sans SC**）
3. 点击 “Embed”，复制 `<link>` 标签

    ```html
    <!-- HTML head 中 -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
    ```

4. 在 CSS 中使用：

    ```css
    body {
    font-family: 'Inter', sans-serif;
    }
    ```

> 优点：自动优化、CDN 加速、支持可变字体  
> 注意：国内访问可能较慢，敏感项目建议自托管



### 1.3.2 **自托管字体**

适用于：
- 内网系统
- 对隐私/性能要求高的项目
- 使用非 Google Fonts 的商业字体

**步骤**：


1. 获取字体文件（如从 [Google Webfonts Helper](https://gwfh.mranftl.com/) 下载 Inter 的 woff2）
2. 放入项目目录（如 `public/fonts/`）
3. 定义 `@font-face`

    ```css
    /* styles/fonts.css */
    @font-face {
      font-family: 'Inter';
      src: url('/fonts/inter-var.woff2') format('woff2');
      font-weight: 100 900; /* 可变字体范围 */
      font-display: swap;
    }
    ```

4. 引入并使用：

    ```html
    <!-- index.html -->
    <link rel="stylesheet" href="/styles/fonts.css">
    ```

    ```css
    html {
      font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
    }
    ```

    >  工具推荐：
    > - [Google Webfonts Helper](https://gwfh.mranftl.com/)：一键下载 Google Fonts 的自托管 包
    > - [Transfonter](https://transfonter.org/)：上传 TTF 转换为 Web 格式



### 1.3.2 **使用可变字体**

可变字体 = 一个文件包含多个字重/宽度，大幅减少请求和体积。

**示例（Inter 可变字体）**：
```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter.var.woff2') format('woff2-variations');
  font-weight: 100 900;
  font-display: swap;
}

.title {
  font-weight: 700; /* 任意值 100~900 都支持 */
}
```

> 优势：一个文件替代多个（如 regular/bold/extra-bold）


## 1.4 性能优化关键点

1. **使用 `font-display: swap`**

    避免文字长时间空白（FOIT），改用 FOUT（Flash of Unstyled Text）。

2. **预加载关键字体（谨慎使用）**

    ```html
    <link rel="preload" as="font" href="/fonts/Inter.woff2" type="font/woff2" crossorigin>
    ```
    > 仅对首屏关键字体使用，否则会阻塞渲染。

3. **子集化（Subset）**

    如果只用中文部分字符，可用工具（如 [fonttools](https://github.com/fonttools/fonttools)）裁剪字体，体积可减少 90%。

4. **使用系统字体栈作为 fallback**

    ```css
    body {
      font-family:
        'Inter',
        /* macOS 10.11+ */ -apple-system,
        /* Windows */ 'Segoe UI',
        /* Android */ 'Roboto',
        /* Linux */ 'Ubuntu',
        /* 通用 */ sans-serif;
    }
    ```

## 1.5 在框架中使用（Vue / React）

1. Vue 3 + Vite

    1. 将字体放入 `public/fonts/`
    2. 在 `main.css` 中定义 `@font-face`
    3. 在 `main.js` 中引入 CSS

    ```js
    // main.js
    import './assets/main.css'
    ```

2.  Next.js / Nuxt
    - 字体放在 `public/` 目录
    - 在 `app/layout.tsx` 或 `app.vue` 中通过 `<link>` 或 CSS 引入
    - **Next.js 13+ 推荐使用 `next/font`（自动优化）**

    ```tsx
    // Next.js 示例
    import { Inter } from 'next/font/google'

    const inter = Inter({ subsets: ['latin'] })

    export default function RootLayout({ children }) {
      return (
        <html className={inter.className}>
          <body>{children}</body>
        </html>
      )
    }
    ```

    > ✅ `next/font` 自动：
    > - 自托管
    > - 预加载
    > - CSS-in-JS 优化
    > - 无布局偏移
