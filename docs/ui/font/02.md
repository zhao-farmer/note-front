# 二、字体转换

将普通的 TTF（TrueType Font）字体文件转换为 Web 友好的 **WOFF2** 格式，是优化网页字体加载性能的关键步骤。WOFF2 是目前**压缩率最高、现代浏览器广泛支持**的 Web 字体格式。



## 2.1 使用命令行工具 `woff2`

这是 Google 提供的 **官方 WOFF2 编码器**，质量高、压缩好。

**步骤**：

1. 安装 `woff2` 工具

    > 需要 Git 和 C++ 编译环境（如 GCC / Clang）

    ```bash
    # 克隆官方仓库
    git clone https://github.com/google/woff2.git

    # 进入目录并编译
    cd woff2
    make clean all
    ```

    > Windows 用户可使用 WSL，或下载预编译二进制（见下方替代方案）。

2. 转换 TTF → WOFF2

    ```bash
    # 假设你的字体是 ./fonts/MyFont.ttf
    ./woff2_compress ./fonts/MyFont.ttf
    ```

    成功后会生成：`./fonts/MyFont.woff2`

    > 注意：原 `.ttf` 文件不会被删除，`.woff2` 会放在同一目录。


## 2.2 使用 Node.js 工具

使用 `woff2` npm 包（非官方，但方便）

```bash
npm install -g woff2
```

然后转换：
```bash
woff2_compress MyFont.ttf
```

> 注意：这个 `woff2` npm 包其实是对 Google 官方工具的封装，**仍需系统有编译环境**，在 macOS/Linux 上较易成功，Windows 可能失败。

## 2.3 使用 Python 脚本

如果你有 Python 环境，可用 [`fontTools`](https://github.com/fonttools/fonttools)：

```bash
pip install fonttools brotli

# 转换 TTF → WOFF2
fonttools ttLib.woff2 compress MyFont.ttf MyFont.woff2
```

> 优点：纯 Python，跨平台  
> 依赖：`brotli`（WOFF2 使用 Brotli 压缩）

---

## 2.4 转换后如何在网页中使用？

```css
@font-face {
  font-family: 'MyWebFont';
  src: url('./fonts/MyFont.woff2') format('woff2');
  font-weight: normal;
  font-style: normal;
  font-display: swap; /* 避免文字闪烁 */
}

body {
  font-family: 'MyWebFont', sans-serif;
}
```

> **最佳实践**：只提供 `woff2` 即可覆盖 >95% 的现代浏览器（[Can I Use](https://caniuse.com/woff2)）。
