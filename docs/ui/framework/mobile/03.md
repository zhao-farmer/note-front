# 三、NutUI 

NutUI 是由 京东 出品的一套企业级移动端 UI 组件库，最初基于 Vue 开发，后来扩展支持 React 和 多端（Taro），形成 “一套设计、多端适配” 的生态。

- 官网：[https://nutui.jd.com/](https://nutui.jd.com/)
- GitHub：[https://github.com/jdf2e/nutui](https://github.com/jdf2e/nutui)



## 3.1 NutUI Vue 版使用

1. 安装

    ```bash
    # Vue 3 项目
    npm install @nutui/nutui@latest
    ```

2. 引入方式

    ```js
    // main.js
    import { createApp } from 'vue'
    import App from './App.vue'
    import NutUI from '@nutui/nutui'
    import '@nutui/nutui/dist/style.css'

    const app = createApp(App)
    app.use(NutUI)
    app.mount('#app')
    ```

3. 示例：基础用法
    ```vue
    <template>
      <div class="demo">
        <nut-cell title="标题" desc="描述" />
        <nut-button type="primary" @click="showToast">显示 Toast</nut-button>
      </div>
    </template>

    <script setup>
    import { showToast } from '@nutui/nutui'

    const showToast = () => {
      showToast('操作成功')
    }
    </script>
    ```
## 3.2 NutUI React 版使用

1. 安装

    ```bash
    # React 18+ 项目
    npm install @nutui/nutui-react
    ```

2. 引入样式（必须）

    ```js
    // 全局引入（推荐）
    import '@nutui/nutui-react/dist/style.css'
    ```

3. 使用组件

    ```tsx
    // App.tsx
    import React from 'react'
    import { Cell, Button, Toast } from '@nutui/nutui-react'

    const App = () => {
      const showToast = () => {
        Toast.show('操作成功')
      }

      return (
        <div className="demo">
          <Cell title="标题" description="描述" />
          <Button type="primary" onClick={showToast}>
            显示 Toast
          </Button>
        </div>
      )
    }

    export default App
    ```

## 3.3 NutUI Vue 对比 NutUI React

| 特性 | NutUI Vue | NutUI React |
|------|----------|------------|
| **包名** | `@nutui/nutui` | `@nutui/nutui-react` |
| **状态管理** | Vue 响应式 (`ref`, `reactive`) | React Hooks (`useState`, `useEffect`) |
| **事件绑定** | `@click` | `onClick` |
| **全局方法** | `showToast()` 直接调用 | `Toast.show()` 静态方法 |
| **按需引入** | 需 `unplugin-vue-components` 或手动 | 原生 ES Module Tree Shaking |
| **主题定制** | SCSS 变量 + CSS Variables | CSS Variables（为主） |
| **TypeScript** | 支持 | 支持 |
