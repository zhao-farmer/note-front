# 三、Ark UI组件

 Ark UI 是由 Chakra UI 团队开发的一个开源、无样式（headless）、跨框架的 UI 组件库

1. 什么是 Ark UI（Web 版）？
    - Headless（无样式）：不提供默认 CSS，只提供交互逻辑和可访问性（a11y）行为。
    - Bring Your Own Styles (BYOS)：你可以用 Tailwind CSS、Panda CSS、Vanilla Extract、 CSS-in-JS 或原生 CSS 自由设计外观。
    - 框架无关：同一套 API 可在 React / Vue / Svelte / Solid 中使用。
    - 基于状态机：复杂交互（如日期选择器、组合框）由 XState 驱动，行为可预测、边缘情况全覆盖。
    - 无障碍优先：内置 WAI-ARIA 支持，键盘导航、屏幕阅读器友好。
    - 开箱即用：45+ 个高质量组件（Accordion, Slider, Dialog, Select, Tabs, Tooltip 等）。

## 3.1 vue使用

1. 安装插件

    ```sh
    npm install @ark-ui/vue
    ```
2. 添加组件(滑动条组件)

    ```vue
    <script setup lang="ts">
    import { Slider } from '@ark-ui/vue/slider'
    </script>
    
    <template>
      <Slider.Root>
        <Slider.Label>Label</Slider.Label>
        <Slider.ValueText />
        <Slider.Control>
          <Slider.Track>
            <Slider.Range />
          </Slider.Track>
          <Slider.Thumb :index="0">
            <Slider.HiddenInput />
          </Slider.Thumb>
        </Slider.Control>
      </Slider.Root>
    </template>
    ```
3. 修改样式

    Ark UI 是一个无头组件库，不包括默认样式。您可以利用data-scope和data-part属性来使用自定义CSS样式化组件。

    ```css
    [data-scope='slider'][data-part='root'] {
      display: flex;
      flex-direction: column;
    }
    ```

## 3.2 solid使用

1. 安装插件

    ```sh
    npm install @ark-ui/solid
    ```
2. 添加组件(滑动条组件)

    ```jsx
    import { Slider } from '@ark-ui/solid/slider'

    export const Basic = () => {
      return (
        <Slider.Root>
          <Slider.Label>Label</Slider.Label>
          <Slider.ValueText />
          <Slider.Control>
            <Slider.Track>
              <Slider.Range />
            </Slider.Track>
            <Slider.Thumb index={0}>
              <Slider.HiddenInput />
            </Slider.Thumb>
          </Slider.Control>
        </Slider.Root>
      )
    }
    ```
3. 修改样式

    Ark UI 是一个无头组件库，不包括默认样式。您可以利用data-scope和data-part属性来使用自定义CSS样式化组件。

    ```css
   /* Targets the <Slider.Root /> */
    [data-scope='slider'][data-part='root'] {
        display: flex;
        flex-direction: column;
    }
    ```
