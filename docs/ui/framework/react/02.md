# 二、Material UI

Material UI（现官方更名为 **MUI**）是一套基于 Google 的 **Material Design** 规范构建的 React UI 组件库，广泛用于构建现代化、响应式的 Web 应用。它提供丰富的组件、强大的主题定制能力以及良好的 TypeScript 支持。

- 官网：https://mui.com/
- GitHub：https://github.com/mui/material-ui
- 组件文档：https://mui.com/material-ui/getting-started/overview/
- 示例模板：https://mui.com/material-ui/getting-started/templates/

## 2.1 快速开始

1. 安装插件

    ```bash
    # 使用 npm
    npm install @mui/material @emotion/react @emotion/styled

    # 使用 yarn
    yarn add @mui/material @emotion/react @emotion/styled
    ```

    > 注意：从 v5 开始，MUI 默认使用 **Emotion** 作为样式引擎，因此必须同时安装 `@emotion/   react` 和 `@emotion/styled`。

2. 示例代码

    ```jsx
    // App.jsx
    import React, { useState } from 'react';
    import {
      Button,
      Table,
      TableBody,
      TableCell,
      TableContainer,
      TableHead,
      TableRow,
      Paper,
      Dialog,
      DialogTitle,
      DialogContent,
      DialogActions,
      Typography,
      Box,
      Stack,
    } from '@mui/material';
    
    const App = () => {
      const [open, setOpen] = useState(false);
      const [selectedRecord, setSelectedRecord] = useState(null);
    
      // 模拟数据
      const data = [
        { id: 1, name: '张三', role: '前端工程师', department: '技术部' },
        { id: 2, name: '李四', role: '产品经理', department: '产品部' },
        { id: 3, name: '王五', role: 'UI设计师', department: '设计部' },
      ];
    
      // 打开弹窗
      const handleOpen = (record) => {
        setSelectedRecord(record);
        setOpen(true);
      };
    
      // 关闭弹窗
      const handleClose = () => {
        setOpen(false);
        setSelectedRecord(null);
      };
    
      return (
        <Box sx={{ p: 3 }}>
          {/* 顶部按钮 */}
          <Stack direction="row" spacing={2} sx={{ mb: 3 }}>
            <Button variant="contained" onClick={() => alert('新增功能')}>
              新增员工
            </Button>
            <Button variant="outlined">导出</Button>
            <Button variant="outlined" color="error">
              批量删除
            </Button>
          </Stack>
    
          {/* 表格 */}
          <TableContainer component={Paper}>
            <Table>
              <TableHead>
                <TableRow>
                  <TableCell>姓名</TableCell>
                  <TableCell>职位</TableCell>
                  <TableCell>部门</TableCell>
                  <TableCell>操作</TableCell>
                </TableRow>
              </TableHead>
              <TableBody>
                {data.map((row) => (
                  <TableRow key={row.id}>
                    <TableCell>{row.name}</TableCell>
                    <TableCell>{row.role}</TableCell>
                    <TableCell>{row.department}</TableCell>
                    <TableCell>
                      <Button
                        size="small"
                        variant="text"
                        onClick={() => handleOpen(row)}
                      >
                        查看详情
                      </Button>
                    </TableCell>
                  </TableRow>
                ))}
              </TableBody>
            </Table>
          </TableContainer>
    
          {/* 弹窗（Dialog） */}
          <Dialog open={open} onClose={handleClose} maxWidth="sm" fullWidth>
            <DialogTitle>员工详情</DialogTitle>
            <DialogContent>
              {selectedRecord && (
                <Box sx={{ py: 2 }}>
                  <Typography><strong>ID:</strong> {selectedRecord.id}</Typography>
                  <Typography><strong>姓名:</strong> {selectedRecord.name}</Typography>
                  <Typography><strong>职位:</strong> {selectedRecord.role}</Typography>
                  <Typography><strong>部门:</strong> {selectedRecord.department}</  Typography>
                </Box>
              )}
            </DialogContent>
            <DialogActions>
              <Button onClick={handleClose} color="primary">
                关闭
              </Button>
            </DialogActions>
          </Dialog>
        </Box>
      );
    };
    
    export default App;
    ```
