# 三、Chakra UI

Chakra UI 是一个 **现代化、可访问性强、高度可定制** 的 React UI 组件库，主打 **开发者体验（DX）优秀**、**主题系统灵活**、**响应式设计内置**，非常适合构建美观且一致的 React 应用。

- 官网：https://chakra-ui.com/
- GitHub：https://github.com/chakra-ui/chakra-ui
- 文档：https://chakra-ui.com/docs/getting-started
- 组件库：https://chakra-ui.com/docs/components

## 3.1 快速使用

1. 安装 Chakra UI

    ```bash
    # 使用 npm
    npm install @chakra-ui/react @emotion/react @emotion/styled framer-motion
    ```
2. 设置 Provider（全局配置）


    在应用根组件（如 `main.jsx` 或 `App.jsx`）中包裹 `ChakraProvider`：

    ```jsx
    // main.jsx (Vite) 或 index.js (CRA)
    import React from 'react';
    import ReactDOM from 'react-dom/client';
    import { ChakraProvider } from '@chakra-ui/react';
    import App from './App';

    const root = ReactDOM.createRoot(document.getElementById('root'));
    root.render(
      <ChakraProvider>
        <App />
      </ChakraProvider>
    );
    ```


3. 基础使用示例 按钮 + 卡片 + 响应式布局

    ```jsx
    // App.jsx
    import {
      Button,
      Card,
      CardHeader,
      CardBody,
      CardFooter,
      Heading,
      Text,
      Stack,
      Box,
      useToast,
    } from '@chakra-ui/react';

    function App() {
      const toast = useToast();

      return (
        <Box maxW="md" mx="auto" p={4}>
          <Card>
            <CardHeader>
              <Heading size="md">欢迎使用 Chakra UI</Heading>
            </CardHeader>
            <CardBody>
              <Text>这是一个简洁、可访问、主题化的 UI 组件库。</Text>
            </CardBody>
            <CardFooter>
              <Stack direction="row" spacing={3}>
                <Button
                  colorScheme="blue"
                  onClick={() =>
                    toast({
                      title: "操作成功",
                      description: "你点击了主按钮！",
                      status: "success",
                      duration: 3000,
                      isClosable: true,
                    })
                  }
                >
                  主要操作
                </Button>
                <Button variant="outline">次要操作</Button>
              </Stack>
            </CardFooter>
          </Card>
        </Box>
      );
    }

    export default App;
    ```
