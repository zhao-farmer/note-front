# 一、element-UI

Element UI 是一套为 Vue 2 设计的桌面端组件库，由饿了么前端团队开发，提供丰富、美观、易用的 UI 组件（如表格、表单、对话框、导航等）。

Element UI 仅支持 Vue 2
官方已停止维护 Element UI（最后版本：2.15.14），但仍在大量项目中使用

element官网:[https://element.eleme.cn/](https://element.eleme.cn/)

## 1.1 快速开始

1. 安装

    ```sh
    npm i element-ui -S
    ```

2. 配置项 main.js

    ```js
    import Vue from 'vue';
    import ElementUI from 'element-ui';
    import 'element-ui/lib/theme-chalk/index.css';
    import App from './App.vue';

    Vue.use(ElementUI);

    new Vue({
      el: '#app',
      render: h => h(App)
    });
    ```
3. 示例：按钮 + 表格 + 弹窗

    ```vue
    <!-- App.vue -->
    <template>
      <div id="app">
        <!-- 按钮 -->
        <el-button type="primary" @click="showDialog = true">打开弹窗</el-button>

        <!-- 表格 -->
        <el-table :data="tableData" style="width: 100%; margin-top: 20px">
          <el-table-column prop="name" label="姓名"></el-table-column>
          <el-table-column prop="email" label="邮箱"></el-table-column>
        </el-table>

        <!-- 对话框 -->
        <el-dialog title="提示" :visible.sync="showDialog" width="30%">
          <span>这是一个对话框</span>
          <span slot="footer">
            <el-button @click="showDialog = false">取消</el-button>
            <el-button type="primary" @click="confirm">确定</el-button>
          </span>
        </el-dialog>
      </div>
    </template>

    <script>
    export default {
      data() {
        return {
          showDialog: false,
          tableData: [
            { name: '张三', email: 'zhangsan@example.com' },
            { name: '李四', email: 'lisi@example.com' }
          ]
        }
      },
      methods: {
        confirm() {
          this.$message.success('操作成功！')
          this.showDialog = false
        }
      }
    }
    </script>
    ```
