# 一、iconify图标库

`@iconify/json` 是 [Iconify](https://iconify.design/) 官方提供的 **本地图标数据包**，包含数千个开源图标集（如 Material Design Icons、Bootstrap Icons、Feather、Tabler、Lucide 等）的完整 JSON 数据。它允许你在 **Node.js 环境或构建时** 获取图标 SVG 数据，非常适合用于：

- 静态站点生成器（如 Next.js、Nuxt、Astro、SvelteKit）
- 构建自定义图标组件
- 离线使用图标（无需网络请求）

> 与在线 CDN 方式（如 `<script src="https://code.iconify.design/...">`）不同，`@iconify/json` 是 **纯数据包**，不包含运行时逻辑。


## 1.1 安装

```bash
npm install --save-dev @iconify/json
```

> 注意：这是一个开发依赖（devDependency），因为通常只在构建时使用。

## 1.2 基本用法（获取图标 SVG 字符串）

示例：在 Node.js 或构建脚本中读取图标

```js
import { icons } from '@iconify/json';

// 获取 mdi 图标集中的 "home" 图标
const homeIcon = icons['mdi:home'];

if (homeIcon) {
  console.log(homeIcon.body); // 输出 SVG 路径字符串，如 '<path d="..."/>'
}
```

每个图标的结构如下：
```ts
{
  body: string;     // SVG 内容（不含 <svg> 标签）
  width?: number;   // 原始宽度
  height?: number;  // 原始高度
  viewBox?: string; // viewBox 属性
}
```

## 1.3 在前端框架中使用（以 React/Vue 为例）

推荐方式：配合 `@iconify/react` 或 `@iconify/vue` 使用（但它们默认走 CDN）

如果你希望 **完全离线 + 按需加载**，可以手动构建图标组件。

-  示例 1：React 自定义 Icon 组件（使用 @iconify/json）

    ```tsx
    // components/Icon.tsx
    import { icons } from '@iconify/json';
    import type { FC, SVGProps } from 'react';

    interface IconProps extends SVGProps<SVGSVGElement> {
      name: string; // 格式如 "mdi:home", "bi:search"
    }

    const Icon: FC<IconProps> = ({ name, ...props }) => {
      const iconData = icons[name];

      if (!iconData) {
        console.warn(`Icon "${name}" not found`);
        return null;
      }

      const { body, width = 24, height = 24 } = iconData;

      return (
        <svg
          xmlns="http://www.w3.org/2000/svg"
          width={width}
          height={height}
          viewBox={`0 0 ${width} ${height}`}
          {...props}
          dangerouslySetInnerHTML={{ __html: body }}
        />
      );
    };

    export default Icon;
    ```

    **使用**：

    ```tsx
    import Icon from './components/Icon';

    function App() {
      return (
        <div>
          <Icon name="mdi:home" className="text-blue-500" />
          <Icon name="bi:search" style={{ fontSize: '2rem' }} />
        </div>
      );
    }
    ```

    > 图标名称格式：`{prefix}:{name}`  
    > 可在 [Iconify Explorer](https://icon-sets.iconify.design/) 查找（左侧是 prefix，右侧是name）


- 示例 2：Vue 3 自定义组件

    ```vue
    <!-- components/Icon.vue -->
    <script setup lang="ts">
    import { icons } from '@iconify/json';
    import { computed } from 'vue';

    const props = defineProps<{
      name: string; // e.g. 'mdi:home'
    }>();

    const icon = computed(() => icons[props.name]);

    if (!icon.value) {
      console.warn(`Icon "${props.name}" not found`);
    }
    </script>

    <template>
      <svg
        v-if="icon"
        xmlns="http://www.w3.org/2000/svg"
        :width="icon.width || 24"
        :height="icon.height || 24"
        :viewBox="`0 0 ${icon.width || 24} ${icon.height || 24}`"
        v-html="icon.body"
      />
    </template>
    ```

    **使用**：

    ```vue
    <template>
      <Icon name="mdi:home" class="text-red-500" />
    </template>
    ```

## 1.4 优化：按需打包

`@iconify/json` 包含所有图标（约 200MB+），但 **现代打包工具（Vite、Webpack）会自动 tree-shake 未使用的图标**，前提是：

- 你使用 **静态字符串** 引用图标名（如 `'mdi:home'`）
- 不要动态拼接（如 `icons[`${prefix}:${name}`]` 可能导致全量引入）

安全写法：
```js
import { icons } from '@iconify/json';
const icon = icons['mdi:home']; // 静态 key，可被 tree-shake
```

危险写法：
```js
const getIcon = (name) => icons[name]; // 动态 key，可能引入全部图标
```

> 构建后可通过分析工具（如 `rollup-plugin-visualizer`）确认是否只打包了用到的图标。
