# 二、框架 `unplugin-icons`

`unplugin-icons` 是一个由 [Anthony Fu](https://github.com/antfu) 开发的通用 Vite/Rollup/Webpack 插件，用于在构建时 **按需、离线、零运行时** 地使用 [Iconify](https://iconify.design/) 图标。它支持几乎所有现代前端框架（Vue、React、Svelte、Solid 等）和构建工具。

> 核心优势：
>
> -   **无需网络请求**（图标来自 `@iconify/json`）
> -   **自动 Tree-shaking**（只打包用到的图标）
> -   **SSR/SSG 安全**
> -   **支持数千个图标集**（mdi、heroicons、tabler、lucide、feather 等）

## 2.1 安装依赖

```bash
# 核心插件
npm install -D unplugin-icons

# 图标数据源（包含所有 Iconify 图标）
npm install -D @iconify/json
```

> 注意：`@iconify/json` 是开发依赖，因为只在构建时读取。


## 2.2 配置构建工具

通用配置（适用于 Vite / Rollup / Webpack / Nuxt / Astro 等）

1. **Vite（最常见）**

    ```ts
    // vite.config.ts
    import { defineConfig } from "vite";
    import Icons from "unplugin-icons/vite";
    import IconsResolver from "unplugin-icons/resolver";
    import Components from "unplugin-vue-components/vite"; // 如果是 Vue 项目

    export default defineConfig({
        plugins: [
            // 自动注册图标组件（可选但推荐）
            Components({
                resolvers: [
                    IconsResolver({
                        prefix: "i", // 组件名前缀，如 <i-mdi-home />
                        extension: "vue", // 或 'jsx' for React
                    }),
                ],
            }),
            // 核心图标插件
            Icons({
                compiler: "vue3", // 或 'jsx', 'solid', 'svelte' 等
                autoInstall: true, // 自动安装缺失的图标集（实验性）
            }),
        ],
    });
    ```

2. **Webpack（如 Vue CLI / React）**

    ```js
    // webpack.config.js
    const Icons = require("unplugin-icons/webpack");

    module.exports = {
        plugins: [
            Icons({
                compiler: "vue3", // 根据框架选择
            }),
        ],
    };
    ```

3. **Rollup**

    ```js
    // rollup.config.js
    import Icons from "unplugin-icons/rollup";

    export default {
        plugins: [Icons({ compiler: "vue3" })],
    };
    ```

> 支持的 `compiler` 值：
>
> -   `'vue3'` / `'vue2'`
> -   `'jsx'`（React / Preact）
> -   `'solid'`
> -   `'svelte'`
> -   `'web-components'`

## 2.3 使用方式

- 方式 1：通过自动注册的组件（推荐）

    启用 `IconsResolver` 后，你可以直接使用组件：

    ```vue
    <!-- Vue 示例 -->
    <template>
        <div>
            <!-- 格式：<i-{prefix}-{name} /> -->
            <i-mdi-home class="text-2xl text-blue-500" />
            <i-hero-academic-cap-solid />
            <i-tabler-brand-github />
            <i-lucide-moon />
        </div>
    </template>
    ```

    > 组件名规则：`i-{collection}-{icon}`
    >
    > -   `mdi:home` → `<i-mdi-home />`
    > -   `hero:academic-cap-solid` → `<i-hero-academic-cap-solid />`

    **优点**：

    -   无需 import
    -   自动按需引入
    -   支持 TypeScript 提示（需额外配置）

- 方式 2：手动导入（适用于 React / 不想自动注册）

    ```tsx
    // React 示例
    import { Icon } from "unplugin-icons/runtime";
    import { mdiHome } from "virtual:icons/mdi/home";

    export default function App() {
        return <Icon icon={mdiHome} className="w-6 h-6 text-red-500" />;
    }
    ```

    或者直接使用 SVG 组件：

    ```tsx
    import HomeIcon from "virtual:icons/mdi/home";

    export default () => <HomeIcon className="w-6 h-6" />;
    ```

    > 路径规则：`virtual:icons/{collection}/{icon}`


## 2.4 自定义配置

1. 修改默认属性（如大小、颜色）

    ```ts
    // vite.config.ts
    Icons({
        scale: 1.2, // 缩放比例
        defaultClass: "inline-block", // 默认 class
        compiler: "vue3",
    });
    ```

2. 支持动态图标（谨慎使用）

    ```vue
    <script setup>
    const iconName = "mdi:home";
    </script>

    <template>
        <!-- 不推荐：无法 tree-shake -->
        <Icon :name="iconName" />
    </template>
    ```

    > 动态 `name` 会导致 **所有图标被打包**！建议限制范围或使用静态组件名。

## 2.5 与 Tailwind CSS 配合

由于图标是内联 SVG，可直接用 Tailwind 控制：

```vue
<i-mdi-heart class="text-pink-500 w-5 h-5 inline" />
```

或全局设置：

```css
/* app.css */
[class^="i-"] {
    @apply inline-block align-middle;
}
```


## 2.6 TypeScript 支持

安装类型生成插件：

```bash
npm install -D @iconify/json
```

然后在 `vite.config.ts` 中启用：

```ts
Icons({
    compiler: "vue3",
    // 自动生成 types.d.ts
    transformAssetsUrls: true,
});
```

或者使用社区方案 [`unplugin-icons/types`](https://github.com/antfu/unplugin-icons#typescript-support) 手动生成类型。
