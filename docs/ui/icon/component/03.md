# 三、Font Awesome

Font Awesome 是全球最流行的图标库之一，提供大量高质量的矢量图标。其**免费版（Free）** 包含 **超过 2,000 个图标**，可用于个人和商业项目（需遵守 [OFL 许可证](https://fontawesome.com/license/free)）。

以下是 Font Awesome 免费版在 Web 项目中的 **完整使用指南**。


## 3.1 获取方式

- 方法 1：通过 CDN（最简单，推荐快速原型）
    在 HTML 的 `<head>` 中添加：
    
    ```html
    <!-- 最新版 Free 版本（自动使用最新） -->
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css" />
    
    <!-- 或使用官方 CDN（可能稍慢） -->
    <link rel="stylesheet" href="https://use.fontawesome.com/releases/v6.5.0/css/all.css" />
    ```
    
    > 优点：无需下载，一行代码搞定  
    > 缺点：依赖网络，无法离线使用


- 方法 2：NPM 安装（推荐用于构建项目：Vue/React/Vite 等）

    ```bash
    npm install --save @fortawesome/fontawesome-free
    ```

    然后在入口文件（如 `main.js`、`app.vue`、`index.css`）中引入：

    ```js
    // 引入全部样式（CSS 方式）
    import '@fortawesome/fontawesome-free/css/all.css'
    ```

    或只引入需要的部分（更优）：

    ```js
    // 推荐：使用 JavaScript/SVG 方式（见下文“高级用法”）
    ```

    > 文件位置：`node_modules/@fortawesome/fontawesome-free/`


- 方法 3：下载 ZIP 手动集成（完全离线）

    1. 访问 [https://fontawesome.com/download](https://fontawesome.com/download)
    2. 下载 **Free for the Web** ZIP 包
    3. 解压后将 `css/` 和 `webfonts/` 目录复制到你的项目（如 `public/assets/fontawesome/`）
    4. 在 HTML 中引入本地 CSS：

    ```html
    <link rel="stylesheet" href="/assets/fontawesome/css/all.min.css">
    ```

    > 注意：`webfonts/` 文件夹必须与 `css/` 同级，否则字体加载失败。



## 3.2 基本使用语法

Font Awesome 图标通过 `<i>` 标签 + class 使用：

```html
<!-- 实心图标（solid） -->
<i class="fas fa-home"></i>

<!-- 线框图标（regular） -->
<i class="far fa-user"></i>

<!-- 品牌图标（brands） -->
<i class="fab fa-github"></i>
```

**图标前缀说明**：

| 前缀 | 含义 | 免费版是否可用 |
|------|------|----------------|
| `fas` | Solid（实心） | 是 |
| `far` | Regular（线框） | 部分（仅限指定图标） |
| `fal` | Light |  仅 Pro |
| `fat` | Thin | 仅 Pro |
| `fab` | Brands（品牌） | 是 |

> 🔍 查看哪些图标免费：访问 [https://fontawesome.com/icons](https://fontawesome.com/icons)，筛选 “Free” 即可。


## 3.3 自定义样式（大小、颜色、动画等）

因为图标是 Web Font，可用 CSS 控制：

```html
<i class="fas fa-spinner fa-spin fa-2x text-blue-500"></i>
```

- 常用工具类（来自 Font Awesome 自带）：

    | 类名 | 作用 |
    |------|------|
    | `fa-lg` / `fa-2x` / `fa-3x` ... `fa-10x` | 调整大小 |
    | `fa-spin` | 旋转动画 |
    | `fa-pulse` | 脉冲动画（8 步旋转） |
    | `fa-flip-horizontal` / `fa-flip-vertical` | 翻转 |
    | `fa-rotate-90` / `fa-rotate-180` / `fa-rotate-270` | 旋转 |

- 用 CSS 自定义：

    ```css
    .fas.fa-home {
      color: #0d6efd;
      font-size: 2rem;
    }
    ```

## 3.4 在现代框架中使用（Vue / React）

1. Vue 3 + Vite（推荐使用 SVG + JS 方式）

    虽然 CSS 方式简单，但 **SVG + JavaScript 方式更灵活、支持 Tree-shaking**：

    ```bash
    npm install --save @fortawesome/fontawesome-svg-core
    npm install --save @fortawesome/free-solid-svg-icons
    npm install --save @fortawesome/free-regular-svg-icons
    npm install --save @fortawesome/free-brands-svg-icons
    npm install --save @fortawesome/vue-fontawesome
    ```

    配置插件：

    ```js
    // main.js
    import { createApp } from 'vue'
    import App from './App.vue'
    import { library } from '@fortawesome/fontawesome-svg-core'
    import { fas } from '@fortawesome/free-solid-svg-icons'
    import { far } from '@fortawesome/free-regular-svg-icons'
    import { fab } from '@fortawesome/free-brands-svg-icons'
    import { FontAwesomeIcon } from '@fortawesome/vue-fontawesome'

    library.add(fas, far, fab)

    const app = createApp(App)
    app.component('FontAwesomeIcon', FontAwesomeIcon)
    app.mount('#app')
    ```

    使用：

    ```vue
    <template>
      <font-awesome-icon :icon="['fas', 'home']" />
      <font-awesome-icon :icon="['fab', 'github']" />
    </template>
    ```

    >  优点：只打包用到的图标，体积更小；支持动态属性；无障碍友好。

2.  React（类似）

    ```bash
    npm install --save @fortawesome/react-fontawesome
    npm install --save @fortawesome/free-solid-svg-icons
    ```

    ```jsx
    import { FontAwesomeIcon } from '@fortawesome/react-fontawesome'
    import { faHome } from '@fortawesome/free-solid-svg-icons'

    function App() {
      return <FontAwesomeIcon icon={faHome} />
    }
    ```
