# 四、Xicons的使用

Xicons 是一个功能强大且资源丰富的开源图标库，它整合了多个流行的图标集（如 Fluent UI、Ionicons、Ant Design 等），并为不同前端框架（Vue 2/3, React）提供了现成的组件。

## 4.1 安装依赖

首先，你需要安装 Xicons 的核心工具包以及你想要使用的具体图标库。Xicons 采用按需加载的方式，你可以只安装需要的图标集，以减少打包体积。

```bash
# 安装核心工具包 (包含 Icon 组件)
npm i -D @vicons/utils

# 安装具体的图标库 (可选，按需安装)
npm i -D @vicons/fluent      # Fluent UI 图标
npm i -D @vicons/ionicons5  # Ionicons 5 图标
npm i -D @vicons/antd       # Ant Design 图标
npm i -D @vicons/fa         # Font Awesome 图标
```

## 4.2 基础使用方式

安装完成后，你有两种主要的方式来使用图标：

- 方式一：直接使用图标组件

    这是最简单直接的方式。你可以直接引入图标组件并在模板中使用。

    ```vue
    <template>
      <!-- 直接使用，但无法通过 props 直接控制颜色和大小 -->
      <CarOutline />
    </template>

    <script setup>
    // 引入具体的图标
    import { CarOutline } from '@vicons/ionicons5'
    </script>
    ```

- 方式二：使用 `Icon` 组件包裹（推荐）

    通过 `@vicons/utils` 提供的 `Icon` 组件，你可以方便地通过 `props` 控制图标的尺寸和颜色，这在构建动  态 UI 时非常有用。

    ```vue
    <template>
      <!-- 使用 Icon 组件包裹，可以轻松控制样式 -->
      <Icon :size="40" color="#0e7a0d">
        <CarOutline />
      </Icon>
    </template>

    <script setup>
    import { CarOutline } from '@vicons/ionicons5'
    import { Icon } from '@vicons/utils'
    </script>
    ```

## 3. 如何查找和选择图标

在编写代码前，你可能需要预览图标以确定其名称和所属库。

*   **在线预览网站**：访问 [xicons.org](https://www.xicons.org/)。
*   **搜索功能**：在网站上你可以按分类（如 Fluent, Ionicons）浏览，也可以直接搜索图标名称。
*   **查看导入信息**：点击选中一个图标，网站会显示该图标所属的库名（如 `@vicons/ionicons5`）和组件名（如 `GameControllerOutline`），这直接对应了你的 `import` 语句。
