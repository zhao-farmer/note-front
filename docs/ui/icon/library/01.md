# 一、iconfont

Iconfont 是阿里巴巴推出的一个矢量图标管理平台（[https://www.iconfont.cn/](https://www.iconfont.cn/)），开发者可以在这里搜索、下载、管理并使用各种免费的 SVG 图标。以下是 Iconfont 的基本使用方法，适用于 Web 项目（包括原生 HTML、Vue、React 等）：

## 1.1 获取图标

1. **注册/登录**  
   访问 [iconfont 官网](https://www.iconfont.cn/)，注册或登录账号。

2. **搜索图标**  
   在首页搜索你需要的图标（如“搜索”、“用户”、“设置”等）。

3. **添加到项目**

    - 点击图标旁的「购物车」图标，加入购物车。
    - 点击页面右上角「购物车」→「添加至项目」。
    - 如果没有项目，可新建一个项目（如 `my-web-icons`）。

4. **生成代码**  
   进入你的项目页面，点击「Font Class」或「Symbol」方式，然后点击「查看在线链接」或「下载至本地」。

## 1.1 在 Web 项目中使用 Iconfont

### 方法一：使用 Font Class

1. **引入 CSS 文件**  
   在 HTML 的 `<head>` 中引入在线 CSS 链接（来自 Iconfont 项目页）：

    ```html
    <link rel="stylesheet" href="//at.alicdn.com/t/c/font_xxxxxx.css" />
    ```

2. **使用图标**  
   在需要的地方使用 `<i>` 标签 + 对应的 class：

    ```html
    <i class="iconfont icon-search"></i>
    ```

    其中 `icon-search` 是你在项目中图标的名称。

3. **自定义样式（可选）**  
   可通过 CSS 调整大小、颜色等：
    ```css
    .iconfont {
        font-size: 24px;
        color: #333;
    }
    ```

### 方法二：使用 Symbol

优点：支持多色图标、避免冲突、语义化更好。

1. **引入 JS 文件**  
   在 HTML 中引入：

    ```html
    <script src="//at.alicdn.com/t/c/font_xxxxxx.js"></script>
    ```

2. **使用图标**  
   使用 `<svg>` + `<use>` 方式：

    ```html
    <svg class="icon" aria-hidden="true">
        <use xlink:href="#icon-search"></use>
    </svg>
    ```

3. **样式控制**  
   可通过 CSS 控制：
    ```css
    .icon {
        width: 1em;
        height: 1em;
        fill: currentColor; /* 支持继承文字颜色 */
    }
    ```

> 注意：在 Vue 3 / React 17+ 中，`xlink:href` 已废弃，可直接用 `href`：
>
> ```html
> <use href="#icon-search"></use>
> ```

### 方法三：下载到本地

1. 下载项目 ZIP 包（包含 `.css`, `.eot`, `.woff`, `.svg`, `.ttf` 等文件）。
2. 将文件放入项目静态资源目录（如 `assets/iconfont/`）。
3. 引入本地 CSS：
    ```html
    <link rel="stylesheet" href="/assets/iconfont/iconfont.css" />
    ```
4. 使用方式同「方法一」。


## 1.3 在 Vue / React 项目

-   **Vue 项目**：推荐使用 Symbol 方式，或封装成组件。

    ```vue
    <!-- Icon.vue -->
    <template>
        <svg class="icon" aria-hidden="true">
            <use :href="`#icon-${name}`" />
        </svg>
    </template>
    <script>
    export default {
        props: ["name"],
    };
    </script>
    ```

    使用：

    ```vue
    <Icon name="search" />
    ```

-   **React 项目**：类似，可用函数组件封装。


## 1.4 常见问题

-   **图标不显示？**  
    检查网络请求是否成功加载 CSS/JS；检查图标名是否正确；本地开发时注意路径。

-   **如何更新图标？**  
    在 Iconfont 项目中更新后，重新生成链接或重新下载即可。

-   **支持多色图标吗？**  
    Font Class 不支持（单色），Symbol 支持多色（需上传时保留颜色信息）。
