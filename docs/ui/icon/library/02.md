# 二、IcoMoon

IcoMoon 是一个功能强大且灵活的 **矢量图标（SVG/Icon Font）生成与管理工具**，适用于 Web、移动端等项目。它允许你从海量图标库中选择图标，或上传自己的 SVG，然后打包成字体文件（Icon Font）、SVG Sprite、React/Vue 组件等多种格式。

官网地址：[https://icomoon.io](https://icomoon.io)

## 2.1 基本使用流程

- 步骤 1：访问 IcoMoon App

    打开 [IcoMoon App](https://icomoon.io/app/)（无需注册即可使用基础功能）。

- 步骤 2：选择图标

    -   默认会加载 **IcoMoon Free** 图标集（数百个免费图标）。
    -   点击左上角 **“Add Icons From Library”** 可添加更多图标库（如 Font Awesome、Material     Icons 等）。
    -   点击任意图标将其加入底部选中区（已选图标会高亮）。
    -   也可以点击 **“Import Icons”** 上传自己的 `.svg` 文件（支持批量）。

- 步骤 3：管理图标

    在选中区（底部栏）可以：

    -   重命名图标（双击名称）
    -   调整图标方向、翻转、旋转
    -   设置 Unicode 编码（用于字体）
    -   删除不需要的图标

- 步骤 4：生成并下载

    点击右下角 **“Generate Font”** 按钮：

    可选配置（点击 “Font Settings”）：

    -   **Font Name**：如 `my-icons`
    -   **Class Prefix**：如 `icon-`（生成 CSS 类名前缀）
    -   **Embed Ligatures**：启用后可通过 `<span>home</span>` 显示图标（需现代浏览器）

    点击 **“Download”**，将得到一个 ZIP 包，包含：

    ```
    icomoon/
    ├── demo-files/       # 预览页面所需资源
    ├── demo.html         # 本地预览所有图标
    ├── fonts/            # 字体文件（.eot, .ttf, .woff, .woff2）
    ├── selection.json    # 项目配置（可用于后续编辑）
    └── style.css         # 样式文件
    ```

## 2.2 在 Web 项目中使用

1. 引入字体和样式

    将 `fonts/` 和 `style.css` 复制到你的项目（如 `assets/icomoon/`）。

    在 HTML 中引入 CSS：

    ```html
    <link rel="stylesheet" href="assets/icomoon/style.css" />
    ```

2. 使用图标
    
    通过 `<i>` 或 `<span>` + class 使用：
    
    ```html
    <i class="icon-home"></i> <span class="icon-user"></span>
    ```
    
    > 图标类名默认为 `icon-xxx`，其中 `xxx` 是你在 IcoMoon 中设置的图标名称。

3. 自定义样式

    ```css
    .icon {
        font-size: 24px;
        color: #007bff;
    }
    ```

## 2.3 其他输出格式（高级用法）

在 “Generate Font” 页面，点击 **“Download” 旁边的下拉箭头**，可选择不同格式：

| 格式                | 适用场景                              |
| ------------------- | ------------------------------------- |
| **Font (Default)**  | 传统 Icon Font，兼容性好              |
| **SVG Sprite**      | 现代 Web 推荐，支持多色、清晰缩放     |
| **React Component** | 用于 React 项目（每个图标为独立组件） |
| **Vue Component**   | 用于 Vue 项目                         |
| **JSON / PNG**      | 用于设计或非 Web 场景                 |

**示例：使用 SVG Sprite（推荐现代项目）**

1. 下载 **SVG Symbol** 格式（实际是 SVG Sprite）。
2. 将 `symbol-defs.svg` 放入 `public/` 目录。
3. 在 HTML 中嵌入（或通过 AJAX 加载）：

    ```html
    <!-- 隐藏的 sprite 定义 -->
    <svg style="display: none;">
        <use href="/symbol-defs.svg#icon-home"></use>
    </svg>
    ```

    或直接内联整个 `symbol-defs.svg` 到 HTML `<body>` 开头（更可靠）。

4. 使用图标：

    ```html
    <svg class="icon">
        <use href="#icon-home"></use>
    </svg>
    ```

5. 样式控制：
    ```css
    .icon {
        width: 1em;
        height: 1em;
        fill: currentColor; /* 继承文字颜色 */
    }
    ```

> 优点：支持多色 SVG、无字体加载问题、语义化更好。
