# 三、Google Fonts

Google Fonts 提供的 **Material Symbols & Icons**（原称 "Material Icons"）是一套免费、开源、高质量的图标库，适用于 Web 和移动端。你可以在 [https://fonts.google.com/icons](https://fonts.google.com/icons) 浏览并使用这些图标。

以下是 **在 Web 项目中使用 Google Fonts 图标** 的完整指南：

## 3.1 快速使用

1. 在 HTML 中引入图标字体

    在 `<head>` 中添加以下一行代码（使用 `Material Symbols`，支持可变字体和多种样式）：

    ```html
    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols  +Outlined" />
    ```

    > 其他样式可选：
    > - `Material+Symbols+Rounded`
    > - `Material+Symbols+Sharp`
    > - `Material+Icons`（旧版，仅单色）

2. 使用图标
    直接用 `<span>` 或 `<i>` 标签，写入图标名称（注意：使用 **下划线命名**，如 `home` →  `home`，但部分需查官网）：

    ```html
    <span class="material-symbols-outlined">home</span>
    <span class="material-symbols-rounded">search</span>
    <span class="material-symbols-sharp">settings</span>
    ```

    > 图标名称可在 [fonts.google.com/icons](https://fonts.google.com/icons) 搜索后点击图标查看（右侧面板显示“Code”）。


## 3.2 自定义样式

Google 的 Material Symbols 是 **文本字体**，因此可通过 CSS 控制大小、颜色等：

```css
.material-symbols-outlined {
  font-size: 24px;
  color: #1976d2;
  vertical-align: middle;
}
```

调整图标粗细、填充、倾斜（仅限 **Material Symbols**，非旧版 Icons）

Material Symbols 支持 **可变字体轴（font-variation-settings）**，可动态调整：

```html
<span class="material-symbols-outlined" style="
  font-variation-settings:
    'FILL' 1,   /* 0=outline, 1=filled */
    'wght' 700, /* weight: 100–700 */
    'GRAD' 0,   /* grade: -25 to +200 */
    'opsz' 48;  /* optical size: 20–48 */
">home</span>
```

> - `FILL`: 0（线框）或 1（填充）
> - `wght`: 字重（类似 bold）
> - `opsz`: 推荐值 24、48（越大细节越多）

## 3.3 离线使用（自托管）

如果你不能依赖 Google CDN（如内网项目），可以：

- 方法 1：下载 WOFF2 字体文件

    1. 打开 [Google Fonts 链接](https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined)
    2. 查看返回的 CSS 内容，找到 `src: url(...)` 中的 `.woff2` 地址
    3. 下载字体文件（如 `material-symbols-outlined.woff2`）
    4. 自建 CSS：

    ```css
    @font-face {
      font-family: 'Material Symbols Outlined';
      src: url('./fonts/material-symbols-outlined.woff2') format('woff2');
      font-weight: normal;
      font-style: normal;
    }

    .material-symbols-outlined {
      font-family: 'Material Symbols Outlined';
      font-size: 24px;
      line-height: 1;
    }
    ```

- 方法 2：使用 NPM 包（适用于构建工具）

    ```bash
    npm install @mdi/font  # ❌ 注意：这是 Material Design Icons（社区版）

    # Google 官方未提供 NPM 包，但可用：
    npm install material-symbols  # 社区维护的字体包
    ```

    然后在 JS 中引入：
    ```js
    import 'material-symbols/outlined.css';
    // 或
    import 'material-symbols/rounded.css';
    ```

    > 注意：`material-symbols` 是第三方包（[GitHub](https://github.com/marella/  material-symbols)），非 Google 官方发布，但同步及时。


## 3.4 在主流框架中使用

**Vue / React**

直接按上述 HTML 方式使用即可，无需额外组件。

也可封装为组件（以 Vue 为例）：

```vue
<!-- MaterialIcon.vue -->
<template>
  <span 
    class="material-symbols-outlined"
    :style="{
      fontVariationSettings: `'FILL' ${fill}, 'wght' ${weight}, 'GRAD' ${grade}, 'opsz' ${size}`
    }"
  >
    {{ name }}
  </span>
</template>

<script>
export default {
  props: {
    name: String,
    fill: { type: Number, default: 0 },
    weight: { type: Number, default: 400 },
    grade: { type: Number, default: 0 },
    size: { type: Number, default: 24 }
  }
}
</script>
```

使用：
```vue
<MaterialIcon name="home" :fill="1" :weight="700" :size="48" />
```
