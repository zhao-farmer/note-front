二、前端核心

2.1 路由

2.1.1 文件路由基础

  1. 路由映射

    • 基础路由映射

      文件路径对应 URL
      routes/index.tsx/
      routes/about.tsx/about
      routes/contact.tsx/contact

    • 动态路由

      routes/user/[id].tsx      → /user/123
routes/post/[...slug].tsx → /post/a/b/c  # 通配符（捕获多级路径）

    • 嵌套路由

      routes/
├── index.tsx
└── dashboard/
    ├── index.tsx       → /dashboard
    └── settings.tsx    → /dashboard/settings

    • 路由分组

      用括号包裹目录名，不影响 URL 结构，仅用于组织代码：

      routes/
├── (load)/
│   ├── path1.tsx     → /path1
│   └── path2.tsx     → /path2
└── (state)/
    ├── success.tsx   → /success
    └── failure.tsx   → /failure

  2. <FileRoutes />：路由的“运行时引擎”

    • 作用

      • 自动扫描 src/routes/ 目录
      • 生成完整的路由树（包括页面 + API）
      • 在客户端和服务器端统一渲染

    • 使用位置

    必须在应用根组件 src/app.tsx 中使用：

    // src/app.tsx
import { Router } from '@solidjs/router';
import { FileRoutes } from '@solidjs/start/router';

export default function App() {
  return (
    <Router>
      <FileRoutes /> {/* 👈 扫描 src/routes/ 并生成路由 */}
    </Router>
  );
}

  3. 两者如何协作？（工作流程）

    当你访问 URL（如 /blog/hello）时：

    1. 构建阶段（开发或构建时）
      SolidStart 扫描 src/routes/，生成内部路由映射表：

      {
  "/": () => import("./routes/index.tsx"),
  "/blog": () => import("./routes/blog/index.tsx"),
  "/blog/:slug": () => import("./routes/blog/[slug].tsx"),
  "/api/users": () => import("./routes/api/users.ts") // 服务端端点
}

    2. 运行阶段（客户端 or 服务端）

      • <FileRoutes /> 根据当前 URL，动态加载对应组件
      • 自动应用嵌套布局（如 layout.tsx → blog/layout.tsx）
      • 渲染最终页面

    3. 结果
      页面结构 =

      App (app.tsx)
  ↓
  Router + FileRoutes
    ↓
    routes/layout.tsx
      ↓
      routes/blog/layout.tsx
        ↓
        routes/blog/[slug].tsx

2.1.2 示例代码

  1. 建立下列文件路由

    // about
export default function About() {
  return <h1>About页面</h1>
}
// home
export default function Home() {
   return <h1>home页面</h1>
}
// ...

  2. App.jsx 修改

    import { MetaProvider } from "@solidjs/meta";
import { Router } from "@solidjs/router";
import { FileRoutes } from "@solidjs/start/router";
import { Suspense } from "solid-js";

export default function App() {
  return (
    <Router
      root={props => (
        // MetaProvider 用于SEO优化
        <MetaProvider>
          <Suspense>{props.children}</Suspense>
        </MetaProvider>
      )}
    >
      {/* 文件路由 */}
      <FileRoutes />
    </Router>
  );
}

2.2 布局

  1. 根布局

    通过 Router 组件的 root 属性进行根布局

    import { Router } from "@solidjs/router";
import { FileRoutes } from "@solidjs/start/router";
import { Suspense } from "solid-js";

export default function App() {
  return (
    <Router
      root={props => (
        /* 相当于根路由 */
        <div id="app-root">
          <header>网站头部</header>
          <Suspense fallback={<div>加载中...</div>}>
            {props.children}
          </Suspense>
          <footer>网站底部</footer>
        </div>
      )}
    >
      {/* 文件路由 */}
      <FileRoutes />
    </Router>
  );
}

  2. 嵌套布局

    通过创建与文件夹同名的文件来实现布局：

    |-- routes/
|   |-- blog.tsx        # 布局文件
|   |-- blog/
|   |   |-- article-1.tsx
|   |   |-- article-2.tsx

    在 blog.tsx中：

    export default function BlogLayout(props:any) {
  return (
    <div>
      <h1>博客布局</h1>
      {props.children}  {/* 子路由内容 */}
    </div>
  );
}

2.3 组件

2.3.1 SolidJS 特有组件

  1. <For>：高效列表渲染（推荐替代 map）

    <For each={users()}>
  {(user) => (
    <UserItem 
      user={user} 
      onEdit={handleEdit} 
      onDelete={handleDelete} 
    />
  )}
</For>

    优势：

    • 100% SolidJS 推荐方式
    • 自动处理 key（使用数组索引）
    • 性能优化（避免不必要的渲染）

  2. <Show>：条件渲染（替代 if）

    <Show when={users.loading}>
  <p>加载中...</p>
</Show>

<Show when={users.error}>
  <p class="error">错误: {users.error.message}</p>
</Show>

    优势：

    • 更清晰的条件逻辑
    • 避免嵌套的 if 语句
    • 与 SolidJS 响应式系统完美集成

  3. <Suspense>：异步加载（用于数据获取）

    <Suspense fallback={<p>加载用户中...</p>}>
  <UserList />
</Suspense>

    通常用于 createResource 的场景，但 SolidStart 会自动处理加载状态。

2.3.2 自定义组件

  • 写在非 src/routes 的文件都不会生成路由

  • 一般约定为 src/components 下

  • 组件代码

    import { createSignal } from "solid-js";

export default function Counter() {
  const [count, setCount] = createSignal(0);
  return (
    <button class="increment" onClick={() => setCount(count() + 1)} type="button">
      Clicks: {count()}
    </button>
  );
}

  • 路由页面使用组件

    import Counter from "~/components/Counter"
export default function Home() {
   return (
      <>
         <h1>home页面</h1>
         <Counter />
      </>
   )
}

2.4 样式

  1. class 样式

    1. 基础用法（静态类名）

      <div class="container mx-auto p-4">内容</div>

      最佳实践：使用 Tailwind CSS 类名（推荐）或自定义 CSS 类

    2. 动态类名（推荐方式）

      // 正确：使用模板字符串
const isActive = true;
<div class={`user-item ${isActive ? 'active' : ''}`}>内容</div>

// 更简洁：使用条件表达式
<div class={`user-item ${isActive && 'active'}`}>内容</div>

  2. style 样式

    • 基础用法（对象）

      <div style={{ color: 'blue', fontSize: '16px' }}>内容</div>

      注意：键名使用 驼峰式（fontSize 而不是 font-size）,但是react的jsx不认识，可以加引号'font-size'

    • 动态内联样式

      const fontSize = '1.2rem';
<div style={{ fontSize, color: '#333' }}>内容</div>

  3. 样式私有

    • 使用 Tailwind CSS

    • 使用模块化引入

      import styles from "./Card.module.css";

const Card = (props) => {
  return (
    <div class={styles.card}>
      <h1>{props.title}</h1>
      <p>{props.text}</p>
    </div>
  );
};

  4. 代码实践

    • css代码

      p {
  border: 1px solid;
}
.test{
  border-color:red;
  font-size: 12px;
}

    • 应用实例代码

      import "../styles/test1.css"

export default function Home() {
   return (
      <>
         <p class="test">类样式</p>
         <p style={{"border-color":"blue","font-size":"18px"}}>style样式</p>
      </>
   )
}

export default function AboutPage() {

2.6 静态资产

在SolidStart中，/public目录可用于存储静态资源。这些资产在相对于公共目录的确切路径中提供：

|-- public
|   favicon.ico                   ->  /favicon.ico
|   |-- images
|   |   |-- logo.png              ->  /images/logo.png
|   |   |-- background.png        ->  /images/background.png
|   |-- models
|   |   |-- player.gltf           ->  /models/player.gltf
|   |-- documents
|   |   |-- report.pdf            ->  /documents/report.pdf

代码示例

export default function Home() {
   return (
      <>
         <h1>欢迎来到 SolidStart</h1>
         <img src="/images/1.jpeg" alt="" />
      </>
   )
}
