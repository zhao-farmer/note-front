4.1 声明周期钩子

4.1.1 核心生命周期钩子

钩子调用时机典型用途
onMount组件 挂载到 DOM 后发起 API 请求、操作 DOM、启动定时器
beforeUpdateDOM 更新前（响应式变量已变）读取 DOM 状态（如滚动位置）
afterUpdateDOM 更新后与 beforeUpdate 配合做动画、日志
onDestroy组件 销毁前清理定时器、取消订阅、移除事件监听
onStart（服务端）SSR 时组件创建仅用于 SvelteKit 服务端逻辑
tick（工具函数）等待当前更新完成强制同步 DOM 状态

重点掌握前 4 个，tick 是辅助工具。

4.1.2 详细用法 + 示例

  1. onMount —— 挂载后执行（最常用）

    <script>
  import { onMount } from 'svelte';

  let data = null;
  let error = null;

  onMount(async () => {
    //  发起 API 请求
    try {
      const res = await fetch('/api/user');
      data = await res.json();
    } catch (err) {
      error = err.message;
    }

    //  操作 DOM（此时元素已存在）
    const el = document.querySelector('#my-element');
    el.focus();

    //  启动定时器
    const interval = setInterval(() => {
      console.log('Tick');
    }, 1000);

    //  不要在这里返回清理函数！用 onDestroy
  });
</script>

{#if error}
  <p>错误：{error}</p>
{:else if data}
  <p>欢迎，{data.name}！</p>
{/if}

    注意：

    • onMount 只在浏览器中运行（SSR 时跳过）
    • 适合所有需要 DOM 或浏览器 API 的操作

  2. onDestroy —— 销毁前清理（防内存泄漏！）

    <script>
  import { onDestroy } from 'svelte';

  let interval;

  // 启动定时器
  interval = setInterval(() => {
    console.log('Running...');
  }, 1000);

  // 清理资源
  onDestroy(() => {
    clearInterval(interval);
    console.log('组件已销毁，定时器清除');
  });
</script>

<p>查看控制台日志</p>

    必须清理的资源：

    • setInterval / setTimeout
    • 事件监听器（window.addEventListener）
    • 第三方库实例（如地图、WebSocket）
    • 手动订阅的 Store（如果没用 $ 语法）

  3. beforeUpdate + afterUpdate —— 响应式更新前后

    <script>
  import { beforeUpdate, afterUpdate } from 'svelte';

  let count = 0;
  let prevCount = 0;

  // 更新前：保存旧值
  beforeUpdate(() => {
    prevCount = count;
    console.log(`即将从 ${prevCount} 变为 ${count}`);
  });

  // 更新后：操作新 DOM
  afterUpdate(() => {
    console.log(`已更新为 ${count}`);
    // 例如：触发动画
    document.body.style.backgroundColor = 
      count % 2 === 0 ? '#f0f0f0' : '#e0e0e0';
  });

  function increment() {
    count += 1; // 触发更新
  }
</script>

<button on:click={increment}>Count: {count}</button>
<p>上次值：{prevCount}</p>

    典型场景：

    • 记录滚动位置（beforeUpdate 读，afterUpdate 恢复）
    • 自定义过渡动画
    • 性能监控（记录渲染时间）

  4. tick —— 等待当前更新完成（同步 DOM）

    不是钩子，而是工具函数，返回 Promise。

    <script>
  import { tick } from 'svelte';

  let visible = false;

  async function showWithHeight() {
    visible = true;

    // 此时 DOM 还未更新！
    // const el = document.getElementById('box');
    // console.log(el.offsetHeight); // 0!

    // 等待 DOM 更新
    await tick();

    const el = document.getElementById('box');
    console.log('元素高度：', el.offsetHeight); // 正确值
  }
</script>

<button on:click={showWithHeight}>显示并获取高度</button>

{#if visible}
  <div id="box" style="height: 100px; background: lightblue;">
    我是盒子
  </div>
{/if}

    适用场景：

    • 动态测量元素尺寸
    • 确保 DOM 已反映最新状态后再操作

4.1.3 案例：计时器

  1. 代码示例 Timer.svelte

    <!-- Timer.svelte -->
<script>
  // 导入 Svelte 4 生命周期钩子
  import { onMount, onDestroy, beforeUpdate, afterUpdate } from 'svelte';

  // 接收外部传入的倒计时总时长（秒）
  export let duration = 60;

  // 响应式状态
  let timeLeft = duration; // 初始剩余时间
  let isActive = false;    // 是否正在倒计时
  let timerId = null;      // 定时器 ID

  // ===== 1. onMount：组件挂载后执行（可选初始化）=====
  onMount(() => {
    console.log('[onMount] 组件已挂载到 DOM');
    // 例如：从 localStorage 恢复上次时间（可选）
    // const saved = localStorage.getItem('timer-timeLeft');
    // if (saved) timeLeft = parseInt(saved);
  });

  // ===== 2. onDestroy：组件销毁前清理资源 =====
  onDestroy(() => {
    console.log(' [onDestroy] 组件即将销毁，清理定时器');
    if (timerId) {
      clearInterval(timerId);
      timerId = null;
    }
  });

  // ===== 3. beforeUpdate：DOM 更新前调用 =====
  beforeUpdate(() => {
    console.log(`[beforeUpdate] 即将更新 timeLeft: ${timeLeft}`);
    // 注意：此时 timeLeft 已是新值（因为 Svelte 在赋值后才触发更新）
  });

  // ===== 4. afterUpdate：DOM 更新后调用 =====
  afterUpdate(() => {
    console.log(`[afterUpdate] DOM 已更新，当前 timeLeft: ${timeLeft}`);
    // 可用于触发动画、日志、第三方库同步等
  });

  // 启动/暂停倒计时
  function toggle() {
    if (isActive) {
      // 暂停
      clearInterval(timerId);
      timerId = null;
    } else {
      // 开始
      timerId = setInterval(() => {
        timeLeft -= 1;
        if (timeLeft <= 0) {
          clearInterval(timerId);
          timerId = null;
          isActive = false;
          console.log('倒计时结束！');
        }
      }, 1000);
    }
    isActive = !isActive;
  }

  // 重置倒计时
  function reset() {
    if (timerId) {
      clearInterval(timerId);
      timerId = null;
    }
    timeLeft = duration;
    isActive = false;
  }
</script>

<!-- UI -->
<div class="timer">
  <h2>倒计时: {timeLeft}s</h2>
  <div class="controls">
    <button on:click={toggle}>
      {isActive ? '暂停' : '开始'}
    </button>
    <button on:click={reset}>重置</button>
  </div>
</div>

<style>

    padding: 1.5rem;
    border: 1px solid #ddd;
    border-radius: 12px;
    text-align: center;
    max-width: 300px;
    margin: 2rem auto;
    font-family: Arial, sans-serif;
    box-shadow: 0 4px 8px rgba(0,0,0,0.1);
  }
  h2 {
    margin: 0 0 1rem;
    color: #333;
  }
  .controls {
    display: flex;
    justify-content: center;
    gap: 0.75rem;
  }
  button {

  }
</style>

4.2 样式作用域与Css变量

4.2.1 作用域规则详解

  1. 普通类/标签选择器 → 自动作用域化

    <style>
  p { color: red; }          /* → p.svelte-hash */
  .box { padding: 10px; }    /* → .box.svelte-hash */
</style>

  2. 全局样式 → 使用 :global()

    如果你故意想定义全局样式（如重置、第三方库兼容），用 :global()：

    <style>
  /* 全局：影响整个应用 */
  :global(body) {
    margin: 0;
    font-family: Arial;
  }

  /* 全局类：可在其他组件使用 */
  :global(.alert) {
    background: yellow;
    padding: 8px;
  }

  /* 仅当前组件内的 .modal 是全局的 */
  .container :global(.modal) {
    position: fixed;
  }
</style>

    谨慎使用 :global()，避免样式冲突。

  3. 后代选择器 → 自动作用域到组件内

    <style>
.card p { font-size: 14px; }
</style>

    编译为：.card.svelte-hash p.svelte-hash

    只匹配当前组件内 .card 下的 <p>。
