二、流媒体-音频

2.1 音频 <audio>

2.1.1 audio介绍

  1. 基本概念

    元素用于在网页文档中嵌入音频内容。 可以通过 src 属性直接指定音频资源，也可以内部嵌套一个或多个 <source> 标签提供多份音频文件；浏览器会自动选择自身支持的第一个音频资源进行加载播放。 也可以接入媒体流实现流式音频播放。

    重要浏览器策略：现代浏览器禁止无用户交互的自动音频播放，autoplay 在没有点击、触摸等用户行为触发时会直接失效。

  2. 支持的格式

    • MP3(audio/mpeg)：兼容性最强，全平台浏览器通用，网页项目首选格式。
    • AAC(audio/aac / audio/mp4)：音质优于MP3，Safari、移动端支持优秀，一般封装在mp4容器内。
    • Ogg‑Vorbis(audio/ogg)：开源免费格式，老版Firefox、Chrome支持；Safari不支持，不建议作为主资源。
    • WAV(audio/wav)：无压缩无损音频，音质最高，但文件体积巨大，适合短音效，不适合长音频网页播放。
    • WebM‑Opus(audio/webm)：新一代开源音频格式，压缩效率高，适合网页；高版本Safari才完整支持。

    开发建议：主资源提供 mp3，搭配 ogg/webm 做降级兼容。

  3. 基本语法格式

    <audio controls src="00.mp3">

2.1.2 常用HTML属性

布尔属性：写上属性名即代表开启，不需要写属性值；如 controls、loop，等价于 controls="controls"。

  1. src

    • 作用：指定音频资源的URL地址，支持相对路径、网络绝对URL。
    • 特点：只写src不会显示播放器UI；需要搭配controls属性才展示浏览器原生控制面板。
    • 如果使用了<source>子标签，audio标签上的src属性会失效。

    代码示例

    <audio src="00.mp3">

  2. autoplay

    • 属性类型：布尔属性
    • 作用：页面加载完成后尝试自动播放音频。>

    浏览器限制：无用户交互时autoplay会被浏览器拦截。 可行方案：autoplay + muted 组合，静音状态允许自动播放；带声音的自动播放几乎全部被浏览器禁用。

    <!-- 静音自动播放，有声自动播放会被拦截 -->
<audio autoplay muted src="00.mp3">

  3. controls

    • 属性类型：布尔属性
    • 作用：展示浏览器原生音频控制面板，包含播放暂停、进度条、音量、下载按钮。>

    不同浏览器原生播放器样式各不相同，无法通过CSS精细修改原生控件。

    <audio controls src="00.mp3">

  4. loop

    • 属性类型：布尔属性
    • 作用：音频播放结束后自动回到开头循环播放。
    <audio loop controls src="00.mp3">

  5. muted

    • 属性类型：布尔属性
    • 作用：设置音频初始为静音；只控制播放输出音量，不会修改音频源文件本身。
    <audio controls muted src="00.mp3">

  6. preload

    • 属性类型：枚举属性，用于设置浏览器预加载策略，仅为浏览器建议，浏览器有权忽略。>

    preload 对设置了 autoplay 的音频无效，自动播放音频会强制加载资源。

    属性取值：

    • auto：页面加载后尽可能预加载完整音频；适合大概率用户会点击播放的音频，消耗较多带宽。
    • metadata：只预加载音频元信息：时长等基础信息，不下载音频二进制数据；音频文件较大时推荐使用。
    • none：完全不预加载；直到用户点击播放才发起网络请求；节省流量，首次点击会有加载等待。
    <audio controls preload="metadata" src="00.mp3">

  7. crossorigin

    • 作用：处理跨域音频资源；当音频来自外部域名，需要音频解码、频谱分析场景时，需要配置该属性，避免资源跨域限制。
    <audio controls crossorigin="anonymous" src="shturl.cc/gCcurZlezd5iLb">

2.1.3 结合 <source> 使用多格式兼容

<source> 作为audio的子标签，用来提供多份不同编码音频，浏览器从上往下匹配，加载第一个自己支持的资源。

source标签属性

  • src：音频文件路径，必填。
  • type：音频MIME类型，建议写上，帮助浏览器快速判断格式是否支持，不用发起网络请求试探。

音频场景下 sizes、srcset 只用于图片，<source> 不要书写这两个属性。 audio标签内部的普通文本，作为老旧浏览器不支持audio标签时的降级提示文案。

<audio controls preload="metadata">
    <!-- 优先尝试 MP3，兼容性最好 -->
    <source src="audio.mp3" type="audio/mpeg">
    <!-- 备选 Ogg，支持 Firefox/Chrome -->
    <source src="audio.ogg" type="audio/ogg">
    
    <!-- 回退内容：当浏览器完全不支持 <audio> 标签时显示 -->
    <p>您的浏览器不支持音频元素。请 <a href="audio.mp3">点击下载</a> 收听。</p>
</audio>

2.2 js中音频对象

Audio 对象对应HTML的 音频标签，new Audio() 创建的对象本质是 HTMLAudioElement，和页面中DOM标签拥有完全一致的属性、方法、事件。

2.2.1 获取 / 创建音频对象

  1. 获取页面上已有的 `` 标签

    页面已经写好audio标签，通过DOM查询拿到音频对象。

    <audio id="myAudio" src="music.mp3">

<script>
// 方式1：getElementById
let audio1 = document.getElementById('myAudio');

// 方式2：querySelector
let audio2 = document.querySelector('audio');
</script>

  2. DOM方式创建audio元素

    使用document.createElement创建，需要手动追加到DOM树才会显示控件。

    let audio = document.createElement('audio');
audio.src = "music.mp3";
// 添加到页面容器，controls才会可视化显示
document.body.appendChild(audio);

  3. JS内存创建Audio对象（new Audio()）

    new Audio() 在内存创建音频对象，默认不会加入DOM树，不会在页面显示播放器控件；如果需要显示控件，必须appendChild挂载到页面。

    // 内存创建，不在页面
let audio = new Audio();
audio.src = "music.mp3";

// 挂载到页面后，页面出现标签
// document.body.appendChild(audio);

三者对象类型都是 HTMLAudioElement，API完全相同。

2.2.2 基础常用操作

const audio = new Audio();
audio.src = "music.mp3";

// 播放
audio.play();
// 暂停
audio.pause();

// 设置跳转播放位置，单位秒
audio.currentTime = 10;
// 获取当前播放时间
let current = audio.currentTime;

// 设置音量 0 ~ 1
audio.volume = 0.5;
// 获取音量
let vol = audio.volume;

// 开启循环
audio.loop = true;
// 获取循环状态
let loopState = audio.loop;

// 重新加载媒体资源
audio.load();

// 监听播放结束
audio.addEventListener('ended', () => {
  console.log('音频播放结束');
});

浏览器策略：autoplay自动播放需要用户交互之后才生效，页面打开直接自动播放会被浏览器拦截。

2.2.3 常用属性

  1. 读写属性

    const audio = new Audio();

audio.src = "music.mp3";        // 音频资源地址
audio.loop = true;             // 是否循环播放
audio.volume = 0.6;            // 音量 0‑1
audio.muted = false;           // 是否静音
audio.controls = true;         // 是否显示浏览器原生播放控件（挂载DOM后才可见）
audio.autoplay = false;        // 自动播放，受浏览器策略限制
audio.preload = "auto";        // 预加载策略：none / metadata / auto
audio.playbackRate = 1.0;      // 播放倍速，正常1，可大于1加速，小于1减速
audio.currentTime = 0;         // 当前播放时间，秒
audio.crossOrigin = "anonymous";// 跨域配置，Web Audio API解析跨域音频需要

  2. 只读属性

    const audio = new Audio();

audio.duration;        // 音频总时长，单位秒；未拿到元数据时为 NaN
audio.paused;          // 布尔，是否处于暂停状态
audio.ended;           // 布尔，是否播放完毕
audio.currentSrc;      // 实际加载的音频地址
audio.readyState;      // 媒体就绪状态
audio.buffered;        // TimeRanges，已缓冲的时间区间
audio.seekable;        // TimeRanges，可跳转的时间区间
audio.networkState;    // 网络加载状态
audio.error;           // 加载错误对象

2.2.4 对象方法

const audio = new Audio();

audio.play();                // 开始播放，返回Promise，可以捕获播放被拦截异常
audio.pause();               // 暂停播放
audio.load();                // 重新加载媒体资源，切换src后可调用
audio.canPlayType('audio/mpeg'); // 检测浏览器是否支持该音频MIME类型

重要：play() 返回Promise，浏览器阻止播放时会reject，建议捕获异常。

audio.play().catch(err=>{
  console.error("播放被浏览器拦截：",err);
})

2.2.5 事件相关

  1. 音频生命周期事件（加载阶段）

    加载顺序：loadstart → progress → durationchange → loadedmetadata → loadeddata → canplay → canplaythrough

    <script>
    const audio = new Audio();
    audio.src = "music.mp3";

    audio.addEventListener('loadstart', ()=>{
        console.log("loadstart：开始请求音频资源");
    });
    audio.addEventListener('progress', ()=>{
        console.log("progress：正在下载数据");
    });
    audio.addEventListener('durationchange', ()=>{
        console.log("durationchange：总时长更新，此时可以读取duration");
    });
    audio.addEventListener('loadedmetadata', ()=>{
        console.log("loadedmetadata：元数据加载完成，可获取时长");
    });
    audio.addEventListener('loadeddata', ()=>{
        console.log("loadeddata：首帧音频数据加载完成");
    });
    audio.addEventListener('canplay', ()=>{
        console.log("canplay：可以开始播放，但可能会缓冲卡顿");
    });
    audio.addEventListener('canplaythrough', ()=>{
        console.log("canplaythrough：全部缓冲完成，可以流畅播完整首");
    });
    audio.addEventListener('error', ()=>{
        console.log("error：音频加载出错（404、格式不支持、跨域）");
    });
</script>

  2. 播放运行时事件

    <button id="playBtn">播放</button>
<button id="pauseBtn">暂停</button>
<button id="volAdd">音量+</button>
<script>
    const audio = new Audio();
    audio.src = "music.mp3";

    document.querySelector('#playBtn').onclick = ()=> audio.play();
    document.querySelector('#pauseBtn').onclick = ()=> audio.pause();
    document.querySelector('#volAdd').onclick = ()=> {
        audio.volume = Math.min(1, audio.volume + 0.1);
    };

    // 播放位置更新，高频触发
    audio.addEventListener('timeupdate', ()=>{
        console.log("timeupdate 当前时间：", audio.currentTime);
    });

    audio.addEventListener('play', ()=>{
        console.log("play：执行play()，即将开始播放");
    });
    audio.addEventListener('playing', ()=>{
        console.log("playing：真正进入播放状态");
    });
    audio.addEventListener('pause', ()=>{
        console.log("pause：已暂停");
    });
    audio.addEventListener('ended', ()=>{
        console.log("ended：播放结束");
    });
    audio.addEventListener('waiting', ()=>{
        console.log("waiting：缓冲不足，播放等待");
    });
    audio.addEventListener('volumechange', ()=>{
        console.log("volumechange：音量/静音发生变化");
    });
    audio.addEventListener('ratechange', ()=>{
        console.log("ratechange：倍速发生改变");
    });
</script>

2.3 常用示例

  • 示例1：基础播放控制

    <button id="playBtn">播放</button>
<button id="pauseBtn">暂停</button>
<button id="resetBtn">回到开头</button>

<script>
const audio = new Audio();
audio.src = "music.mp3";

document.querySelector('#playBtn').onclick = () => {
    audio.play().catch(err => console.log("播放异常", err));
};
document.querySelector('#pauseBtn').onclick = () => {
    audio.pause();
};
document.querySelector('#resetBtn').onclick = () => {
    audio.currentTime = 0;
};
</script>

  • 示例2：操作页面已存在audio标签

    <audio id="player" src="music.mp3">
<button id="volUp">音量+</button>
<button id="volDown">音量-</button>

<script>
const player = document.querySelector("#player");

document.querySelector("#volUp").onclick = () => {
    player.volume = Math.min(1, player.volume + 0.1);
};
document.querySelector("#volDown").onclick = () => {
    player.volume = Math.max(0, player.volume - 0.1);
};
</script>

  • 示例3：监听播放结束，实现循环播放

    <script>
const audio = new Audio();
audio.src = "music.mp3";

audio.addEventListener("ended", () => {
    console.log("播放完毕，重新播放");
    audio.currentTime = 0;
    audio.play();
});
</script>

  • 示例4：Promise封装，等待音频元数据加载完成获取时长

    /**
 * 加载音频，元数据就绪后返回audio对象
 * @param {string} url 音频地址
 * @returns {Promise<HTMLAudioElement>}
 */
function loadAudio(url) {
  return new Promise((resolve, reject) => {
    const audio = new Audio();
    audio.preload = "metadata";
    audio.addEventListener("loadedmetadata", () => resolve(audio));
    audio.addEventListener("error", err => reject(err));
    audio.src = url;
  });
}

// 使用
async function getAudioInfo() {
  try {
    const audio = await loadAudio("music.mp3");
    console.log("音频总时长：", audio.duration);
  } catch (e) {
    console.error("音频加载失败", e);
  }
}
getAudioInfo();

  • 示例5：监听timeupdate实时拿到播放进度

    <div>当前时间：<span id="timeText">0</span></div>

<script>
const audio = new Audio();
audio.src = "music.mp3";
const timeText = document.querySelector("#timeText");

audio.addEventListener("timeupdate", () => {
  timeText.innerText = audio.currentTime.toFixed(1);
});
</script>

  • 示例6：切换音频资源

    <button data-src="a.mp3">播放A音频</button>
<button data-src="b.mp3">播放B音频</button>

<script>
const audio = new Audio();

document.querySelectorAll("button").forEach(btn => {
  btn.onclick = function () {
    const src = this.dataset.src;
    audio.pause();
    audio.src = src;
    audio.load();
    audio.play().catch(e => console.log(e));
  };
});
</script>

  • 示例7：设置播放倍速

    <button id="speed1">1倍速</button>
<button id="speed2">2倍速</button>
<button id="speed05">0.5倍速</button>

<script>
    const audio = new Audio();
    audio.src = "music.mp3";
    
    document.querySelector("#speed1").onclick = () => audio.playbackRate = 1;
    document.querySelector("#speed2").onclick = () => audio.playbackRate = 2;
    document.querySelector("#speed05").onclick = () => audio.playbackRate = 0.5;
</script>

  • 示例8：检测浏览器是否支持音频格式

    const audio = new Audio();
// 返回 '' / 'maybe' / 'probably'
console.log(audio.canPlayType('audio/mpeg')); // mp3
console.log(audio.canPlayType('audio/aac'));  // aac

  • 示例9：监听缓冲进度

    <script>
const audio = new Audio();
audio.src = "music.mp3";

audio.addEventListener("progress", () => {
  if(audio.buffered.length > 0) {
    const bufferedEnd = audio.buffered.end(audio.buffered.length - 1);
    console.log("已缓冲到：", bufferedEnd);
  }
});
</script>

  • 示例10：挂载内存Audio对象到页面，显示原生控件

    <div id="audioBox"></div>
<script>
    const audio = new Audio();
    audio.src = "music.mp3";
    audio.controls = true;
    document.querySelector("#audioBox").appendChild(audio);
</script>

2.4 注意事项

  1. 自动播放限制：autoplay、代码直接play()，必须由用户点击、触摸交互触发，浏览器会拦截无交互的自动播放。play()是Promise，务必catch捕获拦截异常。
  2. new Audio() 创建的对象存在内存，不会自动显示播放器；想要显示controls控件，必须使用appendChild挂载到DOM树上。
  3. duration 在元数据加载完成前为NaN，不要刚赋值src立刻读取，放到loadedmetadata事件内部读取。
  4. preload 预加载策略：
    • none：不预加载；
    • metadata：只预加载元数据（时长）；
    • auto：浏览器尽可能预加载音频。
  5. 跨域音频：如果配合Web Audio API解码音频，需要设置 crossOrigin="anonymous"，并且后端配置CORS响应头。
  6. 切换音频源：修改src之后，建议调用load()重新加载资源。
  7. timeupdate事件会高频触发，不要在事件内做大量DOM操作，容易造成页面卡顿。
