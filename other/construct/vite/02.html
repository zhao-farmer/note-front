二、 Vite 的基础应用

2.1 vue3 + jsx

  1. 初始化项目

    • 安装命令

      pnpm create vite

    • 选项

  2. 安装 jsx 插件

    • 安装插件

      pnpm install @vitejs/plugin-vue-jsx -D

    • vite.config.js 使用插件

      import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueJsx from "@vitejs/plugin-vue-jsx"

// https://vite.dev/config/
export default defineConfig({
    plugins: [vue(),vueJsx()],
})

  3. 使用jsx

    1. 将App.vue 改为 App.jsx

    2. 修改内容 App.jsx

      import { defineComponent } from "vue";

export default defineComponent({
    setup(){
        return () =>{
            return <div>Hello Vue3 jsx</div>
        }
    }
})

    3. 修改入口文件 main.js

      import { createApp } from 'vue'
import './style.css'
import App from './App.jsx'

createApp(App).mount('#app')

    4. 运行结果

2.4 处理css文件

  1. 初始化项目

      pnpm create vite

    • 安装插件

      # 进入目录
cd 04_css

  2. 原生 css 样式

    • styles/index.css

      :root{
    --main-bg-color: brown;
}

.root{
    color:var(--main-bg-color);
}

    • App.vue 使用样式

      <template>
    <div class="root">Hello Vite</div>
</template>

<script setup>
// 使用原生css
import "./styles/index.css"

    • 运行结果

  3. postcss

    vite 默认引用了postccss,无需额外配置

    PostCSS 的 作用 如： Autoprefixer 插件

    #content {
    display: flex;
}

    编译后

    #content {
    display: -webkit-box;
    display: -webkit-flex;
    display: -ms-flexbox;
    display: flex;
}

  4. 配置css文件映射地址

    1. vite.config.js

      import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vite.dev/config/
export default defineConfig({
plugins: [vue()],
    resolve: {
        alias: {
            '@styles': "/src/styles"
        }
    }
})

    2. 新增 src/styles/other.css

      div{
    background-color: black;
}

    3. App.vue 引入

      <template>
    <div class="root">Hello Vite</div>
</template>

<script setup>
// 使用原生css
import "./styles/index.css"
// 使用相对路径
import "@styles/other.css"

</script>

    4. 运行结果

  5. CSS Modules

    任何以 .module.css 为后缀名的 CSS 文件都被认为是一个 CSS modules 文件。

    1. 新增 src/styles/test.module.css

      .mouduleClass{
    color: yellow;
}

    2. App.vue 中使用

      <template>
<div class="root">
    <span>Hello Vite</span><br>
    <span :class=[testMoudle.mouduleClass]>CSS modules</span><br>
</div>
</template>

<script setup>
// 使用原生css
import "./styles/index.css"
// 使用相对路径
import "@styles/other.css"
// 使用 css module
import testMoudle from "@styles/test.module.css"

</script>

    3. 运行结果

  6. 预编译 css

    只需要安装就可以

    1. 安装 less 插件

      pnpm install less -D

    2. 新建文件 src/styles/test.less

      @textColor: blue;

.less-test{
    color: @textColor;
}

    3. App.vue 中使用

      <template>
    <div class="root">
        <span>Hello Vite</span><br>
        <span :class=[testMoudle.mouduleClass]>CSS modules</span><br>
        <span class="less-test">预编译 LESS</span><br>
    </div>
</template>

<script setup>
// 使用原生css
import "./styles/index.css"
// 使用相对路径
import "@styles/other.css"
// 使用 css module
import testMoudle from "@styles/test.module.css"
// 使用less
import "@styles/test.less"

</script>

    4. 运行结果

2.6 处理静态资源的方法

  1. 初始化项目

    • 安装插件

      # 进入目录
cd 06_static

pnpm install

  2. 文件的使用方式

    • 修改App.vue 代码

      <template>
    <div>
        <span>文件-路径调用</span>
        <img src="./assets/vue.svg" >
    </div>
    <div>
        <span>文件-import引入</span>
        <img :src="logo1" >
    </div>
    <div>
        <span>文件-对象方式</span>
        <img :src="logo2" >
    </div>
</template>

<script setup>
// 直接将文件导入
import logo1 from "./assets/vue.svg"

// 文件对象 - 要以src开头
const logo2 = "/src/assets/vue.svg"
</script>

function timedCount(){

    setTimeout(timedCount, 1000);
}

timedCount()

      2. App.vue 的 script 添加代码

    console.log(e);

  5. web Assembly

    1. 安装插件

      pnpm install -D assemblyscript

    2. 新增 TS 脚本文件 src/fib.ts

      export function fib(n: i32): i32 {
    var a = 0, b = 1
    if (n > 0) {
        while (--n) {
            let t = a + b
            a = b
            b = t
        }
        return b
    }
    return a
}

    3. 执行命令

      ./node_modules/.bin/asc fib.ts --outFile fib.wasm --optimize

    4. App.vue 的 script 添加代码

      import init from "./fib.wasm?init"
init().then(instance =>{
    console.log(instance.exports.fib(10));
})

    5. 运行结果

2.8 vite中 env 环境变量

  1. 初始化项目

    • 安装命令

      pnpm create vite

    • 选项

    • 安装插件

      # 进入目录
cd 08_env
# 安装插件
pnpm install

  2. 查看环境变量

    • 修改App.vue代码

      <script setup>
// 打印环境变量
console.log(import.meta.env);

</script>

<template>
</template>

    • 控制台打印结果

    • 构建后的变量

      构建后的代码，直接转换为实际的值

      • 执行构建命令

        npm run build

      • 打包文件中的环境变量

  3. 自定义环境变量

    • 根目录下新建 .env 文件 (必须以VIT开头的key值才能起作用)

      VITE_TITLE=hello

    • App.vue 的 script 添加代码

      // 自定义环境变量
console.log(import.meta.env.VITE_TITLE);

    • 运行结果

  4. 开发/生产环境的 env 变量

    • 开发环境变量

      • 新建 .env.development

        VITE_AAA=开发环境

      • 执行命令

        npm run dev

      • 运行结果

    • 开发环境变量

      • 新建 .env.production

        VITE_AAA=生产环境

      • 执行命令

        npm run build

      • 代码中展示

  5. 使用 mode 使用不同环境变量

    • 新建 .env.test

      VITE_AAA=test

    • 脚本中使用 mode 新值

      "scripts": {
    "dev": "vite",
    "test": "vite --mode test",
    "build": "vite build",
    "preview": "vite preview"
},

    • 执行脚本

      npm run test

    • 运行结果

  6. 设置环境变量的类型

    • 新建文件 env.d.ts

      /// <reference types="vite/client" />
interface ImportMetaEnv{
    VITE_TITLE: string;
}

    • App.vue 的 script 添加代码

      // 设置的环境变量类型
console.log(typeof import.meta.env.VITE_TITLE);

    • 运行结果
