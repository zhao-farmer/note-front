四、运算符

运算符（Operator） 也叫操作符，是用于对一个或多个操作数（值）进行运算的符号。JavaScript 提供了丰富的运算符，本章将逐一介绍。

4.1 算术运算符

算术运算符用于执行基本的数学运算。

运算符名称示例结果
+加法1 + 12
-减法10 - 55
*乘法2 * 48
/除法10 / 52
**幂运算2 ** 416
%模运算（取余）10 % 31

4.1.1 基本运算示例

let a = 1 + 1;        // 2
a = 10 - 5;           // 5
a = 2 * 4;            // 8
a = 10 / 5;           // 2
a = 10 / 3;           // 3.3333333333333335
a = 10 / 0;           // Infinity（除以0得无穷）
a = 10 ** 4;          // 10000（10的4次方）
a = 9 ** 0.5;         // 3（开平方）
a = 10 % 2;           // 0（10除以2余0）
a = 10 % 3;           // 1（10除以3余1）

4.1.2 自动类型转换规则

JavaScript 是弱类型语言，进行算术运算时会自动进行类型转换：

运算场景转换规则示例
非字符串的算术运算将非数值转换为数值10 - '5' → 10 - 5 → 5
任意值 + 字符串将其他值转换为字符串进行拼接'1' + 2 → '12'
布尔值参与运算true → 1，false → 010 + true → 11
null 参与运算null → 05 + null → 5
undefined 参与运算undefined → NaN6 - undefined → NaN
// 自动类型转换示例
a = 10 - '5';          // 5（'5' 转为 5）
a = 10 + true;         // 11（true 转为 1）
a = 5 + null;          // 5（null 转为 0）
a = 6 - undefined;     // NaN（undefined 转为 NaN）

// 字符串拼接
a = 'hello' + 'world'; // "helloworld"
a = '1' + 2;           // "12"（数字转为字符串拼接）
a = true + '';         // "true"（布尔值转为字符串）

console.log(a);

技巧：利用 值 + '' 可以将任意值隐式转换为字符串，与 String(值) 效果相同但写法更简洁。

4.2 一元正负（+ / -）

一元运算符只需要一个操作数。

运算符名称作用
+正号不改变数值的符号
-负号对数值进行符号取反

核心特点：对非数值类型使用正负运算时，会先将其转换为数值再运算。

let a = -10;
a = -a;
console.log(a);  // 10（负负得正）

let b = '123';
b = +b;          // 等价于 b = Number(b)
console.log(typeof b, b);  // number 123

let c = '123';
c = -c;          // 转为数字并取负
console.log(typeof c, c);  // number -123

技巧：利用 +值 可以将任意值隐式转换为数值，与 Number(值) 效果相同。

4.3 自增与自减

4.3.1 自增（++）

自增运算符使变量立即增加 1。

写法名称返回值对变量的影响
a++后自增自增前的值（旧值）变量 +1
++a前自增自增后的值（新值）变量 +1
let a = 10;

// 后自增：先返回旧值，再自增
let b = a++;   // b = 10，a = 11
console.log(b, a);  // 10 11

// 前自增：先自增，再返回新值
let c = ++a;   // a 先变为 12，c = 12
console.log(c, a);  // 12 12

4.3.2 自减（--）

自减运算符使变量立即减少 1。

写法名称返回值对变量的影响
a--后自减自减前的值（旧值）变量 -1
--a前自减自减后的值（新值）变量 -1
let a = 10;
a--;
console.log(a);  // 9

let b = 10;
let c = --b;
console.log(b, c);  // 9 9（前自减：先减1，再返回值）

4.3.3 综合练习

let n = 5;
let result = n++ + ++n + n;
console.log(result);
// 计算过程：
// n++ → 返回 5，n 变为 6
// ++n → n 先变为 7，返回 7
// n → 此时 n = 7
// 结果：5 + 7 + 7 = 19

4.4 逻辑运算符

逻辑运算符用于执行布尔逻辑运算。

4.4.1 逻辑非（!）

  • 对布尔值取反：true → false，false → true
  • 对非布尔值：先转为布尔值，再取反
let a = true;
a = !a;
console.log(a);  // false

// 双重取反 → 转为布尔值
let b = 'hello';
b = !!b;         // 等价于 Boolean(b)
console.log(b);  // true

技巧：利用 !!值 可以将任意值隐式转换为布尔值。

4.4.2 逻辑与（&&）

  • 两边都为 true 时返回 true，否则返回 false
  • 短路与：如果第一个值为 false，则不会计算第二个值

返回值规则（针对非布尔值）：

条件返回值
第一个值为 false（假值）返回第一个值
第一个值为 true（真值）返回第二个值
// 布尔值运算
let result = true && true;   // true
result = true && false;      // false
result = false && true;      // false
result = false && false;     // false

// 短路特性
true && alert(123);   // alert 会执行（第一个为 true）
false && alert(123);  // alert 不会执行（第一个为 false，短路）

// 非布尔值运算（返回原值）
result = 1 && 2;      // 2（1 → true，返回第二个值）
result = 1 && 0;      // 0（1 → true，返回第二个值 0）
result = 0 && NaN;    // 0（0 → false，返回第一个值）

4.4.3 逻辑或（||）

  • 两边有 true 时返回 true，否则返回 false
  • 短路或：如果第一个值为 true，则不会计算第二个值

返回值规则（针对非布尔值）：

条件返回值
第一个值为 true（真值）返回第一个值
第一个值为 false（假值）返回第二个值
// 布尔值运算
let result = true || false;   // true
result = false || true;       // true
result = true || true;        // true
result = false || false;      // false

// 短路特性
false || alert(123);  // alert 会执行（第一个为 false）
true || alert(123);   // alert 不会执行（第一个为 true，短路）

// 非布尔值运算（返回原值）
result = 1 || 2;            // 1（1 → true，返回第一个值）
result = "hello" || NaN;    // "hello"（"hello" → true）
result = NaN || 1;          // 1（NaN → false，返回第二个值）

4.4.4 逻辑运算符总结

运算符名称找值逻辑返回值类型
&&逻辑与找 false，找到就返回原值
``逻辑或
!逻辑非取反布尔值

4.5 关系运算符

关系运算符用于比较两个值之间的关系，成立返回 true，不成立返回 false。

运算符含义示例
>大于10 > 5 → true
>=大于等于5 >= 5 → true
<小于5 < 10 → true
<=小于等于10 <= 5 → false

4.5.1 转换规则

场景转换规则示例
非数值比较先转换为数值再比较'5' < 10 → 5 < 10 → true
两个字符串比较不转数值，逐位比较 Unicode 编码'ab' < 'b' → true
// 数值比较
let result = 10 > 5;      // true
result = 5 > 5;           // false
result = 5 >= 5;          // true

// 自动类型转换
result = 5 < '10';        // true（'10' → 10）
result = '1' > false;     // true（false → 0，1 > 0）
result = 'a' < 'b';       // true（a 的编码小于 b）
result = 'z' < 'f';       // false（z 的编码大于 f）
result = 'abc' < 'b';     // true（先比较第一个字符 a < b）

// 字符串数字的比较
result = '12' < '2';      // true（逐位比较：'1' < '2'）
// 如果需要按数值比较，请先转换：
result = Number('12') < Number('2');  // false

重要：比较两个字符串格式的数字时，一定要先进行类型转换，否则会按字符编码逐位比较。

4.5.2 区间判断

let num = 60;

// 错误写法：5 < num < 10 等价于 (5 < num) < 10 → true < 10 → 1 < 10 → true
// result = 5 < num < 10;  // 永远为 true！

// 正确写法：使用逻辑与
let result = 5 < num && num < 10;
console.log(result);  // false（60 不在 5~10 之间）

4.6 相等运算符

4.6.1 对比表

运算符名称自动类型转换说明
==相等会转换比较值是否相等
===全等不转换比较值和类型是否都相等（推荐）
!=不等会转换比较值是否不相等
!==不全等不转换比较值和类型是否不全等（推荐）

4.6.2 特殊规则

比较组合结果说明
null == undefinedtrue特殊规则
null === undefinedfalse类型不同
NaN == NaNfalseNaN 与任何值都不相等
NaN === NaNfalse同上
// 相等运算符（==）
let result = 1 == 1;          // true
result = 1 == 2;              // false
result = 1 == '1';            // true（'1' → 1）
result = true == '1';         // true（true → 1，'1' → 1）
result = null == undefined;   // true（特殊规则）
result = NaN == NaN;          // false（NaN 不与任何值相等）

// 全等运算符（===）—— 推荐使用
result = 1 === '1';           // false（类型不同）
result = null === undefined;  // false（类型不同）
result = 1 === 1;             // true

// 不等（!=）
result = 1 != 1;              // false
result = 1 != '1';            // false（类型转换后相等）

// 不全等（!==）—— 推荐使用
result = 1 !== 1;             // false
result = 1 !== '1';           // true（类型不同）

最佳实践：除非有特殊需求，否则始终使用 === 和 !==，避免因自动类型转换导致的意外结果。

4.7 条件运算符（三元运算符）

  1. 语法

    条件表达式 ? 表达式1 : 表达式2

  2. 执行流程

    1. 对条件表达式求值
    2. 如果为 true → 执行并返回表达式1
    3. 如果为 false → 执行并返回表达式2
    let a = 10, b = 20;

// 使用三元运算符取最大值
let max = a > b ? a : b;
console.log(max);  // 20

// 等价于 if-else 写法
// if (a > b) {
//     max = a;
// } else {
//     max = b;
// }

4.8 运算符优先级

JavaScript 中的运算符有明确的优先级，与数学中"先乘除后加减"类似。

  • 优先级越高，越先执行
  • 优先级相同时，一般按从左到右的顺序执行
  • 使用 ( ) 可以手动改变优先级（括号内先执行）

  1. 常见优先级（从高到低）

    优先级运算符说明
    最高( )括号
    高++ -- ! + -（一元）自增/自减/非/正负
    中**幂运算
    中* / %乘/除/取余
    中+ -加/减
    低< > <= >=关系运算符
    低== === != !==相等运算符
    低&&逻辑与
    更低`
    最低?:条件运算符
    let a = 1 + 2 * 3;      // 7（先乘后加）
a = (1 + 2) * 3;        // 9（括号改变优先级）

// 逻辑运算符优先级：&& 高于 ||
a = (1 && 2) || 3;      // 2
console.log(a);

  2. 完整优先级参考

    完整的运算符优先级表格请参考 MDN 文档： https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Operator_precedence

建议：遇到不确定优先级的情况，使用 ( ) 明确指定执行顺序，既能保证结果正确，也提高了代码可读性。

4.9 类型转换 —— 显式与隐式

类型转换分为显式转换（手动调用函数）和隐式转换（自动发生）。

目标类型显式转换隐式转换（技巧）说明
字符串String(值)值 + ''利用字符串拼接
数值Number(值)+值利用一元正号
布尔值Boolean(值)!!值利用双重取反
// ── 转换为字符串 ──
let x = 123;
x = x + '';              // 隐式转换
console.log(typeof x, x);  // string "123"

x = true;
x = x + '';
console.log(typeof x, x);  // string "true"

// ── 转换为数值 ──
let y = '123';
y = +y;                  // 隐式转换
console.log(typeof y, y);  // number 123

y = false;
y = +y;
console.log(typeof y, y);  // number 0

// ── 转换为布尔值 ──
let z = '123';
z = !!z;                 // 隐式转换
console.log(typeof z, z);  // boolean true

z = 0;
z = !!z;
console.log(typeof z, z);  // boolean false
